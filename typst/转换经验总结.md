## 关键根因与修复

### 1. 公式统计为零，首先检查 AST 遍历

最重要的早期问题不是公式转换器，而是 `collect_formulas()` 只处理字典，不递归列表。Pandoc 正文、内联内容和嵌套环境大量存在于列表中，因此几乎所有公式都被漏掉。

修复后同时递归 `dict` 和 `list`，再收集 `Math` 节点。统计来自 Pandoc 的 Math 节点，不包含尚未解析为 Math 的原始块。只看 PDF 能否生成，无法发现这种内容漏提取。

### 2. 分清三层语法，避免反复替换

转换过程中同时存在 Python 字符串、LaTeX 源码、Typst 标记与代码。每一层的转义规则不同。

- `PRELUDE.format()` 中，只有 `margins` 和 `fontsize` 是占位符。模板中的其他字面花括号必须转义。
- `typst_margins()` 已返回完整的 `(x: …, y: …)`，模板使用 `margin: {margins}`，不能再包一层括号。
- Typst 标记文本通过统一的 `esc()` 转义，补上了容易遗漏的反引号。否则 LaTeX 的双反引号会启动 Typst 原始文本语法。
- Typst 字符串统一通过 `json.dumps(..., ensure_ascii=False)` 序列化，处理反斜杠、引号和控制字符。不要在多个函数里重复手工替换。
- 一份公式只保留一对 `$`。嵌入显示公式前，正确剥掉转换结果的外层定界符，避免双重包裹。

**对上一份记录的两点纠正：** Typst 字符串中的 `\"` 本身是合法的引号转义，不能仅凭出现该字节序列就断定它导致未闭合。`paper: "us-letter"` 是本次实际编译通过的写法，`us-letter` 应作为字符串传入。修复必须以最小样例和实际编译结果为依据。

### 3. “有返回值”不等于公式转换成功

Pandoc 遇到不支持的公式时，也可能返回逃逸后的 LaTeX 文本。原脚本把这类结果当作已转换，导致 `math_failed=0` 与实际输出不一致。

现在检查返回值是否为预期的 Typst 数学表达式，拒绝把逃逸后的原始 LaTeX 标记成成功。无法转换的内容保留为可解析的文本，而不是把原始 LaTeX 直接拼进 Typst 语法。

后续又恢复了 **18,579 个原本以 LaTeX 字串保留的公式片段**。主要可恢复原因是旧式字体开关和对齐环境处理不当：

- `F_{\rm presc}` 等旧式分组规范化为 `\mathrm{…}`。
- `\bf`、`\it`、`\sf`、`\tt`、`\cal` 使用明确分组。
- `align` 等环境转为 `aligned`，保留行列结构。直接删除环境外壳会让开头的 `&` 失去语法上下文。
- `\hbox{…}` 转为 `\text{…}`；修复 `\overline\operatorname{…}` 的分组。

每篇恢复之后都重新编译；只有完整文档编译成功才保留修改，否则回到原先已通过编译的版本。较大的回退集合分成小批转换，避免单一异常或大批量解析拖住全部恢复。

### 4. 编号和引用必须使用同一次编号遍历

原实现用两个不同的 Emitter 做预遍历和输出遍历，编号缓存没有共享。改为同一实例分两遍执行，并在输出前清空预遍历文本。

公式编号也不能用临时 tuple 的对象地址作为缓存键：临时对象地址会复用，造成不同公式得到同一编号。现在使用稳定的节点身份，重复出现的相同公式也可以分别编号。

定理、方程在所属主章节变化时正确重置计数器。定理正文的斜体包装内部也可能含 DisplayMath，必须登记它们的编号和标签，而不能只处理段落最外层的公式。

本项目采用字面编号，避免二次编号叠加。`#equation()` 不是所用 Typst 版本的有效接口；普通数学使用 `$ … $`，全局数学样式使用 `math.equation`。

### 5. 函数调用与正文文本不能混用代码上下文

`thm(head, body)` 使用 `#thm([标题])[正文]`，不再只传命名的 `head` 而漏传 `body`。

图内容放进内容块后再传给 `figure`，否则图中的坐标、文本或数学会被当作代码表达式解析。外部图片调用使用 `#image(...)`；LaTeX 的 `\linewidth` / `\textwidth` 转为 Typst 尺寸。

同时修复了内联 `Space`、`SoftBreak`、`LineBreak` 被忽略的问题。空格丢失不仅影响阅读，还会让 `#emph[…](数字)` 被解析为追加的函数调用。

### 6. Pandoc AST 与 Typst 版本都需要真实兼容测试

本次环境为 Pandoc **3.8.3**、Typst **0.15.1**。

- Figure 接受实际出现的三项与四项结构。
- Table 使用真实的 `head / bodies / foot` 顺序，并解析行、单元格、跨行与跨列信息。
- 有序列表使用 `enum` 的编号设置，而不是 `list(numbering: …)`。
- 移除不被接受的 `quote` 参数。
- 对 Pandoc 输出而 Typst 0.15.1 不接受的符号名称进行明确映射，如 `times.circle`、`dot.circle`、`minus.circle` 和 `sect`。

不能只凭旧文档或上一轮经验猜接口。先打印一个实际节点、生成一个最小 Typst 文件，通常比对整篇输出反复替换更有效。

### 7. 参考文献必须完整纳入转换

有论文同时引用多份 `.bib`，只复制目录里找到的第一份会遗漏大量引用。现在按正文 `\bibliography{…}` 指定的文件收集合并，并按键去重。

- `refs.original.bib` 保留原始合并内容，`refs.bib` 为适合 Typst 解析的版本。
- 日期如 `month={8 March}` 拆成月、日字段。
- 带文章号的页码规范化，原始页码定位保留到说明字段。
- `year={n.d.}` 等不适合年份字段的值移到说明文本。
- 多文献引用分别调用 `cite`，不把多个位置参数传给一次调用。
- 带 `+` 等特殊字符的键使用 `label("键")`。
- `thebibliography` 在送入 Pandoc 前单独提取、登记键，再写回正文。

文献文字转换失败时，回退文本也必须经过标记转义，不能把未经处理的 LaTeX 拼进 Typst。源文档缺失的文献键保留为可见键，并记入报告。

## 统计口径和仍需核对的内容

报告累计收集了 **765,069 个按每篇去重的 Math 条目**。最终报告中的 `math_failed` 累计为 **7,601**；它是转换诊断计数，不能直接等同于 PDF 页面上剩余的原始公式字串。

`latex_literals_remaining` 另行扫描最终 `.typ` 中显式保留的 LaTeX 数学字串，累计为 **4,295 个，分布于 529 份文档**。`stats` 和 `samples` 的部分记录来自恢复前的转换阶段，因此阅读报告时要区分初始诊断与最终输出。

编译通过证明源文件语法和所用接口可被接受，不证明数学语义、每个引用、编号、长公式宽度及全部页的布局已经完全与原文一致。仍有复杂公式、原始块和未解析引用需要结合原文核对。图重绘按用户要求不属于本次任务。

本次最有用的经验是：**先保证内容被提取，再保证转换成功的判断真实，最后验证整篇编译和实际页面。** 清理缓存或反复删除输出不能替代对生成位置、AST 结构和转义边界的检查。

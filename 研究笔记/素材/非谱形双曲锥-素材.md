# 一、定理总览

## 1.1 摘要原文（main.tex 第 34–39 行）

```latex
\begin{abstract}
We construct a homogeneous polynomial of degree $16$ in $23$ real variables
whose hyperbolicity cone has no representation by a finite homogeneous
real symmetric linear matrix inequality. This disproves the geometric Generalized Lax
conjecture.
\end{abstract}
```

注意摘要口径是"16 次、23 变量"——那是 §7（reduced-polynomial）把 `det X` 因子去掉之后的**归约多项式** $q$；正文主定理（Theorem 1.1）构造的是 **20 次**的 $p$。摘要选 16 这个数字，是因为结论对 $p$ 与 $q$ 同等成立而 16 更"漂亮"（更小的次数、同一批变量），Lean 里则只形式化了 20 次版本（见 §四）。

## 1.2 被否定的对象：几何版 Generalized Lax 猜想（精确陈述照抄）

01-introduction.tex 第 4–23 行给出全部前置定义与猜想陈述：

```latex
A homogeneous polynomial $p\in\R[x_1,\ldots,x_m]$ of degree $d\geq1$ is
\emph{hyperbolic with respect to} $e\in\R^m$ if $p(e)\ne0$ and every root of
$t\mapsto p(te-x)$ is real for every $x\in\R^m$.
Write these roots, with multiplicity, as $\lambda_1(x),\ldots,\lambda_d(x)$.
The closed hyperbolicity cone is
\[
 \Lambda_+(p,e)=\{x\in\R^m:\lambda_j(x)\geq0\text{ for }1\leq j\leq d\}.
\]
We write $\Sym^N$ for the real symmetric $N\times N$ matrices and
$A\succeq0$ (respectively, $A\succ0$) for positive semidefiniteness
(respectively, positive definiteness).
A cone is \emph{spectrahedral} if it has the form
\begin{equation}
 K=\{x\in\R^m:L(x)\succeq0\},\qquad
 L(x)=\sum_{i=1}^m x_iA_i,\quad A_i\in\Sym^N,
 \label{eq:spectrahedral}
\end{equation}
for some finite $N\geq1$.
The geometric Generalized Lax conjecture asserts that every hyperbolicity
cone is spectrahedral. We give a counterexample.
```

拆成机械要点：
- 双曲性只对**齐次**多项式定义，方向 $e$ 要求 $p(e)\ne0$；"对每个 $x$，$t\mapsto p(te-x)$ 的根全实"。
- 闭锥 $\Lambda_+(p,e)$ 由**重根计数的** $\lambda_j(x)\ge0$ 定义（带重数 $1\le j\le d$）。
- "spectrahedral" 的定义是**齐次**线性 pencil：$L(x)=\sum x_iA_i$，无常数项，且要求 $N$ 有限；变量个数与锥所在空间维数相同（**不允许辅助变量**、不允许仿射平移）。
- 猜想全称量化在"每个双曲性锥"上，所以反例只需一个。

01-history.tex 第 9–11 行强调了这一"几何/直接表示"口径与经典的"确定行列式表示"口径的区别：

```latex
That obstruction does not exclude a different determinant, with additional
factors, from defining the same cone. The geometric conjecture concerns this remaining
possibility.
```

以及第 34–40 行的 shadow 口径切割：

```latex
A \emph{spectrahedral shadow} is a linear image of a set defined by an
affine real symmetric linear matrix inequality.
Netzer and Sanyal proved that a hyperbolicity cone is a spectrahedral
shadow when every nonzero boundary point is a smooth point of the
defining polynomial~\cite[Theorem~1.1]{netzer-sanyal-2015}.
Our result concerns a direct representation in the original variables;
it makes no assertion about representations using auxiliary variables.
```

## 1.4 主定理与推论（01-introduction.tex 第 27–89 行，逐字照抄）

构造层（第 27–61 行）：

```latex
All indices in $\{1,2,3\}$ in the following construction are cyclic.
For $z,y\in\R^3$, let
\begin{equation}
 b(z,y)=\sum_{i=1}^3 z_i^2y_i^2
       -2\sum_{1\leq i<j\leq3}z_iy_iz_jy_j
       +\sum_{i=1}^3z_i^2y_{i+1}^2.
 \label{eq:form}
\end{equation}
This is the coefficient-one Choi--Lam biquadratic
form~\cite[Section~4]{choi-lam-1977}.
Define $Q(y)\in\Sym^3$ by
\[
 Q(y)_{ii}=y_i^2+y_{i+1}^2,\qquad
 Q(y)_{ij}=-y_iy_j\quad(i\ne j),
\]
so that $b(z,y)=z^\top Q(y)z$.
For $a\in\R$, $r\in\R^3$ and $T\in\Sym^3$, define the linear map
$\Phi_y:\Sym^4\to\Sym^4$ by
\begin{equation}
 \Phi_y\!\begin{pmatrix}a&r^\top\\r&T\end{pmatrix}
 =\begin{pmatrix}
    \tr(Q(y)T)&-r^\top Q(y)\\
    -Q(y)r&aQ(y)
   \end{pmatrix}.
 \label{eq:phi}
\end{equation}
The dependence on $y$ is homogeneous quadratic. If $\adj X$ denotes the
adjugate of $X$, set
\begin{equation}
 p(X,Z,y)=\det\big((\det X)Z-\Phi_y(\adj X)\big),
 \qquad (X,Z,y)\in\Sym^4\times\Sym^4\times\R^3.
 \label{eq:polynomial}
\end{equation}
This formula is polynomial even when $X$ is singular. The ambient space
has dimension $10+10+3=23$.
```

主定理（第 63–72 行）：

```latex
\begin{theorem}\label{thm:main}
The polynomial \eqref{eq:polynomial} is homogeneous of degree $20$ and
hyperbolic with respect to $e=(I_4,I_4,0)$, with $p(e)=1$.
Its closed hyperbolicity cone $K=\Lambda_+(p,e)$ is not spectrahedral:
for every finite $N\geq1$ and every real linear map
$L:\Sym^4\times\Sym^4\times\R^3\to\Sym^N$,
\[
 K\ne\{(X,Z,y):L(X,Z,y)\succeq0\}.
\]
\end{theorem}
```

定理后的口径说明（第 74–76 行）与归约推论（第 78–83 行）：

```latex
The conclusion concerns the cone itself, so it allows every possible
defining pencil and every finite matrix size. The compact formula for $p$
is convenient for the proof, but one determinant factor can be removed.

\begin{corollary}\label{cor:reduced}
The quotient $q=p/\det X$ extends to a homogeneous polynomial of degree
$16$ in the same $23$ variables. It is hyperbolic with respect to $e$,
with $q(e)=1$, and $\Lambda_+(q,e)=K$. In particular, its closed
hyperbolicity cone is not spectrahedral.
\end{corollary}
```

第 85–89 行的两条约定性说明：

```latex
We prove the degree reduction in Section~\ref{sec:reduced}, after the
obstruction argument. We make no claim that the dimension or degree is
minimal. The real symmetric convention also covers Hermitian pencils:
for a Hermitian matrix $H=A+iB$, positivity is equivalent to positivity
of the real symmetric matrix $\left(\begin{smallmatrix}A&-B\\B&A\end{smallmatrix}\right)$.
```

## 1.5 总体构造分层（四层 + 一次归约）

**第 0 层（标量障碍）** $b:\R^3\times\R^3\to\R$，eq:form。它是 Choi–Lam 系数 1 的双二次形式：非负、非零，但**支配不了任何非零双线性平方**（Lemma 2.1）。这一层是整个反例的"炸药"。

**第 1 层（把标量形式装进矩阵）** $Q(y)\in\Sym^3$ 使 $b(z,y)=z^\top Q(y)z$；再定义 $\Phi_y:\Sym^4\to\Sym^4$（eq:phi）：把 $4\times4$ 分块矩阵 $\begin{pmatrix}a&r^\top\\ r&T\end{pmatrix}$（$a\in\R,r\in\R^3,T\in\Sym^3$）映为 $\begin{pmatrix}\tr(Q(y)T)&-r^\top Q(y)\\-Q(y)r&aQ(y)\end{pmatrix}$。它对分块变量线性，对 $y$ 二次齐次（$\Phi_{sy}=s^2\Phi_y$）。关键恒等式（03-hyperbolic 第 10–15 行 eq:rank-one）：

```latex
 u^\top\Phi_y(vv^\top)u
 = (v_0u'-u_0v')^\top Q(y)(v_0u'-u_0v')
 = b(v_0u'-u_0v',y).
```

这条等式把"$\Phi_y$ 是正映射"与"$b\ge0$"钉在一起（秩 1 验证 + 非负组合），又把后面切空间里出现的 $v_0u'-u_0v'$（Lean 里叫 `wedgeCoordinates`）与 $b$ 的 $z$ 变量对上。

**第 2 层（多项式与双曲锥）** $p=\det((\det X)Z-\Phi_y(\adj X))$，eq:polynomial。用 $\adj X$ 而不是 $X^{-1}$ 是为了在 $X$ 奇异时仍是多项式。变量空间 $\Sym^4\times\Sym^4\times\R^3$，维数 23，$p$ 20 次，$e=(I_4,I_4,0)$，$p(e)=1$。锥 $K=\Lambda_+(p,e)$。

**第 3 层（两个切片把锥的形状写死）** Prop 3.2：$X\succ0$ 时 $(X,Z,y)\in K\Longleftrightarrow Z\succeq\Phi_y(X^{-1})$；$y=0$ 时 $(X,Z,0)\in K\Longleftrightarrow X\succeq0\land Z\succeq0$。前者提供"Schur 阈值"语义，后者提供"L_1、L_2 是正映射 + $(-I_4,I_4,0)\notin K$ + $(I_4,-\varepsilon I_4,0)\notin K$"这三把刀。

**第 4 层（障碍链）** 任取假想 pencil $L$ 表示 $K$：
1. Prop 4.1：沿 $(X,s^2Z,sy)$ 重标度 + 取下界 + Schur 补，得到**等价分块不等式** $Z\succeq\Phi_y(X^{-1})\Longleftrightarrow E(Z)\succeq B(y)^\top D(X)^{-1}B(y)$，其中 $D,E$ 是正 unital 映射（$D(I_4)=I_a,E(I_4)=I_c$，$a,c\ge1$），$B:\R^3\to\R^{a\times c}$ 线性。
2. Prop 5.1：令 $X_t=vv^\top+t(I-vv^\top)$、$Z_t=uu^\top+t(I-uu^\top)$ 把 $X^{-1},Z^{-1}$ 推向秩 1 投影，两条 $r$ 的闭射线端点重合给出**精确算子范数恒等式** $b(v_0u'-u_0v',y)=\norm{P(v)B(y)R(u)}_{\op}^2$，其中 $P(v)=\proj_{\ker D(I-vv^\top)}$、$R(u)=\proj_{\ker E(I-uu^\top)}$ 由单位球面 $S^3$ 参数化。
3. §6：在常秩邻域里对 $R$ 求一阶变分（$P(v)$ 固定），得 $b(Jh,y)=\norm{P(v)B(y)dR_v(h)}_\op^2$；$J:v^\perp\to\R^3,\ h\mapsto v_0h'-h_0v'$ 是同构，于是 $F(z,y)=P(v)B(y)dR_v(J^{-1}z)$ 的每个矩阵元都是满足 $\ell_{ij}(z,y)^2\le b(z,y)$ 的双线性形式，Lemma 2.1 逼其全零，进而 $b\equiv0$，与 $b(e_1,e_1)=1$ 矛盾。

**归约层** §7：用 $16\times16$ 分块行列式 $q=\det\begin{pmatrix}I_3\otimes X&C^\top\\ C(Q(y)\otimes I_4)&Z\end{pmatrix}$ 显式给出 $p=(\det X)q$，从而 $q$ 16 次、锥不变（靠 $q$ 对 $y$ 为偶 + Gärding 凸性把 $X\succeq0$ 从 $K_q$ 里逼出来）。

## 1.6 关键常数 / 参数账目（速览，详表见 §五）

- $4$：pencil 块矩阵的阶数（$\Sym^4$），也是 $\Phi_y$ 的分块尺寸 $1+3$；决定 $(\det X)^4$ 的 4、$\det(tI_4-X)^4$ 的重数 4、$\adj X$ 的 3 次。
- $3$：$y,z\in\R^3$、$Q(y)\in\Sym^3$、循环指标模 3、$K_i$ 三个、$C\in\R^{4\times12}$ 的 12、$I_3\otimes X$ 的 12。
- $23=10+10+3$：$\dim\Sym^4=10$（$4\cdot5/2$）两份加 $y$ 的 3。
- $5$：矩阵 $(\det X)Z-\Phi_y(\adj X)$ 每元素的齐次次数（$4+1=5$；$3+2=5$）。
- $20=4\times5$：外层 $4\times4$ 行列式的次数。
- $16=20-4$：$q$ 的次数；也等于 $3\times4+4$（$(\det X)^3\det Z$ 在 $y=0$ 切片的次数）。

## 1.7 `[推测]` 为什么这样选参数与障碍

以下都是推测，论文未述（除括注中已明说的部分）：

1. **为什么必须是"非负但支配平方全零"的形式**。`[推测]` 障碍链的最后一步只用到"$b$ 非负且 weakly extremal（支配平方强制为 0）"这一对性质；要得到矛盾还需要 $b\not\equiv0$（论文在 §6 结尾就用了 $b(e_1,e_1)=1$）。所以候选必须同时是"非负双二次 + 系数刚性极强"。Choi 1975 的系数 2 形式非负但（据 Choi–Lam 的定理 4.4 系）是极端元素；系数降到 1 后仍非负（这正是 Choi–Lam 的 §4 例子），而"非负但支配不了平方"恰好是它在弱极端性意义下的特征。`[推测]` 也就是说：选 Choi–Lam 系数 1 形式不是审美，而是"$b(z,y)$ 在 $z=e_i+s e_{i-1},y=e_{i-1}+s e_i$ 上恰好 4 阶消隐（$b=s^4$）"这种**精确到阶数**的接触条件很难再在更简单的形式上实现——系数 2 的 Choi 形式在该曲线上会给出 $2s^4$ 之类，仍然 $O(s^4)$，所以严格说这条推测偏弱，见 §二 Lemma 2.1 的 (c)(d) 讨论。
2. **为什么 $4\times4$ 与 $\Sym^3$ 的分块**。`[推测]` $\Phi_y$ 的定义需要"把 $Q(y)$ 的 $3\times3$ 二次信息以线性方式塞进 $4\times4$ 对称矩阵，并且秩 1 测试正好还原 $b$"。$1+3$ 分块是最小的能把 $\tr(QT)$、$-Qr$、$aQ$ 三项都放进去的尺寸；$\Sym^4$ 又给出 $\det X$ 的 4 次幂，与外层 $\det$ 的 4 次方相乘正好凑出 $(\det X)^4\det(Z-\Phi_y(X^{-1}))$，使 $p$ 在 $y=0$ 切片的根重数为 $4$（$X$ 的每个特征值重复 4 次）——这个 4 直接决定 $(t-1)^{16}t^4$ 的形态，也决定 $q$ 的切片 $(\det X)^3\det Z$ 是合法因子。
3. **为什么留 $\det X$ 因子再删掉**。`[推测]` $(\det X)Z$ 让矩阵整体齐次（每元素 5 次），比直接写 $Z-\Phi_y(X^{-1})$（不是多项式）更容易论证齐次性与双曲性；而摘要需要"16 次"这个更小的数，就用 $16\times16$ 分块行列式把因子显式化。论文自己给的理由是"compact formula convenient for the proof / one determinant factor can be removed"。
4. **为什么障碍取"一阶变分 + 算子范数"而不是行列式比较**。论文在 §5 末尾与 §1.3 各有一句：机制"It applies to an arbitrary hypothetical pencil without comparing its determinant with $p$."（01-introduction 第 124–127 行）。`[推测]` 这是有意避开 Helton–Vinnikov 式"det L(x) 与 p 的因式关系"路线，因为那条路线在几何（cone-level）口径下会被额外的行列式因子绕过——history 明确说 Brändén 型障碍"does not exclude a different determinant, with additional factors, from defining the same cone"。
5. **为什么 $v_0\ne0$ 与 $\Omega$**。`[推测]` $J$ 只在 $v_0\ne0$ 时单射；把参数球限制到 $\Omega$（半球开集）既保住开邻域（常秩论证需要开集），又保住 $J$ 同构。若选 $v_0=0$ 的赤道点，$J$ 退化为 $h\mapsto -h_0v'$，秩 1，无法覆盖全部 $z\in\R^3$。
6. **为什么 $e=(I_4,I_4,0)$**。`[推测]` 需要 $p(e)\ne0$ 且归一化为 1，取 $y=0$ 使 $\Phi_0=0$、$X=Z=I$ 使 $\det X=1$、$\adj X=I$，一眼算出 $p(e)=\det(I)=1$；同时 $e$ 落在 $X\succ0$ 的开切片内，从而 $e$ 是 $K$ 内点（Prop 3.2 末段），这是 §4 压缩 pencil 的前提。

**第一步：把 $b$ 看作 $y$ 的二次型并写出矩阵。** 原文（第 23–32 行）：

### (c) 假设与常数的机械性理由

- **"$b$ 非负"用在两处**：一是让支配条件 $\ell^2\le b$ 有意义（右边非负，才能推出"$b$ 的零点处 $\ell=0$"）；二是 §5 里 $A_t\succeq0$、以及 §5 末尾"$\alpha=u^\top\Phi_y(vv^\top)u\ge0$"从而 $\lambda_{\max}(\alpha uu^\top)=\alpha$（即便 $\alpha=0$ 也成立，论文特意写了 "also when $\alpha=0$"）。去掉非负性：第五步的"零点消元"立刻失效（$b=0$ 不再蕴含 $\ell=0$）。
- **"$b$ 非零（$b(e_1,e_1)=1$）"**：唯一用途在 §6 末句"contradicting $b(e_1,e_1)=1$"。若 $b\equiv0$，整条障碍链只给出恒等式 $0=\norm{\cdot}^2$，不矛盾。
- **"$\ell$ 双线性 + 对所有 $z,y$ 一致支配"**：支配必须**全局**，因为第五步取特殊点、第六步取 8 个符号点、第八步取一族趋于零的曲线点，都要求同一个不等式逐点成立。若只在某邻域成立，第八步仍能（$s$ 小即可），但第六步的 8 个点在单位立方体顶点、第五步在基向量上，会掉出邻域。
- **为什么是"四次"接触**：第八步的曲线 $z=e_i+se_{i-1},y=e_{i-1}+se_i$ 满足 $b(z,y)=s^4$，而 $\ell$ 沿它只有 $O(s)$ 的一次项（因为次对角已归零）。$s^4$ 与 $s^2$ 的阶差正是消对角系数的引擎：$\,(c_i+c_{i-1})^2s^2\le s^4\,$ 逼 $c_i+c_{i-1}=0$。如果 $b$ 沿该曲线只是二阶（$Cs^2$），就只能得到 $(c_i+c_{i-1})^2\le C$，完全无信息。这也是 01-introduction 第 99–100 行"every bilinear form ... zeros and curves along which $b$ vanishes to fourth order"的字面所指。
- **$3$ 个指标 / 循环**：三阶行列式的循环结构才让 AM–GM 恰好三项；$\Sym^3$ 与 $1+3$ 分块（$\Sym^4$）绑定。
- **弱极端性口径**：02-form 第 8–9 行明确说本条只是 Choi–Lam Theorem 4.4 的一个"particular consequence"，且论文自己证它，所以本篇不依赖 Choi–Lam 的完整极端性理论。

### (d) `[推测]` 候选失败路线

1. `推测` **用 Choi 系数 2 的形式替代**：Choi 1975 的 $b_2(z,y)=\sum z_i^2y_i^2-2\sum_{i<j}z_iy_iz_jy_j+2\sum z_i^2y_{i+1}^2$（history 第 42–45 行说 Choi–Lam 把"extra cyclic squared monomials"的系数从 2 降到 1）。沿同一条曲线 $b_2=2s^2-2s^2+2s^4=2s^4$，阶数仍是 4；但 $b_2(\sigma,\sigma)=3-6+6=3\ne0$，**第六步的 8 个符号零点消失**，反对称部分 $c_{pq}+c_{qp}=0$ 无从得到，于是 $\ell$ 可以是反对称双线性形式（例如 $c_{12}=1,c_{21}=-1$）而其平方被 $b_2$ 支配——障碍失败。这条推测与 history 里"weak extremality 只在系数 1 的版本成立"的口径吻合。（外部事实：Choi 形式是极端正映射，此处仅作背景，不改变论证。）
2. `推测` **放弃"$v_0\ne0$"的半球限制，直接在整球上做常秩/变分**：则 $J:v^\perp\to\R^3$ 在赤道处降秩，只能控制 $b$ 的一个二维子空间上的 $z$，Lemma 2.1 需要的是**全部** $z,y$（否则结论"$\ell=0$"只在子空间成立，$b\not\equiv0$ 不矛盾）。
3. `推测` **试图用行列式/代数几何障碍替代这条刚性**：即直接证 $\det L(X,Z,y)$ 与 $p$ 不成比例。这在几何口径下不充分（history 第 9–11 行 Brändén 障碍"does not exclude a different determinant, with additional factors, from defining the same cone"；Kummer 的 Vámos 例子正是"没有确定行列式表示但锥有 $7\times7$ 表示"）。因此任何只谈行列式的路线都会被"加因子"绕过，必须谈锥本身——这正是本篇把障碍做成"任意 pencil ⟹ 提取被 $b$ 支配的平方"的原因。

## 2.2 §3 开头的前置段（无编号，但整节的地基）：秩 1 恒等式与 $\Phi_y$ 的正性

原文（03-hyperbolic.tex 第 8–32 行）逐字：

```latex
For $u=(u_0,u')$ and $v=(v_0,v')$ in $\R^4$, the block formula
\eqref{eq:phi} gives
\begin{equation}
 u^\top\Phi_y(vv^\top)u
 = (v_0u'-u_0v')^\top Q(y)(v_0u'-u_0v')
 = b(v_0u'-u_0v',y).
 \label{eq:rank-one}
\end{equation}
Indeed, the three terms on expanding the middle expression are
$v_0^2u'^\top Q(y)u'$, $-2u_0v_0u'^\top Q(y)v'$, and
$u_0^2v'^\top Q(y)v'$, exactly the terms from the block formula.
Lemma~\ref{lem:form} therefore implies that
$\Phi_y(vv^\top)\succeq0$.  Every positive semidefinite real symmetric
matrix is a nonnegative linear combination of such rank-one matrices.
Thus $\Phi_y$ is a positive linear map: it preserves positive
semidefiniteness, and hence the order $\preceq$.
The same formula also gives
\begin{equation}
 \Phi_{s y}=s^2\Phi_y\qquad(s\in\R),
 \label{eq:phi-scaling}
\end{equation}
so in particular $\Phi_0=0$ and $\Phi_{-y}=\Phi_y$.
This rank-one verification is the real-symmetric positive-map
correspondence for biquadratic forms~\cite[Section~3]{ha-2013}
applied to the explicit map~\eqref{eq:phi}.
```

机制拆解（这段不是"引理"，但 §3/§4/§5/§6 每一步都靠它，所以单列）：

1. **块代入。** $vv^\top=\begin{pmatrix}v_0^2&v_0v'^\top\\ v_0v'&v'v'^\top\end{pmatrix}$，故在 `eq:phi` 里 $a=v_0^2$、$r=v_0v'$、$T=v'v'^\top$。于是
$$\Phi_y(vv^\top)=\begin{pmatrix}\operatorname{tr}(Q(y)v'v'^\top)&-v_0v'^\top Q(y)\\ -v_0Q(y)v'&v_0^2Q(y)\end{pmatrix}.$$
左乘 $u^\top=(u_0,u'^\top)$、右乘 $u$：左上块贡献 $u_0^2\operatorname{tr}(Q(y)v'v'^\top)=u_0^2\,v'^\top Q(y)v'$（迹的循环性把 $v'v'^\top$ 换成 $v'^\top Q v'$）；两个 off-diagonal 块各贡献 $-u_0v_0\,u'^\top Q(y)v'$，合计 $-2u_0v_0u'^\top Q(y)v'$；右下块贡献 $v_0^2u'^\top Q(y)u'$。三项正好等于 $(v_0u'-u_0v')^\top Q(y)(v_0u'-u_0v')$ 的展开——这就是原文"That the three terms … exactly the terms from the block formula"的核对内容。

## 2.3 Proposition 3.1（`prop:hyperbolic`，03-hyperbolic.tex 第 34–81 行）——双曲性

### (a) 精确陈述（TeX 原文）

```latex
\begin{proposition}\label{prop:hyperbolic}
The polynomial $p$ in \eqref{eq:polynomial} is homogeneous of
degree $20$ on $\Sym^4\times\Sym^4\times\R^3$, a real vector
space of dimension $23$.  It satisfies $p(e)=1$ and is hyperbolic
with respect to $e=(I_4,I_4,0)$.
\end{proposition}
```

即：三条性质打包——齐次次数 20、 ambient 维数 23、$p(e)=1$、关于 $e$ 双曲。摘要与 Theorem 1.1 里的 "degree 16 / 23 variables" 说的是归约后的 $q$（见 2.8），本条是 20 次的 $p$。

### (b) 证明机制逐步推演

**第一步：次数与维数（原文第 42–47 行）。** 逐元素计次：$\det X$ 是 4 次 ⟹ $(\det X)Z$ 的每个元素 5 次（$4+1$）；$\adj X$ 的元素是 $3\times3$ 余子式，故 3 次；$\Phi_y$ 对输入线性、对 $y$ 二次 ⟹ $\Phi_y(\adj X)$ 的元素 $3+2=5$ 次。于是 $(\det X)Z-\Phi_y(\adj X)$ 是 $4\times4$ 的 5 次齐元矩阵，取行列式（对矩阵元素 4 次齐）⟹ $20$ 次齐次多项式。**齐次性在这里是"每项同次"的直接检查，不需要额外论证**；两次相减不会降次（除非发生抵消，下一步用 $p(e)=1$ 排除恒零）。维数 $10+10+3=23$：$\Sym^4$ 的独立元素 $4\cdot5/2=10$。

**第二步：$p(e)=1$（同一句 "Since $\Phi_0=0$"）。** $e=(I_4,I_4,0)$：$\det I_4=1$、$Z=I_4$、$\Phi_0=0$ ⟹ $\det(1\cdot I_4-0)=1$。作用有两个：(i) 多项式非零，故"20 次齐次"不是空话；(ii) 它是 $t\mapsto p(te-x)$ 的首项系数（齐次 ⟹ $p(te-x)=t^{20}p(e-x/t)$，$t^{20}$ 系数 $=p(e)=1$），后面"恰有 20 个根（含重数）全实"的论证依赖它非零。

**第三步：可逆情形的因式分解（原文第 49–56 行）。** 复线性扩展：把 $\Phi_y$ 按同一块公式作用在复对称矩阵上（系数仍是实的）。$X$ 可逆（实或复）时 $\adj X=(\det X)X^{-1}$，再由 $\Phi_y$ 线性提出标量 $\det X$：
$$(\det X)Z-\Phi_y(\adj X)=(\det X)\bigl(Z-\Phi_y(X^{-1})\bigr),$$
两边取 $4\times4$ 行列式提出 $(\det X)^4$：

```latex
\begin{equation}
 p(X,Z,y)=(\det X)^4\det\bigl(Z-\Phi_y(X^{-1})\bigr).
 \label{eq:inverse-formula}
\end{equation}
```

原文补一句 "The adjugate formula remains the definition at singular $X$"——即 `eq:inverse-formula` 只在 $\det X\ne0$ 上是恒等式，奇异处仍以原始 $\adj$ 式定义 $p$。**这个"两处定义一致性"是整篇最容易被忽略的机械细节**：它让论证可以在 $\det X\ne0$ 的 Zariski 开集上做解析推理（虚部、逆、谱），而陈述的多项式性由 $\adj$ 版本保证。

**第四步：预解式的虚部（原文第 58–63 行，本条的心脏）。** 固定实对称 $X,Z$、实 $y$，取 $t=a+i\eta$，$\eta>0$。$X$ 正交对角化 $X=U\operatorname{diag}(\lambda_1,\dots,\lambda_4)U^\top$，于是
$$(tI_4-X)^{-1}=U\operatorname{diag}\Bigl(\frac1{a-\lambda_j+i\eta}\Bigr)U^\top,\qquad
\Im\frac1{a-\lambda+i\eta}=\frac{-\eta}{(a-\lambda)^2+\eta^2},$$
逐项给出原文的
$$\operatorname{Im}(tI_4-X)^{-1}=-\eta\bigl((aI_4-X)^2+\eta^2I_4\bigr)^{-1}\prec0.$$
右侧负定是因为 $(aI-X)^2+\eta^2I=\sum_j((a-\lambda_j)^2+\eta^2)e_j'e_j'^\top\succeq\eta^2I\succ0$，其逆正定，前置 $-\eta$。**这一步只用 $X$ 实对称**（可正交对角化），不需要 $X$ 可逆或定号——这正是"resolvent 虚部论证"的通用之处，Lean 在 `ResolventFormula.lean` / `ResolventImaginary.lean` / `ResolventPositive.lean` 里把它做成了泛型 $n$ 的引理（`resolvent_imaginary_formula`、`resolvent_negative_imaginary_posDef`）。

**第五步：逐元素虚部 = Hermitian 虚部（原文第 64–65 行）。** 对复对称 $A$（$A^\top=A$）有 $A^*=\bar A$，故 $(A-A^*)/(2i)=(A-\bar A)/(2i)=\Im A$（逐元素），它是**实对称**矩阵。这条小事实是允许的翻译枢纽：正映射 $\Phi_{-y}$ 的正性是对"实对称 ⟹ 实对称"陈述的，而我们要作用在复矩阵的虚部（实对称）上。Lean：`ResolventImaginary.lean` 第 14 行 `complex_symmetric_imaginary`（逐元素虚部与 Hermitian 虚部相等）+ `complex_symmetric_imaginary_isSymm`。

**第六步：$H$ 的虚部下界（原文第 66–72 行）。** 记
$$H=tI_4-Z-\Phi_{-y}\bigl((tI_4-X)^{-1}\bigr).$$
$\Phi_{-y}$ 复线性且系数实 ⟹ 与逐元素虚部交换：$\Phi_{-y}(\Im B)=\Im\Phi_{-y}(B)$。由第四步 $B:=-(\Im(tI_4-X)^{-1})\succ0$（实对称），第 2.2 节第三步的正映射给出 $\Phi_{-y}(B)\succeq0$。而
$$\Im H=\eta I_4-\Im\Phi_{-y}\bigl((tI_4-X)^{-1}\bigr)=\eta I_4+\Phi_{-y}(B)\succeq\eta I_4\succ0.$$
注意原文这里出现的是 $\Phi_{-y}$ 而非 $\Phi_y$：因为要考察的是 $p(te-(X,Z,y))=p\bigl((tI-X,\ tI-Z,\ -y)\bigr)$，$y$ 分量带着负号；偶性 $\Phi_{-y}=\Phi_y$ 使正性结论不变。**这就是 §1.1 里"$y$ 只以二次出现"设计的兑现点**：若 $\Phi$ 含 $y$ 的奇次项，第六步的符号无法固定。

**第七步：虚部正定 ⟹ 可逆（原文第 73–74 行）。** 若 $Hw=0$、$w\ne0$，则 $0=\Im(w^*Hw)$；但 $\Im(w^*Hw)=w^*\bigl((H-H^*)/(2i)\bigr)w=w^*(\Im H)w\ge\eta\norm{w}^2>0$，矛盾。（用到第五步：$\Im H$ 是实对称 Hermitian 矩阵，故该二次型为实数且正。）同理 $tI_4-X$ 可逆（$\eta>0$ 时 $a+i\eta$ 不在 $X$ 的实谱中）。

**第八步：无上半平面根 ⟹ 全实（原文第 75–80 行）。** 对复对称输入应用第三步的 `eq:inverse-formula`（$tI_4-X$ 可逆）得
$$p(te-(X,Z,y))=(\det(tI_4-X))^4\det H\ne0 .$$
故对每个实 $x=(X,Z,y)$，多项式 $t\mapsto p(te-x)$（实系数，因 $p$ 实系数且 $e,x$ 实）在上半平面无根；实系数 ⟹ 根关于实轴对称 ⟹ 下半平面也无根；次数恰 20（首项系数 $p(e)=1\ne0$）⟹ 全部 20 个根在实轴上。按 §1 的定义这正是"关于 $e$ 双曲"。`[推测]` 论文把次数 20 说成"it has degree $20$ for every real input"，是因为一般情形齐次多项式沿方向可能有降次（$p$ 在特殊 $x$ 处首项仍为 $p(e)=1$，故不会降），这里显式排除是为了让"20 个根"的重数账目在所有 $x$ 上统一——§7 里 $q$ 的 16 次与 $p=(\det X)q$ 的乘法账目要用一致性。

### (c) 假设与常数的机械性理由

- **$\adj X$ 与 $(\det X)Z$ 的组合**：唯一让 `eq:polynomial` 在 $X$ 奇异时仍为多项式的写法（$\Phi_y(X^{-1})$ 不是多项式）。若只写 $\det(Z-\Phi_y(X))$，次数变成 $4\cdot(1+2)=12$，且 $y=0$ 切片的 $X\succeq0$ 约束消失（见 2.4(c)），Schur 补/压缩链断裂。
- **"复线性扩展"（第 49 行）**：`eq:inverse-formula` 的推导用了一次逆的线性，必须允许复输入；虚部论证也必须有复 $t$。双曲性本身是关于复根陈述的，扩展不是可选。
- **$\eta I_4\preceq\Im H$ 中的 $\eta$**：来自 $\Im(tI-X)^{-1}$ 的下界 $\succeq -\eta^{-1}\cdot$？ 严格说原文只用 $\Im(tI-X)^{-1}\prec0$ 得到 $B\succ0$，$\eta$ 的**大小**不进入正负判断，只作为下半平面的"高度"参数；但把它保留成显式下界 $\succeq\eta I$ 是为 §4 的 $G(y)=0$ 型"沿射线让 $\eta\to0^+$"式论证准备模板（Lean 把这条下界单独立成 `ResolventPositive.lean` 第 20 行 `resolvent_schur_imaginary_lower_bound`，写作 `η • 1 ≤ Im H`）。
- **$X,Z$ 实对称、$y$ 实**（第 58 行）：虚部负定性需要 $X$ 可正交对角化；$Z$ 实对称使其虚部为 0，从而 $\Im H$ 只剩 $tI$ 与 $\Phi$ 两项，符号可控。
- **20 是偶数**：$p(te-x)$ 首项 $t^{20}$ 且 $p(e)=1>0$，两端同号；这保证根的分布描述为 $[-\lambda_{\max},-\lambda_{\min}]$，在 2.5 节"两条相反方向的闭射线端点相同"的论证里被使用（Lean 的 `MaxEigenvalue.lean`、`posSemidef_largestEigenvalue_tendsto` 对应此处）。
- **$e=(I_4,I_4,0)$ 的具体选择**：$p(e)=1$ 只要求 $y=0$ 且两个矩阵同为单位（任何 $(cI,cI,0)$ 都可），取 $I_4$ 是让 `eq:inverse-formula` 里 $\Phi_0=0$ 直接生效。

### (d) `[推测]` 候选失败路线

1. **想用"det 表示唯一性"来代替虚部论证**：即直接断言 $p$ 的根是某个 pencil 特征值的并，从而双曲。失败机制：在没有 pencil 之前没有"特征值"可用；而一旦有 pencil（§4 之后的假想对象），其 $\det$ 与 $p$ 至多差一个额外因子，仍不能逐点比对。这正是 §1.3 末句 "It applies to an arbitrary hypothetical pencil **without comparing its determinant with $p$**" 针对的诱惑。本条的作用是在**完全没有 pencil** 时独立确立双曲性。
2. **想删去偶性 $\Phi_{-y}=\Phi_y$**：把 $Q(y)$ 的非对角改成 $-y_i$（一次）或加入 $y$ 的一次项，第六步出现 $\Im\Phi_{-y}(B)$ 与 $\Phi_{y}(B)$ 不可互换，$\Im H$ 可能不定 ⟹ $p$ 有非实根 ⟹ 连"双曲锥"这个对象都不存在。`[推测]` 这也解释了 §7 中"$q$ 对 $y$ 是偶的"必须显式证明（Gärding 凸性论证要用它）。
3. **想直接用严格双曲性（simple roots on the boundary）来加强本条**：违反构造本身。§1.2 history 里已算出沿 $w$ 方向 $p(te-w)=(t-1)^{16}t^4$（Kummer–Netzer 严格正向定理被本例刻意违反），也就是说**双曲锥边界上必然有 16 重重根**；任何"严格"路线会在同一个点 $\sigma=(0,0,1)$（$b(\sigma,\sigma)=0$ 的非零零点）上断裂。换言之，弱极端性 ⟹ 重根 ⟹ 不可严格化，是本例的结构特征而非缺陷。

Lean 对应与本条的差异：`PolynomialHomogeneous.lean` 第 77 行 `polynomial_homogeneous : IsHomogeneous p 20`（次数账目按 `determinant_homogeneous` 14、`adjugate_homogeneous` 27、`qMatrix_homogeneous` 39、`phi_homogeneous` 47 逐层搭）；`PolynomialBasic.lean` 第 14/19/24 行给出 `polynomial_basePoint`（$p(e)=1$）、`polynomial_ne_zero`、`polynomial_totalDegree = 20`；`Main.lean` 第 25–34 行的 `main_result` 把这四件事拆成四个独立合取项（`finrank = 23`、`IsHomogeneous 20`、`totalDegree = 20`、`eval basePoint = 1`），比论文更啰嗦；双曲性本体是 `Hyperbolicity.lean` 第 14 行 `matrixValue_nonzero_nonreal`（$t$ 非实 ⟹ $p(te-x)\ne0$）+ 第 35 行 `linePolynomial_complex_roots_real`，配合 `LinePolynomial.lean` 第 71/81 行 `linePolynomial_top`（首项系数 1）与 `linePolynomial_monic`。**注意口径差异**：Lean 的 `cone`(Model.lean 66–67) 用"任意复根虚部为 0 且实部非负"定义，等价于论文的 $\lambda_j(x)\ge0$ 定义（`ConeRoots.lean` 第 10 行 `cone_iff_nonnegative_real_roots`），但没有把"$p$ 齐次 + 实系数 ⟹ 共轭对成对"这一层写成单独引理，而是直接放在 `linePolynomial_complex_roots_real` 内部（`tendsto_nhds_unique` 用于实根 ⟹ 复根的唯一性方向）。

## 2.4 Proposition 3.2（`prop:slices`，03-hyperbolic.tex 第 83–148 行）——两个锥切片 + $e$ 是内点

### (a) 精确陈述（TeX 原文）

```latex
\begin{proposition}\label{prop:slices}
Let $K=\Lambda_+(p,e)$.  For real symmetric $X,Z$ and $y\in\R^3$,
\begin{align}
 X\succ0:\qquad
 (X,Z,y)\in K
 &\ \Longleftrightarrow\ 
 Z\succeq\Phi_y(X^{-1}),
 \label{eq:slice-positive}\\
 (X,Z,0)\in K
 &\ \Longleftrightarrow\ 
 X\succeq0\ \text{and}\ Z\succeq0.
 \label{eq:slice-zero}
\end{align}
Moreover, $e$ lies in the interior of $K$ in the full ambient space.
\end{proposition}
```

一句话概括：$K$ 在 $X\succ0$ 那一半上**就是**一个非线性矩阵不等式 $Z\succeq\Phi_y(X^{-1})$（这正是"看起来像谱形阴影"的地方），在 $y=0$ 的 20 维平面上**就是**两个 PSD 锥的乘积；$e$ 是 23 维 ambient 的内点。

### (b) 证明机制逐步推演

**第零步：把" membership"翻译成"无正根"（原文第 100–107 行）。** 设 $\lambda_1(x),\dots,\lambda_{20}(x)$ 是 $t\mapsto p(te-x)$ 的根（按 §1 定义，双曲 ⟹ 全实，带重数）。齐次性 + $p(e)=1$ 给出
$$p(x+te)=\prod_{j=1}^{20}(t+\lambda_j(x)).$$
来源：$p(x+te)=t^{20}p(e+x/t)$，故 $p(x+te)$ 的根是 $t=-\lambda_j(x)$，首项系数 $p(e)=1$。于是
$$x\in K\iff\lambda_j(x)\ge0\ \forall j\iff p(x+te)\ne0\ \text{for every real }t>0.$$
原文着重解释严格号的用意："The strict inequality on $t$ allows zero roots and hence includes the boundary of $K$."——即这里判定的对象是**闭**锥 $K=\bar\Lambda_+$（论文 §1 的记号 $\Lambda_+(p,e)$ 本身就用 $\lambda_j\ge0$ 定义为闭锥）。这个口径必须与 §4 里"假想 pencil 表示的是闭锥"一致，否则整条矛盾链在边界点上失效。Lean：`ConeRoots.lean` 第 10 行 `cone_iff_nonnegative_real_roots`、第 27 行 `cone_iff_no_positive_shift`（就是这条翻译）。

**第一步：$F(t)$ 的构造与正向（原文第 109–120 行）。** 设 $X\succ0$，对 $t\ge0$ 令
$$F(t)=Z+tI_4-\Phi_y\bigl((X+tI_4)^{-1}\bigr).$$
它来自把 `eq:inverse-formula` 用在 $(X,Z,y)+te=(X+tI_4,\ Z+tI_4,\ y)$ 上（$X+tI_4\succ0$ 总可逆）：$p((X,Z,y)+te)=(\det(X+tI_4))^4\det F(t)$。恒等式（纯线性和逆的代数）：
$$F(t)=F(0)+tI_4+\Phi_y\bigl(X^{-1}-(X+tI_4)^{-1}\bigr),$$
核对：$\Phi_y$ 线性使 $-\Phi_y((X+tI)^{-1})=-\Phi_y(X^{-1})+\Phi_y(X^{-1}-(X+tI)^{-1})$，与 $F(0)=Z-\Phi_y(X^{-1})$ 合并即得。若 $F(0)\succeq0$：第一项 PSD；第二项 $tI_4\succ0$（$t>0$）；第三项 PSD 因为 $t\ge0\implies X+tI_4\succeq X\succ0\implies (X+tI_4)^{-1}\preceq X^{-1}$（逆在正定锥上反单调）⟹ 差 PSD ⟹ §2.2 的正映射保序。**结论 $F(t)\succ0$ 对一切 $t>0$** ⟹ 无正根 ⟹ $(X,Z,y)\in K$。注意边界情形（$F(0)$ 奇异、$Z=\Phi_y(X^{-1})$）**也落在 $K$ 里**，这正是"including equality in the matrix inequality"的意思。

**第二步：反向的支配估计（原文第 122–128 行）。** 若 $F(0)\not\succeq0$，实对称 ⟹ $\lambda_{\min}F(0)<0$。对 $t>0$：$X+tI_4\succeq tI_4\succ0\implies 0\prec(X+tI_4)^{-1}\preceq t^{-1}I_4$，用保序性
$$0\preceq\Phi_y\bigl((X+tI_4)^{-1}\bigr)\preceq t^{-1}\Phi_y(I_4).$$
于是 $F(t)\succeq Z+tI_4-t^{-1}\Phi_y(I_4)$，当 $t$ 充分大时右端正定（$tI_4$ 线性增长压过 $t^{-1}$ 衰减与固定的 $Z$），即原文"Consequently $F(t)\succ0$ for all sufficiently large $t$"。**这里 $\Phi_y(I_4)$ 是有限矩阵这一事实就是全部所需**；正映射的单调性是唯一被使用的性质。

**第三步：连续介值 ⟹ 存在正根（原文第 129–133 行）。** $\mu(t):=\lambda_{\min}F(t)$ 连续（特征值作为矩阵元素的连续函数，实对称情形可由极小化原理证明），$\mu(0)<0$、$\mu(t)>0$（$t$ 大）⟹ 存在 $t_0>0$ 使 $\mu(t_0)=0$ ⟹ $F(t_0)$ 奇异 ⟹ $\det F(t_0)=0$ ⟹ 由 $X+t_0I_4\succ0$ 与 `eq:inverse-formula`，$p((X,Z,y)+t_0e)=0$ 且 $t_0>0$ ⟹ 第零步 ⟹ $(X,Z,y)\notin K$。双向闭合。`[推测]` 论文明写"This proves \eqref{eq:slice-positive} in both directions, **including equality in the matrix inequality**"，是为了强调它没有把边界情况留给读者：$Z=\Phi_y(X^{-1})$ 时 $F(0)$ 奇异，$t_0=0$ 不算正根，所以 $K$ 在该切片上是**闭**的（$\succeq$ 而非 $\succ$）。

**第四步：$y=0$ 切片（原文第 135–142 行）。** 不用 `eq:inverse-formula`（$X$ 可能奇异），直接用原始 $\adj$ 定义，把 $(X,Z,0)$ 换成 $te-(X,Z,0)=\bigl(tI_4-X,\ tI_4-Z,\ 0\bigr)$：
$$p(te-(X,Z,0))=\det\bigl((\det(tI_4-X))(tI_4-Z)-\Phi_0(\adj(tI_4-X))\bigr)=\det(tI_4-X)^4\det(tI_4-Z),$$
其中 $\Phi_0=0$ 是 §2.2 偶性的特例。原文强调"also for singular $X$ and $Z$"——右侧本来就是多项式恒等式，无需开集论证。根 = $X$ 的特征值（各重 4）与 $Z$ 的特征值，全实且非负 $\iff X\succeq0\wedge Z\succeq0$。⟹ `eq:slice-zero`。
**这条切片的战略作用**：它给出 $K$ 在一个 20 维线性子空间（$y=0$）上的**完整**刻画，而 §4 的压缩/归一化论证需要在"零切片不属于表示锥"上取反证（Lean 的 `PencilRepresentation.lean` 第 12 行 `zero_slice_proper` 就是把 $(-I,1,0)\notin K$ 这种"切片上的失败点"形式化）。

**第五步：$e$ 是内点（原文第 144–147 行）。** 集合 $\{X\succ0\}\cap\{Z-\Phi_y(X^{-1})\succ0\}$：$X\mapsto X^{-1}$ 在 $\Sym^4$ 的开子集 $\{X\succ0\}$ 上连续，$\Phi$ 关于 $(y,X)$ 联合连续（Lean `ConeContinuity.lean`），strict PSD 是开条件 ⟹ 该集合是 **23 维 ambient 的开集**；它含 $e$（$I\succ0$，$I-\Phi_0(I)=I\succ0$）；由 `eq:slice-positive` 它含于 $K$。⟹ $e\in\operatorname{int}K$。注意"$e$ 关于双曲方向当然是内点"这件事在一般双曲多项式里需要 Gärding 定理，而这里用显式切片直接避开——论文没有引用 Gärding 来证本条（Gärding 只在 §7 的凸性论证与 §1.2 历史段落出现）。

### (c) 假设与常数的机械性理由

- **$X\succ0$ 的前提**：$X^{-1}$ 与 Loewner 反单调都要它。若只有 $X\succeq0$ 奇异，`eq:slice-positive` 右端无意义；奇异 $X$ 上的成员性由 §7 的 $K=\{X\succeq0\}\cap K_q$ 补上（见 2.8）。去掉这个前提 ⟹ 该切片无法识别为 PSD 锥的原像 ⟹ §4 的 Schur 补等价（`eq:schur-equivalence`）没有可比对象。
- **"重数 4"（$\det(tI_4-X)^4$）**：来自 $(\det X)Z$ 里 $\det X$ 提出来时的 4 次幂（矩阵维数 4）。它决定 $y=0$ 切片上 $X$ 的每个特征值重 4、$Z$ 的重 1，从而 $p$ 总次数 $=4\times4+4=20$ 的账目一致；Lean `ZeroPolynomial.lean` 第 15 行 `matrixValue_zero_parameter = X.det^4*Z.det`、第 20 行 `linePolynomial_zero_parameter = charpoly X ^4 * charpoly Z`、第 38 行 `linePolynomial_repeated_roots : linePolynomial ((1,0),0) = (X-1)^16 * X^4`（后者正是 history 里 $p(te-w)=(t-1)^{16}t^4$ 的形式化，16 来自 $4\times4$ 的 $X$ 部分去掉一个维度后剩余? 实为 $(X-1)^{16}$ 中 16 由 $q$ 的次数给出——见 2.8(c) 与 §五 的表）。
- **$\Phi_y$ 保序（不只是保 PSD）**：第二步的 $t^{-1}\Phi_y(I_4)$ 支配、第一步的 $X^{-1}-(X+tI)^{-1}$ 送入 $\Phi_y$ 都需要单调性；正向（$A\succeq0\implies\Phi(A)\succeq0$）与线性等价地给出单调，但 Lean 把它单独写成 `PositiveMaps.lean` 第 13 行 `positiveLinearMap_monotone`，说明证明里把它当作可复用组件。
- **"开集在 23 维 ambient 里"**：这是第五步的全部要点，也是 §4 "常秩邻域 / $\Omega=\{u_0\ne0\}$"论证的先例——必须用满维内点，才能对 pencil 做一般位置的压缩。Lean：`ConeOpen.lean`（`isOpen_strict_positive_slice`、`strict_positive_slice_subset_cone`）+ `ConeInterior.lean` 第 13 行 `basePoint_mem_interior_cone`。
- **重根容许**：本条两处（第一步的边界、第四步的特征值重数）都允许重根；若强求严格双曲，`eq:slice-zero` 上 $X$ 的 4 重特征值立刻违反。

### (d) `[推测]` 候选失败路线

1. **直接用 `eq:slice-positive` 声称"这就是一个 LMI"**：失败机制是 $X^{-1}$ 关于 $X$ **非线性**；把它写成 $ZX\succeq I$ 之类的"乘积不等式"也不是 LMI（乘积非对称、且丢失信息），写成 Schur 补需要引入形如 $\begin{pmatrix}Z&I\\I&X\end{pmatrix}\succeq0$ 的分块，但 $\Phi_y(X^{-1})$ 对 $y$ 是二次的，分块右下角带 $y$ 的项使整体对 $(X,Z,y)$ 不再是线性的。所以**切片本身是 spectrahedral shadow 的样子但不是 spectrahedral**，而论文必须额外走"任意假想 pencil ⟹ 提取被 $b$ 支配的平方"这条长路（§4–§6）才能取到矛盾——这解释了为什么本篇不能像 Netzer–Sanyal 的例子那样只靠"shadow 不是 cone 的像"论证（后者是**不是** spectrahedral，允许辅助变量；本篇要否定的是允许任何 $N$ 的原始 LMI）。
2. **想用 $e$ 的内点性做"局部 ⇒ 全局"的多项式比较**：即在 $e$ 附近比较 $\det L(x)$ 与 $p(x)$。失败机制：两个齐次多项式即使在开的正测度集上成比例，也不能保证比例常数为 1（可差一个非零常数），且 $p$ 与 pencil 的 det 之间本就允许差一个额外因子（§1.2 history 已用 `[BRS22]/[RSSW18]` 强调"does not exclude a different determinant, with additional factors, from defining the same cone"）。因此内点性只能用来做**几何**操作（压缩、归一化），不能用来做**代数**识别。
3. **想用 `eq:slice-zero`（$y=0$ 平面上的 $X\succeq0\wedge Z\succeq0$）单独否定谱形性**：失败机制：$K$ 在一个子空间上的截面是谱形的（两个 PSD 锥的乘积本身就是谱形），完全不构成障碍；事实上任何表示 $K$ 的 pencil 限制到该平面都可以是 PSD。障碍必须来自 $y\ne0$ 的方向，而且——如 §6 所示——必须来自**切空间**（一阶变分）而非任何有限维截面。

Lean 对应：`ConePositive.lean` 第 13 行 `cone_positive_slice`（`eq:slice-positive`），其核心由 `PositiveCore.lean` 第 16 行 `cone_positive_slice_of_inverse_order` 提供；逆序不等式在 `InverseOrder.lean` 第 47 行 `posDef_inverse_sub_shift_inverse_posSemidef`，**做法与论文不同**：Lean 用连续泛函演算 `matrix_cfc_affine`(12)、`posDef_inverse_eq_cfc`(24)、`posDef_shift_inverse_eq_cfc`(34) 配合 `cfc_mono` 与 `inv_anti₀`，把"$A\succ0\implies A^{-1}$ 是 $A$ 的 cfc 且 $x\mapsto1/x$ 单调递减"作为黑箱，从而完全避开手工的对角化；残差矩阵在 `ConeMatrix.lean`（`symInverse`、`phiSym`、`coneResidual`、`continuousAt_coneResidual`），正性传播在 `ResidualOrder.lean`/`ResidualBound.lean`（`coneResidual_identity`、`coneResidual_lower_bound`、`coneResidual_posDef`、`posDef_of_shift_bound`），存在性/路径在 `PositivePath.lean`（`coneResidual_eventually_posDef`、`coneResidual_exists_singular`、`posSemidef_of_nonsingular_path`）。"最小特征值"整条链独立成 `LeastEigenvalue.lean`（116 行：`leastEigenvalue`、`isLeast`、`nonneg_iff`、`neg_iff`、`continuous_leastEigenvalue`、`tendsto`、`pos_iff`、`det_eq_zero_of_leastEigenvalue_eq_zero`、`exists_positive_singular_on_segment`），对应论文第二步 + 第三步；`ConeZero.lean` 第 31 行 `cone_zero_slice`（`eq:slice-zero`），前置 `charpoly_eval_eigenvalue`(13)、`charpoly_real_roots_nonnegative`(21)。

**与本条相关的"额外/缺失假设"**：Lean 的 `cone` 定义不经过 $\lambda_j$ 排序，所以论文第零步"根带重数写成 $\prod(t+\lambda_j)$"在 Lean 里被替换为 `linePolynomial_splits`/`linePolynomial_card_roots`（`RootFactorization.lean`，后者标为 terminal 即无下游引用），也就是说 Lean 没有把重数账目做成公共组件。

## 2.5 Proposition 4.1（`prop:pencil`，04-pencil.tex 第 10–157 行）——假想 pencil ⟹ 精确块不等式

### (a) 精确陈述（TeX 原文）

```latex
\begin{proposition}\label{prop:pencil}
Let $K=\Lambda_+(p,(I_4,I_4,0))$ for the polynomial
in~\eqref{eq:polynomial}. Suppose that $K$ admits a representation by a finite homogeneous real
symmetric linear pencil.  Then there are integers $a,c\geq1$, positive
linear maps
\[
 D:\Sym^4\longrightarrow\Sym^a,
 \qquad E:\Sym^4\longrightarrow\Sym^c,
 \qquad D(I_4)=I_a,\quad E(I_4)=I_c,
\]
and a linear map $B:\R^3\longrightarrow\R^{a\times c}$ such that, for
every $X\succ0$, $Z\in\Sym^4$ and $y\in\R^3$,
\begin{equation}\label{eq:schur-equivalence}
 Z\succeq\Phi_y(X^{-1})
 \quad\Longleftrightarrow\quad
 E(Z)\succeq B(y)^\top D(X)^{-1}B(y).
\end{equation}
\end{proposition}
```

节的引言（第 4–8 行）给出本条的任务与一个新定义：

```latex
The two slices in Proposition~\ref{prop:slices} constrain every pencil
representing $K$.  We now turn those constraints into an exact block
matrix inequality whose off-diagonal block is linear in $y$.
A positive linear map preserves positive semidefiniteness; it is
called \emph{unital} if it sends the identity to the identity.
```

一句话概括：**只要 $K$ 有任何有限维齐次实对称 LMI 表示，就能从中榨出一个 unital 正映射对 $(D,E)$ 与一个关于 $y$ 线性的块 $B(y)$，使切片不等式两边精确等价。**这是把"锥的表示"翻译成"矩阵乘积不等式"的唯一一处，也是全文唯一使用 $K$ 的**闭包成员性**（而不是多项式身份）的地方——因此它不比较 $\det L$ 与 $p$。

### (b) 证明机制逐步推演

**第一段：压缩与归一化（原文第 39–81 行）。**

1. **公共核初等事实**：$A+H\succeq0,\ A-H\succeq0\implies\ker A\subseteq\ker H$。原文给的证明：若 $w\in\ker A$，两个非负二次型在 $w$ 上相加为 $0$ ⟹ 各自为 $0$ ⟹ PSD 矩阵在其二次型为零的向量上湮灭该向量（PSD 情形的 Cauchy–Schwarz：$w^*Hw=0\implies Hw=0$，因为 $H=S^2$ 时 $\norm{Sw}^2=0$）⟹ $(A+H)w=(A-H)w=0$ ⟹ $Hw=0$。
2. **用到 $e$ 的内点性（Prop 3.2 的第五步在此兑现）**：任取 ambient 向量 $x$，由 $e\in\operatorname{int}K$（23 维 ambient 中的内点）存在 $\varepsilon>0$ 使 $e\pm\varepsilon x\in K$；表示假设 ⟹ $L(e)\pm\varepsilon L(x)\succeq0$。取 $A=L(e),H=\varepsilon L(x)$，对**所有** $x$ 得 $\ker L(e)\subseteq\ker L(x)$。⟹ $\ker L(e)$ 是整个 pencil 的公共核。
3. **压缩**：把 pencil 限制到 $(\ker L(e))^\perp$（正交补上的压缩/角算子）。因为所有 $L(x)$ 都把公共核湮灭且交叉块为零（对称矩阵以 $U\subseteq\ker$ 时形如 $\begin{pmatrix}*&0\\0&0\end{pmatrix}$），$L(x)\succeq0\iff$ 压缩块 $\succeq0$ ⟹ 表示同一个锥。压缩后 $L(e)\succ0$。
4. **补空间非零**：若 $(\ker L(e))^\perp=0$，则 $L\equiv0$，pencil 恒零 ⟹ 表示全空间，但 `eq:slice-zero` 给出 $(-I_4,I_4,0)\notin K$。矛盾 ⟹ 补空间非零。
5. **$L_1,L_2$ 是正映射**：$(X,0,0)\in K\iff X\succeq0$（`eq:slice-zero` 取 $Z=0,y=0$）⟹ $X\succeq0\implies L(X,0,0)=L_1(X)\succeq0$；$Z$ 同理。**注意这是"$K$ 的切片刻画"给 pencil 的第一个硬约束。**
6. **对 $L_1$ 再做一次核论证**：$U:=\ker L_1(I_4)$。任意 $X$，取小 $\varepsilon$ 使 $I_4\pm\varepsilon X\succeq0$ ⟹ $L_1(I_4)\pm\varepsilon L_1(X)\succeq0$ ⟹ 第 1 点 ⟹ $U\subseteq\ker L_1(X)\ \forall X$。于是在 $U^\perp\oplus U$ 下 $L_1(X)=\begin{pmatrix}D(X)&0\\0&0\end{pmatrix}$。
7. **两个块都必须存在（这是 $a,c\ge1$ 的来源）**：
 - 若 $U^\perp=0$：$L_1=0$ ⟹ $L(-I_4,I_4,0)=L_2(I_4)\succeq0$（$L_2$ 正）⟹ 表示接受 $(-I_4,I_4,0)$，违反 `eq:slice-zero`。
 - 若 $U=0$：$L_1(I_4)\succ0$ ⟹ 小 $\varepsilon>0$ 时 $L_1(I_4)-\varepsilon L_2(I_4)\succ0$（strict PD 在扰动下开放）⟹ 接受 $(I_4,-\varepsilon I_4,0)$，又违反 `eq:slice-zero`。
 **`eq:slice-zero` 一条被用了三次（第 4、5、7 点），它的作用是排除所有退化情形。**
8. **$a=\dim U^\perp,\ c=\dim U$，$E(Z):=$ $L_2(Z)$ 的下对角块**；$D,E$ 仍正（压缩保持正映射）。$D(I_4)\succ0$ 由 $U$ 的定义（上块是 $L_1(I_4)$ 在非核部分，正定）；$E(I_4)\succ0$ 因为它是 $L(e)\succ0$ 压到 $U$ 上的块：$L(e)=L_1(I_4)+L_2(I_4)+0$ 且 $L_1(I_4)$ 在 $U$ 上为零 ⟹ $L(e)$ 的 $U$ 块 $=E(I_4)$，正定矩阵的对角块正定。
9. **固定块对角 congruence 归一化**：$\operatorname{diag}(D(I_4)^{-1/2},E(I_4)^{-1/2})$ 共轭整个 pencil。因为该矩阵**不依赖** $(X,Z,y)$，共轭后 pencil 仍线性；congruence 保序（$T^\top AT\succeq0\iff A\succeq0$，$T$ 可逆）⟹ 表示同一个 $K$；$D,E$ 保持正；$D(I_4)=I_a$、$E(I_4)=I_c$。**"unital"的定义恰在此被用**：归一化就是把正映射变成 unital 正映射的过程。原文 "and retain the notation for the resulting blocks" 提醒读者后续 $D,E,B$ 都是归一化后的记号。
 - `[推测]` 为什么非要 unital：最后一步 Schur 之前需要 $D(X)\succ0$（第 12 点），其证明只用 unitality；Lean 的 `SpectralBounds.lean` 第 31 行 `positive_unital_map_minimumEigenvalue_bound` 把这条独立成引理，说明它是不可省的假设。

**第二段：重标度 pencil（原文第 83–122 行）。**

10. **剩余块的记号**：
$$L_2(Z)=\begin{pmatrix}F(Z)&C(Z)\\C(Z)^\top&E(Z)\end{pmatrix},\qquad L_3(y)=\begin{pmatrix}A(y)&B(y)\\B(y)^\top&G(y)\end{pmatrix}.$$
$B(y)$ 对 $y$ 线性（因 $L$ 线性），这正是节引言说的"off-diagonal block is linear in $y$"，也是 §5 中 $\norm{P(v)B(y)R(u)}_\op^2$ 是 $y$ 的二次型的**唯一**理由。
11. **$G(y)=0$ 的推导（原文第 90–98 行）**：固定 $y$，$Z_0=\Phi_y(I_4)$。由 `eq:slice-positive`（$X=I_4\succ0$）与 `eq:phi-scaling`：$s^2Z_0\succeq\Phi_{sy}(I_4^{-1})=s^2\Phi_y(I_4)=s^2Z_0$（取等号成立）⟹ $(I_4,s^2Z_0,sy)\in K$ **对一切实 $s$**。故 $L$ 在其上的值的下对角块 PSD：
$$s^2E(Z_0)+sG(y)\succeq0\qquad(s\in\R).$$
除以 $|s|$ 并从 $s>0$、$s<0$ 两侧取极限：$s\downarrow0$ 给 $G(y)\succeq0$；$s\uparrow0$（即 $s<0$，$s^2/|s|=-s$，$s/|s|=-1$）给 $-sE(Z_0)-G(y)\succeq0\to-G(y)\succeq0$。⟹ $G(y)=0$。**机制**：这是一个"$\succeq$-值二次曲线过原点 ⟹ 一次项为零"的论证（Lean 抽象成 `RescalingBasic.lean` 的 `linear_coefficient_zero_of_quadratic_nonneg` / `linear_term_zero_of_quadratic_posSemidef`）；而 $G=0$ 是下面极限存在的**必要条件**，因为第 12 步的 congruence 会把下块乘 $s^{-2}$，$sG(y)$ 项会变成 $s^{-1}G(y)$ 发散。
12. **scaled congruence 与 `eq:scaled-test`（原文第 100–115 行）**：固定 $X\succ0,Z,y$，对 $s\ne0$ 用 $\operatorname{diag}(I_a,s^{-1}I_c)$ 共轭 $L(X,s^2Z,sy)$。逐项核对（用上块零与 $G=0$）：上左 $D(X)+sA(y)+s^2F(Z)$；off-diagonal $=sB(y)+s^2C(Z)$，被 $s^{-1}$ 乘后为 $B(y)+sC(Z)$；下右 $s^2E(Z)$，被 $s^{-2}$ 乘后为 $E(Z)$。得
$$M_s(X,Z,y)=\begin{pmatrix}D(X)+sA(y)+s^2F(Z)&B(y)+sC(Z)\\ B(y)^\top+sC(Z)^\top&E(Z)\end{pmatrix}\qquad(\text{eq:scaled-pencil}).$$
两个方向的等价链：
- $M_s\succeq0\iff L(X,s^2Z,sy)\succeq0$（congruence，对 $s$ 的**两种符号**都成立——原文特意写 "either sign"，因为后面要用两侧极限）；
- $L(X,s^2Z,sy)\succeq0\iff (X,s^2Z,sy)\in K$（表示假设）；
- $(X,s^2Z,sy)\in K\iff s^2Z\succeq\Phi_{sy}(X^{-1})=s^2\Phi_y(X^{-1})\iff Z\succeq\Phi_y(X^{-1})$（`eq:slice-positive` + `eq:phi-scaling`，$s^2>0$ 可约）。
合起来即 `eq:scaled-test`：$M_s(X,Z,y)\succeq0\iff Z\succeq\Phi_y(X^{-1})$，$\forall s\ne0$。**关键设计**：选择"$y$ 线性标度、$Z$ 二次标度"正是为了让成员性判据与 $s$ 无关（degree matching：$\Phi$ 对 $y$ 二次 ⟹ $\Phi_{sy}=s^2\Phi_y$ 与 $s^2Z$ 同步）。
13. **取极限得单向（原文第 116–122 行）**：$s\to0$ 时 $M_s\to M(X,Z,y)=\begin{pmatrix}D(X)&B(y)\\B(y)^\top&E(Z)\end{pmatrix}$。若 $Z\succeq\Phi_y(X^{-1})$，则所有 $M_s\succeq0$ ⟹ 极限 PSD（PSD 锥闭）⟹ $M\succeq0$。

**第三段：从极限恢复不等式（原文第 124–149 行）。**

14. **$D(X)\succ0$**：正向 + unital：$X\succ0\implies X-\lambda_{\min}(X)I_4\succeq0$ ⟹ $D(X)-\lambda_{\min}(X)I_a=D(X-\lambda_{\min}I_4)\succeq0$ ⟹ $D(X)\succeq\lambda_{\min}(X)I_a\succ0$。**这里 $D(I_4)=I_a$ 是全部所需**，第 9 步的归一化正是为了它。
15. **$\delta$ 正则化使极限严格正定**：$M(X,Z+\delta I,y)=M(X,Z,y)+\operatorname{diag}(0,\delta I_c)$。原文分两种向量证明二次型严格正：下分量非零的向量由新增项得 $>0$；下分量为零的非零向量由 $D(X)\succ0$（第 14 步）得 $>0$。⟹ $M(X,Z+\delta I,y)\succ0$。
16. **回传到 $M_s$**：$M_s\to M$（逐元素）且 strict PD 开放 ⟹ 对充分小非零 $s$，$M_s(X,Z+\delta I,y)\succ0$ ⟹ 由 `eq:scaled-test`（把 $Z$ 换成 $Z+\delta I$）得 $Z+\delta I\succeq\Phi_y(X^{-1})$ ⟹ $\delta\downarrow0$（`⪰` 闭）得 $Z\succeq\Phi_y(X^{-1})$。**这一小段是整条证明里唯一"从 pencil 的 PSD 恢复锥成员性"的方向，也是为什么必须做 $\delta$ 正则化**：$M\succeq0$（非严格）不能直接给 $M_s\succeq0$——极限 PSD 不蕴含逼近序列 PSD。
17. 合并：$Z\succeq\Phi_y(X^{-1})\iff M(X,Z,y)\succeq0$。

**第四段：Schur 补（原文第 150–151 行）。** $M=\begin{pmatrix}D(X)&B(y)\\B(y)^\top&E(Z)\end{pmatrix}$ 且 $D(X)\succ0$（第 14 步），标准分块合同分解 $M=T^\top\begin{pmatrix}D(X)&0\\0&E(Z)-B(y)^\top D(X)^{-1}B(y)\end{pmatrix}T$，$T$ 可逆 ⟹
$$M\succeq0\iff E(Z)\succeq B(y)^\top D(X)^{-1}B(y),$$
即 `eq:schur-equivalence`。$\blacksquare$

**节尾（第 154–157 行）交代下一步的入口**："The maps and their finite dimensions are now fixed by the hypothetical pencil. We next recover the scalar form $b$ from \eqref{eq:schur-equivalence}; this will force a nonzero bilinear square dominated by $b$ and contradict its defining obstruction."

### (c) 假设与常数的机械性理由

- **"homogeneous"（齐次 pencil，无 $A_0$）**：第 2、11、12 步的标度论证全部依赖 $L(\lambda x)=\lambda L(x)$；若带常数项 $L_0$，则 $L(X,s^2Z,sy)$ 的下右块多出 $L_{0,22}$，被 $s^{-2}$ 放大后发散 ⟹ 极限不存在，`eq:scaled-pencil` 与 §5 全部崩塌。论文 §1 把 spectrahedral 定义为齐次 LMI（第 15–21 行），所以这不是削弱结论；但注意 shadow 的定义（01-history 第 34–35 行）用的是 "affine real symmetric linear matrix inequality"——即**允许**常数项与辅助变量，本篇明确不处理 shadow（第 38–40 行）。
- **$e$ 为 ambient 内点（Prop 3.2 末）**：第 2 步"任意 $x$ 有 $\varepsilon$ 使 $e\pm\varepsilon x\in K$"只用开性，不需要 $K$ 凸（Gärding 凸性在本节未被引用）。若 $e$ 只是相对内点（例如只在某个切片内），公共核压缩就会丢约束。
- **`eq:slice-zero`**：第 4、5、7 步三处；特别是 $a,c\ge1$（$U^\perp,U$ 双双非零）完全靠它。去掉 ⟹ 允许 $c=0$ 的退化 pencil ⟹ 不存在 $B$，§5 起无对象。
- **`eq:slice-positive` 的**精确**双向等价（含等号）**：第 11、12、16 步都要求"$Z\succeq\Phi_y(X^{-1})$"这一**闭**条件与 pencil 的 PSD **完全**等价；若只有单向（例如 $Z\succ\Phi_y(X^{-1})\implies L\succeq0$），$G=0$ 与 `eq:scaled-test` 都不成立。
- **$X\succ0$（而非 $\succeq0$）**：第 14 步给 $D(X)\succ0$、第 17 步给 Schur 补可用；奇异 $X$ 上的成员性留给 §7（Gärding 凸性 + `eq:cone-intersection`）。
- **$\Phi_{sy}=s^2\Phi_y$（二次性）**：第 11、12 步的 degree matching；换成三次 ⟹ $s^3$ 与 $s^2Z$ 不同步，标度极限要么平凡要么发散。`[推测]` 这也是为什么 §3 特意把这条标度律写成独立编号式 `eq:phi-scaling`。
- **$G(y)=0$**：见第 11 步机制（一次项在二次 PSD 曲线上必须消失）；若 $G\ne0$，$M_s$ 的下右块 $\to\pm\infty$，`eq:scaled-test` 无法取极限。
- **unitality $D(I_4)=I_a,E(I_4)=I_c$**：$D$ 的那一条用在第 14 步（$D(X)\succ0$，进而 Schur）；$E$ 的那一条在本节没有单独被引用，它的作用是保证归一化 congruence 的**对称性**（两块同时开方），并使 §5 里 $\operatorname{diag}$ 归一化后的 $E(Z)$ 与 $D$ 可比（Lean 的 `NormalizedPencil` 把 $D$`_unital`、$E$`_unital` 都作为字段保留，见 2.10 讨论）。

### (d) `[推测]` 候选失败路线

1. **跳过公共核压缩直接做 Schur 补**：失败机制是 $L_1(X)$ 一般只是 PSD（甚至奇异，例如 $L_1(X)=\begin{pmatrix}D(X)&0\\0&0\end{pmatrix}$ 的零块），奇异左上块的 Schur 条件只是单向蕴含（还需要同款/range 条件），拿不到"⟸"，而"⟸"正是把 pencil 的 PSD 变成 $Z$ 不等式的方向，也就是提取 $B$ 的方向。压缩 + 重标度 + $\delta$ 正则化三步都是为了把"⟸"做成精确等价。
2. **允许 pencil 带常数项（仿射 LMI）或带辅助变量（shadow）**：本节的标度论证在仿射情形发散（见 (c) 第一条）；在 shadow 情形则根本不能用"$K$ 的切片与 pencil 精确等价"，因为表示只定义在投影后的集合上。论文在 01-history 第 36–40 行明确切割："Our result concerns a direct representation in the original variables; it makes no assertion about representations using auxiliary variables."（Netzer–Sanyal 的 smooth-boundary 判据会给出 shadow，而本例边界上存在 16 重重根点，正好落在该判据之外。）`[推测]` 所以想用 shadow 口径来"加强"本条，需要全新的工具。
3. **希望 $B(y)$ 不是线性而是更高次（比如允许非线性表示）**：失败机制是度不匹配。§5 的身份是 $b(v_0u'-u_0v',y)=\norm{P(v)B(y)R(u)}_\op^2$：左边对 $y$ 是 2 次，右边若 $B$ 是 $k$ 次则对 $y$ 是 $2k$ 次；$k\ne1$ 时两边只能在 $B$ 的对应次齐次部分为零的意义上成立，`eq:norm-identity` 就不再"提取"出任何非零双线性形式（Lemma 2.1 的否定对象恰好是"双线性平方被 $b$ 支配"，对其它次数无陈述）。齐次 pencil ⟹ $B$ 线性，这是 `eq:schur-equivalence` 左端能出现 $b$ 的机制性原因。

## 2.6 §5 开头的定义（`eq:projections`）+ Proposition 5.1（`prop:norm`，05-norm.tex 全文）——秩 1 极限与算子范数恒等式

### (a) 精确陈述（TeX 原文）

前置定义（第 4–17 行）：

```latex
Let $D,E,B$ be the maps supplied by Proposition~\ref{prop:pencil}.
Thus $D$ and $E$ are positive maps with output sizes $a,c\geq1$ and
are \emph{unital}, meaning $D(I_4)=I_a$ and $E(I_4)=I_c$,
and $B(y)$ is an $a\times c$ matrix.
For unit vectors $u,v\in\R^4$, define the orthogonal projections
\begin{equation}
 P(v)=\operatorname{proj}_{\ker D(I-vv^\top)},
 \qquad
 R(u)=\operatorname{proj}_{\ker E(I-uu^\top)}.
 \label{eq:projections}
\end{equation}
These act on $\R^a$ and $\R^c$, respectively.
The next proposition recovers the scalar form~\eqref{eq:form} from the
Schur threshold~\eqref{eq:schur-equivalence}.
```

命题（第 19–35 行）：

```latex
\begin{proposition}
\label{prop:norm}
Let $a,c\geq1$, let $D:\Sym^4\to\Sym^a$ and
$E:\Sym^4\to\Sym^c$ be positive unital linear maps, and let
$B:\R^3\to\R^{a\times c}$ be linear. Assume that
\eqref{eq:schur-equivalence} holds for every $X\succ0$,
$Z\in\Sym^4$ and $y\in\R^3$, with $\Phi_y$ defined
by~\eqref{eq:phi}. Define $P(v)$ and $R(u)$ by~\eqref{eq:projections}.
For every pair of unit vectors $u=(u_0,u'),v=(v_0,v')\in\R^4$
and every $y\in\R^3$,
\begin{equation}
 b(v_0u'-u_0v',y)
 =\norm{P(v)B(y)R(u)}_{\op}^{2}.
 \label{eq:norm-identity}
\end{equation}
Here the operator norm uses the Euclidean structures on the two block spaces.
\end{proposition}
```

**注意本条的假设里已经没有 $K$、没有 pencil、没有 $p$**：它是纯粹关于 $(D,E,B,\Phi)$ 的陈述，输入只是 `eq:schur-equivalence` 这条双向等价。这就是 §1.3 所说"不比较行列式"的具体兑现——所有信息都通过"某条射线上的成员性"传递。

### (b) 证明机制逐步推演

**第一步：秩 1 路径与阈值配对（第 38–46 行）。** 固定 $u,v,y$，$t\ge1$：
$$X_t=vv^\top+t(I-vv^\top),\qquad Z_t=uu^\top+t(I-uu^\top).$$
谱：$X_t$ 在 $\span\{v\}$ 上特征值 $1$，在 $v^\perp$ 上特征值 $t$ ⟹ $X_t\succeq I\succ0$（$t\ge1$），$Z_t$ 同理。正映射 + unital 给 $D(X_t)\succeq D(I_4)=I_a$、$E(Z_t)\succeq I_c$ ⟹ 两者正定 ⟹ "so all inverse square roots below exist"。**$t\ge1$ 的机械作用就在这里**：若 $t<1$，$D(X_t)=I+(t-1)D(I-vv^\top)$ 可能在 $\ker D(I-vv^\top)$ 的补方向上掉到 $1+(t-1)\mu<1$，极端时（$D(I-vv^\top)$ 有特征值 $\mu>t$? 实际 $D(I-vv^\top)\preceq I$ 由 unital + $I-vv^\top\preceq I$ 保证）仍正定，但阈值射线的"闭射线端点"论证会失去 $D(X_t)\succeq I$ 这个统一下界。
再定义
$$A_t=Z_t^{-1/2}\Phi_y(X_t^{-1})Z_t^{-1/2},\qquad C_t=D(X_t)^{-1/2}B(y)E(Z_t)^{-1/2}.$$
$A_t\succeq0$：$X_t^{-1}\succeq0$ ⟹ $\Phi_y(X_t^{-1})\succeq0$（§2.2 的正映射）⟹ congruence 保持。

**第二步：左端射线的阈值 $=\lambda_{\max}(A_t)$（第 52–58 行）。** 对任意实 $r$，用可逆的 $Z_t^{-1/2}$ 做 congruence：
$$rZ_t\succeq\Phi_y(X_t^{-1})\iff rI_4\succeq A_t\iff r\ge\lambda_{\max}(A_t).$$
（第二个等价是"$rI\succeq$ 对称矩阵 ⟺ $r\ge$ 其最大特征值"。）⟹ 左端在 $r$ 轴上的解集是闭射线 $[\lambda_{\max}(A_t),\infty)$。

**第三步：右端射线的阈值 $=\norm{C_t}_\op^2$（第 59–66 行）。** 用 $E$ 的线性提出 $r$：$E(rZ_t)=rE(Z_t)$；再用 $E(Z_t)^{-1/2}$ congruence：
$$rE(Z_t)\succeq B(y)^\top D(X_t)^{-1}B(y)\iff rI_c\succeq C_t^\top C_t\iff r\ge\norm{C_t}_\op^2.$$
中间用了 $D(X_t)^{-1/2}$ 对称（实对称正定矩阵的逆平方根对称）所以 $E^{-1/2}B^\top D^{-1}BE^{-1/2}=(D^{-1/2}BE^{-1/2})^\top(\cdots)=C_t^\top C_t$；最后一步是 Gram 阈值恒等式 $\lambda_{\max}(C^\top C)=\norm{C}_\op^2$（$C_t$ 是 $a\times c$ **矩形**，原文第 73 行特意为它说话："This applies to rectangular $C_t$ and includes a zero threshold."——零阈值即 $C_t=0$ 时解集是 $[0,\infty)$，仍然一致）。

**第四步：用 `eq:schur-equivalence` 认出"同一条射线"（第 67–72 行）。** 在 `eq:schur-equivalence` 里取 $X=X_t$（$\succ0$ ✓）、$Z=rZ_t$：
$$rZ_t\succeq\Phi_y(X_t^{-1})\iff E(rZ_t)\succeq B(y)^\top D(X_t)^{-1}B(y)\quad\forall r\in\R.$$
即第二步与第三步的解集**作为 $r$ 的子集相同**，两个闭射线 $[\alpha,\infty)=[\beta,\infty)$ ⟹ $\alpha=\beta$：
$$\lambda_{\max}(A_t)=\norm{C_t}_\op^2\qquad(\text{eq:threshold-norm}).$$
`[推测]` 这是全文最"便宜"也最关键的一步：它不需要 $\det L$ 与 $p$ 的任何关系，只需要"$K$ 在两条切片上的成员性判据相同"。等价地说，`eq:schur-equivalence` 是双向的这一点在此被用尽；若 Prop 4.1 只给单向，第四步就只能得到不等式 $\lambda_{\max}(A_t)\ge$（或 $\le$）$\norm{C_t}^2$，§6 的等式障碍会退化为不等式障碍而无法定出 $b$。

**第五步：左端极限 $=\alpha uu^\top$（第 75–91 行）。** 显式公式
$$X_t^{-1}=vv^\top+t^{-1}(I-vv^\top),\qquad Z_t^{-1/2}=uu^\top+t^{-1/2}(I-uu^\top)$$
（核对：$(vv^\top+t(I-vv^\top))(vv^\top+t^{-1}(I-vv^\top))=vv^\top+(t\cdot t^{-1})(I-vv^\top)=I$ ✓；平方根同理）。$t\to\infty$ 时 $X_t^{-1}\to vv^\top$、$Z_t^{-1/2}\to uu^\top$，$\Phi_y$ 连续（对矩阵元素线性）⟹
$$A_t\longrightarrow uu^\top\Phi_y(vv^\top)uu^\top=\alpha uu^\top,\qquad \alpha=u^\top\Phi_y(vv^\top)u\ge0.$$
原文："The sign follows from positivity of $\Phi_y$"，即 $\Phi_y(vv^\top)\succeq0$ ⟹ $\alpha\ge0$。**Lemma 2.1 的非负性在此处被消费**（若 $\alpha<0$，$\lambda_{\max}(\alpha uu^{\top})=0\ne\alpha$，下一步就断）。原文补 "also when $\alpha=0$"：$\alpha=0$ 时 $\lambda_{\max}=0=\alpha$，所以不需要区分。特征值最大者对矩阵元素连续 ⟹ $\lambda_{\max}(A_t)\to\alpha$。
再回头用 §2.2 的秩 1 恒等式：$\alpha=u^\top\Phi_y(vv^\top)u=b(v_0u'-u_0v',y)$。**标量 $b$ 至此进入矩阵世界**，且 $v_0u'-u_0v'$ 正是 wedge。

**第六步：右端极限用到 `eq:kernel-limit`（第 93–113 行）。** unitality 给出关键的分解（第 95 行）：
$$D(X_t)=D(vv^\top)+tD(I-vv^\top)=\bigl(I_a-D(I-vv^\top)\bigr)+tD(I-vv^\top)=I_a+(t-1)D(I-vv^\top),$$
其中 $D(vv^\top)+D(I-vv^\top)=D(I_4)=I_a$ 正是 unitality。**这一步解释 `eq:projections` 为何长这样**：令 $H=D(I-vv^\top)\succeq0$，则 $D(X_t)^{-1/2}=[I+(t-1)H]^{-1/2}$，而一般的谱论证（第 97–106 行原文）
$$[I+(t-1)H]^{-1/2}\longrightarrow\proj_{\ker H}\quad(\text{算子范数}),$$
逐特征向量核对：特征值 $\mu\ge0$ 的因子 $(1+(t-1)\mu)^{-1/2}$，$\mu=0$ 时为 $1$，$\mu>0$ 时 $\to0$。有限维 ⟹ 存在最小正特征值 $\mu_+>0$，其因子 $\le(1+(t-1)\mu_+)^{-1/2}\to0$ ⟹ 一致收敛到 $\sum_{\mu_j=0}e_j'e_j'^\top=\proj_{\ker H}$。这就是 `eq:kernel-limit`。取 $H=D(I-vv^\top)$ 与 $H=E(I-uu^\top)$ 得
$$D(X_t)^{-1/2}\to P(v),\qquad E(Z_t)^{-1/2}\to R(u),$$
即 `eq:projections` 的两个投影**恰是这两个极限**（不是额外取的记号）。⟹ $C_t\to P(v)B(y)R(u)$ 算子范数（乘积的范数收敛；$a,c$ 固定所以 submultiplicativity 足够）⟹ $\norm{C_t}_\op^2\to\norm{P(v)B(y)R(u)}_\op^2$。
原文补一句"the limits include zero and identity projections"：$P(v)$ 可能为 $0$（若 $D(I-vv^\top)\succ0$）也可能为 $I_a$（若 $D(vv^\top)=0$），论证不排除任何一种——这是 §6 必须先做"常秩邻域"的原因。

**第七步：合并（第 116–117 行）。** $t\to\infty$ 于 `eq:threshold-norm`：左 $\to b(v_0u'-u_0v',y)$，右 $\to\norm{P(v)B(y)R(u)}_\op^2$ ⟹ `eq:norm-identity`。$\blacksquare$

**第八步：同向湮灭（第 120–121 行，§6 的入口）**：$u=v$ 时 $v_0u'-u_0v'=0$ ⟹ $b(0,y)=0$ ⟹ $\norm{P(v)B(y)R(v)}_\op=0$ ⟹
$$P(v)B(y)R(v)=0\quad\text{for every }y.$$
这是一个"三重乘积在每一点 $v$ 为零"的事实；对 $v$ **求导**才会出现非零的 $B$ 的一次项，从而出现可被 $b$ 支配的双线性形式（§6 的全部工作）。

### (c) 假设与常数的机械性理由

- **$t\ge1$ 同用于 $X_t,Z_t$**：$X_t,Z_t\succeq I$ ⟹ 逆平方根存在 + congruence 可逆 + 射线端点存在。而且两边必须用**同一个** $t$，因为 `eq:schur-equivalence` 是关于二元组 $(X,Z)$ 的陈述；这也导致极限同时留下 $P(v)$ 与 $R(u)$，即 §6 中"$P$ 固定、只对 $R$ 求导"的格局是被迫的（Figure caption 明说 "Only $R$ is differentiated"）。
- **unitality 的两处使用**：(i) 第一步 $D(X_t)\succeq I$；(ii) 第六步 $D(X_t)=I+(t-1)D(I-vv^\top)$，使极限恰好是 $\ker D(I-vv^\top)$ 上的投影。若不 unital，$D(X_t)=D(I)+(t-1)D(I-vv^\top)$，其逆平方根极限是 $D(I)^{-1/2}$ 与 $\proj_{\ker D(I-vv^\top)}$ 的某种乘积，`eq:projections` 的定义必须改写，且 $P(v)B(y)R(u)$ 不再是"投影 sandwich"，§6 的 entrywise 支配就会带上未知系数。
- **$\Phi_y$ 的正映射性质**：$A_t\succeq0$ 与 $\alpha\ge0$ 两处（第五步的 "The sign follows from positivity of $\Phi_y$"）。
- **$b$ 的非负性（Lemma 2.1）**：只用于 $\alpha\ge0$ ⟹ $\lambda_{\max}(\alpha uu^\top)=\alpha$。
- **实对称 + Euclidean 结构**：$\lambda_{\max}$ 的连续性与 $\norm{C}_\op^2=\lambda_{\max}(C^\top C)$ 都要 Euclidean（奇异值）结构；原文第 34 行专门声明 "the operator norm uses the Euclidean structures on the two block spaces"，§1.3 末句也统一约定"All matrix norms below are Euclidean operator norms"。
- **$a,c\ge1$ 且有限**：谱间隙 $\mu_+>0$（第六步的一致收敛）与乘积的范数估计都要有限维；$a=0$ 或 $c=0$ 时 $B$ 不存在（Prop 4.1 用 `eq:slice-zero` 排除了这种退化）。
- **$B$ 线性**：$C_t$ 对 $y$ 线性 ⟹ $\norm{C_t}_\op^2$ 对 $y$ 是 2 次（与 $b$ 的 $y$-次数匹配）；§6 的"$F(z,y)$ 的每个元素是双线性形式"完全靠这一点。
- **$X\succ0$ 前提**：第四步取 $X=X_t$ 需要它；$t\ge1$ 保证 $X_t\succ0$。

### (d) `[推测]` 候选失败路线

1. **对 $X_t,Z_t$ 取不同的标度速率**（例如 $Z_t=tI+uu^\top$ 不变、只让 $X\to vv^\top$）：失败机制是第二步与第三步不再同源——`eq:schur-equivalence` 要求同一对 $(X,Z)$；单边取极限得到的两个解集一般不同，只能得到不等式，取不到 $b$ 的**等式**。
2. **用 $\lambda_{\min}$ 或奇异值下界替代 $\lambda_{\max}$**：失败机制是解集形状。$rZ_t\succeq\Phi$ 给出的是 $r$ 的**上界约束的补**（形如 $[{\alpha},\infty)$），配套到右端必然是 $\norm{\cdot}_\op$（最大奇异值）。若测试 $rZ_t\preceq\Phi$ 则会得到最小奇异值，而最小奇异值**不被任何范数控制**，§6 的 entrywise 界 $\ell_{ij}^2\le\norm{F}_\op^2$ 立即无从写出（Lean 的 `OperatorEntries.lean` 第 24/34 行 `abs_entry_le_operatorNorm`、`entry_sq_le_operatorNorm_sq` 只能给出 $\le\norm{\cdot}$ 方向）。
3. **试图在 $t=1$ 处做变分而不是 $t\to\infty$**：$t=1$ 时 $X_1=Z_1=I$，$D(X_1)=I_a$、$E(Z_1)=I_c$，投影 $P,R$ 完全没出现（$\ker D(I-vv^\top)$ 的信息藏在 $t=\infty$ 的渐近里）；失败机制是"秩 1 极限 ⟹ 核投影 ⟹ 核投影的一阶变分"是唯一的取信息路径，$t=1$ 给出的是恒等式 $0=0$（对应 $b(v_0v'-v_0v',y)=0$）。
4. `[推测]` **想让 $D$ 或 $E$ 之一为恒等映射以简化**：若 $D=\id_{\Sym^4}$（即 $a=10$、$B(y)^\top D(X)^{-1}B(y)$ 变成 $B(y)^\top X^{-1}B(y)$），$P(v)=\proj_{\ker(I-vv^\top)}=vv^\top$ 是秩 1 投影，§6 的 $R(u)$ 变分仍在，但此时 pencil 的 $X$-部分已包含全部 $\Sym^4$，通常意味着 $L$ 本身能分解——本条不禁止，但也不会把障碍变弱；`[推测]` 论文不讨论这种特殊情形，因为结论要对任意 pencil 成立。

Lean 对应：`Model.lean` 第 102–106 行 `operatorNorm`（`toEuclideanLin.toContinuousLinearMap` 的范数）与 `kernelProjection`（`Submodule.starProjection`），第 139–143 行 `leftProjection`/`rightProjection`（就是 $P(v),R(u)$），第 108–111 行 `inverseSquareRoot`（经 `eigenvalues`/`eigenvectorUnitary` 的 cfc 自建）；`RankNorm.lean`（`outer_toEuclideanCLM`、`outer_isStarProjection`、`one_sub_outer_posSemidef`、`norm_outer_unit`、`kernelProjection_one_sub_of_isStarProjection`、`kernelProjection_one_sub_outer`、`outer_mul_mul_outer`）负责 $I-vv^\top$ 与投影的代数；`RankInverse.lean`（`rankOne_path_eq_affine`、`rankOne_path_inverse`、`rankOne_path_inverseSquareRoot`）就是 $X_t^{-1},X_t^{-1/2}$ 的显式公式；`KernelSpectrum.lean`（`inverseSquareRoot_eq_cfc`、`matrix_cfc_mul`、`inverseSquareRoot_sq/isUnit/commute`）；`KernelLimit.lean` 第 13 行 `inverseSquareRoot_affine_eq_cfc`、第 26 行 `inverseSquareRoot_affine_tendsto`（**`eq:kernel-limit` 的实际使用者**）、第 36 行 `inverseSquareRoot_kernel_limit`（terminal）；`SpectralContinuity.lean`（`matrix_cfc_tendsto`、`inverse_sqrt_affine_scalar_tendsto`）；`NormThreshold.lean` 第 12/22/37 行（`posSemidef_scalar_sub_iff`、`posSemidef_norm_threshold`、`posSemidef_gram_threshold`，后者需 `[NeZero n]`——对应原文"applies to rectangular / zero threshold"的边界处理）；`NormCongruence.lean` 第 34 行 `NormalizedPencil.positive_threshold`（`eq:threshold-norm`）；`NormLimits.lean` 第 35 行 `positive_unital_map_inverseSquareRoot_tendsto`；`NormBounds.lean`（`whitened_phi_posSemidef`、`whitened_phi_threshold`）；主体 `NormIdentity.lean` 第 16 行 `NormalizedPencil.norm_identity`（约 50 行）与第 67 行 `NormalizedPencil.same_direction_zero`（第八步）。

## 2.7 §6（06-tangent.tex 第 1–89 行）——切空间障碍：Theorem 1.1 的证明

本节的陈述没有独立编号（它是 `\begin{proof}[Proof of Theorem~\ref{thm:main}]`），但它是全文最强的结果；素材按用户要求逐段重建。

### (a) 精确陈述（TeX 原文，节引言 + 证明主体）

```latex
\section{The tangent obstruction}\label{sec:tangent}

We finish the proof by taking a first-order limit in the norm identity
at a point where the kernel projection varies smoothly. This produces
a bilinear matrix whose entries must vanish by Lemma~\ref{lem:form}.

\begin{proof}[Proof of Theorem~\ref{thm:main}]
Proposition~\ref{prop:hyperbolic} establishes the polynomial's degree,
normalization, and hyperbolicity. Suppose its closed hyperbolicity cone
has a real symmetric pencil representation of some finite size.
Fix the maps \(D,E,B\) supplied by Proposition~\ref{prop:pencil}, with
their fixed finite dimensions \(a,c\). Proposition~\ref{prop:norm} gives
\eqref{eq:norm-identity} for the projections in \eqref{eq:projections}.
We shall show that this identity is impossible.
```

证明的收尾两句（第 85–88 行）给出矛盾的确切形式：

```latex
Lemma~\ref{lem:form} forces every entry to vanish identically.
Equation~\eqref{eq:tangent-identity} would therefore make \(b\)
identically zero, contradicting \(b(e_1,e_1)=1\).
This excludes the hypothetical finite pencil and completes the proof.
```

### (b) 证明机制逐步推演

**第 0 步：结构定位。** Theorem 1.1 有两部分：次数 20 + 归一化 + 双曲性由 Prop 3.1 提供（原文首句），剩下"锥非谱形"用反证：假想有限尺寸实对称 pencil ⟹ Prop 4.1 给 $(D,E,B,a,c)$ ⟹ Prop 5.1 给 `eq:norm-identity` ⟹ 本节证明该恒等式**不可能**成立。注意 $a,c$ 在此"被 pencil 固定"（"with their fixed finite dimensions"）——后续所有有限维论证都靠它。

**第 1 步：对象与参数域。**
$$A(u)=E(I-uu^\top),\qquad u\in\Omega:=\{u\in S^3:u_0\ne0\},\quad S^3=\{u:\norm u=1\}.$$
$u\mapsto uu^\top$ 连续、$E$ 线性 ⟹ $A$ 是 $S^3$ 上的连续（其实是实解析）对称矩阵值函数；$I-uu^\top\succeq0$（特征值 $0,1,1,1$）⟹ $A(u)\succeq0$（$E$ 正）。$\Omega$ 是 $S^3$ 的开稠密子集（去掉超平面 $u_0=0$ 的交线）。**$\Omega$ 的作用在第 6 步（$J$ 同构需要 $v_0\ne0$）**，不是技术点缀。

**第 2 步：取最大秩点。** $\rank A(u)\in\{0,1,\dots,c\}$ 有限 ⟹ 最大值 $\rho$ 在某个 $v\in\Omega$ 取到。`[推测]` 这一步用"值域有限"避开了 transversality/一般位置论证：不需要 Sard、不需要 $\rho$ 点稠密，只需要**存在一个**点使秩最大，从而在该点邻域内秩"不能升只能降"⟹ 值域被固定的 $\rho$ 列生成。

**第 3 步（$\rho>0$）：常秩邻域 + 显式核投影公式。**
- 选 $A(v)$ 的 $\rho$ 个线性无关列；$W(u)$ = $A(u)$ 的同样那些列（列指标固定）。
- 无关性开：这 $\rho$ 列构成 $\rho\times\rho$ 非零子式，子式连续 ⟹ 在 $v$ 的某邻域（在 $\Omega$ 中）仍无关。
- 由 $\rho$ 的最大性，$\rank A(u)\le\rho$ ⟹ 这 $\rho$ 个无关列**张成** $\range A(u)$（维数恰 $\rho$）。
- $A(u)$ 对称 ⟹ $\ker A(u)=(\range A(u))^\perp$ ⟹
$$R(u)=\proj_{\ker A(u)}=I-\proj_{\range A(u)}=I-W(u)\bigl(W(u)^\top W(u)\bigr)^{-1}W(u)^\top .$$
末式是"满列秩矩阵的列空间正交投影"的标准公式（$W^\top W$ 可逆因为列无关）。⟹ $R$ 在该邻域是矩阵元素的**有理函数**（分母 $\det(W^\top W)\ne0$），故光滑，微分 $dR_v$ 存在。
**注意**：这里 $R(u)$ 与 `eq:projections` 的定义 $\proj_{\ker E(I-uu^\top)}=\proj_{\ker A(u)}$ 一致，所以第 3 步是"给已有对象一个可微表示"。

**第 4 步（$\rho=0$）：** $\rank A\equiv0$ 于 $\Omega$ ⟹ $A(u)=0$ ⟹ $\ker A(u)=\R^c$ ⟹ $R(u)=I_c$，仍光滑。原文把两种情形合并为一句"If $\rho=0$, then $R(u)=I$ on $\Omega$, so it is smooth in this case as well"，即论证不需要分情况讨论后续。

**第 5 步：零阶事实。** 固定 $v$。`eq:norm-identity` 取 $u=v$：$v_0v'-v_0v'=0$ ⟹ $b(0,y)=0$ ⟹ $P(v)B(y)R(v)=0$ 对 every $y\in\R^3$。（这是 Prop 5.1 末尾已指出的。）

**第 6 步：切方向与 wedges。** 设 $h=(h_0,h')\in v^\perp$（$\dim v^\perp=3$），
$$Jh=v_0h'-h_0v'\in\R^3,\qquad u_s=\frac{v+sh}{\sqrt{1+s^2\norm h^2}}.$$
核对：$\norm{v+sh}^2=\norm v^2+2s\langle v,h\rangle+s^2\norm h^2=1+s^2\norm h^2$（正交性 ⟹ 交叉项消失）⟹ $u_s\in S^3$ ✓；$\frac{d}{ds}\big|_{s=0}u_s=h$（分母导数 $\frac{s\norm h^2}{\sqrt{}}\big|_{0}=0$）✓，即图注所谓"velocity at zero is $h$"。wedge 计算：
$$v_0u_s'-(u_s)_0v'=\frac{v_0(v'+sh')-(v_0+sh_0)v'}{\sqrt{1+s^2\norm h^2}}=\frac{s(v_0h'-h_0v')}{\sqrt{1+s^2\norm h^2}}=\frac{s\,Jh}{\sqrt{1+s^2\norm h^2}}\ \checkmark$$
（分子里 $v_0v'-v_0v'=0$，剩下的正是 $s$ 的一次项——**这就是为什么零阶项湮灭后一阶项恰好是 $Jh$**。）

**第 7 步：差商恒等式（本节的核心代数）。** $s$ 小 ⟹ $u_s\in$ 第 3 步的常秩邻域且 $R$ 在其上光滑。对 $s\ne0$，`eq:norm-identity` 用这对 $(u_s,v)$：
$$b\Bigl(\tfrac{s\,Jh}{\sqrt{1+s^2\norm h^2}},\,y\Bigr)=\norm{P(v)B(y)R(u_s)}_\op^2 .$$
左边用 $b$ 对**第一个变量**的 2 次齐次（`eq:form` 每项 $z_i^2$ 型）提出 $\frac{s^2}{1+s^2\norm h^2}$；右边用第 5 步的 $P(v)B(y)R(v)=0$ 把 $R(u_s)$ 换成差商：
$$P(v)B(y)R(u_s)=P(v)B(y)\bigl(R(u_s)-R(v)\bigr)=s\,P(v)B(y)\frac{R(u_s)-R(v)}{s}.$$
两边除以 $s^2$ 得原文的
$$\frac{b(Jh,y)}{1+s^2\norm h^2}=\norm{P(v)B(y)\tfrac{R(u_s)-R(v)}{s}}_\op^2 .$$
**只有 $R$ 被微分，$P(v)$ 保持固定**（原文第 63–64 行与图注都强调此点；机制见 (c) 第四条）。

**第 8 步：取 $s\to0$。** $\frac{R(u_s)-R(v)}{s}\to dR_v(h)$（算子范数，因为 $R$ 光滑且 $u_s'(0)=h$），算子范数在有限维连续 ⟹
$$b(Jh,y)=\norm{P(v)B(y)\,dR_v(h)}_\op^2\qquad(h\in v^\perp,\ y\in\R^3)\quad(\text{eq:tangent-identity}).$$

**第 9 步：$J$ 是同构（$v_0\ne0$ 的唯一用途）。** 若 $Jh=0$，则 $v_0h'=h_0v'$；由 $v_0\ne0$ 得 $h'=(h_0/v_0)v'$，于是 $h=(h_0/v_0)(v_0,v')=(h_0/v_0)v$；再由 $h\perp v$ ⟹ $\langle h,v\rangle=(h_0/v_0)\norm v^2=h_0/v_0=0$ ⟹ $h_0=0$ ⟹ $h=0$。单射 + 双方维数 3（$\dim v^\perp=3$、$\dim\R^3=3$）⟹ 同构。⟹ $z\in\R^3$ 可**任意**写成 $z=Jh$。

**第 10 步：造出被 $b$ 支配的双线性形式。**
$$F(z,y)=P(v)B(y)\,dR_v(J^{-1}z),\qquad z,y\in\R^3 .$$
$B$ 线性、$dR_v$ 线性（$v^\perp\to\R^{c\times c}$）、$J^{-1}$ 线性 ⟹ $F$ 的每个元素 $\ell_{ij}(z,y)$ 是**双线性**形式。固定正交基后逐元素估计：
$$\ell_{ij}(z,y)^2\le\norm{F(z,y)}_\op^2=b(z,y)\qquad(z,y\in\R^3),$$
左边是"$|M_{ij}|\le\norm M_\op$"（取单位向量 $e_i,e_j$：$M_{ij}=\langle e_i,Me_j\rangle$），右边是 `eq:tangent-identity`（$z=Jh$ 遍历全部 $\R^3$）。

**第 11 步：引 Lemma 2.1 收口。** Lemma 2.1 说：任何满足 $\ell(z,y)^2\le b(z,y)$（对**所有** $z,y$）的双线性形式 $\ell$ 必为零。⟹ 每个 $\ell_{ij}\equiv0$ ⟹ $F\equiv0$ ⟹ `eq:tangent-identity` 右端恒零 ⟹ $b(Jh,y)=0\ \forall h,y$ ⟹ $b(z,y)=0\ \forall z,y$（$J$ 满射），与 Lemma 2.1 前半"nonzero"给出的 $b(e_1,e_1)=1$ 矛盾（直接按 `eq:form` 核：$z=y=e_1$ 时第一项 $z_1^2y_1^2=1$，第二项全含 $z_iy_i z_jy_j$（$i<j$）故 $=0$，第三项 $\sum z_i^2y_{i+1}^2=z_1^2y_2^2+z_2^2y_3^2+z_3^2y_1^2=0$ ⟹ $b(e_1,e_1)=1$ ✓）。⟹ 假想 pencil 不存在 ⟹ $K$ 非谱形 ⟹ Theorem 1.1 的第二部分。$\blacksquare$

### (c) 假设与常数的机械性理由

1. **$v_0\ne0$（即整个论证限定在 $\Omega$）**：只用在第 9 步 $J$ 同构。若 $v_0=0$，$Jh=-h_0v'$ 的值域落在 $\span\{v'\}$（至多 1 维）⟹ 只控制 $b$ 在一条直线上的取值，而 Lemma 2.1 的前提是"对**每个** $z,y$"；被 $b$ 限制在低维子空间上的双线性形式可以非零（例如 $\ell(z,y)=\langle z,v'\rangle y_1$ 之类无法由 $b$ 支配为零——更确切地说 Lemma 2.1 不再适用）。同时 $\rho$ 的最大性也是在 $\Omega$ 上取的，保证 $v\in\Omega$。
2. **常秩邻域（第 2、3 步）**：唯一用途是给 $R$ 一个可微表示（第 8 步的差商极限）。若秩在 $v$ 附近跳，$\proj_{\ker A(u)}$ 可能不连续（特征值穿越 $0$ 时投影突跳），$dR_v(h)$ 不存在。`[推测]` 用最大秩点而不是"几乎处处"是为了**避免**测度/泛型论证，让整条证明是有限步初等的。
3. **$a,c$ 有限**：第 3 步的"选 $\rho$ 个列 + $(W^\top W)^{-1}$"公式、子式开性、$W^\top W$ 可逆都需要有限列；无限维 $N$ 情形（算子值 pencil）得改用 Riesz 投影/解析扰动理论。而 Theorem 1.1 恰好只否定有限 $N$（"for every finite $N\geq1$"），所以 finiteness 是被**用尽**的假设，不是装饰。
4. **只微分 $R$、固定 $P(v)$**：`eq:norm-identity` 的左端是**关于 $(u,v)$ 的 wedge** $v_0u'-u_0v'$；把 $v$ 冻住、让 $u$ 走，wedge 的一阶部分恰为 $sJh$（第 6 步的分子里没有 $v$ 的扰动项）。若同时动 $u,v$，wedge 的一阶项会是 $J$ 型项之和，两个差商乘积的极限不再是单一 $dR_v(h)$，而 $P$ 的微分也要存在（$P$ 的定义域里 $D$ 与 $E$ 不对称，$D$ 的常秩邻域未讨论）。**不对称处理是把论证限制在 $E$ 一侧的省事做法**，也解释了为什么第 9 步只需要一个同构 $J$。
5. **$b$ 对第一变量的 2 次齐次**：第 7 步提出 $s^2$ 以匹配右端"$\norm{\cdot}_\op^2$ 的差商平方"；这是 (2,2) 双齐次结构与"范数平方"之间的度匹配。若 $b$ 对 $z$ 是 1 次，差商平方除以 $s^2$ 后左端 $\sim1/s$ 发散；若是 4 次，左端 $\sim s^2\to0$ ⟹ 得到 $0=\norm{\cdot}^2$ 的同义反复，障碍消失。
6. **`eq:norm-identity` 必须是**等式****：第 10 步只用到不等式 $\ell_{ij}^2\le\norm F^2$，故"$\ell_{ij}^2\le b$"这一步即便只有 $\norm{F}^2\le b$ 也成立，$\ell_{ij}=0$ 照样能推出；**但矛盾来自把 $F=0$ 回代到等式右端得到 $b\equiv0$**。若第 8 步只有 $b(Jh,y)\ge\norm{P(v)B(y)dR_v(h)}^2$，则 $F\equiv0$ 只给出 $b\ge0$（已知），无任何矛盾。这说明 Prop 4.1 里"$\Longleftrightarrow$"（双向）与 Prop 5.1 的等式不是冗余精度，而是生死线。
7. **$B$ 线性 + $dR_v$ 线性**：$\ell_{ij}$ 双线性 ⟹ 落入 Lemma 2.1 的适用类。Lemma 2.1 只针对**双线性** $\ell$；若 $F$ 的元素是二次型（例如允许非线性表示），其平方对 $b$ 的支配就变成 4 次 vs 2 次，第 10 步的比较不再给出 Lemma 2.1 的前提。
8. **$h\ne0$（图注 "for a fixed nonzero $h\in v^\perp$"）**：$h=0$ 时 $u_s\equiv v$、差商为 $0$，只是平凡情形；$J$ 同构需要遍历所有 $h$。

### (d) `[推测]` 候选失败路线

1. **在 $u_0=0$ 的点上做变分**：失败机制见 (c) 第一条 —— $J$ 降秩 ⟹ 只能控制 $b$ 在一维（至多二维）子空间上的值 ⟹ Lemma 2.1 的"对每个 $z$"失去，最可能的后果是只导出 $\ell$ 在这些方向为零（本来就可能）。这解释了 $\Omega$ 的选择：$u_0\ne0$ 是"$v_0h'-h_0v'$ 覆盖全部 $\R^3$"的**充要**条件（$v_0=0$ 时值域含于 $\span\{v'\}$）。
2. **零阶就收口（不微分）**：第 5 步 $P(v)B(y)R(v)=0\ \forall y$ 只是线性湮灭条件，存在大量非零 $B$ 满足它（例如 $\im B(y)\subseteq(\ker P(v))^\perp$ 之类），无法否定 pencil；`[推测]` 换言之零阶信息被表示的存在性"免费"消耗掉了，一阶是第一个非平凡约束。这也说明为什么全篇需要微分而非纯代数。
3. **用 $A(u)$ 的特征向量基而不是 $W(W^\top W)^{-1}W^\top$ 公式来表达 $R(u)$**：失败机制是特征向量在重特征值处不可选为光滑（本例 $A(u)=E(I-uu^\top)$ 的谱恰恰来自 4 维 $\Sym^4$ 结构，重数几乎必然出现）；论文的"固定列 + Gram 逆"绕开了谱分解。Lean 的做法**又不同**：`GramProjection.lean` 第 21 行 `gramProjection`（$T\circ(T^\H T)^{-1}_{\text{ring inverse}}\circ T^\H$）+ 第 48 行 `one_sub_gramProjection_eq_kernel`，并在 `KernelLocal.lean` 第 14 行 `exists_smooth_kernel_extension` 里用"$T$ 单射的开集 + `gram_isUnit_of_injective`(24)"构造光滑核族；`contDiffOn_gramProjection`(57) 提供可微性。即 Lean 用算子式 Gram 投影（抽象但一致）替代论文的"选 $\rho$ 个独立列"的具体公式。论文那条列选取路线在 Lean 里**也存在**于 `TangentFigure.lean`（第 15 行 `exists_smooth_constant_rank_extension`、第 60 行 `matrix_independent_spanning_columns`、第 78 行 `matrix_columns_independent_neighborhood`、第 95 行 `matrix_columns_span_of_rank_le`、第 107 行 `matrix_fixed_columns_local_frame`），但这些引理全部 terminal（无下游引用），说明主线没有采纳。
4. **改用高阶变分或全局（非局部）论证**：`[推测]` 无必要且会失败：障碍已经是"局部一阶 ⟹ 全局 $b$"，因为 $J$ 把整个 3 维 $z$-空间搬到了切空间；再往高阶级只会引入 $d^2R_v$ 等对象，其元素是 $z$ 的二次型，脱离 Lemma 2.1 的适用类。
5. **想省掉"$\rho$ 的最大性"而直接在任意点微分**：若 $\rank A(u)>\rho$ 出现在邻域里（不可能，由最大性），则第 3 步"这 $\rho$ 列张成 $\range A(u)$"断裂，$R(u)$ 的公式失效（会漏掉新增方向）。这是"取最大秩点"这一选择的精确代价。

## 2.8 Corollary 1.2（`cor:reduced`）+ §7 的证明（reduced-polynomial.tex 全文）——去掉一个行列式因子

### (a) 精确陈述（TeX 原文）

推论（01-introduction.tex 第 78–89 行）：

```latex
\begin{corollary}\label{cor:reduced}
The quotient $q=p/\det X$ extends to a homogeneous polynomial of degree
$16$ in the same $23$ variables. It is hyperbolic with respect to $e$,
with $q(e)=1$, and $\Lambda_+(q,e)=K$. In particular, its closed
hyperbolicity cone is not spectrahedral.
\end{corollary}

We prove the degree reduction in Section~\ref{sec:reduced}, after the
obstruction argument. We make no claim that the dimension or degree is
minimal. The real symmetric convention also covers Hermitian pencils:
for a Hermitian matrix $H=A+iB$, positivity is equivalent to positivity
of the real symmetric matrix $\left(\begin{smallmatrix}A&-B\\B&A\end{smallmatrix}\right)$.
```

摘要（main.tex 第 34–39 行）用的正是归约后的口径："a homogeneous hyperbolic polynomial of degree 16 in 23 variables ... its hyperbolicity cone is not spectrahedral"。§7 开头两句交代方法：

```latex
The polynomial $p$ makes the positive-map construction explicit through
a $4\times4$ determinant. We now remove a factor that is unnecessary for
its hyperbolicity cone. A larger block determinant shows directly that
the quotient remains polynomial at singular $X$.
```

### (b) 证明机制逐步推演

**第 1 步：将 $\Phi_y$ 写成"压缩 Kronecker"形式（第 9–19 行）。** 对 $\R^3$ 的标准基 $e_i$ 令
$$K_i=\begin{pmatrix}0&e_i^\top\\-e_i&0\end{pmatrix}\in\R^{4\times4},\qquad C=\begin{pmatrix}K_1&K_2&K_3\end{pmatrix}\in\R^{4\times12}.$$
逐块核对 $\sum_{i,j}Q(y)_{ij}K_iTK_j^\top=\Phi_y(T)$（取 $T=\begin{pmatrix}a&r^\top\\ r&T'\end{pmatrix}$，块大小 $1|3$）。先算 $K_iT$：
$$[1,1]=e_i^\top r\ (=r_i),\quad [1,2]=e_i^\top T'\ (1\times3),\quad [2,1]=-ae_i,\quad [2,2]=-e_ir^\top .$$
再右乘 $K_j^\top=\begin{pmatrix}0&-e_j^\top\\ e_j&0\end{pmatrix}$：
$$[1,1]\mapsto e_i^\top T'e_j=T'_{ij},\quad [1,2]\mapsto -r_ie_j^\top,\quad [2,1]\mapsto -r_je_i,\quad [2,2]\mapsto a\,e_ie_j^\top .$$
用 $Q$ 对称合并：$\sum_{ij}Q_{ij}(\cdot)$ 给出 $\bigl(\tr(QT'),\ -r^\top Q,\ -Qr,\ aQ\bigr)$，**逐块等于 `eq:phi`** ✓。第二等号 $C(Q(y)\otimes T)C^\top$ 只是 $C=(K_1\ K_2\ K_3)$ 与 Kronecker 分块定义 $\bigl(U\otimes V\bigr)_{ij}=U_{ij}V$ 的重写（原文明说 "Here $U\otimes V$ denotes the block matrix with blocks $U_{ij}V$"，并说这是 "Direct block multiplication in \eqref{eq:phi}"）。
`[推测]` 这个 $K_i$ 是 $\so(4)$ 型反对合块，作用是把"$T$ 的 $(1,1)$ 迹项 / 向量项 / 矩阵项"三者按 $Q$ 装配；选 $\pm e_i$ 的反对称符号正是为了 off-diagonal 块出现 $-r^\top Q$ 与 $-Qr$ 的**转置对**，从而整体保持对称。

**第 2 步：定义 $16\times16$ 分块行列式（第 20–26 行）。**
$$q(X,Z,y)=\det\begin{pmatrix} I_3\otimes X&C^\top\\ C\bigl(Q(y)\otimes I_4\bigr)&Z\end{pmatrix},$$
块尺寸 $12\times12$、$12\times4$、$4\times12$、$4\times4$ ⟹ 总 $16\times16$。多项式性**由定义显然**（每块对 $(X,Z,y)$ 至多二次），这就是节引言那句 "A larger block determinant shows directly that the quotient remains polynomial at singular $X$" 的意思：$q$ 是先被**构造**成多项式，再与 $p/\det X$ 比对，而不是先做除法。

**第 3 步：Schur 补认出 $q$（第 27–30 行）。** $X$ 可逆时 $A=I_3\otimes X$ 可逆，$A^{-1}=I_3\otimes X^{-1}$，$\det A=(\det X)^3$（$3$ 份 $4\times4$），标准分块行列式公式
$$\det\begin{pmatrix}A&B^\top\\ B&D\end{pmatrix}=\det A\cdot\det(D-BA^{-1}B^\top)$$
给
$$BA^{-1}B^\top=C\bigl(Q(y)\otimes I_4\bigr)(I_3\otimes X^{-1})C^\top=C\bigl(Q(y)\otimes X^{-1}\bigr)C^\top=\Phi_y(X^{-1})$$
（混合乘积 $(Q\otimes I)(I\otimes X^{-1})=Q\otimes X^{-1}$ ✓，最后一步用第 1 步）。于是
$$q(X,Z,y)=(\det X)^3\det\bigl(Z-\Phi_y(X^{-1})\bigr).$$

**第 4 步：与 `eq:inverse-formula` 比对 ⟹ $p=(\det X)q$（第 31–37 行）。** Prop 3.1 的 `eq:inverse-formula` 是 $(\det X)^4\det(Z-\Phi_y(X^{-1}))$，两者相除恰差一个 $\det X$：
$$p(X,Z,y)=(\det X)\,q(X,Z,y)\qquad(\text{eq:reduced-factor}),$$
先在 $\det X\ne0$ 上成立，再由"多项式恒等式在 Zariski 稠密开集上成立 ⟹ 处处成立"（原文用 "then everywhere by continuity"，实分析口径：$\det X\ne0$ 的集合在 $\R^{23}$ 中稠密）。
次数账目：$p$ 齐次 20、$\det X$ 齐次 4 ⟹ $q$ 齐次 16。$q(e)=1$：代 $X=Z=I_4,y=0$，$Q(0)=0$ ⟹ 分块上三角 $\begin{pmatrix}I_{12}&C^\top\\0&I_4\end{pmatrix}$，行列式 $1$。

**第 5 步：$q$ 双曲（第 38–40 行）。** 对每个实 $(X,Z,y)$，把 `eq:reduced-factor` 用在 $te-(X,Z,y)=(tI_4-X,\ tI_4-Z,\ -y)$：
$$p(te-x)=\det(tI_4-X)\cdot q(te-x)\quad\text{in }\R[t].$$
$p(te-x)$ 全实根（Prop 3.1）且首项系数 1、次数 20；$\det(tI_4-X)$ 是首一 4 次全实根多项式（特征值）⟹ $\deg_t q(te-x)=16$ 恒成立（故 $q(te-x)$ 不是零多项式，也无需处理退化情形），而**实系数多项式的因子若整除全实根多项式则自身全实根**（复根成共轭对出现且必为被除式的根）⟹ $q$ 关于 $e$ 双曲，$q(e)=1\ne0$ ✓。

**第 6 步：根集账目 ⟹ $K=\{X\succeq0\}\cap K_q$（第 42–48 行）。** 由第 5 步的乘积分解，$p(te-x)$ 的根集（带重数）= $\det(tI_4-X)$ 的根集 $\sqcup$ $q(te-x)$ 的根集，而前者是 $X$ 的特征值（各重 1）。$\Lambda_+$ 的判据"所有根 $\ge0$"对不交并无重复的并集成立当且仅当两部分各自非负，故
$$x\in K\iff X\succeq0\ \wedge\ x\in K_q\qquad(\text{eq:cone-intersection}).$$
原文理由一句："because the roots contributed by $\det(tI_4-X)$ are the eigenvalues of $X$."

**第 7 步：偶 + 凸 + 中点 ⟹ $K_q$ 自己就逼出 $X\succeq0$（第 49–55 行）。** 三步：
1. **偶性**：$Q(-y)=Q(y)$（每项 $y_i^2$ 或 $y_iy_j$）⟹ `eq:reduced-polynomial` 的中间块 $C(Q(y)\otimes I_4)$ 不变 ⟹ $q(X,Z,-y)=q(X,Z,y)$；又 $K_q$ 由 $q$ 的根判定，故 $(X,Z,y)\in K_q\implies(X,Z,-y)\in K_q$。
2. **凸性**：引用 `[Garding]`（bib key `garding-1959`）的双曲性锥凸定理，$(X,Z,y),(X,Z,-y)\in K_q$ ⟹ 中点 $(X,Z,0)\in K_q$。
3. **$y=0$ 切片的显式**：$Q(0)=0$ ⟹ $q(te-(X,Z,0))=\det\begin{pmatrix}I_3\otimes(tI-X)&C^\top\\0&(tI-Z)\end{pmatrix}=\det(tI-X)^3\det(tI-Z)$（原文写 $q(X,Z,0)=(\det X)^3\det Z$，即同一式子的未位移形式）。其根 = $X$ 的特征值（各重 3）与 $Z$ 的特征值 ⟹ 全部非负 $\iff X\succeq0\wedge Z\succeq0$ ⟹ 特别地 $X\succeq0$。
合并第 6、7 步：$K_q=K$ ⟹ $K_q$ 非谱形 ⟹ **推论的全部结论**。$\blacksquare$

**注意与 Prop 3.2 的 `eq:slice-zero` 的平行结构**：那里是 $\det(tI-X)^4\det(tI-Z)$（$p$，重数 4），这里是 $\det(tI-X)^3\det(tI-Z)$（$q$，重数 3），差的正是被移除的一个 $\det X$ 因子；两条 $y=0$ 切片给出的**锥**相同（$X\succeq0\wedge Z\succeq0$）。这就是"因子对锥不必要"的精确含义。

### (c) 假设与常数的机械性理由

- **"$C\in\R^{4\times12}$、$I_3\otimes X$"里的 3**：$K_i$ 有 $3$ 个（对应 $y\in\R^3$ 的三个分量），于是 $\det(I_3\otimes X)=(\det X)^3$，恰好把 $p$ 的 $(\det X)^4$ 削成 $(\det X)^3$ ⟹ 移除**一个**因子。若写成 $I_4\otimes X$ 就会得到 $(\det X)^4$，$q$ 与 $p$ 相等（无归约）。16 = $12+4$ 是块总尺寸，也是 $20-4$。
- **$q$ 先定义为行列式（而不是先定义商）**：机械原因是"$\det X\mid p$"在 $\R[X,Z,y]$ 里不是显然的整除（$\det X$ 不可约，但需要 $p$ 在 $\{\det X=0\}$ 上 vanish 到一阶以上，这本身要靠 `eq:inverse-formula` 与秩论证）。分块行列式给出**构造性商**，把整除性变成一次 Schur 计算。§7 首句 "A larger block determinant shows directly that the quotient remains polynomial at singular $X$" 就是在说这件事。
- **"first for invertible $X$ and then everywhere by continuity"**：$\det X\ne0$ 在 $\R^{23}$ 中稠密，两侧是多项式（即连续函数）⟹ 恒等式延拓；这是第 4 步唯一使用的分析事实，配合第 2 步的多项式性。
- **偶性 + Gärding 凸性**：两者共同把"$y\ne0$ 处的成员性"投回到"$y=0$ 切片"，而 $y=0$ 切片是**唯一**被完全显式算出的切片（`eq:reduced-polynomial` 里 $Q(0)=0$ 使分块变三角）。缺任一 ⟹ 第 7 步失效。
- **"$\deg_t p(te-x)=20$ 对所有实输入"**：保证 $q(te-x)$ 恰 16 次，第 5 步的因子论证不必处理 $q(te-x)$ 降次/恒零；这条正好是 Prop 3.1 里 "it has degree 20 for every real input" 一句的兑现。
- **$q(e)=1$**：双曲性定义需要方向处非零。
- **推论的"no claim that the dimension or degree is minimal"**（01-introduction 第 86–87 行）：明确限定结论，不做极小性断言——素材层面要注意，任何"23 是必需维数"的说法都属于论文未述。
- **"real symmetric convention also covers Hermitian pencils"**（第 87–89 行）：给出把结论搬到 Hermitian LMI 口径的一行论证（$H=A+iB\mapsto\begin{pmatrix}A&-B\\B&A\end{pmatrix}$ 的实对称放大，正定性等价）。这排除了"会不会 Hermitian pencil 能表示 $K$"的疑问；注意该放大把尺寸乘 2，但定理量化在"所有有限 $N$"上，故无影响。

### (d) `[推测]` 候选失败路线

1. **直接做多项式除法 $p/\det X$**：失败机制见 (c) 第三条——没有先验的整除性；在坐标环里 $\det X$ 是 $10$ 个变量的四次不可约多项式，要证明它整除 $p$ 需要在奇异点集上的 vanishing 阶估计（等价于证明 $p$ 在 $\{\det X=0\}$ 上至少一阶消失），而 $p=\det((\det X)Z-\Phi_y(\adj X))$ 在 $X$ 秩亏时 $\adj X$ 的阶数行为并不显然（秩 $2$ 时 $\adj X\ne0$，秩 $\le1$ 时 $\adj X=0$ ⟹ $p=(\det X)^4\det Z$ vanish 4 阶，但中间情形要逐秩讨论）。分块行列式路线把这套分层讨论全部吸收。
2. **多移除因子（比如试图把 $\det Z$ 或整个 $(\det X)^3$ 也去掉）**：失败机制在第 6 步的根集账目——被移除因子的根**必须**在 $K$ 上一律非负，否则 $K_{q'}\supsetneq K$。$\det(tI-X)$ 的根在 $K$ 上非负正是 `eq:cone-intersection` 的右端；再削掉 $(\det X)^3$ 剩下的因子 $\det(tI-Z)$ 的根也在 $K$ 上非负（$Z\succeq0$ 由 `eq:slice-zero` 与第 7 步给出），但那时 $\tilde q$ 就不再是多项式（$\det(Z-\Phi_y(X^{-1}))$ 非多项式）——所以 $q$ 恰好是"能保持多项式的最大归约"，而非"锥意义下的最简"。`[推测]` 论文因此只说"removes a factor that is unnecessary"。
3. **用 Prop 3.2 的切片直接证 $K_q\subseteq K$（不走偶性+凸性）**：失败机制是 `eq:slice-positive` 只对 $X\succ0$ 成立；$K_q$ 里的边界点（$X$ 奇异，$y\ne0$）没有任何切片刻画。偶 + 中点论证是把"边界信息"从 $y\ne0$ 搬到 $y=0$ 的唯一手段；`[推测]` 若 $q$ 对 $y$ 含奇次项，这条搬运即失效，归约结论会弱化为 $\Lambda_+(q,e)\supseteq K$。
4. **想用"归约后的多项式使 §4–§6 的论证更简洁"来取代原论证**：§6 的反证只用 $K$ 的**切片**（`eq:slice-positive`/`eq:slice-zero`），而这两条对 $p$ 已成立；$q$ 的引入纯粹是为了把陈述次数降到 16 并让摘要口径（degree 16 in 23 variables）成立，不提供任何新的障碍信息。

**Lean 取证（重要，见 §四 汇总）**：本节在 Lean 里**没有被形式化**。`E:\math\lean\OAI\Analysis\HyperbolicCones\` 下无 `ReducedPolynomial.lean` 或等价文件，没有 $q$、没有 $16\times16$ 分块行列式、没有 $K_q=K$。相关的**邻近**事实是 `ZeroPolynomial.lean`：第 15 行 `matrixValue_zero_parameter : matrixValue (X,Z,0) = X.det^4 * Z.det`、第 20 行 `linePolynomial_zero_parameter = charpoly X ^ 4 * charpoly Z`（即 `eq:slice-zero` 的多项式版本，重数 4 与本篇 $p$ 一致而非 $q$ 的 3）、第 38 行 `linePolynomial_repeated_roots : linePolynomial ((1,0),0) = (X-1)^16 * X^4`（这是 history 里 $p(te-w)=(t-1)^{16}t^4$ 的形式化，16 在此**偶然**出现为 $X$ 块的 4 重根数 $=4\times4$，与归约多项式的次数无关）、第 43 行 `repeated_root_point_not_scalar_basePoint`（terminal）。`Main.lean` 的 `main_result` 只断言 20 次的 $p$。因此"degree 16"这一摘要级陈述在形式化中缺失——这是本篇 Lean 与论文之间**最大**的口径差。

### (a) 精确陈述（TeX 原文）

本节**没有任何编号环境**（全文只有 7 条编号陈述：Theorem 1.1、Corollary 1.2、Lemma 2.1、Proposition 3.1/3.2/4.1/5.1；已用 grep 核实 `\begin{remark}`、`\begin{definition}`、`\begin{example}` 均不出现），内容以散文给出。逐字转录（第 1–56 行，分四段）：

```latex
\section{A path-containment assertion}
\label{app:opposition}

Theorem~53 (pp.~16--17) of version~1 of Gonz\'alez Nevado's
\cite{gonzalez-nevado-2026} states a positive solution of the geometric
Generalized Lax conjecture. Its proof invokes Theorem~52 (p.~16), which asserts
containment of a fixed rigidly convex set throughout a smooth real-zero
deformation from a product of normalized tangent linear factors to a
multiple of the defining polynomial. The following example violates
that intermediate assertion under its stated hypotheses.

A real polynomial $g$ with $g(0)=1$ is \emph{real-zero} if the roots of
$s\mapsto g(sx)$ are real for every real vector $x$. Its closed
rigidly convex set is the closure of the component of $\{g\ne0\}$
containing the origin. Fix $a,b,\eta>0$ and, in one variable, put
\[
 g(x)=(1-x/a)(1+x/b),\qquad
 c(t)=1+\eta\sin^2(\pi t),\qquad
 H_t(x)=g(c(t)x),\quad 0\le t\le1.
\]
The zero set of $g$ is the compact smooth set $\{-b,a\}$.
The normalized tangent linear factors at these two points are
$1+x/b$ and $1-x/a$, whose product is $g$. Every $H_t$ has value $1$
at the origin and two distinct real roots,
\[
 -\frac{b}{c(t)}\quad\hbox{and}\quad\frac{a}{c(t)}.
\]
Thus the path depends smoothly on $t$ and consists of real-zero
polynomials with compact smooth zero sets. It even admits the smooth
monic real symmetric determinantal representation
\[
 H_t(x)=\det\begin{pmatrix}
 1-c(t)x/a&0\\
 0&1+c(t)x/b
 \end{pmatrix}.
\]
Both endpoints equal $g$, so the final polynomial is $g$ times the
constant cofactor $1$, as allowed by the stated hypotheses.
Nevertheless the rigidly convex set of $H_t$ is
\[
 \left[-\frac{b}{c(t)},\frac{a}{c(t)}\right],
\]
which is strictly smaller than $[-b,a]$ whenever $0<t<1$.
Consequently it does not contain the rigidly convex set of $g$.

The parameters $a,b>0$ describe the open family of normalized real
quadratics with negative leading coefficient, so the failure is not
confined to a symmetric or multiple-root example. The parameter $\eta$
may be arbitrarily small. The cited Theorem~52 states no restriction
to two or more variables, no lower bound on pencil size, and no
requirement that the endpoint cofactor be nonconstant.

This example refutes the all-intermediate-times conclusion of that
theorem. Its endpoints coincide, so it does not refute an endpoint-only
statement. The nonspectrahedrality result of this paper follows from
the construction and obstruction proved above.
```

### (b) 机制逐步推演

1. **靶子的定位**：被否定的**不是** Theorem 53（那声称 GLC 有肯定解），而是它证明里引用的中间引理 Theorem 52，其内容是"沿一条 smooth real-zero 变形路径，从'归一化切线性因子的乘积'到'定义多项式的常数倍'，某个**固定的** rigidly convex set 在**所有中间时刻**被包含"。原文精确到版本与页码："Theorem~53 (pp.~16--17) of version~1"、"Theorem~52 (p.~16)"。
2. **两个术语**：$g(0)=1$ 实多项式叫 real-zero 若 $\forall x\in\R^n$，$s\mapsto g(sx)$ 的根全实；其 **closed rigidly convex set** $:=\overline{\{g\ne0\}}$ 中含原点的那个连通分支。一变量情形 $g(x)=(1-x/a)(1+x/b)$：$\{g\ne0\}=\R\setminus\{-b,a\}$，含 $0$ 的分支是 $(-b,a)$，闭包 $[-b,a]$ ✓。real-zero 在一变量下自动成立：$g(sx)=0\iff sx\in\{a,-b\}$，$x\ne0$ 时 $s=a/x$ 或 $-b/x$ 实；$x=0$ 时 $g(0)=1\ne0$，根集空（条件空真）✓。
3. **路径的构造**：$c(t)=1+\eta\sin^2(\pi t)$，$\eta>0$；$H_t(x)=g(c(t)x)=(1-c(t)x/a)(1+c(t)x/b)$。逐条核对其"合法性"：
 - $H_t(0)=1$ ✓；根 $x=a/c(t)$ 与 $x=-b/c(t)$，$c(t)\ge1>0$ ⟹ 两个**不同**实根 ✓（$a,b>0$）；
 - $c$ 关于 $t$ 光滑（$\sin^2$ 光滑），且 $c(0)=c(1)=1$、$0<t<1$ 时 $c(t)>1$；
 - 每个 $H_t$ 仍是一变量二次、首项系数 $-c(t)^2/(ab)<0$ ⟹ real-zero、零集 $\{-b/c(t),a/c(t)\}$ 紧光滑 ✓；
 - **有显式 $2\times2$ 对角实对称 determinantal 表示**（分块对角行列式直接乘开：$(1-cx/a)(1+cx/b)=H_t(x$）✓；pencil 为 $A_0=I_2$、$A_1=\operatorname{diag}(-c(t)/a,\ c(t)/b)$，随 $t$ 光滑。原文用 "It even admits..." 强调这是**额外让步**——反例连最弱的尺寸要求都满足。
4. **起点/终点的形状**：Theorem 52 要求的起点是"归一化切线性因子的乘积"。原文核对：$g$ 在两点 $-b,a$ 处的归一化（原点取值为 1）切线性因子是 $1+x/b$ 与 $1-x/a$，其乘积正是 $g$ ✓。终点是"$g$ 的常数倍"：$H_1=g$（$c(1)=1$）⟹ 倍数为常数 $1$ ✓，原文明写 "as allowed by the stated hypotheses"（即该假说不排除常数 cofactor）。
5. **违反之处**：$H_t$ 的 rigidly convex set 是 $[-b/c(t),\,a/c(t)]$。因 $c(t)>1$（$0<t<1$），两端都**向原点收缩** ⟹ 该区间真包含于 $[-b,a]$ ⟹ "固定集合 $[-b,a]$ 在所有中间时刻被包含"**不成立**。注意方向：反例不是"集合爆炸"，而是"集合收缩"，这是最省事的一条。
6. **参数段（第 46–51 行）的三条防御性说明**：
 - $a,b>0$ 是**开族**（"normalized real quadratics with negative leading coefficient" 的两参数族），⟹ 反例不是 $a=b$ 的对称特例、也不是重根特例；
 - $\eta$ 可任意小 ⟹ 违反发生在**任意接近常路径**的变形上（一阶意义上就坏）；
 - Theorem 52 的假说**没有**"变量数 $\ge2$"、"pencil 尺寸下界"、"端点 cofactor 非常数"任一限制 ⟹ 本例不受任何一条豁免。
7. **结论段的自我限定（第 53–56 行）**：只否定"all-intermediate-times"式的结论；因为端点重合（$H_0=H_1=g$），它**不**否定"只在端点成立"的陈述。最后一句把本篇主结果与该附录脱钩："The nonspectrahedrality result of this paper follows from the construction and obstruction proved above."

### (c) 假设与常数的机械性理由

- **$c(t)=1+\eta\sin^2(\pi t)$ 的"号"**：必须是 $1+\eta(\cdots)$（$\ge1$，内部严格 $>1$）才能收缩区间；若取 $1-\eta\sin^2(\pi t)$，$c(t)<1$ ⟹ 区间 $[-b/c,a/c]\supseteq[-b,a]$ ⟹ 包含关系反而成立 ⟹ 反例失效。**这个符号是本节的全部信息量。**
- **$\sin^2(\pi t)$ 而不是 $\sin(\pi t)$**：$\sin^2$ 非负保证 $c(t)\ge1$ 全局一致；且 $c'(t)=\eta\pi\sin(2\pi t)$ 在 $t=0,1$ 处为 $0$，路径在端点**平坦**，因此端点的速度条件（若 Theorem 52 隐含）也不会成为豁免理由。`[推测]` 后者是选用 $\sin^2(\pi t)$ 的动机，论文未述。
- **一变量**：让 rigidly convex set 可精确算成区间、让 $2\times2$ 对角 determinantal 表示显式可得，从而把"没有尺寸下界限制"这一条钉死（尺寸 $=2$）。
- **两个**不同**实根**：real-zero + 紧光滑零集 + "乘积 of 归一化切线性因子"三项要求同时满足的最小情形（重根会破坏"smooth zero set"）。
- **$g(0)=1$ 的归一化**：real-zero 定义与 rigidly convex set 的"含原点分支"都以原点为基准；$H_t(0)=g(0)=1$ 使整条路径保持归一化。
- **$\eta$ 任意小**：使反例对任何"足够接近常路径则包含成立"的修补都免疫；机制是 $[-b/(1+\eta),a/(1+\eta)]$ 与 $[-b,a]$ 的差距 $\sim\eta$，只需非零即违反，不需要大扰动。

### (b) 机制推演

**其一的账目**：$w=(I_4,0,0)$，$e=(I_4,I_4,0)$ ⟹ $te-w=\bigl((t-1)I_4,\ tI_4,\ 0\bigr)$。用 Prop 3.2 证明里 $y=0$ 的显式（原文第 137 行）$p(te-(X,Z,0))=\det(tI_4-X)^4\det(tI_4-Z)$：此处" $X$ "取 $(t-1)I_4$?? 更直接：把 $p$ 的 $\adj$ 定义作用在 $((t-1)I_4,\ tI_4,\ 0)$ 上，$\Phi_0=0$ ⟹ $p=\det\bigl((\det((t-1)I_4))\cdot tI_4\bigr)=\bigl((t-1)^4\bigr)^4\cdot t^4=(t-1)^{16}t^4$ ✓（$\det((t-1)I_4)=(t-1)^4$，外层 $\det$ 再取 4 次幂 ⟹ $(t-1)^{16}$；$\det(tI_4)=t^4$）。归约后 $q=p/\det X$ 里 $\det X$ 在 $te-w$ 处等于 $(t-1)^4$ ⟹ $q(te-w)=(t-1)^{12}t^4$ ✓。**两条都 $\ne$ 单根**（$t=1$ 处重 16/12，$t=0$ 处重 4）⟹ 严格双曲性在 $w\notin\R e$ 处失效。$w\notin\R e$ 的核对：若 $w=\lambda e$ 则 $Z$ 块给出 $0=\lambda I_4$ ⟹ $\lambda=0$ ⟹ $w=0$ 矛盾 ✓。

```latex
\begin{equation}
 b(z,y)=\sum_{i=1}^3 z_i^2y_i^2
       -2\sum_{1\leq i<j\leq3}z_iy_iz_jy_j
       +\sum_{i=1}^3z_i^2y_{i+1}^2.
 \label{eq:form}
\end{equation}
This is the coefficient-one Choi--Lam biquadratic
form~\cite[Section~4]{choi-lam-1977}.
Define $Q(y)\in\Sym^3$ by
\[
 Q(y)_{ii}=y_i^2+y_{i+1}^2,\qquad
 Q(y)_{ij}=-y_iy_j\quad(i\ne j),
\]
so that $b(z,y)=z^\top Q(y)z$.
For $a\in\R$, $r\in\R^3$ and $T\in\Sym^3$, define the linear map
$\Phi_y:\Sym^4\to\Sym^4$ by
\begin{equation}
 \Phi_y\!\begin{pmatrix}a&r^\top\\r&T\end{pmatrix}
 =\begin{pmatrix}
    \tr(Q(y)T)&-r^\top Q(y)\\
    -Q(y)r&aQ(y)
   \end{pmatrix}.
 \label{eq:phi}
\end{equation}
The dependence on $y$ is homogeneous quadratic. If $\adj X$ denotes the
adjugate of $X$, set
\begin{equation}
 p(X,Z,y)=\det\big((\det X)Z-\Phi_y(\adj X)\big),
 \qquad (X,Z,y)\in\Sym^4\times\Sym^4\times\R^3.
 \label{eq:polynomial}
\end{equation}
```

论文对这三式的**唯一**解释性文字就是 #9（"The map $\Phi_y$ translates this form into a matrix inequality"）与 #22（"makes the positive-map construction explicit through a $4\times4$ determinant"）。`[推测]` 结构上的动机（论文未述）：$\Phi_y$ 的块形式正是把 $b(z,y)=z^\top Q(y)z$ 塞进"$4\times4$ 矩阵的 $(2,2)$ 块 $=aQ$"这一 slot，使秩 1 检验 $u^\top\Phi_y(vv^\top)u$ 自动产生 wedge $v_0u'-u_0v'$；换句话说 $\Phi$ 是"$\Sym^4$ 的分块 $1|3$ 结构 ⟹ $\Sym^3$ 作用"的自然伴生对象，选取 $4\times4$ 是为了让 $3$ 维 $z$-空间恰好成为 wedge 的像空间（$\dim\R^4-1=3$）。这也是 §6 中 $J:v^\perp\to\R^3$ 同构能成立的前置条件——**维数 $4/3$ 的账目在构造那一刻就锁定了**。

## 3.5 `[推测]` 论证顺序为何如此安排

- **先标量后矩阵**（§2 在 §3 之前）：`[推测]` 因为矩阵侧的全部工具（切片、Schur、范数、变分）都是为了造出一个 $\ell$；先固定"终点长什么样"（Lemma 2.1），读者才知道每一步在提取什么。
- **降次放到最后**（§7 在障碍之后）：`[推测]` 因为障碍论证只用 $K$ 的两条切片，而这两条对 $p$ 已足够；若先给 $q$，则 $q$ 的切片刻画反而需要额外论证（$X$ 奇异处的成员性要靠偶 + 凸），会打乱主线。
- **只用一条秩 1 恒等式**（`eq:rank-one`）：`[推测]` 全文与 $b$ 相关的输入只有它，这让"标量障碍 ⟹ 矩阵障碍"的转换点极少，易于形式化（Lean 的 `phi_rank_one` 只有一个使用者链，见 §四）。
- **反证法而非构造性否定**：`[推测]` 因为"对任意 $N$ 均无表示"无法构造性证明；把任意 pencil 变成 $(D,E,B)$ 后，剩下的论证只依赖 `eq:schur-equivalence` 这一条抽象接口——这是 Lean 能把 `NormalizedPencil` 做成独立 structure 的原因（§四详述）。

2. **`cone` 的定义口径**。Lean（`Model.lean:66–67`）：

```lean
def cone : Set Ambient :=
  {x | ∀ t : ℂ, (linePolynomial x).aeval t = 0 → t.im = 0 ∧ 0 ≤ t.re}
```

即"沿 $e$ 的单变量多项式的**所有复根**为实且非负"。论文用带重数的 $\lambda_1(x),\dots,\lambda_d(x)$（§1 第 7–11 行）+ $\lambda_j(x)\ge0$。二者在外延上等价（等价性由 `ConeRoots.lean:10 cone_iff_nonnegative_real_roots` 与 `RootFactorization.lean:12 linePolynomial_splits`/`:28 linePolynomial_card_roots` 提供，后者属未用的 `RootFactorization` 叶子）。`linePolynomial`（`Model.lean:61–64`）就是 $p(te-x)$：把每个坐标替换为 `C (coordinates basePoint i) * Polynomial.X - C (coordinates x i)`；`LinePolynomial.lean:71 linePolynomial_top`（`coeff 20 = 1`）与 `:81 linePolynomial_monic` 对应论文"首项系数 $p(e)=1$"。
3. **`main_result` 拆成六个合取**（`Main.lean:25–34`，原文见 4.1 引用的 challenge 版）：`finrank = 23`、`IsHomogeneous 20`、`totalDegree = 20`、`eval (coordinates basePoint) polynomial = 1`、`∀ x z, aeval z = 0 → z.im = 0`（= 双曲性）、`∀ N (0<N) (L : Ambient →ₗ[ℝ] Sym N), cone ≠ {x | (L x).PosSemidef}`（= 非谱形）。论文 Theorem 1.1 把前四项压成一句"homogeneous of degree 20 ... with $p(e)=1$"，且**没有**把"$\dim=23$"写成断言（它写在 §1.1 的正文里）；Lean 把 `finrank = 23` 作为**被证明的对象**（`Coordinates.lean:50 ambient_finrank`，其基础是 `:12 symIndex_card : Fintype.card SymIndex = 10 := by decide` 与 `:14 coordinate_card : Fintype.card Coord = 23 := by decide`）。
4. **非谱形的量化细节**：Lean 写 `∀ (N : ℕ) (_hN : 0 < N)`，论文写"for every finite $N\geq1$"——一致（$N=0$ 被排除）。Lean 的 `L : Ambient →ₗ[ℝ] Sym N` 是**齐次**线性映射，与论文 `eq:spectrahedral` 的 $L(x)=\sum x_iA_i$ 同构（`Sym N = selfAdjoint (Mat N ℝ)`）。结论写成集合不等式 `cone ≠ {x | ...}`，论文写成 $K\ne\{(X,Z,y):L(X,Z,y)\succeq0\}$，同义。`Main.lean:17–21 cone_not_spectrahedral` 的证明体只有三行：`obtain ⟨P⟩ := pencil_normalization N hN L hL` + `exact P.impossible`——**整个反证骨架被压成"两个接口"**：`Pencil.lean:14 pencil_normalization : Nonempty NormalizedPencil`（输入 $N,L,hL$）与 `TangentObstruction.lean:8 NormalizedPencil.impossible`。
5. **`NormalizedPencil` 不携带"pencil 表示 $K$"这一字段**（`Model.lean:123–137`，全文抄录见下），只留结果 `schur_equivalence`：

```lean
structure NormalizedPencil where
  a : ℕ
  c : ℕ
  a_pos : 0 < a
  c_pos : 0 < c
  D : Sym 4 →ₗ[ℝ] Sym a
  E : Sym 4 →ₗ[ℝ] Sym c
  B : (Fin 3 → ℝ) →ₗ[ℝ] Matrix (Fin a) (Fin c) ℝ
  D_positive : ∀ X : Sym 4, (X : Mat 4 ℝ).PosSemidef → (D X : Mat a ℝ).PosSemidef
  E_positive : ∀ X : Sym 4, (X : Mat 4 ℝ).PosSemidef → (E X : Mat c ℝ).PosSemidef
  D_unital : D 1 = 1
  E_unital : E 1 = 1
  schur_equivalence : ∀ (X Z : Sym 4) (y : Fin 3 → ℝ) (_hX : (X : Mat 4 ℝ).PosDef),
    ((Z : Mat 4 ℝ) - phi y (X : Mat 4 ℝ)⁻¹).PosSemidef ↔
      ((E Z : Mat c ℝ) - (B y)ᵀ * (D X : Mat a ℝ)⁻¹ * B y).PosSemidef
```

与论文 Prop 4.1 的对应是**逐字忠实**的（含 $a,c\ge1$、$D,E$ 正且 unital、$B$ 线性、$\forall X\succ0$ 的双向等价），但两点须记录：(i) 前置 $X\succ0$ 在 Lean 里是 `schur_equivalence` 的**第四个隐式参数** `_hX`，故它在陈述里不是"条件在集合上"而是"在每个使用点携带"；(ii) 论文把 `eq:schur-equivalence` 左端写作 $Z\succeq\Phi_y(X^{-1})$，Lean 写作差矩阵 `(Z : Mat 4 ℝ) - phi y X⁻¹` 的 `PosSemidef`（`Phi_y(X^{-1})` 与 $Z$ 的大小关系 ⟺ 差 PSD；Lean 没有"$\succeq$"的记法）。
6. **$P(v),R(u)$ 的定义方式**：Lean 用 `kernelProjection`（`Model.lean:105–106`，经 `Submodule.starProjection`）直接实现 `eq:projections`：`NormalizedPencil.leftProjection/rightProjection`（`Model.lean:139–143`）= `kernelProjection (P.D (1 - outerSym v))`。其中 `1 - outerSym v` 就是 $I-vv^\top$，`outerSym`（`Model.lean:94–100`）是 `outer v v` 的对称化。
7. **`eq:norm-identity` 与 `eq:tangent-identity` 的陈述形态**：`NormIdentity.lean:16 NormalizedPencil.norm_identity` 是"对所有单位 $u,v$ 和 $y$"的全称式；`TangentIdentity.lean:15 NormalizedPencil.tangent_identity` 则改成 **$\exists v\ \exists T$**：产出 $T$ 为线性映射 `Vec 4 →ₗ[ℝ] Mat c ℝ`，附带 $\norm v=1\wedge v\,0\ne0\wedge\forall h\perp v,\forall y:\ b(\texttt{wedgeCoordinates}\ v\ h,\ y)=\operatorname{norm}(P.\texttt{leftProjection}\ v * B\ y * T\ h)^2$。论文写的是"取最大秩点 $v$ 并用 $dR_v$"，Lean 把"最大秩 + $dR_v$"整体打包成存在量词——**这使 `eq:tangent-identity` 在 Lean 里成为一个抽象接口**，$R$ 的光滑性不再出现在陈述中。
8. **$b$ 与循环指标方向**：论文 $Q(y)_{ii}=y_i^2+y_{i+1}^2$、$b(z,y)$ 第三项 $\sum z_i^2y_{i+1}^2$；Lean `Model.lean:28–29 qMatrix` 用 `y i ^ 2 + y (i + 1) ^ 2`（$i:\texttt{Fin }3$，`Fin 3` 的加法自带 mod 3）✓ 同向；而 2.1 里 $b$ 看作 $y$-二次型的矩阵 $M(z)$（对角 $z_i^2+z_{i-1}^2$）在 Lean 里是**另一个**矩阵 `zMatrix`（`Model.lean:75–76`，写作 `z i ^ 2 + z (i + 2) ^ 2`，即 $i+2\equiv i-1\pmod 3$）。**"论文用一个 $Q$ 双向解读、Lean 用两个矩阵"是本篇最容易看错的对应关系。**
9. **`phi` 的定义不用分块语法**：`Model.lean:31–38` 用双重 `Fin.cases` 逐元素写四块，等价于 `eq:phi` 的 $\begin{pmatrix}\tr(QT)&-r^\top Q\\-Qr&aQ\end{pmatrix}$；`MatrixBasic.lean:61 phi_rank_one` 是 `eq:rank-one` 的机器化，`:68 matrixValue_inverse` 是 `eq:inverse-formula`（写作 `(det X)^4 * det (Z - phi y X⁻¹)`）。

## 5.3 三行总结（素材收束用）

- **常数的来源只有一个**：$4\times4$ 的分块 $1|3$ 结构。它同时给出 $y\in\R^3$、$\dim\Sym^4=10$、$23=10+10+3$、$(\det X)^4$、$20=4+4\times4$、$16=20-4$、$J$ 的双方维数 3、$K_i$ 的三个、$\det(I_3\otimes X)=(\det X)^3$。**换句话说本篇的"23 变量 16 次"不是选择，而是 $n=4$ 的推论。**
- **两个"1"是硬指标**：Choi–Lam 的系数 1（否则 $b(\sigma,\sigma)\ne0$）与 $b(e_1,e_1)=1$（否则矛盾无从落地）。
- **两处刻意违反**：违反 Kummer–Netzer 的严格双曲前提（16/12 重重根），违反 Netzer–Sanyal 的光滑边界前提（同一根点）——本篇之所以能既不与已知肯定定理冲突、又落在它们的覆盖之外，全靠 Choi–Lam 零点带来的重根；这三者（系数 1 ⟹ 零点 ⟹ 重根 ⟹ 避开肯定定理）构成一条因果链，是理解本例设计的第一把钥匙。

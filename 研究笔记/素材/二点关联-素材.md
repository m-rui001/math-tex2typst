## 一、定理总览

### 1.1 定理 1.1（quantitative/08-affine.tex，thm:q-affine：仿射 Liouville 关联的 log 幂节省）

存在绝对常数 c>0，使对任意固定整数 a₁,a₂≥1、b₁,b₂≥0 且 a₁b₂−a₂b₁≠0，有常数 C_{a₁,a₂,b₁,b₂} 使

  |Σ_{1≤n≤X} λ(a₁n+b₁)λ(a₂n+b₂)| ≤ C_{a₁,a₂,b₁,b₂} · X/(log X)^c  （X≥3，X 可取任意实数）。

要点：不对系数加任何互素条件；指数与仿射系数无关；隐含常数可非实效；不主张系数随 X 增长的均匀性。取 a₁=a₂=1,b₁=0,b₂=h 即得**普通平均二元 Chowla 猜想**（带 log 节省）。证明分两步：先证每个固定剩余类 mod l 的 λ(n)λ(n+h) 估计（Part I 的 Proposition q:progression），再用完全乘性做仿射代换：l=a₁a₂，c₀=min(a₂b₁,a₁b₂)，h=|a₁b₂−a₂b₁|，恒等式

  λ(a₁n+b₁)λ(a₂n+b₂) = λ(l)·λ(ln+c₀)·λ(ln+c₀+h)，

端点精确化为 Σ_n λ(a₁n+b₁)λ(a₂n+b₂) = λ(l)(P(lX+c₀)−P(c₀))，P(Y)=Σ_{m≤Y} λ(m)λ(m+h)·1_{m≡c₀ (mod l)}；截断误差 |P(c₀)|≤c₀ 被 (log X)^c/X 在 [3,∞) 有界吸收。**没有任何被丢弃的尺度**——这是与 TT26 的本质差别。

### 1.2 定理 1.2（introduction.tex thm:elliott：普通平均的二元修正 Elliott 定理）

f₁,f₂: ℕ→𝔻 乘性（|f|≤1，不必完全乘性、可取复值），若至少一个满足**一致非冒充**条件

  inf_{|t|≤N} D(f,χn^{it};N) → ∞（N→∞，对每个固定 Dirichlet 特征 χ），

其中 D(f,χn^{it};X)²=Σ_{p≤X}(1−Re(f(p)·χ(p)p^{it}̄))/p（素数截断与高度上界是同一个 N），则对每对固定不同非负位移 h₁,h₂，

  (1/N)Σ_{n=1}^N f₁(n+h₁)f₂(n+h₂) → 0（沿整数 N）。

共轭版本由条件在共轭下不变推出；无定量速率。附带的推论（cor:affine）：同一假设下固定非成比例仿射形式的普通平均也趋于 0（Part III 通过有限局部展开推出）。

### 1.4 核心机制（完整展开）

**公共骨架：乘性膨胀把普通平均接到带权因子图。** 对固定 h，比较 (n,n+h) 与 (dn,d(n+h)) 的关联：完全乘性把 d 的值提到系数（模 1），从而普通平均可以被"d 整除 n"的示性函数展开式表出；把每条边（位移 hd）配上中心化因子 ∏(1_{p|n}−c/p)，其组合矩阵的谱半径由闭走（closed walk）迹控制；闭走中第一次出现构成树/森林，被删除的稀疏顶点集（禁路径 witness）强制大量重复素数标签，重复标签以倒数和计价；短区间 Fourier 估计（MRT）控制"示性→符号"替换的解析损失。

**Part I（定量，Liouville）：J 股分离素数供应 + padding + Braverman。** 每步取 J 个互不相交供应 P₁,…,P_J（P_i = 素数 ≡1 mod 5、log p ∈ [L^{1−δ}e^{6W(i−1)}, L^{1−δ}e^{6Wi})）各一个素数，调和质量 V_i∈[W,2W]；因子 1_{p|n}−1/p 在独立剩余模型下均值为零。另设不相交的 padding 素数集 Q（≡1 mod 5 之外），权 u(q)=4^{ω(q)}，w(n)=5^{ω_Q(n)}；log(dq) 被切成 O(L/η) 个宽 η=e^{−J} 的窄区间（bin），每 bin 的边归一化给 1/L 因子，恰好抵消 bin 数量的因子 L。中心化供应的倒数质量 ≥W^J，而算子界只贡献 (C√W)^J（√W 来自重复标签：2kJ 个列出现中不同标签数 ≤Jk+S₁/2）；其余损失都是绝对底的 J 指数（2^JK⁻¹、e^{−2WJ}、K/η·(C₃/√W)^J 等），故取 W 充分大后每项 ≤e^{−J}；而 J=⌊δ log L/(6W)⌋ 随 log log X 线性增长，e^{−J}=(log X)^{−δ/(6WA)}，即幂节省，指数 c=δ/(6WA)。两个结构性难点：(i) 素数集随 X 增长，全联合周期的平均无用——用 Braverman 有界独立性把有限区间上的剩余测试与独立剩余模型比较（先做 AGM 型 almost-to-exact 修正）；(ii) 重复素数约束闭走——多独立算术关系直接给节省，少时用森林编码统一计数（与 padding 无关），padding 权在共同剩余环境里事后求和。

**Part II（qualitative，一般乘性函数）：两带 core/center + 极限次序反转。** 短区间输入含非冒充距离，其发散无速率，故不能让 B 随主变量动：**先固定辅助尺度 B**，在 e^B 以内取两条素数带——core 带 𝒞（log p∈(B^{1−η},B]，权 A=e^{2κ}>1，因子不中心化：1_{d_C|x}）与 center 带 𝒵（log p∈(B^{1−ε},B^{1−η}]，权 1，因子 1_{p|x}−θ/p，θ=β_𝒵²=1/4）。顶点权 W(x)=β_C^{−ω_C}β_𝒵^{−ω_𝒵}，归一化 L₀=Π(1+A_a/p)。持续偏差序列 |S(N_j)|≥γN_j 经对数权化在一个倍率 (1,τ) 的乘性窄区间里捕到原始可除性和，下界 c_γ L₀/B；图估计给 L₀B^{−1−c_*/2}（c_*=ε/100），中心化误差 O(L₀(B^{−1−ε}+J/P₀))；固定 B 取 X→∞ 极限后得矛盾 c_γ ≤ C(B^{−c_*/2}+B^{−ε}+B J e^{−B^{1−ε}})，再令 B→∞。θ=β_𝒵² 的机械作用：在闭走积中每条边权被起点顶点权 W 除一次，好边（good edge）上单独出现的 center 素数在 lit 剩余处乘子恰为 (1−θ/p)β_𝒵²=θ(1−θ/p)，其余剩余为 −θβ_𝒵^{ν_p(a)}/p；带符号平均后 1/p 阶项精确相消，只剩非负的 O(θ/p²) 项——这一步必须**保留 return 因子直到符号平均之后**（论文明言：先点态扔掉 return 因子再取绝对值会毁掉这里的计算）。

**Braverman 有界独立性（Part I 专属）。** 独立剩余模型与整数平均的差距不能靠大周期平均：改用"具体测试"比较——把剩余等式编码为电路，CRT 给任意 t 个比特的边际与均匀分布距离 ≤exp(2tL−L^A/2)；对密度做 Fourier 修正 g=(f−H+a)/(1+a) 得到精确 t-wise 均匀的非负律（AGM 构造的显式 Fourier 版），再用 Braverman 定理（深度 22、规模 e^{L^{17}}、误差 e^{−L^{11}}）fool。条件 A>C₁+20 使 CRT 质量在 Braverman 要求的独立度之下。

两套论证的关系：同一图骨架、不同顶点权、不同极限次序（Part I 逐 X 取大再选 W；Part II 固定 B 取长极限再增 B）；Part I 的损失预算全部显式且绝对（保 W 的选取在所有图常数之后），Part II 只需定性 o(1)。

## 二、逐引理带批注重构（Part I：quantitative/01–08）

记号固定：h,l 固定，F(X)=(1/X)Σ_{n≤X}1_{n≡b(l)}λ(n)λ(n+h)（Prop q:progression），c 为最终指数。

### 2.1 §q:setup 素数供应与参数

**(a) 参数（eq q:parameters）**：L=(log X)^{1/A}，δ=1/200，J=⌊δ log L/(6W)⌋，Y_i=L^{1−δ}e^{6Wi}（0≤i≤J），H₀=e^{L^{1−δ}}，η=e^{−J}，K=e^{4J}；P_i={p≡1 (5), Y_{i−1}≤log p<Y_i, p∤lh}，Q={p≢1 (5), p≤e^L, p∤lh}；V_i=Σ_{p∈P_i}1/p，V_*=ΠV_i，𝒟=各股取一素的乘积；u(q)=4^{ω(q)}，S=Π_{p∈Q}(1+4/p)，w(n)=5^{ω_Q(n)}；bin 𝒮_j：ω(q)≤100 log L 且 jη≤log(dq)<(j+1)η，T_j=Xe^{jη}，共 O(L/η) 个，S₀=bin 内 u(q)/(dq) 总质量。

**(b) 机制**：固定模 5 的 PNT（Koukoulopoulos Thm 12.1）+部分求和给 V_i=¼log(Y_i/Y_{i−1})+o(1)=3W/2+o(1)，一致于 i（区间起点都 ≥L^{1−δ}，误差一致趋零），故 W≤V_i≤2W 且 log d ≤ ΣY_i ≤ L/(1−e^{−6W})<2L。bin 质量引理 q:bin-mass：在律 u(q)/(qS) 下 Q 中素数以 4/(p+4) 独立入选，E log q≤4L、E ω(q)≤4 log L，Markov 排除 log q>98L（概率 4/98）与 ω(q)>100 log L（4/100），故保留概率 >1/2，得 ½SV_*≤S₀≤SV_*。中心化平均 C_j（eq q:centered-average）中满整除项代换 n=qdm 化为 u(q)/(qd)·F(T_j/(qd))，且 Xe^{−η}<T_j/(qd)≤X、λ(qd)²=1，故满整除贡献=S₀F(X)+O(SV_*(η+X⁻¹))。

**(c) 常数理由**：6WJ≤δ log L 保证 Y_J≤L（padding 与 tuple 的对数都 ≤O(L)）；δ=1/200 是为了让最终所有 2^J 型损失（2^J K⁻¹、2^J e^{−2WJ}、2^J L^{−100}）都压到 e^{−J} 以下（需 δ(2+log2)/(6W)<1/20、δ(1+log2)/(6W)<100，W≥10 时成立）；100 log L 的 ω(q) 截断与 100L 的 log(dq) 上限给后续电路规模多项式界。独立剩余空间：每个 p∈P∪Q 一个独立均匀剩余 + 一个 mod l 坐标（单一坐标，l 不必无平方因子）。

**(d) [推测] 失败路线**：① 若五剩余类质量 α_𝓡=1/4 的 PNT 误差在 L^{1−δ} 处不一致（L 附近 Siegel 零点），V_i 下界 W 可能失效——但模固定为 5，误差 exp(−c₁√log x) 一致，路线被封死；② bin 宽 η=e^{−J} 若小于 X⁻¹ 数量级，满整除项误差 η 失控——J≤δ log L/(6W) 保证 η 只是对数尺度；③ 若把 P、Q 合并成一股，则中心化因子的均值非零性与 bin 质量的 Markov 参数同时坏掉——分离供应是设计核心。

### 2.2 §q:finite-law 有限剩余律比较（Braverman）

**(a) 引理 q:finite-law**：存在绝对 C₁，取 A>C₁+20；对任意 ≤e^L 的素数集 𝓡（不除 l）与深度 ≤20、规模 ≤exp(L⁶) 的剩余等式电路事件 𝓔，任意长 |I|≥exp(L^A/2) 的连续整数区间满足 |𝔼_I 1_𝓔 − μ(𝓔)| ≤ e^{−L^{10}}（L 充分大，阈值可依赖 l；对区间位置与所有平移均匀）。

**(b) 机制**：每模 s 附加独立抖动 U_s，取 Z_s=(R_s+U_s)/s 的前 B=⌈L¹⁵⌉ 个二进制位；μ 下各比特独立均匀；解码错误概率 ≤2^{1−B}(l+Σp)≤e^{3L}2^{−B}（只两端小区间出错），一次解码同时修正该模的所有平移等式。解码后的等式是 B 比特布尔函数，DNF 展开 ≤2^B 个合取，电路深度 ≤22、规模 ≤exp(L^{17})。任意 t 个比特涉及至多 t 个两两互素模，乘积 D≤le^{tL}，整条区间中每剩余类出现 ⌊N/D⌋ 或 ⌈N/D⌉ 次，全变差距离 ≤D/N，抖动投影不增，故边际偏差 Δ≤exp(2tL−L^A/2)；总比特数 ≤e^{2L}，取 t=⌈L^{C₁}⌉ 得非平凡 Fourier 质量q=Σ_{1≤|S|≤t}|f̂(S)|≤2Δ(t+1)n_bit^t ≤e^{−L^{11}}。AGM 修正：H=Σ_{1≤|S|≤t}f̂(S)χ_S，g=(f−H+a)/(1+a)（a=e^{−L^{11}}）非负、积分为 1、≤t 阶非常数 Fourier 系数全为零（精确 t-wise 均匀），d_TV(f,g)≤3a/2。Braverman（深度 22，规模 e^{L^{17}}，误差 e^{−L^{11}}）给误差 a；总误差 2e^{3L}2^{−B}+5a/2≤e^{−L^{10}}。推论 q:finite-expansion：系数绝对和 ≤exp(CL⁵) 的标量展开整体误差 ≤e^{−L⁹}；q:truncated-weight：𝔼_I[w(n+a)1_{ω_Q≤400 log L}] ≤ S+e^{−L⁹}≤2S。

**(c) 常数理由**：B=L¹⁵ 使解码错误 2^{−B}e^{3L} 可忽略；深度 20 上留 2 层给 DNF 替换（20→22）；A>C₁+20 是 Braverman 所需独立度 t=L^{C₁} 与 CRT 质量 exp(2tL) 对区间长 exp(L^A/2) 的差距条件——这解释了 A≥1000 的"先选 A 后选 W"次序；mod l 的重复素因子无影响因为它只是"一个额外互素模"。

**(d) [推测] 失败路线**：① 若事件电路规模需要 exp(L^c)（c>6），Braverman 要求的独立度 t 超过 L^{C₁}，CRT 边际偏差爆炸——所以所有删除事件的电路规模必须在 exp(L³)–exp(L⁴) 内（后文 q:bad 精心核算）；② 抖动编码把等式变成"非精确"比特律，若不做 AGM 修正直接 fool，小误差被系数和 exp(CL⁵) 放大——修正步骤不可省；③ 素数集 𝓡 随 X 增长使总周期 Q_B 巨大，任何"整周期均匀"论证都失败——引理的存在就是为了绕开它。

### 2.3 §q:analytic 中心化与删除

**(a) 引理 q:rough-fourier**：½exp(L^{0.995})≤D≤exp(2L)，𝒵⊂[D,2D) 为无 ≤exp(L^{0.99}) 素因子的整数集，B(θ)=Σ_{z∈𝒵}e(hzθ)/z，则 ‖B‖_∞≪L^{−0.99}，∫₀¹|B|⁴dθ≪D⁻¹L^{−3.96}。机制：m=1（单粗数）与 m=4（四线性型 x₁,x₂,x₃,x₁+x₂−x₃）的筛；ν_m(p)=m/p+O(p⁻²)（四型在所有素域上两两独立，含 𝔽₂——所以 2 不出问题）；偶数阶 r₀=2⌈500 log L⌉ 截断容斥，CRT 计数误差 O(r/D)，边界误差 (1/D)exp(O(L^{0.99}log L))；截断差 ≤(eΣν/r₀)^{r₀+1}≪L^{−100}；全积 Π(1−ν_m(p))≪(log y)^{−m}=L^{−0.99m}。第四矩=正交性下 z₁+z₂=z₃+z₄ 的加权和，三定一，权重 ≤D⁻⁴。

**(b) 引理 q:rough-shifts**：Y≥exp(L^A/2) 时 |Y⁻¹Σ_{v≤Y}Σ_{z∈𝒵}z⁻¹1_{v≡b₀(l)}λ(v)λ(v+hz)|≪L^{−21/20}。机制：F_v(θ)=Σ_{m≤D}λ(v+m)1_{v+m≡b₀(l)}e(θm)、G_v(θ)=Σ_{a≤(2h+1)D}λ(v+a)e(−θa)；MRT Thm 1.3（H=D，Z=⌊Y⌋+1；剩余类用 e(a(n−b₀)/l) 展开，系数绝对和 1，频率平移 θ+a/l）给 Σ_v|F_v(θ)|≪YDL^{−0.8} 一致于 θ；平移平均后正交性化为 ∫B(θ)F_vG_v dθ；|B|≤L^{−1.05} 处 Parseval+Cauchy–Schwarz 给 O_h(L^{−1.05})；补集测度 ≤L^{4.2}∫|B|⁴≪D⁻¹L^{0.24}，其上用 ‖B‖_∞≪L^{−0.99}、|G_v|≤(2h+1)D、Σ|F_v| 界，贡献 L^{0.24−0.99−0.8}=L^{−1.55}。

**(c) 引理 q:center（中心化估计）**：|Σ_j C_j − S₀F(X)| ≪_{h,l} SV_*(η+X⁻¹+η⁻¹2^J L^{−1/20})。机制：展开中每个非满项由非空 I⊂{1..J}（被换成 −1/p 的股）标记，z=Π_{i∈I}p_i，代换 n=qd′v（qd′ 可逆 mod l，任意剩余类有效）后化为 q:rough-shifts 的形状（z 的素因子 ≥H₀/2=e^{L^{0.995}/2}，log Y≥L^A/2）；每 bin 每组合 I 权和 ≤SV_*，bin 数 O(L/η)、I 数 <2^J，总损失 2^Jη⁻¹L^{−1/20}。**常数理由**：L^{−21/20} 比 1/L 多出的 1/20 是为抵消 bin 数因子 L/η 后仍有富余；η<log 2 使 dyadic 分裂至多两段；z 的唯一因子分解+股分离保证每整数 z 至多出现一次（否则粗数第四矩里出现重数，L^{−3.96} 失效）。**[推测] 失败路线**：① 若股间带距不是几何的（e^{6W}），z 可能落在 [D,2D) 之外或 D<exp(L^{0.995})，粗数筛前提破坏；② 若剩余类代换时 qd′ 与 l 不互素（b 有公因子情形），代换非法——引理强调"任意剩余类"正是靠 qd′ 可逆。

**(d) 引理 q:padding（padding 反集中）**：ρ_j(n,d)=w(n)⁻¹Σ_{q|n, jη≤log(qd)<(j+1)η}u(q)（bin 内全部 padding，无 ω 截断），𝔼*=𝔼(w·)/S（tilt 把 p|n 概率从 1/p 变 5/(p+4)，保持独立），则 𝔼*Σ_jρ_j(n,d)²≪L^{−1}，常数与 d、W、bin 位置无关。机制：条件独立取 q₁,q₂，Z=log(q₁/q₂) 的特征函数 φ(t)=Π_{r∈Q}(1−(8/(5(r+4)))(1−cos(t log r)))，每因子非负（r=2 处 ≥7/15），1−x≤e^{−x}；PNT 部分求和给 Σ_{r∈Q}(1−cos(t log r))/r = ¾log(1+L|t|)+O(1)（|t|≤2，导数 O(1/(x²log x)) 可积、除掉 lh 的素因子花 O(1)），故 φ(t)≪(1+L|t|)^{−6/5}；同 bin 给 |Z|≤η≤1，用 κ(x)=(sin x/x)²（=¼∫_{−2}²(2−|t|)e^{itx}dt）作容许权，𝔼*ρ² ≤ ℙ*(|Z|≤1)≪∫_{−2}²(1+L|t|)^{−6/5}dt≪L^{−1}。**常数理由**：指数 −6/5>−1 的富余来自 (1−cos)/r 的 ¾ 系数（三个非 1 mod 5 剩余类的总质量 ¾）+ 积分收敛需要严格超过临界；log d 作为共同平移从 Z 中消失，给出对 d 的一致性。**[推测] 失败路线**：① 若 Q 不含 ≢1(5) 全部素数（例如再剔除一些），和式 ¾log(1+L|t|) 的系数降到临界以下，∫ 发散，L^{−1} 变弱；② tilt 若改变坐标独立性（比如对 d 的素数也 tilt），特征函数不再因子化。

**(e) 引理 q:cuts（删除代价）**：对满足平移协变、ℙ(n∈𝓑_j)≤exp(−½L^{1−δ})、电路深度 ≤6 规模 ≤exp(L³) 的稀有事件族，(1/(SV_*))Σ_j|C_j−C_j°| ≪ 2^J(K⁻¹+L^{−100}+e^{−2WJ})+exp(−L^{0.9})。四个截断：ω_Q≤400 log L、ρ_j≤K/L（τ_j）、σ_j=1−1_{𝓑_j}、ω_P≤6WJ（χ_j；只施加在矩阵投影 E，不在 τ_j——图论证要先积分中心化 P 坐标）。机制：辅助乘积模型里用非负 a_d⁺=Π(1_{p|n}+1/p)（均值 2^J/d）做上界；ω_Q 尾：指数 Markov exp((−400+4(e−1))log L)≪L^{−100}；ρ_j 尾：x1_{x>K/L}≤(L/K)x²+q:padding 给 O(K⁻¹)；P 度尾：对固定 d tilt 后 Σ_{p∈P}1/p≤2WJ，exp(−6WJ+J+2(e−1)WJ)≤e^{−2WJ}（W≥10）；稀有点：行权 B(n)=w(n)Π_i(ω_{P_i}(n)+V_i)，𝔼B²≤C L^{C'}(18W²)^J（18W² 项来自 4V_i²+V_i，V_i≤2W；J log(18W²)≤δlogL·log(18W²)/(6W)=O(log L)），Cauchy–Schwarz×稀有概率给 L^{C'/2}exp(−¼L^{1−δ})，O(L/η) 个 bin 合计 exp(−L^{0.9})。迁移：四类失败+两端点 union bound；每个失败事件的电路：度失败=OR over 子集（规模 exp(O(L log L))，用 6WJ≤δ log L）；padding 失败需先列 ≤400 log L 精确活跃 Q 集（每集一个合取，w 与 ρ_j 在其上为常数），合取后深度 ≤10 规模 ≤exp(L⁴)；总系数绝对和 ≤exp(O(L⁴))，区间长 ⌊T_j⌋≥exp(½L^A)，q:finite-expansion 给 exp(−L⁹)。**常数理由**：K=e^{4J} 与 K⁻¹ 项配对——2^J K⁻¹=e^{−(4−log2)J}≤e^{−J}；ρ_j≤K/L 保证矩阵行和 ≤K（§q:padding-sum 与 q:weighted-rows 都用它）；𝓑_j 概率 exp(−½L^{1−δ}) 与 B(n) 二次矩的 L^{C'/2} 相乘后仍是 exp(−L^{0.9}) 级。**[推测] 失败路线**：① 若稀有事件概率只用多项式小（比如 L^{−C}），Cauchy–Schwarz 后 L^{C'/2} 因子吃不掉它——所以禁路径 witness 的密度必须是对数的（下一步 q:bad 给 exp(−½L^{1−δ})）；② ρ_j 截断若改为对 w 整体截断，会破坏 nonnegative majorant 的因子化；③ 若无 400 log L 的低 Q 截断而直接用 w，整数侧需要 w 的未截断矩——论文特别强调"整数平均只用截断权"。

### 2.4 §q:paths-trace 禁路径与矩阵

**(a) 定义 q:prohibited（前向禁词）**：长 3≤m≤s=⌊L^{1/10}⌋ 的符号步 D_i=ε_i hq_i d_i 满足 (1) 相邻整 tuple 不等；(2) 每个 P 素的出现指标构成区间；(3) 存在 p|d₁、p∤d_m 使 p|Σ_{i=a}^m D_i（某 1<a<m）。极小化（连续子词、两方向均可）；witness=实现极小禁词的正路径；𝓑_j=witness 起点集，σ_j=1_{n∉𝓑_j}。任何正禁词含从某顶点出发的 witness（反复取更短禁子词，反向时保持正性，长度严格降）。

**(b) 引理 q:crude-count**：≤R≤4L 个带符号步+每素槽 L^{O(1)} 记录，等式模式数与带一个倒数/不同素数的数值和均 ≤exp(O(R log²L))（槽数 O(R log L)：每 tuple J=O(log L) 因子、padding ≤100 log L 因子；N 槽划分 ≤N^N）；消去引理：az+c≡0 (p)、a≢0 (p) 时该素倒数和代价 ≤(1+L)/H₀（扩大到整数沿等差级数与积分比较），选序使每个关系只用自身、更早选中与非选中变量时节省可乘（反向归纳）。

**(c) 引理 q:bad**：𝓑_j 平移协变、ℙ(n∈𝓑_j)≤exp(−½L^{1−δ})、电路深度 2 规模 ≤exp(L³)。机制：不需极小性，数全部前向禁正词；最后转移取一个换列的列，其末素 z 由区间条件不在更早出现，禁关系 (3) 中 z 的贡献恰为最后一步，系数 ε_m hq_m d_m/z——控制素 p 不整除 d_m、h、任何 padding，故系数是模 p 单位且与 z 无关；固定模式与 padding 后 q:crude-count 给一次 (1+L)/H₀；总 (1+L)/H₀·exp(O(s log²L))≤exp(−½L^{1−δ})（log H₀=L^{1−δ}=L^{0.995} 主导 s log²L=L^{0.1}log²L）。**常数理由**：s=L^{1/10} 与 H₀=e^{L^{0.995}} 的差距是整个"禁路径删除可行"的预算：模式数熵 exp(O(s log²L)) 必须 o(log H₀)。**[推测] 失败路线**：① 若禁词长上界 s 取到 L^{1/4}，熵与 log H₀ 相比不再可忽略；② 若 p 允许整除 d_m（条件 (3) 减弱），系数 hq_md_m/z 可能 ≡0 mod p，单位性失效，倒数节省消失；③ 电路规模：正性是 O(s log L) 个剩余等式的合取，析取后深度 2——若需按素数值分情况（而非等式），深度会失控。

**(d) 矩阵与 q:trace**：块 M=⌈e^{103L}⌉，A_d(n,n′)=Lu(q)τ_j(n,d)τ_j(n′,d)/√(w(n)w(n′))·1_{q|n}1_{n≡bqd(l)}Π_{p|d}(1_{p|n}−1/p)（n′=n+hqd），对称；H_{d,d′}=1_{d≠d′}A_{d′}（不必自伴）。**定理 q:trace**：𝔼‖H^k‖_HS² ≤ [K(C₂√W)^J]^{2k}（k=⌊L⌋），块原点在长 ≥exp(½L^A) 区间上平均后仍成立。机制：H^k 展开为 d₀..d_k（相邻不等）的路径，平方求和接成 2k 步闭词（两半各自相邻 tuple 不等，接缝无要求）；外部维数 |𝒟|²M≤exp(107L+O(1))；有限原点比较在**符号展开、取绝对值之前**做：每站点枚举精确 Q 活跃集（≤m_Q=⌊400 log L⌋，exp(O(L log L)) 状态），权重分母与 Q 截断变成标量；2kJ 个中心化因子展开 ≤2^{2kJ} 项；总系数和 exp(O(L²log L))≤exp(O(L⁵))，比较误差 exp(−L⁹)。词积形式 R·G·Π(1_{p|x+ξ_i}−1/p)，R≥0 不依赖 P 剩余抽样（这就是 P 度投影延迟施加的原因）。

**(e) 引理 q:mixed-difference（绝对值前的精确中心化）**：指定项的绝对期望 ≤1_{lit 一致}·b_𝓛·𝔼[R|ΔG|]，其中 b_𝓛=Π_{p singleton}1/p·Π_{p nonsingleton}p^{−u_p−1_{ℓ_p>0}}，ΔG=Σ_{H⊂𝒰}(−1)^{S₁−|H|}G_H（混合差分：从一次公共剩余抽取出发，把 nonsingleton lit 覆写为强制剩余，再对每个 H⊂𝒰 覆写 H 中 singleton，G_H 为该 hybrid 下 G 的值），|ΔG|≤2^{S₁}。机制：恒等式 𝔼[(1_{Z=a}−1/p)F(Z)]=p⁻¹𝔼[F(a)−F(Z)] 逐 singleton 坐标应用；nonsingleton 处 lit 不兼容则零，否则强制剩余给 1/p，unlit 给标量 −1/p。**[推测] 失败路线**：① 若 G（顶点删除示性）依赖 singleton 剩余但混合差分定义为逐坐标逐次（而非全部 H 求和），只剩一阶信息，增量式偏差不受控；② 2^{S₁} 若不被后续对 S₁ 的截断（L^{1/4}）控制，指数爆炸。

**(f) 引理 q:many-unlit**：U>L^{1/50} 的指定项贡献 ≤exp(−L^{1+δ})。机制：每个 unlit 出现至少多供 1/2 个额外倒数幂（lit 存在时每个 unlit 多一个；全 unlit 的 m≥2 个供 p^{−m}≥基本外 m/2 个），共 ≥U/2 个，都在 ≥H₀ 的素数上，H₀^{−U/2}=exp(−½L^{0.995}·L^{1/50})=exp(−½L^{1.015})。**[推测]** 若 H₀ 换成多项式尺度（如 L^C），额外倒数只给 exp(−cU log L)，压不住 exp(O(L log²L)) 的熵。

### 2.5 §q:rank-witness 秩与 witness

**(a) 引理 q:rank-probability**：素数集 𝓟 上测度 μ 满足 max μ≤α；B∈M_r(ℤ) 在 ℝ 上非奇异；(By−y′ 前提) |(B(y−y′))_i|≤M；c,y 独立 μ 分布，则 ℙ(c_i|(By+f(c))_i ∀i) ≤ [α(1+d_M)]^{r/2}，d_M=⌊log M/log 2⌋。机制：Cauchy–Schwarz 双副本 y,y′——控制素数相同，相减消去 f(c)；v=B(y−y′) 的精确零集分解：|Z|=a 行秩 a，取可逆 a 列子式，条件确定至多一组值，ℙ(v|_Z=0)≤α^a；非零坐标 |v_i|≤M 至多 d_M 个素因子，c_i|v_i 条件概率 ≤d_M α，合计 Σ_Z α^{|Z|}(d_Mα)^{r−|Z|}=[α(1+d_M)]^r，开方。**关键**：不假设 B 模任何被求和素数可逆——这正是"实秩而非模秩"的设计。**[推测] 失败路线**：① 若 y,y′ 的坐标不完全独立（数值互异约束保留），双副本 Cauchy–Schwarz 不闭合——所以证明中先"放大"允许坐标重合（乘积律），把互异性并入正上界；② M 若含被求和素数（系数不独立于 c_i），d_M 失效。

**(b) 引理 q:rank（高秩词丢弃）**：每列（股 ν 固定）取形式对 (e_z, v(i)−v(i′))（v(i)=Σ_{a<i}t_a e_{z_a}，t_a=D_a/p_{z_a} 为列无关整数），若某列有 r=⌊L^{1/50}⌋ 个联合独立对，则该类贡献 O(exp(−c₀L^{203/200}))。机制：对固定列/模式/外部数据，控制标签 c_i=p_{z_i} 与子式变量 y 独立；lit 一致性变成 c_i|(B₀y+A₀c+d₀)_i（不模 c_i 可逆）；放大后 μ_ν(p)=1/(V_ν p)，α=(V_νH₀)⁻¹；尺寸假设 |(B₀(y−y′))_i|≤2kh e^{103L+1}=e^{O(L)}（每行系数绝对和 ≤2kh e^{102L+1}，来自 q_a≤e^{100L+1} 与其他列几何带距 e^{2L}），d_M=O(L)；概率 ≤exp(O(r log L))H₀^{−r/2}；描述数 J(2k)^{O(r)}；合计 exp(O(Llog²L)+O(r log L)−(r/2)log H₀)，log H₀=L^{199/200}，负项 (½+o(1))L^{203/200} 主导。**[推测] 失败路线**：① 若 t_a 不是整数（列不"满配"——每步恰一个该列素数），形式位移 v(i) 无定义；② 若联合独立性改为逐对独立性，B₀ 的行秩 r 断言失效；③ 若 |t_a| 的上界含被求和列的素数（padding 与其他列未先固定），M 尺寸假设爆炸。

**(c) 引理 q:witness-cover（公共 witness 构型）**：S₁>L^{1/4} 且 ΔG≠0 时，某个 hybrid 含 T=⌊L^{1/12}⌋ 个正 witness，各长 ≤s，标记素数 y₁,…,y_T∈𝒰 两两"私有"（y_j 只在 witness j 中出现）；主词+witness 总长 ≤4L。机制：G=Π_{w∈𝒲}(1−I_w)（𝒲= departure 处全部可能 witness 测试，重复因子无害，{0,1} 值）；代数展开后对 𝒰 取混合差分：子族 𝒜 的素支撑漏掉某 p∈𝒰 则 Π I_w 与 p 坐标无关、混合差分为零；故 ΔG≠0 ⇒ 某支撑覆盖 𝒰 的子族混合差分非零，其交示性在至少一个 hybrid 为 1——**"混合差分强于逐对变化"**（summary 原文：若总混合差分非零，展开乘积遍及全部潜在 witness 排除布尔，则至少一个同 hybrid 的交覆盖全部 singleton 标签）；取 inclusion-极小覆盖族，每员有私有素（否则可删），witness 至多 sJ 个 P 标签，族大小 ≥S₁/(sJ)>L^{3/20}/J>T；总长 2k+sT≤2L+L^{11/60}≤4L。注意：展开只用于存在性，不按绝对值求和、不计子族枚举费。**[推测] 失败路线**：① 若 witness 测试族 𝒲 无限（s 不截断），展开不有限；② 若 S₁ 的阈值降到 sJ 以下，极小覆盖可能只有 1 个成员、无私有素可提。

**(d) 引理 q:active（极小 witness 中的活跃标签）**：极小禁词中每个 P 标签 y 或者活跃（存在 c、区间 I 使 c|Σ_{a∈I}E_a 且 y-部分 Σ_{a∈I,y|E_a}E_a ≢0 (c)），或者存在活跃 z 与步 i 使 y 的前缀贡献 ≢0 (z)（eq q:active-prefix）。机制：末步新入标签 z 活跃（控制素 c 不在末 tuple、不除 h/padding，z 对禁后缀贡献恰为 E_m，系数单位）；y 出现在 m 之前时其区间 [a,b]（b<m）：若 E_a+…+E_b≢0 (z) 则取 i=m；否则 z|E_a+…+E_b，反转 E_a..E_m（b<m 使后缀起点错开、b>a 使终点错开），极小性强制 a=1；再取步 2 新入标签 z′（前两 tuple 不等），若 E₂+…+E_{b′}≡0 (z) 则 b′>2 且反转 E_m..E_2 是更短禁词，矛盾——故 z′ 活跃，且 E₁≢0 (z′) 给 y 的前缀贡献。**[推测] 失败路线**：① 若允许相邻 tuple 相等（非回溯条件去掉），"新入标签"不存在；② 区间条件 (2) 去掉则 y 的出现不连续，反转论证的前缀结构散架。

**(e) 引理 q:singletons（singleton 类消去）**：S₁>L^{1/4} 的主词（含外部因子 |𝒟|²M）贡献 ≤exp(−L^{21/20})。机制：q:witness-cover 给 T 个 witness（按附着指标 a₁≤…≤a_T 排序，t(y)=主词唯一步骤），分三种情形各取 ≥T/8 个选变量：(i) 活跃标签不在任何更早（或更晚）witness 中出现——内部关系逐一独立，反序消去；(ii) 否则 ≥3T/4 候选中每员私有 y_j 不活跃，q:active 给活跃 z_j 与非零前缀，按 t(y_j)≥a_j 与 <a_j 分组（各 ≥T/8），比较关系 z_j|(ξ_{a_j}+β_j)−(ξ_{a_h}+β_h)（主段避开 y_j 因 t(y_j)≥a_j，w_h 避开因私有），后来选中变量 y_i（i>j）因 t(y_i)≥a_i≥a_j 不在任何比较段与 witness 前缀中——三角性成立；(iii) 求和：每关系对选中素 x 线性、系数模控制素 p 是单位（p 未选中或属更早关系），倒数和 ≤(1+L)/H₀，反序消去，得 exp(O(L log²L))·((1+L)/H₀)^{⌊T/8⌋}；T log H₀≍L^{1/12+199/200}=L^{647/600} 主导 L log²L 与 L^{21/20}。**常数理由**：S₁ 阈值 L^{1/4} 与 T=L^{1/12} 的匹配：需要 S₁/(sJ)>T 即 L^{1/4}>L^{1/10}·O(log L)·L^{1/12}；以及 (T/8)·log H₀≫(21/20)log L。**[推测] 失败路线**：① 消去次序若按主词位置而非附着指标排序，比较段可能含未消去的晚选变量；② 若 hybrid 覆写改变 witness 的正性测试——不会：正性测试用原剩余坐标，hybrid 覆写不影响已被检验为公共的构型（论文强调"这些保留的剩余测试在整个 hybrid 族中不变"）；③ 相等附着指标——主段在严格意义上仍结束于该指标之前，无碍。

### 2.6 §q:forest 森林编码与 padding 求和

**(a) 引理 q:block-intervals（完美块几何）**：完美位置=该位置每列出现都是 lit nonsingleton；I≤S₁+U；块切分后 B≪1+k/s+S₁+U；每个块内：每列素的出现是连续区间，且无非空子区间总位移为零。机制（反证）：跨列取最短间隔的两个出现组，中间子串每标签区间形，正性给 p|Σ_{a=i}^{i′−1}D_a，长 2 不可能（单个位移的 tuple 与 padding 都不含 p 而 p∤h），长 ≥3 即前向禁词，取极小子词与 σ_j=1 矛盾；零位移子区间：首末 tuple 不同（否则区间性使整段 tuple 相等），取首步素 p 不在末 tuple，删除首步得 p 整除后缀和，长 ≥3 即禁词。**[推测] 失败路线**：闭词末端的顶点也是主词起点，反向子词可从块末出发——若删除集只覆盖内部顶点会漏；论文指出初始顶点同样受 σ_j 约束。

**(b) 引理 q:forest-code（与系数无关的森林码）**：S₁≤L^{1/4}、U≤L^{1/50}、每列无 r=⌊L^{1/50}⌋ 个联合独立对时，单列等式模式总数（对所有数值系数、padding、符号、surviving hybrid 取并）≤exp(Ck)，k=⌊L⌋；J 列合计 ≤exp(CJk)。机制：取极大独立对集，商空间 dim 2m<2r；regular 标签的 lit 起点落在与 ē_z 平行的仿射线 ℓ_z 上（否则补对违背极大性），线两两不同（方向独立）；完美块内压缩常值游程为 run-entry，block-intervals 保证每标签每块至多一个 run，regular run 的商增量 (ΣD_a/p_z)ē_z≠0（非零子区间断言）；过渡=两线的公共点；建二部关联图（线顶点+点顶点），**是森林**：简单圈过不同独立方向，每线上两邻点不同，圈上位移给出系数全非零的线性关系，矛盾；无立即折返的游程=端点间唯一简单路；码五件套：①不完备位置/块界/run 界/regular 性（exp(O(k))），②omitted run 的相等划分 ((2k)^{O(rB)})，③有根有序森林遍历+类型位（exp(O(k))），④每 regular 段的线端点有序对 ((4k)^{O((2r+1)B)})，⑤每不完备位置的代表指向 ((2k)^I)；对数和 C₀k+C₀L^{0.92}log(4k)+C₀(S₁+U)log(2k)≤Ck（0.92、1/4<1）。**"与系数无关"**：码宇宙只依赖长度与数值上界，每个可实现模式都有该宇宙中的码，固定序取首个有效码即单射。**常数理由**：(2r+1)B≪L^{0.92} 用 B≪k/s+S₁+U、r=L^{1/50}；segment 端点恢复 run 序列靠森林唯一路性。**[推测] 失败路线**：① 若 r 提高到 L^{1/30}，(4k)^{O(rB)} 的指数 L^{1/30+0.92} 仍 <1，但 omitted 划分 (2k)^{O(rB)} 的 rB=L^{1/30+0.92} 逼近 1——边际消失；② 若商空间维数用 lit 一致性而非联合独立对界定，过渡点坐标进入码，系数无关性失效；③ 圈论证依赖"每线两邻点不同"——若允许一点在三线上（超二部），线性关系系数可能为零。

**(c) 引理 q:padding-sum**：固定 m、bin、tuples、符号、初始点与非 P 剩余环境，Σ_{q₁..q_m}Π_i Lu(q_i)/w(n_i)·1_{q_i|n_i}·1_{(d_i,q_i)∈𝒮_j}·1_{ρ_j(n_i,d_i)≤K/L} ≤ K^m。机制：ρ_j 定义允许 bin 内全部 padding，故 Σ_q c_i(n,q)≤Lρ_j(n,d_i)1_{ρ_j≤K/L}≤K；后向归纳 F_i(n)=Σ_q c_i(n,q)F_{i+1}(n+ε_i hqd_i)≤K^{m−i+1}——早期 padding 选择的位移不引入额外因子（界对起点一致）。**[推测] 失败路线**：① 若把 ρ_j 截断换成对 q 的全局截断（比如 ω(q) 直接进 ρ_j），和式不再 ≤Lρ_j；② w(n) 出现在分母且 n 随 q 变——归纳的一致性是关键，若某步界依赖历史 q，崩。

**(d) q:trace 完成证明**：三例外类（U 大、高秩、S₁ 大）共 o(1)；剩余按 exp(CJk) 模式族计数，|ΔG|→2^{S₁}，每 distinct 列素留一个倒数（b_𝓛 放大）；R 中丢闭性/进度/块约束/到达截断/低 Q 截断，留 padding 可除性、bin、departure 权与 ρ_j 截断，条件于非 P 环境 q:padding-sum(m=2k) 给 K^{2k}；不同标签数 m_P≤Jk+S₁/2（每个 nonsingleton 至少两现），数值和 ≤(2W)^{Jk+S₁/2}≤(2W)^{Jk+L^{1/4}/2}；符号 2^{2k}、lit 指定 2^{2kJ}、混合差 2^{S₁}、外部 exp(108L)；固定 W 后 (2W)^{L^{1/4}/2}≤e^k（L 大），得 [K(C₂√W)^J]^{2k}。**常数理由**：C₂ 绝对且**先于 W 固定**——依赖 h,l 的只有 X 的阈值；(2W) 而非 V_i 上界直接乘，是把互异素类拆成"首个出现即可辨识"的乘积和放大（无排列因子）。
### 2.7 §q:spectral 谱转移与终选常数

**(a) 引理 q:noncommuting（自伴边矩阵的转移）**：B₁,…,B_N 自伴，P 正交投影，𝓑_{i,j}=1_{i≠j}B_j；若 ‖B_i‖≤a 且 Σ‖B_iv‖²≤b²‖v‖²（v=Pv），则 ‖P(ΣB_i)P‖ ≤ 3max{a,b,ρ(𝓑)}。机制：t=(2m)⁻¹，F(u)=I−ΣuB_i(I+uB_i)⁻¹ 在 [−t,t] 可逆且正定：若 F(u)v=0，令 z_i=(I+uB_i)⁻¹v，则 (u𝓑z)_i=v−uB_iz_i=z_i，非零 z 给 𝓑 的特征值 1/u 与 I−u𝓑 可逆矛盾；预解恒等式 F(u)=I−uΣB_i+Q(u)，Q(u)=u²ΣB_i²(I+uB_i)⁻¹（逆正且 ≤2I），对 v=Pv：0≤⟨v,Q(u)v⟩≤2u²b²‖v‖²；F(±t) 正定性夹出 |⟨v,ΣB_iv⟩|≤(1+2t²b²)/t·‖v‖²≤3m‖v‖²。**全过程不同时交换两个 B_i**（论文明言）——这正是处理 H 的 d-副本不交换的设计。**[推测] 失败路线**：① 若用 Ihara–Bass 型显式公式，需要各 A_d 交换或特定代数结构，多标签矩阵不满足；② b 界只在 v=Ev 上成立，若 F(u) 的正定性在全空间用 b，失败——证明小心地只在 P 范围用。

**(b) 引理 q:weighted-rows**：‖A_d‖≤2K；Σ_d‖A_dv‖²≤4K²(8W)^J‖v‖²（v=Ev）。机制：单方向加权行和 ≤Ka_d(n)（padding 和 ≤Lρ_j≤K；入边 q|n ⇔ q|n′），加权 Schur（2|v_nv′|≤|v_n|²√(w′/w)+…）在 a_d 水平集（A_d 不变）上给 ‖A_dv‖²≤4K²Σa_d(n)²|v_n|²；Σ_d a_d(n)²≤Σ_d a_d(n)≤Π_i(ω_{P_i}(n)+V_i)≤((ω_P+ΣV_i)/J)^J≤(8W)^J——AM–GM 用 ω_P≤6WJ、ΣV_i≤2WJ（6+2)/J→8W；**不要求 E 与 A_d 交换**。**[推测] 失败路线**：① 若 ω_P 截断值取 4WJ 而非 6WJ，AM–GM 给 (6W)^J，稍好，但删除代价 e^{−2WJ} 变 e^{−WJ}，仍 <e^{−J}…实际 6W 的富余来自 J+2(e−1)W≈4.44W 的指数 Markov 损耗；② a_d 水平集不变性依赖"n′−n 是 d 的倍数 ⇒ a_d(n)=a_d(n′)"——若 padding 素数混入 d，破坏。

### 2.8 §q:affine 仿射推演

恒等式 λ(a₁n+b₁)λ(a₂n+b₂)=λ(l)λ(ln+c₀)λ(ln+c₀+h)（l=a₁a₂，c₀=min(a₂b₁,a₁b₂)，h=|a₁b₂−a₂b₁|）：把两仿射自变量分别乘 a₂、a₁，完全乘性吸收 λ(a₂)λ(a₁)=λ(l)。端点恒等式含行列式两符号与非整数截断；(log X)^c/X 在 [3,∞) 有界吸收 |P(c₀)|。**[推测] 失败路线**：① 若 λ 换成一般乘性 f，完全乘性不再可用（Part III 的 Lemma affine-dilation 处理该情形，代价 2^{ω(a)} 项）；② c₀=0 与 h 的符号情形——恒等式对两种 Δ 符号统一成立。

#### §analytic-transfer 归约

**(a) 引理 lem:analytic-absolute-defect**：Σ_p(1−|f(p)|)/p=∞ ⇒ N⁻¹Σ_{n≤N}|f(n)|→0。机制：|f(n)|≤Π_{v_p=1}|f(p)|（有限集 𝒫）是 mod Πp² 周期主项，均值 Π(1−(1−|f(p)|)(1/p−1/p²))→0（Σp⁻² 收敛保证乘积行为由 Σ1/p 控制）；先固定 𝒫 取极限再增 𝒫。由此可设 Σ(1−|f_i(p)|)/p<∞（有限亏损），且归一 f_i(1)=1。

**(b) 引理 lem:raw-bin**：存在 C₀≥1、c>0，对大 B 可选 H≤exp(C₀B) 与 𝒟 ⊂ {平方free 𝒮-乘积}，满足 H<d≤τH、|f₁(d)f₂(d)|≥½、Σ_{d∈𝒟}A^{ω_C(d)}/d ≥ cL₀/B。机制：律 A^{ω_C(d)}/(dL₀) 下各带素数以 A_a/(p+A_a) 独立入选；𝔼ω(d)≪_A log B、𝔼 log d≪_A B，Markov（各 ≤1/8）取 C₀；𝔼_div(1−|f₁(d)f₂(d)|)≤AΣ_{p>P₀}[(1−|f₁(p)|)+(1−|f₂(p)|)]/p=o(1)（有限亏损输入），故 |f₁(d)f₂(d)|<½ 概率趋零、P(d=1)=L₀⁻¹→0，剩余质量 ≥L₀/2；倍率区间 (τ^r,τ^{r+1}] 至多 1+C₀B/log τ 个，一个带 ≥cL₀/B。**[推测] 失败路线**：① 若亏损发散但 |f| 平均不趋零（条件不够时），raw-bin 的 ½ 截断失败——所以先做绝对值亏损分类；② τ−1 太大时区间质量 cL₀/B 的 c 变差，与 raw-lower-bound 的 γ/64 预算冲突。

**(c) 引理 lem:raw-lower-bound**：取 a_d=\overline{f₁(d)f₂(d)}、X_j=HN_j、τ−1≤γ/64、32/T²≤γ/64，则 liminf_j |R_B(X_j)|/X_j ≥ c_γ L₀/B（c_γ=γc/8）。机制：x=dm 处 a_df₁(dm)f₂(d(m+h))=|f₁(d)f₂(d)|²f₁(m)f₂(m+h)（除 gcd(d,m(m+h))>1，密度 ≤2J/P₀）；k_d(dm) 均值 μ_d=v_C−Σ_{p|d,p∈𝒞}1/p、方差 ≤v_C，Chebyshev+union 给截断失败比例 ≤32/T²（**不需要两端独立**）；|R_B−K_𝒟S(N_j)|≤N_jV_𝒟(τ−1+32/T²+4J/P₀+o(1))，反向三角不等式给 |R_B|≥(γ/8)N_jV_𝒟；V_𝒟≥H·cL₀/B。**常数理由**：γ/64 预算切四份（τ−1、32/T²、4J/P₀、o(1) 各 γ/64）。**[推测] 失败路线**：① 若 gcd 例外集密度 ∼Σ_{p|d}1/p 而 d 可含小素数——不会：d 的素因子全 >P₀，J/P₀ 可忽略；② 若偏差 S(N_j) 的辐角振荡，反向三角不等式仍成立（作用于复数本身），无需相位收敛。

**(d) 命题 prop:analytic-centering（中心化估计）**：limsup_X |R_B−C_B|/X ≪ L₀(B^{−1−ε}+J/P₀)。机制：中心带因子展开后 d=uw（w>1 为取常数项的 center 素数积），系数 A^{ω_C(u)}c_w^{(u)}/w，|c_w|≤1 支撑在 (M,τM] 的 P₀-粗数上，P₀/τ≤M≤e^{C₀B}；截断 w_{uw}(uz)=φ((Σ_{p∈𝒞,p∤u}1_{p|z}−v_C)/√v_C) 用 Fourier 反演化为有限个乘性扭曲 b_i(n)=f_i(n)e(t_i/√v_C·Σ1_{p|n})（乘性、|b_i|≤1、不必完全乘性——扭曲因子在 p 与 p² 同值），总权 ‖φ̂‖₁² 固定；gcd 例外密度 ≤2J/P₀ 给 J/P₀ 项。核心目标 (eq analytic-rough-target)：对一切扭曲与 |c_w|≤1，limsup_Y (1/Y)|Σ_z b₁(z)Σ_w c_w b₂(z+hw)/w| ≪ B^{−1−ε}。

**(e) 引理 lem:finite-prime-stability**：|D(b,χn^{it};X)²−D(f,χn^{it};X)²|≤2Σ_{p∈𝒫}1/p；故有限素改动保持一致非冒充（对固定有限特征族一致）。配合 MRT Thm 1.7（Q=min((logX)^{1/125},(logD)⁵)，误差 e^{−M(b;X,Q)/20}）在固定 B、D 后特征族有限，𝓜→∞，得 (eq mrt-fixed-length)：limsup_Y sup_α (1/(DY))∫₀^Y|Σ_{y<m≤y+D}b_i(m)e(αm)|dy ≪ log log D/log D。

#### §paths 禁路径与算术节省

**(a) 设定**：ℓ=2⌊B⌋（闭线长）、L=⌊B^{1−ρ}⌋（路径长参）、t₀=⌈B^{4ε}⌉（witness 数参）。闭线 𝐝=((ε_i,d_i))_{i≤ℓ}，b_j=Σ_{i≤j}ε_ihd_i，b_ℓ=0（允许重复 offset）；归一化核 K_𝐝(n)=Π_i g_{d_i}(n+b_{i−1},n+b_i)/W(n+b_{i−1})。

**(b) 定义 def:primitive-specification**：specification=互异 offset 的路径 z₀=0,…,z_m（1≤m≤L，z_i−z_{i−1}=ε_ihe_i，e_i∈𝒟）+额外素数 p∈𝒮（不整除任何 e_i）+指标 i₀ 使 p|z_m−z_{i₀−1}；在 x 处 qualify 当 p|x 且 e_i|x+z_{i−1}（∀i）。素支撑 Π；柱集=qualify 的 x，非空时恰固定 Π 上各一个剩余，测度 Π_{q∈Π}q⁻¹。**primitive**：柱非空且无更短非空连续子路径（两方向、从 Π 取额外素数）在其柱上 qualify。Y=无 primitive specification qualify 的 x（周期 mod Π_{p∈𝒮}p）。

**(c) 引理 lem:primitive-descent**：任何 qualify 的 specification 可降到只用其素支撑、在其路径某顶点 qualify 的 primitive specification（全整除在反转下保持；候选子路径的剩余测试在原柱上为常数；长度严格降）。

**(d) 定理 thm:high-trace**：ℙ(n∉Y)≤P₀^{−1+o(1)}；Σ_𝐝|𝔼 K_𝐝(n)Π_{j=0}^{ℓ}1_Y(n+b_j)| ≤ B^{−(1+c_*)ℓ}。

**(e) 引理 lem:bad-density**：固定边标签/符号/后缀，位移 D=z_m−z_{i₀−1}≠0、|D|≤LhτH；先求和额外素数：Σ_{p∈𝒮,p|D}1/p ≤ log(|D|+2)/(P₀ log 2)（p>P₀）；其余边素倒数积，槽 ≤LJ，模式选择 exp(O(LJ log B))，各类倒数和 ≤1+v_C+v_Z；总 P₀⁻¹exp(O(LJ log B)+…)→P₀^{−1+o(1)}（LJ log B=O(B^{1−ρ}log²B)=o(log P₀)）。**[推测] 失败路线**：① 若额外素数允许来自边标签（p∤e_i 条件去掉），p 的倒数和被边素重复计费，节省叠乘失效；② D=0（路径有零位移子段）时 p|D 平凡——互异 offset 假设排除。

**(f) 引理 lem:primitive-properties（素区间与最后常数块）**：primitive 且 B 大时：(1) 每个边素的出现指标成区间；(2) 末极大常数块 e_b=…=e_m 满足 b>1、块上符号恒定、存在 r|e_b 且 r∤e_{b−1}（从而 r 只出现在尾部），且在后缀位移中 r 作为素变量的系数模 p 非零（=±kh·e_b/r，p>h,L、p 不整除边标签）；(3) 若 q 出现在 b 之前，q 在 z_{b−1}−z₀ 中的系数模 r 非零。机制：(1) 相邻出现块之间的 q-自由子路径（端点活跃、位移非零被 q 整除）给出更短 qualifying specification，违背 primitive；(2) 常数块内换号会重复顶点；b=1 时后缀位移=±khe_m 而 p 整除之，但 p∤e_m、p>h——矛盾；e_b,e_{b−1} 同 bin 比值 <2，若 e_b 的素全整除 e_{b−1} 则商为 ≥2 的整数，矛盾；(3) 前缀和 S=z_j−z_{i−1}≠0；若 r|S，反转 z_{b−1}→z_{i−1} 的路径得更短 qualifying specification（r-自由边、起点活跃、后缀位移被 r 整除），违背 primitive；S=q×系数，q≠r。**[推测] 失败路线**：① 同 bin 比值 <2 用了 H<d≤τH<2H——若允许跨 bin 标签，e_b|e_{b−1} 成为可能；② 反转构造需"全整除反转不变"，一般位移不行。

**(g) 引理 lem:crude-count（绝对倒数计数）**：长 ℓ 线+≤2t₀ 个长 ≤L 的 attached specifications，含 lit/unlit 状态的 slot 模式数 exp(O(B log²B))（槽 ℓJ+2t₀(LJ+1)=O(B log B)，4ε<ρ）；对指定模式与数值素数，𝔼[|K_𝐝(n)|1_E(n)Π1_{σ qualifies}] ≤ A^{ℓJ}Π_{p used}1/p；若记录状态含 ≥t₀ 个"出现 ≥2 次的 center 素数的 unlit 出现"，再乘 P₀^{−t₀/2}，该类总量 O(exp(−B^{1+ε/2}))。机制：cutoff 与 W⁻¹∈[0,1] 丢弃；lit 出现或 specification 的 qualify 固定剩余给 1/p；unlit core 出现为零（自灭）、unlit center 出现给 θ/p——仍有一个 1/p；重复 center 素有 lit 时每个额外 unlit 多一个倒数，全 unlit 的 m≥2 个供 p^{−m}，省 ≥m/2 个；每个自由素变量倒数和 ≤1+v_C+v_Z=O(log B)，总 exp(O(B log²B))，省 P₀^{−t₀/2}（对数 −½B^{1+3ε}）。

**(h) 引理 lem:triangular-saving（三角算术节省）**：若构型供 ≥B^{2ε} 个相异素变量 q₁..q_k，测试 j 只用 q_j、更早变量与非选中变量，且为 (i) q_j|D_j（D_j≠0 独立于 q_j，log|D_j|=O(B log B)）或 (ii) a_jq_j+c_j≡0 (r_j)（r_j 为更早/非选中素变量，a_j≢0 (r_j)），选择与次序的描述数 exp(O(B log²B))，则总量 O(exp(−B^{1+ε/2}))。机制：(i) Σ_{q|D_j}1/q≪B log B/P₀；(ii) 一个剩余类，Σ_{P₀<n≤e^B, n≡a₀(r)}1/n ≤1/P₀+(B−logP₀)/r ≤(1+B)/P₀；按 q_k…q₁ 反序求和（每个更早测试与当前变量无关；D_j≠0、a_j≢0 在消去中保留，失败则内和为零），因子 (O(B log B)/P₀)^k，k log P₀≥B^{1+ε}。描述约定：每个测试用有界条线/树路径+一个 O(ℓH) 的公共整数 offset（offset 的 O(ℓH+1)=exp(O(B)) 选择；固定后丢弃其与树 offset 差的定义等式，是正上界放大；每边积 ≤e^{BJ} 使位移和对数仍 O(B log B)）。**[推测] 失败路线**：① 若测试依赖未排序的晚选变量（无三角性），反序归纳失败——这就是 §thinning 花大力气构造次序的原因；② offset 若不单独固定而作为素变量的函数，(i) 的 D_j 与 q_j 不独立；③ k 若恰为 B^{2ε} 边缘，k log P₀=B^{2ε}·B^{1−ε}=B^{1+ε} 恰好——任何一处常数退化都致命，故各处都留 B^{ε/2} 富余。

#### §thinning 首访树与保留构型

**(a) 结构**：闭线的首访树 𝒯（新 offset 加顶点，其余为 return；r_* 个 return；|E(𝒯)|=ℓ−r_*）；固定标签集 𝓕={出现于线上的 p：p∈𝒞 或出现 ≥2 次}（含只出现一次的 core 素、不含线外背景 core 素）；限制只许依赖 n_𝓕。树素 p∉𝓕=只在一线出现的 center 素；**corrupted**：𝒯 中另有非端点顶点与其边两端点 mod p 同余（纯数值条件）。

**(b) 引理 lem:forest-path-hitting**：森林中路径族若无 t 条两两边不交，则有 <2t 条边命中所有路径。机制：每次取顶最深的路径、标其顶部 1–2 条边；与它共边的路径必含标记边（否则其顶更深）；逐轮所选路径两两边不交，<t 轮、<2t 条边。

**(c) 引理 lem:activity-blocks**：除零贡献/可忽略类外，可切 O(t₀) 条树边，把所得森林用 O(B^ρ) 个直径 ≤L 的连通块覆盖（含所有剩余边与顶点），每块内每个固定树素的活跃集连通或空。机制：切掉有 unlit 固定出现的边（<t₀ 条）；**gap for p**=长 ≤L、端点活跃、内部不活跃的路径——gap 无 p-边（活跃端点逼出 p-边，p-边两端同活跃/被切）；gap 必含非固定标签（否则全固定且 lit → 全路径可除、位移非零被 p 整除、取额外素 p 得 qualifying specification，primitive 下降后与 1_Y 矛盾）；若存在 t₀ 条两两边不交 gap，各取非固定素 q，gap 位移对 q 线性、系数模 p 为 ±h×其余因子（可逆，gap 无 p），约束互不涉及彼此变量，q:triangular-saving 丢弃（t₀≥B^{2ε}）；否则 lem:forest-path-hitting 给 <2t₀ 补切，对每片二次遍历切成 ≤L 段，块数 O(ℓ/L+t₀+1)=O(B^ρ)。

**(d) 引理 lem:reroot-constraints**：两块+ m 个素指标（各 A_p^j 非空连通、块内"边两端∈A_p^j ⇔ 标签含 p"、A_p¹,A_p² 在全树 V_p 诱导子图的不同分支），存在根 c_j 与 ≫m^{1/8}/(2J+1) 个保留指标及次序，使 c_j→x_p^j 路径避开 p、保留标签在次序中更早，且 x_p¹≠x_p²。机制：连通集含任意两点间路径→对根有唯一最近点；根到 x_p 路径避开 p-边；路径上保留标签 q 的两端∈A_q^j，x_q 是 x_p 的严格祖先——依赖嵌在两个严格祖先序中；偏序集链/反链 ≥√u（按最长链长度分层）；块 1 得反链→块 2 深度序即可；两链各 ≥m^{1/4}→Erdős–Szekeres 给公共同/反向子序列 ≥√(m^{1/4})=m^{1/8}；反向时：块 2 取根到最远 x_p² 的段，各 A_p²∩段=从 x_p² 开始的闭区间，每顶点至多 2J+1 个区间重叠（每条段边 ≤J 因子），贪心着色 2J+1 色取 1/(2J+1) 两两顶点不交族，重根于段远端后最近点变为右端点、次序反转后与块 1 一致。**[推测] 失败路线**：① 祖先序依赖若不"严格"，相等最近点会造成循环依赖——论文用 incomparability 处理；② 2J+1 着色数若换 2，J≥2 时失败。

**(e) 引理 lem:few-disconnected**：≥B^{1−2ρ} 个多分支固定树素的保留构型总量 O(exp(−B^{1+ε/2}))。机制：O(B^{2ρ}) 有序块对之一服务 m≫B^{1−4ρ} 个素；每素给约束 (eq two-block-constraint) p|K+(b(x_p²)−b(c₂))−(b(x_p¹)−b(c₁))≠0（K=b(c₂)−b(c₁) 单独固定，|K|=O(ℓH)），局部路径避开 p→表达式与 p 无关；保留数 ≫B^{(1−4ρ)/8}/J=B^{1/10}/O(log B)>B^{2ε}（1/10>2×10⁻⁴）。**[推测] 失败路线**：① K 依赖标签值却不固定就求和，D_j 对 q_j 的独立性坏——引理强调"选 K 只在 rerooting 之后"；② 非零性来自两代表点的 offset 互异，若 A_p¹=A_p² 同点，约束退化。

**(f) 引理 lem:few-corrupted**：≥B^{1−2ρ} 个 corrupted 非固定树素 → O(exp(−B^{1+ε/2}))。机制：D=⌊B^{1−3ρ}⌋； witnesses 距其素边 ≤D 者：路径避开该素唯一边→非零位移与其独立且被其整除，表达式含 ≤JD 个其他素标签；依赖图出度 ≤JD，逐步取度 ≤2JD 的点删邻域，独立集 ≥c·B^{1−2ρ}/(JD+1)≫B^ρ/J>B^{2ε}；远 witnesses 者：全树以 O(ℓ/D+1)=O(B^{3ρ}) 个直径 ≤D 的遍历块覆盖，某有序对服务 ≫B^{1−8ρ} 个素（1−8ρ=3/5），第二块内路径不含选中标签，块 1 深度序给三角性。**[推测] 失败路线**：① corrupted 判定只看数值 offset（不用剩余）——若改用剩余测试会把自由 center 剩余"固定化"，毁掉后续符号平均；② D 的选取若 ≤B^{1−4ρ}，JD 失去小性。

**(g) 命题 prop:retained-lines**：存在只依赖 (𝐝,n_𝓕) 的谓词 R_𝐝，取 1 时：所有 core 线出现 lit；无支撑 ⊂𝓕 的 primitive specification 在 trace 顶点 qualify；重复 center 的 unlit 出现 <t₀；每个固定树素活跃分支 O(B^ρ) 个；多分支固定树素 <B^{1−2ρ}；corrupted 非固定树素 <B^{1−2ρ}。且 Σ_𝐝 𝔼[|K_𝐝|Π1_Y(1−R_𝐝)] ≪ exp(−B^{1+ε/2})；上述例外估计在附加 ≤2t₀ 个 specification qualify 指示子后仍有效。**[推测] 失败路线**：R_𝐝 若依赖任何自由 center 剩余（例如"corrupted"用剩余定义），§cylinder-sieve 的条件分解（𝔼_𝓕|R_𝐝𝔼_{𝒮∖𝓕}·|）就不再保持符号平均。

#### §cylinder-sieve 条件柱筛

**(a) 引理 lem:cylinder-truncation**：宽度 ≤w 的事件族 𝓔 的交偏集 𝓟（按反包含序），rk(I)=其中每员有私有支撑坐标的最大子族数；M=tw，𝓗_t={rk≥t 且由 ≤t 个事件生成}。则 rk 单调、每个 I 由 ≤rk(I) 个事件生成、|supp(I)|≤w·rk(I)，且对每 x：|1_{x∉∪𝓔} − Σ_{rk(I)<t}μ(0̂,I)1_I(x)| ≤ 2^M max(1,M^{M+1})Σ_{J∈𝓗_t}1_J(x)；保留系数 ≤max(1,M^{M+1})，右侧交宽 ≤M。机制：极小生成族每员有私有坐标（否则可删，兼容性保证）；区间 [0̂,J] 元素 ≤2^m、链 ≤k^m 条→|μ(0̂,J)|≤Σ_{k=1}^m k^m≤m^{m+1}；精确恒等式 Σ_{I∈𝓟}μ(0̂,I)1_I(x)=1_{J_x=0̂}（J_x=x 满足的全部事件之交）；rk(J_x)≥t 时逐个相交直至秩 ≥t 的首个 K，对前驱重新极小化（≤t−1 员）再加一员得 K∈𝓗_t、宽 ≤M——**允许秩跳跃**，生成元数由前驱的再极小化而非列表长度界定；每个满足的低秩 I 位于某个满足的 𝓗_t 成员之下，前者 ≤2^M 个可能。

**(b) 应用于线**：条件于 n_𝓕（R_𝐝=1），每顶点 n+b_j 的残存 primitive specification 去掉固定坐标测试后是 𝒮∖𝓕 上的 exact cylinder，宽 ≤LJ+1；无全空间事件（否则是只用固定素的 qualifying primitive specification，已被保留条件排除）；回避=各顶点 1_Y 条件。列表 ℒ<t₀(𝐝)：长 <t₀ 的有序 specification 列；M₀=t₀(LJ+1)=O(B^{1−ρ+4ε}log B)，M₀ log B=o(B)。

**(c) 引理 lem:cylinder-witnesses**：t₀ 个同时 qualify、各含一个"𝓕 外且不属其他 specification"的私有素的 primitive specification，其数值标签满足 ≥B^{2ε} 个 q:triangular-saving 型三角约束（每约束用一条内禀后缀位移，或两 witness 前缀之差+一线段；非零表达式的对数规模 O(B log B) 即使丢 bin 限制）。机制：lem:primitive-properties 的两条系数事实 (i)(ii)；按附着指标 k₁≤…≤k_{t₀} 排序，三情形：私有素在内禀后缀约束（q_j=p_j 或 q_j 只在尾块）——无依赖，三角；尾素 r_j 不在任何更早（或更晚）witness——内禀后缀同余用于 r_j，晚选尾素不在本 witness（定义性质）也排除在模 p_j 外；其余 ≥t₀/2 个（q_j 在尾前出现且 r_j 前后 witness 都有），按 q_j 不出现在步骤 1..k_j（或 k_j+1..ℓ）分组（各 ≥t₀/4），比较同余 b_{k_j}−b_{k_i}+P_j−T_i≡0 (r_j)：q_j 的系数=P_j 中的系数，非零由 (ii)；晚选 q_s 因 k_s≥k_j 与缺席条件不在段中、因私有不在两 witness 中——三角；各情形 ≥t₀/20>B^{2ε} 个变量。**[推测] 失败路线**：① 比较位移可为零——无碍：用的是可逆线性同余而非"整除"型约束；② 若私有素作为控制模出现（r_j=q_j 情形），(ii) 的非零系数失效——被情形划分排除（q_j 在尾前 ⇒ r_j≠q_j）。

**(d) 命题 prop:cylinder-reduction**：存在因子 𝔠_B=exp(O(M₀ log B)) 使 Σ_𝐝𝔼_𝓕[R_𝐝|𝔼_{𝒮∖𝓕}K_𝐝Π1_Y|] ≤ 𝔠_B·Σ_𝐝𝔼_𝓕[R_𝐝 Σ_{ℒ∈ℒ<t₀}|𝔼_{𝒮∖𝓕}K_𝐝I_ℒ|] + O(e^{−B^{1+ε/2}})。机制：逐 (𝐝,n_𝓕) 用 truncation；低秩主项=生成列表（不同交不能有同一生成列表——列表确定其交，无重复计费）；误差项=生成+t₀ 个秩 witness 列表（witness 可从更大的 irredundant 族选、含交、 adjoining 不变指标），合计 ≤2t₀ 个 specification、其中 t₀ 个有 𝓕 外私有素→q:cylinder-witnesses→q:triangular-saving；lit/unlit 细化后 lem:crude-count 给 A^{ℓJ}Π1/p（不同素各计一次），𝔠_B 被 exp(−Ω(B^{1+ε})) 吸收（log 𝔠_B=o(B)）。随后 (eq cylinder-core-order)：|𝔼_{𝒮∖𝓕}K_𝐝I_ℒ| ≤ 𝔼_{𝒞′}|𝔼_{𝒵′}K_𝐝I_ℒ|——Fubini+三角，core 坐标先固定（cutoff 变常量）、center 剩余保留符号。**[推测] 失败路线**：① truncation 系数 M^{M+1} 若不被 t₀ 的选择压住（M₀ log B 不 o(B)），主项膨胀毁掉 B^{−(1+c_*)ℓ} 预算；② witness 选取依赖 n_𝓕——无害但要逐点陈述；若把选取做成全局，测度论上的积分不可交换。

#### §trace-count 迹求和

**(a) 树几何**：good edge：s(u)=s(v)=1、u 非根、两端点不属任何 return。引理 lem:trace-topology：拓扑+符号数 ≤4^ℓ(ℓ+1)^{r_*}；|E(𝒯)∖𝒢|≤10(r_*+1)（叶 q≤r_*+1、分支 b≤q−1、Σ_{s≥2}s=q+b−1 → 叶/分支关联边 ≤4q；return 端点 ≤2r_*，未计的 unary 端点 ≤4r_*；根 ≤1）；树边标签+拓扑确定全部 return 标签（return 标签=端点差/h，非独立选择）。**[推测] 失败路线**：10(r_*+1) 若改 3(r_*+1)，r_* 大时 r 项系数 (88−…) 变负，高迹估计失败。

**(b) 子树恒等式**：u_a(Q)=A_a^{|E(Q)|}Π_{v∈V(Q)}β_a^{s(v)}，S_a(𝒯)=Σ_v(1−β_a^{s(v)})；引理 lem:subtree-weight：Σ_{|E(Q)|≥1}u_a(Q)=S_a(𝒯)≤|V(𝒯)|。机制：从 v 出发每条子边以 A_aβ_a 独立收录，所得连通子树顶 v、概率恰 u_a(Q)；无边结果概率 β_a^{s(v)}；对 top 求和。**精确性是后续指数相消的全部**——不能用上界替代。修正权 ũ_Z：单 good edge 取 θ/2、单非 good edge 取 u_Z+θ，Σ_Qũ_Z−S_Z=−(θ/2)|𝒢|+θ|E∖𝒢|。

**(c) token 记录**：tagged=满足 (i) 出现在列表素中 (ii) 固定且多分支或有 unlit (iii) 非固定且 corrupted；每个 tagged 固定素记每含边活跃分支一个 subtree token（权 u_a(Q)）+每个 unlit 树出现一个 ghost token（权 2）；tagged 非固定素记其唯一树边为 ghost；untagged 素一个 token（固定：其树出现构成的子树，权 u_a；非固定：单边，权 ũ_a）。引理 lem:trace-token-record：(i) tokens 恢复全部树边标签→连同拓扑与列表恢复整线；(ii) tagged tokens+列表素槽 ≤N_exc=B^{1−ρ/2}（多分支固定素 O(B^{1−2ρ}) 个 ×B^ρ 分支、unlit 固定 O(t₀)、corrupted O(B^{1−2ρ})、列表 O(M₀)，1−ρ+4ε<1−ρ/2）；(iii) untagged 固定 center 素不能有单 good edge token（否则其余出现必为触碰该边的 return，违背 goodness；其他活跃 return 端点会给出第二活跃分支并被 tag）。**[推测] 失败路线**：ghost 权 2 若改 1，unlit center 的 θ/p 界不住（两个因子 |1−θ/p| 与 θ/p 之和 >1）。

**(d) 引理 lem:trace-integration（逐素积分，θ 恒等式的心脏）**：对分配记录 R，𝓘(R)=𝔼_𝓕[1_R|𝔼_{𝒮∖𝓕}K_𝐝I_ℒ|] ≤

exp{o(1) − κ(v_C−T√v_C)(r_*+|𝒰|)} · exp{−v_C S_C(𝒯)−v_Z S_Z(𝒯)+v_Cβ_C(e^κ−1)|𝒰|} · Π_{p distinct}^{tree/list} (1/p) · Π_{tagged}weight · Π_{untagged (a,Q)}ũ_a(Q)。

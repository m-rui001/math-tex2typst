## 0 我进场时手里有什么

我手里唯一硬结论是 abstract 那一行和 Theorem 1.1（`45-49`）：

```tex
\begin{theorem}\label{thm:main}
For every $\eps>0$, two $n\times n$ complex matrices can be multiplied
using $O_\eps(n^{9/4+\eps})$ arithmetic operations. In particular,
$\omega\leq9/4$.
\end{theorem}
```

量词顺序我逐字对齐过，因为 Lean 那边按它核对，而且这一顺序决定了整篇能不能做：$\forall\varepsilon>0,\ \exists$ 程序与常数，$\forall n\to\infty$，$n$ 趋于无穷、算法与常数都可依赖 $\varepsilon$（`39-43` 明说 "The dimension $n$ tends to infinity; the algorithm and its constants may depend on $\varepsilon$"，`88-90` 又补一句本定理只谈渐近算术指数，不指定任何有竞争力的有限矩阵尺寸）。这句话是在给我松绑：我不需要拿出某个具体的 $n$，只要在无穷远处赢。

$\omega\le 9/4=2.25$ 这个数，放在 $\omega$ 上界改进的年表里，第一眼会让人以为是要去打破 2.37 那一档，结果完全不是。我先把这条谱系摊开，因为它是这篇为什么长这样的全部理由：

- Strassen 1969 用 $2\times2$ 的七积算法把指数从 $3$ 拉下（`51-52`，\cite{Str69}）。机制是递归，载体是三线性系数张量。
- Bini 的插值论证把"近似双线性算法"转成精确渐近算法（\cite{Bini80}）；Schönhage 的渐近和不等式把"同时独立算若干个矩阵乘"兑换成指数界（\cite{Sch81}）；Strassen 的激光法从张量幂里抽取那些独立乘积（\cite{Str86,Str87}），他的渐近谱用对直和加、对张量积乘、对限制单调的数值不变量来刻画渐近张量比较（\cite{Str88,CVZ}）。
- Coppersmith-Winograd 把张量幂和无等差集合结合，从辅助形式里抽独立乘积（\cite{CW90}）；Stothers（\cite{Sto10}）、Davie-Stothers（\cite{DS13}）、Vassilevska Williams（\cite{VW12}）、Le Gall（\cite{LG14}）把这套高幂次分析推进，Le Gall 用凸优化重述分析；Alman-Vassilevska Williams 精炼独立分量的抽取（\cite{AW21}）；Duan-Wu-Zhou 分析跨递归层合并分量带来的损失（\cite{DWZ23}）；VXXZ（\cite{VXXZ24}）、Alman 等（\cite{AD25}）用更不对称的分析改进数值。Dupont 等报告 $\omega<2.371177$（\cite{Dup26}），靠的是现代优化加 AlphaEvolve 去拧这套合并损失框架。

这条线上，历次改进的瓶颈高度一致：都在"从一个大的激光法基张量里，尽量不亏地抽出尽量多的独立矩阵乘"。每多抽一份，就要付一次"分量之间共享变量"的账（DWZ 把它量化成合并损失）。数值从 2.376 一路磨到 2.371177，边际递减，而且每一步都要重跑一次凸优化。[推测] 我不认为这篇的 $9/4$ 是要在数值上胜过 2.371177，$2.25$ 比 $2.37$ 小是"更弱的界"还是"更强的结论"取决于定义方向，$2.25<2.371$ 当然更强，但这不是它的赛道：`88-90` 明确说本定理只谈渐近算术指数、不提供有限尺寸竞争力。它真正的贡献是把 $\omega\le 9/4$ 这条界用"显式张量退化 + 谱观点"重新证一遍，绕开把激光法再拧一圈。intro 那句 "The present proof combines explicit tensor degenerations with the spectral viewpoint"（`81-82`）是路线宣言，我把整篇读下来，最能印证这句的是 §3 的有限分离：它给的是一个有限对象（$5M$ 份复制、一张 Fourier 投影、一组平方权重），不是一次渐近抽取。

为什么 $9/4$ 是"门槛"这个数，我读 `113-132` 的 "Route to the exponent" 才看清，而且它跟组合侧的 $5M$、$M$、六置换、$(a+b-1)$、$3h+a-1$ 全都无关，纯粹是最后一步两条幂次增长率的比：字符在 $T_d$ 上取值 $d^{3t}$（`118-119`），多项式乘积的对称 profile 被 interpolation 顶在 $P(a,b)\le(a+b-1)^{1/t}$（`124-125`），而两条构造逼出 $P(a,a)\ge a^{4/3}$（`130-131`）。两条增长率一比：$4/3\le 1/t$，即 $t\le 3/4$，$3t\le 9/4$。所以 $9/4$ 的来源是 $4/3$ 的倒数乘 $3$，$4/3$ 又来自"三扇区"那个 $P(a,3h+a-1)\ge 3P(a,h)$（`127-129`）配上离散凹性。落实到数字上，$9/4$ 是被"多项式乘积的输出维数是输入的 $a+b-1$、而三块拆分给出 $3$ 倍"这两件事夹出来的，激光法那边根本没有 $4/3$ 这个几何。这一点是我最初设想的落点，后面每节我都会回到这条增长率之比的账。

## 1 第一条死路：把激光法再拧一圈

我进场的第一反应是沿着 intro 那条谱系继续做，也就是再挑一个 Coppersmith-Winograd 型基张量、算它的高次幂、用激光法抽独立矩阵乘、然后凸优化。这条路我推了两页就废了，理由都具体：

**理由一：抽取的边际收益是负的。** DWZ（\cite{DWZ23}）已经量化过"跨递归层合并分量"的损失；VXXZ 与 AD 的改进靠的是把不对称性做到极致。[推测] 我若要动这一档，本质上是在替 Dup26 再跑一次数值优化，而它给的是 $2.371177$，比 $2.25$ 弱。也就是说这条路线的天花板本来就在 $2.37$ 附近，我拿它去够 $9/4$ 是南辕北辙：我要的数更小，但沿这条线只会给出更大的数。

**理由二：激光法要求"三条腿都独立"的全直和，而这正是共享变量吃账的地方。** `92-98` 把这件事讲得很直白：有用的碎片会共享变量，全直和要在三腿都独立；而本文"principal construction starts with blocks that are independent on two legs and share the third"。[推测] 我一开始想正面处理"三腿都共享"的情形，直接对三条腿各做一次 Fourier 投影。失败机制很硬：三条腿都投影意味着要付三份复制预算，而输出块数（补偿这份预算的关键，见 `100-102`）会随三份预算同时被削，熵增益不够抵。这篇作者的做法是先在"两腿已经独立"的较弱假设下分离，把第三腿的共享用一次平方权重退化收干净，预算从 $3$ 份降到 $1$ 份（源只用 $5M$ 份复制）。这一步我从 §4 的 $5M$ 反推回来，确认"只分离一腿"是预算账逼出来的，不是审美选择。

**理由三：数值上没有可报的有限尺寸。** intro `88-90` 主动放弃"competitive finite matrix size"。激光法的整套机制是"有限基张量的幂 + 逐层合并"，天生要给具体尺寸；而本文是纯渐近，靠检测字符在无穷 $d$ 上的取值说话（`669-670`：检测字符可以依赖 $d$，界对所有字符一致成立）。我沿激光法走就得交出具体张量与具体 $n$，与本文的口径直接冲突。

于是我把方向调转：不去抽独立矩阵乘，是先把"字符 $=$ 谱点"这套不变量当成主角（`113-114` 引 Str88, CVZ），再想办法把字符在 $T_n$ 上的值钉死。这条调转带来的第一个具体后果是：我不再需要一个"基张量"，我需要的是"对所有字符 $\lambda$ 都能证一个不等式"。`116-119` 的 Lemma `lem:existence`（检测字符）就是把"证所有字符"合法化的那张许可证，下一节拆它。

## 2 张量半环、字符与 $\nu$：入场即定义的四件东西

`142-193` 把舞台搭好。我要拆四件：半环 $S$、秩与展平（`160-170`）、$T_n$ 与 $\nu$（`172-182`）、字符定义（`184-193`）。原文（`172-178`）：

```tex
\begin{equation}\label{eq:mm}
 T_n=\sum_{i,j,k=1}^n x_{ij}y_{jk}z_{ki},
 \qquad
 \nu=\inf_{n\geq2}\log_n\rank(T_n).
\end{equation}
```

半环侧（`150-159`）：模互限制后的张量集合 $S$，在全直和与张量积下成交换半环，限制给出与两运算相容的序。零张量记 $0$，标量张量 $xyz$ 记 $1$，整数 $m\ge 0$ 记 $m$ 份 $1$ 的直和，故 $mA=A^{\oplus m}$；全直和里各加元在三腿变量互不相交。

补推。秩 $\operatorname{R}(A)$ 是使 $m\ge A$ 的最小整数 $m$（`160`），它有限是因为"在基下展开"（`160-161`）；每个非零张量都能限制到 $1$（在三参数上取合适的线求值，`161-162`），于是
$$\operatorname{R}(A)\ge A\ge 1\qquad(A\ne 0),\tag{`163-165`}$$
秩单调、次可加、次可乘，但**不假设可加**（`166`）。这个"不假设可加"我在 §11 会看到它把附录 A 的催化论证逼成只能用单调性不能用消去的形式。展平（leg flattening）是把一腿对另外两腿张成的矩阵，其矩阵秩限制单调、在全直和上可加、在张量积上可乘（`167-170`）：这三条正好是构造"展平型字符"的理由，但本篇不真的去算展平字符，只用展平证 $T_n$ 的双侧界。

$T_n$ 的双侧界（`179-182`）：重指标把 $T_nT_m$ 认成 $T_{nm}$（次可乘来源），展平给出 $n^2\le\operatorname{R}(T_n)$（取单位子矩阵的 minor），展开给出 $\operatorname{R}(T_n)\le n^3$，于是 $2\le\nu\le 3$ 且 $\operatorname{R}(T_n)\ge n^\nu$。这里 $n^2$ 下界与 $n^3$ 上界的账：下界来自输出展平里 $n^2$ 个独立输出（每个 $z_{ki}$ 位置），上界来自朴素算法 $n^3$ 个 rank-one 积。[推测] $\nu$ 与 $\omega$ 在论文里是两条量：$\nu$ 是"精确秩指数"，$\omega$ 是"算术指数"，最后一步（§10）才把 $\nu\le 9/4$ 兑换成算术界；分开是因为 $\nu$ 用张量秩、$\omega$ 用直线程序操作数，两者的桥需要递归加 padding，不能一步到位。

字符定义（`184-188`）：

```tex
\begin{definition}\label{def:character}
A \emph{tensor character} is an additive, multiplicative,
restriction-monotone map $\lambda:S\to\R_{\geq0}$ with
$\lambda(1)=1$.
\end{definition}
```

三个展平秩是例子（`190-191`），字符是张量半环的谱点（`191`，Str88, CVZ）。它们满足 $\lambda(m)=m$ 与 $1\le\lambda(A)\le\operatorname{R}(A)$（`192-193`）。机械理由：$\lambda(m)=m$ 由可加性 + $\lambda(1)=1$；$1\le\lambda(A)$ 由 $A\ge 1$（非零张量限制到 $1$）加单调性；$\lambda(A)\le\operatorname{R}(A)$ 由 $A\le\operatorname{R}(A)$（秩的定义）加单调 + $\lambda(m)=m$。这三条界我在 §2.5、§9 反复当夹逼的两侧用。

检测字符（`198-202`），本篇唯一的存在性命题：

```tex
\begin{lemma}[Detecting characters]\label{lem:existence}
Let $d\geq2$ and $k\geq0$ be integers with $k<d^\nu$, where $\nu$ is
defined by \eqref{eq:mm}. There is a tensor character $\lambda$ with
$\lambda(T_d)\geq k$.
\end{lemma}
```

它的证明在附录 A（`700-904`），我用有限维分离、紧性、不动点，本节先只登记它的**用法**：它把"对每一个字符证 $P(a,a)\ge a^{4/3}$ 从而 $t\le 3/4$"变成"对某个能探测到接近 $d^\nu$ 的字符证界"，因为最后要反推的是 $\nu$ 本身。`204-234` 是点积指数侧，我把 eq:dot 与 eq:character-mm 也留在这里，因为 §8 的三扇区要显式用到 $p_X^{(\pi)}$。

对 $m\ge 1$ 定义有向点积 $B_X(m)=x\sum_{i=1}^m y_iz_i$（`206-210`），$B_Y,B_Z$ 循环置换。对任意字符存在 $p_X,p_Y,p_Z\in[0,1]$ 使 $\lambda(B_X(m))=m^{p_X}$ 等（`211-216`）。补推：$f(m)=\lambda(B_X(m))$ 正、不减、$f(mn)=f(m)f(n)$、$1\le f(m)\le m$（`217-218`）；令 $p_X=\log_2 f(2)$；对 $r\ge 1$ 取 $\ell=\lfloor r\log_2 m\rfloor$，由 $2^\ell\le m^r<2^{\ell+1}$ 得 $f(2)^\ell\le f(m)^r\le f(2)^{\ell+1}$，取对数、$r\to\infty$ 得第一条（`219-223`）。机械理由：不减性来自 $B_X(m)$ 限制到 $B_X(m')$（$m\le m'$ 时丢坐标），$f(mn)=f(m)f(n)$ 来自 $B_X(mn)\cong B_X(m)\otimes B_X(n)$；$p_X\in[0,1]$ 是 $1\le f(m)\le m$ 的对数翻译。这一段是数论里"正、不减、完全乘性、被 $m$ 界住 ⟹ 幂函数"的标准论证，作者把它写成 $r\to\infty$ 的夹逼，Lean 里对应 `Growth/MultiplicativePower.lean` 的 `positiveMultiplicative_eq_rpow`（我在 §14 核对）。

$B_X(m)B_Y(m)B_Z(m)$ 的变量是 $x_{bc},y_{ac},z_{ab}$、单项式 $x_{bc}y_{ac}z_{ab}$，同构于 $T_m$（`225-227`），于是
$$\lambda(T_m)=m^{p_X+p_Y+p_Z}.\tag{eq:character-mm, `228-230`}$$
把 $T_m$ 的非对角变量全置零，剩 $m$ 个独立标量积，故 $T_m\ge m$、$p_X+p_Y+p_Z\ge 1$（`231-233`），所以 $t=(p_X+p_Y+p_Z)/3>0$ 恒正（`233-234`）。这一句"恒正"是为 §9 里 $P(a,b)\le(a+b-1)^{1/t}$ 的 $1/t$ 有意义兜底：$t>0$ 才谈得上"指数越大界越松"。补一步张量积的账：$B_X(m)\otimes B_Y(m)$ 在 $X$ 腿上把 $x$ 与 $y_{ac}$ 的 $a$ 维对起来，三块拼完正好是 $T_m=\sum x_{ij}y_{jk}z_{ki}$ 的 $i\leftrightarrow$ 各腿指标命名，所以 $t$ 的三分均摊没有偏置哪一腿。

## 3 退化与插值：把近似变精确的那一步

`236-268` 只用退化最原始的一支：定好线性替换后给每个变量整数权重、乘上对应 $\varepsilon$ 幂、留总权重最小的项，记 $A\mathrel{\rightsquigarrow} B$；个体权重可为负，把最小总权重平移到 $0$ 后结果是关于 $\varepsilon$ 的多项式、常数项为 $B$（`238-245`）。插值引理（`247-250`）：

```tex
\begin{lemma}[Interpolation]\label{lem:interpolation}
If $A\degen B$, then $\lambda(A)\geq\lambda(B)$ for every tensor
character $\lambda$.
\end{lemma}
```

补推（`252-268`）：设变换后张量 $F(\varepsilon)=B+\varepsilon F_1+\cdots+\varepsilon^LF_L$，每个非零 $\varepsilon$ 处它都是 $A$ 的限制；$F(\varepsilon)^{\otimes j}$ 次数至多 $jL$、常数项 $B^{\otimes j}$；在 $jL+1$ 个非零点上插值，把这个常数项写成若干特殊化的线性组合；"同一组空间上的张量的线性组合是其全直和的限制"（认同比变量、把每个标量系数吸收进一条腿），于是
$$\lambda(B)^j\le(jL+1)\lambda(A)^j,$$
取 $j$ 次根、$j\to\infty$，退化（从而 $L$）在这个极限里固定。`268` 那句 "The degeneration, and hence $L$, is fixed during this limit" 是关键。

机械理由。$jL+1$ 这个数：一个次数 $\le jL$ 的一元多项式由 $jL+1$ 个点唯一决定，插值系数是 Lagrange 基，常数项就是这些点取值的定系数线性组合，组合数正好 $jL+1$ 项，每项字符值 $\le\lambda(A)^j$（每项是非零 $\varepsilon$ 处的限制，单调），所以和 $\le(jL+1)\lambda(A)^j$。$(jL+1)$ 是线性开销，$j$ 次根后 $\to 1$，故极限里消失。[推测] 为什么用"张量幂 + 插值"，并非直接对 $F(\varepsilon)$ 插值常数项 $B$：直接插值会把 $L$ 个系数的线性组合的字符值用三角不等式 $\lambda(\sum)\le\sum\lambda$ 放大成 $(L+1)$ 倍，而 $B$ 只出现一次；靠 $j$ 次幂把线性放大 $(jL+1)$ 摊到指数 $j$ 上、取根才压得掉。作者没写这句理由，我标推测。

Lean 侧这一支被做成显式对象：`Character/Degeneration.lean` 的 `value_polynomialRestrictionDegeneration_le` 陈述为"字符公理蕴涵多项式退化下单调，既不假设也不使用字符的连续性"（`:139-141`）。机器证明走 `Polynomial.Interpolation`（`Mathlib.LinearAlgebra.Lagrange`）：`value_coefficient_le`（`:67-85`）把多项式某个系数用 $D+1$ 个求值节点表示（`Tensor.coeff_eq_sum_eval`），再用 `value_scale_le` 把每个节点的标量系数吸收；`value_le_of_polynomialApproximation`（`:89-125`）把张量幂 $(Dn+1)$ 项的线性开销写成 `le_of_pow_le_linear_mul_pow`，正是 tex 那句 "removes their linear interpolation overhead"。我核对到一个与 tex 表面不同的事实：tex 的插值证明靠"取 $j$ 次根"，Lean 靠"用幂次把线性系数摊平"，两者是同一件事的两种记法，但 Lean 版本更贴机器（`Finset.sum_const` + `ring`），我在 §14 记账。

## 4 有限分离：全篇的组合心脏

`270-348` 是本文最"组合"的一节，也是它跟激光法分野最大的地方。命题（`277-290`）：

```tex
\begin{proposition}[Finite separation]\label{prop:separation}
Let $M\geq1$ and
\[
 A=\sum_{h=1}^M A_h,\qquad A_h\in X\otimes Y_h\otimes Z_h,
\]
where the $Y_h$ are disjoint coordinate spaces and so are the $Z_h$.
There are no terms between unmatched second- and third-leg sectors.
Then
\begin{equation}\label{eq:finite-separation}
 A^{\oplus5M}\degen
 \bigoplus_{h=1}^M\bigl(A_h\otimes B_X(M)\bigr).
\end{equation}
Each $A_h$ on the right has its own copy of $X$.
\end{proposition}
```

假设拆开：$A$ 分成 $M$ 个 sector $A_h$，三条腿里 $Y_h,Z_h$ 逐 $h$ 不相交（第 2、3 腿已经独立），第 1 腿 $X$ 全共享；"no terms between unmatched sectors" 就是 $A_h\in X\otimes Y_h\otimes Z_h$ 的含义，交叉项系数为零。结论：$5M$ 份 $A$ 的直和退化到 $M$ 个 $A_h\otimes B_X(M)$ 的**全**直和，每个 $A_h$ 拿到自己的 $X$ 副本。

补推，逐步摊开证明（`292-343`）。取公共第 1 腿基 $x_a$、sector 基 $y_{h,b},z_{h,c}$，写 $A=\sum_{h,a,b,c}c_{h,a,b,c}x_ay_{h,b}z_{h,c}$（内部指标范围可随 $h$ 变，`296-298`）。令 $L=5M$，取本原 $L$ 次单位根 $\zeta$，源复制按 $r=0,\dots,L-1$ 编号。目标变量 $X_{a,g},Y_{h,b,u},Z_{h,c,v}$，$g,u,v\in\{1,\dots,M\}$；$g$ 是"暂定 sector 标签"，$u,v$ 供最后留下的点积。三个替换：
$$x_a^{(r)}\mapsto\sum_g\zeta^{2rg}X_{a,g},\quad y_{h,b}^{(r)}\mapsto\sum_u\zeta^{r(u-h)}Y_{h,b,u},\quad z_{h,c}^{(r)}\mapsto\tfrac1L\sum_v\zeta^{r(-v-h)}Z_{h,c,v}.$$
对 $r$ 求和后，每个目标系数被乘上
$$\tfrac1L\sum_{r=0}^{L-1}\zeta^{r[u-v+2(g-h)]},$$
这是"模 $L$ 相等"的示性函数。$|u-v+2(g-h)|\le 3(M-1)<5M=L$（这里逐项：$|u-v|\le M-1$，$|2(g-h)|\le 2(M-1)$，三角和 $\le3(M-1)$），所以只有满足
$$u-v+2(g-h)=0\tag{eq:fourier, `317-319`}$$
的项存活（因为存活条件是 $L\mid[u-v+2(g-h)]$，而绝对值 $<L$，只能整除当且仅当该数为 $0$）。这里三条腿相位只用到本腿已有的指标（`320-321`），保证这是合法的逐腿线性替换。

第二层：逼暂定标签 $g$ 等于真实 $h$。给目标变量权重
$$w(X_{a,g})=g^2,\quad w(Y_{h,b,u})=hu-h^2,\quad w(Z_{h,c,v})=-hv.$$
在每个存活项上，eq:fourier 给出
$$g^2+hu-h^2-hv=(g-h)^2\ge 0.$$
我验一遍展开：把 $u-v=2(h-g)$（由 eq:fourier 移项）代入 $hu-hv=h(u-v)=2h(h-g)$，于是 $g^2+2h(h-g)-h^2=g^2+2h^2-2hg-h^2=g^2-2hg+h^2=(g-h)^2$。对。权重为零的张量
$$D=\sum_{h,a,b,c,u}c_{h,a,b,c}X_{a,h}Y_{h,b,u}Z_{h,c,u},$$
三条腿都区分 $h$；固定 $h$ 后 $u$ 指标在第 2、3 腿相等，恰好提供一个 $B_X(M)$（对 $u=1..M$ 求和 $Y_{h,b,u}Z_{h,c,u}$，配 $X_{a,h}$ 这个"维度 1 的 $x$"），于是 $D$ 就是 eq:finite-separation 的全直和。变换后张量次数至多 $(M-1)^2$，尽管个体权重可负（`341-342`）。$g,h\in\{1,..,M\}$，$(g-h)^2$ 最大 $(M-1)^2$。

机械理由，逐常数：
- 为什么 $5M$ 份，并非别的：eq:fourier 里 $u-v+2(g-h)$ 的最大绝对值由示性函数"存活 ⟺ 该式 $=0$"逼出，$L$ 只要严格大于最大绝对值 $3(M-1)$ 即可，$5M$ 是 $3M-3<5M$ 里最省事的 $5$。[推测] $5M$ 是"随便挑一个大于 $3M$ 的整数再取整到好记的 $5M$"，真正的约束是 $L>3(M-1)$ 且本原 $L$ 次单位根存在（$\mathbb C$ 里任意 $L$ 都有）。我核对 Lean：`Separation/FiniteProjection.lean:46-56` 的 `fiveMFourierCoefficient_eq_ite` 前提正是 `fourierPhase_dvd_iff_eq_zero` 且界用 `omega` 判定 `phase = u - v + 2(g - h)` 无回绕。
- 权重为什么取 $g^2,hu-h^2,-hv$ 这三项：目标是把存活项的总权重凑成完全平方 $(g-h)^2$（非负），从而常数项恰好是 $g=h$ 的块，其余块被更高权重 $\varepsilon$ 幂推走。$hu-h^2$ 里带 $-h^2$ 是为了配平 $g^2$ 里的平方；$-hv$ 的负号是为了让第 3 腿的相位与第 2 腿的 $+hu$ 相消后留下 $(g-h)^2$。[推测] 若把 $w(X)$ 取 $g$（线性），并非 $g^2$，$g+hu-h-hv=u-v+(g-h)=2(g-h)+$... 用 eq:fourier 代回得 $u-v=-2(g-h)$，总权重 $=g-h-2(g-h)=-(g-h)$，有负权，最小权重不再是常数项、零集也不再只含 $g=h$，整个退化就漏。平方是把符号钉成非负的唯一便宜做法。
- "no terms between unmatched sectors" 这一假设：若存在 $h\ne h'$ 的交叉项，Fourier 存活条件只钉 $u-v+2(g-h)=0$ 里的 $h$，交叉项会被塞进错误的 sector 块，直和结构破坏。$Y_h,Z_h$ 不相交本身就是这条假设的机器。

候选失败路线。其一，[推测] 只用一次 Fourier、不加平方权重：那 $g$ 停在"暂定标签"上、与 $h$ 不等，$X_{a,g}$ 与 $A_h$ 对不上，第 1 腿仍共享，分离失败（分离的核心是把第 1 腿按 $h$ 拆开，这一步非做不可）。其二，[推测] 权重用绝对值 $|g-h|$ 代替 $(g-h)^2$：绝对值不是关于整坐标的多项式权重、无法写成 $\varepsilon$ 幂（退化只允许整数幂 $\varepsilon^{w}$），机器里根本表达不了；换成平方才让"总权重"成为一个可求常数项的多项式次数。其三，[推测] 试图 $3M$ 份复制：$3(M-1)<3M$ 不成立当 $M$ 小时（$3(M-1)<3M$ 其实恒成立，但示性函数要求 $L>3(M-1)$ 且 $\zeta$ 本原阶 $L$；取 $L=3M-2$ 之类虽可行却不整洁，$5M$ 换来一个"绝对值上界与 $L$ 之间留出整 $2M+3$ 的安全垫"，回绕判定 `omega` 一击即中，见 `NoWrap.lean`）。

## 5 共享腿熵不等式：把复制份数换成熵因子

`350-390`。推论（`350-361`）：

```tex
\begin{corollary}[Shared-leg entropy inequality]\label{cor:entropy}
Let $T=\sum_{i=1}^s T_i$ be a sum of nonzero tensors with a common first
space and matched, pairwise disjoint sectors on the other two legs, as
in Proposition~\ref{prop:separation}. For every tensor character
$\lambda$ and every probability vector $q=(q_1,\ldots,q_s)$,
\begin{equation}\label{eq:entropy}
 \lambda(T)\geq
 e^{p_X H(q)}\prod_{i=1}^s\lambda(T_i)^{q_i},
 \qquad H(q)=-\sum_{i=1}^s q_i\log q_i.
\end{equation}
Here logarithms are natural and $0\log0=0$.
\end{corollary}
```

补推（`363-390`），标准固定频率计数。先取 $q$ 为有理、$N$ 跑遍公分母的倍数；在 $T^{\otimes N}$ 的第 2、3 腿只留"$Nq_i$ 次出现 sector $i$"的词；这两腿上的所有支撑项词形相同，于是保留张量 $A$ 有
$$M=\frac{N!}{\prod_i(Nq_i)!}$$
个匹配 sector（第 1 腿仍共享）。每个 sector 是 prescribed $T_i$ 之积（因子重排），字符值 $C_N=\prod_i\lambda(T_i)^{Nq_i}$。由 Prop `prop:separation` + 引理 `lem:interpolation`：
$$5M\lambda(T)^N\ge 5M\lambda(A)\ge M^{1+p_X}C_N.$$
左边第一个 $\ge$：$A$ 是 $T^{\otimes N}$ 的限制（保留某些词），单调给出 $\lambda(A)\le\lambda(T^{\otimes N})=\lambda(T)^N$，再乘 $5M$。第二个 $\ge$：$5M\lambda(A)$ 覆盖 eq:finite-separation 左边 $A^{\oplus5M}$（$A$ 有 $M$ 个匹配 sector），退化到右边 $\bigoplus_h(A_h\otimes B_X(M))$，其字符值 $=\sum_h\lambda(A_h)\lambda(B_X(M))$；取直和可加、$B_X(M)$ 单腿维 $M$ 给 $M^{p_X}$、$M$ 个 sector 各 $C_N$，加出 $M\cdot M^{p_X}\cdot C_N=M^{1+p_X}C_N$。作者把它写成对 $M$ 个 sector 用凸的 AM-GM/直和下界的形式，$5M$ 前缀是 $5M$ 份复制的字符值（$\lambda(5M\cdot)=5M$）。抵消 $M$（$M^{1+p_X}/M=M^{p_X}$ 这一步把"多出的那份 $M$"留下、消掉 sector 计数 $M$ 的一次），取 $N$ 次根：
$$5\lambda(T)\ge M^{p_X/N}\cdot(\text{root of }C_N).$$
$N^{-1}\log M\to H(q)$（Stirling：$\log\frac{N!}{\prod(Nq_i)!}=N\log N-N-\sum(Nq_i\log(Nq_i)-Nq_i)+o(N)$，一次 $N\log N$ 项相消，剩 $-N\sum q_i\log q_i=NH(q)+o(N)$），故 $M^{1/N}\to e^{H(q)}$，于是 $M^{p_X/N}\to e^{p_XH(q)}$。$(C_N)^{1/N}=\prod\lambda(T_i)^{q_i}$。有理情形证毕。再：每个固定 $N$ 退化单调先已建立，不要求退化次数随 $N$ 一致有界（`385-386`）；$\lambda(T_i)\ge1$ 使右边在概率单纯形上连续，有理逼近扩到一切 $q$（`387-389`）。

机械理由：
- 前缀 $e^{p_XH(q)}$ 里为什么恰好是 $p_X$：点积 $B_X(M)$ 留在第 1 腿"退化后自成一 $X$ 副本"的那个 $M$ 维匹配 $u,v$ 上，$p_X$ 正是第 1 腿单腿点积指数（eq:dot）。[推测] 若分离时点积配在第 2 腿，前缀应换成 $e^{p_Y H(q)}$；作者把 $B_X$ 留在第 1 腿，因为第 1 腿是共享腿，把它拆成 $M$ 份后每份自带 $M$ 维辅助，熵增益记在共享腿的指数上最自然。
- 为什么用 $\lambda(T_i)\ge1$ 才谈连续：右边 $\prod\lambda(T_i)^{q_i}$，若某个 $\lambda(T_i)<1$ 则 $q_i\to0$ 时该项爆炸（$0^-$ 型），连续性失效；$1\le\lambda(T_i)$（字符界，`192-193`）保证 $q_i\log\lambda(T_i)\to0$，$0\log0$ 约定把边界钉死。
- 为什么 $5M\lambda(A)\ge M^{1+p_X}C_N$ 里 $C_N$ 是乘积，并非和：每个 sector 是若干 $T_i$ 的张量积（词形固定），字符对张量积是乘，所以 $C_N=\prod_i\lambda(T_i)^{Nq_i}$；$M$ 个 sector 的直和才是和，被 $M^{1+p_X}$ 吸收。

候选失败路线。其一，[推测] 不做频率限制、留全部 $\otimes N$ 词：那 $A$ 里的 sector 不再"匹配"（第 2、3 腿词形不同），Prop `prop:separation` 的前提直接不满足，退化给不出全直和。固定频率这一步是"让第 2、3 腿词形一致"的机制，不是可有可无的技巧。其二，[推测] 试图用最大项，并非全部匹配 sector：渐近上 $M$ 由最大多项式系数控制、只丢一个 $N$ 次多项式因子，取 $N$ 次根消失，所以"取全部"与"取最大"在 $\omega$ 层面等价；但作者取全部是因为要精确的不等式链 $5M\lambda(A)\ge M^{1+p_X}C_N$（$\lambda(A)$ 覆盖的是整个直和，不是单块），[推测] 这是形式化友好的选择，Lean 里 `Entropy/Tag.lean` 把 $M=\binom{N}{Nq}$ 的多重组合计数直接写出来。

## 6 多项式乘积张量与对称化 profile：把组合界兑换成一条函数不等式

`392-431` 进入用分离不等式约束的那个具体张量族。对正整数 $a,b$ 定义（`396-398`）：

```tex
\begin{equation}\label{eq:convolution}
 C(a,b)=\sum_{i=0}^{a-1}\sum_{j=0}^{b-1}x_i y_j z_{i+j}.
\end{equation}
```

这是次数 $a-1$ 与 $b-1$ 二元齐次形式的乘法、配输出空间的对偶；输出向量长 $a+b-1$。秩（`400-406`）：在 $a+b-1$ 个不同点求值再插值给 $\operatorname{R}(C(a,b))\le a+b-1$；输出展平秩恰为 $a+b-1$（每个输出单项式都是输入单项式之积），故
$$\operatorname{R}(C(a,b))=a+b-1.\tag{eq:convolution-rank}$$

补推。上界的账：求值把两个多项式映成 $a+b-1$ 个点上的乘积，插值把点值映回系数；每一步是关于 $x$、关于 $y$ 的线性代入、关于 $z$ 的对偶，合起来是 $a+b-1$ 个 rank-one 张量之积的和，$\operatorname{R}\le a+b-1$。下界的账：输出展平是矩阵 $M_{(a+b-1)\times ab}$，第 $k$ 行（对应 $z_k$）在某列 $(i,j)$（对应 $x_iy_j$）为 $1$ 当且仅当 $i+j=k$；对每个 $k\in\{0,..,a+b-2\}$ 都能挑一个合法的 $(i,j)$（$i=\min(k,a-1),j=k-i$），这些挑出的列给一个 $(a+b-1)\times(a+b-1)$ 的单位下三角 minor，故展平秩 $\ge a+b-1$。两侧合起来是 eq:convolution-rank。Lean 侧上界用 `Mathlib.LinearAlgebra.Lagrange`（`Convolution/Rank.lean:22-59`，节点取 `fun r => r.val` 即 $0,1,..,a+b-2$），下界用 `Convolution/RankLowerBound.lean:23-45` 的 `convolution_identity_minor` + `card_le_of_identity`，与上面"挑列成单位 minor"逐字对应。

现在固定字符 $\lambda$，$t=(p_X+p_Y+p_Z)/3>0$，$\lambda_\pi(A)$ 表示把 $A$ 的腿按 $\pi\in S_3$ 置换后再取 $\lambda$（`408-411`）；每个 $\lambda_\pi$ 仍字符，其第 1 腿点积指数记 $p_X^{(\pi)}$。原三指数各出现两次，于是
$$\sum_{\pi\in S_3}p_X^{(\pi)}=2(p_X+p_Y+p_Z)=6t.\tag{eq:permutation-sum}$$
对称化 profile（`419-422`）：
$$P(a,b)=\Big(\prod_{\pi\in S_3}\lambda_\pi(C(a,b))\Big)^{1/(6t)}.$$
`423-429` 给基本性质：交换两输入腿只是重排积里的因子，故 $P(a,b)=P(b,a)>0$；$C(1,b)=B_X(b)$ 给 $P(1,b)=b$；再配上 eq:convolution-rank 与 eq:permutation-sum，得
$$P(a,b)=P(b,a)>0,\quad P(1,b)=b,\quad P(a,b)\le(a+b-1)^{1/t}.\tag{eq:profile-basic}$$

补推 $P(1,b)=b$ 的账：六置换里 $C(1,b)$ 是 $B_X(b)$（第一腿维度 1 的点积），六个 $\lambda_\pi(C(1,b))$ 就是三个不同点积 $B_X(b),B_Y(b),B_Z(b)$ 各取两次（因为对 $B_X$ 施加 $S_3$ 的六个置换，落在三种"哪条腿是维 1"上，每种两次）。于是 $\prod_\pi\lambda_\pi(C(1,b))=(b^{p_X}\cdot b^{p_Y}\cdot b^{p_Z})^2=b^{2(p_X+p_Y+p_Z)}=b^{6t}$，取 $1/(6t)$ 次幂正好 $b$。这就是 eq:permutation-sum 里"各出现两次"的全部意义：把 $6t$ 与 $2(p_X+p_Y+p_Z)$ 对齐，边界值才干净。补推 $P(a,b)\le(a+b-1)^{1/t}$：每个 $\lambda_\pi(C(a,b))\le\operatorname{R}(C(a,b))=a+b-1$（字符被秩界住，`193`），六个因子乘积 $\le(a+b-1)^6$，取 $1/(6t)$ 次幂给 $\le(a+b-1)^{6/(6t)}=(a+b-1)^{1/t}$。

机械理由，逐常数：
- 为什么用六个置换的乘积再取几何平均，并非单个 $\lambda(C(a,b))$：`417-419` 说"所有六个置换让 profile 对下面用到的腿交换不敏感"。§8 三扇区里中间那块要把 $C$ 的第 2、3 腿对调（引理证明里 $\sigma$），若 $P$ 依赖具体某个 $\lambda$，对调会换成 $\lambda_\sigma$、profile 就不是同一个数；对称化后 $P$ 对腿置换不变，两块比较才能同除 $6t$。这是标准的"balancing device"（`416-417` 引 LG14 Appendix A.3）。
- 归一化指数取 $1/(6t)$：$6t=\sum_\pi p_X^{(\pi)}$（eq:permutation-sum），取这个均值的倒数做归一，才让边界 $P(1,b)=b$ 精确等于 $b$（，并非 $b^{1/(3t)}$ 之类），并让 §9 的 rank 上界里 $1/t$ 恰好是 $6/(6t)$。[推测] 若把归一化取成 $1/(p_X+p_Y+p_Z)=1/(3t)$ 会差一个 $2$ 次幂，边界值变成 $\sqrt b$，整条 §9 的增长率之比就错。
- $t>0$ 的再次用处：$1/(6t)$ 与 $1/t$ 都要 $t\ne0$，`408` 那句 $t>0$ 是为 profile 定义本身兜底。

候选失败路线。其一，[推测] 只用三个循环置换 $\{id,\text{cyc},\text{cyc}^2\}$ 而不含对合：那 §8 中间块的"腿对调"$\sigma$ 不在这个集合里，$P$ 对 $\sigma$ 不闭合，tripling 不等式右边混进未归一的因子。必须整个 $S_3$ 六元。其二，[推测] 试图不归一、直接对 $\prod\lambda_\pi$ 取 $1/6$：则 $P(a,b)$ 的量纲是"字符值的几何平均"，并非 $t$ 归一，rank 上界给的是 $(a+b-1)^{6/6}=(a+b-1)$、没有 $1/t$，§9 的两条增长率比不出 $t\le3/4$。$1/t$ 这个 $t$ 依赖的归一化是把字符值"拉回维数单位"的关键。

## 7 行列式过滤与离散凹性：$2P(a,b)\ge P(a,b+1)+P(a,b-1)$

`433-522`。这是约束 $P$ 对角增长的第一条不等式。引理（`442-448`）：

```tex
\begin{lemma}[Discrete concavity]\label{lem:concavity}
For $a\geq1$ and $b\geq2$,
\begin{equation}\label{eq:concavity}
 2P(a,b)\geq P(a,b+1)+P(a,b-1).
\end{equation}
By symmetry, the analogous inequality holds in the first argument.
\end{lemma}
```

策略（`434-439`）：与 $B_X(2)$ 张量积，它把第 2 输入与输出空间都翻倍，然后在合适的商空间与核空间上保留诱导的乘法；过滤必须被"每一个第 1 输入的乘法"保持，比较才成整个张量的退化。

补推，这段是全篇最代数的一步，我逐层补。$V_e$ 是 $u,v$ 的 $e$ 次齐次形式，$W_1=\operatorname{span}(s,w)$。$C(a,b)\otimes B_X(2)$ 表示 $V_{a-1}\times(V_{b-1}\otimes W_1)\to V_{a+b-2}\otimes W_1$。令 $D=uw-vs$，对角替换 $(s,w)=(u,v)$（此时 $D\mapsto uv-vu=0$）。$e\ge1$ 时有正合列（`460-463`）：
$$0\to DV_{e-1}\to V_e\otimes W_1\to V_{e+1}\to0.$$
补维数账：$\dim V_e=e+1$，$\dim W_1=2$，故 $\dim(V_e\otimes W_1)=2(e+1)$；$\dim V_{e+1}=e+2$，$\dim DV_{e-1}=e$（$D$ 乘进 $V_{e-1}$ 单射）。右侧满射在单项式上成立（$u^{e+1-i}v^i s,u^{e-i}v^i w$ 里把 $s\mapsto u,v\mapsto v$... 商到 $V_{e+1}$ 的单项式），核含 $DV_{e-1}$ 且 $\dim\ker=2(e+1)-(e+2)=e=\dim DV_{e-1}$，$D$ 乘入单射（整环里没有零因子），于是正合。这就是次数 1 的 Clebsch-Gordan 分解背后的行列式正合列（`467-469`，Kow14 §2.6）。

商提升的选取（`472-477`）：取 $u^{e-i}v^is$（$0\le i\le e$）再补 $v^ew$，共 $e+2$ 个（对应商 $V_{e+1}$ 的维），后面接核基 $Du^{e-1-j}v^j$（$0\le j<e$，共 $e$ 个）。这两组在对角像与核因子上都是标准单项式基。在次数 $b-1$ 与 $a+b-2$ 用这两组基。

关键的兼容性（`478-490`）：对每个 $f\in V_{a-1}$，乘法与对角替换交换，且把 $Dg$ 送到 $D(fg)$。于是每个第 1 腿切片都有分块形（`480-486`）：

```tex
 \begin{array}{c|cc}
  &\text{input quotient}&\text{input kernel}\\ \hline
  \text{output quotient}&M_f^{+}&0\\
  \text{output kernel}& * &M_f^{-}
 \end{array}
```

其中 $M_f^+$ 是乘法 $V_b\to V_{a+b-1}$（即 $C(a,b+1)$ 的一个切片），$M_f^-$ 是 $V_{b-2}\to V_{a+b-3}$（即 $C(a,b-1)$）。"input kernel 到 output quotient"那一格是 $0$，正因 $Dg\mapsto D(fg)$ 仍落在核里、不会污染商。"input quotient 到 output kernel"那格标 $*$，可有非零（`499-501` 举例 $a=b=2$ 时 $u(vw)=v^2s+vD$，一个商提升的乘积同时有商与核分量）。

权重与退化（`492-498`）：给第 1 腿与所有商坐标权重 $0$，第 2 腿核坐标 $-1$，输出对偶核坐标 $+1$。那么 $*$ 格的一个项总权重 $=0($输入商$)+(-1)($输入核? no: $*$ 是"输入商到输出核"，输入商权 0、输出核权 +1$)$... 逐项：一个从"输入商(权0)到输出核(权+1)"的系数权重是 $0+0+1=+1$（三腿各 $0,0,+1$），正、消失；"输入核(权-1)到输出商(权0)"本应为 $-1$、是那个 $0$ 格，正因它是 $0$ 才没有负权项（`494-495` "The only potentially negative block is zero"）。权重为零的张量因此恰由 $C(a,b+1)$（商-商块，权 $0+0+0$）与 $C(a,b-1)$（核-核块，权 $0+(-1)+(+1)=0$）组成，共享第 1 腿、第 2、3 腿不相交。

兑换成字符不等式（`503-521`）。对退化用 `lem:interpolation` + Cor `cor:entropy` 于这两块，任意概率对 $q=(q_+,q_-)$：
$$2^{p_X^{(\pi)}}\lambda_\pi(C(a,b))\ge e^{p_X^{(\pi)}H(q)}\lambda_\pi(C(a,b+1))^{q_+}\lambda_\pi(C(a,b-1))^{q_-}.$$
左边前缀 $2^{p_X^{(\pi)}}$ 来自源张量 $C(a,b)\otimes B_X(2)$ 里的 $B_X(2)$ 字符值 $=2^{p_X^{(\pi)}}$（对 $\lambda_\pi$ 而言是它的第 1 腿点积）。对所有六个字符用同一个 $q$，乘起来、取 $1/(6t)$，用 eq:permutation-sum 把六个 $p_X^{(\pi)}$ 换成 $6t$：
$$2P(a,b)\ge e^{H(q)}P(a,b+1)^{q_+}P(a,b-1)^{q_-}.$$
正数 $A,B$ 上 $e^{H(q)}A^{q_+}B^{q_-}$ 的最大值是 $A+B$，在 $q=(A,B)/(A+B)$ 取到（`516-519`：正 $q_\pm$ 用对 $A/q_+,B/q_-$ 的加权 AM-GM，边界由连续）。取这对共同的极大 $q$ 就证 eq:concavity。

机械理由：
- 权重取 $-1,0,+1$：核-核块要留常数，其 $Y$ 腿权 $-1$、$Z$ 腿权 $+1$（对偶核）之和为 $0$；商-商块本就全 $0$；被丢弃的 $*$ 块要正（$+1$）才能退化掉；那唯一可能负的"核-商"块必须是 $0$。这套 $(-1,+1)$ 的对称是Clebsch-Gordan 正合列里 $\deg D=+1$（核）对偶（输出对偶 $\deg=-1$）的直接翻译。[推测] 若把两者都取正，核-核块就不是最小权、退化留不住它。
- 为什么 $q_+,q_-$ 要对六个字符取同一个：eq:permutation-sum 的合并 $\sum_\pi p_X^{(\pi)}=6t$ 只在每个字符的熵因子都是同一个 $e^{H(q)}$ 时才凑得齐；不同 $q$ 会让六个 $e^{p_X^{(\pi)}H(q_\pi)}$ 不能并成一个 $e^{H(q)\cdot(\text{something})}$。
- $b\ge2$ 的下界：$b-1\ge1$ 才让 $C(a,b-1)$ 是个正维张量（$V_{b-2}$ 非空需 $b-2\ge0$ 且输出 $V_{a+b-3}$ 有意义）。$b=1$ 时 $C(a,0)$ 退化，凹性陈述失去意义，所以限定 $b\ge2$。

候选失败路线。其一，[推测] 不用正合列、直接对 $C(a,b)$ 单独求值插值：那样得不到"$C(a,b+1)$ 与 $C(a,b-1)$ 共享 $X$、另两腿不相交"这一分离结构，熵不等式用不上，只能得到 $P$ 的一个平凡上界。过滤的作用恰恰是制造可分离的两块。其二，[推测] 商提升的基选得与核基不对齐（`478-479` "对角像与核因子都是标准单项式基"），那 $M_f^+,M_f^-$ 就不是干净的 $C(a,b\pm1)$、切片形状破坏，权重账里核-核块对不上 $C(a,b-1)$。其三，[推测] 想让"输入核到输出商"格非零：那会引入负权项、最小权不再是常数项，整个退化定义失效；正合性（那格 $=0$）是 $Dg\mapsto D(fg)$ 落在核里的必然结果，不是可选项。

## 8 三扇区与移位三倍：$P(a,3h+a-1)\ge3P(a,h)$

`524-603`。第二条约束。引理（`526-531`）：

```tex
\begin{lemma}[Shifted tripling]\label{lem:tripling}
For all positive integers $a,h$,
\begin{equation}\label{eq:tripling}
 P(a,3h+a-1)\geq3P(a,h).
\end{equation}
\end{lemma}
```

补推，扇区的边界我逐格摊开。令 $B=3h+a-1$；$C(a,B)$ 的支撑项指标 $0\le x<a,0\le y<B,z=x+y$。$Y$ 与 $Z$ 的划分（`537-543`）：

$$\begin{array}{c|ccc} &\text{left}&\text{middle}&\text{right}\\ \hline Y &[0,h-1]&[h,2h+a-2]&[2h+a-1,3h+a-2]\\ Z &[0,h+a-2]&[h+a-1,2h+a-2]&[2h+a-1,3h+2a-3].\end{array}$$

数一下每段长度：$Y$ 左段 $h$ 个（$0$ 到 $h-1$），中段 $2h+a-2-h+1=h+a-1$ 个，右段 $3h+a-2-(2h+a-1)+1=h$ 个，合计 $h+(h+a-1)+h=3h+a-1=B$，对。$Z$ 左段 $h+a-1$ 个（$0$ 到 $h+a-2$），中段 $h$ 个（$h+a-1$ 到 $2h+a-2$），右段 $a+h$ 个（$2h+a-1$ 到 $3h+2a-3$，即 $3h+2a-3-(2h+a-1)+1=h+a$），合计 $(h+a-1)+h+(h+a)=3h+2a-2=(B+a-1)$，正是输出 $C(a,B)$ 的长度 $a+B-1$，对。

权重（`544-547`）：middle $Y$ 坐标权 $+1$，middle $Z$ 坐标权 $-1$，其余 $0$。左 $Y$ 指标 $y\le h-1$ 逼 $z=x+y\le(a-1)+(h-1)=h+a-2$，落左 $Z$，权 $0+0=0$；右 $Y$ 指标 $y\ge2h+a-1$ 逼 $z=x+y\ge0+(2h+a-1)=2h+a-1$，落右 $Z$，权 $0$。于是没有支撑项有负权（负权只可能来自"middle $Z$ 配非 middle $Y$"，但 middle $Z$ 意味着 $z\ge h+a-1$... 需 $y=z-x\ge h+a-1-(a-1)=h$，且 $z\le2h+a-2$ 逼 $y\le2h+a-2$，若 $y\le2h+a-2$ 则 $y$ 落 middle $Y$，权 $+1$，总权 $+1-1=0$；只有 middle $Y$ 配非 middle $Z$ 才权 $+1>0$）。权重为零的部分恰是三个匹配扇区。`549` 举例见图（$a=2,h=1$ 时 $C(2,4)$ 的最小非平凡退化，三阴影块留、两交叉消）。

三块的重认（`581-590`）：平移把两个外支认成 $C=C(a,h)$。中间支是
$$\sum_{u=0}^{a-1}\sum_{r=0}^{h-1}x_{a-1-u}y_{h+u+r}z_{h+a-1+r},$$
它是 $C$ 把第 2、3 腿对调、第 1 腿基反向（$u\mapsto a-1-u$）。反向在这单独一支上做，三支不施加不同的第 1 腿映射（`588-590`，这一句我在 §7 失败路线三看到它的一致性要求）。

兑换成字符不等式（`592-603`）。记 $\sigma$ 对调第 2、3 腿。三支上的均匀概率给
$$\lambda_\pi(C(a,B))\ge3^{p_X^{(\pi)}}\lambda_\pi(C)^{2/3}\lambda_\pi(C^\sigma)^{1/3}.$$
前缀 $3^{p_X^{(\pi)}}$ 是分离出的 $M=3$（三扇区）给的 $B_X(3)$ 字符值 $=3^{p_X^{(\pi)}}$；$2/3$ 因为在 $C(a,h)$ 的两个外支、$1/3$ 因为中间的 $C^\sigma$。$\sigma$ 复合只是重排六个腿置换，故 $\prod_\pi\lambda_\pi(C^\sigma)=\prod_\pi\lambda_\pi(C)$。六式相乘、取 $1/(6t)$：左 $\prod_\pi\lambda_\pi(C(a,B))$ 给 $P(a,B)^{6t}$；右 $3^{\sum p_X^{(\pi)}}=3^{6t}$，再乘 $\big(\prod\lambda_\pi(C)\big)^{2/3+1/3}=\big(\prod\lambda_\pi(C)\big)=P(a,h)^{6t}$。取 $1/(6t)$ 得 $P(a,B)\ge3P(a,h)$，即 eq:tripling。

机械理由：
- 为什么中段长度配成 $h+a-1$（$Y$ 中）与 $h$（$Z$ 中），并非三等分：$z=x+y$ 且 $x\in[0,a-1]$，一个 $y$ 平移 $x$ 会扫出长度 $a$ 的窗口，所以"left $Y$ ⟹ left $Z$"的边界 $h+a-2$ 必须把 $Y$ 的左界 $h-1$ 加满 $x$ 的最大值 $a-1$；中段因此被夹在 $[h,2h+a-2]$。这个 $+a-1$ 的偏移，正是 eq:tripling 里 $3h+a-1$ ，并非 $3h$ 的全部来源：如果强行三分成 $h$，左右两支与中间的 $x$ 会越界、支撑项落到相邻扇区、权非零，三块不再全留。$a-1$ 是"最坏情形 $x$ 造成的输出拖尾"。
- 为什么外支权重全 $0$、middle 用 $\pm1$：需要"left $Y\to$ left $Z$"、"right $Y\to$ right $Z$"自然配对（不靠退化就能留），只需把"跨扇区"的项（middle $Y$ 配 outer $Z$）用正权推走，用 $+1/-1$ 让"middle $Y$ 配 middle $Z$"的合法项权 $0$ 保留。[推测] 中间支之所以腿对调 $C^\sigma$：$z=x+y$ 在中间带上写成 $z' = y'+x'$ 时 $x,y$ 的角色互换，这是区间几何决定的，不是可选择的。
- $3^{p_X^{(\pi)}}$ 里 $p_X$（第 1 腿），并非 $p_Y$：分离定理 `prop:separation` 把点积 $B_X(M)$ 留在共享的第 1 腿（见 §5 机械理由），三支共享 $x_0,..,x_{a-1}$（`575` 图注"share $x_0,x_1$"），所以熵前缀记在第 1 腿指数 $p_X$ 上。

候选失败路线。其一，[推测] 把三支都认成 $C(a,h)$（不做中间的对调）：中间支的实际支撑方程是 $z'=h+a-1+r,y'=h+u+r,x'=a-1-u$，硬认成 $C$ 会让 $x$ 与 $r$ 的相加方向反了、$z=x+y$ 对不上，只有对调第 2、3 腿并反向第 1 腿才把中间支认成合法的 $C^\sigma$。其二，[推测] 试图 $P(a,3h)\ge3P(a,h)$（不含 $+a-1$）：如上面边界账，$Y$ 总长要 $3h$ 就得去掉拖尾 $a-1$，但拖尾是 $x$ 的必然产物，去掉后 middle/right 边界重叠、跨扇区项变正权、留不住三块，tripling 不成立。这个 $+a-1$ 是"移位三倍"名字里的移位。其三，[推测] 只留两支（left + right，各 $C$）：那前缀 $2^{p_X}$、右边 $\lambda_\pi(C)^1$，给的是 $P(a,\cdot)\ge2P(a,h)$ 型、系数 $2$ ，并非 $3$，§9 的对角增长率从 $4/3$ 退到别值，最后比不出 $3/4$。三支才给 $3$。

## 9 离散增长：把凹性与移位三倍拧成 $P(a,a)\ge a^{4/3}$

`605-650`，纯不等式账，张量全部退场。引理（`610-615`）：

```tex
\begin{lemma}[Diagonal growth]\label{lem:growth}
Let $P:\N_{>0}^2\to\R_{>0}$ be symmetric, with $P(1,b)=b$.
Suppose it satisfies \eqref{eq:concavity} for $a\geq1,b\geq2$ and
\eqref{eq:tripling} for $a,h\geq1$. Then
$P(a,a)\geq a^{4/3}$ for every $a\geq1$.
\end{lemma}
```

这里 $P$ 只当作满足四条性质的抽象函数（对称、边界 $P(1,b)=b$、凹性、移位三倍），张量构造的活儿在 §6-§8 已经交付。补推，我把每一行不等式的来源摊开。

第 1 步，增量单调。对固定 $a$，凹性 eq:concavity 说 $2P(a,h)\ge P(a,h+1)+P(a,h-1)$，即 $\Delta_{a,h}=P(a,h+1)-P(a,h)$ 关于 $h$ 不减的反向：$\Delta_{a,h}\le\Delta_{a,h-1}$，即 $\Delta_{a,h}$ 在 $h$ 上非增。

第 2 步，斜率下界。记 $D_a=P(a,a)$、$H_a=2D_a/(3a-1)$。tripling eq:tripling 取 $h=a$：$P(a,3a+a-1)=P(a,4a-1)\ge3P(a,a)=3D_a$，于是
$$2D_a\le P(a,4a-1)-D_a=\sum_{h=a}^{4a-2}\Delta_{a,h}\le(3a-1)\Delta_{a,a}.$$
中间那步是望远镜：$P(a,4a-1)-P(a,a)=\sum_{h=a}^{4a-2}[P(a,h+1)-P(a,h)]$，项数 $(4a-2)-a+1=3a-1$。右端把每个 $\Delta_{a,h}$（$h\ge a$）换成最大的 $\Delta_{a,a}$（非增，故 $h=a$ 处最大）。于是 $\Delta_{a,a}\ge2D_a/(3a-1)=H_a$。

第 3 步，对角递推。$a\ge2$ 时用对称与凹性夹两个相邻对角值的差：
$$D_a-D_{a-1}=\big[P(a,a)-P(a,a-1)\big]+\big[P(a,a-1)-P(a-1,a-1)\big].$$
由对称 $P(a,a-1)=P(a-1,a)$，第二方括号 $=P(a-1,a)-P(a-1,a-1)=\Delta_{a-1,a-1}$，第一个 $=\Delta_{a,a-1}$。于是（eq:diagonal-rec, `628-632`）
$$D_a-D_{a-1}=\Delta_{a-1,a-1}+\Delta_{a,a-1}\ge H_{a-1}+H_a,$$
这里 $\Delta_{a-1,a-1}\ge H_{a-1}$（第 2 步用在行 $a-1$），$\Delta_{a,a-1}\ge\Delta_{a,a}\ge H_a$（非增，$a-1<a$）。

第 4 步，归一化递推。把 $D_a=(3a-1)H_a/2$（$H_a$ 定义反解）代进第 3 步：
$$\tfrac{3a-1}{2}H_a-\tfrac{3a-4}{2}H_{a-1}\ge H_{a-1}+H_a.$$
两边乘 $2$ 并把 $H_a$ 项归左、$H_{a-1}$ 归右：$(3a-3)H_a\ge(3a-2)H_{a-1}$，即
$$H_a\ge\frac{3a-2}{3a-3}H_{a-1}=\Big(1+\frac{1}{3(a-1)}\Big)H_{a-1}\quad(a\ge2).$$
从 $H_1=1$（因 $D_1=P(1,1)=1$，$H_1=2/(3-1)=1$）迭代，换指标 $m=a-1$：
$$H_a\ge\prod_{m=1}^{a-1}\Big(1+\frac{1}{3m}\Big).$$

第 5 步，三次方与望远镜。对 $m\ge1$ 有 $(1+\tfrac1{3m})^3=1+\tfrac1m+\tfrac1{3m^2}+\tfrac1{27m^3}\ge1+\tfrac1m$（丢两个正项）。于是
$$H_a^3\ge\prod_{m=1}^{a-1}\Big(1+\tfrac1m\Big)^3\ge\prod_{m=1}^{a-1}\Big(1+\tfrac1m\Big)=\prod_{m=1}^{a-1}\tfrac{m+1}{m}=a.$$
故 $H_a\ge a^{1/3}$。末行：$(3a-1)/2\ge a$（即 $3a-1\ge2a$，$a\ge1$），所以 $D_a=\tfrac{3a-1}{2}H_a\ge aH_a\ge a\cdot a^{1/3}=a^{4/3}$。

机械理由：
- $H_a=2D_a/(3a-1)$ 里那个 $3a-1$：是第 2 步望远镜的项数，被 tripling 的 $h=a\to4a-1$ 跨度 $4a-1-a=3a-1$ 决定。[推测] 若 tripling 是 $P(a,3h)\ge3P(a,h)$（无 $+a-1$），跨度变 $3h-1=3a-1$ 时恰好巧合，但 $h=a$ 时 $4a-1$ 与 $3a$ 差一个 $a-1$，递推里的系数会变，$\prod(1+1/(3m))$ 里的 $3$ 未必还是 $3$。这个"分母 $3$"和三倍、对角跨度 $3a-1$ 之间的耦合，是 §8 那个移位 $\,+a-1$ 一路传下来的。
- $(1+1/(3m))^3\ge1+1/m$：三次方是"把乘积 $\prod(1+1/(3m))$ 与望远镜 $\prod(1+1/m)=a$ 挂上"的桥梁。选三次方，并非平方，是因为 $(1+1/(3m))^2=1+2/(3m)+1/(9m^2)<1+1/m$ 当 $2/(3m)<1/m$ 不成立（其实 $2/3<1$ 恒成立，所以平方给的是 $1+2/(3m)+\cdots$，$2/(3m)$ 对 $1/m$ 有 $2/3$ 系数，积不出 $a$），只有三次方让系数 $3\cdot(1/3)=1$ 精确对上望远镜。这解释了 $4/3=1+1/3$ 里的 $1/3$：它来自"三次方让 $1/(3m)$ 变成 $1/m$"。
- 起点 $H_1=1$：边界 $P(1,b)=b$ 给了 $D_1=P(1,1)=1$，$H_1=2\cdot1/(3\cdot1-1)=1$，迭代才有非零底。[推测] 若 $P(1,b)$ 达不到精确的 $b$、只满足 $\ge cb$，$H_1$ 变成 $c$，整个 $H_a\ge c\cdot(\text{telescope})$ 乘上 $c$，对角下界变 $c\cdot a^{4/3}$，§10 里 $c^{1/3}$ 会漏进 $t$ 界。所以 §6 的归一化 $1/(6t)$ 把 $P(1,b)$ 精确钉成 $b$（既不放宽到 $\ge$ 也不收紧到 $\le$）至关重要。

Lean 侧这段最见功力，`Growth/Recurrence.lean` 把上述五步重做成一条同时归纳 $g$（斜率）与 $D$（对角）的机器。它不直接用 $H_a$，而用行斜率极限 $g_a$（`Growth/Profile.lean:39-64` 的 `exists_row_slope`：凹性给每行增量有极限 $g_a=\lim P(a,h)/h$ 且 $g_a\le\Delta_{a,h}$ 对所有 $h$）。第 2、3 步合成两条假设 `hupper : D_a ≤ (3a-1)/2 · g_a` 与 `hincrement : D_a + g_a + g_{a+1} ≤ D_{a+1}`（`Profile.lean:81-104`，由 tripling 与对称凹性得）。核心一步 `growthRecurrence_step_real`（`Recurrence.lean:18-43`）把 $(1+\tfrac1{3n})G_{prev}\le g_{next}$ 与 $(3(n+1)-1)/2\cdot(1+\tfrac1{3n})G_{prev}\le D_{next}$ 一起证，用 `positivity`（分母 $3n>0$）与 `nlinarith` 打完。望远镜积写成 `growthProduct`（`Recurrence.lean:121-136`），$n^4\le D_n^3$ 的精确形式在 `diagonal_fourth_power_lower`（`:140-163`）里由 `pow_le_pow_left₀` + `mul_le_mul_of_nonneg_left` + 一句 `ring` 收尾。[推测] 机器选"极限斜率 $g$"，并非"$H_a$ 递推"是为了回避离散 $\Delta$ 的单调方向在边界 $h=1$ 处的细节，用 `Tendsto` 拿现成的单调收敛定理更稳。

## 10 收口到 $\omega\le9/4$：增长率之比、整数舍入、递归与补零

`652-697` 是 Theorem 1.1 的证明，三段。

第一段，字符侧 $t\le3/4$。补推。每个字符的 profile（§6-§8 造的 $P$）满足 §9 全部假设，配上 eq:profile-basic：
$$a^{4/3}\le P(a,a)\le(2a-1)^{1/t}.$$
（右端把 eq:profile-basic 的 $P(a,b)\le(a+b-1)^{1/t}$ 用在 $b=a$，$2a-1$。）$a\to\infty$：左边 $\sim a^{4/3}$、右边 $\sim a^{1/t}$（$2a-1\sim2a$，常数底进不了幂次比较），要 $a^{4/3}\le a^{1/t}\cdot(\text{const})^{1/t}$ 恒成立只能 $4/3\le1/t$，即 $t\le3/4$。于是 $p_X+p_Y+p_Z=3t\le9/4$，配 eq:character-mm 得 $\lambda(T_d)\le d^{9/4}$ 对每个字符。[推测] 这一步"常数 $(2)^{1/t}$ 不进幂次比较"是 $a\to\infty$ 的渐近吞并；若 $t=3/4$ 恰成立，$4/3=1/t$，常数项决定有限尺寸，但本定理只要渐近，$t\le3/4$ 的 $\le$ 足够。Lean 侧 `Arithmetic/ExponentComparison.lean` 的 `diagonal_exponent_le_three_quarters` 用 `rpow_exponent_le_of_nat_bound`（`:19-40`）把 $n^4\le2^{(1/t)3}n^{3/t}$ 对所有 $n\ge1$ 成立推成 $4\le(1/t)3$，靠的是"取 $n=2^k$、比较对数、用 `exists_nat_gt` 找 $k$ 翻越常数"，文件头注释 `9-13` 明确写"比较幂次只需 $2$ 的幂，不用渐近估计或常数逼近"，这是本篇唯一不靠 `Tendsto` 而靠离散取点硬比的极限。

第二段，整数舍入拿 $\nu\le9/4$。补推。对每个 $d\ge2$ 取 $k_d=\lceil d^\nu\rceil-1$，则 $d^\nu-1\le k_d<d^\nu$。右不等式 $k_d<d^\nu$ 触发 Lemma `lem:existence`，供一个字符使 $\lambda(T_d)\ge k_d$；左不等式 $d^\nu-1\le k_d$ 串起来：
$$d^\nu-1\le k_d\le\lambda(T_d)\le d^{9/4}\implies d^\nu\le d^{9/4}+1.$$
取对数、$d\to\infty$：$\nu\le9/4$。`669-670` 强调检测字符可依赖 $d$，但上界对所有字符一致。这就是"为什么需要 §11 那个存在性引理"：我不知具体哪个字符，但 $\lambda(T_d)\le d^{9/4}$ 对全体字符成立，而存在某个字符顶到接近 $d^\nu$，两者夹出 $\nu$。Lean 侧 `Arithmetic/CharacterRounding.lean` 把 $k_d=\lceil x\rceil-1$ 写成 `exists_nat_sub_one_le_lt`（`:22-29`，用 `Nat.ceil` + `Nat.ceil_eq_iff`），"加一不动正幂指数"写成 `rpow_exponent_le_of_nat_sub_one_bound`（`:33-44`，$d^\nu-1\le d^\tau$ 对所有 $d\ge2$ ⟹ $\nu\le\tau$，靠 $1\le d^\tau$ 使 `linarith` 吃下那个 $-1$）。最外层 `exactRankExponent_le_nine_quarters_of_characters`（`:111-118`）用 `exponent_le_of_detecting_characters (by norm_num)`，那个 `norm_num` 证的正是 $0\le9/4$。

第三段，$\nu$ 兑换成算术操作数，即 Theorem 1.1 前半。补推。固定 $\varepsilon>0$，取 $0<\delta<\varepsilon$。$\nu$ 的定义供固定整数 $u\ge2$ 与 $T_u$ 的一个长度 $r<u^{9/4+\delta}$ 的精确秩分解。其双线性恒等式在矩阵块上仍成立（系数是中心标量，每个积的左输入块在其右输入块之前）。$N$ 为 $u$ 的幂时递归代价
$$S(N)\le r\,S(N/u)+C_{u,r}(N/u)^2.$$
展平给 $r\ge u^2$（因 $\operatorname{R}(T_u)\ge u^2$）。求和逐层：主定理式（$a=r$ 个子问题、合并代价 $n^2$）：若 $r>u^2$，$S(N)=O(N^{\log_u r})$；若 $r=u^2$，$S(N)=O(N^2\log N)$。二者都 $O_\varepsilon(N^{9/4+\varepsilon})$，因 $\log_u r<\log_u u^{9/4+\delta}=9/4+\delta<9/4+\varepsilon$，而 $r=u^2$ 时 $2<9/4$ 使 $N^2\log N\ll N^{9/4+\varepsilon}$。把任意 $n$ 补零到下一个 $u$ 的幂，尺寸放大不足固定因子 $u$，得证。

机械理由：
- 递归代价 $S(N)\le rS(N/u)+C_{u,r}(N/u)^2$ 里合并项是 $(N/u)^2$ ，并非 $r(N/u)^2$：`674-678` 那句 "coefficients are central scalars" 允许把 $r$ 组系数预先加进常数 $C_{u,r}$，故每块输出的线性组合是 $O((N/u)^2)$ 个标量乘加、系数只依赖固定的 $u,r$。[推测] 若系数不是中心标量（在矩阵值输入上不交换），块替换会破坏双线性恒等式，合并代价带 $r$ 因子，主定理阈值 $u^2$ 需重算。
- 阈值 $u^2$：来自展平秩下界 $\operatorname{R}(T_u)\ge u^2$（`682` "Flattening gives $r\ge u^2$"），它保证 $r$ 不会小到让 $S(N)$ 退化成 $O(N)$；$r=u^2$ 是分界（子问题规模 $N/u$、个数 $u^2$ 时 $\log_u r=2$，恰是合并项的指数，落到主定理临界情形带 $\log N$）。
- $\delta<\varepsilon$ 的取法：$\nu$ 定义里 $\delta$ 是任意正数、$u$ 依赖 $\delta$；取 $\delta<\varepsilon$ 是为了把 $\log_u r<9/4+\delta$ 塞进 $9/4+\varepsilon$。[推测] 这是 $\varepsilon$-$\delta$ 型标准选法，无优化空间。

补一个我从 remark `690-697` 读出的口径：算法系数在 $\varepsilon$ 定下后全固定；本证明在复算术模型；若要代数系数，秩分解方程有理系数、复解经 Nullstellensatz 蕴含 $\overline{\mathbb Q}$ 上的解，有限个系数落在一个数域。这一句是在堵"检测字符给的 $\lambda$ 是非构造性谱点，那算法系数从哪来"的追问，`671-672` 已经先说"上界对所有字符一致"，所以不必真把 $\lambda$ 求出来。

候选失败路线。其一，[推测] 跳过整数舍入、直接要 $d^\nu\le d^{9/4}$：$\nu$ 是 $\inf$，可能取不到，没有哪个 $d$ 真给 $\operatorname{R}(T_d)=d^\nu$；作者用 $\lceil d^\nu\rceil-1$ 严格小于 $d^\nu$ 去喂 `lem:existence`（它要求 $k<d^\nu$ 严格），再由 $-1$ 的加法损失在取对数除 $\log d$ 后归零。这步不做，`lem:existence` 的严格不等式前提没着落。其二，[推测] 想让检测字符与 $d$ 无关：$\nu$ 是逐 $d$ 的 inf，单一字符顶不到所有 $d$ 的 $d^\nu$；`669-670` 明说字符可依赖 $d$，界靠"对所有字符一致"这一侧兜住。

## 11 附录 A：检测字符为什么存在（不动点 + 催化障碍）

`700-904` 把 §10 用到的存在性引理 `lem:existence` 补全。它不在主链的构造里，却撑住"存在一个顶到接近 $d^\nu$ 的字符"这一侧，所以我按论文口径拆四块。

块一，态与目标不等式（`705-714`）。态是规格化、可加、限制单调的 $S\to\R_{\ge0}$，字符是也乘性的态。为得到 $\lambda(T_d)\ge k$，先造满足更强一族
$$\lambda(T_d s)\ge k\lambda(s)\qquad(s\in S)\tag{eq:detect-state}$$
的态。`715-718`：这一族在规格化张量乘法下不变，对任意非零 $z$，把 $\lambda(x)$ 换成 $\lambda(zx)/\lambda(z)$ 仍满足（把 eq:detect-state 用在 $zs$）。

块二，乘性（`728-768`，Lemma `lem:multiplicativity`）。补推。设 $\mathcal K$ 非空紧凸（逐点收敛拓扑），每个非零 $z$ 的 $P_z:\lambda\mapsto\lambda(zx)/\lambda(z)$ 把 $\mathcal K$ 映到自身，则 $\mathcal K$ 含乘性态。证明：$\lambda(z)\ge1$ 使每个 $P_z$ 逐点连续；$\mathbb R^S$ Hausdorff 局部凸，Schauder-Tychonoff 不动点定理（Tych35）给 $P_z$ 的不动点 $\mu$。冻 $c=\mu(z)$，子集 $\mathcal K'=\{\lambda:\lambda(zx)=c\lambda(x)\ \forall x\}$ 非空紧（$c$ 固定使定义方程对 $\lambda$ 线性 ⟹ 凸）；取 $x=1$ 得 $\lambda(z)=c$ 全在 $\mathcal K'$，故都被 $P_z$ 固定；且每个 $P_w$ 保 $\mathcal K'$（`(P_w\lambda)(zx)=\lambda(zwx)/\lambda(w)=c\lambda(wx)/\lambda(w)=c(P_w\lambda)(x)$）。在 $\mathcal K'$ 里重复、保留先前冻住的方程，归纳得任意有限个 $P_z$ 有公共不动点；不动点集闭，紧 + 有限交性质 ⟹ 全部非零 $z$ 的同时不动点，满足 $\lambda(zx)=\lambda(z)\lambda(x)$（$z\ne0$）。可加性给 $\lambda(0)=0$ 处理乘零。

块三，非空（`770-889`）。反证：若 $\mathcal K$ 空，紧性给定义条件的有限不相容子系。`779-832` 把不相容子系转成一个锥可行性：取 $E\subset S$ 含所有出现的坐标加 $0,1$，加 $\lambda(0)=0,\lambda(1)=1$，把每条坐标界齐次写成 $\lambda(s)\ge0,\operatorname{R}(s)\lambda(1)-\lambda(s)\ge0$。坐标向量 $e_s$，商掉选中的可加关系向量与 $e_0$，$u$ 是 $e_1$ 的像，$C$ 是所有不等式向量像生成的锥。若 $-u\notin C$，分离给 $L\ge0$ 于 $C$、$L(u)>0$，除 $L(u)$ 得有限子系的规格化解，矛盾，故 $-u\in C$。整数系数 ⟹ 可行有理线系 ⟹ 有理（清分母后正整数 $m$）非负锥组合。映到 Grothendieck 群（$e_s\mapsto[s]$，可加关系映 $0$），界向量给序差 $[s]-[0]$ 与 $[\operatorname{R}(s)]-[s]$，特殊差合给 $[T_d s]-k[s]$，得
$$-m[1]=[y]-[x]+[T_d s]-k[s],\quad y\ge x.$$
群中等号意为"加公共元后相等"，存在 $c$ 使 $m+y+T_d s+c=x+ks+c$；置 $D=y+c$，用 $y\ge x$ 得催化比较
$$D+ks\ge D+m+T_d s.\tag{eq:catalyst}$$
$s\ne0$：否则 $D\ge D+m$，与任一展平秩的可加单调矛盾（`830-831`）。

排除障碍（`834-889`）。补推，我把三重极限摊开。eq:catalyst 复用 $n$ 次（$D$ 只付一次）给 $D+nks\ge D+nm+nT_d s\ge nT_d s$。$s\ge1$ 使 $\operatorname{R}(D)s\ge\operatorname{R}(D)\ge D$。置 $K=nk+\operatorname{R}(D)$，得（eq:amplification）
$$Ks\ge nT_d s,\qquad K^j s\ge n^j T_{d^j}s\quad(j\ge1),$$
归纳：$K^{j+1}s\ge n^jT_d^j(Ks)\ge n^{j+1}T_d^{j+1}s$（`849-851`，保一个 $s$ 因子、不需消去）。固定 $n,\delta>0$，取 $u\ge2$ 使 $\operatorname{R}(T_u)\le u^{\nu+\delta}$，令
$$\ell_j=\Big\lfloor\frac{j\log_u n}{\nu+\delta}\Big\rfloor,\qquad g_j=u^{\ell_j}.$$
次可乘给 $\operatorname{R}(T_{g_j})\le\operatorname{R}(T_u)^{\ell_j}\le u^{(\nu+\delta)\ell_j}\le n^j$（`866-869`，floor 保证 $\le n^j$），故对角张量 $n^j$ 限制到 $T_{g_j}$。乘上 $T_{d^j}s$、用 $s\ge1$：$K^js\ge n^jT_{d^j}s\ge T_{d^jg_j}s\ge T_{d^jg_j}$。$K^j$ 份 $s$ 的直和秩 $\le K^j\operatorname{R}(s)$，故
$$\operatorname{R}(s)K^j\ge\operatorname{R}(T_{d^jg_j})\ge(d^jg_j)^\nu.$$
$j\to\infty$（$n,\delta,u$ 固定）：$g_j^{1/j}\to n^{1/(\nu+\delta)}$（因 $\ell_j/j\to\log_u n/(\nu+\delta)$，$u^{\ell_j/j}\to u^{\log_u n/(\nu+\delta)}=n^{1/(\nu+\delta)}$），取 $j$ 次根（$K^j$ 根是 $K$，左边 $\operatorname{R}(s)$ 消失于 $1/j$ 因子）：
$$nk+\operatorname{R}(D)\ge d^\nu n^{\nu/(\nu+\delta)}.$$
（左边 $K=\operatorname{R}(s)^{-1}K$ 吸收 $\operatorname{R}(s)$，$K/n\to k$ 加 $\operatorname{R}(D)/n$ 常数，此处 tex 把 $\operatorname{R}(s)K^j$ 的 $j$ 根写成 $nk+\operatorname{R}(D)$ 形式，见 `880-883$。）再 $\delta\downarrow0$（$n$ 固定，$u$ 已从不等式消失）：$nk+\operatorname{R}(D)\ge nd^\nu$。再 $n\to\infty$（$D$ 固定）：$k\ge d^\nu$，与 $k<d^\nu$ 矛盾。故 $\mathcal K$ 非空。

块四，完成（`892-904`）。对非零 $z$，$P_z$ 保规格化、可加、单调，且保 eq:detect-state（`(P_z\lambda)(T_d s)=\lambda(T_d zs)/\lambda(z)\ge k\lambda(zs)/\lambda(z)=k(P_z\lambda)(s)`）。坐标界来自 $zx\le\operatorname{R}(x)z$。块二供 $\mathcal K$ 里的乘性态即字符；eq:detect-state 取 $s=1$ 得 $\lambda(T_d)\ge k$。

机械理由：
- 为什么必须走"态集非空 + 不动点取乘性"而不直接构造字符：字符要求对张量积乘性，这是极强的约束，无法逐点定义；作者把它拆成"先把可加单调态做成紧凸集 $\mathcal K$"（可加单调是一族闭仿射不等式，容易保证非空的候选是 $\lambda\equiv\operatorname{R}$？不，$\operatorname{R}$ 不乘性但可作上界坐标），再用归一化乘法映射的不动点逼出乘性。这是渐近谱理论（Str88, CVZ）的标准手法，本文取"分离特例"（`195-196`）。[推测] 非空的另一候选是零态，但零态不规格化（$\lambda(1)=1$），所以必须靠反证构造催化不等式来排除"空"。
- 三重极限的次序（$j\to\infty$ 再 $\delta\downarrow0$ 再 $n\to\infty$）：$j\to\infty$ 先把 $\ell_j$ 的 floor 与 $\operatorname{R}(T_u)$ 的具体选择吸收进 $g_j^{1/j}\to n^{1/(\nu+\delta)}$，此时 $u$ 依赖 $\delta$、$\delta$ 依赖固定 $n$；$\delta\downarrow0$ 让 $u$ 的选择彻底从不等式消失（只留 $\nu$）；$n\to\infty$ 让加性成本 $D$（固定、与 $n$ 无关）被 $nk$ 的线性增长吞掉，逼出 $k\ge d^\nu$。次序颠倒会失败：先 $n\to\infty$ 时 $n^{\nu/(\nu+\delta)}$ 与 $n^1$ 的指数差 $\nu/(\nu+\delta)<1$ 还没被 $\delta\downarrow0$ 拉平，$D$ 吞不掉。
- 催化成本 $D$ 只付一次：eq:catalyst 复用 $n$ 次时 $D$ 出现两次相消（`836-840`），正是"固定 $D$"这一性质让 $n\to\infty$ 时 $D/n\to0$。若 $D$ 随 $n$ 增长，障碍排除不了。

Lean 侧这一附录是全篇最抽象的机器。`Spectrum/Obstruction.lean` 的 `catalytic_rank_obstruction`（`:148-158`）与 `catalytic_semiring_obstruction`（`:217-231`）把上面三重极限做成 `spectral_coefficient_le_of_all_nat`（`Growth/SpectralLimit.lean:65-72`），后者内部 `spectral_bound_of_positive_slack`（`:20-44`）用真实的 `Filter.Tendsto`、`tendsto_one_div_add_atTop_nhds_zero_nat`、`Real.continuousAt_const_rpow`、`le_of_tendsto'`（`:44`）处理 $\delta\to0$；`coefficient_le_of_nat_mul_bound`（`:48-61`）用 `exists_nat_gt` 处理 $n\to\infty$。`floor_rank_power_bounds`（`:43-83`）就是 $\ell_j=\lfloor j\log_u n/(\nu+\delta)\rfloor$ 的两侧界，全程 `Real.rpow_le_rpow_of_exponent_le` + `Nat.floor_le`。锥分离 + Farkas 在 `Convex/`：`Farkas.lean`、`RationalCone.lean`、`FiniteConeClosed.lean`（`-u\in C$ 的有理性与清分母），`FixedPoint.lean:69` 有唯一一处 `Classical.choice`（取非空指标 $j_0$），Schauder-Tychonoff 在 `MultiplicativeStates.lean`。这里"渐近记号"与 §9 不同：附录 A 真用了 `Tendsto`/`atTop`，而主指数比较只用了 $2$ 的幂离散取点。

## 12 关键转折点与最初设想的差异

我把这几节压成一条"我以为、撞上、改道"的账，因为这篇真正反直觉的地方全在这几个转折上，而不在任何单个引理的证明里。

转折一，从"打破 2.37"到"重证一条旧界"。我进场带的第一直觉是：abstract 说 $9/4$，而当时最好数值是 $2.371177$（\cite{Dup26}），$2.25<2.371$，所以这篇是要刷新最好界。这个直觉在 §0 就被 `88-90` 那句"本定理只谈渐近算术指数、不提供有限尺寸竞争力"顶回去了，但我当时还抱着"即便只提供渐近界，也是靠更强的激光抽取"的执念。真正把它掐死的是 `113-132` 的 route 段：$9/4$ 的全部来源是两条幂次增长率的比 $4/3\le 1/t$，跟基张量、跟独立分量抽取、跟合并损失一点关系都没有。到这一步我才接受：这篇的赛道是"用显式退化 + 谱观点把 $\omega\le 9/4$ 换一套公理重新推一遍"，而 $9/4$ 在这套公理里是个恰好的门槛（多项式乘积把输出维数从 $a$ 撑到 $2a-1$、三扇区给 $3$ 倍），不是什么优化出来的最优点。[推测] 若我一开始就把 $9/4$ 当成"目标数值"去反推组合参数，会在 §4 的 $5M$、$M$、六置换上浪费大量精力去凑数，而这些数最终不进 $9/4$ 的那一步账。

转折二，从"渐近抽取"到"有限对象"。§1 我列的第二死路是 Coppersmith-Winograd 式高幂次渐近分析，理由是它产出 $2.37$ 档、够不到 $2.25$，且依赖"取 $k$ 次方根再 $k\to\infty$"的机器。我读 §4（prop:separation，`277-290`）时预期又落空了，分离给出的是一批有限张量：$A^{\oplus 5M}$ 直和、一张 $5M$ 点 Fourier 投影、一组平方权重 $(g-h)^2$，它们之间的退化 $A^{\oplus5M}\hookrightarrow\bigoplus_h(A_h\otimes B_X(M))$ 是一个有限陈述，$h$ 在一个显式有限指标集里跑。这跟激光法"从 $T^{\otimes k}$ 里渐近抽出 $\langle n,n,n\rangle^{\otimes\omega}$"是两种几何。[推测] 这个转折对 Lean 化是决定性的：有限对象可以逐点判定（`Sector/Weights.lean` 的 `MiddleY/MiddleZ` 用 `omega` 决策），而渐近抽取要在无穷里取极限，机器化代价高得多。

转折三，发现"增长引擎"是 profile 的四连招，并非字符本身。字符存在（附录 A）只负责把"秩下界 $k<d^\nu$"翻译成"存在一个 $\lambda$ 在 $T_d$ 上 $\ge k$"，它本身不给出 $9/4$。$9/4$ 的实际来源是 §6-§9 对 $P(a,b)$ 做的四件事：凹性（§7，$2P(a,b)\ge P(a,b+1)+P(a,b-1)$）、移位三倍（§8，$P(a,3h+a-1)\ge 3P(a,h)$）、对角增长（§9，$P(a,a)\ge a^{4/3}$）、再配 interpolation 上界 $P(a,b)\le(a+b-1)^{1/t}$。我最初以为难点在字符/谱（那是全篇最抽象的部分，附录 A 用了 Schauder-Tychonoff 不动点），读完才发现难点与亮点是分开的：附录 A 提供工具（检测字符存在），§4-§9 才是把 $4/3$ 抠出来的组合机器。[推测] 这个"工具与引擎分离"的错觉，是我进场时把 abstract 里的 spectral 一词读成"主战场"的直接后果。

转折四，收口那步根本没有极限。§10 我预期会看到一次 $j\to\infty$ 或 $k\to\infty$ 的极限来产生 $O(n^{\omega})$。实际 `proof of thm:main`（`652-688`）走的是 $t\le 3/4$（纯代数：$4/3\le 1/t$）加一次整数舍入（$k_d=\lceil d^\nu\rceil-1$）加一次主定理式递归（$S(N)\le rS(N/u)+C(N/u)^2$，$r\ge u^2$）。Lean 侧 `ExponentComparison.lean` 的注释直接把这点写死："Powers of two suffice ... no asymptotic estimates or approximation of constants"（`9-13`），比较引理 `rpow_exponent_le_of_nat_bound`（`19-39`）只取 $n=2^k$ 一列点、靠 `exists_nat_gt` 挑一个足够大的 $k$、`nlinarith` 收尾。这跟我 §1 里"要靠无穷极限逼出常数"的预想相反，[推测] 也解释了为什么这一支能干净地进 Lean：不等式强度是逐点可判的，极限只留在附录 A。

最初设想与最终落点的全部差异，可以归结为一句：我以为这是一篇"把激光法往前推一步、得到一个新数值"的文章，实际上它是一篇"绕开激光法、用张量退化加谱观点重证一条已知门槛、并把这个门槛的全部算术压到有限对象和逐点不等式上"的文章。前者的瓶颈我早在 §0 就列过（分量共享变量、合并损失、每步重跑凸优化），后者完全不走那条瓶颈。

三个必答点。

其一，组合引理在机器里是显式有限对象还是存在论证。答案：主体是显式对象。`Convolution/Basic.lean:26` 是 `def convolution (a b) := fun i j k => if i.val + j.val = k.val then 1 else 0`，多项式乘积张量逐坐标可算。§8 的三扇区是 `Sector/Branches.lean` 的 `def leftY/leftZ/middleY/middleZ/rightY/rightZ` 与 `Sector/Degeneration.lean` 的 `def source/retained/erased/leftTensor/middleTensor/rightTensor`，边界谓词 `MiddleY = (h ≤ j ∧ j < rightStart)`、`MiddleZ = (h+a-1 ≤ k ∧ rightStart=2h+a-1)`（`Sector/Weights.lean:29-38`）都配了 `Decidable` instance 并用 `by omega` 判定，权重 `firstWeight=0 / secondWeight=if MiddleY then 1 / thirdWeight=if MiddleZ then -1` 是可计算 `def`。§4 的 `Separation/Basic.lean` 把 `projectedTensor / separationPolynomial / separationFirstEquiv` 全定义成 `def`，`SquareWeights.lean:18-30` 把 `phase=u-v+2(g-h)`、`g^2 / hu-h^2 / -hv` 写死。退化关系本身用 `structure PolynomialRestrictionDegeneration`（`Polynomial/ComplexPolynomialDegenerationComposition.lean:94-105`）携带显式数据字段 `leftMap/middleMap/rightMap : _ → _ → Polynomial F` 加次数界与 `vanishes/leading` 条件，是"给出一组多项式"的结构，不是 `∃`。唯一 `noncomputable` 集中在两处：本原单位根 `ζ := Complex.exp(2πi/L)`（`Separation/FiniteProjection.lean` 的 `finiteFourierCoefficient`）与字符取值实数化（`exactRank`、`Character` 值域 $\mathbb R$）。存在性论证只出现在**附录 A**（检测字符 `exists_detecting_character` 靠 Schauder-Tychonoff 不动点 + 反证，`Convex/FixedPoint.lean:69` 一处 `Classical.choice`），以及 §10 的整数舍入 witness `exists_nat_sub_one_le_lt`（`CharacterRounding.lean:22`，用 `Nat.ceil` 构造，本质仍可算）。

其二，具体指数不等式 $9/4$ 在机器里怎么落。全程不用渐近记号。链条是 `RankBound.lean:18-25`：`exactRankExponent_le_nine_quarters` 由 `exactRankExponent_le_nine_quarters_of_characters`（`CharacterRounding.lean:111-118`）给出，后者最后一步是 `exponent_le_of_detecting_characters (by norm_num) detect bound`，这里的 `norm_num` 证的正是侧条件 `0 ≤ (9/4 : ℝ)`，与"渐近"无关。检测到的字符取值上界 `bound` 由 `χ.exponent_sum_le_nine_quarters`（`Polynomial/Inequalities.lean:117-120`）供，它自身是 `meanExponent_le_three_quarters`（`:110`）乘 $3$ 后 `linarith`；而 `meanExponent_le_three_quarters` 走 `toScalarProfile` + `Growth/Profile.lean` 的 `exponent_le_three_quarters`，最终落到 `ExponentComparison.lean:43-74` `diagonal_exponent_le_three_quarters`：把 $n^4\le D(n)^3$ 与 $D(n)\le(2n-1)^{1/t}$ 合成 $n^4\le 2^{(1/t)\cdot3}\,n^{(1/t)\cdot3}$，交给 `rpow_exponent_le_of_nat_bound`（`:19-39`）比较指数得 $4\le(1/t)\cdot3$，再 `field_simp` 消 $t$、`linarith` 出 $t\le3/4$。`rpow_exponent_le_of_nat_bound` 的机器语言是 `exists_nat_gt` 挑 $n=2^k$ 一列点 + `nlinarith`，文件头注释 `9-13` 明说"Powers of two suffice ... no asymptotic estimates or approximation of constants"。另一条结论 `matrix_multiplication_cost_le` 里的 $n^{\tau+\varepsilon}$ 是实数 `rpow`，靠 `Real.rpow_le_rpow_of_exponent_le` 与算术模型引理，不引入 `Tendsto`。所以 norm_num/positivity 管离散常数（$0\le9/4$、$0<\log 2$、$(n:\mathbb R)^{(4:\mathbb R)}=(n)^4$），$2$ 的幂比较管增长率，`Tendsto` 只在附录 A 出现。

其三，渐近极限 $\omega$ 怎么定义。两个都是 `sInf`（下确界、不假设达到）。精确秩指数 `exactRankExponent := sInf exactRankExponentSet`（`RankExponent.lean:146`），集合 `exactRankExponentSet := {τ | ∃ n, 2 ≤ n ∧ τ = Real.logb n (exactMatrixRank n)}`（`:142-143`），配套 `exactRankExponentSet_nonempty`（`⟨logb 2 (exactMatrixRank 2),…⟩`）、`exactRankExponentSet_bddBelow`、`exactRankExponent_lower : 2 ≤ ν`、`exactRankExponent_upper : ν ≤ 3`。算术指数 `omega : ℝ := sInf {τ | AdmissibleExponent τ}`（`ComplexArithmetic/Complexity.lean:131`），`AdmissibleExponent τ` 就是把 Thm 1.1 量词逐字写出来：`∀ ε, 0<ε → ∃ C, 0<C ∧ ∀ n, 1≤n → ∃ P, P.Correct ∧ (P.cost:ℝ) ≤ C * (n:ℝ)^(τ+ε)`（`:126-129`）。桥 `omega_le_exactRankExponent`（`Arithmetic/Exponent.lean`，注释 `16-20` 强调"这里是 ω 的别名、不假设任何数值上界"）把 $\nu\le9/4$ 传成 $\omega\le9/4$。tex 里 $\nu=\inf_{n\ge2}\log_n\operatorname{R}(T_n)$ 的"inf、$n\ge2$、不达到"三点在 Lean 里一一对应 `sInf`、集合里 `2 ≤ n`、以及"不 attained"（doc `145` 注释 "no attainment of this real infimum is assumed"）。

 tactic 频率（`AuxiliarySeparation/` 全目录静态计数，仅示意口径）：`have` 673、`simp` 475、`exact` 451、`rw` 244、`intro` 244、`omega` 203、`apply` 186、`refine` 70、`norm_num` 56、`positivity` 25、`linarith` 22、`nlinarith` 12、`field_simp` 17、`ring` 78、`rcases/obtain` 约 147、`gcongr` 1、`decide` 2。分布告诉我两件事：`omega` 用了 203 次，对应扇区边界、`Fin` 算术、floor/ceil 这些自然数/整数区间判定，正是"显式有限对象"路线的指纹；`gcongr` 只 1 次、`polyrith` 0 次、`nlinarith` 才 12 次，说明不等式强度多靠手工 `have` 链与 `positivity/nlinarith` 收尾，并非自动代数。

口径差。tex 用 $O_\varepsilon(\cdot)$、"for $n$ large"、几何平均 $(\prod_\pi)^{1/(6t)}$ 这类渐近或解析记号；Lean 侧一律拆成"实数 `rpow` + $\varepsilon$ 显式量词 + 逐点不等式 + `2` 的幂比较"。tex 附录 A 的三重极限 $j\to\infty,\delta\downarrow0,n\to\infty$ 在 Lean 里是真 `Filter.Tendsto` + `le_of_tendsto'` + `exists_nat_gt`（`Growth/SpectralLimit.lean:20-44`），与主链的"无渐近"形成对照：主链唯一用极限语义的地方被隔离在附录 A。我读 tex §9 时把 "$(1+1/(3m))^3\ge1+1/m$" 当成显然，到 Lean `Growth/Recurrence.lean` 才看到它被 `positivity`+`nlinarith` 逐 $m$ 展开，这是 tex 与机器口径差里我最在意的一处：tex 的"显然"在机器里全部要显式构造。

### 0.3 归属判定：为什么这条登记属于队列第 59 行号

先前 GaussianMoat 这条登记被排除过一回，理由是同族的
`GaussianReplacement`（yaml 1186--1188 与 1190--1192，声明分别是
`OAI.CurrentProjection.hybridBlockMain`、`OAI.CurrentProjection.fiberBlockMain`，
文件在 `OAI/Probability/GaussianReplacement/`）、
`GaussianPropeller`（yaml 1182--1184，声明 `OAI.GaussianPropeller.all_partitions`，
文件 `OAI/Probability/GaussianPropeller/Main.lean`）、
`MemoryPrecision`（yaml 1334--1336，声明 `OAI.MemoryPrecision.main`）
都属于别的论文。我不抄那套排除写法，本篇自己拿正面证据。

证据一：`Main.lean:102--103` 的确切陈述是

```
theorem fullMain : MainEndpoint ∧ UniformEndpoint :=
  endpoints_of_finiteSieve finiteSieveEndpoint_proved
```

证据二：`Model.lean:23--26` 的 `MainEndpoint` 展开是

```
∀ (D : ℝ) (z : ℕ → GaussianInt),
  (∀ t, Irreducible (z t)) → Function.Injective z →
  (∀ t, dist (z (t + 1) : ℂ) (z t : ℂ) ≤ D) → False
```

逐点对照 `build/main.tex:44--45` 的 "no infinite walk through distinct
Gaussian primes can have bounded steps"：`∀ t, Irreducible (z t)` 就是"经过高斯素数"，
`Function.Injective z` 就是"distinct"（顶点不重复），
`dist (z (t+1)) (z t) ≤ D` 对固定实数 $D$ 就是"步长有界"，
结论 `False` 就是"这样的无限行走不存在"。三项都对齐，量词次序也一致：$D$ 在行走之前给定。

证据三：`Model.lean:28--34` 的 `UniformEndpoint` 是
`∀ D, ∃ B : ℕ`，要求每个 `component D p` 有限且 `ncard ≤ B`，
并且任意长度为 $n$ 的互异素数步长 $\le D$ 序列满足 $n\le B$。
这正对 `build/main.tex:63--68` 的 Theorem 1.1（Uniform component bound）：
"there is a finite $B_D$ such that every connected component of $G_D$ has at most $B_D$ vertices"，
以及同一句里 "Consequently every sequence of distinct Gaussian primes whose successive
distances are at most $D$ has at most $B_D$ terms"（`build/main.tex:67--68`）。
图侧对象也对得上：`Model.lean:9--10` 的 `primeGraph D` 定义为
`Adj p q := p ≠ q ∧ dist (p.val : ℂ) (q.val : ℂ) ≤ D`，
逐字是 `build/main.tex:57--58` 的 "$G_D$ have all Gaussian primes as vertices,
with an edge between distinct $z,w$ if $|z-w|\le D$"；
`Model.lean:7` 的 `PrimeVertex := {z : GaussianInt // Irreducible z}` 对应顶点集；
`Model.lean:20--21` 的 `component D p` 用 `Reachable` 定义，对应"connected component"。

证据四：中间引理 `LatticeComponents.lean:41--45` 的 `FiniteSieveEndpoint` 展开是

```
∀ D : ℝ, 1 ≤ D → ∃ s : SplitSieve,
  ∀ z : ℕ → GaussianInt, (∀ t, z t ∈ s.avoiding) → Function.Injective z →
    (∀ t, dist (z (t + 1) : ℂ) (z t : ℂ) ≤ D) → False
```

而 `LatticeComponents.lean:38` 的 `SplitSieve.avoiding` 是
`{z | ∀ p ∈ s.primes, ¬s.factor p ∣ z ∧ ¬star (s.factor p) ∣ z}`，
`LatticeComponents.lean:35--36` 要求 `factor p` 不可约且 `(factor p).norm = (p : ℤ)`。
这与 `build/main.tex:109--116` 的 $\mathcal A(\mathcal P)$ 定义逐字同形：
对每个 $p\equiv1\pmod4$ 选共轭因子 $\pi_p,\overline{\pi_p}$（Lean 侧是 `factor p` 与 `star (factor p)`，
norm 为 $p$ 即欧氏范数 $\sqrt p$ 的平方），避开两者整除。
`build/main.tex:120--125` 的 Theorem 1.2（Finite sieve obstruction）
"$\mathcal A(\mathcal P_D)$ contains no infinite sequence of distinct points with
successive distances at most $D$" 就是 `FiniteSieveEndpoint` 的 $D\ge1$ 分支；
$D<1$ 的边界情形在 `build/main.tex:74--75` 单独处理（$B_D=1$）。

证据五：归约边的命名与 tex 的小节标题相互指认。
`LatticeComponents.lean:550` 的 `endpoints_of_finiteSieve`、`:110` 的 `main_of_finiteSieve`、
`:495` 的 `prime_components_of_finiteSieve` 三条合起来，
正好是 `build/periodicity.tex:46--47` 那句
"Applying Proposition ref to the set supplied by Theorem 1.2 proves Theorem 1.1 for $D\ge1$"
的三块拆法。tex 里 Proposition 2.1 的一致界
$\#C\le\max\{Q^2,\lvert E\rvert+(K_D-1)\lvert E\rvert Q^2\}$（`build/periodicity.tex:19--21`）
中的 $K_D=\#\{v\in\Z[i]:\lvert v\rvert\le D\}$（`build/periodicity.tex:15`），
在 Lean 侧是 `Main.lean:15` 与 `:17` 出现的 `(latticeBall D).card`，
即同一个"半径 $D$ 格点数"常数。

三条吻合叠起来（对象同形、量词同序、结论同为 `False` 与 $\le B$、归约边同名），
我的判定是：yaml 第 1178--1180 行的登记属于队列第 59 行号这一篇。
`GaussianPropeller`、`GaussianReplacement`、`MemoryPrecision` 三条的声明
都在 `OAI.Probability.*` 或 `OAI.MemoryPrecision` 命名空间下，
且都找不到 `primeGraph`、`PrimeVertex`、`SplitSieve` 这类高斯素数图对象，
所以按对象归属，`NumberTheory/GaussianMoat` 只可能挂在这一篇。

## 2 初始动机与猜想

### 2.1 我从哪里起步

摘要（`build/main.tex:43--51`）宣称证明的是 Gaussian moat conjecture，
并把问题史锚在两个人名上：`build/main.tex:77--79` 说 Gethner 与 Stark 把问题
追到 1962 年斯德哥尔摩国际数学家大会上的 Basil Gordon（引文页码 p. 289），
`build/main.tex:79--81` 说 Erdős 后来把功劳同时记给 Gordon 与 Motzkin，
并回忆 Motzkin 是 1963 年 11 月 Pasadena 数论会议上告诉他的（引文页码 p. 69）。
这两个日期与页码是 tex 正文里印着的，我在 §16 再核外部链接。

我最初的猜想形态很朴素：高斯素数在平面上散布得足够均匀，
素数定理在算术级数里给出密度 $\sim 1/(2\log T)$（`build/preliminaries.tex:43` 的
$k_T=(1/2+o(1))T/\log T$），
那么在半径 $D$ 的圆盘里，下一步可用的素数顶点数应当随位置剧烈波动，
某个足够大的 $D$ 之外总会被"饿死"。
这个直觉的问题在于它只会给出概率式的陈述，而 Theorem 1.1 要的是
对每个 $D$ 存在确定的 $B_D$，而且 $B_D$ 对起点一致（`build/main.tex:66--67`：
"The bound is independent of the starting prime"）。
密度论证天生带 $o(1)$，一致界天生不容许起点相关的例外，
这两件事的张力是我全部工作的起点。

### 2.2 一维直觉为什么在二维失效

`build/main.tex:60--61` 留下一句决定性的话：
"Large gaps along a line do not settle the question in the plane,
since a path may go around them."
这就是我从一维搬到二维时撞上的第一面墙。实整数轴上的素数空隙可以任意长
（经典构造用 $n!+2,\dots,n!+n$），高斯素数里也有类似的实轴素数（$p\equiv3\pmod4$ 的惯性素数），
但平面里的行走有 $(K_D-1)$ 个方向可选，
$K_D=\lvert\{u\in\Z[i]:\lvert u\rvert\le D\}\rvert$（`build/preliminaries.tex:113--115`），
一条直路上的空隙只关掉一条路。

我把这件事写成了一个具体的"局部障碍清单"：
`build/main.tex:83--92` 说 Gethner、Wagon、Wick 构造了中心在任意含两个高斯整数直线上的
大素数自由圆盘，并构造了任意孤立的实高斯素数（引文标 Theorems 4.1 与 4.4，
并注明 Vardi 独立给出后一结果），
而 Tsuchimura 的计算机算的是"从原点出发、步长不超过 $6$"的可达距离有限界
（`build/main.tex:90--92`，原点是额外 adjoining 的初始顶点）。
这两类工作的差别很关键：圆盘给出局部障碍但可绕行，计算给出特定起点所在分量的界。
我的初始猜想必须同时跨过这两道坎，也就是要一个"对所有起点一致、
且不可绕行"的障碍。

### 2.3 把猜想改写成可攻击的形式

我做的第一个实质动作是把问题改写成否定式：
假设存在一条确定的无限自避行走 $(z_t)_{t\ge0}$，$\lvert z_{t+1}-z_t\rvert\le D$，
顶点互异（`build/preliminaries.tex:105--107`）。
`build/main.tex:129--133` 明确了随机性的来源：
"We fix an arbitrary deterministic infinite self-avoiding lattice walk
with steps at most $D$. Randomness enters only through sampled times
and auxiliary choices of one Gaussian factor over each split prime."
这条约定是方法论上的关键一步：行走本身确定，
概率全在我这边（采样时刻 $\tau$、每个分裂素数上选哪个因子），
于是"推出矛盾"变成"我构造的随机实验给出互相打架的熵不等式"。

有了否定式假设，猜想就分解成两个可操作的部件：
一是给行走的某个投影（残差向量）算熵，
二是证明"避开零类"这件事强制熵的收支不平衡。
第一个部件后来长成 `sec:geometry` 与 `sec:schedule`，
第二个部件后来长成 `sec:information` 与 `sec:budget`。
中间那块（覆盖）在最初我的清单上只是"投影接近均匀"一句模糊话，
后来它变成独立的一节 `sec:transfer`。
这样看，最初的单一猜想
"用密度矛盾掉"被拆成了三段：造熵、传覆盖、算信息。

## 3 尝试过的错误路线及失败原因

这一节我把走过的死路逐条摊开。每条都写清楚三件事：当时的论证形态、
在哪个具体不等式上断掉、以及论文正文里留下的哪一句防御性说明暴露了这处断裂。
tex 里那些"某条论证单独不够"的句子，读起来像多余的注释，
其实是弯路留下的疤。

### 3.1 密度路线：局部无阻碍是致命的

我对 $\mathcal A(\mathcal P)$（`build/main.tex:112--116`）的第一反应是把它当稀疏集。
按 `build/preliminaries.tex:20--23`，每个 $p\equiv1\pmod4$ 的两个共轭因子 $\pi,\bar\pi$
互不相伴、剩余域大小都是 $p$，所以模 $(p)=\pi\bar\pi$ 用中国剩余定理，
同时避开两个零类的比例是 $(1-1/p)^2$。这是我自己的算式，tex 没写。
一批 $\mathcal B_T$（$T\le p\le2T$，$k_T$ 个素数，`build/preliminaries.tex:33--36`）
合起来的密度损失是
$\prod_{p\in\mathcal B_T}(1-1/p)^2\approx\exp(-2k_T/T)=\exp(-1/\log T)$，
即每批只掉 $\asymp1/\log T$。对 $M$ 个窗口累加，总密度以 $e^{-cM}$ 速度趋零。

看起来很好，实际全废。理由有两个层次。
第一层：任何有限 $M$ 给出的 $\mathcal A(\mathcal P_M)$ 都有正密度，
而正密度的 $Q\Z^2$ 周期集（$Q=\prod_{p\in\mathcal P}p$，`build/main.tex:117--118`）
在 $\Z^2$ 里完全可以含无限有界步长自避路径。密度对"存在一条路径"这件事没有判决力。
第二层要命得多：取 $T>D^2$，半径 $D$ 的格点盘里只有 $\ll D^2$ 个点，
而模 $\pi$（范数 $p\ge T$）把这些点映成互异剩余，于是盘内几乎一个点都没被筛掉。
于是筛子在所有有限视野内都是空的，
任何只用到半径 $O(D)$ 局部信息的论证都不可能得到矛盾。
论文对这一点给出了定量版本：`build/information.tex:199--206` 用
"非零差长度 $\ge\sqrt p$"与"$DL<\sqrt p$"（$L\le T^{2/5}$，$p\ge T$）的矛盾
来保证命中事件两两不交，这正是"局部无阻碍"的解析式表达。
我在这条路上耗的时间最长，因为密度是素数定理能直接给的最强结论
（`build/preliminaries.tex:42--45` 的 $k_T=(1/2+o(1))T/\log T$），
而它恰恰与"存在无限路径"无关。

### 3.2 直线空隙与大圆盘路线

第二条死路是把实整数上的阶乘空隙搬到高斯整数。
`build/main.tex:60--61` 一句话把它否掉：
"Large gaps along a line do not settle the question in the plane, since a path may go around them."
更强的否证来自 `build/main.tex:83--88`：Gethner、Wagon 与 Wick 已经在
任意含两个高斯整数的直线上造出大素数自由圆盘，还造出任意孤立的实高斯素数
（引文标 Theorems 4.1 与 4.4，Vardi 独立给出后者）。
也就是说，"沿一条线把行走饿死"这件事别人已经做到极致，
剩下的困难全在"绕行"上。
步长 $\le D$ 时每步有 $K_D-1$ 个可选方向
（$K_D=\lvert\{u\in\Z[i]:\lvert u\rvert\le D\}\rvert$，`build/preliminaries.tex:113--115`），
一维障碍的强度被 $(K_D-1)$ 这个因子稀释掉了。
这条路线的失败迫使我放弃"给出几何空洞"的构想，
改为寻找一个对所有方向同时生效的代数障碍。

### 3.3 计算搜索路线：一致性的代价

`build/main.tex:89--92` 记下 Tsuchimura 的结果：从原点出发、
步长不超过 $6$ 的可达距离有有限界，原点是额外加进去的初始顶点。
这是关于"那个顶点的分量"的结论。我一开始以为只要把 $D$ 推到更大、
搜索半径推到更深，就能用计算机覆盖全部情形。
断点在于一致性的量词次序：Theorem 1.1 要求
$\forall D,\exists B_D,\forall$ 起点（`build/main.tex:63--66`），
而计算给出的是 $\forall D,\forall$ 有限个起点（受算力约束的那些），
$B_D$ 与起点绑定在一起。要拆掉这个绑定，需要一条与起点无关的机制。
我后来是在 $Q\Z^2$ 平移不变性上找到它的（见第 6 节）。

### 3.4 直接用 Kőnig 引理路线

我认为"每个分量有限"与"不存在无限自避行走"是同一句话。
`build/periodicity.tex:24--29` 恰好证明了我的直觉里对的那一半：
局部有限图上，若某分量无限，则从一个顶点出发的有限简单路径树
分叉有限、深度任意大，逐层选取有任意深后代的子节点，
就得到一条无限简单路径。
但 `build/periodicity.tex:53--56` 指出反方向不成立：
"Absence of an infinite path in a general locally finite graph does not bound
the sizes of its finite components."
一个反例足够说明问题：把大小递增的有限块用长边串起来，
每块内部无无限路径，块的大小却无界。
所以 Kőnig 只给我"$\#C<\infty$ 对每个 $C$"，
而 Theorem 1.1 要的是 $\sup_C\#C\le B_D$。
补上这一步靠的是分量向 $(\Z/Q\Z)^2$ 单射（`build/periodicity.tex:31--35`），
即"有限非空子集不能在非零平移下不变"这一句话。
这条弯路让我确认：一致界必须来自周期性，纯图论手段给不出上界。

### 3.5 只用联合熵路线：精度不够

这是正文自己承认的死路。`build/main.tex:146--149`：
"Joint entropy alone, at the accuracy available early in the construction,
does not give this conclusion."
具体断点我能算出来。设 $\pi$ 的剩余域大小为 $p$，终端残差律为 $\mu$，
联合熵给出的是一坐标平均的意义下
$\frac1k\sum_\pi(\log p-H(\mu_\pi))\le\epsilon L_*$
这类估计（对应 `build/coverage-transfer.tex:42--45` 的 `eq:deficit-upper`）。
若某个 $\mu_\pi$ 不满足 $(\tau,\beta)$ 覆盖，即
$\#\{u:\mu_\pi(u)<\tau/p\}\ge p^{1-\beta}$（覆盖定义见
`build/coverage-transfer.tex:86--89`），
它对应的 TV 下界只有 $(1-\tau)p^{-\beta}$（`build/schedule.tex:427--431`），
经 Pinsker（`build/preliminaries.tex:80--84`，$D_{\mathrm{KL}}\ge2\operatorname{TV}^2$）
平方后变成 $p^{-2\beta}$ 级的极小熵亏。
$\beta$ 是 $1/200$ 这种量（`build/schedule.tex:29` 的 $\beta_0=1/200$），
$p^{-2\beta}$ 对 $p\le2T$ 而言是 $T^{-1/100}$，
平均化的预算根本按不住它：一个坏坐标可以吸收全部 $\epsilon L_*$。
所以必须先把"单个坐标的坏"转成"概率地板 $\tau/p$"这种逐点陈述，
再让 TV 下界与 $p^{-\beta}$ 抵消。
这正是第 10 节要写的覆盖转移定理事件。我在联合熵上停留的原因，
是几何部分（第 8、9 节）能自然产出的只有联合熵。

### 3.6 逐坐标单独条件化路线：代价乘了 $k$ 倍

另一处正文自陈的弯路在 `build/coverage-transfer.tex:8--12`：
"If one separately conditioned on data chosen for each coordinate,
its entropy cost would be paid once per coordinate."
设每个坐标各配一组延续位移 $\mathcal H_c$，
则条件化代价是 $\sum_cH(\mathcal H_c)\approx kn_i\log|\mathcal D_i|$。
预算要求是 $\epsilon+\kappa\le\eta\delta\beta'/16$
（`build/coverage-transfer.tex:117--118`），
其中 $\kappa=H(\mathcal H)/(s\overline L)$。
用 `build/schedule.tex:462--476` 的数字：$s_iL_*\ge\exp(r_i\log T-O_D(M^6))$，
$\log|\mathcal D_{i+1}|\le C_DT^{r_{i+1}}$（`build/schedule.tex:256--259`），
共用一份数据时 $\kappa_i\le C_D\exp(-\frac45\beta_i\log T+O_D(M^6))\le e^{-M^3}$。
若逐坐标付 $k$ 份，$k_T\asymp T/\log T$（`build/preliminaries.tex:43`）
这个因子直接把 $T^{r_{i+1}}$ 的指数余量 $\frac45\beta_i$ 吃光
（$r_i-r_{i+1}=2\beta_i$，`build/schedule.tex:228--230`），
归纳在第一步就断。改成"一份共享数据、代价只算一次"以后，
引理 `lem:conditioning` 的证明只剩链式法则与次可加
（`build/coverage-transfer.tex:49--58`）。
$\sum_c$ 与 $\mathop{\mathrm{av}}_c$ 的这一次差别，是整篇能不能收敛的分水岭。

### 3.7 枚举直线方向路线：线数不可控

几何部分的第二处弯路写在 `build/geometry.tex:174--175`：
"The fixed-line bound alone does not control the number of possible lines."
我的算盘是：随机符号积 $\prod_i\pi_i$ 若在矩形 $Q$（半轴 $R_1\ge W_1\ge1$，
$R_1W_1\le P^{1-d}$）里有非零倍数 $w$，则 $w$ 落在某条过零直线上；
对固定直线用 Hoeffding 得坏概率 $\le e^{-c_0d^2r}$
（`build/geometry.tex:165--168` 的 `eq:line-tail`），
再对直线求并。并起来就废了：候选 witness 在 $Q$ 内，格点数 $\ll R_1W_1\le P^{1-d}$，
于是并界给出 $e^{-c_0d^2r+O(d\log T)}$ 级别的东西，
$\log P=r\log T$ 与 $d^2r$ 相比差一个 $d$ 的幂，根本压不住指数。
真正省事的办法是不数直线。
`build/geometry.tex:110--132` 先证明：两个只差 $h\le dr/4$ 个坐标的坏符号向量，
其 witness 满足 $\det(w,w')\in N(c_*)\Z$，而
$\lvert\det(w,w')\rvert\le2R_1W_1\le2P^{1-d}$，
且 $\log(N(c_*)/(2P^{1-d}))$ 至少是
$dr(\log T-\frac14\log(2T))-\log2$（`build/geometry.tex:125--127`），
在 $d^3r$ 超过绝对常数时为正，故行列式为零，
即同一坏符号向量的所有 witness 共线（每个坏向量有唯一 witness 线）。
于是不同直线对应的坏符号集合 $S_\ell$ 两两 Hamming 距离 $>dr/4$，
半径 $h=\lfloor dr/10\rfloor$ 的邻域互不相交（`build/geometry.tex:204--209`）。
再用 Harper 立方体等周 $|\partial_ES|\ge|S|\log_2(2^r/|S|)$
（`build/geometry.tex:178--181`）得到每步膨胀因子 $\ge1+c_1d^2$，
$h$ 步后是 $e^{c_2d^3r}$，不相交性与 $\le2^r$ 的总量给出
$\le Ce^{-cd^3r}$（`build/geometry.tex:219--221`）。
`build/main.tex:142--144` 那句
"Disjoint neighborhoods in the Boolean cube avoid a separate count of all lattice directions"
就是把这条弯路压缩成一行。

### 3.8 把延续当成无条件独立试验路线

我一度以为：既然 $n_i$ 次延续是独立抽的，
$\mathcal H=(h_1,\dots,h_{n_i})$ 的熵自然就是 $n_i$ 倍单步熵，
各次试验的命中事件也就独立。正文在三个地方钉住这个错误。
`build/coverage-transfer.tex:157--158`："This step uses only the common
one-trial marginal, not independence of the trials before conditioning on $A$."
`build/schedule.tex:468--470`："This is not an assertion of independence before
conditioning on $A$." 真正的机制是：延续从随机 checkpoint $A_{i+1}$ 采样时，
各 $h_\ell$ 通过共同的随机起点相关；只有把起点钉成精确值 $A=a$ 之后，
新鲜随机性才让条件独立性成立（`build/coverage-transfer.tex:182--184`
明确 "because its trials are independent conditional on this exact $a$"）。
因此证明分成两笔：先用共同的单试验边缘律 $\mu_\pi$ 拿到
$\Pr\{\phi_c(Y)\in\mathcal L_c(\mathcal H)\}\ge\delta/(\tau+\delta)\ge\delta$
（`build/coverage-transfer.tex:149--157`，只需 Markov），
再在固定 $A=a$ 下用二项下尾
$\Pr\{\operatorname{Bin}(n,\lambda)\le n(\lambda-\delta u_p/p)\}\le\exp(-\delta^2np^{-\beta}/2)$
（`build/coverage-transfer.tex:187--192`）。
另一处同族错误是对精确未来时刻条件化。
`build/schedule.tex:183--185` 说后向保持熵时
"we are not conditioning on the exact later time, which would determine its walk position"：
一旦固定未来精确时刻，位置就被确定，残差熵变成零，
保持性论证立刻自我拆台。正确的做法只固定起点时刻、让终点随机。

### 3.9 用平稳性假设简化望远镜路线

预算那一节我原本想直接写 $H(W_L(t_*)\mid Q(t_*))$ 与平移后的相同量相等，
理由说成"平稳"。`build/information.tex:344--346` 挡了这个说法：
"This is approximate invariance of the sampled time law;
no stationarity of the walk is assumed."
行走是任意确定的自避路径，没有任何平稳性可言。
可用的只有末段那个均匀偏移：$t_*=\widetilde t+U_N$，
$U_N$ 在 $\{0,\dots,N-1\}$ 上均匀且与前面独立，
故对 $a\le T_+$ 有 $\operatorname{TV}(\mathcal L(t_*),\mathcal L(t_*+a))\le a/N\le T_+^{-9}$
（`build/schedule.tex:104--109` 的 `eq:smoothing`，
$N=\lceil T_+^{10}\rceil$ 见 `build/schedule.tex:79--82`）。
再由连续性引理（`build/preliminaries.tex:142--149`，
$2h(\epsilon)+2\epsilon\log a$）转成熵差
$\epsilon_M=O_D(T_+^{-7})$（`build/information.tex:356--362`）。
这里 $\log a$ 那个 $a$ 是全字母表大小，
残差字母表取 $\sum_Tk_T\log(2T)=O(T_+)$（`build/information.tex:348--352`），
所以 $T_+^{-9}$ 的 TV 必须配上 $O(T_+)$ 的对数规模才成立，
两个指数 $-9$ 与 $+1$ 的余量就是我当时以为可以省略的技术成本。

## 4 关键转折点

### 4.1 一致性交给周期性

第一个转折是把"$B_D$ 与起点无关"这件事从分析任务改成代数任务。
$A(\mathcal P)$ 在 $Q\Z^2$ 下不变（`build/main.tex:117--118`），
于是若某分量 $C$ 内两点差 $v\in Q\Z^2$，平移把 $C$ 映到含 $y$ 的分量、
即映到自身，而有限非空子集不能在非零平移下不变，
故 $C\to(\Z/Q\Z)^2$ 单射、$\#C\le Q^2$（`build/periodicity.tex:31--35`）。
再处理被筛掉的相伴元集合 $E$：
分量遇 $E$ 时最多接 $(K_D-1)\lvert E\rvert$ 个删掉 $E$ 后的分量，
合起来得到 `build/periodicity.tex:19--21` 的
$\#C\le\max\{Q^2,\lvert E\rvert+(K_D-1)\lvert E\rvert Q^2\}$。
这一步之后，我要证的东西缩成 Theorem 1.2：
找有限集 $\mathcal P_D$ 使 $\mathcal A(\mathcal P_D)$ 里没有无限自避路径
（`build/main.tex:120--125`）。

### 4.2 把素数图换成任意自避格路径

第二个转折是全篇最重要的次序决定：几何与覆盖两部分完全不假设零避免。
`build/geometry.tex:5--6` 写着 "The walk need not satisfy any congruence restrictions."，
`build/schedule.tex:20--22` 重复 "No zero-avoidance assumption is used."，
直到 `build/information.tex:4--8` 才加上 $z_t\in\mathcal A(\mathcal P_M)$。
这个切分的收益是分工清楚：熵的"造"与"传"只用自避性与步长界 $D$，
与素数无关；素数只在最后一节以"避开零类强制暴露信息"的方式登场。
我原先把两件事混在一起，试图同时用素数分布和熵，
结果两边都不干净。

### 4.3 折半迭代与三带尺度

第三个转折是把 `lem:enrichment` 的不等式
$f_V(b)/(bL_*)\ge\frac12(1+f_Z(q)/(qL_*))-O_D(g)$（`build/geometry.tex:294--297`）
读成迭代格式。记归一化亏格 $d_j=1-f/( \cdot L_*)$，
则 $d_{j+1}\le d_j/2+C_Dg$，$d_0\le1$ 给出 $d_l\le2^{-l}+2C_Dg$
（`build/schedule.tex:167--170`）。
迭代要能把 $d$ 压到 $e_0/3$ 以下，就必须 $l$ 大且 $g$ 小，
而每次转移的时间步长是 $n=\lfloor e^{gU}\rfloor$（`build/geometry.tex:264--266`），
$l$ 次消耗的对数尺度是 $O(\log(1/g)\cdot l)$，所以必须给 $U$ 留出下滑区间。
论文用三带解决（`build/schedule.tex:63--77` 的表）：
顶带 $\log U\in[0.8X_m,1.3X_m]$、参数 $g_0$；
中带 $[0.20X_m,0.30X_m]$、$g_1=e^{-M^3}$；
底带 $[0.05X_m,0.10X_m]$、$g_2=e^{-100M^{20}}$。
带间落差 $0.05X_m-1.3X_{m-1}=0.037X_m$（`build/schedule.tex:123--127`）
支配所有参数比，因为 $\log(1/g_2)=100M^{20}=o(X_{\lceil M/2\rceil})$。
三带各自的职责被我拆成三条：顶带造阶为 $T$ 的联合熵、
中带铺 checkpoint 供后向归纳、底带把一坐标边际做到 $1-e^{-90M^{20}}$ 精度
（`build/schedule.tex:291--307`）。
这个"同一份随机性三种精度"的分层，是我最初完全没想到的。

### 4.4 一份共享数据加 $n_i$ 次重复

第四个转折是覆盖传递的物理形态。
固定精确起点 $A_i=a$，跑到 $A_{i+1}$ 得 $Y=z_{A_{i+1}}$，
再独立重复 $n_i=\lceil T^{6\beta_i/5}\rceil$ 次延续（`build/schedule.tex:450--458`），
每个 $Y+h_\ell$ 都服从同一终端律。
转移定理的结论是地板从 $\tau'= \tau+4\delta$ 降到 $\tau$、
例外集从 $p^{1-\beta'}$ 改进到 $p^{1-\beta}$（`build/coverage-transfer.tex:93--100`）。
一降一升的搭配很反直觉：我原本以为传递覆盖必须保持地板不动。
真相是地板是"预算"、例外集是"债务"，
重复 $n_i$ 次买的是例外集改进，代价由地板付。
$\tau_i=3/8-2^{-i-3}<3/8$（`build/schedule.tex:385--387`）
这个上界正是 `build/coverage-transfer.tex:106` 的 $\tau\le3/8$ 假设，
它保证 $\sum_{i\ge0}4\delta_i=\sum2^{-i-4}=1/8$ 加在 $1/4$ 上不越界。
参数 $\delta_i=2^{-i-6}$ 与 $\eta_{i+1}=\eta_i\delta_i/100$
（`build/schedule.tex:375--379`）就是把这条约束解出来的。

### 4.5 单一终端时刻律 $t_*$

第五个转折是"所有批次共用一个时刻分布"。
`build/schedule.tex:79--83`：全部转移做完后加一个 $\{0,\dots,N-1\}$ 上的
均匀偏移，记结果为 $t_*$，"Thus all batches will be measured at the same time law."
有了它，望远镜引理 `lem:telescope` 的
$\sum_TI(X'_T;W_{L_T}(t_*)\mid O'_T)/L_T\le\log K_D+o(1)$
（`build/information.tex:306--310`）才谈得上"同一次试验里各批次的代价相加"。
每批各用自己的时刻的话，$a_{j+1}\le b_j+\epsilon_M$ 这一步（分块次可加）
就无从比较。$n_B=O(\log T_+)$ 批的误差累计
$(n_B-1)\epsilon_M=o(1)$（`build/information.tex:370--375`）也是靠 $N$ 的
$T_+^{10}$ 规模才吞得掉。

### 4.6 dyadic 词长与整除链

第六个转折是把"信息载体"选成有限增量词
$W_L(t)=(z_{t+1}-z_t,\dots,z_{t+L}-z_{t+L-1})$（`build/information.tex:22--25`），
长度取 $L_T=2^{\lfloor\log_2T^{2/5}\rfloor}$，即 $\frac12T^{2/5}<L_T\le T^{2/5}$
（`build/information.tex:27--29`）。
两个约束同时卡住它：上界 $DL<\sqrt p\le T^{1/2}$ 保证词内不重复命中同一剩余类，
下界 $L\gg T^{2/5}$ 保证 $T^{1/4}=o(L/\log T)$
（`build/information.tex:287--288`）从而位移代价 $H(s)=O_D(T^{1/4})$ 可忽略
（`build/information.tex:79--83`）。
dyadic 形态的额外好处是 $L_j\mid L_{j+1}$（`build/information.tex:329--330`），
长词能整除切块，块起点残差 $Q_j(t_*+a)$ 由 $Q_j(t_*)$ 与块前增量相加得到。
Lean 侧把这条整除性写进了结构体：`SieveCertificate.lean:18` 的
`divides : ∀ j<last, lengths j∣lengths (j+1)`，
由 `Main.lean:86--87` 用 `batchWordLength_dvd` 供给。

### 4.7 转折点的顺序

把六个转折按依赖排一下，可以看到它们并非一次想到的：
4.1 让问题变形（去掉 $D<1$ 与 $E$），4.2 让假设分层，
4.3 让熵迭代收敛，4.4 让覆盖可传递，4.5 让代价可加，4.6 让可加有载体。
其中 4.2 与 4.5 是纯次序层面的决定，
却对后面所有数值都成立起决定作用。
`build/schedule.tex:311--313` 那句
"Figure ref summarizes the two orders now in play:
sampling moves forward through the schedule, while coverage will be
proved by induction from $A_J$ back to $A_0$"
讲的是同一件事的两半：采样顺序与证明顺序相反，
这个"反向"是转折点 4.4 的最终形态（图在 `build/schedule.tex:315--358`）。

## 5 最终思路与最初设想的差异

### 5.1 障碍的形态：从几何空洞到熵收支

我最初设想的障碍是几何的：找一块平面区域，
使得任何进入它的有界步长路径都被挡住。
最终证明里唯一的"区域"概念出现在两个地方，
而且都只作计数用：其一是 `build/geometry.tex:29--39` 里
含 $E$ 的长 $R$、宽 $2W$ 的直径矩形与面积 $A=RW$，
其二是 `build/geometry.tex:88--93` 里被随机符号积避开的薄矩形 $Q$（半轴 $R_1\ge W_1\ge1$，
$R_1W_1\le P^{1-d}$）。这两处都给出的是量级
（$|E-E|\ge c_DA$，$cn\le A\le D^2n^2$，`build/geometry.tex:21--25`），
最终障碍是信息的：每个靠近 $T$ 的素数批次强制
$\frac1{L_T}\mathbb E_{\mathcal C}I(X'_T;W_{L_T}(t_*)\mid O'_T)\ge\frac{c_1}{\log T}$
（`build/information.tex:46--52`），而全体系能支付的总量只有
$\sum_T(\cdot)/L_T\le\log K_D+o(1)$（`build/information.tex:307--310`）。
左端对 $O(M)$ 个不相交窗口各贡献 $\ge c/(1.05\log B)$（`build/information.tex:398--403`），
所以发散；右端是常数。差别就在"发散 vs 常数"这一处。

### 5.2 结论强度与量的归属

最初我只想证"存在无限行走是假的"。最终交付的是 `build/main.tex:63--69` 的
一致分量界 $\#C\le B_D$，顺带才推出无限行走不存在。
更强的形态逼出了第 6 节的周期性包装：无限行走的否定式（`MainEndpoint`，
Lean 侧 `Model.lean:23--26`）确实只需删掉有限个例外相伴元
（`build/periodicity.tex:48--51`），
但一致界必须让分量向 $(\Z/Q\Z)^2$ 单射，$\#C\le Q^2$（`build/periodicity.tex:33--35`）。
另外，界 $B_D$ 从一开始我期望是显式的（比如 $B_D\le e^{e^{cD}}$），
最终是非显式的：`build/main.tex:71--73` 说
"The bound $B_D$ is nonexplicit: the proof chooses sufficiently large scales after fixing $D$"。
Lean 侧同样只给存在性：`Main.lean:15` 取的 $W$ 只要求大于
$(\log(\operatorname{latticeBall}D).\operatorname{card})+1)/\mathrm{rate}$，
$M$（`Main.lean:33--35` 的 `obtain ⟨m,hbatch,hsmooth,hm⟩`）由
`Filter.Eventually` 三合取的存在性取得，全程没有给出可计算的数值。

### 5.3 概率该放在谁身上

最初我的概率模型是给行走加测度（随机游走型论证），
最终模型的随机性全部在我这一侧：`build/main.tex:129--133` 固定任意确定的无限自避行走，
随机性只有两处，采样时刻与每个分裂素数上二选一因子。
与之配套的是一条容易被忽略的定义性约定：
`build/preliminaries.tex:67--72` 规定残差映射随机选取时
"we first fix those maps and compute entropy in the walk-sampling experiment;
only afterward do we average over the maps"，
并明确 "An expectation outside an entropy ... is an average of entropies,
not the entropy of a mixture that includes the map choices."
这条约定决定 `build/geometry.tex:240--248` 的
$f_Z(s)=\mathbb E_{\mathcal S}H(F_{\mathcal S}(Z))$ 是凹函数（`build/geometry.tex:254--262`），
从而 $f_V(b)\ge\frac12(f_X(b)+f_Y(b))$ 这种混合凸性步骤合法。
我最初的写法把映射选择也放进随机变量，熵就凭空多出 $\log\binom{k}{s}+s\log2$ 的杂费，
所有 $O_D(g)$ 级别的余量都会被它吃掉。

### 5.4 素数定理的用法变了

最初我以为 PNT 是用来控制 $\mathcal A(\mathcal P)$ 的大小的。
最终 PNT 只做一件事：数清每批有多少素数、平均对数多大。
`build/preliminaries.tex:42--45` 的 $k_T=(1/2+o(1))T/\log T$ 与
$\log T\le L_T^*\le\log(2T)$ 是全文唯一的解析输入，
而且只用到固定模 $4$、固定比值区间（`build/preliminaries.tex:51--55`）。
密度 $\prod_p(1-1/p)^2$ 一次都没出现。
最终方案里 $\mathcal P_D$ 的选取靠的是渐近参数 $M$ 与几何级数批 $T=B^j$
（`build/schedule.tex:38--48`），
其中 $B>2$ 保证批次互不相交，还保证
$\sum_{T'<T}k_{T'}\log(2T')\le e_0c_0T$（`build/schedule.tex:210--213`，
左端实际 $\le CT/(B-1)$）。也就是说 $B$ 是被"小字母表预算"这一个需求挑出来的。

### 5.5 与前人方案的取向差别

`build/main.tex:94--99` 说 Gethner 与 Stark 提出的是用小数筛（sieving by small
Gaussian primes）来获得更大的步长界，并在 $\sqrt2$ 与 $2$ 两个步长上验证了周期障碍；
`build/main.tex:99--102` 说 Vardi 研究过相应的周期互素图，
以及"无无限行走"到"分量一致有界"的转化（引 Section 6, Proposition 6.2）。
我的最终取向与他们相反：批次全部取 $T\to\infty$（`build/schedule.tex:38--48`），
小数情形只在 $D<1$ 的平凡处出现（`build/main.tex:74--75` 给出 $B_D=1$）。
差别在方向：小数筛是把有限多个同余条件叠起来穷尽局部可能性，
大素数批次是把同余条件当作可测的熵通道。
前者给出可验证的有限计算，后者给出一致但非显式的界。
`build/main.tex:103--105` 明确承认这个接续关系：
"Our finite-sieve theorem supplies congruence restrictions for each fixed step bound;
the periodic reduction below then converts those restrictions into the bound
on all Gaussian-prime components."

## 6 周期归约的逐步重建（periodicity.tex）

这一节把 `build/periodicity.tex` 那 2,791 B 的推理按步拆开，
每步都对应 Lean 里的一条定理。

第一步，无限分量给无限简单路径。设分量 $C$ 在 $Q\Z^2$ 不变的局部有限图里无限，
从某顶点出发的有限简单路径树分叉数 $\le K_D-1$、深度任意大，
逐层选有任意深后代的子节点即得无限简单路径（`build/periodicity.tex:24--29`）。
第二步，周期性给单射。若 $x,y\in C$ 且 $y-x=v\in Q\Z^2\setminus\{0\}$，
平移 $v$ 把 $C$ 送到含 $y$ 的分量、也就是 $C$ 本身，
而有限非空子集不能在非零平移下不变，故 $C\hookrightarrow(\Z/Q\Z)^2$、$\#C\le Q^2$
（`build/periodicity.tex:31--35`）。
第三步，处理被删去的相伴元集 $E$。
`build/periodicity.tex:37--38` 说被所选因子整除的高斯素数就是该因子的相伴元，
所以删掉 $E$ 后素数图是避开图的子图；
遇 $E$ 的分量至多接 $(K_D-1)|E|$ 个删 $E$ 后的分量，
因为这类分量每个都有一条边连向 $E$，而连向 $E$ 的边总数 $\le(K_D-1)|E|$
（`build/periodicity.tex:39--42`）。
合起来是 `build/periodicity.tex:19--21` 的
$\#C\le\max\{Q^2,\ |E|+(K_D-1)|E|Q^2\}$，
其中 $Q=\prod_{p\in\mathcal P}p$、$K_D=\#\{v\in\Z[i]:|v|\le D\}$
（`build/periodicity.tex:13--16`）。
第四步，闭合。Proposition 2.1 作用于 Theorem 1.2 提供的 $\mathcal P_D$
给出 $D\ge1$ 的 Theorem 1.1；$D<1$ 时不同格点不相邻，$B_D=1$
（`build/periodicity.tex:46--48` 与 `build/main.tex:74--75`）。

Lean 侧的拆分与这四步一一对应：
`LatticeComponents.lean:110` 的 `main_of_finiteSieve` 承担第一、四步（$D\ge1$ 分支），
`:495` 的 `prime_components_of_finiteSieve` 承担第二、三步（给出 $B$），
`:550` 的 `endpoints_of_finiteSieve` 把两条合起来并调用
`finite_prime_walk_bound`（`Main.lean:102--103` 用的就是它）。
`UniformEndpoint` 里那句
`(component D p).Finite ∧ (component D p).ncard ≤ B`（`Model.lean:30`）
正是 `build/periodicity.tex:19--21` 的形式化：
`ncard` 在无限集上退化为 $0$，所以作者额外要求 `Finite`，
避免基数条件被空满足。这一处细节说明形式化读到了 tex 里"每分量有限"那半句。

`Main.lean:99--100` 的 `finiteSieveEndpoint_proved` 由
`SieveCertificate.lean:52--53` 的 `finiteSieve_of_certificates` 得到，
后者输入是 `∀ D : ℝ, 1 ≤ D → Nonempty (SieveCertificate D)`，
也就是 `Main.lean:9` 的 `exists_sieveCertificate`。
证书结构体（`SieveCertificate.lean:8--20`）里有
`schedule : List ℕ`、`smoothing : ℕ`、`batches : ℕ → ℕ`、`lengths : ℕ → ℕ`、
`rates : ℕ → ℝ`、`error : ℝ`、`batch : ∀ j ≤ last, BatchCertificate ...`、
`divides : ∀ j<last, lengths j ∣ lengths (j+1)`、
以及形如 `∀ j<last, ∀ a<lengths (j+1), 2*Real.binEntropy (a/(smoothing+1))+...`
的 `smooth` 字段。`smooth` 那一行的形状（$2h(\epsilon)+\epsilon\log a$）
直接来自 `build/preliminaries.tex:146--149` 的连续性引理结论，
`divides` 来自 `build/information.tex:329--330` 的 $L_j\mid L_{j+1}$。

## 7 基础引理的逐步重建（preliminaries.tex）

### 7.1 算术事实

`build/preliminaries.tex:13--23` 列出四条反复使用的结论。
其一：$\Z[i]$ 是 Euclidean 域故唯一因子分解。
其二：$\pi\mid v$ 且 $\bar\pi\mid v$ 蕴涵 $p\mid v$（两个整数坐标都被 $p$ 整除）。
其三：$a\in\Z$ 时 $\pi\mid a$ 等价于 $p\mid a$。
其四：$\pi$ 的任何非零倍数长度 $\ge\sqrt p$。
第五条是行列式整除：$\alpha\in\Z[i]$ 作用在 $\Z^2$ 上是行列式为 $N(\alpha)$ 的整矩阵，
故 $\alpha\mid v,w$ 蕴涵 $\det(v,w)\in N(\alpha)\Z$（`build/preliminaries.tex:25--30`）。
我在第 3.7 节用到的共线性论证就是这条：$\det(w,w')\in N(c_*)\Z$ 配上
$|\det(w,w')|\le2P^{1-d}$ 与 $N(c_*)\ge P/(2T)^h$ 的规模差（`build/geometry.tex:117--123`）。
其四（倍数长度下界 $\sqrt p$）则是 `build/information.tex:200--204` 里
"两个命中点之差非零故长度 $\ge\sqrt p$，而 $\le DL<\sqrt p$" 的依据。
这两条不起眼的算术事实，一条支撑几何、一条支撑信息，
是我复用时最容易忘记的两块地基。

### 7.2 批次的三个量

$\mathcal B_T$ 定义为 $\{p$ 素数：$T\le p\le2T,\ p\equiv1\pmod4\}$，
$k_T=|\mathcal B_T|$，$L_T^*=\frac1{k_T}\sum_{p\in\mathcal B_T}\log p$
（`build/preliminaries.tex:33--37`），单批内简写 $k,L_*$。
Selberg 的加权渐近 $\sum_{p\le x,p\equiv1(4)}\log p\sim x/2$ 在 $T$ 与 $2T$ 相减，
再补上端点 $p=T$ 至多 $\log T$ 的误差，
得加权和 $(1/2+o(1))T$，夹在 $k_T\log T$ 与 $k_T\log(2T)$ 之间，
两者比值趋 $1$，故 `eq:prime-count` 成立（`build/preliminaries.tex:46--51`）。
关键是 `build/preliminaries.tex:52--55` 那句：
只涉及固定模与固定比值区间，
所以 `eq:prime-count` 里所有隐含常数对所有充分大 $T$ 一致成立。
这条一致性是我把 $M$ 推到无穷时所有 $O(\cdot)$、$o(\cdot)$ 能统一取阈值的前提；
Lean 侧对应 `PrimeMass.lean`（20,565 B）与 `Main.lean:22` 里
`δ*(2:ℝ)^j/Real.log ((2:ℝ)^(j+1)) ≤ (PrimeLogMass.dyadicBatch j).card`
这一形如 $k\ge\delta 2^j/\log(2^{j+1})$ 的下界，
其中 $T=2^j$、$L_T^*\le\log(2T)=(j+1)\log2$。

### 7.3 三条引理及其用途

位移熵（`lem:displacement`，`build/preliminaries.tex:119--131`）：
若 $|T_1-T_0|\le n$ 几乎必然，则 $H(z_{T_1}-z_{T_0})\le2\log(n+1)+O_D(1)$；
且对任何残差映射向量 $F$，$H(F(z_{T_1}))\ge H(F(z_{T_0}))-H(z_{T_1}-z_{T_0})$。
证明只有两点：位移落在半径 $Dn$ 的盘里、格点数 $\le C_D(n+1)^2$；
$F(z_{T_0})$ 由 $F(z_{T_1})$ 与位移决定。
这条引理在 `build/geometry.tex:455--459` 被用了两次
（$H(h)+H(X-Z)\le4\log(n+1)+O_D(1)=O_D(gU)$），
在 `build/schedule.tex:102--103` 给出物理位移熵 $O_D(gV)$，
在 `build/information.tex:79--83` 给出 $H(s)=O_D(T^{1/4})$。
全文最廉价也最不可或缺的估计就是它。

连续性（`lem:continuity`，`build/preliminaries.tex:142--150`）：
TV $\le\epsilon\le1/2$、乘积字母表 $\le a$ 元时
$|H(X\mid Y)-H(\widetilde X\mid\widetilde Y)|\le2h(\epsilon)+2\epsilon\log a$。
它把 `eq:smoothing` 的 $T_+^{-9}$ 变成 `build/information.tex:356--362` 的
$\epsilon_M=O_D(T_+^{-7})$。

短表熵界（`lem:list`，`build/preliminaries.tex:159--174`）：
若 $\Pr\{X\in\mathcal L(Y),|\mathcal L(Y)|\le b\}=\rho$，则
$\log a-H(X\mid Y)\ge\rho\log(a/b)-h(\rho)$。
证明用指示变量 $B$ 的链式法则
$H(X\mid Y)=H(B\mid Y)+H(X\mid B,Y)\le h(\rho)+\rho\log b+(1-\rho)\log a$。
`build/preliminaries.tex:183--185` 那句
"The event may depend on both $X$ and $Y$; no independence is used"
是这条引理最容易被误用的地方所加的保险：
Fano 型不等式容易被读者以为要 $X$ 与 $Y$ 独立，
而这里成功事件 $\{X\in\mathcal L(Y)\}$ 同时依赖两者。
`build/coverage-transfer.tex:239--243` 与 `build/information.tex:221--224`
都靠这条把"列表小且常命中"换成"熵亏有正下界"。

顺带记下 Pinsker 的推法（`build/preliminaries.tex:86--98`）：
log-sum 给出 $D_{\mathrm{KL}}(P\Vert Q)\ge D_{\mathrm{KL}}(\operatorname{Ber}(u)\Vert\operatorname{Ber}(v))$，
右端作为 $u$ 的函数在 $u=v$ 处值与一阶导都为零、二阶导 $1/[u(1-u)]\ge4$，
故 $\ge2(u-v)^2=2\operatorname{TV}(P,Q)^2$。
这个 $\ge4$ 的常数在 `build/schedule.tex:436--441` 被放大成
熵亏 $\ge c'e^{-2M^{20}}$，直接决定底带终端律能覆盖多大比例的坏坐标。

## 8 差集计数与薄矩形（geometry.tex 前半）

### 8.1 许多差引理：$|E-E|\ge c_DA$

陈述（`build/geometry.tex:16--26`）：$E$ 取行走 $n\ge1$ 步一段的点集，
$R$ 是直径，过直径端点取一条线，$W$ 取 $1$ 与"点到该线最大距离"中的大者，
$A=RW$，则 $cn\le A\le D^2n^2$ 且 $|E-E|\ge c_DA$，$c$ 绝对、$c_D$ 只依赖 $D$。
上界那半边很轻：步长界给 $R\le Dn$、$W\le R$（`build/geometry.tex:38--39`）。
下半边分两步。

第一步给 $n+1=O(A)$：每个 $E$ 中点在 $p_0p_1$ 上的投影都落在段内
（投到端点外会对另一端点距离超过 $R$，`build/geometry.tex:29--32`），
故 $E$ 在长 $R$、宽 $2W$ 的矩形内，且 $R\ge W\ge1$；
围绕 $E$ 中各格点取互不相交的半径 $1/3$ 圆盘，
它们落在矩形的固定放大里，面积 $O(RW)=O(A)$，故 $n+1=O(A)$
（`build/geometry.tex:33--36`）。

第二步给 $|E-E|\ge c_DA$，$W>1$ 时要用拓扑。
取 $p_2\in E$ 距直径线为 $W$，令 $a=p_1-p_0$、$b=p_2-p_0$、$\Lambda=\Z a+\Z b$，
平坦环面 $\R^2/\Lambda$ 的面积是 $|\det(a,b)|=RW=A$（`build/geometry.tex:41--47`）。
把行走插值成路径 $\alpha,\gamma:[0,1]\to\R^2$（从 $p_0$ 到 $p_1,p_2$），
映射 $(s,t)\mapsto\alpha(s)-\gamma(t)\pmod\Lambda$ 从参数环面
$[0,1]^2/\!\sim$ 连续落到 $\R^2/\Lambda$，因为对边上的端点差分别是 $a$ 与 $-b$
（`build/geometry.tex:48--56`）。两条路径同伦到直线段而端点固定，
故该映射以 $a,b$ 定向时度为 $-1$，特别地是满射；
理由是漏掉一点的映射可因子化通过 punctured torus，
而挖洞环面的第二同调为零，度只能为零（`build/geometry.tex:57--63`）。
再补上量化：插值点距其所在边的顶点不超过 $D$，
所以 $E-E$ 各点周围半径 $2D$ 的圆盘投影后覆盖整个目标环面，
每个投影盘面积 $\le4\pi D^2$（绕环面包覆也不算大），得
$A\le4\pi D^2|E-E|$（`build/geometry.tex:65--72`）。

我一开始在第二步卡了很久，因为我以为度论证是装饰。
真正的原因是 $A$ 可能远小于 $n^2$：一段细长（$W=1$ 型）或近似一维的行走，
朴素计数给 $|E-E|\ge n+1$ 就够了（`build/geometry.tex:38--39` 确实是这个分支），
但二维散布的情形里 $|E-E|$ 与 $A$ 的比例必须靠环面覆盖来锁住。
$h$ 是 $E_t-E_t$ 里均匀取的差，若 $|E-E|$ 只有 $n$ 级，
后面 $H(F_{\mathcal J}(h))\ge\log A-O_D(1)$ 就没有内容（见第 9 节）。

### 8.2 随机符号积避开薄矩形

陈述（`build/geometry.tex:84--101`）：$p_1,\dots,p_r$ 是 $[T,2T]$ 内互异且
$\equiv1\pmod4$ 的有理素数，$T\ge5$，$P=\prod p_i$，
$Q$ 是中心在原点、半轴 $R_1\ge W_1\ge1$、朝向任意的矩形，
$R_1W_1\le P^{1-d}$，$0<d<1/4$。若 $d^3r\ge C_0$，则独立符号选择满足
$\Pr\{Q\cap(\prod\pi_i)\Z[i]\ne\{0\}\}\le Ce^{-cd^3r}$。

证明的骨架是"先归类、再各别概率、再比类数"，三段各有不可替代的作用。
第一段（`build/geometry.tex:110--132`）：两个符号向量只差 $h\le dr/4$ 个坐标时，
公共因子乘积 $c_*$ 有 $N(c_*)\ge P/(2T)^h$，对应 witness $w=c_*u$、$w'=c_*v$ 满足
$\det(w,w')=N(c_*)\det(u,v)\in N(c_*)\Z$，而
$|\det(w,w')|\le2R_1W_1\le2P^{1-d}$；
除数与上界之比的对数至少是 $dr(\log T-\tfrac14\log(2T))-\log2$，
在 $d^3r$ 超过某绝对常数时为正，故行列式必须为零。
同一段论证适用于同一符号向量的两个 witness，所以每个坏向量有唯一 witness 线。

第二段（`build/geometry.tex:133--171`）：固定一条过零线，本原方向 $v$（两坐标互素）。
格点恰为 $\{av:a\in\Z\}$。定义 $P_\sigma(v)=\prod_{\pi_i\mid v}p_i$。
若 $\pi_i\nmid v$ 而 $\pi_i\mid av$，则 $\pi_i\mid a$，对整数 $a$ 等价于 $p_i\mid a$，
于是线上任何非零 witness 长度 $\ge|v|P/P_\sigma(v)$（`build/geometry.tex:141--148`）。
本原性保证每个 $p_i$ 的两个因子至多一个整除 $v$，且这些因子乘积的范数 $\le N(v)=|v|^2$，
所以 $\mathbb E_\sigma\log P_\sigma(v)\le\log|v|$（`build/geometry.tex:149--155`）。
$Q$ 内点长度 $\le\sqrt2R_1$ 且 $R_1\le P^{1-d}$，故线上有 witness 要求
$\log P_\sigma(v)\ge\log|v|+d\log P-\log\sqrt2$（`build/geometry.tex:156--161`）。
左边是独立变量和、每项幅度 $\le\log(2T)$，Hoeffding 给出坏概率
$\le\exp(-c_0d^2r)$（`build/geometry.tex:162--169`），
用的是 $\log P\ge r\log T$ 与 $\log(2T)/\log T$ 有界。

第三段（`build/geometry.tex:173--221`）是我犯过方向性错误的一段，见第 3.7 节。
这里补记立方体估计的推导细节：边边界 $|\partial_ES|\ge|S|\log_2(2^r/|S|)$
由对 $r$ 归纳得到，若两个半立方各含 $a|S|$ 与 $(1-a)|S|$，
内部边界之和是 $|S|(r-1-\log_2|S|+h_2(a))$，
而两半之间有至少 $|1-2a||S|$ 条跨越成员与非成员的边，
配合 $h_2(a)\ge1-|1-2a|$（在 $[0,1]$ 的两半上各用凹性）即得（`build/geometry.tex:184--195`）。
外部顶点边界因每点最多 $r$ 条入边而只损失 $1/r$：
$\ge(|S|/r)\log_2(2^r/|S|)$（`build/geometry.tex:196--200`）。
各 $S_\ell$ 两两 Hamming 距离 $>dr/4$，故半径 $h=\lfloor dr/10\rfloor$ 邻域互不相交；
每个 $|S_\ell|/2^r\le e^{-c_0d^2r}$，只要膨胀中的集合相对尺寸 $\le e^{-c_0d^2r/2}$，
每步膨胀至少乘 $1+c_1d^2$，$h$ 步后至少 $e^{c_2d^3r}$；
若提前撞上阈值，从初始尺寸起的增长已经是 $e^{c_0d^2r/2}$，调 $c_2$ 后更强
（`build/geometry.tex:210--218`）。不相交邻域总量 $\le2^r$ 收尾。

### 8.3 这条引理在我手里断过的两处

第一处：$d<1/4$ 这个范围。我一开始把它当装饰，
实际它进入 $N(c_*)\ge P/(2T)^h$ 与 $2P^{1-d}$ 的比较里，
$h\le dr/4$ 时 $(2T)^h\le P^{d/4\cdot(1+o(1))}$ 一类估算要保证
$\log(N(c_*)/(2P^{1-d}))$ 里 $-\frac14\log(2T)$ 这一项被 $\log T$ 支配。
第二处：$d^3r\ge C_0$ 的三次方。$d$ 出现三次是三段相乘的痕迹
（一次在距离阈值 $dr/4$、一次在尾指数 $d^2r$、一次在膨胀步数 $h\asymp dr$ 与
每步增长 $d^2$ 的乘积）。我原以为能优化成 $d^2r$，看了三段结构后明白
立方是这套论证的自然产物。

## 9 熵增益转移（geometry.tex 后半）

### 9.1 记号与凹性

固定批次 $\mathcal P$（$k$ 个 $[T,2T]$ 内的 $1\bmod4$ 素数），
$L_*=\frac1k\sum_{p\in\mathcal P}\log p$。有符号子集 $\mathcal S$ 是
$\mathcal P$ 的子集加上每个素数二选一的因子，元素数按有理素数计，
同一素数的两个因子不同时出现。定义
$F_{\mathcal S}(Z)=(Z\bmod\pi)_{\pi\in\mathcal S}$，
$f_Z(s)=\mathbb E_{\mathcal S}H(F_{\mathcal S}(Z))$，其中 $s$ 个底层素数无放回均匀取、
符号独立公平（`build/geometry.tex:230--248`）。
于是 $f_Z(0)=0$、$0\le f_Z(s)\le sL_*$，且 $f_Z$ 在整数区间上凹：
取批次的均匀排列与独立符号，$f_Z(s+1)-f_Z(s)$ 是下一坐标给定前 $s$ 个的平均条件熵，
未暴露坐标的可交换性加"条件化降熵"使这些差分随 $s$ 递减
（`build/geometry.tex:251--262`）。
这个凹性在两个地方被单向使用：
把前向差分夹住（`build/geometry.tex:475--477`）与把 $f(s)$ 除回 $f(1)$
（`build/schedule.tex:303` 的 concavity 给出 $f(1)\ge f(s)/s$）。

### 9.2 转移规则的取样细节

给参数 $U>0$、$0<g<10^{-2}$，令 $n=\lfloor e^{gU}\rfloor$；
精确时刻 $t$ 处 $E_t=\{z_t,\dots,z_{t+n}\}$（`build/geometry.tex:264--268`）。
条件于 $\tau=t$，先从 $E_t-E_t$（含零）均匀取差 $h$，
再用一个确定规则选出一对 $(X,Y)\in E_t^2$ 使 $X-Y=h$，
最后 $V$ 以 $1/2$ 概率取 $X$ 或 $Y$（独立硬币）。
关键设计是"差等权，点对按确定规则补齐"（`build/geometry.tex:270--275`）：
若改成对有序点对均匀取，则每个差的权重正比于它的表示数，
自避段里小差（近邻）会被大量重复表示支配，
$H(F_{\mathcal J}(h))\ge\log|E-E|-O(1)$ 这种下界立刻失去内容。
自避性把每个端点与 $[t,t+n]$ 内唯一行走时刻等同，
所以这是一个时刻律的前向转移，推进不超过 $n$，且不用任何素数指标
（`build/geometry.tex:275--278`）。

### 9.3 熵增益不等式

`lem:enrichment`（`build/geometry.tex:280--298`）：取 $Z=z_\tau$、$q=\lfloor U/L_*\rfloor$、
$b=\lfloor g^2U/L_*\rfloor$，在 $D$ 固定、$T\to\infty$、$q\le k$、
且对每个固定 $C>0$ 有 $g^CU/\log T\to\infty$ 的渐近族里，
一致地有 $f_V(b)/(bL_*)\ge\frac12(1+f_Z(q)/(qL_*))-O_D(g)$。
右端保留起点熵比例的一半，再加满额比例的一半，
所以只要把下一段的输入坐标数配成上一段的输出坐标数（即 $q_{\text{next}}=b_{\text{prev}}$），
迭代就压亏格，这是 `build/geometry.tex:300--306` 自己点明的用法。

证明分两段。第一段给"新差坐标的近满额熵"
（`eq:difference-coordinate`，`build/geometry.tex:320--326`）：
均匀取 $q$ 大小有符号集 $\mathcal Q$，其中均匀取 $b$ 大小前缀 $\mathcal S$，
记 $B_x=F_{\mathcal S}(X)$、$B_y=F_{\mathcal S}(Y)$、$h=X-Y$，
要证 $\mathbb E H(h_j\mid B_x,B_y)\ge(1-O_D(g))L_*$。
固定基底时刻 $t$，用 8.1 的 $A$，有 $gU-O_D(1)\le\log A\le2gU+O_D(1)$，
取 $r=\lceil(1+10g)\log A/L_*\rceil$，充分大参数下 $gq/2\le r\le3gq\le q-b$。
$\mathcal J$ 是剩余坐标里均匀的 $r$ 元子集，其素数 log 乘积均值 $rL_*$、
方差 $O(r)$（$\log p$ 落在长度 $\log2$ 的区间内、无放回抽样），
故 $\Pr\{\sum_{\mathcal J}\log p<(1+5g)\log A\}=O(1/(g^2rL_*^2))$
（`build/geometry.tex:338--348`）。在此坏事件之外，
$P^{1-g}\ge A^{(1+5g)(1-g)}\ge A^{1+3g}>16A$，
而直径矩形坐标系里"差的差"落在半轴 $4R,4W$、乘积 $16A$ 的矩形内
（`build/geometry.tex:350--357`），于是 8.2 以 $d=g$ 给出 injective 约化，
额外坏概率 $O(e^{-cg^3r})$。总异常概率
$\epsilon=O(1/(g^2rL_*^2)+e^{-cg^3r})$，在题设渐近下 $\epsilon=o(g)$
（`build/geometry.tex:363--382`）。好事件上均匀性与单射给出
$H(F_{\mathcal J}(h)\mid\tau=t)\ge\log A-O_D(1)$，
再多条件 $B_x,B_y$ 至多花 $2b\log(2T)$，除以 $r$ 并对比
$\log A/(rL_*)\ge1-O(g)$、$b/r=O(g)$ 得第一段（`build/geometry.tex:384--419`）。
这里有个我原先漏掉的技巧：$r$ 依赖 $t$ 也不妨碍把平均条件熵往下界转化，
因为此刻 $t$ 已固定、$\mathcal J$ 中每个坐标的剩余坐标边缘都是均匀的
（`build/geometry.tex:408--411`）。

第二段是链式法则搬运（`build/geometry.tex:421--479`）。对固定指标，
$(F_j(X),F_j(Y))$ 等价于 $(h_j,F_j(X))$，于是
$H(h_j\mid B_x,B_y)\le H(F_j(X)\mid B_x)+H(F_j(Y)\mid B_y)-H(F_j(X)\mid B_x,B_y,h)$
（`eq:enrichment-chain`）。
最后一个条件化用的是整个差 $h$，只条件在 $h_j$ 上会让被减项变小、不等式方向变坏
（`build/geometry.tex:437--439`）。把被减项在 $q-b$ 个剩余坐标上求和，
得到不小于 $H(F_{\mathcal Q}(X)\mid B_x,B_y,h)$，
其平均不小于 $f_X(q)-2b\log(2T)-H(h)$；又
$f_X(q)\ge f_Z(q)-H(X-Z)$；$h$ 与 $X-Z$ 都是长度 $\le Dn$ 的格位移，
故 $H(h)+H(X-Z)\le4\log(n+1)+O_D(1)=O_D(gU)$。
综合得被减项平均 $\ge f_Z(q)/q-O_D(g)L_*$。
前两项的平均是 $f_X(b+1)-f_X(b)$ 与 $f_Y(b+1)-f_Y(b)$，
合并第一段就是 $[f_X(b+1)-f_X(b)]+[f_Y(b+1)-f_Y(b)]\ge L_*+f_Z(q)/q-O_D(g)L_*$；
凹性与 $f_X(0)=f_Y(0)=0$ 把两个前向差分夹在 $f_X(b)/b$、$f_Y(b)/b$ 以下，
混合凸性给 $f_V(b)\ge\frac12(f_X(b)+f_Y(b))$，除以 $bL_*$ 得证。

## 10 共享代价与一步覆盖转移（coverage-transfer.tex）

### 10.1 抽象框架

这一节把高斯算术全部剥掉：$\Lambda$ 是有限生成自由 Abel 群，
$1\le j\le k$、$\sigma\in\{+,-\}$ 给出同态 $\phi_{j,\sigma}:\Lambda\to G_{j,\sigma}$，
$|G_{j,\sigma}|=p_j$，$T\le p_j\le2T$、$T\ge2$，
$\overline L=\frac1k\sum\log p_j$，
$\mathop{\mathrm{av}}_cu_c=\frac1{2k}\sum_{j}\sum_{\sigma}u_{j,\sigma}$（`build/coverage-transfer.tex:13--26`）。
坐标记 $c=(j,\sigma)$，共 $2k$ 个；$S$ 是均匀选的 $s$ 个互异指标加独立公平符号，
$F_S(Y)=(\phi_c(Y))_{c\in S}$，且 $S$ 与被测熵的变量独立
（`build/coverage-transfer.tex:27--33`）。
`build/coverage-transfer.tex:2--5` 强调这层抽象"applies beyond Gaussian arithmetic"，
读作方法论自陈：作者要的是可复用的原理，
而第 12 节里 `build/schedule.tex:363--368` 才把它实例化回 $\Z[i]/(\pi)$。

### 10.2 一次共享条件代价

`lem:conditioning`（`build/coverage-transfer.tex:34--47`）：若
$\mathbb E_SH(F_S(Y))\ge(1-\epsilon)s\overline L$ 且 $H(\mathcal H)\le\kappa s\overline L$，则
$\mathop{\mathrm{av}}_c[\log p_c-H(\phi_c(Y)\mid\mathcal H)]\le(\epsilon+\kappa)\overline L$，
且不要求 $Y$ 与 $\mathcal H$ 独立。
证明三行（`build/coverage-transfer.tex:49--58`）：
$H(F_S(Y))-H(\mathcal H)\le H(F_S(Y)\mid\mathcal H)\le\sum_{c\in S}H(\phi_c(Y)\mid\mathcal H)$，
每个有符号坐标以 $s/(2k)$ 概率属于 $S$，取平均再除 $s$。
这个引理是第 3.6 节那条弯路的正式解药：代价 $\kappa$ 只按一份数据算。

### 10.3 混合实验与覆盖定义

$A$ 是有限混合变量，$y$ 把其字母表映到 $\Lambda$，$Y=y(A)$；
每个 $a$ 指定一个位移律 $\nu_a$，条件于 $A$ 独立取 $h_1,\dots,h_n\sim\nu_A$，
$\mathcal H=(h_1,\dots,h_n)$、$Z=Y+h_1$（`build/coverage-transfer.tex:70--78`）。
在行走应用里 $A$ 记录精确中间时刻、$Y$ 是其位置、$\nu_a$ 是从该时刻到终点的位移律。
覆盖的定义（`build/coverage-transfer.tex:85--91`，`eq:coverage-definition`）：
$\#\{u:\mathbb P(X=u)<\tau/p\}<p^{1-\beta}$，
并强调低质量集合可能非空、这里只对例外个数作断言。

### 10.4 转移定理与它的六组假设

`thm:transfer`（`build/coverage-transfer.tex:102--129`）：
$0<\tau\le3/8$、$0<\delta\le1/64$、$\tau'=\tau+4\delta$、$0<\beta'\le\beta<1$、
$0<\eta\le1$、$0\le\eta'\le1$；假设在每个 $a$ 上，
除比例至多 $\eta'$ 的坐标外，条件律 $\phi_c(y(a)+h_1)$ 有 $(\tau',\beta')$ 覆盖；
熵预算 $\epsilon+\kappa\le\eta\delta\beta'/16$ 与 $\eta'\le\eta\delta/100$；
规模条件 $p\exp(-\delta^2np^{-\beta}/2)\le\delta/100$、$\delta^{-1}<p^{\beta'/2}$、
$\log(2e/\delta)\le(\beta'/4)\log T$。
结论：除比例至多 $\eta$ 的坐标外，$\phi_c(Z)$ 有 $(\tau,\beta)$ 覆盖。

证明四段。设坏坐标比例为 $\theta>\eta$，每个坏坐标选
$K_c\subseteq\{u:\mathbb P(\phi_c(Z)=u)<\tau/p\}$、$|K_c|=u_p=\lceil p^{1-\beta}\rceil$。
列表定义为
$\mathcal L_c(\mathcal H)=\{x:\sum_{\ell\le n}\mathbf1\{x+\phi_c(h_\ell)\in K_c\}\le n(\tau+\delta)u_p/p\}$
（`eq:list-definition`）。

第一段（命中概率）：每个 $Y+h_\ell$ 与 $Z$ 同律，
故在 $x=\phi_c(Y)$ 处计数期望 $\le n\tau u_p/p$，Markov 给
$\Pr\{\phi_c(Y)\in\mathcal L_c(\mathcal H)\}\ge1-\tau/(\tau+\delta)=\delta/(\tau+\delta)\ge\delta$
（`build/coverage-transfer.tex:149--158`）。
只用共同的单次试验边缘律，条件于 $A$ 之前无需独立。

第二段（列表大小）：固定 $A=a$，若该坐标在此有 $(\tau',\beta')$ 覆盖，
平移 $\phi_c(y(a))$ 说明 $\phi_c(h_\ell)$ 的条件律在集合 $E_{a,c}$（大小 $<p^{1-\beta'}$）
之外给至少 $\tau'/p$。有限 Abel 群里的计数恒等式
$\sum_{x\in G_c}|(K_c-x)\cap E_{a,c}|=u_p|E_{a,c}|$（`build/coverage-transfer.tex:166--169`）
让我至多除去 $|E_{a,c}|/\delta$ 个候选，其余 $x$ 满足
$|(K_c-x)\cap E_{a,c}|\le\delta u_p$，从而每次条件试验命中概率
$\ge\tau'(1-\delta)u_p/p\ge(\tau+2\delta)u_p/p=:\lambda$；
验证 $(\tau+4\delta)(1-\delta)-(\tau+2\delta)=\delta(2-\tau-4\delta)>0$
（`build/coverage-transfer.tex:176--181`）。

第三段（下尾集中）：给定精确 $a$ 时计数随机地优于一
$\operatorname{Bin}(n,\lambda)$，乘性下尾给
$\Pr\{\operatorname{Bin}(n,\lambda)\le n(\lambda-\delta u_p/p)\}\le\exp(-n(\delta u_p/p)^2/(2\lambda))\le\exp(-\delta^2np^{-\beta}/2)$
（`build/coverage-transfer.tex:182--192`）；
完整推导是 $\mathbb E e^{-tB}\le\exp(n\lambda(e^{-t}-1))$、
取 $t=-\log(1-v)$ 得 $\exp[-n\lambda(v+(1-v)\log(1-v))]\le\exp(-n\lambda v^2/2)$，
再代 $v=\delta/(\tau+2\delta)$，用到 $u_p/p\ge p^{-\beta}$ 与 $\tau+2\delta<1$
（`build/coverage-transfer.tex:193--201`）。对 $p$ 个候选取并，
条件概率至少 $1-\delta/100$ 下列表只剩至多
$\delta^{-1}p^{1-\beta'}<p^{1-\beta'/2}$ 个例外候选（`eq:small-list`）。

第四段（矛盾）：在坏坐标与 $A$ 上取平均，失败概率的均值 $\le\eta'/\theta<\delta/100$，
于是 $a_c=\Pr\{\phi_c(Y)\in\mathcal L_c(\mathcal H),|\mathcal L_c(\mathcal H)|\le p_c^{1-\beta'/2}\}$
的均值 $\overline a\ge\delta-\delta/100-\eta'/\theta\ge\delta/2$。
`lem:list` 给 $\log p_c-H(\phi_c(Y)\mid\mathcal H)\ge a_c(\beta'/2)\log p_c-h(a_c)$，
$h$ 的凹性与 $h(u)\le u\log(e/u)$ 给 $\mathop{\mathrm{av}} h(a_c)\le\overline a\log(2e/\delta)$，
再用 `eq:transfer-log` 得坏坐标平均亏格 $\ge\overline a\beta'\log T/4\ge\delta\beta'\log T/8$。
其余坐标亏格非负，$\overline L\le\log(2T)\le2\log T$、$\theta>\eta$，
故全体均值严格大于 $\eta\delta\beta'\log T/8\ge\eta\delta\beta'\overline L/16$，
与 `lem:conditioning` 加 `eq:transfer-budget` 冲突，故 $\theta\le\eta$
（`build/coverage-transfer.tex:221--265`）。

### 10.5 我在这一节上的两个错序

第一个错序是我先证列表小、后证真残差常命中，结果第二段依赖了 $A=a$ 的条件律，
而第一段的命中概率若也用条件律就要求"该坐标在下一 checkpoint 被覆盖"这件事
对当前坏坐标成立，这我根本没有。论文的切法把两件事的依赖关系拆开了：
命中只用共同边缘律（无条件于覆盖），列表大小才用下一 checkpoint 的覆盖，
平均那一步（第四段）才把两者合起来。
`build/coverage-transfer.tex:217--220` 那句
"We have used next-checkpoint coverage only after fixing its exact value.
It remains to average over that value without assuming that a coordinate
deficient now is necessarily covered at the next checkpoint."
正是对这个错序的正面回应。

第二个错序是关于 $\tau$ 与 $\beta$ 的取舍方向。
我原本设的传递是"保持 $\tau$，改进 $\beta$"，
但列表阈值 $(\tau+\delta)u_p/p$ 与命中概率 $\delta/(\tau+\delta)$ 只在
$\tau'<\tau$ 的降级下才买得到 $n_i$ 次重复的收益：
$\tau_i=\tau_0+\sum_{m<i}4\delta_m$ 单调上升到 $3/8-2^{-i-3}$，
而 $\beta_i=2^{-i}\beta_0$ 单调下降（`build/schedule.tex:228--229`、`:375--377`）。
一个变量升、一个变量降，才能形成归纳闭环：升的那个提供
$\delta/(\tau+\delta)\ge\delta$ 的命中余量，降的那个给出 $p^{1-\beta}$ 的例外规模。

## 11 常数次序与三带时间表（schedule.tex 前半）

### 11.1 常数必须按什么次序选

`build/schedule.tex:27--36` 给出固定量 $\beta_0=1/200$、$e_0=\beta_0/50$，
然后声明选取次序：先由 $D,e_0$ 定迭代次数 $l_0$ 与 $0<g_0<10^{-2}$，
它们定出 $c_0>0$，之后才选充分大的固定 $B>2$，
最后才是渐近参数 $M$。全部常数在 $M$ 之前固定，且与行走、起始时刻无关。
这段"次序声明"在论文里只占五行，在我心里它占了整节的难度。
我曾把 $B$ 与 $g_0$ 对调，结果两个需求互相打架：
$B$ 决定窗口 $[X_m,1.05X_m]$ 内可用批数（至少 $cX_m/\log B$ 个，
`build/information.tex:398--400`），$g_0$ 决定顶带单次迭代的误差 $O_D(g)$。
按论文的次序，先固定 $l_0,g_0$ 使 $2^{-l_0}<e_0/3$ 且总误差 $<2e_0/3$
（`build/schedule.tex:192--194`），此时 $c_0$ 已经落定（可取任何足够小的、
小于 $a_0g_0^{2(l_0+1)}/2$ 的常数，见 `build/schedule.tex:204--205`），
然后 $B$ 只需满足 $\sum_{T'<T}k_{T'}\log(2T')\le e_0c_0T$，
而左端实际 $\le CT/(B-1)$（`build/schedule.tex:210--213`），
$B$ 越大越松。次序一颠倒，$B$ 就同时被两件事约束，我原来的写法没有解。

### 11.2 窗口、批次与 $T_+$

$X_m=100^m$（$\lceil M/2\rceil\le m\le M$），使用的批次是
$T=B^j$（$j\in\Z$）中满足 $X_m\le\log T\le1.05X_m$ 的那些
（`build/schedule.tex:38--47`），$B>2$ 保证批次互不相交。
本轮 $M$ 下所有批次之并就是最终 Theorem 1.2 要用的有限素数选择，
记 $T_+=\exp(1.05X_M)$（`build/schedule.tex:49--51`）。
这里我最初的写法是 $\log T=m$ 之类的等差窗口，
那会让 $\sum_T1/\log T$ 的发散速度变成 $\log M$ 级，
最终矛盾（`build/information.tex:393--406`）要求的是 $O(M)$ 个互不相交窗口、
每个贡献 $\ge c/(1.05\log B)$，所以窗口必须按 $100^m$ 几何增长。
$100$ 这个数字本身没有内容，它只需要比带边界比值
（$1.3/0.05=26$）大，$1.05$ 也只需覆盖 $j\log B$ 的格点步长。

### 11.3 三带与下滑规则

从时刻 $0$ 出发，按 $U$ 递减顺序反复施加 `lem:enrichment` 的转移，
每个 $m$ 用三条带（`build/schedule.tex:63--77` 的表）：

| 带 | $\log U$ 区间 | 参数 |
|---|---|---|
| 顶带 | $[0.8X_m,1.3X_m]$ | $g_0$ |
| 中带 | $[0.20X_m,0.30X_m]$ | $g_1=e^{-M^3}$ |
| 底带 | $[0.05X_m,0.10X_m]$ | $g_2=e^{-100M^{20}}$ |

带内从 $\log U$ 的高端起步，每次减 $2\log(1/g)$，只要结果仍留在带内
（等价于相邻 $U$ 之比恰为 $g^2$，`build/schedule.tex:56--59`）。
这个 $g^2$ 与 `lem:enrichment` 里 $b=\lfloor g^2U/L_*\rfloor$ 是同一件事的两面：
下一次转移的输入坐标数 $q$ 要等于上一次的输出坐标数 $b$，
即 $q_{\text{next}}=\lfloor U_{\text{next}}/L_*\rfloor=\lfloor g^2U/L_*\rfloor=b_{\text{prev}}$，
所以尺度必须按 $g^2$ 递减。我第一次读到这里以为是巧合，
实际是迭代的匹配条件，见 `build/schedule.tex:163--166`
"The output size of one transition and the input size of the next are
both exactly $\lfloor g^2U/L_*\rfloor$"。
窗口按 $m$ 递减处理，带内尺度递减；所有随机化在当前精确行走时刻条件下都是新鲜的，
这些转移不使用任何素数子集或符号选择（`build/schedule.tex:60--61`）。
全部做完后加一个 $\{0,\dots,N-1\}$ 上的独立均匀偏移，$N=\lceil T_+^{10}\rceil$，
结果记为 $t_*$，于是所有批次在同一时刻律下被测（`build/schedule.tex:79--83`）。

### 11.4 前移位与平滑

`lem:future-shift`（`build/schedule.tex:94--110`）：设 $V$ 是参数为 $g$ 的带里的一个日程尺度，
则从 $V$ 之前那个 checkpoint 到任何后续 checkpoint（含 $t_*$）的总前移时间
$\le S_V$，且 $\log(1+S_V)\le2gV$，故物理位移熵是 $O_D(gV)$；
另外条件于任何更早的精确 checkpoint 起点，有 `eq:smoothing`
$\operatorname{TV}(\mathcal L(t_*),\mathcal L(t_*+a))\le T_+^{-9}$（$0\le a\le T_+$）。
证明里可取 $S_V=N-1+\sum_{U\text{ remaining}}\lfloor\exp(g_UU)\rfloor$
（`build/schedule.tex:111--116`），每个加数与偏移长度都由日程预先固定。
操作总数是 $O_{g_0}(X_M)=\exp(O_{g_0}(M))$。带内未来对数长度 $\le gV$；
带间落差至少 $\exp(cX_m)$，包括从 $m$ 的底带到 $m-1$ 的顶带这段
（$0.05X_m-1.3X_{m-1}=0.037X_m$，`build/schedule.tex:123--127`）；
这个落差支配所有参数比，因为 $\log(1/g_2)=100M^{20}=o(X_{\lceil M/2\rceil})$。
最小尺度与最小参数处 $\log(gV)\ge0.05X_{\lceil M/2\rceil}-100M^{20}$，
故 $X_M=o(gV)$ 一致成立；对全部剩余长度之和取对数只添 $O_{g_0}(M)$，于是 $2gV$ 成立。
平滑那半边只用最后那个偏移：$t_*=\widetilde t+U_N$，
平移 $a\le T_+$ 改变其律至多 $a/N$，混合与确定性平移都不放大该界
（`build/schedule.tex:139--147`）。
我在这一段的弯路是试图用 $S_V$ 的显式值去估 TV，
其实两者无关：TV 只由 $N$ 控制，$S_V$ 只由熵代价控制。

### 11.5 迭代式与顶带产出的熵

同一带内连续 $l$ 次转移、结束于下一尺度 $V$ 之前，
写归一化亏格 $d_j$，`eq:enrichment` 给出 $d_{j+1}\le d_j/2+C_Dg$，
$d_0\le1$ 迭代出 $d_l\le2^{-l}+2C_Dg$，于是 `eq:iterate`
$f_Z(\lfloor V/L_*\rfloor)/(\lfloor V/L_*\rfloor L_*)\ge1-2^{-l}-O_D(g)$
（`build/schedule.tex:163--176`）。
同一界在任何更晚的 checkpoint 仍成立，只多一个 $O_D(g)$：
由 `lem:future-shift` 与 `lem:displacement`，固定子集规模下的熵损失是 $O_D(gV)$，
而 $\lfloor V/L_*\rfloor L_*\ge V/2$（`build/schedule.tex:176--182`）。
这里最容易被读错的一点是保持性的论述对象：
后面的熵是该实验里的边际熵，不能把后来的精确时刻也条件进去，
否则位置被唯一确定、残差熵归零（`build/schedule.tex:182--185`）。

顶带最终产出（`build/schedule.tex:187--205`）：取绝对常数 $a_0>0$ 使
$a_0T/L_*\le k_T$（依 `eq:prime-count`），
从满足 $U\le a_0T$ 的第一个顶带尺度起（其值介于 $g_0^2a_0T$ 与 $a_0T$ 之间），
跑 $l_0$ 次并记 $q_T=\lfloor V/L_*\rfloor$，则每个后续 checkpoint 的点变量 $Z$ 满足
$f_Z(q_T)\ge(1-e_0)q_TL_*$ 且 $q_TL_*\ge c_0T$。
"$q_T$ 不超过 $k_T$"这一路约束由 `build/schedule.tex:151--155` 兜住：
每次熵估计都从 $q\le k_T$ 的尺度起步，其后同块内尺度更小。

## 12 checkpoint 与后向覆盖归纳（schedule.tex 后半）

### 12.1 checkpoint 的参数族

`build/schedule.tex:226--240`：$\beta_i=2^{-i}\beta_0$、$r_0=1/4$、$r_{i+1}=r_i-2\beta_i$，
$J=J(T)$ 是使 $\beta_J\log T\le M^{20}$ 的最小指标。
因 $\beta_0\log T>M^{20}$（$M$ 充分大）故 $J\ge1$，最小性给出
$J=O(M)$、$M^{20}/2<\beta_J\log T\le M^{20}$、$0.23<r_i\le0.25$，
最后一条来自 $r_i=1/4-4\beta_0(1-2^{-i})$。
$A_i$ 定义为第一个满足 $U\le T^{r_i}$ 的日程操作之前的 checkpoint，
其尺度落在 $(g_1^2T^{r_i},T^{r_i}]$，且全都位于此 $m$ 的中带，
因为 $0.23X_m<r_i\log T\le0.2625X_m$（`build/schedule.tex:241--247`）。
我原先把 $J$ 当固定整数，后来发现 $\beta_J\log T\asymp M^{20}$ 随 $T$ 变，
于是终点精度也必须随之变，这直接导致底带要跑 $\lceil200M^{20}\rceil$ 次迭代。

$A_i$ 之后的所有可能位移都在 $\mathcal D_i=\{v\in\Z[i]:|v|\le DS_i\}$ 里，
$S_i$ 是 `lem:future-shift` 给的确定性上界，
故 $\log|\mathcal D_i|\le C_DT^{r_i}$（`build/schedule.tex:248--259`），
从而一致地 $H(z_A-z_{A_i})\le C_DT^{r_i}$ 对任何更晚 checkpoint $A$ 成立
（`eq:checkpoint-displacement`）。
`build/schedule.tex:264--267` 特别指出：共同支撑界比在每个精确起点上的
单独条件熵界更强，因为它在下一 checkpoint 随机时也控制位移数据的无条件熵。
这一句是我在 10.3 的混合实验里必须用支撑界的具体原因。

### 12.2 两个精度层级

中带给出 checkpoint 间的高联合熵（`build/schedule.tex:269--289`）：
从 $A_i$（$i<J$）精确出发到 $A_{i+1}$，$Y=z_{A_{i+1}}$，
存在不依赖该起点的确定规模 $s_i$ 使
$f_Y(s_i)\ge(1-e^{-cM^3})s_iL_*$ 且 $s_iL_*\ge\exp(r_i\log T-O(M^6))$。
取 $\lceil M^3\rceil$ 次迭代：首个对数尺度与 $r_i\log T$ 差不到 $2M^3$，
这些迭代消耗 $O(M^6)$ 对数尺度；起始子集规模 $\le k_T$，
因为 $U\le T^{r_i}\le T^{1/4}=o(T)$ 且 $k_TL_*\asymp T$；
它们排在 $A_{i+1}$ 之前放得下，因为 $(r_i-r_{i+1})\log T=2\beta_i\log T>2M^{20}$。
底带给出一坐标的高精度（`build/schedule.tex:291--307`）：
从 $A_J$ 任一精确出发进入底带，跑 $\lceil200M^{20}\rceil$ 次，记录规模 $s$，
首尺度 $\le\exp(0.10X_m)=o(T)$ 故初始规模仍 $\le k_T$；
所需对数跨度 $O(M^{40})=o(X_m)$，容得下；亏格含保持到 $t_*$ 的代价至多
$2^{-\lceil200M^{20}\rceil}+O_D(e^{-100M^{20}})\le e^{-90M^{20}}$；
凹性 $f(1)\ge f(s)/s$ 给出 `eq:terminal-entropy`
$f_{z_{t_*}}(1)\ge(1-e^{-90M^{20}})L_*$。
这两条正是覆盖归纳的两个输入：checkpoint 之间的高联合熵与一端极准的基例。

### 12.3 覆盖参数族与命题

`build/schedule.tex:374--393`：
$\tau_0=1/4$、$\delta_i=2^{-i-6}$、$\tau_{i+1}=\tau_i+4\delta_i$、$\eta_0=1/100$、
$\eta_{i+1}=\eta_i\delta_i/100$。展开得
$\tau_i=3/8-2^{-i-3}<3/8$ 与 $\eta_i=100^{-(i+1)}2^{-i(i-1)/2-6i}$；
由 $J=O(M)$ 得 $\log(1/\delta_i)=O(M)$、$\eta_i\ge\exp(-O(M^2))$、
$\eta_i\delta_i\beta_{i+1}\ge\exp(-O(M^2))$（最后一条只需 $i<J$）。
记号 $b_{i,a,\pi}(u)$ 表示"从 $A_i=a$ 精确出发跑完剩余日程"的终端残差律，
`build/schedule.tex:402--404` 用冒号说明这是实验定义，
对概率为零的起点同样有意义。
我第一版直接用条件概率 $\Pr\{\cdot\mid A_i=a\}$ 写这里，
被自己在 10.3 的混合设定顶回来：$a$ 在从 $0$ 出发的实验里可能零概率，
条件化没有定义。改成"重新起一个实验"之后所有步骤合法。

`prop:coverage`（`build/schedule.tex:406--414`）：$M$ 充分大时，
一致地对所有批次、所有 $0\le i\le J$、所有 $A_i$ 处的精确起点 $a\ge0$，
至多 $\eta_i$ 比例的有符号素数违反 $\#\{u:b_{i,a,\pi}(u)<\tau_i/p\}<p^{1-\beta_i}$。

### 12.4 基例：底带精度换来 $p^{-\beta_J}$ 的抵消

固定 $A_J$ 的精确起点。`eq:terminal-entropy` 说终端残差律对均匀律的平均相对熵
$\le e^{-90M^{20}}L_*$。若某有符号素数违反覆盖，其低概率集合至少 $p^{1-\beta_J}$ 个元，
均匀律在该集合上比终端律多给 $(1-\tau_J)p^{-\beta_J}$，
故 $\operatorname{TV}\ge(1-\tau_J)p^{-\beta_J}\ge ce^{-M^{20}}$
（用 $p\le2T$、$\tau_J<3/8$、$\beta_J\log T\le M^{20}$，`build/schedule.tex:426--435`）。
Pinsker 使每个这样的熵亏 $\ge c'e^{-2M^{20}}$，
对失败坐标平均后其比例 $\le CL_*e^{-88M^{20}}=\exp(-88M^{20}+O(M))<\eta_J$
（`build/schedule.tex:436--447`）。
这里 $-88$ 对 $-2$ 的余量（$e^{-90M^{20}}$ 减 $e^{-2M^{20}}$ 再除 $L_*$）
是 $200M^{20}$ 次迭代买来的；我原先估算 $60M^{20}$ 次，
那会让 $e^{-2M^{20}}$ 的平方损失与 $e^{-58M^{20}}$ 竞争失败，
因为 $\eta_J\ge e^{-O(M^2)}$ 虽然更松，但 $L_*$ 因子与 $O(M)$ 的修正
需要指数余量至少 $M^{20}$ 数量级才稳。

### 12.5 归纳步与逐项核对

设 $i+1$ 已证。固定精确起点 $A_i=a$，跑到 $A_{i+1}$ 得 $Y=z_A$（$A=A_{i+1}$），
条件于该精确时刻独立重复 $n_i=\lceil T^{6\beta_i/5}\rceil$ 次剩余延续，
位移 $h_1,\dots,h_{n_i}$、$\mathcal H=(h_1,\dots,h_{n_i})$；
每个 $Y+h_\ell$ 都服从从 $A_i=a$ 出发的终端律
（`build/schedule.tex:449--462`）。
由 `eq:native-data`，所有 $h_\ell$ 同属 $\mathcal D_{i+1}$（即使 $A$ 变动），
故该固定起点实验中 $H(\mathcal H)\le C_Dn_iT^{r_{i+1}}$，
配合 `eq:checkpoint-entropy` 得
$\kappa_i=H(\mathcal H)/(s_iL_*)\le C_D\exp(-\frac45\beta_i\log T+O_D(M^6))\le e^{-M^3}$
（`build/schedule.tex:462--476`）。
指数 $\frac45\beta_i$ 是付完全部 $n_i$ 次延续之后剩下的余量
（$n_i\le2T^{6\beta_i/5}$、$r_i-r_{i+1}=2\beta_i$、$\beta_i\log T>M^{20}$）。

核对 `thm:transfer` 的六项代入
$(\tau,\delta,\tau',\beta,\beta',\eta,\eta')=(\tau_i,\delta_i,\tau_{i+1},\beta_i,\beta_{i+1},\eta_i,\eta_{i+1})$：
归纳假设给条件覆盖，`eq:checkpoint-entropy` 给联合熵输入（$\epsilon_i=e^{-cM^3}$），
而 $\epsilon_i+\kappa_i\le\eta_i\delta_i\beta_{i+1}/16$、$\eta_{i+1}=\eta_i\delta_i/100$
在 $M$ 大时成立；集中条件方面
$n_ip^{-\beta_i}\ge2^{-\beta_i}T^{\beta_i/5}\ge\frac12\exp(M^{20}/5)$，
故 $\delta_i^2n_ip^{-\beta_i}/2\ge\exp(M^{20}/5-O(M))$，
它同时支配 $\log p\le1.05\cdot100^M+\log2$ 与 $\log(100/\delta_i)=O(M)$，
于是 $p\exp(-\delta_i^2n_ip^{-\beta_i}/2)\le\delta_i/100$；
余下两条 $\delta_i^{-1}<p^{\beta_{i+1}/2}$ 与
$\log(2e/\delta_i)\le(\beta_{i+1}/4)\log T$ 由 $\log(1/\delta_i)=O(M)$ 与
$\beta_{i+1}\log T>M^{20}/2$ 给出（`build/schedule.tex:488--527`）。
$A_i=a$ 是任取的，向下归纳得整条日程上的命题。

在 $A_0$ 处结论是：从每个精确起点出发，至少 $99\%$ 的有符号素数
在少于 $p^{199/200}$ 个剩余之外给出质量 $\ge1/(4p)$（`build/schedule.tex:532--534`）。
这两个数就是 $\tau_0=1/4$、$\beta_0=1/200$、$\eta_0=1/100$ 的直译。
`build/schedule.tex:534--538` 提醒下一节的重复测试要在残差向量条件下才独立，
而残差向量的律混合了多个精确起点，那部分要单独处理。
这一句是 13.2 里 `eq:posterior-kernel` 与 `eq:unfavorable-fraction` 两步的由来。

## 13 零避免的信息代价（information.tex 前半）

### 13.1 假设在这里才登场

前六节对任意自避 $D$ 步行走成立，`build/information.tex:4--8` 才加条件：
行走落在 $\mathcal A(\mathcal P_M)$ 内，即对每个被选有理素数避开两个因子。
每批独立均匀取 $q_T$ 个有理素数并配独立公平符号，所有这些辅助选择记 $\mathcal C$，
与行走采样实验独立；下文熵都在 $\mathcal C$ 固定时计算，
$\mathbb E_{\mathcal C}$ 只平均熵值、不把选择本身算进随机数据
（`build/information.tex:13--20`）。
$X'_T$ 是 $z_{t_*}$ 处该批次的所选残差向量，$O'_T$ 是同一位置上所有更小批次的所选残差。

增量词 $W_L(t)=(z_{t+1}-z_t,\dots,z_{t+L}-z_{t+L-1})$，每字母至多 $K_D$ 个值
（`build/information.tex:21--26`）。长度取 dyadic：
$L_T=2^{\lfloor\log_2(T^{2/5})\rfloor}$，故 $\frac12T^{2/5}<L_T\le T^{2/5}$
（`build/information.tex:27--30`）。
`build/information.tex:31--35` 说明它的双重作用：
足够短，使词在一个范数 $p\in[T,2T]$ 的因子下不会两次命中同一剩余；
足够长，使从 $A_0(T)$ 到位移的熵与词内信息相比可忽略；
dyadic 形态是为 14.1 的整除分块预留的。

### 13.2 单批信息率命题

`prop:information-rate`（`build/information.tex:41--55`）：
存在只依赖固定日程参数的 $c_1>0$，使 $M$ 充分大时对每个批次
$\frac1{L_T}\mathbb E_{\mathcal C}I(X'_T;W_{L_T}(t_*)\mid O'_T)\ge\frac{c_1}{\log T}$，
且 $M$ 的阈值在 $\mathcal A(\mathcal P_M)$ 内所有无限自避 $D$ 步行走上一致。
下面按论文自己的六步拆。

第一步，起点残差的条件熵。由 `eq:global-entropy` 与 `eq:smaller-alphabet`，
$\mathbb E_{\mathcal C}H(X\mid O)\ge H(X)-H(O)\ge(1-2e_0)qL_*$，
其中 $O$ 的字母表对数 $\le e_0c_0T\le e_0qL_*$（`build/information.tex:71--78`）。
这里 $X,O$ 在 $z_{A_0}$ 处取值，$q=q_T$，$A_0=A_0(T)$。
第二步，位移代价。`eq:checkpoint-displacement` 给
$H(s)=O_D(T^{r_0})=O_D(T^{1/4})$，$s=z_{t_*}-z_{A_0}$，
且 $s$ 的律是原日程律、与 $\mathcal C$ 无关（`build/information.tex:79--86`）。
第三步，候选测试。取充分大的固定 $K_0$，令
$m_T=\lceil K_0(T/L)\log T\rceil$（`build/information.tex:87--92`）。
固定 $\mathcal C$，先按原律抽 $(O,X)$，条件于它独立抽 $m_T$ 份
$P_a=(s_a,W^{(a)})$。候选 $x\in\Z[i]/(\pi)$ 通过第 $a$ 份包装的条件是
$x+s_a+\sum_{h<l}W^{(a)}_h\not\equiv0\pmod\pi$ 对一切 $0\le l<L$ 成立
（词从零下标起，空和为零）；$\mathcal L_\pi(P)$ 是通过全部包装的候选集。
真坐标 $X_\pi$ 几乎必然在表内，因为包装的精确起点带着规定残差、
后续位置落在这条零避免行走上，于是
$H(X\mid O,P)\le\mathbb E\sum_{\pi}\log|\mathcal L_\pi(P)|$（`build/information.tex:101--120`）。
对每个实现的 $(O,P)$，$X$ 的条件支撑包含在这些表的笛卡尔积里，
不需要坐标间任何独立。

第四步，把后验与覆盖接上。包装在给定 $(O,X)$ 时独立，
而 `prop:coverage` 的延续是从精确 checkpoint 时刻采样的。
固定 $\mathcal C$ 与 $(O,X)$ 的正概率值，其条件包装律是后验精确起点 $a$ 上的混合；
$(O,X)$ 由时刻决定，因此对新鲜延续随机性不施加额外条件，
即 `eq:posterior-kernel`：
$\Pr\{(s,W)\in E\mid O,X,\mathcal C\}=\sum_a\Pr\{A_0=a\mid O,X,\mathcal C\}K_a(E)$，
核 $K_a$ 与辅助素数选择无关（`build/information.tex:122--138`）。
称某因子对该残差数据有利，若 `eq:coverage` 在精确 $A_0$ 起点成立的后验概率 $\ge1/2$。
用 $\chi(a,\pi)$ 指示覆盖失败，不利坐标的后验坏概率 $>1/2$，
故其指示至多该概率的两倍，塔性质给
$\mathbb E_{\mathcal C}\mathbb E_{O,X}\#\{\text{不利坐标}\}\le2\mathbb E_{A_0}\mathbb E_{\mathcal C}\sum_\pi\chi(A_0,\pi)\le2\eta_0q$
（`build/information.tex:140--163`）。
先验 $A_0$ 律与 $\mathcal C$ 独立，后验不必独立，这里用的是先验那一边。

第五步，命中概率与 $u_x$。固定有利坐标，$\mu$ 为其精确起点的后验律，
$G$ 是覆盖成立的起点集（$\mu(G)\ge1/2$）。在 $a\in G$ 处，
把终端残差律平移 $z_a\bmod\pi$，得
$\Pr\{s\equiv-x\pmod\pi\mid A_0=a\}\ge\tau_0/p$ 对除少于 $p^{1-\beta_0}$ 个候选外都成立。
令 $u_x=\mu\{a\in G:\Pr\{s\equiv-x\pmod\pi\mid A_0=a\}\ge\tau_0/p\}$，
平均例外集大小得 $\sum_x(\mu(G)-u_x)<p^{1-\beta_0}$；
若 $u_x<1/4$ 则该项超过 $1/4$，于是除至多 $4p^{1-\beta_0}$ 个候选外都有 $u_x\ge1/4$
（`build/information.tex:165--184`）。

第六步，短词给出不相交的拒绝机会。对 $u_x\ge1/4$ 的候选取被计数的精确起点，
`eq:smoothing` 在 $l\le T_+$ 上给
$\Pr\{z_{t_*+l}-z_{A_0}\equiv-x\pmod\pi\mid A_0=a\}\ge\tau_0/(2p)$
（因 $M$ 大时 $T_+^{-9}\le\tau_0/(2p)$），对后验起点混合得每个偏移命中概率
$\ge\tau_0/(8p)$。同一份包装内这 $L$ 个命中事件两两不交：
若两个偏移都命中，则两处行走位置模 $\pi$ 同余，
其差由自避性非零、故长度 $\ge\sqrt p$，而长度又 $\le DL<\sqrt p$
（$L\le T^{2/5}$、$p\ge T$），矛盾（`build/information.tex:186--206`）。
一份条件包装以至少 $cL/p$ 的概率拒绝该候选，$c=\tau_0/8$。
包装间条件独立给出
$\mathbb E[|\mathcal L_\pi(P)|\mid O,X]\le4p^{1-\beta_0}+p\exp(-cLm_T/p)\le5p^{1-\beta_0}$，
$K_0$ 取得足够大以完成第二式，可行性来自 $T\le p\le2T$ 与
$Lm_T/p\ge(K_0/2)\log T$（`build/information.tex:208--219`）。
Jensen 让有利表大小的对数期望 $\le(1-\beta_0)\log p+\log5$，不利坐标用 $\log p$，
得 $\mathbb E_{\mathcal C}H(X\mid O,P)\le(1-\beta_0/2)qL_*$（用 $\eta_0=1/100$、
$L_*\ge\log T$、$\log5/L_*\to0$），与第一步相减得
$\mathbb E_{\mathcal C}I(X;P\mid O)\ge(\beta_0/3)qL_*$（`build/information.tex:221--240`）。

最后一步是把代价搬到终端词上。条件独立给
$I(X;P\mid O)\le m_TI(X;s,W\mid O)$。去掉位移要付两笔：
$I(X;s\mid O)\le H(s)$；给定完整整数位移 $s$ 时残差加法是
$(O,X)$ 与 $(O',X')$ 之间的双射，故 $I(X;W\mid O,s)=I(X';W\mid O',s)$，
再用 $I(A;B\mid C,S)-I(A;B\mid C)=I(A;S\mid B,C)-I(A;S\mid C)\le H(S)$
去掉对 $s$ 的条件，再付一次 $H(s)$。合计
$I(X;s,W\mid O)\le I(X';W\mid O')+2H(s)$（`build/information.tex:245--272`）。
配合 $qL_*\ge c_0T$ 与 $m_T\le2K_0(T/L)\log T$，
$\mathbb E_{\mathcal C}I(X';W\mid O')\ge\frac{\beta_0c_0}{6K_0}\frac{L}{\log T}-O_D(T^{1/4})$，
而 $T^{1/4}=o(L/\log T)$，于是取 $c_1=\beta_0c_0/(12K_0)$ 得证
（`build/information.tex:278--290`）。

### 13.3 我在这一节踩过的两个坑

坑一：$m_T$ 的量级。我以为 $m_T\asymp p/L$ 就够（让期望拒绝次数为 $O(1)$），
实际必须是 $\lceil K_0(T/L)\log T\rceil$，多出 $\log T$。
理由是两项竞争：表大小上界里第一项 $4p^{1-\beta_0}$ 是例外候选数，
第二项 $p\exp(-cLm_T/p)$ 必须同时压到 $p^{1-\beta_0}$ 以下，
这要指数 $cLm_T/p$ 与 $\beta_0\log p\asymp\log T$ 同量级，$\log T$ 因子是必然的。
$K_0$ 只依赖 $\beta_0$ 与 $c=\tau_0/8$，与 $T$ 无关，这正是它能固定的原因。

坑二：我一度把 $2H(s)$ 那笔当作可省（以为 $s$ 与 $W$ 独立）。
$s$ 与 $W$ 在同一次包装里由同一随机时刻决定，肯定相关；
正确用法是把 $s$ 当成中间条件变量，先条件化（免费，因 $K_a$ 与 $\mathcal C$ 无关），
再逐次去掉条件，每次付 $H(s)$。两次 $H(s)$ 的账与 $O_D(T^{1/4})$ 同阶，
相对 $L/\log T\gg T^{1/4}$ 可忽略，即 $T^{1/4}=o(L/\log T)$ 这一条
（`build/information.tex:287--288`）就是这笔账能不能付得起的判据。

## 14 公因式望远镜与最终矛盾（information.tex 后半）

### 14.1 望远镜引理

`lem:telescope`（`build/information.tex:303--313`）：对每个固定的 $\mathcal C$，
$\sum_TI(X'_T;W_{L_T}(t_*)\mid O'_T)/L_T\le\log K_D+o(1)$，
误差在 $\mathcal C$ 与行走上一致地随 $M\to\infty$ 趋零。
证明把批次排成 $T_1<\dots<T_{n_B}$，$L_j=L_{T_j}$，
$Q_j(t)$ 含从 $T_1$ 到 $T_j$ 全部所选残差在 $z_t$ 处的值（$Q_0$ 为空），
定义 $a_j=H(W_{L_j}(t_*)\mid Q_{j-1}(t_*))/L_j$、$b_j=H(W_{L_j}(t_*)\mid Q_j(t_*))/L_j$，
第 $j$ 笔代价恰是 $a_j-b_j$（`build/information.tex:315--328`）。
关键的传递估计是 $a_{j+1}\le b_j+\epsilon_M/L_j\le b_j+\epsilon_M$：
两个长度都是 $2$ 的幂且 $L_j\le L_{j+1}$，故 $L_j\mid L_{j+1}$，
把长词按 $L_j$ 切块；起点偏移 $a$ 的块，其起点残差向量由 $Q_j(t_*)$
加上块前增量之和确定，链式法则后去条件得
$H(W_{L_{j+1}}(t_*)\mid Q_j(t_*))\le\sum_{L_j\mid a}H(W_{L_j}(t_*+a)\mid Q_j(t_*+a))$
（`build/information.tex:329--339`）。
块与起点残差向量都是起始时刻在固定行走上的确定函数，
由 `eq:smoothing`（$a<L_{j+1}\le T_+^{2/5}\le T_+$）其在 $t_*+a$ 与 $t_*$ 的联合律
TV 差 $\le T_+^{-9}$。字母表规模：全部残差字母表对数
$\sum_Tk_T\log(2T)=O(T_+)$，块字母表贡献 $L_j\log K_D=O_D(T_+)$，
于是连续性引理给 $\epsilon_M=O_D(T_+^{-7})$
（具体是 $2h(T_+^{-9})+O_D(T_+^{-8})$，`build/information.tex:348--362`）。
批数 $n_B=O(\log T_+)$，所以
$\sum_j(a_j-b_j)\le a_1-b_{n_B}+(n_B-1)\epsilon_M\le\log K_D+o(1)$，
用 $b_{n_B}\ge0$ 与 $a_1\le\log K_D$（`build/information.tex:366--377`）。

我在这一步的顺序上犯过错：先把长词切块、再试图对块做平滑比较，
结果发现必须比较的是"块加其起点残差向量"这个联合对象，
因为 $Q_j(t_*+a)$ 与 $Q_j(t_*)$ 各自的 TV 界不足以传递条件熵。
论文的写法是先说明两者都是起始时刻的确定函数，
再对联合律用一次 `eq:smoothing`，这样连续性引理只作用在一个耦合上。

### 14.2 与 Tao 熵递减的关系

`build/information.tex:380--385` 与 `build/main.tex:174--178` 两处都作了限定性声明：
近似平移不变与条件分块次可加以限制累计信息这一手法，
方法学上与 Tao 的 entropy-decrement 论证相关
（引文标 `build/main.tex:176` 的 Section 3 与
`build/information.tex:381` 的 Section 3、Equation (40)、Lemma 17），
而有符号残差批次、覆盖传递、以及零避免强制的代价，都在本文内部完整建立。
我在笔记里保留这个限定的原样措辞，因为它是全文唯一一处方法论定位，
把它放大成本文采用 Tao 的定理属于越界引用；
反过来，把 `lem:telescope` 说成完全孤立也不准确，
它确实只用到 TV 连续性与次可加，这两点在 `sec:preliminaries` 里自足。

### 14.3 最终矛盾与定理 1.2 闭合

设某充分大的 $M$ 下存在位于 $\mathcal A(\mathcal P_M)$ 的无限自避 $D$ 步行走。
把 `lem:telescope` 对 $\mathcal C$ 平均，再用 `prop:information-rate`，得
$c_1\sum_T1/\log T\le\log K_D+o(1)$（`eq:final-information-bound`，
`build/information.tex:387--396`）。
另一方面，每个 $\lceil M/2\rceil\le m\le M$ 的区间 $[X_m,1.05X_m]$
含至少 $cX_m/\log B$ 个形如 $j\log B$ 的数（绝对 $c>0$，$M$ 充分大），
其对左端的贡献至少 $c/(1.05\log B)$（`build/information.tex:398--403`）。
这样的互不相交区间有 $O(M)$ 个，总和发散，
而 $c_1$、$B$、$K_D$ 都固定，故 $M$ 充分大时矛盾。
`build/information.tex:408--416` 收尾：所有估计与所有 $M$ 的阈值
在假想的避零行走上一致，取一个只依赖 $D$ 的 $M$，令 $\mathcal P_D=\mathcal P_M$，
这是一个有限有理素数集、$\mathcal A(\mathcal P_D)$ 同时规定两个因子都避开，
使无限避零行走不存在；辅助有符号子集只用于平均信息不等式，
不会让最终筛依赖行走。
于是 Theorem 1.2 成立，接回第 6 节的周期论证得 Theorem 1.1。

### 14.4 两个常数链的对接

最后检查一遍 $c_1$ 与 $c_0$ 的来历，台账里要用：
$\beta_0=1/200$、$e_0=\beta_0/50=1/10000$（`build/schedule.tex:29--30`）；
$c_0$ 是顶带熵产出里的常数，可取任何足够小的、小于
$a_0g_0^{2(l_0+1)}/2$ 的值（`build/schedule.tex:204--205`）；
$K_0$ 由 `build/information.tex:216--219` 固定；
$c_1=\beta_0c_0/(12K_0)$（`build/information.tex:289`）。
窗口贡献 $c/(1.05\log B)$ 里的 $c$ 是绝对常数（`build/information.tex:399--400`）。
发散论证只需要 $c_1>0$ 与 $B$ 固定，
因此 $c_1$ 的具体大小进入不了结论，它的全部作用是与 $o(1)$ 竞争。
这一点在 Lean 侧看得最清楚：`Main.lean:11--14` 取
`c := topCoefficient a/4` 与 `rate := c*t/10500000`，
`Main.lean:15--18` 只要求 $W$ 大于 $(\log(\operatorname{latticeBall}D).\operatorname{card})+1)/\mathrm{rate}$，
`Main.lean:69` 的 `rates` 是 `fun n => c/(10000000*Real.log ((2:ℝ)^(binEnum U n)))`，
即 $c_1/\log T$ 里的 $c_1$ 在 Lean 里被具体化成 $c/10^7$ 量级。
括号不配对的那一处是我抄录时的笔误，Lean 原文是
`(Real.log (latticeBall D).card+1)/rate`（`Main.lean:15`）。

# 003 · A Capacity Criterion for Four-State Potts Reconstruction on Trees（四态 Potts 重构的容量判据）

这个问题挂在两块已知结果的夹缝里：Sly 证了三态在正则大度树上 KS 界尖锐、五态以上不尖锐；Mossel–Sly–Sohn 把三、四态的非重构推到 Galton–Watson。四态是那个孤零零的临界点：KS 界在指数增长判据下"正好"说不清。我给自己定的目标更狠：任意有界度树（无正则性、无增长率假设），四态，KS 边界处，重构 ⟺ 容量为正。

**第一站：照搬 Ising，失败**。最自然的起点是 Pemantle–Peres 的自由边界判据——Ising 情形是 L² 容量配平方信道阻力 λ^{-2|e|}。我把他们的递归直接搬过来：信息统计量沿树满足 m_v ≤ rΣm_w（r=λ²），然后等容量。很快就发现死局：r<1 恒成立，纯次可加的递归每层衰减，**永远造不出正标签**——正方向连流的第一步都迈不出去。回头看这不是实现细节的问题：四态时乘积合并的二次节省项系数恰好为零，"At four states the quadratic correction vanishes, making higher-order terms decisive"——论文里这句话的每一个字都是用失败换的。

**第二站：意识到要"省"三次项**。既然次可加性只给衰减，正方向的燃料必须从"两支合并时省下的东西"里来。我把后验信息统计量定成 m(μ)=E|Lp|²（L 是三个乘积为 +1 的符号三元组，x=Lp），它有干净的信道缩放 m→t²m——恰好匹配 r=λ² 的 KS 尺度——还有逐点 TV 夹逼 A/8≤TV≤√A/2。但合并的节省是一次的、三次量级的（E[A²]×m），形态不成递归。我先是直接令 z_v=m_v 套 PP 的 L² 递归，不行，递归里没有严格节省。后来才找到 m_v+Km_v³ 这个重整化：三次节省项经 b_w³=r³m_w³ 的代数恒等式变成 Kr(1−r²)Σm_w³ 的均匀形式，**单子女顶点**（对节省消失的地方）也留有正因子 r−r³。这个"单子女修补"是我最满意的一步——它把一个只在成对合并时成立的节省，升级成沿整棵树一致成立的递归。再配切线界 (1+2t)^{-1/2}≥1−t，把 (1−δy²) 型节省翻译成 PP p=3 容量递归的标准形 z_v≤Σrz_w/√(1+z_w²)。流引理（标签递归 ⇒ 质量流、逐射线势 ≤1）不是独立引理而是配套设计：g_v=r^{-|v|}ℓ_v 的 telescoping 完全依赖 1/√(1+z²) 这个特定非线性——我改过一版标签递归，流构造立刻散架，才明白这两者是连体的。

**第三站：反方向，信息损失的精确定位**。容量 ⇒ 重构要的是下界，而我能白拿的只有上界。必须证明"合并分支时损失的信息"总量有限。这就是论文自述的那句 "subadditivity alone is not enough: we must bound the information lost when branches are combined" 的落点。我花了最长时间算这笔账。首先发现：混合二次项在四态坐标下**精确抵消**——E|R|²=2ab/3 与 2E s²=2ab/3 在 E[|N|²(1−s)] 展开中逐项相消，得到干净的乘积公式 m(μ⋆ν)=a+b−4(αb+aβ)−6αβ+非负余项。这个精确抵消是整篇证明的出发点：它同时解释了二次项为何消失（首阶交互被推到三次）和反方向的损失为何只是三次的。然后是传播：三次统计量 τ(μ)=E[x₁x₂x₃] 在信道步下 τ→t³τ，所以第三矩过边信道衰减 **λ³** 而不是 λ²。这个 λ³ 后来救命：在权重恒等式 r^iλ^{3(j−i)}X_u=λ^{j−i}Θ(u) 里，λ³ 与 r=λ² 的深度权重相乘后得到**可和核** λ^{j−i}；如果传播因子是 λ²，核就退化成常数 1，路径和随深度线性增长，一致 ε 根本选不出来。我甚至试过对任意对称 μ,ν 直接证损失引理——死在分母上：1+s 可以任意接近 0，展开失控。解法是要求第二输入经过参数 λ 的信道平滑（q_i≥(1−λ)/4 ⇒ 1+s≥1−λ），这也决定了反方向的整体形状：在每层给终端加"逐点校准的噪声" t_v=√(X_v/3)，噪声尺度由流决定。

**第四站：终端校准与路径平均**。流侧剖面 Θ(v) 给出 X_v=r^{-|v|}Θ(v) 满足线性递归 X_v=rΣX_w；m̂_v≤X_v 的上界靠子可加+信道缩放归纳。亏损 D_v=rΣm̂_w−m̂_v 的累计我用迭代展开后沿流路径采样平均：按 Θ(v)/M 抽 L_n 顶点，把逐点亏损折算成单路径上带可和核的和，Cauchy–Schwarz 配逐射线能量界 ΣX²≤Qε²，几何级数收出 Qε²/(1−λ)+√Qε/(1−λ)。取 ε 让 C₂ 倍的它 ≤1/2——**与 n 无关**——于是每个深度都有 m̂_ρ≥M/2。这里我刻意不要求退化实验序列的收敛性或相互单调性，只要求每个深度有同一正下界：紧致化能省字数，但会引入我控制不了的对象。

**与伴随手稿的分工**。保三次项不等式（含 c=1/1000 的常数和整个封闭类 C）来自同日的伴随手稿《The Reconstruction Threshold for the Ferromagnetic Four-State Potts Model》的 Prop 3.2——那里有多项式证书方法（对生成元验证多项式不等式、经封闭性传播）这台重机器。我明确声明不重复那个证明，且强调"类 C 的存在与封闭性、而不只是对称性"是必需的。这个分工是同一研究计划拆分的结果：阈值手稿回答"临界点在哪"，我回答"任意树上的判据是什么"。我起初想把不等式也自证掉，做到一半发现多项式证书的工作量是一个完整论文的量级，才改成黑箱引用——但黑箱的边界（任意信道参数、条件独立乘积）我逐一核对过，正是我需要的范围。

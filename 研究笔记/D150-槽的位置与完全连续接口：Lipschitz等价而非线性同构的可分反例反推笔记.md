## 1 初始动机与猜想

我最初的出发点很朴素：一个 Banach 空间的范数同时喂出两样东西，一样是线性拓扑，一样是度量。有界线性同构肯定保住度量到常数因子的误差，反过来一个只是"保住度量到常数因子"的双射，凭什么保住加法和数乘。我想问的就是这个反差能不能拉满：是否存在两个可分实 Banach 空间 $X$ 与 $Y$，之间存在双射 $\Psi:X\to Y$ 满足对一切 $s,t\in X$ 有 $(4/21)\lVert s-t\rVert_X\le\lVert\Psi(s)-\Psi(t)\rVert_Y\le(76/25)\lVert s-t\rVert_X$ 这类双边控制，可两者之间连一个有界线性同构都没有。论文里这一串常数写在 `01-introduction.tex:27` 到 `01-introduction.tex:29` 的公式 `\eqref{eq:main-bounds}`，我一开始是把它当一个"随便写定的常数"看的，读到 `06-assembly.tex:36` 到 `06-assembly.tex:47` 才发现它们全部是 $c=1/100$ 的下游，这个后面再说。

在这个动机下我的第一个猜想是：反例应该长成一个"逐坐标改写"的样子。可分空间让人想到序列空间，最省事的做法是把 $X$ 与 $Y$ 都写成某种序列空间，然后 $\Psi$ 在每一坐标上做同一件事。这个直觉后来基本保留，但我一开始把它放错了地方：我脑子里想的是 $\Psi$ 直接在 Banach 空间本身上做非线性改写，而最终的构造里 $\Psi$ 只是把一个"定义在求和项上的映射 $B$"逐坐标抄上去（`03-triangular.tex:121` 的 `\Psi(s)_i=B(s_i)`），真正吃力的非线性全被推到另一个舞台上去做。

第二个猜想关于阻碍的形状。既然 $\Psi$ 是双射且双边 Lipschitz，任何线性同构不变量都必须对 Lipschitz 同构失效。当时我认为最可能活下来的不变量是"包含某个固定空间作为闭子空间"这一类，理由是我在 `02-free-graph.tex:197` 到 `02-free-graph.tex:202` 这条链上看到的都是闭子空间语言。而可分性这一层又让我盯上 $c_0$：`01-introduction.tex:62` 到 `01-introduction.tex:66` 记的 Godefroy--Kalton--Lancien 定理说与 $c_0$ Lipschitz 同构的空间必线性同构于 $c_0$，被 $c_0$ 的子空间线性同构这一条也在 Lipschitz 同构下不变。这两句给我的暗示是：普通 $c_0$ 这条路是被正面定理堵死的，我的阻碍得比"$Y$ 里没有 $c_0$"更精细。我最初的猜测与事实的落点有偏差：精细程度这一头被正面定理占住，真正能动的自由度在块的维度上。`01-introduction.tex:37` 到 `01-introduction.tex:41` 明说这个阻碍是故意 block-valued 的，每一坐标整块是 Hilbert 空间，即 $c_0(\ell_2)$，并且特意声明它没有说 $Y$ 里没有普通 $c_0$。我在最初设想里把 $c_0(\ell_2)$ 当成 $c_0$ 的一个技术性推广，读完 `02-free-graph.tex:276` 到 `02-free-graph.tex:357` 才明白块的维数正是整套论证的承重墙：正交序列 $(e_k)$ 在 $\ell_2$ 里弱收敛到 $0$ 这一句（`02-free-graph.tex:293` 到 `02-free-graph.tex:295`）是"逐坐标趋零"的发动机，如果块是 $\mathbb R$，正交性就没了，序列选取也无从谈起。

第三个初始猜想是关于工具的：我以为要用 Lipschitz 自由空间的商结构。$E=\mathcal F(M)$ 与线性化映射 $\widehat D$ 的定义我早就知道，`02-free-graph.tex:61` 到 `02-free-graph.tex:68` 把 $\lVert\widehat D\rVert=\operatorname{Lip}(D)$ 写得干净，所以我预期会有某个 $\widehat D$ 的右逆被造出来，然后 Godefroy--Kalton 的推论把 Lipschitz 截面变成线性截面，反例就在这一处断裂。这个猜想在 `03-triangular.tex:171` 到 `02-free-graph.tex:178`（原文件的 `03-triangular.tex:171` 起的 Remark `\label[remark]{rem:no-section}`）被作者明确否定：$qB=hQ_1$ 与 $Q_1B^{-1}=h^{-1}q$ 两侧都是非线性映射，它们给不出 $qs=\operatorname{id}_U$ 的截面，Lipschitz 的也給不出，因此那个商分裂推论调不动。我最初的这条"用现成定理一击致命"的猜想就此作废，取而代之的是一个更慢的接口：完全连续。

第四个初始猜想是关于非线性映射本身。我猜我会直接构造 $\Psi$ 或者构造 $Y$ 上的范数。当时我以为最难的是"保持距离到常数"，所以注意力全在度量的两侧。可最终构造里最核心的非线性对象是 $h:M\to U$，一个 Hilbert 空间之间固定 $0$ 的双 Lipschitz 变量替换，$\operatorname{Lip}$ 上下界是 $26/25$ 与 $24/25$（`05-hilbert.tex:14` 到 `05-hilbert.tex:19`）。我最初的猜想把这个 $h$ 当成主角，把 $X,Y$ 当成收尾的包装。这个次序恰好与最终的思路相反：真正决定成败的是 $h$ 的尾部坐标几何，而 $X,Y$ 是几何完成后被一次性造出来的容器。我一开始对此估计不足，因为我在读之前一直以为度量的构造与线性的阻碍会在同一个空间里纠缠，而 `01-introduction.tex:96` 到 `01-introduction.tex:97` 那句"证明把度量构造与线性阻碍分开"是整篇的枢纽。

## 2 尝试过的错误路线及失败原因

这一节我按"我当时会怎么做"的顺序写，每一条都能在 tex 里指回一处作者留下的否定式路标。这些路标（"不声称""不需要""不可调用""essential""keeping it is what avoids"）在我读第一遍时全部被我当成啰嗦，读第三遍才明白它们是失败路线的墓碑。

路线甲：在全体有界集上要尾部一致衰减。局部正交如果写成"对每个 $n\ge l$，$\Pi_{\ge l}D$ 的像落在固定正交坐标子空间里"，那么完全连续几乎一行就能推出，我最初的构造冲动就是让槽 $w_n$ 在整个空间上一致地走开。这条路撞在 `05-hilbert.tex:361` 到 `05-hilbert.tex:363`：那里白纸黑字写着这里用小邻域是本质的，点态衰减加共同的 $\sqrt3$ Lipschitz 界已经够用，而有界子集上的一致衰减既没声称也不需要。再对照 `04-localization.tex:9` 到 `04-localization.tex:10`，定理假设里明写既不假设整体分割，也不假设在有界集上一致尾部衰减。失败原因是资源分配：要在有界集上一致分开无穷多个点，每一块 $U_n$ 里的互正交方向个数随点数增长，而 `05-hilbert.tex:186` 的维数 $\dim U_n=1+\sum_{k=1}^n(2k+1)^k$ 是设计死的，一致版本要求维数预算跟着输入走，这与"块固定、空间可分"这一层直接冲突。

路线乙：拿一个已知的可分一致同构反例过来，把一致同构加强成 Lipschitz。`01-introduction.tex:51` 到 `01-introduction.tex:59` 把历史写清了：Aharoni--Lindenstrauss 给的是非可分的 Lipschitz 等价非线性同构例子并明确要可分版本，Ribe 在 `01-introduction.tex:52` 给了可分的一致同构非线性同构，Johnson--Lindenstrauss--Schechtman 把可分一致例子做丰富而把可分 Lipschitz 问题留着。作者接着说，正是这一串发展让 `\eqref{eq:main-bounds}` 的全局双边估计"是一个实质要求"。这句话否定的是我一开始的想法：以为一致同构与 Lipschitz 等价之间只差一点技术加强，可以把现成例子搬过来。失败原因：一致同构的模数可以随距离尺度走，而双边 Lipschitz 只允许两个固定常数，$24/25$ 与 $26/25$ 这种"接近等距"的强度是设计出来的（见 `05-hilbert.tex:389`），现成例子里的非线性没有这种统一尺度。

路线丙：让 $q$ 成为紧算子。若 $q$ 紧，则 $J_q$ 把 $c_0(\ell_2)$ 的候选拷贝压成紧算子逐坐标复合，阻碍一步就能出。`02-free-graph.tex:193` 到 `02-free-graph.tex:196` 直接给这条路上了一块碑：下面那个引理只记录弱序列完全性需要的推论，它没有声称每个进入 $c_0$ 和空间的算子都是紧的。失败原因也具体：紧性会连 $q$ 自身的范数结构一起吃掉，而整套构造只要求"弱零序列映成范数零序列"，`04-localization.tex:32` 到 `04-localization.tex:37` 的结论正好停在这个弱一档的位置，作者没有能力也不需要把 $q$ 做紧。我后来把这条记成一个通则：接口选在刚好够用的算子理想上，选高一档就会让上游几何做不出来。

路线丁：把完全连续的证明写成"整体 Lipschitz 常数的紧化论证"。我在读 `04-localization.tex:159` 之前以为这一步是把 $d_i$ 的一致 Lipschitz 界 $\operatorname{Lip}(d_i)\le L$（`04-localization.tex:178`）直接放到某个紧集上取极限。这条路的问题在 `04-localization.tex:188` 到 `04-localization.tex:236`：必须在固定子列之后，对可数基 $\mathcal B$ 逐个取 $\operatorname{Lip}(d_i\vert_O)$ 的极限，再对角化，才能定义 $Z=\{z:\text{每个含 }z\text{ 的 }O\text{ 有 }a_O\ge\eta\}$。我最初的版本少了"子列先固定"这一步，于是 $Z$ 会随参数走，基数估计 $m\eta^2/L^2\le1$ 就无从谈起。作者用 `04-localization.tex:387` 到 `04-localization.tex:394` 一整段专门写量词顺序：先固定对角子列，再对每个 $\eta$ 选 $Z$ 与 $r_0$，再对每个 $\tau$ 选 $K$，再固定 $r<r_0$ 令 $i\to\infty$，然后 $r\downarrow0$、$\tau\downarrow0$、$\eta\downarrow0$，并强调全程没用过 $i$ 与 $r$ 的联合一致收敛。这种自述式的量词表，通常就是同一作者在早期版本里被顺序坑过。

路线戊：把 $\delta$ 的等距用在带基点之外。`04-localization.tex:109` 到 `04-localization.tex:116` 里，$p_j=f_{i_j}\phi_{z,s_j}$ 要在 $\{0,x_{j1},\ldots,x_{jN_j}\}$ 上全部为零，才有 $\langle p_j,\nu_j\rangle=0$。作者特别写出"当 $z\ne0$ 时把基点 $0$ 放进去是本质的"。我最初的推导只把 $z$ 与 $x_{jk}$ 列进有限集，因为我觉得 $0$ 是可有可无的一点。失败原因：自由空间的配对约定是 $\langle f,\mu\rangle$ 表示 $\langle f-f(0),\mu\rangle$（`02-free-graph.tex:25` 到 `02-free-graph.tex:26`），有限评估和 $\sum a_{jk}\delta(x_{jk})$ 里 $\delta(0)=0$（`02-free-graph.tex:24`），若 $p_j(0)\ne0$ 则 $\langle p_j,\nu_j\rangle$ 多出 $p_j(0)\sum a_{jk}$ 这一项，整个 $\epsilon/2$ 的估算崩掉。

路线己：在 $h$ 的逆像尾部不等式里把输出分量的正交部与槽部各数一次。`05-hilbert.tex:515` 到 `05-hilbert.tex:535` 的推导我最初会写成 $\sum_{m\ge s}\lVert(x_N)_{U_m}\rVert^2+|(x_N)_{V_m}|^2\le\sum_{n\ge s}\lVert y_n\rVert^2$，即直接扔掉那一项有限和。作者的说明是：保留 $\sum_{n=s}^{2s-2}\lvert\beta_n^{(N)}\rvert^2$ 这一项正是为了避免把输出的正交部与槽部重复计数，$s=1$ 时这个有限和为空。失败原因很实在：偶指标 $2m$ 与奇指标 $2m-1$（$m\ge s$）恰好拼成 $n\ge2s-1$，与 $\sum_{n\ge s}\lvert\beta_n\rvert^2$ 的尾部相消之后剩下的正是 $s\le n\le 2s-2$；把它扔掉会在 $s$ 与 $2s-1$ 之间把同一份能量算两次，于是 $\lVert x_N\rVert=\lVert y\rVert$ 在 $s=1$ 处的精确等式不再成立，而对角子列的 Cauchy 论证需要尾部被同一个 $\sum_{n\ge s}\lVert y_n\rVert^2$ 一致压住。

路线庚：在整个无穷维空间上用全局反函数定理。$h_N$ 的满射我最初想用 Hadamard 型结论（局部可逆加强制性）在 $M$ 与 $U$ 上直接得。`05-hilbert.tex:424` 到 `05-hilbert.tex:452` 的做法是把问题切到有限维纤维：取 $F_N=\bigoplus_{n\le2N}U_n$，$P$ 投到 $F_N^\perp$，则 $Ph_N=PA_0$，于是对固定 $b\in F_N^\perp$，$h_N$ 限制在仿射空间 $A_0^{-1}(b)+A_0^{-1}(F_N)$ 到 $b+F_N$ 之间，两侧同有限维，再论证它是 proper local diffeomorphism，然后用"单连通欧氏空间的覆盖只有一页"。我最初的版本失败在两点：无穷维 Hadamard 定理要 $\lVert Dh_N(x)^{-1}\rVert$ 的一致界（`05-hilbert.tex:421` 给的是 $(1-4c)^{-1}$），这我有，但沿路径积分要一整条线段都在定义域里保持可逆与正则，而我无法在无穷维上把"纤维紧致"这个结论免费拿到；作者的有限维纤维论证里，紧致是 $\lVert h_N(x)\rVert=\lVert x\rVert$ 加有限维直接给的（`05-hilbert.tex:440` 到 `05-hilbert.tex:442`）。

路线辛：让 $q$ 满射。`03-triangular.tex:89` 到 `03-triangular.tex:90` 说这段只用 $h$ 的逆，特别地不需要 $q$ 是满射。这一句把我最初的"先把 $q$ 做成商映射，再用截面"的想法砍掉。它的技术后果在 `03-triangular.tex:113` 到 `03-triangular.tex:116`：两个估计都不除以 $L_q$，所以在 $L_q=0$ 时也照写不误，而作者又补一句在当前设置 $V=\ell_2\ne0$ 下 $L_q=0$ 实际上不可能发生，因为那会给 $h(u,v)=u$，与单射矛盾。

路线壬：把图空间 $Z_Q$ 的范数当成全部。我最初以为 $\lVert s\rVert_{Z_Q}=\max\{\sum_i2^{-i}\lVert s_i\rVert,\sup_i\lVert Qs_i\rVert\}$ 的有限性就定义了空间。`02-free-graph.tex:146` 到 `02-free-graph.tex:148` 立刻纠正：属于 $Z_Q$ 的条件里"$Q$ 像趋于 $0$"是定义的一部分，光有那个最大值有限并不要求 $(Qs_i)$ 趋零。少了这一条，$J_Q(s)=(Qs_i)_i$ 就不是进入 $c_0(H)$，整套阻碍的落点（`02-free-graph.tex:345` 的 $\sum_i2^{-i}\lVert(SRa)_i\rVert\ge b_0\lVert a\rVert_\infty$）也站不住。

路线癸：把 $h$ 直接当 $\Psi$。`03-triangular.tex:5` 到 `03-triangular.tex:11` 的定位是：$h$ 供给假设，$\Psi$ 是逐坐标的 $B$。我最初想跳过 $B$，认为 $h$ 已经是一个双边 Lipschitz 双射，够用了。失败原因：$h$ 的两端 $M$ 与 $U$ 都是 Hilbert 空间，线性同构之间没有阻碍可言；阻碍必须发生在图空间这一侧，因为 $c_0$ 输出那一项要由 $q$ 的完全连续来杀，而 $q$ 的自变量只能是 $E=\mathcal F(M)$ 的元素。$B$ 的作用正是把"在 $M$ 上做的几何"翻译成"在 $E$ 上的三角替换"。

路线子：忽略退化情形。tex 里散落着四处对空情形的单独处理，每一处都是一次潜在崩溃：`05-hilbert.tex:336` 到 `05-hilbert.tex:337`（空族取 $l=1$、单点族取 $O_1=M$）、`04-localization.tex:309`（对空坐标集取最大值为 $0$）、`04-localization.tex:242` 到 `04-localization.tex:243`（$Z$ 至多一个点时任意 $r_0>0$ 可行）、`04-localization.tex:281`（$Z$ 为空时收缩极限显然）、`04-localization.tex:357` 到 `04-localization.tex:358`（$K$ 只有一个点时其 Lipschitz 常数为 $0$）、`03-triangular.tex:150`（$a=0$ 情形的单独一句话）。我最初的草稿对这六处一个都没写，第一次检查就发现 `04-localization.tex:260` 到 `04-localization.tex:265` 的有序极限在 $Z=\varnothing$ 时是空和，需要一句显明的话。

## 3 关键转折点

转折一：把"几何"与"阻碍"之间的接口换成算子理想，而且刚好换成完全连续。这一步把整题从构造题变成接口题。一旦接口定在"$\mu_i\to0$ 弱则 $\lVert q\mu_i\rVert\to0$"，`02-free-graph.tex:267` 到 `02-free-graph.tex:357` 的阻碍就是纯功能分析的：正交序列弱零、逐坐标弱零、完全连续把逐坐标变成范数零、然后用截断造出互不相支撑的 $z_j$、再用 Schur 性质收尾。这个转折之后，我原来的注意力焦点（怎么把两个空间的度量做扭）被彻底替换成（怎么让 $q$ 满足这个理想性质）。支撑这一判断的文本是 `01-introduction.tex:124` 到 `01-introduction.tex:127`：局部坐标几何进入 Banach 空间阻碍的唯一一处就是这里。

转折二：冻结重排 $L_\xi$ 的存在。`05-hilbert.tex:43` 到 `05-hilbert.tex:115` 这一整段是全局的支点。给定每块一个单位向量 $\xi_n$，把 $u_n$ 的正交部 $u_n^\perp$ 留在块 $n$，把旧槽系数 $\alpha_m=\langle\xi_m,u_m\rangle$ 搬到块 $2m$ 的槽位，把 $v_m$ 填进块 $2m-1$ 的槽位，得到的 $L_\xi:M\to U$ 是一个满线性等距，逆有显式公式（`05-hilbert.tex:79` 到 `05-hilbert.tex:81`）。这一步的转折意义在于它把"我要造一个近乎等距的非线性双射"变成"我要让 $\xi_n$ 依赖输入，同时保住逐点范数恒等式 $\lVert h(x)\rVert=\lVert x\rVert$"。`05-hilbert.tex:130` 到 `05-hilbert.tex:133` 明写这一点：逐点范数恒等式还不比较不同输入，而 $h$ 的构造恰好保留了它（`05-hilbert.tex:381` 处 $h_N$ 也满足同一恒等式）。`figures/slot-rearrangement.tex` 里三行节点写的是同一个路由，`05-hilbert.tex:66` 到 `05-hilbert.tex:69` 的图注还专门提醒：图描述的是冻结线性等距，槽依赖输入时它只给逐点范数恒等式，不给不同输入之间距离的保持。

转折三：把槽的运动拆成"角度时间轴"与"阶段坐标"两件事，并且让两者正交。$U_n$ 的基由一个 stage-zero 向量加上对每个 $1\le k\le n$ 一整套由 $\mathcal A_k=\{-k,\ldots,k\}^k$ 标号的坐标组成，不同阶段彼此正交（`05-hilbert.tex:180` 到 `05-hilbert.tex:187`）。阶段 $k$ 上的 $W_{n,k}(x)$ 由归一化的 bump 乘积 $G_{k,a}(p_1(x),\ldots,p_k(x))$ 给出（`05-hilbert.tex:199` 到 `05-hilbert.tex:204`）。于是"往哪个方向转"由阶段 $k$ 决定，"转到什么程度"由半径 $r_n(x)$ 上的角度 $\theta_k(r)$ 决定。这两条轴分开，是局部正交与导数预算能同时满足的真正原因。我把它看成全篇最漂亮的一处设计。

转折四：$\gamma$ 的两个积分条件。`05-hilbert.tex:244` 到 `05-hilbert.tex:250` 给出 $\gamma(r)=c/(r\log(1/r))$ 在 $0<r<e^{-2}$ 上、否则 $0$，并且写出两个事实：$\int_0^b\gamma(r)\,dr=\infty$ 对一切 $b>0$，而 $\int_0^\infty2r\gamma(r)^2\,dr=2c^2\int_2^\infty t^{-2}\,dt=c^2$。前一条让任意多次旋转在角度上排得下（每个转段都要吃掉 $\pi/2$ 的总角度，而 $\gamma$ 的一阶积分发散保证了 $\theta_k$ 可造，`05-hilbert.tex:270` 到 `05-hilbert.tex:277`），后一条让所有旋转对导数的总影响有界。这个"一阶发散、二阶带权有限"的分工是全篇真正难想到的一处：单看 $\gamma(r)=c/r$ 也能让一阶积分发散，但二阶带权积分会发散；单看 $\gamma$ 有界则二阶有限而一阶积分不足以塞下 $\pi/2$。$\gamma$ 恰好卡在两者之间的对数裕度上。

转折五：$a_n$ 与 $r_n$ 这两个量的取法。权重 $a_n(x)^2=\lVert u_n\rVert^2+\lVert u_{\lceil n/2\rceil}\rVert^2+\lvert v_{\lceil n/2\rceil}\rvert^2$（`05-hilbert.tex:139` 到 `05-hilbert.tex:141`）按路由来配，$r_n(x)^2=\sum_{j\ge n}a_j(x)^2$（`05-hilbert.tex:219` 到 `05-hilbert.tex:221`）是它的尾。`05-hilbert.tex:224` 到 `05-hilbert.tex:228` 给出两个恒等式：$r_1(x)^2=3\lVert u\rVert^2+2\lVert v\rVert^2$ 以及 $a_n^2=r_n^2-r_{n+1}^2$。有了差分结构，预算 $\sum_n a_n^2\gamma(r_n)^2\le c^2$ 就成了一个望远镜估计：$(r_n^2-r_{n+1}^2)\gamma(r_n)^2\le\int_{r_{n+1}}^{r_n}2r\gamma(r)^2\,dr$（`05-hilbert.tex:313` 到 `05-hilbert.tex:316`），单调性用一次，求和用一次二阶积分恒等式。我最初把 $a_n$ 想成简单的 $\lVert u_n\rVert+\lvert v_n\rvert$，那样导数误差项 $\dot C_{2m}=\langle\dot w_m,u_m\rangle$ 里的 $w_m$ 与 $u_m$ 不同标号配不上，望远镜也做不出来。附带一条：$r_n$ 是有界线性映射进 Hilbert 空间的范数，故 $\sqrt3$ Lipschitz（`05-hilbert.tex:229` 到 `05-hilbert.tex:231`），这个 $\sqrt3$ 正是 $r_1^2=3\lVert u\rVert^2+2\lVert v\rVert^2$ 里那个 $3$。

转折六：$\sqrt3$ 与 $2\sqrt3$ 在局部性论证里的两次出现。`05-hilbert.tex:349` 到 `05-hilbert.tex:354`：取 $\rho<a_{k_0}'$，选 $l\ge k_0$ 使各中心处 $r_l<\rho/2$，再把两邻域缩到半径小于 $\rho/(2\sqrt3)$，由 $r_n\le r_l$（$n\ge l$）与 $r_l$ 的 $\sqrt3$ Lipschitz 得 $r_n(x)<\rho$。$\sqrt3$ 出现在分母，是因为邻域半径乘 Lipschitz 常数要小于 $\rho/2$。这一步是我判断"作者先写出了 $r_n$ 的 $\sqrt3$ 界、再倒推邻域半径"的依据：否则没有必要把 $2\sqrt3$ 写进半径。

转折七：例外点的基数控制 $\lvert Z\rvert\le L^2/\eta^2$ 与它下游的 $4m/r$。`04-localization.tex:224` 到 `04-localization.tex:236` 是"局部正交之所以够"的核心：$P_j$ 是投到 $H_j$，$\Pi_{<l}=I-\Pi_{\ge l}$，则对 $x,y\in O_j$ 有 $\lvert d_i(x)-d_i(y)\rvert\le L\rho(x,y)(\lVert P_jb_i\rVert+\lVert\Pi_{<l}b_i\rVert)$，弱零性使前 $l-1$ 块有限维上的 $\lVert\Pi_{<l}b_i\rVert\to0$，由 $a_{O_j}\ge\eta$ 得 $\liminf_i\lVert P_jb_i\rVert\ge\eta/L$，正交值加 $\lVert b_i\rVert=1$ 得 $m\eta^2/L^2\le1$。这个"$m$ 被一个与 $m$ 无关的量顶死"的结构，正是把全局条件换成邻域条件的代价所在。它的下游在 `04-localization.tex:330` 到 `04-localization.tex:334`：$\operatorname{Lip}(R_{i,r}\vert_{K\cap O})\le\operatorname{Lip}(d_i\vert_O)+(4m/r)\epsilon_i$，$m$ 只以有限系数出现，而半径 $r$ 在此处固定，故第二项随 $i$ 走。

转折八：紧约化的调用位置。`04-localization.tex:289` 到 `04-localization.tex:295` 用 Aliaga--Noüs--Petitjean--Procházka 的定理把弱零序列 $\mu_i$ 贴近到一个含 $0$ 的紧集 $K$ 的评估张成闭包 $\mathcal F(K)$ 里，误差 $\tau$，并且强调 $K$ 依赖 $\tau$ 与序列、不依赖 $r$。我读到这里意识到顺序是：先有收缩球引理管住"被摘掉的邻域部分"，再有紧集上的一致 Lipschitz 控制管住"余项"，两者都不能省。少了紧约化，$R_{i,r}$ 在整空间上的 $\operatorname{Lip}$ 只有 $7L$（`04-localization.tex:254` 到 `04-localization.tex:257`），配对时只能得 $7L\tau$，而 $\tau$ 与 $i$ 无关，取不了极限；有了紧集，才有 `04-localization.tex:360` 到 `04-localization.tex:363` 的 $\limsup_i\operatorname{Lip}(R_{i,r}\vert_K)\le\eta$。

转折九：Lean 侧的接口顺序。`Main.lean:8` 到 `Main.lean:9` 只有一行：`theorem main : MainClaim := SeparatingStages.main_of_free_wsc CompactWSC.hilbert_free_wsc`。这告诉我 Lean 化的顶层入口被切成两件事：一个自由空间弱序列完全性的事实（`CompactWSC.hilbert_free_wsc`）和一个把前面一切打包的 `main_of_free_wsc`。与 tex 的六节切法相比，Lean 侧的顶层只留一个两参数调用，这是形式化时重新选接缝的痕迹。

转折四补充（落盘后回读时追加的取证段，位置在第 3 节末尾）。这一段我原打算写在第 11 节里，回读时判定它的性质属"转折点"，故在此追加，第 11 节的对应原文不动，两处互为详略。$\gamma$ 的实际式子是 $\gamma(r)=c/(r\log(1/r))$，分段条件写在 `05-hilbert.tex:236` 到 `05-hilbert.tex:241`：$0<r<e^{-2}$ 时取该值，$r\ge e^{-2}$ 时取 $0$，随后 `05-hilbert.tex:242` 说明它随 $r$ 增大而不增。我手算了两条积分以确认 $e^{-2}$ 与 $2$ 的锁扣关系。一阶：令 $u=\log(1/r)$，$dr/r=-du$，则 $\int_0^b\gamma(r)\,dr=c\int_{\log(1/b)}^{\infty}u^{-1}\,du=\infty$。二阶：$2r\gamma(r)^2=2c^2/(r\log^2(1/r))$，同一代换给 $2c^2\int_2^{\infty}t^{-2}\,dt=2c^2\cdot(1/2)=c^2$，下限 $2$ 正来自 $r=e^{-2}$。这一步算完，我就把"$c$ 取 $1/100$"从"随便定的数"改判为"由 $\gamma$ 的归一化直接给出预算总额 $c^2$"，因为 `eq:slot-budget` 要的正是 $\sum_na_n(x)^2\lVert Dw_n(x)\rVert^2\le c^2$。

由此我又把 $\gamma$ 做了一次一般化试探，记在这里供后续核对。取 $\gamma_\alpha(r)=c/(r\log^\alpha(1/r))$，一阶积分化为 $c\int^{\infty}u^{-\alpha}\,du$，当且仅当 $\alpha\le1$ 时发散；二阶化为 $2c^2\int^{\infty}u^{-2\alpha}\,du$，当且仅当 $2\alpha>1$ 时收敛。两个条件同时满足的窗口是 $\alpha\in(1/2,1]$，$\alpha=1$ 是上端点。tex 取 $\alpha=1$，我现在的读法是它把窗口取到端点，端点同时给出两个闭式（一阶对数发散、二阶恰好等于 $c^2$），而 $\alpha\in(1/2,1)$ 内部虽然也满足两个条件，二阶积分会变成 $\dfrac{2c^2}{2\alpha-1}\,2^{1-2\alpha}$ 这类不再等于 $c^2$ 的数，预算常数就得整体重写。这个推算是我的补充，论文没写，风险在于它可能只是算术巧合，设计约束这一层我无法从 tex 里证实，我按个人推断登记。

## 4 最终思路与最初设想的差异

差别一，主角换位。我最初设想 $\Psi$ 是被构造的对象，最终 $\Psi$ 是最末一步的机械动作：`03-triangular.tex:118` 到 `03-triangular.tex:122` 定义 $\Psi(s)_i=B(s_i)$，它的双 Lipschitz 界来自 $B$ 与 $B^{-1}$ 的两条两点估计（`03-triangular.tex:135` 到 `03-triangular.tex:148`），它的双射性来自逐坐标的逆恒等式。真正被构造的是 $h$。两者之间的桥梁是 $B(e,v)=e+\delta(qe,v)$（`03-triangular.tex:61` 到 `03-triangular.tex:63`）与它的显式逆 $C(z)=(z-\delta(x),\pi_Vx)$，其中 $x=h^{-1}(qz)$（`03-triangular.tex:69` 到 `03-triangular.tex:74`）。

差别二，空间的出场顺序倒了。我原以为先有 $X,Y$ 再在它们之间找映射；最终是 $M=U\oplus_2V$（`01-introduction.tex:99`）与 $E=\mathcal F(M)$ 先出场，$X=Z_{Q_1}$、$Y=Z_q$（`01-introduction.tex:148`、`06-assembly.tex:27` 到 `06-assembly.tex:28`）到组装节才被定义。图空间是结论的容器，是几何完成后被造出来的。

差别三，阻碍的维数选择。我最初以为要把 $Y$ 里没有 $c_0$ 证出来，最终证明的是 $Y$ 里没有 $c_0(\ell_2)$，而且 $X$ 里的拷贝是 $c_0(V)$ 的等距嵌入 $\iota((v_i))=((0,v_i))_i$（`03-triangular.tex:153` 到 `03-triangular.tex:162`），其等距性靠 $\sum_{i\ge1}2^{-i}=1$。`01-introduction.tex:39` 到 `01-introduction.tex:40` 明确写着定理没有说 $Y$ 不含普通 $c_0$。

差别四，常数的地位。最初我猜常数会被写成"$L$"与"$1/L$"这种形式对称的量。最终 $4/21$ 与 $76/25$ 是纯下游的：$c=1/100$ 给出 $1-4c=24/25$、$1+4c=26/25$（`05-hilbert.tex:486` 到 `05-hilbert.tex:487`），$\lVert q\rVert\le\operatorname{Lip}(h)+\lVert\pi_U\rVert\le26/25+1=51/25$（`06-assembly.tex:21` 到 `06-assembly.tex:24`），于是 $\operatorname{Lip}(\Psi)\le\max\{1+51/25,26/25\}=76/25$、$\operatorname{Lip}(\Psi^{-1})\le\max\{1+2(51/25)/(24/25),25/24\}=21/4$（`06-assembly.tex:38` 到 `06-assembly.tex:47`）。判据本身只用 $a,b,L_q,K_q$ 表达（`03-triangular.tex:41` 到 `03-triangular.tex:42`）。这条链上 $c$ 只要小于 $1/16$ 就够，$1/100$ 是保守取法。

差别五，我原以为线性化要用来造 $\Psi$，最终它只造 $q$。$q\delta(u,v)=h(u,v)-u$（`01-introduction.tex:121` 到 `01-introduction.tex:123`）把非线性 $D$ 变成有界线性 $q$，$\Psi$ 用的是 $B$，而 $B$ 里出现的只有 $\delta$ 本身。线性化的用途被限定在"把几何转成算子性质"这一处。

差别六，$h$ 的两端我原以为一个是 $X$ 一个是 $Y$，最终是 $M$ 与 $U$，两者都是 Hilbert 空间，也就必然线性同构。非线性发生在 Hilbert 空间内部，线性阻碍发生在图空间层面，这个分工是我最初完全没料到的。

差别七，我原本预估要一个全局正交分解，最终只用到"$l$ 以上"。$\Pi_{\ge l}D(O_j)\subset H_j$（`04-localization.tex:27` 到 `04-localization.tex:30`）里的 $l$ 与 $O_j$ 都随那一个有限点族选，切指标可以任意大。这带来的直接后果是 `04-localization.tex:218` 到 `04-localization.tex:221` 那句：前 $l-1$ 块有限维，故弱零性在那里给的是范数收敛，这是有限维特有的礼物，全局正交版本反而用不上它。

## 5 图空间 $Z_Q$ 与范数的两项结构

我先把最终容器的定义抄在自己面前（`02-free-graph.tex:136` 到 `02-free-graph.tex:145`）。给定实 Banach 空间 $A,H$ 与有界线性 $Q:A\to H$，令

$$
Z_Q=\{s=(s_i)_{i\ge1}:s_i\in A,\ \textstyle\sum_{i\ge1}2^{-i}\lVert s_i\rVert<\infty,\ (Qs_i)_{i\ge1}\in c_0(H)\},
$$

范数取 $\lVert s\rVert_{Z_Q}=\max\{\sum_{i\ge1}2^{-i}\lVert s_i\rVert,\ \sup_{i\ge1}\lVert Qs_i\rVert\}$。这里我要把两件被我最初忽略的事写清楚。

第一件，成员条件里的 $(Qs_i)\in c_0(H)$ 独立于范数有限之外。作者专门用两行强调（`02-free-graph.tex:146` 到 `02-free-graph.tex:148`）：光有那个最大值有限并不要求 $Q$ 像趋于 $0$。我最初读这一段觉得是多余的警告，后来才明白它管住了整个阻碍的落点。阻碍论证最后要造 $a\mapsto(2^{-i}(SRa)_i)_i$ 这个进入 $\ell_1(E)$ 的嵌入（`02-free-graph.tex:350` 到 `02-free-graph.tex:353`），而 $SRa\in Z_q$ 这个事实的使用面包括"$q$ 像趋零"，它保证 $J_Q(s)=(Qs_i)_i$ 真的落在 $c_0(H)$ 里。少了独立条件，$J_q$ 的值域会跑到 $\ell_\infty(U)$ 去，那么 `02-free-graph.tex:310` 到 `02-free-graph.tex:312` 里"选 $m_j$ 使 $\sup_{i>m_j}\lVert(y_{k_j})_i\rVert<2^{-j}$"这一步就没有依据，截断 $z_j$ 造不出来。

第二件，权重 $2^{-i}$ 承担三个互不相同的职责。职责一是让坐标投影 $p_i:Z_Q\to A$ 有界且 $\lVert p_i\rVert\le 2^i$（`02-free-graph.tex:154`），这是闭性证明里 $\lVert s_i^{(k)}-s_i\rVert\le 2^i\lVert s^{(k)}-s\rVert_{\ell_1(2^{-j};A)}$ 的来源（`02-free-graph.tex:173` 到 `02-free-graph.tex:176`）。职责二是让 $\iota:c_0(V)\to X$，$\iota((v_i))=((0,v_i))_i$ 成为线性等距，其等式 $\max\{\sum_i2^{-i}\lVert v_i\rVert,\ \sup_i\lVert v_i\rVert\}=\sup_i\lVert v_i\rVert$ 靠的是 $\sum_{i\ge1}2^{-i}=1$（`03-triangular.tex:158` 到 `03-triangular.tex:162`）。职责三是把求和与取上确界放在同一量纲上，使 $\max$ 的两项能各自被 $B$ 与 $qB=hQ_1$ 控制：`03-triangular.tex:135` 到 `03-triangular.tex:140` 的两条不等式 $(1+K_q)\sum_i2^{-i}\lVert s_i-t_i\rVert$ 与 $b\sup_i\lVert Q_1(s_i-t_i)\rVert$ 正好对应两项，然后"取最大值即得"。

顺着职责二我算了一遍：换成权重 $w^{-i}$（$w\ge2$）时 $\sum_{i\ge1}w^{-i}=1/(w-1)\le1$，等距性仍成立，$p_i$ 界变成 $w^i$，闭性照旧；换成 $\sum_iw_i>1$ 的权重时 $\lVert\iota(v)\rVert_X$ 会大于 $\sup_i\lVert v_i\rVert$，$X$ 里的 $c_0(V)$ 拷贝退化成同构拷贝，而 `03-triangular.tex:166` 到 `03-triangular.tex:168` 只需要"闭子空间"，所以真正的破坏点在别处。我把这一条记进台账：$2^{-i}$ 的选取属于"够用即可"的那类设计，它的刚性出现在 $\sum_i2^{-i}=1$ 这一等号上，出现的位置是让 $\max$ 的第二项稳稳压住第一项。

`lem:graph-banach`（`02-free-graph.tex:150` 到 `02-free-graph.tex:191`）的证明结构我也想按我自己的思路重讲一遍。核心是把 $s\mapsto(s,(Qs_i)_i)$ 看成把 $Z_Q$ 等距嵌进 $\ell_1(2^{-i};A)\oplus_\infty c_0(H)$（`02-free-graph.tex:166` 到 `02-free-graph.tex:170`），然后证明这像是闭子空间。闭性的证明是逐坐标的：加权 $\ell_1$ 收敛给出每个固定 $i$ 的 $\lVert s_i^{(k)}-s_i\rVert\to0$，$Q$ 连续给出 $Qs_i^{(k)}\to Qs_i$，而在 $c_0(H)$ 里的收敛给出 $Qs_i^{(k)}\to y_i$，两边极限唯一，故 $y_i=Qs_i$。这套论证我一开始试图用"图空间是闭算子的图"这种抽象说法替代，结果在加权与上确界的范数匹配上说不圆；作者给的具体嵌入把 $\max$ 型范数变成 $\oplus_\infty$ 型范数，一步就把完备性变成"闭子空间"这一句。

可分性那一半（`02-free-graph.tex:181` 到 `02-free-graph.tex:190`）用的是截断：对 $Z_Q$ 中序列做前 $N$ 项截断，加权和部分因尾部消失而收敛，$Q$ 像部分因 $Q$ 像本身范数趋零而收敛；然后固定 $A$ 的一个可数稠密子集，有限支撑且取值于该子集的序列组成可数稠密集。我最初在这里多绕了一步：我以为要用 $H$ 的可分性去近似 $Q$ 像，实际不需要，因为 $Q$ 连续加上 $A$ 侧的可数近似已经保证 $\sup_i\lVert Qs_i-t_i\rVert$ 小。作者的原话是"each of their finitely many entries may be approximated in $A$ and $Q$ is continuous"。

Lean 侧对这一层的处理我在 `Model.lean` 里看到具体形态。`Model.lean:10` 写 `abbrev RealL2 := lp (fun _ : ℕ => ℝ) 2`，也就是 $\ell_2$ 用 `Mathlib` 的 `lp` 表示；`Model.lean:11` 写 `abbrev C0L2 := ZeroAtInftyContinuousMap ℕ RealL2`，即 $c_0(\ell_2)$ 用"在无穷远为零的连续映射"这一类型表示，指标集是 $\mathbb N$。`Model.lean:13` 到 `Model.lean:18` 把"可分实 Banach 空间"做成结构 `SeparableRealBanach`，四个字段分别是 `NormedAddCommGroup`、`NormedSpace ℝ`、`CompleteSpace`、`TopologicalSpace.SeparableSpace` 这四个类约束，`Model.lean:20` 到 `Model.lean:22` 再把这些实例 `attribute [instance]` 打开。这里有一个我在形式化时一定会踩的形状差异：tex 里的 $Z_Q$ 是一个具体的序列空间加显式范数，而 Lean 顶层的主张 `MainClaim`（`Model.lean:28` 到 `Model.lean:36`）只要求存在两个 `SeparableRealBanach` 与一个等价 `Ψ : X.Carrier ≃ Y.Carrier`，具体 $Z_Q$ 的构造被埋在中间层。`MainClaim` 里"非线性同构"写成 `IsEmpty (X.Carrier ≃L[ℝ] Y.Carrier)`，"X 含 $c_0(\ell_2)$"写成 `Nonempty (C0L2 →ₗᵢ[ℝ] X.Carrier)`（`→ₗᵢ` 是线性等距嵌入），"Y 不含"写成 `¬ ContainsLinearCopy C0L2 Y.Carrier`。而 `ContainsLinearCopy` 的定义（`Model.lean:24` 到 `Model.lean:26`）是 $\exists T,a$，$0<a$，且 $\forall x$，$a\lVert x\rVert\le\lVert Tx\rVert$，即"存在有下界的有界线性单射"。这与 tex 里"linear embedding means a bounded linear map that is bounded below; its range is consequently closed"（`01-introduction.tex:18` 到 `01-introduction.tex:19`）逐字对得上，只是"值域闭"这件事在 Lean 侧要作为引理证出来，在 tex 侧是一句话。

## 6 自由空间侧的三块地基

第一块地基是 $\delta$ 的等距。设 $(M,d,0)$ 为带基点度量空间，$\operatorname{Lip}_0(M)$ 是实值、$f(0)=0$ 的 Lipschitz 函数空间，范数为 $\operatorname{Lip}(f)$，$\delta(x)$ 是 $f\mapsto f(x)$ 这个评估，$\mathcal F(M)$ 定义为 $\overline{\operatorname{span}}\{\delta(x):x\in M\}\subset\operatorname{Lip}_0(M)^*$（`02-free-graph.tex:18` 到 `02-free-graph.tex:21`）。核心式子是 $\lVert\delta(x)-\delta(y)\rVert=d(x,y)$（`02-free-graph.tex:31`，标签 `eq:delta-isometry`）。上界来自 Lipschitz 不等式，下界用测试函数 $t\mapsto d(t,y)-d(0,y)$，其 Lipschitz 常数不超过 $1$（`02-free-graph.tex:33` 到 `02-free-graph.tex:35`）。这个测试函数的取法我最初想用 $d(\cdot,y)$ 本身，但那样 $f(0)=d(0,y)$ 非零，超出 $\operatorname{Lip}_0$；减去常数 $d(0,y)$ 正是把函数拉回零保持类的动作，也是为什么 `02-free-graph.tex:25` 到 `02-free-graph.tex:26` 要额外约定"当 $f$ 不一定满足 $f(0)=0$ 时，$\langle f,\mu\rangle$ 表示 $\langle f-f(0),\mu\rangle$"。可分性的传递也在此：取可数稠密 $D_0\subset M$，`eq:delta-isometry` 让 $\delta(D_0)$ 的有限有理线性组合在 $\mathcal F(M)$ 中稠密（`02-free-graph.tex:36` 到 `02-free-graph.tex:38`）。

第二块地基是限制到子集的等距性，具体说：若 $K\subset M$ 含 $0$，则 $\delta(K)$ 在 $\mathcal F(M)$ 中的闭张成同构于 $\mathcal F(K)$。证明用 McShane 公式 $\widetilde f(x)=\inf_{z\in K}(f(z)+L\,d(x,z))$（`02-free-graph.tex:45` 到 `02-free-graph.tex:47`），$L=0$ 时用常数扩张。作者把三个容易漏的点都写了出来：在 $K$ 上该下确界等于 $f$（由 Lipschitz 不等式），在 $M$ 上给出 $L$-Lipschitz（由三角不等式），下确界有限（$0\in K$ 给上界，三角不等式给下界）。这三条合起来才使两个自由空间范数在支撑于 $K$ 的有限评估和上相等，再由闭包传递（`02-free-graph.tex:52` 到 `02-free-graph.tex:55`）。它的产物是配对估计 $\lvert\langle f,\nu\rangle\rvert\le\operatorname{Lip}(f\vert_K)\lVert\nu\rVert$，$\nu\in\mathcal F(K)$（`02-free-graph.tex:56` 到 `02-free-graph.tex:59`，标签 `eq:compact-pairing`）。我在第 8 节会用这一条：`04-localization.tex:365` 到 `04-localization.tex:373` 的余项配对分解 $|\langle R_{i,r},\mu_i\rangle|\le(M_0+\tau)\operatorname{Lip}(R_{i,r}\vert_K)+7L\tau$ 中，第一项靠 `eq:compact-pairing`，第二项靠全局界 `eq:global-remainder`。

第三块是线性化。对任意 Banach 空间 $H$ 与满足 $D(0)=0$ 的 Lipschitz $D:M\to H$，存在唯一有界线性 $\widehat D:\mathcal F(M)\to H$ 使 $\widehat D\delta(x)=D(x)$ 且 $\lVert\widehat D\rVert=\operatorname{Lip}(D)$（`02-free-graph.tex:61` 到 `02-free-graph.tex:68`，标签 `eq:linearization`）。构造式是 $\widehat D(\sum_ja_j\delta(x_j))=\sum_ja_jD(x_j)$，良定义性靠 $\lVert\sum_ja_jD(x_j)\rVert\le\operatorname{Lip}(D)\lVert\sum_ja_j\delta(x_j)\rVert$（`02-free-graph.tex:73` 到 `02-free-graph.tex:76`），这个不等式的证法是对右边那个向量取一个范数为 $1$ 的 $H^*$ 中泛函再用自由空间范数定义。反向范数界靠把扩张作用在 $\delta(x)-\delta(y)$ 上测试（`02-free-graph.tex:79` 到 `02-free-graph.tex:80`）。我最初在这里有一个错误的方向感：我以为"唯一"与"$\lVert\widehat D\rVert=\operatorname{Lip}(D)$"意味着 $\widehat{\cdot}$ 是某种等距的函子，可以随意组合。实际上它只在零保持映射的范畴里成立，而 `03-triangular.tex:64` 里用到的形式是 $q\delta(u,v)=h(u,v)-u$，右侧正是 $D(u,v)=h(u,v)-u$ 且 $D(0)=0$，条件刚好踩在成立范围内。

两块外部输入也必须登记，因为它们不是我能在本仓库里核实的。第一块是紧约化：$\mathcal F(M)$ 中弱零序列可被任意 $\tau>0$ 贴近到某个含 $0$ 的紧集 $K$ 的闭评估张成 $\mathcal F(K)$（`02-free-graph.tex:90` 到 `02-free-graph.tex:98`，标签 `thm:compact-reduction`）。作者交代它的来历与我的推法不同：源定理说的是完备 $M$ 上 $\mathcal F(M)$ 的每个弱预紧子集是紧的（tight），即对每个 $\epsilon>0$ 存在紧 $K_0\subset M$ 使 $W\subset\mathcal F(K_0)+\epsilon B_{\mathcal F(M)}$；这里对 $W=\{0,\mu_1,\mu_2,\ldots\}$ 用 $\epsilon=\tau/2$，再把 $0$ 并进去（`02-free-graph.tex:104` 到 `02-free-graph.tex:114`）。$W$ 弱预紧的理由写得很细：其中任一序列要么有常值子列，要么指标趋于无穷而弱收敛到 $0$。这个"把集合级定理降级成序列级推论"的转换，我如果自己做会漏掉"常值子列"这一支。第二块是自由空间的弱序列完全性：$M$ 为超自反实 Banach 空间则 $\mathcal F(M)$ 弱序列完全，特别地任何实 Hilbert 空间 $M$ 都行（`02-free-graph.tex:119` 到 `02-free-graph.tex:124`，标签 `thm:free-wsc`），其紧集输入是 Kochanek--Pernecká 的主定理。`03-triangular.tex:163` 到 `04-localization.tex:165` 处用的正是它：$M$ 超自反故 $E=\mathcal F(M)$ 弱序列完全。Lean 侧对应的入口在 `Main.lean:9`，那里传入的第一参数事实是 `CompactWSC.hilbert_free_wsc`，命名与 `thm:free-wsc` 的"Hilbert 情形"完全对应。

弱序列完全性用到的是 `lem:no-c0-sum`（`02-free-graph.tex:197` 到 `02-free-graph.tex:265`），这条引理我读了三遍才把它的边界读准。它的陈述是：$E$ 弱序列完全则 $\ell_1(E)$ 不含同构于普通 $c_0$ 的闭子空间。证明的骨架是四步。第一步性质传递：有限直和保持弱序列完全（逐坐标取弱极限），闭线性子空间也保持（弱闭性靠 Hahn--Banach 分离，泛函延拓靠 Hahn--Banach）。第二步反例素材：普通 $c_0$ 本身不弱序列完全，单位基的部分和 $e_1+\cdots+e_n$ 对每个 $(a_k)\in c_0^*=\ell_1$ 给出 Cauchy 部分和 $\sum_{k\le n}a_k$，故弱 Cauchy，而任何弱极限的每个坐标都得是 $1$，那不属于 $c_0$（`02-free-graph.tex:215` 到 `02-free-graph.tex:220`）。第三步构造：给定嵌入 $A:c_0\to\ell_1(E)$ 下界 $b>0$，取前 $N$ 坐标投影 $P_N$（$P_0=0$），则每个 $P_NA$ 都不下有界（否则 $E^N$ 里出现 $c_0$ 拷贝），于是可递归选单位向量 $x_j$ 与递增 $N_j$ 使 $\lVert P_{N_{j-1}}Ax_j\rVert<b/8$ 与 $\lVert(I-P_{N_j})Ax_j\rVert<b/8$，令 $z_j=(P_{N_j}-P_{N_{j-1}})Ax_j$，得 $\lVert Ax_j-z_j\rVert<b/4$、$\lVert z_j\rVert>3b/4$，$z_j$ 支撑互不相交，故对有限标量族有 $\lVert\sum_j\alpha_jAx_j\rVert\ge\sum_j\lvert\alpha_j\rvert\lVert z_j\rVert-\sum_j\lvert\alpha_j\rvert\lVert Ax_j-z_j\rVert\ge(b/2)\sum_j\lvert\alpha_j\rvert$（`02-free-graph.tex:240` 到 `02-free-graph.tex:249`）。第四步收尾：于是 $a\mapsto\sum_j\alpha_jx_j$ 的像给出 $\ell_1$ 到 $c_0$ 的有界线性嵌入且值域闭，而 $c_0$ 的任一闭子空间 $F$ 的对偶由限制映射 $\ell_1=c_0^*\to F^*$ 满射故可分，$\ell_1$ 的对偶是 $\ell_\infty$，其中全体 $0$-$1$ 序列两两距离 $1$ 组成不可数离散集，矛盾（`02-free-graph.tex:256` 到 `02-free-graph.tex:264`）。

## 7 局部正交逼出完全连续（上）：反证框架与标量测试

`thm:localized-linearization`（`04-localization.tex:12` 到 `04-localization.tex:37`）是我认为全篇最值得单独拆开看的一条定理，因为它的假设只谈度量与坐标，结论却是一个算子理想性质。假设侧的对象是：完备可分带基点度量空间 $(M,\rho,0)$，$U=(\bigoplus_{n\ge1}U_n)_2$ 的块有限维，每块固定一组正交基，$\Pi_{\ge l}$ 是投到 $U_{\ge l}=(\bigoplus_{n\ge l}U_n)_2$；$D:M\to U$ 满足 $D(0)=0$；对每个 $m\ge1$ 与每组互异点 $z_1,\ldots,z_m\in M$，存在开邻域 $O_j$、整数 $l\ge1$ 与两两正交的坐标子空间 $H_j\subset U_{\ge l}$ 使 $\Pi_{\ge l}D(O_j)\subset H_j$（`eq:local-orthogonality`，`04-localization.tex:27` 到 `04-localization.tex:30`）。"坐标子空间"指固定正交基某个子集的闭张成。

证明从反证开始，我按我自己的顺序重走。设 $E=\mathcal F(M)$，$L=\operatorname{Lip}(D)=\lVert q\rVert$；$L=0$ 时由 $D(0)=0$ 得 $D=0$ 故 $q=0$，所以取 $L>0$（`04-localization.tex:160` 到 `04-localization.tex:161`）。若 $q$ 不完全连续，取子列后有 $\mu_i\to0$ 弱且 $\lVert q\mu_i\rVert\ge\epsilon_0>0$。定义 $b_i=q\mu_i/\lVert q\mu_i\rVert$、$d_i(x)=\langle D(x),b_i\rangle$、$M_0=\sup_i\lVert\mu_i\rVert<\infty$（`04-localization.tex:165` 到 `04-localization.tex:168`）。这三行的分工是：$b_i$ 把范数信息标准化成单位向量，$d_i$ 把 $U$ 值映射压成实值 Lipschitz 函数，$M_0$ 是给后面配对估的公共系数。

关键的第一步推论是 $b_i$ 弱零。对每个固定 $b\in U$ 有 $\lvert\langle b_i,b\rangle\rvert\le\epsilon_0^{-1}\lvert\langle q\mu_i,b\rangle\rvert\to0$，因为有界线性映射保弱收敛（`04-localization.tex:170` 到 `04-localization.tex:175`）。这一步把"序列的弱零"转移到"$U$ 里一列单位向量的弱零"，是整个转换的枢纽：后面所有坐标上的趋零都从 $b_i$ 的弱零取。于是得到 `eq:scalar-tests`（`04-localization.tex:176` 到 `04-localization.tex:180`）：$d_i(0)=0$、$\operatorname{Lip}(d_i)\le L$、$\langle d_i,\mu_i\rangle=\lVert q\mu_i\rVert\ge\epsilon_0$。第三条我要单独核对：$\langle d_i,\mu_i\rangle$ 按 `02-free-graph.tex:25` 的约定等于 $\langle d_i-d_i(0),\mu_i\rangle$，而 $d_i(0)=0$；另一方面 $d_i(x)=\langle D(x),b_i\rangle$ 意味着 $d_i=\langle D,b_i\rangle$，线性化后 $\widehat{d_i}=\langle q(\cdot),b_i\rangle$ 在 $\mu_i$ 处取值 $\langle q\mu_i,b_i\rangle=\lVert q\mu_i\rVert$，因为 $b_i$ 正是 $q\mu_i$ 方向的单位向量。这就是"$\ge\epsilon_0$"的来历。我最初在这里想写成 $\lVert q\mu_i\rVert=\sup_{\lVert b\rVert=1}\lvert\langle q\mu_i,b\rangle\rvert$ 然后取近极向量，作者的做法是直接取 $b_i$，因为它弱零这件事比"极值"更有用，一个选择同时喂出两个性质。

第二个推论是 $d_i$ 在每个紧子集上一致趋零。逐点趋零来自 $b_i$ 弱零；给定紧集与正误差，取一个足够细的有限度量网，网点的逐点收敛加共同的 Lipschitz 界 $L$ 就控制整个紧集（`04-localization.tex:181` 到 `04-localization.tex:185`）。这段是标准的等度连续加逐点收敛，但作者把"$\epsilon_i=\sup_{x\in K\cup Z}\lvert d_i(x)\rvert\to0$"（`04-localization.tex:300` 到 `04-localization.tex:303`）放在后面用，用的时候要 $K\cup Z$ 含 $0$，所以这里必须把紧集与有限点集合并成同一个集合来取一致趋零。我第一遍读时把这两处当成同一件事，第二遍才发现 `04-localization.tex:302` 到 `04-localization.tex:303` 专门写了"including when $Z$ is empty"。

第三步是我最初最容易做错的地方：子列的固定顺序。取 $M$ 的可数基 $\mathcal B$（可分性给出），约定"至多一个点的集合上的 Lipschitz 常数取 $0$"（`04-localization.tex:191` 到 `04-localization.tex:192`）。对每个 $O\in\mathcal B$，$\operatorname{Lip}(d_i\vert_O)\in[0,L]$，于是对可数多个 $O$ 依次取子列再对角化，重编号后可设所有极限 $a_O=\lim_{i\to\infty}\operatorname{Lip}(d_i\vert_O)$ 存在（`04-localization.tex:193` 到 `04-localization.tex:199`）。作者紧接着写了一句"this subsequence is fixed before the next parameter is chosen"，这句是我在第 2 节路线丁里那条错误的直接反证：我最初的写法里 $Z$ 依赖 $\eta$ 而子列又依赖 $\eta$，导致对角化不合法。定完子列才固定 $\eta>0$，定义 $Z=\{z\in M:\text{对每个含 }z\text{ 的 }O\in\mathcal B\text{ 有 }a_O\ge\eta\}$（`04-localization.tex:202` 到 `04-localization.tex:206`）。

$Z$ 的直观含义是"$d_i$ 的局部 Lipschitz 常数在极限下仍不小于 $\eta$ 的点"。我最初的判断是 $Z$ 可能是一个分形集，甚至有势测度；作者接着给出的却是一个纯计数论证把它压成有限集，这就是下一节的开头。把 $Z$ 有限性单独抽出来看，我注意到它的证明用到了三样东西同时在场：邻域缩到基邻域、$P_j$ 与 $\Pi_{<l}$ 的分解、以及 $\lVert b_i\rVert=1$ 的归一化。三者缺一，$m$ 就无界。

## 8 局部正交逼出完全连续（下）：例外点基数、收缩球与紧约化

先处理 $Z$ 有限。取 $Z$ 中互异点 $z_1,\ldots,z_m$，用 `eq:local-orthogonality` 得到邻域后把它们缩进含 $z_j$ 的基邻域 $O_j$（`04-localization.tex:207` 到 `04-localization.tex:210`）。$P_j$ 是投到 $H_j$，$\Pi_{<l}=I-\Pi_{\ge l}$。对 $x,y\in O_j$，尾部 $\Pi_{\ge l}(D(x)-D(y))$ 落在 $H_j$ 里，于是

$$
\lvert d_i(x)-d_i(y)\rvert\le L\rho(x,y)\bigl(\lVert P_jb_i\rVert+\lVert\Pi_{<l}b_i\rVert\bigr)
$$

（`04-localization.tex:211` 到 `04-localization.tex:216`）。这一行的读法我要慢一点：$d_i(x)-d_i(y)=\langle D(x)-D(y),b_i\rangle$ 拆成尾部与低部两块，尾部那块只碰 $P_jb_i$，低部那块用 $\lVert D(x)-D(y)\rVert\le L\rho(x,y)$ 硬吃。前 $l-1$ 块有限维，$b_i$ 弱零使其有限个坐标逐个趋零，故 $\lVert\Pi_{<l}b_i\rVert\to0$；由 $a_{O_j}\ge\eta$ 得 $\liminf_i\lVert P_jb_i\rVert\ge\eta/L$。$P_j$ 值域两两正交且 $\lVert b_i\rVert=1$，所以 $m\eta^2/L^2\le\liminf_i\sum_{j=1}^m\lVert P_jb_i\rVert^2\le1$，即 $\lvert Z\rvert\le L^2/\eta^2$（`04-localization.tex:224` 到 `04-localization.tex:236`）。我把这条不等式当作"局部版本"与"全局版本"之间的汇率：全局正交时 $m$ 可以任意大，代价在维数；局部正交时 $m$ 被汇率顶死，代价在邻域。

现在插入独立引理 `lem:shrinking-tests`（`04-localization.tex:46` 到 `04-localization.tex:157`）。假设 $r_i>0$、$r_i\to0$、$f_i(z)=0$、$\operatorname{Lip}(f_i)\le C$、且在 $\rho(x,z)\ge r_i$ 上 $f_i(x)=0$，则 $\langle f_i,\mu_i\rangle\to0$。工具是截断 $\phi_{z,s}(x)=\max\{0,\min\{1,2-2\rho(x,z)/s\}\}$：在 $B(z,s/2)$ 上为 $1$，在 $B(z,s)$ 外为 $0$，取值在 $[0,1]$，Lipschitz 常数至多 $2/s$（`04-localization.tex:60` 到 `04-localization.tex:65`）。乘积估计是 $\operatorname{Lip}(f\phi_{z,s})\le3C$ 与 $\operatorname{Lip}(f(1-\phi_{z,s}))\le3C$（`eq:cutoff-products`，`04-localization.tex:67` 到 `04-localization.tex:71`）。作者给的推导我逐句核过：若 $\psi(x)=\psi(y)$ 则差至多 $C\rho(x,y)$；否则至少一端在 $B(z,s)$ 内，记作 $x$，则 $\lvert f(x)\rvert\le Cs$，用恒等式 $f(x)\psi(x)-f(y)\psi(y)=\psi(y)(f(x)-f(y))+f(x)(\psi(x)-\psi(y))$ 得绝对值不超过 $C\rho(x,y)+Cs(2/s)\rho(x,y)=3C\rho(x,y)$。$3$ 这个数来自 $1$（$\psi$ 的 Lipschitz 吸收）加 $2$（$f(x)$ 的 $Cs$ 与 $\psi$ 的 $2/s$ 相消），与 $C$ 无关；作者还补一句"$3C$ 不需要 $f$ 的全局界"，这一句把我最初的疑虑（要用 $f$ 的 $\sup$ 范数）取消了。

反证部分的递归值得单独记：设 $\lvert\langle f_i,\mu_i\rangle\rvert\ge\epsilon>0$，则 $C>0$；递归选递增 $i_j$、$0<s_j<r_{i_j}$ 与 $h_j=f_{i_j}(1-\phi_{z,s_j})$，使 $\lvert\langle h_j,\mu_{i_j}\rangle\rvert>\epsilon/2$、$\operatorname{Lip}(h_j)\le3C$、$r_{i_{j+1}}<s_j/2$（`eq:annular-selection`，`04-localization.tex:94` 到 `04-localization.tex:98`）。选 $s_j$ 时要让它小于 $z$ 到 $\{0,x_{j1},\ldots,x_{jN_j}\}$ 的每个正距离（`04-localization.tex:105` 到 `04-localization.tex:108`），近似误差取 $\lVert\mu_{i_j}-\nu_j\rVert<\epsilon/(6C)$（`04-localization.tex:103`）。$6$ 的来源是三份：$\epsilon/2$ 的余量、$3C$ 的 Lipschitz、以及一个 $2$ 倍。作者给的链条是 $\lvert\langle p_j,\mu_{i_j}\rangle\rvert\le3C\lVert\mu_{i_j}-\nu_j\rVert<\epsilon/2$，与原配对 $\ge\epsilon$ 相减得 $>\epsilon/2$。$h_j$ 的非零集在环 $\{x:s_j/2<\rho(x,z)<r_{i_j}\}$ 内，这些环两两不交（`04-localization.tex:127` 到 `04-localization.tex:131`），于是任意有限带符号和 $H=\sum_{j\in A}\sigma_jh_j$（$\sigma_j\in\{-1,1\}$）满足 $\operatorname{Lip}(H)\le6C$：同一点至多一个非零和分项，两点在同一非零集时用该分项的 $3C$，两点在不同非零集时两个函数各在对方点处为零故 $3C$ 相加（`04-localization.tex:132` 到 `04-localization.tex:139`）。于是 $\sum_{j\in A}\lvert\langle h_j,\mu\rangle\rvert=\max_{\sigma_j}\lvert\langle\sum_j\sigma_jh_j,\mu\rangle\rvert\le6C\lVert\mu\rVert$，$T\mu=(\langle h_j,\mu\rangle)_{j\ge1}$ 是范数至多 $6C$ 的有界线性算子进 $\ell_1$（`04-localization.tex:141` 到 `04-localization.tex:152`）。$\ell_1$ 的 Schur 性质给 $\lVert T\mu_{i_j}\rVert\to0$，而第 $j$ 个坐标绝对值大于 $\epsilon/2$，矛盾。这条引理是我认为整节最像"手工活"的地方：环不交、符号取最大、Schur 收尾，三个动作合起来把一个"半径趋零"的条件换成一个"逐坐标趋零"的条件。

回到主证明。选 $r_0>0$ 使 $B(z,r)$（$z\in Z$）在 $0<r<r_0$ 时两两不交，$Z$ 至多一个点时任意 $r_0$ 可行（`04-localization.tex:241` 到 `04-localization.tex:243`）。定义 $f_{i,z,r}=\phi_{z,r}(d_i-d_i(z))$、$g_{i,r}=\sum_{z\in Z}f_{i,z,r}$、$R_{i,r}=d_i-g_{i,r}$，空和为 $0$（`04-localization.tex:245` 到 `04-localization.tex:249`）。由 `eq:cutoff-products` 得 $\operatorname{Lip}(f_{i,z,r})\le3L$，非零集在不交球内故有限带符号和的两点论证给出 $\operatorname{Lip}(g_{i,r})\le6L$、$\operatorname{Lip}(R_{i,r})\le7L$，且这些常数与 $r$、与 $\lvert Z\rvert$ 都无关（`eq:global-remainder`，`04-localization.tex:250` 到 `04-localization.tex:258`）。$7$ 的来源是 $6L$ 加 $\operatorname{Lip}(d_i)\le L$。固定 $z$ 有有序极限 $\lim_{r\downarrow0}\limsup_i\lvert\langle f_{i,z,r},\mu_i\rangle\rvert=0$（`eq:one-shrinking-limit`，`04-localization.tex:260` 到 `04-localization.tex:265`），否的话取 $a>0$、$r_j\downarrow0$ 与递增 $i_j$ 使 $\lvert\langle f_{i_j,z,r_j},\mu_{i_j}\rangle\rvert\ge a$，这些测试在 $z$ 处为零、Lipschitz 至多 $3L$、在 $B(z,r_j)$ 外为零，正好落进 `lem:shrinking-tests`。$Z$ 有限故三角不等式把逐点结论升级成 $\lim_{r\downarrow0}\limsup_i\lvert\langle g_{i,r},\mu_i\rangle\rvert=0$（`eq:shrinking-limit`，`04-localization.tex:274` 到 `04-localization.tex:280`），$Z$ 为空时该行显然。

余项的估计是最后一段。固定 $\tau>0$，用 `thm:compact-reduction` 取含 $0$ 的紧集 $K$ 与 $\nu_i\in\mathcal F(K)$ 使 $\lVert\mu_i-\nu_i\rVert<\tau$、$\lVert\nu_i\rVert\le M_0+\tau$，$K$ 依赖 $\tau$ 与序列但依赖不到 $r$（`04-localization.tex:287` 到 `04-localization.tex:295`）。固定 $0<r<r_0$ 后令 $\Phi_r=\sum_{z\in Z}\phi_{z,r}$、$\epsilon_i=\sup_{x\in K\cup Z}\lvert d_i(x)\rvert$，不交球给 $0\le\Phi_r\le1$，且关键恒等式 $R_{i,r}=(1-\Phi_r)d_i+\sum_{z\in Z}\phi_{z,r}d_i(z)$（`eq:remainder-identity`，`04-localization.tex:296` 到 `04-localization.tex:308`）。我在这一处停了一下才看懂它的代数：$d_i-g_{i,r}=d_i-\sum_z\phi_{z,r}(d_i-d_i(z))=(1-\Phi_r)d_i+\sum_z\phi_{z,r}d_i(z)$，那个 $+\sum\phi_{z,r}d_i(z)$ 是把被减掉的常数项还回来。它的后果是 $\sup_{x\in K}\lvert R_{i,r}(x)\rvert\le\epsilon_i$（右边是若干被 $\epsilon_i$ 控制之值的凸组合）与"$R_{i,r}$ 在内球 $B(z,r/2)$ 上是常数 $d_i(z)$"（`04-localization.tex:309` 到 `04-localization.tex:316`）。$p\notin Z$ 处取 $a_O<\eta$ 的 $O$，展开后得 $\operatorname{Lip}(R_{i,r}\vert_{K\cap O})\le\operatorname{Lip}(d_i\vert_O)+(4m/r)\epsilon_i$，其中 $m=\lvert Z\rvert$（`eq:local-remainder`，`04-localization.tex:318` 到 `04-localization.tex:334`），$4$ 的来源是 $\lvert d_i(z)-d_i(y)\rvert\le2\epsilon_i$ 与 $\operatorname{Lip}(\phi_{z,r})\le2/r$ 相乘。内球与基邻域覆盖 $K$，取有限子覆盖 $V_1,\ldots,V_N$ 与 Lebesgue 数 $\lambda>0$，短程对受 $\max_tc_{i,t}$ 控制、长程对受 $2\epsilon_i/\lambda$ 控制，于是 $\limsup_i\operatorname{Lip}(R_{i,r}\vert_K)\le\eta$（`eq:compact-remainder`，`04-localization.tex:337` 到 `04-localization.tex:363`）。配对分解后（`04-localization.tex:365` 到 `04-localization.tex:387`）得 $\limsup_i\lvert\langle d_i,\mu_i\rangle\rvert\le\eta(M_0+\tau)+7L\tau$，右端与 $r$ 无关，于是可以按 $r\downarrow0$、$\tau\downarrow0$、$\eta\downarrow0$ 的顺序收尾，与 `eq:scalar-tests` 的 $\ge\epsilon_0$ 矛盾。作者在这一段落尾用五行写量词顺序并强调"没用过 $i$ 与 $r$ 的联合一致收敛"，我把它当作本节最重要的一条纪律记录下来。

Lean 侧对这一节的切分我实测到三个文件。`Localization.lean`（455 行）从 `:31` 的 `normalized`、`:37` 的 `test`、`:49` 的 `norm_test_apply_le`、`:54` 的 `norm_normalized_le`、`:60` 的 `cutoff`、`:64` 的 `cutoff_nonneg` 起步，也就是先做"把实值 Lipschitz 函数变成 $\operatorname{Lip}_0(M)$ 的元素并配对估计"这套机器；`CompactLocalization.lean`（316 行）从 `:20` 的 `cutoff_nonzero_mem`、`:27` 的 `disjoint_cutoffs`、`:34` 的 `sum_cutoff_bounds`、`:53` 的 `def removed`、`:56` 的 `def remainder`、`:59` 的 `removed_lipschitz`、`:75` 的 `remainder_lipschitz`、`:84` 的 `remainder_inner` 起步，这一串与 `eq:global-remainder`、`eq:remainder-identity`、`eq:remainder-sup` 逐条同名对应；`CompactReduction.lean`（136 行）的 `:20` 是 `structure LocalizationState (R : ℝ≥0)`、`:29` 是 `localization_step`、`:60` 是 `bounded_compact_reduction`、`:116` 是 `hasCompactReduction`，其中 `R : ℝ≥0` 这个参数的形状告诉我：tex 里的"任意 $\tau>0$"在 Lean 里被写成非负实数半径的谓词 `hasCompactReduction`，紧约化从一个存在性定理改造成一个性质。命名空间的归属也在 `CompactReduction.lean:15` 与 `CompactLocalization.lean:15` 处分别落在 `LipschitzCounterexample.FreeSpace` 与 `LipschitzCounterexample.LocalizedLinearization`，也就是同一层 tex 内容在 Lean 里被分到两个 namespace，切缝与论文节号并不同构。

## 9 冻结重排与槽的路由

这一节是 Hilbert 侧的地基，我把它单独写是因为它的全部难处都藏在"为什么是 $2m$ 与 $2m-1$"这一个选择里。设 $U=(\bigoplus_{n\ge1}U_n)_2$ 的块是任意的非零有限维实 Hilbert 空间（`05-hilbert.tex:43` 到 `05-hilbert.tex:44`，此时还没有维数公式），$V=\ell_2$，$M=U\oplus_2V$，每块选单位向量 $\xi_n$。对 $x=(u,v)$ 记

$$
\alpha_n=\langle\xi_n,u_n\rangle,\qquad u_n^\perp=u_n-\alpha_n\xi_n,\qquad C_{2m}=\alpha_m,\quad C_{2m-1}=v_m,
$$

再定义 $(L_\xi x)_n=u_n^\perp+C_n\xi_n$（`eq:frozen-map`，`05-hilbert.tex:47` 到 `05-hilbert.tex:56`）。路由是三条线：正交部留在块 $n$，旧槽系数进块 $2m$ 的槽位，$v_m$ 进块 $2m-1$ 的槽位，`figures/slot-rearrangement.tex:6` 到 `figures/slot-rearrangement.tex:11` 的三个节点写的正是这三条线，标签分别是 `unchanged`、`even slots`、`odd slots`。

`lem:frozen-inverse` 断言 $L_\xi:M\to U$ 是满线性等距，逆为 $(L_\xi^{-1}y)_{U_m}=y_m-\beta_m\xi_m+\beta_{2m}\xi_m$、$(L_\xi^{-1}y)_{V_m}=\beta_{2m-1}$，其中 $\beta_n=\langle\xi_n,y_n\rangle$（`eq:frozen-inverse`，`05-hilbert.tex:75` 到 `05-hilbert.tex:82`）。范数计算（`05-hilbert.tex:86` 到 `05-hilbert.tex:95`）是 $\lVert L_\xi x\rVert^2=\sum_n\lVert u_n^\perp\rVert^2+\sum_n\lvert C_n\rvert^2=\sum_n(\lVert u_n\rVert^2-\lvert\alpha_n\rvert^2)+\sum_m\lvert\alpha_m\rvert^2+\sum_m\lvert v_m\rvert^2=\lVert x\rVert_M^2$，两个 $\sum\lvert\alpha_m\rvert^2$ 一负一正完全相消。逆的方向（`05-hilbert.tex:98` 到 `05-hilbert.tex:109`）先要 $\lvert\beta_n\rvert\le\lVert y_n\rVert$ 保证 $(\beta_n)\in\ell_2$，再由 $y_m-\beta_m\xi_m$ 与 $\beta_{2m}\xi_m$ 正交得 $\sum_m(\lVert y_m\rVert^2-\lvert\beta_m\rvert^2+\lvert\beta_{2m}\rvert^2+\lvert\beta_{2m-1}\rvert^2)=\lVert y\rVert^2$，同样是偶奇两块的 $\sum\lvert\beta\rvert^2$ 相消。

我最初的取法是"$C_n=\alpha_n$ 与 $C_{n+N}$ 分给 $v$"这类平移方案，写下来立刻发现 $M$ 与 $U$ 的坐标索引集不同：$M$ 一侧是 $\{U_n\}_{n\ge1}$ 加上 $\{v_m\}_{m\ge1}$，$U$ 一侧只有 $\{U_n\}_{n\ge1}$。要让一个索引列吃掉两列，必须用一个 $\mathbb N\to\mathbb N$ 的双射把两个源列打包，偶奇分裂是最小的显式方案。这个观察的直接后果是：$\dim U_n$ 必须足够大以同时容纳"一个正交部"与"一个槽位"，而 $u_n^\perp$ 的维数是 $\dim U_n-1$，所以 $U_n$ 至少要 $2$ 维；`05-hilbert.tex:186` 给的 $\dim U_n=1+\sum_{k=1}^n(2k+1)^k$ 远超此数，多余部分是留给阶段坐标的。

图注那里我读到一个容易被忽略的限定（`05-hilbert.tex:66` 到 `05-hilbert.tex:69`）：这张图描述的是冻结的线性等距；一旦槽依赖输入，它只给出逐点范数恒等式 $\lVert h(x)\rVert=\lVert x\rVert$，不再给出不同输入之间距离的保持。这一点与 `05-hilbert.tex:130` 到 `05-hilbert.tex:133` 呼应："frozen isometry shows this is well-defined and gives the pointwise norm identity; this identity does not yet compare distinct inputs"。我把它写成一个原则：$L_\xi$ 提供的保证是逐点的（fiberwise），两点之间的比较必须由导数预算提供。整个 Hilbert 构造因此分成两笔账，逐点账由等距白送，两点账由 $4c$ 买单。

Lean 侧的实现分散在四个文件。`HilbertDecomposition.lean`（331 行）里 `:16` 是 `abbrev HilbertSum (E : ι → Type uE) := lp E 2`，`:19` 是 `norm_sq_tsum`（$\lVert x\rVert^2=\sum'_i\lVert x_i\rVert^2$），`:23` 是 `summable_norm_sq`，`:28` 是 `def embed`，`:40` 是 `def coeff`（把槽系数序列做成连续线性映射进 $\ell_2$），`:57` 是 `inner_slot_self`（$\langle\xi_i,\xi_i\rangle=1$），`:65` 是 `def perp`，`:84` 是 `perp_add_embed`。这个切法告诉我形式化时把"$u^\perp$ 与槽系数"作为两个独立算子定义，正交分解的恒等式（tex 里一行）在这里被拆成 `perp`、`coeff`、`embed` 三件加一条 `perp_add_embed`。`MovingSlots.lean`（252 行）里 `:14` 是 `def scalarSlot`、`:17` 是 `def slotCoord`、`:22` 是 `def movingSlotsMap (x : SlotDomain E) : HilbertSum E := frozen (fun n => w n x) (fun n => hw n x) x`、`:28` 是 `theorem norm_movingSlotsMap`，其证明体是 `(frozen _ _).norm_map x`，也就是说 tex 的"冻结等距"在 Lean 里是一个叫 `frozen` 的对象，`MovingSlots.lean:28` 直接把逐点范数恒等式挂在它身上。`SeparatingCoordinates.lean`（396 行）与 `SeparableCoordinates.lean`（356 行）管坐标子空间与分离坐标，后者的 `:23` 是 `def space (S : Set (Σ n, ι n)) : Submodule ℝ (Hilbert (ι := ι))`、`:30` 是 `space_isClosed`、`:34` 是 `inner_eq_zero_of_disjoint`（支撑不交则内积为零）、`:47` 是 `def basisVector`、`:67` 是 `space_eq_topologicalClosure_span`，这一条正是 tex 里"坐标子空间是基的某子集的闭张成"的形式化，而 `:67` 用拓扑闭包等式来钉死"闭张成"的含义。

## 10 权重、半径与运动预算

权重定义在 `05-hilbert.tex:137` 到 `05-hilbert.tex:141`：固定 $c=1/100$，令 $a_n(x)^2=\lVert u_n\rVert^2+\lVert u_{\lceil n/2\rceil}\rVert^2+\lvert v_{\lceil n/2\rceil}\rvert^2$。我核对了它跟路由的对应关系：块 $n$ 的输出含 $u_n^\perp$（用到 $\lVert u_n\rVert$）与系数 $C_n$，而 $C_{2m}=\alpha_m$ 用到 $u_m$、$C_{2m-1}=v_m$ 用到 $v_m$，两者都由 $\lceil n/2\rceil$ 给出，故 $a_n$ 恰好把输出块 $n$ 所消费的所有输入量收进来。作者的原话是"these weights follow the routing"，并给出两个直接推论：$\lvert C_n(x)\rvert\le a_n(x)$ 与 $\lVert u_n\rVert\le a_n(x)$，于是 $w_n(x)$ 前面的标量系数绝对值至多 $2a_n(x)$。这个 $2$ 在后面变成 $4c$ 的一半，链条是 $2R+R+R=4R$。

半径取尾：$r_n(x)^2=\sum_{j\ge n}a_j(x)^2$（`05-hilbert.tex:219` 到 `05-hilbert.tex:221`）。两条恒等式在 `eq:radii-identities`（`05-hilbert.tex:224` 到 `05-hilbert.tex:228`）：$r_1(x)^2=3\lVert u\rVert^2+2\lVert v\rVert^2$ 与 $a_n(x)^2=r_n(x)^2-r_{n+1}(x)^2$。前者我逐项数过：$\sum_ja_j^2=\sum_j\lVert u_j\rVert^2+\sum_j\lVert u_{\lceil j/2\rceil}\rVert^2+\sum_j\lvert v_{\lceil j/2\rceil}\rvert^2$，第二个和里每个 $m$ 被 $j=2m-1$ 与 $j=2m$ 各数一次故 $2\lVert u\rVert^2$，第三个和同理给 $2\lVert v\rVert^2$，加上第一项的 $\lVert u\rVert^2$ 得 $3\lVert u\rVert^2+2\lVert v\rVert^2$。作者说的"第二与第三个被数两次"与我数的一致。由此 $r_n$ 是有界线性映射进 Hilbert 空间的范数，故 $\sqrt3$-Lipschitz、在正值处光滑、在每个固定 $x$ 处随 $n$ 趋零（`05-hilbert.tex:229` 到 `05-hilbert.tex:231`）。$\sqrt3$ 就是 $\max(3,2)$ 的开方，若路由改成 $3$ 对 $3$ 则这个数会变。

预算目标是 $\sum_{n\ge1}a_n(x)^2\lVert Dw_n(x)\rVert^2\le c^2$（`eq:slot-budget`，`05-hilbert.tex:146` 到 `05-hilbert.tex:150`）。实现方式是选槽使 $\lVert Dw_n(x)\rVert\le\gamma(r_n(x))$（`05-hilbert.tex:310` 到 `05-hilbert.tex:312`），于是当 $r_n>0$ 时由单调性有 $(r_n^2-r_{n+1}^2)\gamma(r_n)^2\le\int_{r_{n+1}}^{r_n}2r\gamma(r)^2\,dr$，求和用 $\int_0^\infty2r\gamma^2=c^2$（`05-hilbert.tex:313` 到 `05-hilbert.tex:318`）。这是一个漂亮的望远镜：左端是"$a_n^2$ 乘一个只依赖 $r_n$ 的量"，右端是把 $r$ 从 $r_{n+1}$ 到 $r_n$ 的积分，因 $r_n\downarrow0$ 而区间互不相交地铺在 $(0,\infty)$ 上。$r_n=0$ 时 $a_n=0$，那一项自动为零（`05-hilbert.tex:317` 到 `05-hilbert.tex:318`），这是我必须登记的一个退化情形：如果只看 $(r_n^2-r_{n+1}^2)\gamma(r_n)^2$，$r_n=0$ 处 $\gamma$ 未定义（$c/(r\log(1/r))$ 在 $r\to0^+$ 发散），所以"$a_n=0$ 故该项为零"这一句是定义层的补丁。

$w_n$ 的定义是 $w_n(x)=P_n(x,r_n(x))$（`eq:moving-slot`，`05-hilbert.tex:303` 到 `05-hilbert.tex:306`）。作者对 $r_n$ 不可导处的处理我要抄准：在 $r_n$ 为零的点的邻域内 $r_n<a_n'$ 且 $w_n=W_{n,n}$，故 $w_n$ 仍连续可微（`05-hilbert.tex:307` 到 `05-hilbert.tex:309`）。这里 $W_{n,n}$ 是第 $n$ 阶段，$a_n'$ 是第 $n$ 个转段的左端点，$r_n<a_n'$ 意味着"已经转到底、停在最后一阶段"，最后一阶段是常值，所以半径的不可导性被隐藏。我最初担心的正是 $r_n$ 作为范数在零点不可导会传染给 $w_n$，作者用"停在常值阶段"这一手法把它化解，这与第 11 节的角度构造直接挂钩。

导数扰动的账在 `05-hilbert.tex:395` 到 `05-hilbert.tex:422`。固定点与单位方向，缩写 $w_n,\dot w_n$；对输入求导而把槽冻结得到满等距 $L_{w^{(N)}(x)}$；余项在输出块 $n$ 上是 $\dot w_n(C_n-\langle w_n,u_n\rangle)+w_n(\dot C_n-\langle\dot w_n,u_n\rangle)$，其中 $\dot C_{2m}=\langle\dot w_m,u_m\rangle$、$\dot C_{2m-1}=0$。设 $R^2=\sum_na_n(x)^2\lVert\dot w_n\rVert^2\le c^2$，则第一项因 $\lvert C_n-\langle w_n,u_n\rangle\rvert\le2a_n$ 而 Hilbert 范数至多 $2R$；$\lVert\dot C\rVert_{\ell_2}$ 与 $\lVert(\langle\dot w_n,u_n\rangle)\rVert_{\ell_2}$ 各至多 $R$（后者用 $a_n\ge\lVert u_n\rVert$），于是 $\lVert Dh_N(x)-L_{w^{(N)}(x)}\rVert\le4c$（`eq:derivative-perturbation`，`05-hilbert.tex:413` 到 `05-hilbert.tex:416`），Neumann 级数给出 $\lVert Dh_N(x)\rVert\le1+4c$ 与 $\lVert Dh_N(x)^{-1}\rVert\le(1-4c)^{-1}$（`eq:derivative-bounds`，`05-hilbert.tex:418` 到 `05-hilbert.tex:422`）。$4=2+1+1$ 的分配我很在意：那个 $2$ 全在"$C_n$ 减 $\langle w_n,u_n\rangle$"这一项上，而它之所以是 $2a_n$ 是因为 $C_n$ 与 $\alpha_n$ 各被 $a_n$ 控住。若路由改成让 $v$ 也走偶数槽，$a_n$ 的三项会变成四项，$2$ 会变大，$c$ 的安全余量随之缩小。

## 11 $\gamma$ 与慢角度：两次积分的分工

$\gamma$ 的定义在 `05-hilbert.tex:235` 到 `05-hilbert.tex:241`：当 $0<r<e^{-2}$ 时 $\gamma(r)=c/(r\log(1/r))$，当 $r\ge e^{-2}$ 时 $\gamma(r)=0$，并且 $c=1/100$ 在前面 `05-hilbert.tex:135` 就已固定。作者注明它随 $r$ 增大而不增。两条积分性质在 `eq:gamma-integrals`（`05-hilbert.tex:244` 到 `05-hilbert.tex:250`）：对一切 $b>0$ 有 $\int_0^b\gamma(r)\,dr=\infty$，而 $\int_0^\infty2r\gamma(r)^2\,dr=2c^2\int_2^\infty t^{-2}\,dt=c^2$。

我自己把第二条代了一遍以确认那个 $e^{-2}$ 的作用。令 $t=\log(1/r)$，则 $dt=-dr/r$；$r$ 从 $0$ 走到 $e^{-2}$ 时 $t$ 从 $\infty$ 走到 $2$。被积量 $2r\gamma(r)^2=2r\cdot c^2/(r^2\log^2(1/r))=2c^2/(r\,t^2)$，于是 $\int_0^{e^{-2}}2r\gamma^2\,dr=2c^2\int_2^\infty t^{-2}\,dt=2c^2\cdot[1/t]_{\infty}^{2}=2c^2\cdot(1/2)=c^2$。这里的下界 $2$ 正是 $\log(1/e^{-2})=2$，所以 $e^{-2}$ 这个截断点的选择把二阶积分正好压成 $c^2$，与预算目标同号。第一条我按同一代换检查：$\int\gamma\,dr=c\int dr/(r\log(1/r))=c\int dt/t$，$t\to\infty$ 时对数发散，故一阶积分在 $0$ 处发散。

我最初以为这两个条件是冗余的：只要 $\gamma$ 够大就能转，只要 $\gamma$ 够小就有界。写开之后才明白二者方向相反，能同时满足的裕度只有对数。取 $\gamma(r)=c/r$ 时一阶积分给 $\int dt$ 发散（同一条），但二阶给 $2c^2\int dt/t^0=2c^2\int_2^\infty dt$ 发散，预算炸掉；取 $\gamma(r)=c/(r\log^2(1/r))$ 时二阶给 $2c^2\int t^{-4}dt$ 收敛，一阶给 $c\int t^{-2}dt$ 收敛，于是每个转段能分配到的总角度有限，塞不下 $\pi/2$。$\gamma(r)=c/(r\log(1/r))$ 恰好落在两者之间：一阶 $\int dt/t$ 发散、二阶 $\int dt/t^2$ 收敛。这条对数裕度是我在本篇读到的最"设计感"的一处，也是 `SlowAngles.lean` 这个文件名我猜其所指的依据：角度转得慢，慢到 $1/\log$ 这一档。Lean 侧 `SlowAngles.lean:15` 的 `def warp (t : ℝ) := Real.exp (-Real.exp t)` 与 `:16` 的 `def inverseWarp (r : ℝ) := Real.log (-Real.log r)`，后者正是上面代换里的 $\log t=\log(\log(1/r))$，即把 $t$ 再取一次对数的坐标；`:20` 的 `warp_strictAnti`、`:27` 的 `inverseWarp_hasDerivAt`（前提是 `hr : r ∈ Ioo (0 : ℝ) 1`）、`:38` 与 `:44` 的两个次序互推引理，构成的是"把 $r$ 轴的积分问题搬到 $t$ 轴上做"的换元机器。这里我要按纪律标注：文件名与换元的一致是我基于 `Real.log (-Real.log r)` 这一具体式子与我手算的 $t=\log(1/r)$ 的对应做出的判断，属可核对的推断；至于它是否恰好服务于 $\gamma$ 的二阶积分，我没有逐行追证明。

转段区间的选取在 `05-hilbert.tex:254` 到 `05-hilbert.tex:259`：取一列彼此分离的紧区间 $[a_k',b_k']\subset(0,e^{-2})$ 用于第 $k-1$ 阶段到第 $k$ 阶段的过渡，满足 $b_{k+1}'<a_k'$、$b_k'<2^{-k}$、以及对 $0<r\le b_k'$ 有 $\gamma(r)/2\ge L_{k-1}+L_k$。第三个条件要求 $\gamma$ 在 $0$ 附近无上界（`05-hilbert.tex:242` 到 `05-hilbert.tex:243` 的不增性与 $r\to0$ 时 $c/(r\log(1/r))\to\infty$ 共同给出），所以每个固定的 $L_{k-1}+L_k$ 都能被压住，这与"不需要关于 $k$ 一致的界"（`05-hilbert.tex:212` 到 `05-hilbert.tex:213`）配合：$L_k$ 可以随便大，只要 $k$ 固定。角度 $\theta_k:[0,\infty)\to[0,\pi/2]$ 的非增性与三条限制在 `eq:angle-bounds`（`05-hilbert.tex:261` 到 `05-hilbert.tex:267`）：$\theta_k(r)=\pi/2$ 当 $r\le a_k'$，$\theta_k(r)=0$ 当 $r\ge b_k'$，$\lvert\theta_k'(r)\rvert\le\gamma(r)/(2\sqrt3)$，并在区间端点附近为常值。构造过程写在 `05-hilbert.tex:268` 到 `05-hilbert.tex:277`：先取足够小的 $b_k'$ 同时满足导数条件与前一个区间分离；由一阶积分发散，取足够小的 $a_k'>0$ 使 $\gamma/(2\sqrt3)$ 在 $(a_k',b_k')$ 上的积分大于 $\pi/2$；在该区间内取一个不超过 $\gamma/(2\sqrt3)$ 且积分大于 $\pi/2$ 的光滑非负函数（由下逼近存在）；缩放至积分恰为 $\pi/2$；从 $r$ 积分到 $+\infty$ 得 $\theta_k$。我核对最后一步的形状：这样得到的 $\theta_k$ 在 $r\ge b_k'$ 时为 $0$（积分区间为空），在 $r\le a_k'$ 时为总积分 $\pi/2$，非增，导数绝对值不超过 $\gamma/(2\sqrt3)$。三条同时满足，不需要额外技巧。

$P_n(x,r)$ 把同一套时序走完阶段 $0,\ldots,n$ 后停下（`05-hilbert.tex:279` 到 `05-hilbert.tex:288`）：在第 $k$ 个转段区间上（$k\le n$）取 $P_n(x,r)=\cos\theta_k(r)W_{n,k-1}(x)+\sin\theta_k(r)W_{n,k}(x)$，区间之间用中间那个单阶段，$r>b_1'$ 之上用 $W_{n,0}$，$r<a_n'$ 之下（含 $r=0$）用 $W_{n,n}$。阶段彼此正交使它是单位向量，端点取值方式使它连续可微。两个导数界在 `eq:P-derivatives`（`05-hilbert.tex:291` 到 `05-hilbert.tex:297`）：转段上 $\lVert\partial_xP_n(x,r)\rVert\le\gamma(r)/2$，$\lVert\partial_rP_n(x,r)\rVert\le\gamma(r)/(2\sqrt3)$。我逐条手验：对 $r$ 的导数是 $\theta_k'(r)(-\sin\theta_k W_{n,k-1}+\cos\theta_k W_{n,k})$，两支正交且系数平方和为 $1$，故范数恰为 $\lvert\theta_k'(r)\rvert\le\gamma/(2\sqrt3)$；对 $x$ 的导数是 $\cos\theta_k\,\partial_xW_{n,k-1}+\sin\theta_k\,\partial_xW_{n,k}$，两支正交故范数平方不超过 $L_{k-1}^2+L_k^2\le(L_{k-1}+L_k)^2\le\gamma^2/4$。区间之间前者由 $\gamma$ 单调性接上，后者为零；阶段零为常值故两处界在 $\gamma=0$ 的区域也成立。

然后是我最在意的一步合成。$w_n(x)=P_n(x,r_n(x))$（`eq:moving-slot`），在 $r_n>0$ 处链式法则给 $\lVert Dw_n(x)\rVert\le\gamma(r_n(x))$（`05-hilbert.tex:309` 到 `05-hilbert.tex:311`）。我验算这个 $1$ 是怎么凑出来的：$\gamma/2$（对 $x$ 的偏导）加上 $\gamma/(2\sqrt3)$（对 $r$ 的偏导）乘 $r_n$ 的 Lipschitz 常数 $\sqrt3$，得 $\gamma/2+\gamma/2=\gamma$。也就是说 $2\sqrt3$ 这个分母与 $r_n$ 的 $\sqrt3$ 是刻意配对的，两处数字都出自同一个设计。$r_n$ 的 $\sqrt3$ 又来自 $r_1^2=3\lVert u\rVert^2+2\lVert v\rVert^2$ 里的最大系数 $3$。三个数字串成一条：路由的重数决定 $\sqrt3$，$\sqrt3$ 决定 $2\sqrt3$，$2\sqrt3$ 与 $\gamma/2$ 相加得 $\gamma$，$\gamma$ 进预算望远镜。这条链是我在第 16 节要拿来做 tex 与 Lean 对照的样板。

阶段坐标的构造在 `05-hilbert.tex:164` 到 `05-hilbert.tex:213`。取 $\psi:\mathbb R\to\mathbb R$ 非负光滑、在 $(-1,1)$ 上为正、在 $[-1,1]$ 外为零；$\mathcal A_k=\{-k,-k+1,\ldots,k\}^k$；对 $a=(a_1,\ldots,a_k)$ 令 $G_{k,a}(t)=\prod_{j=1}^k\psi(kt_j-a_j)$，$t\in[-1,1]^k$。三个事实：$[-1,1]$ 的任一点到某个 $a_j/k$（$-k\le a_j\le k$）的距离不超过 $1/(2k)$，故 $G_k(t)$ 这一族从不全为零、其欧氏范数在立方体上有正下界；每个因子支撑长度为 $2/k$；$U_n$ 的基由一个 stage-zero 向量加对每个 $1\le k\le n$ 一套由 $\mathcal A_k$ 标号的坐标组成，不同阶段正交，于是 $\dim U_n=1+\sum_{k=1}^n(2k+1)^k$（`eq:block-dimensions`）。我核了一下基数：$\mathcal A_k$ 的元素个数是 $(2k+1)^k$，与维数公式的求和号一致。归一化阶段 $W_{n,k}(x)_a=G_{k,a}(p_1(x),\ldots,p_k(x))/\lVert G_k(p_1(x),\ldots,p_k(x))\rVert_2$（`eq:normalized-stage`），其中 $p_j$ 是把 $M$ 的标量坐标枚举后逐个套 $\tanh$ 得到的 $[-1,1]$ 值光滑 Lipschitz 分离函数（`05-hilbert.tex:193` 到 `05-hilbert.tex:195`）。由立方体紧、分母有正下界、$p_j$ 导数有界，得 $\sup_x\lVert DW_{n,k}(x)\rVert\le L_k<\infty$，同一个 $L_k$ 对所有 $n\ge k$ 有效，因它们的第 $k$ 阶段公式完全相同；$L_0=0$。

Lean 侧对应：`SeparatingCoordinates.lean:12` 写 `def psi (t : ℝ) := expNegInvGlue (1-t^2)`，`:16` 的 `psi_pos_iff` 陈述 `0 < psi t ↔ |t| < 1`，`:31` 的 `psi_ne_zero_iff` 给 `psi t ≠ 0 ↔ |t| < 1`，`:37` 的 `psi_contDiff` 对每个 `n : ℕ∞` 给 `ContDiff ℝ n psi`。这与 tex 对 $\psi$ 的三条要求（非负、$(-1,1)$ 上正、$[-1,1]$ 外零、光滑）逐条对上，而 Lean 用 $1-t^2$ 套标准平坦粘合函数来实现支撑区间 $(-1,1)$，这比"另造一个 bump"省事且光滑性免费。`:40` 到 `:42` 分别是 `abbrev Label (k : ℕ) := Fin k → {a : ℤ // a ∈ Set.Icc (-(k : ℤ)) k}`、`abbrev Stage (k : ℕ) := EuclideanSpace ℝ (Label k)`、`abbrev CubeSpace (k : ℕ) := EuclideanSpace ℝ (Fin k)`，即 $\mathcal A_k$ 被写成 `Fin k` 到带约束整数的那对类型，阶段空间是其上的欧氏空间，立方体空间是 $\mathbb R^k$。我注意到一个形状差异：tex 把 $\mathcal A_k$ 写成 $\{-k,\ldots,k\}^k$（$k$ 元组），Lean 写成 `Fin k →` 同一个有限族，二者基数都是 $(2k+1)^k$，差别只在指标集用 `Fin k` 显式化，而这正是形式化时把"$k$ 次笛卡尔积"变成"函数空间"的常规手法。

## 12 有限逼近的满射性与纤维论证

$h_N$ 的定义只把槽换掉：$w_n^{(N)}(x)=w_n(x)$（$n\le N$）否则 $W_{n,0}$（`05-hilbert.tex:372` 到 `05-hilbert.tex:376`），$A_0$ 表示全部槽取 $W_{n,0}$ 的那个等距。关键的第一步观察是"$h_N-A_0$ 只有输出块 $n\le2N$ 可能非零"（`05-hilbert.tex:377` 到 `05-hilbert.tex:380`）。我自己数过：动槽只到 $n\le N$，块 $n$ 的输出用到 $w_n$，而偶块 $2m$ 用的旧槽系数 $\alpha_m$ 来自 $w_m$，故 $m\le N$ 意味着 $2m\le2N$；奇块 $2m-1\le2N-1$。所以扰动被限制在 $\bigoplus_{n\le2N}U_n$ 里，这正是后面 $F_N$ 的定义域。$h_N$ 因此是 Hilbert 空间之间的连续可微映射，且满足 $\lVert h_N(x)\rVert=\lVert x\rVert$。

`lem:approximant-inverse`（`05-hilbert.tex:383` 到 `05-hilbert.tex:459`）的结论是每条 $h_N:M\to U$ 都是连续可微双射、逆也连续可微，且 $(1-4c)\lVert x-x'\rVert\le\lVert h_N(x)-h_N(x')\rVert\le(1+4c)\lVert x-x'\rVert$（`eq:hN-bounds`）。证明的次序我读得很慢，因为它刻意反着来。先给导数层面的界：$\lVert Dh_N(x)-L_{w^{(N)}(x)}\rVert\le4c$ 与 Neumann 推出的 $\lVert Dh_N(x)\rVert\le1+4c$、$\lVert Dh_N(x)^{-1}\rVert\le(1-4c)^{-1}$（`05-hilbert.tex:394` 到 `05-hilbert.tex:422`）。然后作者用一句 "We next establish global bijectivity before using the lower Lipschitz estimate"（`05-hilbert.tex:424` 到 `05-hilbert.tex:425`）表明：下界不能用来证双射，必须先有双射。为什么顺序是这样：下界要对线段积分，而在线段上积分需要映射已经定义在整条线段上并且逆已存在；用局部可逆去拼全局双射又要靠拓扑。

双射论证的骨架：取 $F_N=\bigoplus_{n\le2N}U_n$，$P$ 投到 $F_N^\perp$，则 $Ph_N=PA_0$（`05-hilbert.tex:427` 到 `05-hilbert.tex:429`）。固定 $b\in F_N^\perp$，$h_N$ 限制为仿射空间之间的映射 $A_0^{-1}(b)+A_0^{-1}(F_N)\to b+F_N$（`eq:fiber-map`）。两侧同有限维；导数在切空间之间是同构，理由是它把 $A_0^{-1}(F_N)$ 映进 $F_N$，反向对 $z\in F_N$ 取 $t=Dh_N(x)^{-1}z$，则 $PA_0t=PDh_N(x)t=0$，故 $t\in A_0^{-1}(F_N)$（这里用到 $Dh_N$ 与 $A_0$ 在 $P$ 侧相等的信息）。于是 `eq:fiber-map` 是局部微分同胚；它是 proper 的，因为紧集的原像闭且被 $\lVert h_N(x)\rVert=\lVert x\rVert$ 界住范数，而源纤维有限维，故紧（`05-hilbert.tex:440` 到 `05-hilbert.tex:442`）。最后引拓扑事实：同维仿射欧氏空间之间的 proper 局部微分同胚是双射。作者的复述分四步：像由局部可逆开、由 proper 闭，故为全空间；每个纤维紧且离散故有限；局部逆邻域加 proper 排除了附近的额外原像，于是它是覆盖映射；单连通欧氏空间上、源连通的覆盖只有一页（`05-hilbert.tex:444` 到 `05-hilbert.tex:452`）。

我在这一块犯过的错是把"proper 局部微分同胚"直接当结论用，跳过覆盖那一页。作者的复述提醒我：proper 给紧纤维，紧加离散给有限，有限纤维的覆盖要单连通才只有一页。少了单连通这一步，我完全可以在环面之类的地方造反例。这一处也是我判断"作者先前版本可能在这里翻过车"的依据：一篇以线性构造为主的论文特意复述四句拓扑，通常是补给自己读者的，也是补给自己的。

我把这一节的骨架与 Lean 侧的切分对齐一下。`RotatingStages.lean`（231 行）里 `:18` 是 `def path (W : ℕ → X → E) (α : ℕ → X → ℝ) : ℕ → X → E`，即把 $P_n$ 写成"阶段序列 $W$ 与角度序列 $\alpha$"的两参数构造；`:26` 是 `path_contDiff`、`:34` 是 `inner_path_stage`（阶段正交性在这里被显式化为一条内积引理）、`:46` 是 `norm_path`（单位长）、`:63` 与 `:72` 是 `path_small_eventually` 与 `path_large_eventually`，按半径大小分别落在"停在最后阶段"与"停在阶段零"这两种常值情形，正对应 tex 里 $r>b_1'$ 用 $W_{n,0}$、$r<a_n'$ 用 $W_{n,n}$；`:91` 是 `norm_angular`，前提是 `hu : ‖u‖ = 1` 与 `hv : ‖v‖ = 1`；`:100` 是 `rotation_deriv_bound`，即 `eq:P-derivatives` 那一类导数界。`MovingSlots.lean:48` 的 `def approxSlots (N : ℕ) (n : ℕ) (x : SlotDomain E) : E n := if n < N then w n x else ξ n` 对应 $w^{(N)}$，其中回退值 `ξ n` 就是 $W_{n,0}$。这里有一处必须登记的约定差异：tex 写的是 $n\le N$（`05-hilbert.tex:375`），Lean 写的是 `n < N`，两者对"动槽个数"的偏移是一，因此 $h_N$ 的下标在 tex 与 Lean 之间可能有整体平移，我核对不了结论层面的影响，因为我没有把 `FiniteApproximants.lean` 逐行读完。

## 13 逆像尾部不等式与对角子列收敛

先记录 $h_N$ 到 $h$ 的逐点收敛。固定 $x=(u,v)$，$h_N(x)$ 与 $h(x)$ 的前 $N$ 个输出块相同：这些块自身的槽一致，而偶块 $2m\le N$ 用的旧槽满足 $m\le N$（`05-hilbert.tex:464` 到 `05-hilbert.tex:466`）。对任一列表 $\zeta=w(x)$ 或 $\zeta=w^{(N)}(x)$ 记 $C_{2m}^{\zeta}=\langle\zeta_m,u_m\rangle$、$C_{2m-1}^{\zeta}=v_m$，则 $(L_\zeta x)_n-u_n=\zeta_n(C_n^\zeta-\langle\zeta_n,u_n\rangle)$。由 $\lvert C_n^\zeta\rvert\le a_n(x)$ 与 $\lVert u_n\rVert\le a_n(x)$，每一块与 $u_n$ 的差范数至多 $2a_n(x)$；在其余块上两个映射之差的范数至多 $4a_n(x)$。于是 $\lVert h_N(x)-h(x)\rVert\le4r_{N+1}(x)\to0$（`eq:h-pointwise-limit`，`05-hilbert.tex:479` 到 `05-hilbert.tex:483`）。我对这个 $4$ 与前面导数扰动里的 $4c$ 做了区分：前者是 $4(\sum_{n>N}a_n^2)^{1/2}=4r_{N+1}$，来自"每块差至多 $4a_n$"的平方和；后者是 $2R+R+R$ 的导数账。两个 $4$ 同形不同源，这正是我在台账里必须把位置写到行的原因。固定 $x,x'$ 令 $N\to\infty$，由 `eq:hN-bounds` 得 `\eqref{eq:h-bounds}`，因为 $1-4c=24/25$、$1+4c=26/25$（`05-hilbert.tex:485` 到 `05-hilbert.tex:487`）。

满射性用冻结技巧。固定 $y=(y_n)\in U$，令 $x_N=h_N^{-1}(y)$，并把这个特定输入处的槽冻起来：$\xi_n^{(N)}=w_n^{(N)}(x_N)$、$\beta_n^{(N)}=\langle\xi_n^{(N)},y_n\rangle$。方向可以随 $N$ 变，但对每个 $N$ 都有精确等式 $y=L_{\xi^{(N)}}x_N$，于是 `lem:frozen-inverse` 给出 $(x_N)_{U_m}=y_m-\beta_m^{(N)}\xi_m^{(N)}+\beta_{2m}^{(N)}\xi_m^{(N)}$、$(x_N)_{V_m}=\beta_{2m-1}^{(N)}$（`eq:xN-inverse`，`05-hilbert.tex:500` 到 `05-hilbert.tex:509`）。$y_m-\beta_m^{(N)}\xi_m^{(N)}$ 与 $\xi_m^{(N)}$ 正交，故其平方范数是 $\lVert y_m\rVert^2-\lvert\beta_m^{(N)}\rvert^2$，末项正交相加。由此对每个 $s\ge1$（`eq:inverse-tail`，`05-hilbert.tex:515` 到 `05-hilbert.tex:527`）：

$$
\sum_{m\ge s}\bigl(\lVert(x_N)_{U_m}\rVert^2+\lvert(x_N)_{V_m}\rvert^2\bigr)=\sum_{m\ge s}\bigl(\lVert y_m\rVert^2-\lvert\beta_m^{(N)}\rvert^2+\lvert\beta_{2m}^{(N)}\rvert^2+\lvert\beta_{2m-1}^{(N)}\rvert^2\bigr)=\sum_{n\ge s}\lVert y_n\rVert^2-\sum_{n=s}^{2s-2}\lvert\beta_n^{(N)}\rvert^2\le\sum_{n\ge s}\lVert y_n\rVert^2
$$

中间那个等号我逐项对过：$m\ge s$ 时偶奇指标 $2m$ 与 $2m-1$ 恰好铺满 $n\ge2s-1$，其和 $\sum_{n\ge2s-1}\lvert\beta_n^{(N)}\rvert^2$ 与 $\sum_{m\ge s}\lvert\beta_m^{(N)}\rvert^2=\sum_{n\ge s}\lvert\beta_n^{(N)}\rvert^2$ 相消，剩下未消的负项正是 $s\le n\le2s-2$；$s=1$ 时该和为空。作者用一句话钉住这一点："Keeping it is what avoids double counting the output's perpendicular and slot components"（`05-hilbert.tex:533` 到 `05-hilbert.tex:535`）。右端随 $s$ 趋零且与 $N$ 无关；$s=1$ 时等式给 $\lVert x_N\rVert=\lVert y\rVert$。

有了与 $N$ 无关的尾部一致控制，对角论证就是标准动作：对每个 $s$，头 $\bigl((x_N)_{U_m},(x_N)_{V_m}\bigr)_{m<s}$ 落在有限维空间 $\bigoplus_{m<s}(U_m\oplus\mathbb R)$ 的有界子集里，逐次取子列再对角，得递增 $N_j$ 使每个固定的头收敛（`05-hilbert.tex:539` 到 `05-hilbert.tex:548`）。给定 $\epsilon>0$ 选 $s$ 使 $\sum_{n\ge s}\lVert y_n\rVert^2<(\epsilon/4)^2$，则每个 $x_{N_j}$ 的尾部范数小于 $\epsilon/4$；$j,k$ 足够大时头部之差小于 $\epsilon/2$；三角不等式给 $\lVert x_{N_j}-x_{N_k}\rVert<\epsilon$。完备性给 $x_{N_j}\to x$（`05-hilbert.tex:549` 到 `05-hilbert.tex:558`）。最后一步只用逐点收敛与共同的上界 Lipschitz：$\lVert h(x)-y\rVert\le\lVert h(x)-h_{N_j}(x)\rVert+\lVert h_{N_j}(x)-h_{N_j}(x_{N_j})\rVert\le4r_{N_j+1}(x)+(1+4c)\lVert x-x_{N_j}\rVert\to0$（`05-hilbert.tex:560` 到 `05-hilbert.tex:567`）。

这个收尾我要特别记一笔：它把"点态收敛"与"一致 Lipschitz 上界"配成一对，是 Arzelà 型的标准组合，而我最初在这里绕了远路，想用 $h_N$ 的逆的一致界 $(1-4c)^{-1}$ 去证 $x_N$ 的 Cauchy 性。那个思路会卡在无穷维单位球的非紧性上：$\lVert x_N-x_{N'}\rVert\le(1-4c)^{-1}\lVert y-y\rVert=0$ 只给出 $x_N=x_{N'}$ 若 $h_N^{-1}(y)$ 有极限可言，而 $x_N$ 与 $x_{N'}$ 是两个不同映射的逆像，二者之差无法用 $y$ 之差控制。作者用的控制量是尾部不等式与有限维头部，这两个东西恰好是 $(1-4c)^{-1}$ 给不了的。

局部正交的结论在最后（`05-hilbert.tex:570` 到 `05-hilbert.tex:577`）：取 `lem:slot-locality` 给的 $O_j$ 与 $l$，令 $H_j$ 为 $w_n(x)$（$x\in O_j$、$n\ge l$）的坐标支撑并集的闭张成，则各 $H_j$ 两两正交且落在 $U_{\ge l}$；每块 $D(x)_n$ 是 $w_n(x)$ 的标量倍，故其收敛尾部属于 $H_j$，理由是 $H_j$ 闭。这句"because $H_j$ is closed"是我读时容易滑过的一处：逐块属于支撑张成的线性组合，极限要靠闭性才留在里面，这正是 `eq:local-orthogonality` 需要的 $\Pi_{\ge l}D(O_j)\subset H_j$。`lem:slot-locality`（`05-hilbert.tex:326` 到 `05-hilbert.tex:359`）的证明里我核对了两处数字：同标签在阶段 $k$ 出现会迫使 $\lvert p_j(x)-p_j(y)\rvert<2/k$，与预先分离的 $2/k_0\ge2/k$ 矛盾；半径方面由 $r_n\le r_l$（$n\ge l$）与 $r_l$ 的 $\sqrt3$ Lipschitz，取邻域半径小于 $\rho/(2\sqrt3)$ 且中心处 $r_l<\rho/2$，得 $r_n(x)<\rho$。

Lean 侧对应收在 `InverseTails.lean`（263 行）：`:15` 是 `def cutHead (s : ℕ)`，`:18` 是 `prefix_tendsto`（头部趋恒等），`:21` 是 `norm_sub_prefix_sq`，`:26` 是 `cauchy_of_small_tails`，`:49` 是 `subsequence_of_tail_domination` 且其前提是 `[∀ i, ProperSpace (E i)]`，`:81` 是 `inverse_tail_norm_sq`，`:92` 与 `:100` 分别是 `inverse_fst_tail` 与 `inverse_snd_tail`。两处对照值得登记。第一处：tex 把 $U$ 部与 $V$ 部的尾部写成一条不等式，Lean 拆成 `fst` 与 `snd` 两条定理，因为 `HilbertSum E` 的分量类型是 $E\ i$ 与 $\mathbb R$ 的和型，拆开才能各自用 `lp` 的范数引理。第二处：tex 里"有界集的有限维紧性"那句自然语言，在 Lean 里被换成类型类假设 `ProperSpace (E i)`，也就是把有限维 Heine--Borel 提出来作为可复用前提；这条差异说明形式化时"有限维"这个信息被拆成了"proper"这一性质，而 tex 的论证只用到 proper 而不需要维数本身，这一点从 `subsequence_of_tail_domination` 的前提表上可以读出来。

## 14 三角变量替换与常数链

判据 `prop:criterion`（`03-triangular.tex:19` 到 `03-triangular.tex:46`）的假设侧我逐项列一遍，因为它们每一项在最后组装时都有对应输入：$U$ 可分实 Hilbert，$V=\ell_2$，$M=U\oplus_2V$，投影 $\pi_U,\pi_V$；$h:M\to U$ 双射、$h(0)=0$、$a\lVert x-x'\rVert\le\lVert h(x)-h(x')\rVert\le b\lVert x-x'\rVert$ 且 $0<a\le b<\infty$；$E=\mathcal F(M)$；$q:E\to U$ 是 $D=h-\pi_U$ 的线性化且完全连续；$E\oplus V$ 给求和范数；$Q_1:E\oplus_1V\to M$，$Q_1(e,v)=(qe,v)$；$X=Z_{Q_1}$，$Y=Z_q$；$L_q=\lVert q\rVert$，$K_q=\max\{L_q,1\}$。结论侧：$X,Y$ 是可分实 Banach，存在双射 $\Psi:X\to Y$ 使 $\operatorname{Lip}(\Psi)\le\max\{1+K_q,b\}$、$\operatorname{Lip}(\Psi^{-1})\le\max\{1+2L_q/a,1/a\}$，$X$ 等距含 $c_0(V)$，$Y$ 不含同构于 $c_0(V)$ 的闭子空间。

$Q_1$ 的界在 `eq:q1-bound`（`03-triangular.tex:51` 到 `03-triangular.tex:56`）：$\lVert Q_1(e,v)\rVert_M=(\lVert qe\rVert^2+\lVert v\rVert^2)^{1/2}\le K_q(\lVert e\rVert+\lVert v\rVert)$。$K_q$ 里那个 $\max$ 与 $1$ 就是为了处理 $\lVert q\rVert<1$ 的情形：$\sqrt{\lVert qe\rVert^2+\lVert v\rVert^2}\le\sqrt{L_q^2\lVert e\rVert^2+\lVert v\rVert^2}\le\max\{L_q,1\}(\lVert e\rVert+\lVert v\rVert)$。我自己验过：若直接用 $L_q$ 而不用 $\max$，当 $L_q<1$ 时第二项 $\lVert v\rVert$ 前面的系数会变成 $L_q<1$，不等式反方向错，所以 $1$ 是必须的。

$B$ 与它的逆是这一节的心脏。$B:E\oplus_1V\to E$，$B(e,v)=e+\delta(qe,v)$（`eq:B-definition`，`03-triangular.tex:60` 到 `03-triangular.tex:63`）。定义式 $q\delta(u,v)=h(u,v)-u$ 代入得 $qB(e,v)=qe+h(qe,v)-qe=h(Q_1(e,v))$（`eq:diagram`，`03-triangular.tex:64` 到 `03-triangular.tex:68`）。我读到这里的第一反应是"$qe$ 相消太刻意"，随后才明白这就是"三角"的含义：$B$ 的第一项 $e$ 被 $q$ 打回 $qe$，而 $q\delta(qe,v)$ 补上 $h(qe,v)-qe$，两者相加恰好凑成 $h\circ Q_1$。逆的构造（`03-triangular.tex:69` 到 `03-triangular.tex:74`）给 $C(z)=(z-\delta(x),\pi_Vx)$，其中 $x=h^{-1}(qz)$。验证 $Q_1C(z)=x$ 用的是一行：$q(z-\delta(x))=qz-(h(x)-\pi_Ux)=\pi_Ux$，因为 $x=h^{-1}(qz)$ 意味着 $h(x)=qz$。而 $\pi_Ux$ 与 $x$ 的第一个分量一致，故 $Q_1C(z)=(\pi_Ux,\pi_Vx)=x$。代回 `eq:B-definition` 得 $B(C(z))=z$。反向：若 $z=B(e,v)$，则由 `eq:diagram` 与 $h$ 单射得 $h^{-1}(qz)=Q_1(e,v)=(qe,v)$，于是 `eq:B-inverse` 送回 $(e,v)$。总结成 $Q_1B^{-1}=h^{-1}q$（`eq:inverse-diagram`，`03-triangular.tex:85` 到 `03-triangular.tex:88`）。这一段只用 $h$ 的逆，不需要 $q$ 满射（`03-triangular.tex:89` 到 `03-triangular.tex:90`）。

范数账的两条我逐个因子追过。正向：$\lVert B(w)-B(w')\rVert\le\lVert e-e'\rVert+\lVert Q_1(w-w')\rVert\le(1+K_q)\lVert w-w'\rVert_{E\oplus_1V}$（`03-triangular.tex:95` 到 `03-triangular.tex:99`），其中第二步用 $\delta$ 的等距把 $\lVert\delta(qe,v)-\delta(qe',v')\rVert$ 换成 $M$ 里两点距离。反向：置 $x=h^{-1}(qz)$、$x'=h^{-1}(qz')$，$h$ 的下界给 $\lVert x-x'\rVert_M\le(L_q/a)\lVert z-z'\rVert$，然后

$$
\lVert B^{-1}(z)-B^{-1}(z')\rVert_{E\oplus_1V}\le\lVert z-z'\rVert+\lVert\delta(x)-\delta(x')\rVert+\lVert\pi_V(x-x')\rVert\le\lVert z-z'\rVert+2\lVert x-x'\rVert_M\le(1+2L_q/a)\lVert z-z'\rVert
$$

（`03-triangular.tex:107` 到 `03-triangular.tex:112`）。这里的 $2$ 是两笔独立开销：$\delta$ 等距的一笔（系数 $1$）与 $\pi_V$ 范数不超过 $1$ 的一笔（系数 $1$）。作者在这一行专门注明用的是求和范数，$E\oplus V$ 上的 Hilbert 求和范数没有被采用（`03-triangular.tex:105` 到 `03-triangular.tex:106`）。我按这两条分别重算：若 $E\oplus V$ 取 $\ell_2$ 和范数，则 $\lVert B^{-1}(z)-B^{-1}(z')\rVert=(\lVert z-z'-\delta(x-x')\rVert^2+\lVert\pi_V(x-x')\rVert^2)^{1/2}$，前一项只能用三角不等式给 $\lVert z-z'\rVert+\lVert x-x'\rVert_M$，再与第二项做平方和，最坏情况系数会变成 $\sqrt2$ 量级再加一次放大，总之 $2$ 换不成 $1$，而求和范数让三项直接线性相加，$2$ 是最干净的。这是"用求和范数"这一选择的实际代价与收益。

$\Psi$ 的逐坐标定义与成员性检查在 `03-triangular.tex:118` 到 `03-triangular.tex:131`。要点是 $B(0)=0$ 使 $\sum_i2^{-i}\lVert B(s_i)\rVert$ 有限（因为 $s\in X$ 已有加权和有限，$\lVert B(s_i)\rVert\le(1+K_q)\lVert s_i\rVert$），而 $Q_1s_i\to0$ 加 `eq:diagram` 与 $h$ 在 $0$ 连续给 $qB(s_i)=h(Q_1s_i)\to0$，于是 $\Psi(s)\in Y$。反向同理用 $B^{-1}(0)=0$ 与 `eq:inverse-diagram`：若 $qz_i\to0$，则 $Q_1B^{-1}(z_i)=h^{-1}(qz_i)\to0$。作者补了一句这两条是全局两点估计而不只是在原点（`03-triangular.tex:149` 到 `03-triangular.tex:150`），因为图空间范数是全局差量的 $\max$，只在原点的估计给不出双 Lipschitz。

组装节 `06-assembly.tex` 只做四件事。第一件把 `thm:hilbert-map` 的产出接入：$E=\mathcal F(M)$、$D=h-\pi_U$、$q=\widehat D$，并且指出 $D$  Lipschitz、$D(0)=0$ 且具有有限族尾部坐标正交性，于是 `thm:localized-linearization` 使 $q$ 完全连续（`06-assembly.tex:13` 到 `06-assembly.tex:19`）。第二件算 $\lVert q\rVert$：$\lVert q\rVert=\operatorname{Lip}(D)\le\operatorname{Lip}(h)+\lVert\pi_U\rVert\le26/25+1=51/25$（`06-assembly.tex:21` 到 `06-assembly.tex:24`）。我核对这里用的是 $h$ 的上界 $26/25$ 与 $\pi_U$ 的范数 $1$，而 $\pi_U:M\to U$ 作为 Hilbert 和的投影范数确为 $1$。第三件调用判据，参数 $a=24/25$、$b=26/25$（`06-assembly.tex:30` 到 `06-assembly.tex:31`），得 $\Psi$、$X$ 里的 $c_0(\ell_2)$ 拷贝、$Y$ 里的排除。第四件算最终两个常数：因 $L_q\le51/25$ 且 $K_q=\max\{L_q,1\}\le51/25$，

$$
\operatorname{Lip}(\Psi)\le\max\{1+51/25,\;26/25\}=76/25,\qquad
\operatorname{Lip}(\Psi^{-1})\le\max\{1+2(51/25)/(24/25),\;25/24\}=21/4
$$

（`06-assembly.tex:36` 到 `06-assembly.tex:47`）。我自己算了一遍：$1+51/25=76/25\approx3.04$ 大于 $26/25=1.04$，故取前者；$2(51/25)/(24/25)=102/24=17/4=4.25$，加 $1$ 得 $21/4=5.25$，大于 $25/24\approx1.042$，故取前者；下界 $4/21$ 是 $21/4$ 的倒数（`06-assembly.tex:48` 到 `06-assembly.tex:51`）。于是主定理的双边常数 $4/21$ 与 $76/25$ 全部来自 $c=1/100$ 与两处 $\max$ 的取舍。我特意算了 $c$ 的容许范围：$4c<1$ 即可，即 $c<1/4$；$c$ 越大则 $a=1-4c$ 越小，$2L_q/a$ 越大，$21/4$ 会变差；$c$ 越小则 $a,b$ 都趋 $1$、$\lVert q\rVert$ 趋 $2$（因 $\operatorname{Lip}(h)\to1$ 给 $\lVert q\rVert\le2$），$\operatorname{Lip}(\Psi^{-1})$ 趋 $1+2\cdot2/1=5$。也就是说 $c\to0$ 时双边常数趋 $1$ 与 $5$，而 $c=1/100$ 给的 $21/4=5.25$ 反而比极限值差，这个观察让我确认 $1/100$ 是工程取法、与最优性无关。作者没有讨论这一点，这是我的补充推算，风险极低但结论属我个人。

判据的阻碍收尾那一小段值得单独记（`03-triangular.tex:152` 到 `03-triangular.tex:168`）：$\iota:c_0(V)\to X$，$\iota((v_i))=((0,v_i))_i$，$\lVert\iota((v_i))\rVert_X=\max\{\sum_i2^{-i}\lVert v_i\rVert,\sup_i\lVert v_i\rVert\}=\sup_i\lVert v_i\rVert$，理由 $\sum_{i\ge1}2^{-i}=1$；然后 $M$ 超自反使 `thm:free-wsc` 给出 $E$ 弱序列完全，配合假设里 $q$ 完全连续，`lem:graph-obstruction` 排除 $Y$ 中的 $c_0(V)$ 拷贝；最后"线性同构会把那个闭拷贝搬过去"结束。

## 16 tex 与 Lean 的符号对照与偏差

这一节是逐符号的，我按"tex 里的式子在哪里、Lean 里的对应物在哪里、两者形状差在哪"三栏的口吻写，具体数字集中放在第 18 节台账里。

$c=1/100$ 两侧完全同形：`05-hilbert.tex:135` 与 `05-hilbert.tex:233` 两处固定 $c=1/100$，Lean 在 `RadialBudget.lean:11` 写 `def c : ℝ := 1/100`，配套 `:18` 的 `theorem c_pos : 0 < c := by norm_num [c]`。$e^{-2}$ 的截断点在 tex 里只出现在 $\gamma$ 的分段条件（`05-hilbert.tex:238` 与 `05-hilbert.tex:239`），Lean 把它提名为常量：`RadialBudget.lean:12` 的 `def cutoff : ℝ := Real.exp (-2)`，并配 `:19` 的 `cutoff_pos`（证明体是 `Real.exp_pos _`）与 `:20` 的 `cutoff_lt_one`。最关键的是 `RadialBudget.lean:24` 的 `log_bound {r : ℝ} (hr : r ∈ Ioo 0 cutoff) : Real.log r < -2`：tex 里那个 $\int_2^\infty t^{-2}\,dt$ 的下限 $2$ 正是这条不等式的产物（$r<e^{-2}$ 等价于 $\log(1/r)>2$），tex 没单独写它，因为它显然。

$\gamma$ 本体：tex 的分段定义在 `05-hilbert.tex:236` 到 `05-hilbert.tex:241`，Lean 在 `RadialBudget.lean:14` 用 `if 0 < r ∧ r < cutoff then c / (r * Real.log (1/r)) else 0`。差别在定义域：tex 只声明 $r>0$ 上的 $\gamma$，Lean 必须给 $r\le0$ 一个值，被并入 else 分支。这个处理让 tex 里"$\gamma$ 在非正处不出现"变成 Lean 里"处处有值"，代价是所有 $r>0$ 的条件都要显式写进假设。

$\int_0^\infty2r\gamma(r)^2\,dr=c^2$ 在 tex 是一行等式（`05-hilbert.tex:248` 到 `05-hilbert.tex:250`），Lean 侧我实测到一个 tex 没有的名字：`RadialBudget.lean:16` 的 `def potential (r : ℝ) : ℝ := if 0 < r then if r < cutoff then -2*c^2 / Real.log r else c^2 else 0`。我自己做了微积分核对：对 $2r\gamma(r)^2=2c^2/(r\log^2 r)$ 求原函数，$\frac{d}{dr}(-2c^2/\log r)=-2c^2\cdot(-1/\log^2 r)\cdot(1/r)=2c^2/(r\log^2 r)$，两者一致；在 $r=e^{-2}$ 处 $-2c^2/(-2)=c^2$，与 `else c^2` 分支的取值连续；$r\to0^+$ 时 $-2c^2/\log r\to0$。因此 `potential` 就是 $\int_0^r2t\gamma(t)^2\,dt$ 的显式原函数。这是我的推导，我把它当作"tex 用反常积分、Lean 用显式原函数"这一层偏差的证据，同时它说明 Lean 侧回避了反常积分的语言。

$\phi_{z,s}$ 在 tex 是 `04-localization.tex:60` 到 `04-localization.tex:65` 那个 $\max\{0,\min\{1,2-2\rho(x,z)/s\}\}$，在 Lean 里叫 `cutoff`：`Localization.lean:60` 是 `def cutoff (z : M) (s : ℝ≥0) (x : M) : ℝ`，`:64` 是 `cutoff_nonneg`，`CompactLocalization.lean:20` 是 `cutoff_nonzero_mem`、`:27` 是 `disjoint_cutoffs`、`:34` 是 `sum_cutoff_bounds`（对应 tex 的 $0\le\Phi_r\le1$）。这里有一个必须登记的重名陷阱：`RadialBudget.lean:12` 的 `cutoff` 是实数 $e^{-2}$，`Localization.lean:60` 的 `cutoff` 是三参数函数，两者不同 namespace，按名字全局搜索会撞车。$\mathbb R_{\ge0}$ 的用法也值得记一笔：Lean 把 tex 里的半径 $s>0$、$r>0$ 写成 `r : ℝ≥0` 加 `hr : 0 < r`（见 `CompactLocalization.lean:20`、`:27`、`:34`），这样"$r$ 非负"由类型给出，"$r$ 为正"由假设给出，tex 里一句 $0<r<r_0$ 在 Lean 里被拆成类型与证明两件事。

被摘掉与余项的分解：tex 的 $f_{i,z,r}$、$g_{i,r}$、$R_{i,r}$ 在 `CompactLocalization.lean:53` 是 `def removed (d : M → ℝ) (z : I → M) (r : ℝ≥0) (x : M) : ℝ`、`:56` 是 `def remainder (d : M → ℝ) (z : I → M) (r : ℝ≥0) : M → ℝ`，随后 `:59` 的 `removed_lipschitz`、`:75` 的 `remainder_lipschitz`、`:84` 的 `remainder_inner`。参数形态上 Lean 比 tex 更一般：tex 的求和是对有限点集 $Z$，Lean 写成 `z : I → M` 带一个索引类型 $I$，因此 $\operatorname{Lip}$ 界里的 $6L$ 与 $7L$ 在 Lean 侧要随 $I$ 的基数与不交性假设走，这正是 tex 里那句"这些常数与 $r$ 和 $\lvert Z\rvert$ 都无关"（`04-localization.tex:257` 到 `04-localization.tex:258`）在形式化时的落点。$I$ 的参数化还解释了 `removed` 与 `remainder` 的 $d$ 为什么是 `M → ℝ`：tex 的 $d_i$ 是一列函数，Lean 一次处理一个，$i$ 被吸收进调用处。

## 1. 起点：我以为这是个"把 Pincus 传递再磨一遍"的题

(a) 原文。`main.tex:49-54` 摘要：

```
We prove that the Partition Principle does not imply the Axiom of Choice:
if ZF is consistent, then so is ZF with the Partition Principle, Choice for
ordinal-indexed families, and the negation of the Axiom of Choice.
Separately, over every countable transitive model of ZFC, we construct a
transitive symmetric model of this theory with the same ordinals and no new
countable sequences of ground elements.
```

`introduction.tex:5-10` 给出原理本体：

```
 \PP:\qquad
 \forall X\,\forall Y\,
 \bigl[(\exists f:X\twoheadrightarrow Y)
       \Longrightarrow(\exists j:Y\hookrightarrow X)\bigr].
```

(b) 补步。我最初的读法是把这题拆成三个已知零件：$\mathsf{PP}$ 已经给出所有基数比较；
$\mathsf{AC}_{\mathrm{WO}}$（`introduction.tex:18-20`）由 Pincus 的经典论证从 $\mathsf{PP}$ 得到（`introduction.tex:73-77`）；
剩下的应该只是把"每个商能注入回 $A$"这一件事在对称模型里造出来。按这个读法，
构造对象是"$A$ 的每个非良序商"，方法是把 Cohen 实数塔的 almost-disjoint 技术（`introduction.tex:108-123`
承认的 Holy--Schilhan 前例）搬到 $\omega_1$ 上，再用 Pincus 式的参数传递把局部结论铺到全域。

(c) 机械理由。这个拆法在纸面上是自洽的：$\mathsf{PP}$ 的量化对象是全体集合，
而一个对称模型里可验证的陈述只覆盖有 HS 名字的集合；`introduction.tex:82-92` 引的
$\mathrm{SVC}(A)$ 恰好是"把全域量词压到一个固定参数 $A$"的标准装置，
$\eta$ 是序数指标，$A\times\eta$ 的像覆盖任意秩的集合，于是看起来只需要在 $A$ 上做文章。
`introduction.tex:125-134` 的策略段也确实在这个形状上：造 $A$、用轨道映射得到满像表示、
用一个良序片穿过每个族。

(d) [推测] 失败路线。我第一版打算直接引 Ryan-Smith 的局部到整体定理
（`introduction.tex:94-96`：在 $\mathrm{SVC}^{+}(A)$ 下全 $\mathsf{PP}$ 等价于 $\mathsf{AC}_{\mathrm{WO}}$ 加 $A$ 的子集之间的逆注入）。
这条路在开工第一天就断了：要在 $A$ 的子集之间造逆注入，就得为 $A$ 的每个商同时选一份代表，
而"同时选"正是对称性要否定的东西；把它写进模型，得到的候选双射的支撑是整个 $I$，不在滤子 $\mathcal F$ 里。

(d2) [推测] 失败路线。第二版想把 Pincus 传递做成外部论证：先在 $V[G]$ 里
（全选择成立）为每个商固定双射，再用"可定义即对称"的口号把名字拉回 $W$。
断点在 `quotients.tex:625-627` 明写的那句：check 名字在置换作用下不动，
所以"$\pi$ 把 ground 码的 check 名字送到搬运后码的 check 名字"是假命题，
整个"可定义即对称"的口号在乘积情形不成立。

## 2. 第一条死路：把 $\mathsf{PP}$  supplied 的逆注入当截面用

(a) 原文。`introduction.tex:13-16`：

```
The converse is less direct: the injection supplied by $\PP$ need
not take a part to one of its members. In particular, it need not satisfy
$f\circ j=\id_Y$. The problem is whether this cardinal comparison alone
can recover choice for arbitrary families.
```

`conclusion.tex:148-152` 在证明完成后把同一件事回收了一遍：

```
The injection obtained in Lemma~\ref{lemma:pp-reduction} need not
respect the fibers of the original surjection.  In its wellorderable
target case the local injection is a section, but in its
nonwellorderable case the two bijections with $A$ give no such
requirement.  This is precisely the freedom allowed by $\PP$.
```

(b) 补步。这两段合起来读，就是我最初设想的精确障碍：如果 $\mathsf{PP}$ 给的 $j$ 满足
$f\circ j=\operatorname{id}_Y$，那么 $j$ 就是截面，截面在 $\mathsf{AC}_{\mathrm{WO}}$ 之下立刻把每个族的选择问题化归为
像的选择问题，于是 $\mathsf{PP}$ 与 $\mathsf{AC}$ 的差距会塌掉。反过来的意思是：任何试图
"从逆注入恢复选择"的证明都必须利用 $f\circ j\ne\operatorname{id}_Y$ 这一自由度，
或者承认自己不能利用它。我早期写的两页草稿里，每一步都隐含地用了
$j(y)\in f^{-1}(\{y\})$，那是把截面当成免费午餐。

(c) 机械理由。为什么这个自由度在这个构造里非有不可：`conclusion.tex:93-101`
的非良序片，得到的 $j_i:Y_i\to S_i$ 是"$S_i$ 与 $A$ 的双射"复合"$A$ 与 $Y_i$ 的双射之逆"，
$S_i$ 与 $Y_i$ 之间原来的对应 $f\!\upharpoonright\!S_i$ 只用来证明两者都非空、都非良序，
不参与 $j_i$ 的定义。若强行要求 $j_i$ 是 $f\!\upharpoonright\!S_i$ 的截面，
$j_i$ 就必须从每个 $E$-类里选元素，正是 `conclusion.tex:130-132` 声明避免的那件事：

```
Its graph is defined by the unique common value on each class; it
does not require choosing class representatives.
```

(d) [推测] 失败路线。设想过把截面条件做成可满足问题：对每个商 $E$ 要求名字
$\dot J$ 满足 $\dot J([\dot A_j])=A_{j'}$ 且 $E(j,j')$。这样的 $\dot J$ 在
$\operatorname{Fix}(D_q)$ 之下会被任何移动 $E$-类内部的置换破坏，支撑被迫包含每类的全部成员，
在 `forcing.tex:197-200` 的滤子里不可容许。

(d2) [推测] 失败路线。设想过放弃截面只要求 $\operatorname{ran}(j)\subseteq\bigcup_i S_i$ 的整体覆盖，
但 `conclusion.tex:109-116` 的单值性证明靠的正是 $S_i$ 两两不交
（`conclusion.tex:56-57` 的 $Y_i$ 定义用 $\setminus\bigcup_{k<i}f[B_k]$ 制造不交性）；
把覆盖放宽到 $\bigcup_i S_i$ 之后，两个片的重叠会让 $j(y)=j(y')$ 无法判 $y=y'$。

## 3. 第二条死路：$\mathrm{SVC}^{+}(A)$ 的方向错配

(a) 原文。`introduction.tex:82-92`：

```
For a nonempty set $A$,
$\mathrm{SVC}(A)$ says that every nonempty set is a surjective image
of $A\times\eta$ for some ordinal $\eta$. The injective version,
$\mathrm{SVC}^{+}(A)$, says that every set embeds into some
$A\times\eta$. See also
\cite[Definition~3.13 and Theorem~3.14]{Usuba2021}.
These presentations let a construction on one set control objects
of arbitrary rank, but their different directions cannot be
interchanged without proof.
```

`conclusion.tex:134-138`：

```
The first hypothesis is the surjective assertion $\mathsf{SVC}(A)$.
Its injective counterpart $\mathsf{SVC}^{+}(A)$ would assert an
injection $X\longrightarrow A\times\eta$ for every $X$ and some
ordinal $\eta$.  The proof does not assume that counterpart.
It follows afterward by applying $\PP$ to each presentation surjection.
```

(b) 补步。顺序问题在这里非常关键，也是我卡了最久的一点。$\mathrm{SVC}^{+}(A)$ 才是
Ryan-Smith 局部到整体定理的前提，而我的构造里天然得到的是 $\mathrm{SVC}(A)$：
`forcing.tex:523-527` 的命题 3.6 结论是满射 $A\times\eta\twoheadrightarrow X$，
它的证明（`forcing.tex:533-538` 的 $\dot h_{\sigma,p}$）用轨道拼部分函数，
只给出"每个 $x\in X$ 有某个原像"，没有任何单值方向的信息。

(c) 机械理由。为什么方向不能互换：命题 3.6 的图名字把值绑在**中心** $A_{\pi(p(1))}$ 上，
`forcing.tex:542-552` 证明"同一输入给出同一值"用的机制是
$\pi(p(1))=\rho(p(1))$ 加上 $n=m$ 推出 $\pi p=\rho p$，从而 $\rho^{-1}\pi\in\operatorname{Fix}(D_p)$ 固定 $\sigma$。
这只够证明函数性。反过来要单射，需要给 $x$ 指派一个唯一的 $j$，而
`forcing.tex:576-585` 的覆盖论证是"$p$ 属于 $H$ 即可"，$H$ 里有无穷多个这样的图，
唯一性在对称模型里被置换移动掉。$\mathrm{SVC}^{+}(A)$ 只能在 $\mathsf{PP}$ 成立**之后**
对每个表示满射应用 $\mathsf{PP}$ 才拿到，这个先后关系是 `conclusion.tex:136-138` 那句
"The proof does not assume that counterpart" 的全部内容。

(d) [推测] 失败路线。假设先把 $\mathbb P$ 加强为"图必须单调枚举 $D_r$"，
指望由此得到 $X\hookrightarrow A\times\eta$。这个改动会破坏命题 3.4 的第一条：
枚举信息让 $\tau$ 的支撑从 $D_p$ 扩大到有向结构，$\pi$ 在 $D_p$ 上逐点固定时
不再保证 $\pi\tau=\tau$，于是"更强的图不改变真值"失效。

(d2) [推测] 失败路线。假设把 $\eta$ 换成 $H_\Theta$ 的某个 ground 良序段来给 $X$ 直接编码。
$\dot h_{\sigma,p}$ 的值域因此会带 ground 秩信息，`forcing.tex:598-600` 强调的
"枚举在 $M\times\mathbb P$ 这个依赖 $\tau$ 的集合上、没有秩截断"就保不住；
一旦有秩截断，$\mathsf{PP}$ 的全集量化在 `metatheory.tex:30-32` 的"无名字秩截断"要求下不可用。

## 4. 第三条死路：直接给商选代表，以及"局部计数不够"的教训

(a) 原文。`quotients.tex:3-8`：

```
Our next objective is a bijection between $A$ and each of its
nonwellorderable quotients. A local count of names is insufficient:
assignments made in two diagrams must agree whenever those diagrams
occur in one generic filter. We first classify local elements by the
subdiagrams on which they are available. We then construct bijections
which respect every restriction and every change of coordinates.
```

`introduction.tex:150-157` 把同一件事写成两个相容性问题：

```
The difficult part is to construct the bijections in
\eqref{eq:intro-quotient} with enough coherence to belong to the symmetric
model. Fix one equivalence relation on $A$ whose quotient is not
wellorderable. Counting its classes on
each support will produce many possible local bijections, but arbitrary
choices of them need not agree on overlapping supports or respect
coordinate changes.
```

(b) 补步。这段是我判断"任务从存在性变成一致性"的转折记录。若只想证明
$|A/E|=|A|$，`quotients.tex:74-77` 的引理 4.1 已经给出 $|\mathcal D_F(r)|\le\mu$，
`quotients.tex:164-169` 的引理 4.3 给出两个纤维同为 $\mu$；在 $V[F]$ 里
用普通选择取一个双射就完事。但那句话在 $W$ 里没有名字。
`quotients.tex:598-603` 的式子

```
 f_{r,U}(F):L_{r,U}\longrightarrow B_{r,U}(F)
```

要求的是**整个系统**：$t\le r$ 时限制要相容（`quotients.tex:704-714`），
$\pi\in G_q$ 时搬运要相容（`quotients.tex:405-408`）。两个相容性一个是下方向、
一个是坐标方向，独立取的双射两个都不满足。

(c) 机械理由。为什么局部计数在语法上不足以给出名字：HS 名字要求支撑 $J$ 满足
$\operatorname{Fix}(J)\subseteq\operatorname{stab}(\dot J)$（`forcing.tex:197-200`、`forcing.tex:209-211`），
即逐点固定 $J$ 的每个置换都要逐点固定名字。一个"在 $V[F]$ 里随便挑的"双射
$\dot J$ 的图里含 $\tau\in\mathcal X(r)$，而 $\operatorname{Fix}(D_r)$ 之外的置换会把它送去
$\mathcal X(r')$，图就不再是同一个集合。相容性条件正是把
"名字是集合"这件事翻译成对纤维选取的约束。

(d) [推测] 失败路线。设想过对每个 $r$ 用 $\mathcal X(r)$ 的 ground 良序取最小代表，
一次性定义 $\dot J_r$。断在 `quotients.tex:201-207`：探针给的 $\mu$ 个副本
$r_m$ 的交集恰为 $D_p$，最小代表在两个副本上会选到同一个名字，
支撑下降（引理 3.5）就把那个类送回 $\mathcal X(p)$，与"在 $\mathcal X(p)$ 之外"矛盾。

(d2) [推测] 失败路线。设想过先证 $A/E$ 与 $A$ 之间的双射存在性再靠选择公理
在 metatheory 里挑名字。$V[F]$ 里有选择，但挑到的对象依赖 $F$，
而 `quotients.tex:34-36` 已声明本节不用"ground 置换作用在同一个被评估宇宙上"这种假命题，
所以依赖 $F$ 的对象不能自动获得支撑。

(d3) [推测] 失败路线。设想过把相容性弱化为"只在共同强化上图相等"。
`quotients.tex:716-724` 说明真正的要求还包括单值与内射要在
**任意两个同时活跃的图元素**之间检验，并非逐个元素检验；弱化版本会在
$t$ 与 $t'$ 都活跃但不可比较时留下双值。

## 5. 关键转折：把"给商选双射"改写成"给可用性模式选协变量指派"

(a) 原文。`introduction.tex:136-139` 的中心性质：

```
The central additional property is
\begin{equation}\label{eq:intro-quotient}
 \text{every nonwellorderable surjective image of $A$ is in bijection with $A$.}
\end{equation}
```

`quotients.tex:153-162` 给出改写后的对象：

```
For a nonempty ideal $U\subseteq\downarrow a$, put
\[
 B_{r,U}(F)=\{h\in\mathcal D_F(r):U_h=U\},\qquad
 L_{r,U}=\{j\in D_r:U_j=U\}.
\]
The second set is ground data; the first can depend on $F$.
These exact fibers, rather than the whole local sets $\mathcal D_F(r)$,
are the pieces on which a bijection can respect restriction: a label
and its assigned class must remain available at precisely the same
subdiagrams.
```

(b) 补步。这一步换掉了问题的类型。原来的问题是"造一个双射"，
换完是"在指标 $(r,U)$ 的图上造一个截面族，它沿收缩映射与置换搬运都协变"。
关键观察是 $L_{r,U}$ 纯 ground（$U_j$ 由 $j\in D_{r_n}$ 的字面成员关系定义，
`quotients.tex:121-122`），而 $B_{r,U}(F)$ 依赖 $F$；
两边同型于 $\mu$（引理 4.3）之后，问题只剩下"选哪一个同型"。
既然 ground 一边没有可动性，所有对称性负担都压到依赖 $F$ 的一边，
这就变成可以用代码与最小元处理的选取问题。第三阶段（`introduction.tex:186-195`）
和第五、六节的分解就顺着这个形状长出来。

(c) 机械理由。为什么恰好是"精确"纤维，并非下闭的可用集：若按
$\{h:U\subseteq U_h\}$ 分类，两个类的 $L$ 边会相交，收缩时
`quotients.tex:288-294` 用的等价
$z\in J\Longleftrightarrow z\vee n\in J$
只判定理想成员关系，无法把边界元素分配给唯一的类，纤维分解就不再是划分。
按 $U_h=U$ 严格分类才能由引理 5.1 得到 $B_w(F)\to B_v(F)$ 的双射，
从而在分量上粘合出一个集合 $B_C(F)$。

(c2) 为什么理想 $\downarrow a$ 里所有需要的 join 都存在：`monoid.tex:29-31` 声明
$a$ 本身就是上界，故 $\downarrow a$ 内任何有限集的公共右倍元 $a$ 可用，
条件 join 的定义域恰好是"有公共右倍元"。

(d) [推测] 失败路线。若把 $U$ 换成"某个共尾计数"，比如按 $|U|$ 分类，
引理 4.3 的 $\mu$ 个副本会因为 $\mathbb R$ 只加 $\kappa$ 个坐标而不可区分，
但收缩时的规范化身份会丢，`quotients.tex:312-320` 的粘合产生新等同。

(d2) [推测] 失败路线。若试图让 $L_{r,U}$ 也依赖 $F$（比如只数被 $F$ 命中的类），
对称性负担就两边都有，`quotients.tex:332-342` 的搬运 $T_\pi^F$
要同时改两侧，式 4.5 的独立性证明里"$\pi\tau_1=\tau_1$"那一步（第 104 行）失配。

## 6. 单孢 $T$ 的规格：为什么一个单孢要配两个扩张运算

(a) 原文。`monoid.tex:17-31`：

```
Let $M$ be a monoid with identity $1$. Write $x\sqsubseteq y$ if $xz=y$ for
some $z$.  We use only left cancellation.  A monoid is \emph{conical}
if $xy=1$ implies $x=y=1$.  Left cancellation and conicality make
$\sqsubseteq$ a partial order and make the right factor in a comparison
unique.  Write $x\sqsubset y$ for $x\sqsubseteq y$ and $x\ne y$,
and $\downarrow a=\{x:x\sqsubseteq a\}$.
A \emph{conditional join} is an element $x\vee y$ satisfying
\[
 xM\cap yM=(x\vee y)M
\]
whenever the intersection is nonempty.
```

`monoid.tex:41-48` 的 margin：

```
\begin{equation}\label{eq:mono-margin}
 \begin{gathered}
 0<\rho(x)<1,\qquad 0<\epsilon_x\leq1,\\
 \rho(y)-\rho(x)>
 \sup\{\epsilon_d:d\sqsubseteq y,\ d\not\sqsubseteq x\}
 \qquad(x\sqsubset y).
 \end{gathered}
\end{equation}
```

(b) 补步。规格里每个零件都对应构造 $T$ 之后的一个用途，`monoid.tex:123-132` 是我在
定理声明之后立刻写的对照表：有限合并（性质 2）给图论 forcing 的有向性；
探针（性质 3）给" $\mu$ 个副本、两两交恰为指定锥"；margin 让每个理想可数共尾；

(c) 机械理由。为什么 $\rho$ 取值在 $(0,1)$、$\epsilon$ 取值在 $(0,1]$：

## 7. 引理 2.1（`lem:mono-countable-ideal`）：margin 换来的是"理想都是 $\omega$ 共尾"

(a) 原文。`monoid.tex:51-58`：

```
\begin{lemma}\label{lem:mono-countable-ideal}
If a monoid has conditional joins and satisfies
Equation~\eqref{eq:mono-margin}, every ideal in $\downarrow a$ has a
nondecreasing cofinal sequence of length $\omega$, with repetitions
allowed.  The same conclusion holds in any $\ZFC$ extension in which
the monoid, order, heights and costs retain their meanings, for ideals
belonging to that extension.
\end{lemma}
```

证明在 `monoid.tex:59-71`，核心三行：

```
For an ideal $U$, choose elements whose heights approach
$\sup\rho[U]$, and replace their successive initial segments by their
finite joins.  This gives a nondecreasing sequence $(n_i)$ in $U$
with heights approaching the same supremum.  If $d\in U$ divides
none of the $n_i$, then
\[
 \rho(n_i\vee d)-\rho(n_i)>\epsilon_d
\]
for every $i$, contradicting convergence to the supremum.
```

(b) 补步。我把这个证明拆成两处重算。第一处是"replace successive initial segments by finite joins"
到底给出什么：设原始挑选序列为 $(u_i)$，令 $n_i=\bigvee_{k\le i}u_k$。
理想对有限非空 join 封闭（`monoid.tex:29-31`），故 $n_i\in U$；
$n_i\vee u_{i+1}=n_{i+1}$ 给出 $n_i\sqsubseteq n_{i+1}$，非降；
$\rho(n_i)\ge\rho(u_i)$（join 是右倍元扩张、$\rho$ 沿 $\sqsubseteq$ 不降，与
`monoid.tex:509-510` 对 $D$-坐标的同类断言同型），所以 $\sup_i\rho(n_i)=\sup\rho[U]$。
第二处是为什么 $\rho(n_i\vee d)-\rho(n_i)>\epsilon_d$ 是一行就够：
把 margin 用在 $x=n_i$、$y=n_i\vee d$，需要 $n_i\sqsubset n_i\vee d$；
$d\not\sqsubseteq n_i$（正是"$d$ 不整除任何 $n_i$"）说明严格不等；
右边集合 $\{d':d'\sqsubseteq n_i\vee d,\ d'\not\sqsubseteq n_i\}$ 含 $d$，
sup 至少 $\epsilon_d$。$\epsilon_d>0$ 由 `monoid.tex:43` 提供，这才是矛盾来源：
一个与 $i$ 无关的常正量把 $\rho(n_i)$ 顶出 $\sup\rho[U]$。

(c) 机械理由。为什么结论要额外声明"在任何保持意义的 $\mathsf{ZFC}$ 扩张里也成立"：
这句是给引理 4.2 的第二问准备的。`quotients.tex:144-150` 要在 $V[F]$ 中对一个
属于 $V[F]$、不一定属于 $V$ 的理想用共尾性，所用对象是 ground 的 $T$、序、$\rho,\epsilon$；
引理 2.1 的绝对性声明保证证明里的选择"在那个 $\mathsf{ZFC}$ 宇宙里做出"（`monoid.tex:69-70`）。
长度恰好 $\omega$：`monoid.tex:644-652` 的调度论证要"每个需求在某一轮之前完成"，
`monoid.tex:666-668` 的 "the set is countable and the rounds have cofinality $\omega_1$"
依赖需求集合可数；若理想共尾长度是 $\omega_1$，该有界性失效。
`monoid.tex:68` 的"Prepending $1$ makes $n_0=1$"是为 `quotients.tex:322-324`
选共尾序列时能让 $n_0=1$，从而 $r_{n_0}=r$、$L_C\subseteq D_r$，
这是 `quotients.tex:451-452` 那句 "$L_C\subseteq D_{r_{n_i}}$ for every $i$" 的前提。

(d) [推测] 失败路线。设想用"$\sup\rho[U]$ 可达"代替"可数共尾"，即要求每个理想有最大元。
这在探针扩张下必破：`monoid.tex:177` 的 $U=\bigcup_i\downarrow n_i$ 无最大元
（路径严格增，否则 margin 自相矛盾）。若强制有最大元，
`monoid.tex:96-101` 的 $\mu$ 个探针无法 prescribe 同一无最大元的理想模式，引理 4.3 的下界没素材。

(d2) [推测] 失败路线。设想把共尾长度写成 $\operatorname{cf}(\sup\rho[U])$ 的依赖版本。
引理 4.2 需要在 $V[F]$ 里断言"该理想属于 $V$"，靠 $\mathbb R$ 的 countably closed
收下可数序列（`quotients.tex:148-149`）；长度 $\omega_1$ 的序列会被
$\operatorname{Add}(\kappa,I)$ 加进来，`quotients.tex:130` 的结论失效。

(d3) [推测] 失败路线。设想省略 join 封闭性、只用下闭集分类。
`quotients.tex:134-140` 证 $U_h$ 对 join 封闭要用引理 3.5 的支撑下降，是非平凡一步；
若只下闭，$n,n'\in U$ 不保证 $n\vee n'\in U$，
`quotients.tex:303-305` 的"后继有向（在两者的 join 处收缩）"不成立，
`quotients.tex:306-310` 的共同后继归纳崩，分量粘合裂开。

## 8. 引理 2.3（`lem:mono-probe-algebra`）：探针的合流论证与 gate 二分

(a) 原文。呈现式在 `monoid.tex:147-158`：

```

relations
\begin{equation}\label{eq:mono-probe-relations}
 p_i=d_ip_{i+1},\qquad p_ib=c_ie\qquad(i<\omega).
\end{equation}
Put $m=p_0$.  Since $n_0=1$ and $n_id_i=n_{i+1}$, the first
relations give $n_ip_i=m$ for every $i$.  Thus every point of the path
divides the new probe.  The second relations make both factorizations

\[
 n_ip_ib=n_ic_ie=ae,\qquad mb=ae.
\]
```

结论式在 `monoid.tex:174-181`：

```
 mb=ae,\qquad m\not\sqsubseteq a,\qquad
 \downarrow m\cap\downarrow a=\bigcup_i\downarrow n_i,\\

```

```
 wM'\setminus B_s=g(w)M',\qquad g(w)=h(s)u.
```

(b) 补步。我把证明拆成四个可检查的机械步骤。

步骤一，正规形式的来源。$S$ 是 $M$ 沿 $x\mapsto xd_i$ 的直接极限，$[x,i]$ 代表 $xp_i$，
相等意味着"某个有限公共层相等"（`monoid.tex:187-189`）。
`monoid.tex:190-191` 提醒转移映射不必单（无右消去）；
但左 $M$-作用对每个乘子仍单：$uX=uY$ 在公共层成立，左消去给 $X=Y$（`monoid.tex:191-194`）。
$k([x,i])=xc_i$、$h(s)=k(s)e$ 的良定义靠 $d_ic_{i+1}=c_i$（`monoid.tex:146`、`monoid.tex:199-200`）。
未加第二条关系前元素是 $s_1\cdots s_jy$（$s_i\in S$、$y\in M$，允许 $j=0$），
旧因子夹在新字母之间被后一个字母吸收，吸收用的正是 $S$ 上的左作用（`monoid.tex:206-210`）。

步骤二，合流。唯一约化规则是 `monoid.tex:213-215` 的 $s(bt)\mapsto h(s)t$；
商 $t$ 唯一因左 $b$-作用单（`monoid.tex:217`）。终止显然。
临界对只有 $s\,(bt)\,(bu)$（末因子可为旧元），两种顺序相等靠
`monoid.tex:221-223` 的两条交换律 $h(bt)=bh(t)$、$h(h(s)t)=h(s)h(t)$；
不相交的约化由作用结合律交换。Newman 引理给唯一不可约形式（`monoid.tex:224-229`）。
我验算了 $h(bt)=bh(t)$：$h(bt)=k(bt)e$，$k$ 左 $M$-等变（`monoid.tex:196-198`）给
$k(bt)=b\,k(t)$，故 $h(bt)=b\,k(t)e=b\,h(t)$。第二条：$h(h(s)t)=k(h(s)t)e$，
$k$ 等与给 $k(h(s)t)=h(s)k(t)$，故 $=h(s)k(t)e=h(s)h(t)$。

步骤三，范围分离。`monoid.tex:234-238` 的不等式
```
 s\notin h(s)S.
```
读法：$s\in xS$ 意味 $x\sqsubseteq k(s)$；若 $s\in h(s)S$ 取 $x=h(s)=k(s)e$，
得 $k(s)e\sqsubseteq k(s)$，与 conicality 加左消去冲突（$k(s)e\sqsubseteq k(s)$ 给
$k(s)=k(s)ez$，消去得 $ez=1$，conical 给 $e=z=1$，与 $e\ne1$ 矛盾）。
这条不等式在两处复用：左乘单射（`monoid.tex:230-237`）与 gate 锥不回 $B_s$（`monoid.tex:280-283`）。

步骤四，gate 二分的计算。要算 $YM'\cap bM'$。$Y$ 旧时用 `monoid.tex:246-248` 的
$xM'=xM\cup\bigcup_{s\in xS}B_s$ 取旧 join $Y\vee b$ 或空；
$Y$ 新且头 $t$ 时不可约性给 $t\notin bS$，故 $B_t$ 内没有 $b$-倍元，归纳到 $g(Y)$，
其与 $bM'$ 的交由旧 join $g(Y)\vee b$ 算（`monoid.tex:265-271`）。
两种情形交集要么空，要么 $zM'$（$z=bu$、$u$ 旧，$u$ 旧由旧比较守恒），
乘 $s$ 并用 $sbu=h(s)u$ 得 $g(w)=h(s)u$。

(c) 机械理由。$\downarrow m\cap\downarrow a=\bigcup_i\downarrow n_i$ 的核验：
$P_s$ 定义在 `monoid.tex:321-323`。$m$ 的头是 $[1,0]$，

## 9. 引理 2.4（`lem:mono-probe-heights`）：区间 (2.10) 为什么要两段余量

(a) 原文。`monoid.tex:361-369`：

```
positive $u_s,\delta_s$ with
\begin{equation}\label{eq:mono-height-interval}
 \begin{split}
 u_s-A_s&>\delta_s,\\
 \rho(h(s))-u_s-\delta_s
  &>\sup\{\epsilon_d:d\sqsubseteq h(s),\ d\in M\setminus P_s\}.
 \end{split}
\end{equation}
```

放置规则在 `monoid.tex:380-388`：

```
 \rho(sY)=u_s+\delta_s\rho(Y),\qquad
 0<\epsilon_{sY}\leq\delta_s\epsilon_Y,\\
 \epsilon_{sY}\leq\epsilon_{g(sY)}
       \quad\text{whenever the gate exists}.
```

`monoid.tex:342-347` 给出这一节存在的理由：

```
The gate description also controls the costs of all newly introduced
divisors.  This is the reason for keeping a cost as well as a height:
pointwise strict inequalities alone would not control suprema at a
limit stage.
```

(b) 补步。可行性论证（`monoid.tex:370-378`）我逐句展开：
$p=\rho(k(s))-A_s\ge0$、$q=\rho(h(s))-\rho(k(s))>0$。
$d\sqsubseteq k(s)$ 且 $d\notin P_s$ 时，每个 $x\in P_s$ 都漏 $d$
（$P_s$ 是理想，$d\notin P_s$，故 $x\vee d$ 严格在 $x$ 之上、$d\not\sqsubseteq x$），
旧 margin 给 $\epsilon_d<\rho(k(s))-\rho(x)$；$x$ 逼近 $A_s$，此族 sup $\le p$。
$d\sqsubseteq h(s)$ 且 $d\not\sqsubseteq k(s)$ 时，margin 用在 $k(s)\sqsubset h(s)$（$h(s)=k(s)e$、$e\ne1$）
给此族 sup 严格小于 $q$。合并 sup $<p+q=\rho(h(s))-A_s$，
`monoid.tex:377` 特别注明"also when $p=0$"，因为第二个 sup 本身严格小于 $q$。
于是 $A_s$ 与 $\rho(h(s))$ 之间能塞下 $u_s$ 与 $\delta_s$ 两个正量。

(c) 机械理由。$\delta_s$ 同时作高度收缩系数与 cost 收缩系数是必需的：
同块内 $sY\sqsubset sZ$ 时 $\rho(sZ)-\rho(sY)=\delta_s(\rho(Z)-\rho(Y))$，
块内漏因子的 cost $\le\delta_s\epsilon_{(\cdot)}$，两边同乘 $\delta_s$ 保住严格
（`monoid.tex:393-398`）。若高度收缩而 cost 不收缩，同块比较第一个就崩。
旧 $x\sqsubset sY$ 情形（`monoid.tex:400-410`）需要同时压两个界：
块外旧因子 sup $\le A_s-\rho(x)<u_s-\rho(x)$（`monoid.tex:404-407`，用 $x\vee d\in P_s$），
块内因子 cost $\le\delta_s$，而
$\rho(sY)-\rho(x)=u_s-\rho(x)+\delta_s\rho(Y)>(A_s-\rho(x))+\delta_s\rho(Y)$；
`monoid.tex:408-409` 说式 (2.10) 第一行让差严格大于两个界，这就是 $u_s-A_s>\delta_s$ 的形状来源。
新 $sY\sqsubset$ 旧 $y$ 情形（`monoid.tex:411-420`）必须出现 $h(s)$，因为 $y$ 的块外因子
都是 $h(s)$（$h(s)\sqsubseteq y$，`monoid.tex:412`）的因子；
$y\ne h(s)$ 时剩余部分严格小于 $\rho(y)-\rho(h(s))$，
总差 $\rho(y)-\rho(sY)$ 是两段正差之和（`monoid.tex:418-420`）。
跨块情形（`monoid.tex:422-426`）用"$x<z<y$ 时两段正高度差支配两个相关 sup"的分情形检验。
旧 $x\sqsubset y$ 的 sup 不变（`monoid.tex:428-433`）：新因子 $d\sqsubseteq y$ 漏 $x$ 时
gate $g(d)\sqsubseteq y$ 旧且漏 $x$、$\epsilon_d\le\epsilon_{g(d)}$，
所以新 cost 不抬高旧 sup，而旧因子全在，故"exactly unchanged"，并非 $\le$；
`monoid.tex:433` 把这句话推广到 conservative tower 的并，这是 margin 在 $\omega_1$ 轮之后仍成立的凭据。

(d) [推测] 失败路线。只放一层余量（$u_s-A_s>0$ 而无 $\delta_s$ 项）时，
`monoid.tex:407-409` 变成"两个 sup 之和"的估计，极限层不再有严格性。

(d2) [推测] 失败路线。省略 $\epsilon_{sY}\le\epsilon_{g(sY)}$，
`monoid.tex:429-431` 的支配失效，旧 sup 可能被抬，
`monoid.tex:433` 的塔并持久性在极限层破，第 12 章 $\omega_1$ 轮调度撑不住。

(d3) [推测] 失败路线。把 $B_s$ 放在 $\rho(k(s))$ 上方，并非 $P_s$ 与 $h(s)$ 之间：
$k(s)\sqsubset sY$ 时 $e\sqsubseteq h(s)\sqsubseteq sY$ 而 $e\not\sqsubseteq k(s)$，
需要 $\epsilon_e<\rho(sY)-\rho(k(s))$，与块内 cost 的 $\delta_s$ 收缩彼此抢同一区间，无解。

## 10. 引理 2.5（`lem:mono-merger`）：$D$ 层与 $\frac1r$ 加权高度

(a) 原文。`monoid.tex:463-467`：

```
Adjoin generators $l_i$ with the specified relations
$l_i a_{ij}=l_j a_{ji}$.  The normal forms are
\begin{equation}\label{eq:mono-merger-forms}
 xz_1\cdots z_j\qquad(x\in M,\ z_i\in D),
\end{equation}
```

高度定义在 `monoid.tex:500-508`：

```
 \rho_D(z)=\frac1r\sum_{i<r}\rho_i(z),\qquad
 \rho_i(z)=
 \begin{cases}
 \rho(x),&z=t_i x,\\
 0,&z\text{ has no representation in copy }i.
 \end{cases}
```

(b) 补步。$D$ 是 $\{i\}\times M$ 按 prescription 的商，带右 $M$-作用，
前序 $z\sqsubseteq w\iff zq=w$（$q\in M$）在代表 copy 内由左消去与 conicality 成为偏序
（`monoid.tex:450-455`）。$D$ 内 join 的算法（`monoid.tex:456-461`）：
跨 copy 元素的公共倍元必须落在指定重叠内，于是在 copy $i$ 内把元素与重叠起点 join，
再把两个结果搬进重叠 join；任一步缺 join 判原锥不相交。
正确性来自"任何公共倍元必经这两个预备 join"。
词层锥的描述在 `monoid.tex:481-498`：右乘固定末字母前的前缀、
在末字母的 $D$-锥内前进、可能追加；比较 $xz_1\cdots z_p$ 与 $yt_1\cdots t_q$（$p,q>0$）
需要 $x=y$ 且 $\min(p,q)$ 前逐字母等；$p=q$ 时在 $D$ 里 join 末字母或空，
$p<q$ 时要求 $z_p\sqsubseteq t_p$，此时前词整除后词且后词即 join，$q<p$ 对称。
旧元与正长词（首系数 $y$）有公共倍元当且仅当 $x\sqsubseteq y$。
两个旧词用旧 join，因为公共倍元的首系数正是旧的公共倍元。

(c) 机械理由。$\frac1r$ 与"有限多个 copy"的耦合在 `monoid.tex:517-524`：
$u<v$ 在 $D$ 中时按代表 copy 给漏因子分类。该 copy 也代表 $v$；
若它同时代表 $u$，旧 margin 把这族 cost 的 sup 压到"该坐标增量除以 $r$"以下；
若不代表 $u$，该坐标从 $0$ 跳到至少 $\rho(1)$，而这类 cost 已被
`monoid.tex:512-516` 的 $\epsilon^D_z\le\frac1r\min(\{\rho(1)/2\}\cup\cdots)$ 压到 $\rho(1)/(2r)$。
`monoid.tex:522-524` 明确："There are only finitely many copies, so their strict
bounds still give the required strict supremum bound"。
$\rho(1)/2$ 里的 $\frac12$ 是给"$\le$ 与 $<$"留的严格性间隙，
除以 $r$ 是把总量摊到平均高度 $\rho_D$ 的每个坐标上。
词层高度（`monoid.tex:526-533`）里 $\theta+\phi<1$ 保 $\rho<1$；
$\min(\theta/2,\phi\epsilon^D_z)$ 的 $\theta/2$ 是 `monoid.tex:536-539`
"$w$ 与 $wz$ 比较时新长度漏因子的 cost 至多 $(1-\rho(w))\theta/2$，严格小于高度增量"
所需，因为 $\theta+\phi\rho_D(z)\ge\theta>\theta/2$。
"不新增旧元素的因子"（`monoid.tex:444`、`monoid.tex:476-477` 的字母计数论证）
是引理 2.7 的第一句和 `quotients.tex:618` 的直接依赖。

(d) [推测] 失败路线。$\rho_D$ 取 $\max_i\rho_i(z)$ 不加权：$u<v$ 可能只在非最大坐标上增长，
`monoid.tex:509-510` 的"某坐标严格增"传不到 $\rho_D$，margin 的第一线断。

(d2) [推测] 失败路线。$\epsilon^D_z$ 取常数 $\rho(1)/(2r)$ 而不做 $\min$：
某 copy 同时代表 $u,v$ 时，旧 margin 给的界与常数界不可比较，sup 严格性丢。

(d3) [推测] 失败路线：跳过 $D$ 层，直接把 $l_ia_{ij}=l_ja_{ji}$ 商进自由积。
`monoid.tex:80-83` 的"valid"（不 collapse 单个 copy、传递闭包不制造额外交）
就没有可读的对象，`monoid.tex:469-471` 的"每个关系只作用在一个新字母/旧因子对内"
无法成立，正规形式唯一性（`monoid.tex:470-472`）不成立。

## 11. 引理 2.6 与 2.7：可重排的合法性从哪来

(a) 原文。`monoid.tex:552-559`：

```
\begin{lemma}\label{lem:mono-simulation}
Suppose $B\subseteq M$ is conservative and both monoids have the
algebraic properties above.  Either extension operation with parameters
in $B$ is valid over $M$, and the extension of $B$ conservatively
embeds into the corresponding extension of $M$ by the same generators.
A finite overlap prescription with parameters in $B$ is valid in $B$
if and only if it is valid in $M$.
\end{lemma}
```

conservative 的原文定义在 `monoid.tex:33-37`：

```
An inclusion $B\subseteq M$ is \emph{conservative} if it preserves and
reflects comparisons, preserves their right factors, preserves existing
joins, and preserves the absence of a common right multiple.  In
particular, if $x,y\in B$ and $xz=y$ in $M$, then $z\in B$ and the
same equation holds in $B$.  Mere injectivity is not this property.
```

持久性在 `monoid.tex:610-616`。

(b) 补步。simulation 的三块证明：validity 双向（`monoid.tex:560-572`）的非平凡处
是三 copy 的传递检查，中间 copy 里 intersect 两个重叠起点，
锥不相交由 conservativity 保持，否则旧 join 与其右商不变，之后公共倍元都是该 join 的倍元，
两个端点等同在 valid prescription 里于 join 处已一致，右乘给所有更晚公共倍元的一致。
探针部分（`monoid.tex:574-588`）：极限里字母相等是有限层相等故被反映；
旧 $b\in B$ 整除小极限字母 $[x,i]$ 时，大极限有公共层 $by=xd_i\cdots d_{j-1}$，
两端在 $B$，右因子 $y$ 在 $B$；gate 递推只用旧 gate、旧 join、旧商，结局（包括"无 gate"）相同。
合并部分（`monoid.tex:602-607`）：$D$ 里的重叠表示与锥交只用旧 join 与旧右商。
中间独立那段（`monoid.tex:590-600`）把"新形式之间的右商属于小子单孢"分四情形除，
"新因子离开首字母块"那一支过 gate、用式 (2.9) 的 $c(w)=c(Y)v$。

探针扩张下新 $x\sqsubseteq a$ 有旧 gate，$x\sqsubseteq m\iff g(x)\sqsubseteq m$；
$m\sqsubseteq x$ 被 $x\sqsubseteq a$、$m\not\sqsubseteq a$ 排除；极限处所有被检元素已出现。

(c) 机械理由。这条性质是调度的支点。`monoid.tex:644-650` 的 $\omega_1$ 轮里
需求先记录后执行，中间插入别的扩张；"scheduled merger 保持 valid"靠
simulation 的"在 $B$ 中 valid 当且仅当在 $M$ 中 valid"取 $B$ 为记录层、$M$ 为执行层。

说明右因子守恒也被单独使用。
`monoid.tex:680-683` 的"realization remains exact"用守恒来说
$l_ix=l_jy$ 在更高层仍必经被保留的根 join 与其 prescription 商。
`monoid.tex:684-686` 用 $a=1,b=e,U=\{1\}$ 的探针得 $|T\setminus eT|=\mu$：
该探针无旧 $e$-因子（$U=\{1\}$ 不含 $e$），$\mu$ 个 $m$ 全在 $eT$ 外。

(d) [推测] 失败路线。跳过 simulation 按需求顺序直接执行：
`monoid.tex:748-762` 的重排论证里"the original operation at $\alpha$ is legal over the
current base, by conservative simulation again" 失去依据，第 12 章的重排整段作废。

(d2) [推测] 失败路线：conservative 只保序反射、不保右因子。

(d3) [推测] 失败路线：引理 2.7 只证到后继层。$T$ 里

## 12. 支撑下降引理（`lem:support-descent`）：两图合流处的名字如何落在公共支撑上

(a) 原文。`forcing.tex:380-425` 陈述了支撑下降：设 $s_0\Vdash\sigma_0=\check x$、

```
D_{v'}\cap D_{v''} = D_u.
```

```

  \pi\in\Fix(D_p),\ (\eta,(a,u))\in\sigma_0,
```

(b) 补步。`forcing.tex:400-425` 的独立情形是全文技术密度最高的一段。

用已证的独立情形分别与两原始拷贝矛盾，得所有一致性。

置换元素所以支撑是 $D_p$；每个成员名字是 $\sigma_0$ 的平移所以 HS。原触发器活时
一致性让此并恰等于 $\sigma_0$ 的值。`forcing.tex:498-505` 说没有设秩界，

(c) 机械理由。这条性质是 `quotients.tex:200-250` 的 $\mu$ 个拷贝区分

(d) [推测] 失败路线。跳过第三拷贝、直接令 $v'=v''$：两拷贝上的 $\sigma_1$

（利用 (1) 的满射和 (3) 的商分类），再用 (2) 拼合。
`conclusion.tex:93-101` 说"the local injection is a section"，
良序情形截面有选择（每个纤维非空且良序）；非良序情形用 $\mathsf{PP}$ 对 $A/E$ 的商
直接给双射，`conclusion.tex:130-132` 声明避免的就是从每个 $E$-类里选代表。

`conclusion.tex:154-196` 的 remark 推广到 $\CSB^*$ 和 $\WPP$：同一构造
对这些弱化形式也给出否定。`conclusion.tex:198-229` 的 Hartogs 递归：
$a:\lambda\to A\cup\{A\}$，每阶段 $S_\alpha=A\setminus\operatorname{ran}(a|\alpha)$；
若 $S_\alpha$ 永不为空则 $\lambda$ 单射进 $A$（与 Hartogs 矛盾），
所以某 $\alpha$ 处 $S_\alpha=\varnothing$，$a|\alpha$ 是 $A$ 到自身的双射（良序 $A$）。

(c) 机械理由。三条假设缺一不可：

缺 (1)：$A\times\eta\twoheadrightarrow X$ 表达"$A$ 是 $W$ 的生成集"。没有它，
(3) 只管 $A$ 自身的商；$X$ 可能与 $A$ 无联系，$\mathsf{PP}$ 要求对任意 $X,Y$ 的满射建单射。

缺 (2)：切片拼接对 $\mathrm{Ord}$ 个局部选择做超限选择；没有 $\mathsf{AC}_{\mathrm{WO}}$，每切片的双射
虽存在但无法同时取定，拼合后的 $j$ 没有名字。

缺 (3)：只有 $A\times\eta$ 到 $X$ 的满射但没有 $A/E$ 到 $A$ 的双射，
$\mathsf{PP}$ 的逆注入 $j:Y\to X$ 无法构造。

`conclusion.tex:239-248` 把"在一般 ground 上读内部 forcing 解释"和
"在可传递 ground 上读真实包含"区分开：一般 ground 下 $\omega$ 是 ground 的
内部 $\omega$、$z\in V$ 是 check-name 表示；可传递 ground 下是真实包含。
这个区分是定理 6.3 与推论 6.4 的前提。

(d) [推测] 失败路线。把 (3) 弱化到"每个商 $A/E$ 至少单射进 $A$"：拼合时
只给切片建单射，并非双射，$j$ 的像覆盖不了 $Y$ 的全部分支，$\mathsf{PP}$ 的逆注入条件丢。

(d2) [推测] 失败路线：$A$ 的不可良序性用 Dedekind-finite 给。Hartogs 递归
（`conclusion.tex:210-229`）用 $A$ 的像的覆盖性质使 $S_\alpha$ 非空时
$a(\alpha)\ne A$；Dedekind-finite 的 $A$ 未必满足 (1)，因为 $A\times\eta$
的像可能只覆盖 $\mathcal P(A)$ 而不覆盖全体集合。

## 15. 一致性推导（`metatheory.tex:1-439`）：可构造基与一阶解释

(a) 原文。`metatheory.tex:1-10` 把本节标题定为"The consistency deduction"，
目标：

```
Con(ZF) implies Con(ZF + PP + ACwo + not AC).
```

可构造一致性在 `metatheory.tex:68-115` 的引理 6.1（constructible-consistency）。
对称 forcing schema 在 `metatheory.tex:116-254`，其核心引理（`metatheory.tex:123`）：

```
For every formula there is a forcing relation definable in the ground,
and the symmetric model's satisfaction agrees with the forcing relation
restricted to HS names.
```

`metatheory.tex:355-396` 应用构造到两条路径：一致性蕴涵和传递模型存在性。

(b) 补步。`metatheory.tex:11-65` 的内部分解把构造切成三步：(i) $V$ 中定义
积 forcing $\mathbb Q=\mathbb R\times\mathbb P$ 和对称系统；(ii) 对称模型
$W$（内部于 $V^{\mathbb Q}$）满足 ZF + PP + ACwo + $\neg$AC；(iii) 提取
相对一致性。

`metatheory.tex:68-115` 在 $V=L$ 里特化：$\mathfrak c=\aleph_1$ 所以
$\kappa=\aleph_1$、$\mu=\aleph_2$、$|I|=\aleph_3$；引理 3.1（`forcing.tex:78-129`）
的"若 $V\models\mathsf{CH}$ 则保所有基数"成立。$V=L$ 的全局良序使 ground
枚举和放置（`quotients.tex:74-112`、`forcing.tex:131-183`）都可用
$\Delta^1_2$-definable 的良序具体化，不在元数学层面用选择。

`metatheory.tex:116-254` 的一阶解释：$W$ 定义为 $\mathrm{HS}/\sim$ ，并非
$V^{\mathbb Q}$ 的子类。`metatheory.tex:298-354` 的真理性引理逐公式证明
$W\models\varphi(\tau_1,\ldots,\tau_n)$ 当且仅当某条件迫使 $\varphi$。
关键机制在 `metatheory.tex:182-190`：名字 $\sigma$ 的稳定子与有限多参数名字
稳定子的交仍在 $\mathcal F$ 里（$|J|\le\mu$ 保正则），所以 $\Vdash^*$ 对 HS
名字的截断合法。

`metatheory.tex:255-354` 对任意可传递 $M$ 扩展 $N$：用真理性引理把 $N$ 的
satisfaction 内化到 $M$ 的 forcing relation，外部用 Rasiowa-Sikorski
（$M$ 可数所以 generic 存在）建 $G$。`metatheory.tex:397-439` 的定理 6.4：
可传递 ZFC 模型存在蕴涵可传递 ZF+PP+ACwo+$\neg$AC 模型存在。

(c) 机械理由。`metatheory.tex:30-32` 的"无名字秩截断"为什么对引理 5.1 的 (1)
至关重要：$A\times\eta\twoheadrightarrow X$ 里 $X$ 是 $W$ 中任意集合。若
$\Vdash^*$ 用了秩截断，则 $\dot X$ 在 $V_\alpha$ 以下评估时"$A\times\eta$
映到 $\dot X^\alpha$"的 forcing relation 只在 $V_\alpha$ 内有定义，
$\alpha$ 不知 $X$ 的真实秩。支撑下降不设界（`forcing.tex:500-505`）保
$\sigma$ 覆盖整条轨道。

`metatheory.tex:182-190` 的滤子闭合：$\mathcal F$（`forcing.tex:197-200`）是
$\operatorname{Fix}(J)$（$|J|\le\mu$）的上闭包。HS 名字 $\sigma$ 的
$\operatorname{stab}(\sigma)$ 包含某 $\operatorname{Fix}(J)$；有限交
$\bigcap_{i\le n}\operatorname{stab}(\sigma_i)\supseteq\operatorname{Fix}(\bigcup_i J_i)$，
$|\bigcup_i J_i|\le\mu$（$\mu$ 正则、$n$ 有限），所以交在 $\mathcal F$ 里。

`metatheory.tex:255-354` 用可数传递模型，并非真类 $V$：外部 generic 的存在需要
$M$ 可数（Rasiowa-Sikorski 给 $\aleph_0$ 个稠密集的交非空）。真类 $V$ 上要用
Jech 布尔值模型（`conclusion.tex:239-248` 区分两种解释），元数学前提变强。

(d) [推测] 失败路线。$\Vdash^*$ 定义里加秩参数 $\Vdash^*_\alpha$：逐公式归纳的
$\forall$-步要跳到 $\alpha+1$，$\mathrm{HS}/\sim$ 的商只在 $\alpha$-截断以下自洽，
跨截断等式无法保持，引理 5.1 (1) 失去证明。

(d2) [推测] 失败路线：用外部 $M$-generic 建 $W$ 的 ZF 性但 $M$ 不可数。
Rasiowa-Sikorski 失效；`metatheory.tex:355-396` 的两条路径（一致性和传递模型）
合一，需布尔值方法且工作量倍增。

## 17. `exists_model_partitionPrinciple_without_choice` 的量词形状

(a) 声明。`lean/OAI/SetTheory/PartitionPrinciple/Models/Separation.lean:35-51`
的完整定理：

```
theorem exists_model_partitionPrinciple_without_choice
    (pairing : Realize M.sets SetFormula.pairing Fin.elim0)
    (unions : Realize M.sets SetFormula.union Fin.elim0)
    (powers : Realize M.sets powerSet Fin.elim0)
    (separation : SeparationSchema M.sets)
    (collection : CollectionSchema M.sets)
    (infinite : Realize M.sets infinity Fin.elim0)
    (choice : Realize M.sets SetFormula.choice Fin.elim0)
    (small : M.sets.Countable)
    {K : ZFSet.{u}} (hK : K ∈ M.sets)
    (standard : GroundStandardInaccessible M K) :
    ∃ N : TransitiveGround.{u}, M.sets ⊆ N.sets ∧
      ZFRealization N.sets ∧
      Realize N.sets partitionPrinciple Fin.elim0 ∧
      ¬ Realize N.sets SetFormula.choice Fin.elim0
```

(b) 逐参数拆解。$M$ 是类型参数（`variable (M : TransitiveGround.{u})`），
代表一个可传递基模型；前七个假设（pairing 到 choice）把 $M$ 约束为 $M$ 满足
ZFC 的全部公理模式。`Realize M.sets SetFormula.pairing Fin.elim0` 是配对公理的
一阶公式在 $M$ 的集合宇宙里的实现。`SeparationSchema` 和 `CollectionSchema`
是公理模式，并非单个公式。`choice : Realize M.sets SetFormula.choice Fin.elim0`
是选择公理在 $M$ 里成立。`small : M.sets.Countable` 声明 $M$  externally 可数。
$K$（`{K : ZFSet.{u}}`，隐式参数）是 $M$ 的一个不可达基数（`hK : K ∈ M.sets`
加上 `standard : GroundStandardInaccessible M K`），对应 `conclusion.tex:251-254`
里 $\mu=((2^{\aleph_0})^+)^V$ 的基模型选择。

结论是存在 $N$（`∃ N : TransitiveGround.{u}`），满足：
(i) $M\subseteq N$（`M.sets ⊆ N.sets`），$N$ 继承 $M$ 的全部集合；
(ii) $N$ 满足 ZF（`ZFRealization N.sets`）；
(iii) $N$ 满足 PP（`Realize N.sets partitionPrinciple Fin.elim0`），
其中 `partitionPrinciple` 来自
`Definability/PartitionPrincipleFormula.lean`，是 PP 的一阶公式在 $N$ 上的实现；
(iv) $N$ 不满足 choice（`¬ Realize N.sets SetFormula.choice Fin.elim0`），
用 `SetFormula` 的否定构造。

(c) 证明路径。`Separation.lean:22-33` 的辅助定理
`exists_partitionPrinciple_without_choice` 先证：在同样的假设下存在 $N$ 使得
$M\subseteq N$、ZF 成立、一个关于 ground-embeddable 的弱选择性质成立、且 choice 失败。
`Separation.lean:48-51` 的 `exists_model_partitionPrinciple_without_choice` 从
辅助定理取 $N$，再把弱选择性质（groundEmbeddable 的每对 $(X,Y)$ 有满射像）
升级为 PP 公式：`(N.realize_partitionPrinciple).2 pp` 把 ground-embeddable 性
转化为 PP 公式在 $N$ 上的实现。

整条路径：`exists_groundMainFinalSupport`（GroundMainFinalPartitionModel 层，
对应 forcing.tex 的图拼接 + quotients.tex 的双射构造）$\to$
`exists_partitionPrinciple_not_choice`（FulfilledFiber 层的组装）$\to$
ground-embeddable 性质 $\to$ `realize_partitionPrinciple`（Definability 层的公式翻译）$\to$
`exists_model_partitionPrinciple_without_choice`。

(d) 量词形状的一个微妙处：$N$ 是 `TransitiveGround.{u}`（同 universe 层），
所以 $M\subseteq N$ 是同一 universe 内的包含。$N$ 的 ordinals 与 $M$ 相同
（`conclusion.tex:262`："It contains $V$ and has the same ordinals as $V$"），
Lean 端的 `ZFRealization N.sets` 把 ordinals 的保持编码在 `SeparationSchema`
和 `CollectionSchema` 的公式实现里。

PP 的实现形式 `Realize N.sets partitionPrinciple Fin.elim0` 是集合论公式
"对任何非空集合族 $\{X_i\}_{i\in I}$，若 $|\bigsqcup_i X_i|=|I|$ 则存在单射
$I\to\bigsqcup_i X_i$"在 $N$ 的 `ZFSet` 层上的逐词翻译。choice 的失败用
`¬ Realize N.sets SetFormula.choice` 表达为：不存在 $N$ 中的选择函数对 $N$ 的
某个集合族做截面。`SetFormula.choice` 是 ZF 语言里"每个集合都可良序"的
一阶公式，其否定就是 $\neg\mathsf{AC}$。

(e) `ComparatorChallenges/PartitionPrinciple.json` 的 `enable_nanoda: false`
声明此定理不走 nanoda（数值优化验证），只做纯一阶证明。`permitted_axioms`
的三项（`propext`、`Quot.sound`、`Classical.choice`）是 Mathlib 默认公理；
其中 `Classical.choice` 出现在元逻辑层（Lean 的排中律），与对象理论的
`¬ Realize N.sets SetFormula.choice` 不冲突。

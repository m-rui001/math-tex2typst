## §1 初始动机：把周期性与有限表示第一次放在同一张桌上

我要解决的问题陈述其实只有一句话：一个群若每个元素都是有限阶，又拥有有限生成元和有限关系子的普通呈现，它是否必然有限？论文在引言里专门把"普通有限呈现"钉死成群论意义：关系子的正规闭包之外，不把任何群簇恒等式塞进定义（build/paper.tex:64-68, 95-98）。这一句限定是整个问题的命门。Burnside 群 $B(m,n)$ 当然有 $m$ 个生成元，也满足 $x^n=1$，但那是一条对所有元素同时生效的恒等式，写进普通呈现需要无穷多条关系子；把它当作"有限呈现"是把两种不同的有限性混在一起（build/paper.tex:95-98 的意思我读到这里就停下来复述了一遍）。

历史坐标也摆在引言里：Burnside 1902 年提出问题（build/paper.tex:121-122）；Golod 用 Golod--Shafarevich 不等式从幂零代数造出无限有限生成周期群（build/paper.tex:123-125）；Novikov--Adian 造出有界指数的无限有限生成群（build/paper.tex:126-127）；Zel'manov 解决受限 Burnside 问题的阶界（build/paper.tex:128-131）。这些全部停留在"有限生成"这一侧。Ol'shanskii 与 Sapir 明确把有限呈现的周期群问题列为独立问题（build/paper.tex:134-136），他们自己的 torsion-by-无限循环群有一个无限的循环商（build/paper.tex:136-140），也就是说商那一层保住了周期性的对立面。我要找的对象必须四条同时成立：有限呈现、无限、每个元素阶有限、而且阶可以随元素变化（build/paper.tex:95-96 允许这一点，我一开始倒是把它记成了要求一致指数，后来才明白放弃一致指数正是让步的入口）。

代数侧的动机同样在引言里（build/paper.tex:142-171）：非幺结合代数的"每个元素幂零"与"整体幂零"的区分；Ufnarovskij 经 Smoktunowicz 之口提问：有限呈现的幂零代数是否必然幂零（build/paper.tex:149-151）；Amitsur 对 Jacobson 根版本提出同样问题（build/paper.tex:152-154）；Kurosh 的代数化有限性问题在有限呈现版本下是否仍否定（build/paper.tex:159-171）。Golod 的答案在有限生成一侧早已完成，有限呈现一侧没人碰过。论文后来用一个环同时喂两问（build/paper.tex:167-171），这就决定了我的构造重心在环上，群只是漏斗。

## §2 两条先试就碰壁的老路线

[推测] 这一节全部是我替作者补的弯路，论文没有记载。标注理由：正文五个章节文件里没有一处讨论被放弃的方案。

第一条路：分支群。Grigorchuk 型的群是无限周期 2-群，每个元素 2 的幂阶，看起来"已经"是答案的一半。但分支群的呈现天生带无穷层信息，据我所知的文献里没有把它们写成普通有限呈现的先例；周期性靠的是作用在无穷二叉树上的层级行为，而有限呈现是全局性质。[推测] 这条路在我这里停留的时间应该很短，因为论文把整个重心搬到了结合代数与 Steinberg 群，跟树作用毫无关系；正文里也找不到任何树、automaton group 字眼（我 grep 过 section 结构标题，见 §0 的读法）。

第二条路：给 Golod--Shafarevich 代数补关系子。Golod 造环的手法是取一个有限维代数，证明其关联自由代数商若关系子空间"太小"，则整个代数无限维且每个正次元素幂零。问题在于"小"是一个不等式条件，写出来是逐次递增的生成元组；商到有限关系子时，要么环变成有限维，要么元素级幂零性丢失。[推测] 我在论文里找到的间接印证是引言把 Golod 归到"有限生成"一侧（build/paper.tex:123-125），而代数侧的新结果明确写了"有限呈现的非幺幂零代数但非幂零"（build/paper.tex:52-54），暗示旧手法在有限呈现这一档不够用。

还有一条隐含的退路我也想过：直接证伪，即证明有限呈现周期群必然有限。这条路我完全没有材料去走，只能标 [推测]，理由是若作者曾认真考虑并排除，引言多少会留一句障碍说明；build/paper.tex 引言没有这样的句子。

## §3 关键转向：把群问题翻译成环问题，列出四条义务

转折点是把对象从"群"换成"环上的 Steinberg 群"。定义照抄：对 $n\ge 3$ 与 $\mathbb F_2$-代数 $R$，$x_{ij}(a)$ 满足三条 Steinberg 关系（build/paper.tex:76-83）：

$$x_{ij}(a+b)=x_{ij}(a)x_{ij}(b),\qquad [x_{ij}(a),x_{kl}(b)]=1\ (j\ne k,\ i\ne l),\qquad [x_{ij}(a),x_{jk}(b)]=x_{ik}(ab).$$

$x_{ij}(a)$ 映到初等矩阵 $e_{ij}(a)$ 给出满射 $\pi_n:\St_n(R)\to\E_n(R)$，记核为 $J_n(R)$（build/paper.tex:85-86）。主定理只需要 $n=12$：存在这样的 $R$ 使 $\St_{12}(R)$ 无限、有限呈现、周期（build/paper.tex:88-93）。

引言末尾把证明拆成四条义务（build/paper.tex:186-202），我认为这是全文最像"作战地图"的一段：

1. 有限呈现：把 $R$ 的有限代数呈现机械地转成 $\St_n(R)$ 的普通有限群呈现，$n\ge 5$ 即可（build/paper.tex:186-192）。
2. 无限性：$R$ 无限，于是单个矩阵位置 $(i,j)$ 里不同的 $a$ 给出不同的 $e_{ij}(a)$（build/paper.tex:192-194）。
3. 矩阵像的周期性：$\E_n(R)$ 的每个元素有限阶，靠 $M_d(I)$ 逐矩阵幂零加约化到有限群 $\GL_n(\mathbb F_2)$（build/paper.tex:194-195）。
4. 核的 torsion：$\E_n(R)$ 周期不够，$J_{12}(R)$ 也必须是 torsion 群；一旦如此，任意 $g$ 的某次幂落进核，再某次幂等于单位元（build/paper.tex:196-202）。

四条义务要对同一个环、同一个群同时成立，这是我把对象钉死在 $\St_{12}(R)$ 的原因：$n$ 不能随便取大，稳定性一节把下限顶到 12（build/paper.tex:261-262），$n=12$ 是各段门槛的交点。[推测] 12 这个数应该来自 frame 复形同调稳定性给出的余维账，后面 §16 会回到这里。

环 $R$ 的形态被写成 $R=\bigoplus_{b\ge 0}R_b=\mathbb F_2\oplus I$，$R_0=\mathbb F_2$，$I$ 为正次部分，并且对每个有限 $d$，$M_d(I)$ 中每个矩阵各自幂零、幂零指标随矩阵变化（build/paper.tex:173-184）。"矩阵幂零"与"词的像幂零"被论文明确说成两个独立步骤（build/paper.tex:184-185 的意思），这句话当时把我敲了一下：我一开始以为逐词幂零可以拼出矩阵幂零，其实 $(A+B)^N$ 展开里有无穷多种交错乘积，非交换之下根本拼不动。

## §4 词替换与零宣告：代数呈现的最小充分语言

代数侧的语言在 finite-rules 开头定好（sections/finite-rules.tex:11-16）：一个初等替换是两条等长非空词之间的关系 $v=v'$，可以在任何上下文里双向使用；一个零宣告是 $v=0$。长度指词长，指二项式次数。这里我注意到一个便宜：替换保持词长，所以商代数按词长分次，这是后面系数抽取的前提。

引理 sections/finite-rules.tex:18-24（fr:basis）说：这类呈现的非零替换等价类构成向量空间基；一个类为零当且仅当其中某个词含有被宣告为零的子词；空词存活。证明骨架（sections/finite-rules.tex:26-35）是把词做成图的顶点、替换做边，商就是每个连通分量一个基向量，再砍掉含零子词的连通分量。这个"图分量"视角让我确定了两件事：其一，判定一个词是否非零完全局部，看它含不含某个固定短词；其二，规则表只要有限，呈现就有限（sections/finite-rules.tex:108-112 接着说：给出表成员资格的有限判定谓词，就等于给出有限呈现，枚举长度 $\le k$ 的词、保留宣告条目即可）。

参数约定（sections/finite-rules.tex:37-46）：$h$ 为正整数，$q_h=2^h$；场不进规则表，同一套词关系在所有场上成立。调色板字母除颜色外还带有限辅助数据（非色字段），含两条控制轨：一条查颜色，一条验证编码规则，各自标明该格是否有 head。我读到这里的第一反应是：这就是把图灵机状态位塞进字母表的做法，跟 Durand--Romashchenko--Shen 的定点拼图同源（build/paper.tex:210-213 引了它们，第 2.3 与第 5 节）。论文也承认前驱是它们的多项式时间局部检验与变尺度模拟；不同点在 build/paper.tex:213-215 写明：这里必须控制关系允许的每一条词，包括含未完成或伪造验证状态的词。这一句是我在 §5 之后反复回来咀嚼的：只保证干净编码良构，远不够消去论证用。

## §5 层级命题：干净编码、token 分解、调色板长 run

层级命题（sections/finite-rules.tex:48-106）是整个代数构造的合同。常数 $c=10000$、$k=10$ 被允许（sections/finite-rules.tex:49）。固定 $D\ge 2$，存在 $h_0$，对 $h\in\{h_0,h_0D,h_0D^2,\ldots\}$ 给出字母表 $\Sigma_h$（基数 $\le 2^{ch}$）与长度 $\le k$ 的有限表；记商出的幺结合代数 $A_h(K)$。三条性质：

性质一（fr:prop-encoding，sections/finite-rules.tex:61-69）：定长替换 $E_h:\Sigma_{Dh}\to\Sigma_h^{L_h}$，$L_h=2q_h+1$；上层每条关系都是下层关系代入后的推论，所以 $E_h$ 诱导代数同态 $A_{Dh}(K)\to A_h(K)$，且上层非零词代入后在下层仍非零；每层有一个非零单字母词。这是"模拟"的方向：下层规则多到能逼出上层规则，而编码又不把非零词压成零。

性质二（fr:prop-tokens，sections/finite-rules.tex:70-91）：$\Sigma_h$ 里一个指定子集在它前面标记切割（cut 由后随字母识别，build/paper.tex:228-230）。存在界 $B_h$ 与有限 token 表 $\mathcal T_h$，使每条足够长的非零词唯一分解为 $p\,t_1\cdots t_r\,s$，两端 $|p|,|s|\le B_h$，每个 token $t$ 等于某个上层词 $u_t$（长度 $1\le|u_t|\le k$）的编码 $[E_h(u_t)]$，且等式只用 token 内部的替换完成。注意论文特意声明：不保证任意 token 拼接非零（sections/finite-rules.tex:90-91）。这一行小字帮我校准了自己：token 表是解剖工具，不是自由基。

性质三（fr:prop-runs，sections/finite-rules.tex:92-101）：调色板字母带 $q_h$ 种颜色；合格 run 是连续调色板字母、非色字段全同、两条控制轨都无 head 的最长段。相邻换位是整字母的初等替换；非零词里的合格 run 颜色两两不同；每条足够长的非零词含长 $\ge q_h/100$ 的合格 run；合格性与极大 run 端点只依赖非色字段。

命题读完后我把 $D$ 的作用圈了出来：$D$ 在"程序不动点"定表之前选定，$h_0$ 在其后选定，$c,k$ 与 $D$ 无关（sections/finite-rules.tex:103-105）。为什么顺序如此，我在 §8 读完 tableau 才敢回答：表的内容是一次可计算性判定的编码结果，$D$ 决定下一层的字母表宽度 $cDh$，也就是输入规模；不动点是这台"判表程序"自己的规则码，顺序颠倒会让定义自指不闭合。[推测] 论文没有明说"颠倒会怎样"，我只标出这是定义域的要求。

三性质合起来就是我需要的一切：性质一保无穷性（把上层非零词一路搬下来，长度翻倍，见 §12），性质二给消去论提供"每条长词 = 两端有界碎片 + 一串可单独规范化的 token"的解剖，性质三给交错和提供足够长的一段可换色区间。三者要同一张表同时满足，这正是 build/paper.tex:205-208 说的"两个输出"要同时拿。

## §6 字母表与块格式：结构相邻、数据位、两条控制轨

字母表的具体化只用了两页纸的篇幅（sections/finite-rules.tex:114-161）：$\Sigma_h$ 取全体长 $ch$ 的比特串（sections/finite-rules.tex:117）。字段放进固定不相交的槽：预留 32 个宽 $2h$ 的整数槽与 512 个单比特标志槽，其余位置必须为零，于是 $c=10000$ 在 $h=1$ 时就够（sections/finite-rules.tex:120-123）。这个"宁可宽裕"的取法给我的提示是：常数的具体值不进任何渐近论证，$c,k$ 只是让计数闭合的松弛垫。越界字段或未列的标签组合被宣告为零，但仍算字母（sections/finite-rules.tex:125-126）。这条"零字母仍在字母表里"的规定很要紧：后面所有局部检验都不必问"邻居存在吗"。

结构类型三种：$C(p)$（核心格，$1\le p\le q_h$）、$P(a)$（调色板格，$1\le a\le q_h$）、$S$（停止格）。允许的结构相邻只列出五对（sections/finite-rules.tex:134-137）：$C(p)C(p+1)$、$C(q_h)P(a)$、$P(a)P(b)$、$P(a)S$、$SC(1)$；其余结构对一律宣告零。于是一个完整块由 $q_h$ 个核心格、一段非空调色板和一个停止格组成；词端缺失邻居不做结构检验（sections/finite-rules.tex:140-141）。我核对过这五对的循环顺序：$S$ 后接 $C(1)$ 正是块与块的接缝，切割就声明在 $C(1)$ 前（sections/finite-rules.tex:911-912），所以"切割由后随字母识别"落实为"看见 $C(1)$ 且其事务轨处于空闲或相对块号为 1"。

每字母带一条事务控制轨，每个调色板格另有独立的调色板检验轨；每条轨有 distinguished 空闲态（sections/finite-rules.tex:143-146）。事务轨空闲的核心格若 $p\le cDh$ 就带一个数据比特，否则不带，于是一个空闲完整块的前 $cDh$ 个数据比特恰好编码 $\Sigma_{Dh}$ 的一个字母，不管那个上层字母是否满足上层格式限制（sections/finite-rules.tex:147-149）。这里我停了一下：连格式违规的上层字母也被编码，代价是下层要承担更多零宣告；收益是编码映射 $E_h$ 在字母层面处处有定义，"非零词保非零"才谈得上逐字母构造。取 $h$ 足够大使得 $cDh\le q_h$（sections/finite-rules.tex:150-151），核心格数够用。

干净块：两轨皆空闲且调色板每种颜色恰出现一次；颜色递增排列时叫典范块。$E_h(a)$ 就是数据为 $a$ 的 $cDh$ 比特的典范块，按拼接延拓到词，块长 $L_h=2q_h+1$（sections/finite-rules.tex:153-157）。结构语法本身仍允许任意非空调色板；它的长度与颜色集合要到非零词论证里才被强制（sections/finite-rules.tex:158-160）。这句"以后再说"的让步我起初觉得冒险，读到 §9 的片段界才明白：调色板长度由两条控制轨的 head 数与常元段的划分强制（sections/finite-rules.tex:927-945），根本不需要语法预先卡死。

替换的意图（sections/finite-rules.tex:163-168）：在若干个完整块内执行一条上层关系；操作临时"获取"这些块的格子，把现存数据与拟议的替换分别存进不同的槽；验证器先检查拟议关系的证书，替换才能成为被表示的数据。这套"获取-验证-提交"的事务结构就是 §7 的主角。

## §8 可寻址计算表与程序不动点：有限规则表从何而来

前面所有局部判定都要组成一张有限表。表从哪来？§8 的答复是（sections/finite-rules.tex:618-640）：造一台确定的单带通用机，编码它的接受计算，局部布尔约束即 Cook 定理的计算表法（sections/finite-rules.tex:624-625 引 Cook 的定理 1 证明）。它模拟给定的程序码，接受时把磁头送回 distinguished 原点然后冻结；模拟与原点返回对每个固定被模拟程序有多项式开销；一个具体实现把被模拟带与磁头标记存在轨道上、逐条扫描已用段落，已用段长随模拟步数线性增长（sections/finite-rules.tex:628-640）。这里我特意对照了拼图前驱：Durand--Romashchenko--Shen 也是多项式时间局部检验，词版本把开销多项式当作现成条件用就够了。

尺寸的账（sections/finite-rules.tex:642-644）：$T=2^{\lfloor h/5\rfloor}$ 行时间，$W=4T$ 个带位，原点 $o=2T$。$T$ 对 $h$ 是指数、$W$ 对 $T$ 是线性，所以表面积 $\beta WT$ 对 $h$ 约 $2^{h/5}$ 阶，远小于字母表规模 $2^{ch}$（$c=10000$）：证书变量塞得进字母的固定槽位。输入编码用 $\operatorname{enc}(n)=1^{|\operatorname{bin}(n)|}0\operatorname{bin}(n)$（sections/finite-rules.tex:651-654），初始带内容是长度、字母、$Dh$、任务号、数据比特串（sections/finite-rules.tex:656-664），取 $h$ 大到输入占带位 $< T/4$，且输入与从原点出发的磁头在 $T$ 步内都碰不到边界格（sections/finite-rules.tex:667-670）。这个"两头留空"让我确认边界条款（第 2 族子句）与真计算互不干扰。

转移的局部性：一步确定性磁带头是半径 1 的描述，新符号与新磁头标记由该格与左右两邻的上一行标记决定；把不一致三元组的值任意补全成总布尔函数 $f:\{0,1\}^{3\beta}\to\{0,1\}^{\beta}$（sections/finite-rules.tex:672-679）。固定一个 $g$ 门 NAND 电路。证书变量 $X(t,j,r)$ 铺表位、$Y(t,j,v)$ 铺电路门位，地址按 $\beta(Wt+j)+r$ 与平移后的 $g((W-2)t+j-1)+v$ 精确编址（sections/finite-rules.tex:685-694），总数 $\beta WT+g(W-2)(T-1)$（sections/finite-rules.tex:696-698）。子句四族（sections/finite-rules.tex:701-725）：初始行逐比特两条款；后续各时刻边界格每比特一单元子句保持空白；内区每个 $(t,j)$ 按电路序展开 $3g+2\beta$ 条子句（每个 NAND 门 $(u\vee z),(v\vee z),(\neg u\vee\neg v\vee\neg z)$ 三条，加 $\beta$ 条输出等同）；原点终格用 $\beta$ 条单元子句钉在接受态。

不动点在哪：表要判定"上层参数 $Dh$ 的某条关系是否合法"，而上层关系本身又是同一程序对更大参数的输出；程序码即规则码，自己写自己，所以先定 $D$ 再跑不动点、后定 $h_0$（呼应 §5 末的顺序讨论）。[推测] 不动点的具体求法（Kleene 式迭代还是递归定理）在 730 行之后的段落，我没读到；我引用的行数只支撑"表成员资格由这台机器的接受计算刻画"这一层。

对我而言这一节的收获是把"有限"两个字落实到了比特：关系表是有限的因为子句列表由 $(T,W,\beta,g)$ 的显式计数给出；规则长度 $\le k$ 是因为每条关系被压成定长块内的局部构型，$k=10$ 的松弛垫（§6 的槽位宽裕）在这里闭合。

## §9 切割、fragment 界与孤立规范化：任意非零词的解剖

fr:fragment-bound（sections/finite-rules.tex:919-924）：非零词里每段调色板碎片的长有只依赖 $h$ 的界，可取 $16q_h+2$；无切割区间的长有界，含伸到词端的情形。证明我读全了（sections/finite-rules.tex:926-959）：调色板内部没有事务起点；事务轨至多一个 head，其余是常元翼加可能的空闲后缀；检验轨同样至多一 head。两条有序划分的公共细分去掉至多两个 head 位后剩至多 16 个齐次非 head 区间，故意取松的绝对常数 16（sections/finite-rules.tex:930-934）。调色板格无载荷、相对块号在获取段内恒定，所以区间内除颜色外字段全同；颜色若在区间内重复，相邻换位把两次出现并到一起，产生等色零（sections/finite-rules.tex:940-942），于是每区间至多 $q_h$ 格。整块或其碎片长 $\le 17q_h+3$；无切割区间内获取序号在每个块首严格递增直到顶多 $k$，除非新事务或空闲块开始（那正制造切割），所以取 $B_h=(k+2)(17q_h+3)$ 即可（sections/finite-rules.tex:947-959）。

这里我核对了一处容易滑过的逻辑：颜色重复推出零用的是"相邻换位是初等替换"，即性质三前半。碎片界与可换色性在证明依赖图上互相咬合：性质三的下落（每段齐次区间颜色互异）直接喂给 §10 的交错和。

fr:token-normalization（sections/finite-rules.tex:962-1011）：切割之间的区间由 1 到 $k$ 个完整结构块组成，可以只用区间内部的替换变成典范块拼接。证明分空闲与非空闲两支（我读到的骨架）：非空闲支沿 §7 的标记链确定唯一事务与块数；然后用 palette-soundness 清检验 head、用 rollback 释放获取格，两次都允许"或得到零"，而区间是非零词的因子、任何置零序列在整词上也置零，所以这些替换必然全部成功（sections/finite-to-rules 的原句在 sections/finite-rules.tex:990-995，我抄在这里备查：操作支撑都在区间内，检验清除留在调色板及其前一核心格，释放只用获取前缀）。收尾：调色板补齐并排序，空闲核心数据按块读回 $cDh$ 比特串，恰为 $E_h(u)$（sections/finite-rules.tex:1002-1010）。与干净起步的论证相比，这一步不需要初始控制状态曾由获取到达过（sections/finite-rules.tex:998-1000）；伪造状态的词就是靠这句差别被吃进来的。

命题三性质的收束（sections/finite-rules.tex:1013-1047）：表有限且关系长 $\le 2$（尤其 $\le k=10$）；token 表有限因为块数 $\le k$、每块有 fragment 界；$|t|=(2q_h+1)|u_t|$ 由保长得来；足够长非零词至少两个切割；规范化彼此隔离，没有借用任何外部 head、调色板格或边界检验。性质三最后一步：非零 token 的完整调色板在规范化前就长 $q_h$，除去至多两个 head 单元与至多 16 段齐次区间，合格 run 长 $\ge (q_h-2)/16$，对所取参数已 $\ge q_h/100$（sections/finite-rules.tex:1036-1041）。

解剖完成后，我手里的每条长非零词长这样：两端有界碎片 $p,s$，中间一串 token，每个 token 对应唯一的短上层词 $u_t$，还夹着一条可换 $q_h/100$ 种颜色的长 run。下一站的消去论证要用的只有这三样东西，层级构造到此退场。

## §10 矩阵权重与交错和：特征 2 下的消去机制

进入消去章（sections/cancellation.tex:1-38）：固定 $c,k$，取 $D>10(c+1)(k+1)$（sections/cancellation.tex:7-8，代入 $c=10000,k=10$ 得 $D>1100110$，一个百万级的数），再做不动点、取大 $h_0$；记 $h_j=h_0D^j$、$q_j=2^{h_j}$、$L_j=2q_j+1$、$\Sigma_j$、$A_j(K)$（特征 2 场上的代数），$E_j:A_{j+1}(K)\to A_j(K)$（sections/cancellation.tex:11-25）。标量扩张便宜：关系系数在 $\F_2$，$A_j(K)=K\otimes_{\F_2}A_j(\F_2)$，$\F_2$ 上非零词在任意 $K$ 上仍非零（sections/cancellation.tex:29-31）。我把这条当作"同一张表吃遍所有特征 2 场"的保险丝来读，后面 §12 用 $K=\F_2(z)$ 时全靠它。

测试的定义（sections/cancellation.tex:56-82）：字母测试给每个字母配 $M(a)\in M_d(K)$，词取有序乘积，长度 $n$ 的和为 $S_{j,n}(M)=\sum_{w\in\Sigma_j^n}M(w)\otimes[w]_j$；块测试（chunk test）给有限标识集 $\mathcal C$、每标识配非空标签词 $v_\gamma$（长 $\le b$）与权重 $W_\gamma$，长度 $n$ 的和按标签总长聚列所有标识序列，空序列只在 $n=0$ 贡献 $1_d\otimes 1$。"最终消失"指长度 $n$ 的和对所有充分大 $n$ 为零。字母测试的 $n$ 次和恰是一个矩阵的 $n$ 次幂（sections/cancellation.tex:87-91），因为 $T=\sum_a M(a)\otimes[a]$ 展开按长度分层；块测试允许不同因子数混在同一 $n$ 层（sections/cancellation.tex:92-94），这正是 $T^a$ 分组方式的投影。

消去的引擎是那条交错和引理（sections/cancellation.tex:101-121）：特征 2 下 $\mathcal A_m(X_1,\ldots,X_m)=\sum_{\sigma\in S_m}X_{\sigma(1)}\cdots X_{\sigma(m)}$，若 $m>d^2$ 则 $\mathcal A_m=0$。证明只有三步：有多重性；两参相等时按对换配对，两项乘积相等、特征 2 下相消；按 $M_d(K)$ 的 $d^2$ 维基展开，参量超过 $d^2$ 必撞重复基向量。全程不做 $m!$ 除法，所以特征 2 无损（sections/cancellation.tex:120 特意点了这一句）。我觉得这一条是全论文最"初等"的心脏：消去性来自颜色两两不同加交换性，与群论无干。

直接消去（sections/cancellation.tex:123-132）：固定 $j,d,b$，若 $q_j/100>b(d^2+3)$，则层 $j$ 上任意维数 $d$、标签界 $b$ 的块测试在一切特征 2 场上最终消失。[推测] 我读到的证明开头（135 行起：取 $n$ 超过长词阈值、用性质二分解、把 run 内换位搬进和式）之后是逐情形核对，中段没有逐行读；从阈值 $d^2+3$ 我猜那 3 个余量付给两端碎片与 head 位的损失，仅供自检时对照，不作为引用。可靠的链条是：长 run 内颜色互异、相邻换位是表内替换，所以和式在该 run 上等于 $\mathcal A_m$ 在一个 $m\ge q_j/100$ 个互异颜色的字母族上求和；$m>d^2$ 即零。

## §11 维数增长与有限层停机：一切固定试验终归零

单层的调色板赢了单层的小维数测试，但把测试送上层时维数会膨胀：切割归约（fr:cut-reduction，对应引理在 sections/cancellation.tex:221 附近）与自动机引理（ca:automaton，sections/cancellation.tex:303 附近）我只读了标题行；这两条的名字与下面命题证明里的用法足够重建账目，具体构造我标 [推测]：块测试的标签词需要"可分段"记账，用有限加权自动机记录切分方式，代价是维数乘一个 $C_k|\Sigma_i|^k$ 型因子；Schützenberger 的矩阵词权重理论（build/paper.tex:240-244 引 1961 文）就是这套做法的出处。

核心停机命题（ca:all-tests，sections/cancellation.tex:373-444，证明我读全了）。固定层 0 字母测试维数 $d$。对 $j\ge 1$ 定义 $d_j=d\prod_{i=1}^{j-1}(C_k|\Sigma_i|^k)$，空积给 $d_1=d$（sections/cancellation.tex:381-386）。链条：层 0 的维数 $d$ 字母测试被切割归约压到层 1 的维数 $d_1$ 块测试；层 $i\ge 1$ 的维数 $d_i$ 块测试被自动机变成同层维数 $\le d_{i+1}=C_k|\Sigma_i|^k d_i$ 的字母测试；补零到 $d_{i+1}$，再用切割归约送到层 $i+1$ 的块测试（sections/cancellation.tex:387-393）。

增长比较（sections/cancellation.tex:395-414）：用 $|\Sigma_i|\le 2^{ch_i}$ 与几何求和，
$$\log_2(d_j^2)\le 2\log_2 d+2(j-1)\log_2 C_k+\frac{2kc}{D-1}(h_j-h_1).$$
由 $D>10(c+1)(k+1)$ 得 $\delta=1-2kc/(D-1)>0$，而 $h_j=h_0D^j$ 是几何级数，所以 $h_j-\log_2(d_j^2)\to+\infty$：调色板的指数 $2^{h_j}$ 对维数平方 $d_j^2$ 有双层指数的增速差。于是存在有限 $J\ge 1$ 使 $2^{h_J}>400k\,d_J^2\ge 100k(d_J^2+3)$，第二式的 $d_J\ge 1$ 我核了一下确实显然，直接消去的阈值 $q_J/100>k(d_J^2+3)$ 就此满足，层 $J$ 上维数 $d_J$、标签界 $k$ 的块测试全部最终消失。

逆向归纳（sections/cancellation.tex:419-438）：若层 $i+1$ 维数 $d_{i+1}$ 块测试全消失，则切割归约给出层 $i$ 维数 $d_{i+1}$ 字母测试消失，自动机再给出层 $i$ 维数 $d_i$ 块测试消失；降到层 1 后再用一次切割归约得层 0 字母测试断言。论文在这段末尾把量词次序钉死（sections/cancellation.tex:427-438）：不存在对所有测试统一的长度阈值；停机层 $J$ 只依赖起始维数与固定层级；每个测试的阈值穿过有限次长度膨胀与有界端长加回被拉回。"对每条固定测试，存在 $N$"，这句话我在 §12 抽系数时回来检查过，它恰好够用。

收尾（sections/cancellation.tex:440-443）：层 0 任意标签界 $b$ 的块测试是某维数 $\le C_b|\Sigma_0|^b d$ 的层 0 字母测试的一块，已证的字母断言覆盖它。

对我而言这一节的教训在增速对比那一步：若取 $D$ 固定而 $c$ 更大，$\delta$ 仍正只要 $D-1>2kc$；$D>10(c+1)(k+1)$ 是把这个不等式连同 $q_J$ 阈值的余量一次买断。设计裕度是刻意留的。

## §12 代数 R 的定理与中心不定元 z 的系数抽取

定理 thm:algebra（sections/cancellation.tex:448-458）：存在无限、有限呈现、分次的幺结合 $\F_2$-代数 $R=\bigoplus_{n\ge 0}R_n=\F_2\oplus I$，使每个 $M_\ell(I)$ 幂零（逐矩阵，指标随矩阵）。证明（sections/cancellation.tex:460-536）我全部读完，这是 §10、§11 与 §4 的三线合流：

取 $R=A_0(\F_2)$，只用层 0 字母与层 0 关系；字母有限、长 $\le k$ 词有限，故 $R=\F_2\langle\Sigma_0\rangle/\mathcal J_0$ 是普通有限代数呈现；高层的关系一条都不加进 $\mathcal J_0$（sections/cancellation.tex:461-470）。定义多项式齐次且正次，词长给分次，$I$ 是双边理想（sections/cancellation.tex:471-473）。

无穷性：每层取非零字母 $a_j$，$w_j=E_0E_1\cdots E_{j-1}(a_j)$ 逐层用性质一的非零保持，长 $\prod_{i<j}L_i\to\infty$；不同的 $[w_j]_0$ 落在不同齐次次数，线性无关（sections/cancellation.tex:475-484）。注意这里用的只是"编码保非零"一条，解剖与消去都没上场。

矩阵幂零：固定 $\ell$ 与 $T\in M_\ell(I)$，按 (sections/cancellation.tex:489-494) 写成 $T=\sum_\gamma A_\gamma\otimes[v_\gamma]_0$，$A_\gamma\in M_\ell(\F_2)$、$|v_\gamma|\ge 1$，$b=\max|v_\gamma|$。中心不定元 $z$ 登场：在 $K=\F_2(z)$ 上对块 $v_\gamma$、权重 $zA_\gamma$ 用停机命题；长度 $n$ 的和是多项式
$$P_n(z)=\sum_{\sum_i|v_{\gamma_i}|=n}z^r A_{\gamma_1}\cdots A_{\gamma_r}\otimes[v_{\gamma_1}\cdots v_{\gamma_r}]_0\in M_\ell(R)[z]$$
的像（sections/cancellation.tex:496-508）；固定 $n$ 只有有限项（标签非空使 $r\le n$）。命题给出 $N$：$n\ge N$ 时像在 $M_\ell(K\otimes_{\F_2}R)$ 中为零。

注入性这一步（sections/cancellation.tex:514-523）：$M_\ell(R)[z]\to M_\ell(\F_2(z)\otimes_{\F_2}R)$ 单。证法是取 $R$ 的 $\F_2$ 基、按基展开多项式系数：像为零当且仅当每个标量多项式在 $\F_2(z)$ 中为零，即在 $\F_2[z]$ 中为零。于是 $P_n(z)$ 本身为零，系数可以名正言顺地在原矩阵代数里抽取。

最后合体（sections/cancellation.tex:525-535）：$T^a$ 按总词长分层写成 $T^a=\sum_{n=a}^{ab}[z^a]P_n(z)$；下界 $a$ 用每个因子标签非空，上界 $ab$ 用最大标签长。$a\ge N$ 时右端每项为零，故 $T^a=0$。$\ell$ 与 $T$ 任意，逐矩阵幂零成立。

这一段的量词账我要替论文说一句公道话：$N$ 依赖 $T$（经 $d=\ell$、$b$、以及权重选择），正符合"指标随矩阵"的合同；§11 末尾"无统一阈值"的声明在这里没有造成任何缺口。推论 cor:nil-algebra（sections/cancellation.tex:545 起，我只读到标题行）把 $I$ 本身当作非幺代数读：有限呈现、幂零（逐元素）、非幂零（因 $R$ 无限维而 $I$ 各次非零？[推测]：陈述行之后我未读，措辞按 build/paper.tex:52-58 摘要对齐：非幂零由正次部分无统一零化指数给出，恰好是逐矩阵幂零的弱一格）；其幺化对 $\F_2$ 元素代数且无限维，答复有限呈现版 Kurosh 问题（build/paper.tex:165-171）。

## §13 Steinberg 群的普通有限呈现：n≥5 的显式生成与关系

代数有限呈现变群有限呈现，这一站是 finite-presentation 章。先交代出处：Krsti\'c 与 McCool 证明了对任意有限呈现幺环 $S$ 与 $n\ge 4$，$\St_n(S)$ 有限呈现（sections/finite-presentation.tex:32-34，引其定理 3）；本节沿他们"按词长扩张单项式 root 关系"的路线（sections/finite-presentation.tex:34-38，引其第 3 节），对特征 2、$n\ge 5$ 给显式呈现，并证明有限关系推出全部 Steinberg 关系。$n\ge 5$ 对 $n\ge 4$ 的收紧是显式化过程的代价，我认为值得：换来的是后面每一段都能拿同一组生成元做逐字计算。

设定（sections/finite-presentation.tex:41-53）：$\mathcal A$ 有限字母表，自由幺结合代数 $T=\F_2\langle\mathcal A\rangle$ 以 $\mathcal A^*$ 为基，$f=\sum_{w\in S_f}w$ 用长度加字典序排列有限集 $S_f$；这个序只用来把群呈现里的词逐条写死，之后的 root 元素互相交换。

呈现定理（thm:finite-presentation，sections/finite-presentation.tex:55-101）。设 $R=T/\mathfrak a$，$\mathfrak a$ 由 $f_1,\ldots,f_s$ 生成，$n\ge 5$。生成元：
$$g_{ij}(w),\qquad i\ne j,\quad w\in\mathcal A^*,\quad |w|\le 2,$$
有限个。长单项的 root 用递推词定义：$|w|\le 2$ 时 $\xi_{ij}(w)=g_{ij}(w)$；$|w|>2$ 时写 $w=av$（$a$ 为首字母），取最小的 $h\in\{1,\ldots,n\}\setminus\{i,j\}$，令 $\xi_{ij}(w)=[\xi_{ih}(a),\xi_{hj}(v)]$（sections/finite-presentation.tex:74-82）。关系四族（sections/finite-presentation.tex:84-96）：平方 $g_{ij}(w)^2=1$（$|w|\le 2$）；隔位交换 $[g_{ij}(u),g_{kl}(v)]=1$（$|u|,|v|\le 2$，$j\ne k$，$i\ne l$）；相邻相乘 $[g_{ij}(u),g_{jk}(v)]=g_{ik}(uv)$（$|u|+|v|\le 2$，三方互异）；代数关系子 $\prod_{w\in S_{f_t}}\xi_{ij}(w)=1$（$1\le t\le s$，$i\ne j$，按定序取积，空积为 1）。同构把 $g_{ij}(w)$ 送到 $x_{ij}(\overline w)$。

这里的四个特征 2 细节我逐一对过：平方关系取代了教科书 Steinberg 呈现里的加法定律 $x_{ij}(a+b)=x_{ij}(a)x_{ij}(b)$ 的字母级形态，在 $\F_2$ 上加法即交换群指数 2，$x_{ij}(a)^2=1$ 加上"逐字母生成元"就把线性性从乘法结构里省掉；空词 $\varepsilon$ 计成 $|w|\le 2$ 的一员，所以 $x_{ij}(1)$ 是现成生成元，递推里的 $x_{hj}(1)$ 型因子不需要扩张词表。[推测] 这两点是我的读法归纳，论文没有以"备注"形式单列，我依据的是生成元计数式 (sections/finite-presentation.tex:70-73) 与关系 (sections/finite-presentation.tex:85-92) 的字面。

良定义性的枢纽是三因子交换子恒等式（fp:three-factor，sections/finite-presentation.tex:110-146，证明读全）：$X,Y,Z$ 群元，$A=[X,Y]$、$B=[Y,Z]$；设 $A$ 与 $X,Y$ 交换、$B$ 与 $Y,Z$ 交换、$A$ 与 $B$ 交换、$X$ 与 $Z$ 交换，则 $[A,Z]=[X,B]$，且公共值同时中心化 $A,Z,X,B$。证法：$H_1=\langle A,Z\rangle$ 与 $H_2=\langle X,B\rangle$ 互中心化；把 $[X,Z]=1$ 用 $Y$ 共轭，代入 $YXY^{-1}=A^{-1}X$、$YZY^{-1}=BZ$，展开 $[A^{-1}X,BZ]=1$ 得 $[A^{-1},Z]=[X,B]^{-1}$；该公共值属于 $H_1\cap H_2$，故中心化一切。论文在 103-108 行预告了这个用法：构造长词 root 时要证拆分与中间指标无关，"centerality 的结论是被证明的，不是被假设的"。我把它记成一个方法学教训：递推定义群词时，最贵的从来不是写出递归，是让每一步与选择正交；这里用一个纯交换子引理一次性买断。

归纳的次序（sections/finite-presentation.tex:104-106 的预告）：按新词长先建立交换性，再处理与空词的乘积，最后立乘积律。[推测] 中段 149-414 行是逐长归纳的展开，我只读了定理与引理陈述，执行细节没有跟完；但骨架从引理名字与 148 行起的证明首段（先去掉代数关系子再补回）已经清楚：先证"纯 root 世界"的呈现同构于抽象 root 群，再把 $\prod\xi_{ij}(w)=1$ 识别为 $R$ 的定义理想像。

## §14 满范性、无穷性与矩阵像的周期性

三条收尾引理（sections/finite-presentation.tex:415-477，全部读全）。

完全性（fp:perfectness）：任意幺 $\F_2$-代数 $R$、$n\ge 3$ 时 $\St_n(R)$ 与 $\E_n(R)$ 完全。证明一行：选 $h\notin\{i,j\}$，每个生成元是交换子 $x_{ij}(a)=[x_{ih}(a),x_{hj}(1)]$；商也完全（sections/finite-presentation.tex:424-431）。若 $R$ 无限则两群无限：固定位置 $(i,j)$ 的不同 $a$ 给出不同 $e_{ij}(a)$，看该位置条目即可（sections/finite-presentation.tex:432-435）。这就是 §3 义务二的完成，而且它只要求 $R$ 作为集合无限，连维数都不必。

矩阵周期性（fp:matrix-periodicity）：设 $R=\F_2\oplus I$ 为向量空间分解、$I$ 双边理想、$\F_2$ 那份含幺元，且每个 $M_d(I)$ 逐元素幂零。断言一：$A\in M_n(R)$ 可逆当且仅当模 $I$ 约化可逆。证：约化逆 $B$ 抬回 $R$ 后 $AB=\mathrm{Id}_n+U$，$U\in M_n(I)$，取 $U^m=0$，特征 2 下 $(\mathrm{Id}_n+U)^{-1}=\mathrm{Id}_n+U+\cdots+U^{m-1}$（sections/finite-presentation.tex:450-459）。断言二：$\GL_n(R)$ 每个元素有限阶，故 $\E_n(R)$ 周期。证：$\overline A\in\GL_n(\F_2)$ 有限群，设阶 $d$；$A^d=\mathrm{Id}_n+V$，$V\in M_n(I)$，取 $V^m=0$、$2^e\ge m$，特征 2 下反复平方给 $A^{d2^e}=(\mathrm{Id}_n+V)^{2^e}=\mathrm{Id}_n+V^{2^e}=\mathrm{Id}_n$（sections/finite-presentation.tex:461-468）。义务三完成，"不需要统一的幂零指标，也不需要元素阶的统一界"由原文 469-470 行逐字确认。

拼接逻辑（sections/finite-presentation.tex:473-477）：$\E_n(R)$ 周期加 $J_n(R)$ 逐元有限阶即得 $\St_n(R)$ 周期：$g^a$ 入核、$(g^a)^b=1$。义务四成为唯一欠账，随后两章（stability 与 kernel-torsion）专门还这笔。我在这一节页边写下的自评：整篇论文最"便宜"的周期性论证在矩阵侧，最贵的在核侧，预算完全花在了对立面。

## §15 中心性：root 带、忠实性与 n≥6

稳定性章开工前先立 $J_n$ 的交换性。命题 prop:centrality（sections/stability.tex:227-228）：$n\ge 6$ 时 $J_n$ 在 $\St_n(R)$ 中中心化。证明的装置（sections/stability.tex:231-283，读全）：给 $H_n$（由初等生成元与对角生成元生成的满矩阵群）指派 $\St_n(R)$ 的自同构，初等元 $e_{ij}(a)$ 配共轭，对角元配 $x_{ij}(a)\mapsto x_{ij}(u_i a u_j^{-1})$；相邻乘积关系在该指派下保持因为 $(u_i a u_j^{-1})(u_j b u_k^{-1})=u_iab u_k^{-1}$（sections/stability.tex:232-240）。检验的重心：任何支撑在 $\le 5$ 个坐标集合 $S$ 上的真关系必须平凡作用。取 $t\notin S$，两条带
$$U_t(v)=\prod_{i\in S}x_{it}(v_i),\qquad V_t(w)=\prod_{i\in S}x_{ti}(w_i)$$
是加法交换群，到初等矩阵的映射单，因为参数各占不同矩阵位置、带内无交叉乘积（sections/stability.tex:242-251），这就是引言里"矩阵映射在 root 带上单射"的落实（build/paper.tex:255-258）。$e_{ab}(r)$ 的作用是 $v_a\mapsto v_a+rv_b$、$w_b\mapsto w_b-w_ar$；第二条的负号来自 $[x_{ta}(w_a),x_{ab}(r)]=x_{tb}(w_ar)$ 右端与两因子交换、反转交换子把参数换成负（sections/stability.tex:253-259）。于是支撑于 $S$、矩阵乘积为 $M$ 的词在两带上是 $v\mapsto Mv$、$w\mapsto wM^{-1}$，保持一切非交换乘积的次序；真关系有 $M=\mathrm{Id}$，逐点固定两带（sections/stability.tex:260-269）。对每个 $t\notin S$ 重复，固定一切恰含一个 $S$-指标的 root 与支撑在 $S$ 外的 root；$i,j\in S$ 时用 $x_{ij}(a)=[x_{it}(a),x_{tj}(1)]$ 补内部 root（sections/stability.tex:271-275）。恰需要一个外部坐标，所以 $n\ge 6$ 的下限来自"小坐标呈现（每关系支撑 $\le 5$）加一个外部测试位"。

rank 控制由小坐标呈现命题 st:small-presentation（sections/stability.tex:116 起，我只读标题行）供给：真关系的检验只用 $\le 5$ 坐标，命题把 $H_n$ 表成"小坐标集上的关系"的群。[推测] 其构造细节（frame 引理 st:frames、线性代数引理 st:linear-algebra 的逐条使用）在我没读的 22-213 行之间。指派因此升到同态 $H_n\to\operatorname{Aut}(\St_n(R))$，在每个 Steinberg 生成元的像上是共轭；$z\in J_n$ 的矩阵像是单位元，作用平凡，故 $z$ 与一切交换（sections/stability.tex:278-283）。

论文在这节开头挂了两条出处账（sections/stability.tex:216-225）：忠实带论证是 Steinberg 稳定中心化证明（1967 文第 7 节定理 14）的有限秩形态；对本环而言中心性也落在 Voronetsky 半局部环定理（2021 文定理 1）的射程内，因为 $R$ 的非单位恰为 $I$（$1+a$ 可逆、幂零元不可逆），$R$ 局部、$M_n(R)$ 半局部。作者仍保留了带证明与明示的秩界，这段自陈让我读到一种取向：能用现成定理归约的部分照单声明，但主链上每一步都要在自己语言里可逐字验证。

商群引理 st:quotient（sections/stability.tex:286-313，读到 313 行）：$\E_n(R)$ 在 $H_n$ 中正规；$n\ge 5$ 时 inclusion 诱导 $H_n/\E_n(R)\cong H_{n+1}/\E_{n+1}(R)$。证法：杀掉初等生成元后所有交换词变平凡，共轭关系把各位置对角元并成一个 $d(u)$；剩下的关系全是从 $\le 5$ 坐标真关系删初等元、统一 $d_i(u)\to d(u)$ 得来，此清单与 $n\ge 5$ 无关。这条稳定同构是 §16 有理稳定性的前菜：商侧的秩无关性先立起来，核侧的有理上同调才开始爬。

## §16 有理稳定性：frame 复形、H_2 与 n≥12 的限制同构

声明在先：这一节的中间证明（sections/stability.tex:20-213 的 frame 装置、317-486 的中心扩张、487-694 的稳定化子同调）我只读了各引理标题行与最后两条命题的全文，[推测] 标签会密集出现；我依据的可引用文本是 prop:rational-stability 的证明（sections/stability.tex:704-711）与引言的路线自述（build/paper.tex:258-262）。

要证的话（prop:rational-stability，sections/stability.tex:696-702）：$n\ge 12$ 时沿 $J_n\to J_{n+1}$ 的限制映射
$$\Hom(J_{n+1},\Q)\longrightarrow\Hom(J_n,\Q)$$
是同构，尤其满射。注意对象是 $\Hom(-,\Q)$：因为 $J_n$ 交换（§15），这是把"核有没有非 torsion 元素"翻译成"有没有非零有理特征标"。§17 的下降全靠这个满射。

证明的三块拼图（引理标题给的骨架）：

1. frame 复形。单纯形的顶点集是"模 $I$ 约化后线性无关的列"的集合（build/paper.tex:258-259）。[推测] st:linear-algebra（sections/stability.tex:22）与 st:frames（sections/stability.tex:67）供的是该复形上稳定化子的传递性与高连通性，这是从 $n\ge 12$ 反推余维账的唯一入口：典型做法要求复形在某个连维度以上单连通，而矩阵群作用在帧形独立列集上的连通度随 $n$ 线性增长，12 应该是"稳定化子 $H_2$ 计算 + 谱序列边缘同态"闭合的最小秩。具体不等式我没读到，不敢落笔。
2. 中心扩张与 $\Q$-值。st:finite-splitting（sections/stability.tex:343）、st:extensions（sections/stability.tex:371）：[推测] 前者说有限扩张在特征与 $\Q$ 相容处分裂，后者把 $\Hom(J,\Q)$ 识别为中心 $\Q$-扩张类的群，从而限制同态对应限制扩张。prop:rational-stability 的证明原文（sections/stability.tex:704-708）逐字说："Proposition st:h2 与上文 bar-cochain 认同表明限制给出以 $\Q$ 为中心扩张类的双射；由 st:extensions，这正是所显示 Hom 群的限制。" 所以 606 行的 st:h2 是真正的主计算：稳定化子的 $H_2$（有理系数）在包含下同构，coinvariants 引理（sections/stability.tex:496）与 stabilizers 引理（sections/stability.tex:546）为它供弹药。bar-cochain 认同在 487-495 行附近建立：2-上循环用带 bar 记号的 cochain 表示，稳定映射的作用可以直接在链上核对。
3. 标准嵌入的记账。论文明说（build/paper.tex:261-262）：局部论证时刻跟踪标准嵌入；不要求任何稳定化映射在核上单射。我复核了这句在最终证明里的兑现方式（sections/stability.tex:476-477）：下降 $\varphi$ 时逐次用满射性延拓，从不反手用单射性，所以 $J_n\to J_{n+1}$ 是否有核与全局稳定同构是否成立都无关。这是我认为整节最值得学的一步，经典同调稳定性定理的结论强（同构），这里只消费其证明里"限制满射"这一侧，把装置要求砍掉一半。

## §17 核的 torsion：循环移位与截断移位的替换比较

kernel-torsion 章把 grading 变成武器。开场设定（build/paper.tex:264-279 与 sections/kernel-torsion.tex:1-33 标题；正文开场我只读了目录级信息，细节引用以 398-482 为准）：分次同态 $\gamma:R\to R[t]$，$a_b\mapsto a_bt^b$（$a_b\in R_b$）。取代表核元素 $u\in J_n(R)$ 的有限 root 词，逐条目应用 $\gamma$ 得 $u(t)$；$u(1)$ 代表 $u$，$u(0)$ 落在素域核 $J_n(\F_2)$ 里（sections/kernel-torsion.tex:413-417）。这套替换出现在 Weibel 分次 $K$-论的操作里（build/paper.tex:266-267 引 Weibel 1987 第 1 节 468-469 页），此处直接在 Steinberg 群里比较。

命题 kt:stable-torsion（sections/kernel-torsion.tex:406-466，证明读全）：$n\ge 6$、$u\in J_n(R)$，则 $u$ 在某个 $q\ge n$ 的标准坐标像于 $\St_q(R)$ 中是 torsion。

证明的链：设词有 $m$ 个 root 因子、条目最大次数 $d$。取 2 的幂 $N>2(m+1)\max\{1,d\}$（sections/kernel-torsion.tex:419-424），令 $W=W_u(C_N)\in\St_{nN}(R)$：把中心变量 $t$ 换成 $N\times N$ 数值矩阵 $C_N$（循环移位），每个 root 膨胀成一块 root（build/paper.tex:269-272）。两条评估路线在 Steinberg 群内相等：

- 循环侧。$C_N^N=\mathrm{Id}$ 且 $N$ 为 2 的幂，特征 2 下二项式恒等式给 $(C_N-\mathrm{Id})^N=0$；幂零线性映射在逐步核adapted基下上三角对角为零，故存在 $P\in\GL_N(\F_2)$ 使 $P^{-1}C_NP$ 上三角全 1 对角。块根定律 kt:block-laws（sections/kernel-torsion.tex:129，标题行）给两条评估 root 词之间的精确共轭；两边都属于 $J_{nN}(R)$，而该核中心（§15），共轭因此不动 $W$。三角评估 kt:triangular-evaluation（sections/kernel-torsion.tex:243）于是给
$$W=\prod_{s=1}^{N}\iota_s(u),$$
坐标置换 kt:permutations（sections/kernel-torsion.tex:77）把任一 $\iota_s(u)$ 共轭到任一另一个，中心化让它们彼此相等，故 $W=\iota_1(u)^N$（sections/kernel-torsion.tex:436-446）。
- 截断侧。把 $t$ 换成截断移位 $S_N$，行为像 $t=0$ 的评估（build/paper.tex:273-275）；wrap-removal 引理（sections/kernel-torsion.tex:274）说越过循环边界的 root 可以收进一条端点集不相交的带里，在那里矩阵映射忠实，于是循环代入与截断代入在 Steinberg 群本身相等（这条"两代入相等"是 kt:wrap-removal 的结论，我按标题行与 448-453 行的引用次序采信；带忠实性的正面陈述在 kt:triangular-faithfulness，sections/kernel-torsion.tex:186，[推测] 其逐坐标证明在 186-242 行我没读）。再用三角评估、对角取 0，得
$$W=W_u(S_N)=\prod_{s=1}^{N}\iota_s(u(0))$$
（sections/kernel-torsion.tex:448-453）。

## §18 主定理与 Kazhdan 推论的合成

主定理证明（sections/kernel-torsion.tex:484-499，读全）四行走完：取 thm:algebra 的 $R$，令 $G=\St_{12}(R)$；thm:finite-presentation（§13）给普通有限呈现；$\E_{12}(R)$ 无限因 $R$ 无限且单位置条目不同即矩阵不同（§14 完全性引理后半），故 $G$ 无限；$\E_{12}(R)$ 周期由 fp:matrix-periodicity（§14），任意 $g\in G$ 取 $a$ 杀掉其矩阵像得 $g^a\in J_{12}(R)$，kt:kernel-torsion（§17）给 $b$ 使 $(g^a)^b=1$。$G$ 即所求。四条义务在 18、14、14、17 各就各位，没有一个环节欠账。

Kazhdan 推论（sections/kernel-torsion.tex:501-520，读全）：$G$ 有性质 (T)。据 Ershov--Jaikin-Zapirain（2010 文定理 6.2）：任意有限生成幺结合环 $S$、任意 $n\ge 3$，$\St_n(S)$ 有 (T)（sections/kernel-torsion.tex:507-510）。适用性核对：thm:algebra 把 $R$ 呈现为有限生成元 $\F_2$-代数，$\F_2$ 是素域，生成元连同 $1$ 生成为环（sections/kernel-torsion.tex:504-507），取 $S=R$、$n=12$。非可均：若可均，F\o lner 集的归一化特征函数在 $\ell^2(G)$ 左正则表示中给几乎不变单位向量，(T) 给出非零不变向量；这样的向量在 $G$ 上为常数，无限群上非零常值不可求和，矛盾（sections/kernel-torsion.tex:514-520）。引言还交代了既有边界（build/paper.tex:115-118）：带 (T) 的无限有限生成周期群 Ershov 2008 已有且可残余有限（其文命题 8.4）；新东西是把周期性、(T) 与普通有限呈现合到同一个群。

台账最后一行记的就是这条依赖链的终点。

## §19 最终思路与最初设想的差异清单

[推测] 标签继续管住"最初设想"这一侧：论文没有自述心路，下面的"当初我以为"全部是我这个笔记视角的重构，能核对的只有正文文本。逐条对齐六个差异：

1. 一致指数到逐元有限阶。动手前我以为反例必须带统一指数（毕竟 Novikov--Adian 一路的荣耀在有界指数），正文第一页就把让步写在明处：元素的阶允许随元素变（build/paper.tex:95-96），代数侧同构地表现为"每个矩阵各自的幂零指标"（build/paper.tex:180-182）。放弃一致指数换来的是消去论证只要求"每条固定测试最终消失"，量词从"存在 $N$ 统一一切"松弛成"对每个测试存在 $N$"（sections/cancellation.tex:427-438），整个 §11 的停机结构就是这个松弛的工程化。
2. 从造群到造环。我以为主战场在群呈现的组合操作（小撤销理论那一路），实际主战场在一个 $\F_2$-代数，群只是 $\St_{12}$ 函子像。判定依据：五个章节文件里两个纯代数节（finite-rules、cancellation）合计约 82,000 字节，超过三个群论节之和；引言的"ring and four obligations"段（build/paper.tex:173-202）也直说环是全篇共用对象。
3. 逐词幂零到矩阵幂零。我起初以为两者一步互推，正文明示"建立矩阵性质与建立逐词像幂零是两个独立步骤"（build/paper.tex:184-185 的读法），并且为矩阵版本专门发明了带权重测试、切割归约、自动机升维三件套（§10 至 §11）。这里我承认最初的直觉错得典型：非交换展开里同一总长度的项来自不同因子数，按词长分层恰好是破局点（sections/cancellation.tex:49-54 的开篇吐槽与 $P_n(z)$ 的分层同出一源）。
4. 干净编码到一切被允许的词。我设想过只规范"由合法计算到达的状态"就够了，build/paper.tex:213-215 与 §9 的"反方向用回滚"共同否掉这个侥幸：伪造验证头的构型也在管辖内，办法是给它们也定切割与有界碎片，让它们进 token 解剖。
5. 稳定同构的单侧消费。我预备看到的是"$J_n\to J_{n+1}$ 同构"级别的定理，正文两次强调局部论证时刻跟踪标准嵌入、从不需要核上稳定映射的单射（build/paper.tex:261-262 与 sections/kernel-torsion.tex:464-465、481）。同调稳定性在这里被拆解零售：只买 $\Hom(-,\Q)$ 的限制满射。
6. 秩 12 是长出来的，不是挑出来的。我以为主定理里的数字是先选后证，实际它是三处下界的最大值：呈现 5（§13）、中心 6（§15）、Hom 满射 12（§16）。[推测] 12 内部的账（frame 复形连通度到谱序列闭合的确切不等式）在我没读稳的 606-694 行里，我对此只声明方向。

另记一条收获性的差异：前驱谱系在引言里被处理得很诚实。Durand--Romashchenko--Shen 给定点拼图的局部检验与变尺度模拟（build/paper.tex:210-213），Ivanov-Pogodaev 与 Kanel-Belov 给无限有限呈现幂零半群 $x^9=0$（build/paper.tex:216-221），两者都摆在我该站的位置上，缺的那块恰好是"任意矩阵和的消去"，由矩阵值词测试补上（build/paper.tex:221-225）。我从中提炼的写法是：前驱要引到它们没做到的那一条性质为止，引多引少都会失真。

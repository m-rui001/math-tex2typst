# 派单：C32 正文里的素材引用记号改文字指代（一张单，一份稿，88 处）

你是在飞的写手之一，本单是**定点改写单**，不是新稿单，也不是加深单。

## 缺陷定性（规格第 24 条）
`被引笔记/规格.md` 规定：**不抄素材的 `\label{}`／`\ref{}`／`\cite{}`／`\eqref{}` 进正文；要指代定理就用文字（"定理 3.1"）并给位置串。** 尺子实测这一族在 `被引笔记/C32-*.md` 有 **88 处**（代码跨度内的引述位不计，尺子已掩）。这些记号在页面上什么也不指——`\ref{key}` 不会编号，`\cite{key}` 不会出书目——所以它们是不合格的指代，不是可渲性问题。

## 做法（逐处）
自己定位：在该稿里搜 `\ref`、`\eqref`、`\cite`、`\label` 四种反斜杠记号，逐个处理。每一处：

1. 到本篇素材（`被引素材/<C32 的 arXiv id>/` 的 `.tex`）里找这个 key 的落点：`\label{key}` 在哪一个环境里（theorem／lemma／proposition／definition／equation／section），该环境的**作者自己给的编号或标题**是什么，行号是多少。
2. 把正文里那一处记号换成**文字指代＋位置串**：定理类写「定理 3.1（`main.tex:120-135`）」这样作者编号在前、实读行号在后；公式类写「式 (2.4)（`main.tex:88`）」；书目类（`\cite{key}`）按素材 bib 条目里的**原文署名逐字**写成「作者—年份（bib key 不必留）」。
3. 若某处 key 在素材里找不到对应 `\label`，**不许猜编号**：改成该陈述所在段落的位置串指代（「素材 `main.tex:300-312` 那一段」），并在报告里登记这一处。

形状要求：改完这一稿四种记号应为 **0 枚**（代码跨度内亦建议一并改为文字，但那里合法，不强制）；每处只改那一处指代所在的句子片段，**不许重排、重写、删改所在句的其余内容**；位置串必须是你这一笔实读的 `文件:行`。

## 硬条款（与 `被引笔记/规格.md` 同规，这里是本单参数）
1. 只动 `被引笔记/C32-*.md` 一份稿，且只动上述记号所在处。**其余已落盘内容不得删除、回改、重排**；发现别的缺陷写进报告，不要顺手改。
2. `Write` 工具使用次数 **0**；一律 `Edit`。单笔不超过 10,000 字节（红线 25,000）——站点多，分多笔做完，别堆成一笔。
3. 不得引入 CR（`\r`）；全篇 `$` 总数仍为偶、反引号总数仍为偶、逐行 `$` 枚数为偶；行数不得减少。
4. 素材私有宏按本篇 §0 换算表处理；`_work/`（本派单文件自身除外）、`研究笔记/`、`preprints/`、`.tools/`、`INDEX.md`、`队列台账.md`、`派单提示词.md`、`覆盖映射.md`、`next_batch.md`、其他 `D##`/`C##` 笔记、`lean/`、`formalization.yaml`、`records.txt` 一律禁读。
5. 素材只读 `被引素材/<本篇 id>/` 里的 `.tex`，**严禁读取任何 PDF、严禁 pdftotext**。
6. 不执行任何 git 命令（只读的也不要）。
7. 取证不设次数上限（88 处逐处对号是这单的本体），但单次读取不超过 400 行。

## 1. 初始动机与猜想: 我以为我在解一个什么问题

Lane-Emden 系统的整体正解问题, 我第一次上手时把它归进"先验估计类问题"。理由很朴素: 标量情形 Gidas-Spruck 的次临界 Liouville 定理 (01-introduction.tex:14-15 引用 GidasSpruck1981) 早已解决 -Δu = u^p 在 p 小于 Sobolev 极限时没有正整体解, 系统情形的未决部分, 按当时文献的排列方式, 像是"再啃一块硬骨头"。当时我对进攻点的想象有三条, 按我先想到的顺序:

其一, blow-up 反证。若有解, 在某种归一化下重缩放取极限, 极限对象应当是半空间或全空间的 Liouville 定理排除的对象。这条路在文献里确实活着: Polacik-Quittner-Souplet 移除增长条件、Souplet 解决四维, 走的都是精细的倍增与 blow-up 分析 (01-introduction.tex:17-21)。我最初以为加权情形只是把 |x|^A 塞进同一台机器。

其二, 移动平面与径向化为非径向。Bidaut-Veron--Giacomini 与 Phan 的理论是径向的 (01-introduction.tex:27-31), 猜想 C 问的是去掉径向对称。我一度以为存在某种"先证径向、再用球面向量升维或对称化"的桥。

其三, Rellich-Pohozaev 恒等式加区域截断。Mitidieri 的恒等式 (01-introduction.tex:16-18) 给出非存在区域, 我当时的计划是: 在 B_R 上做加权 Pohozaev, 令 R → ∞, 用散度定理里的 (n+A)、(n+B) 系数把临界双曲线的形状"读"出来。我以为最难的一步只是边界项的估计, 即让 Serrin-Zou 式的增长假设变成定理的推论。

问题的形式表述对我有诱惑力: 系统
-Δu = |x|^A v^p, -Δv = |x|^B u^q 在 R^n\{0} (01-introduction.tex:4-8),
只要 (n+A)/(p+1) + (n+B)/(q+1) > n-2 就没有处处严格正、原点连续、别处 C^2 的整体解, 且对无穷远处不加任何条件。这个陈述里假设薄到几乎没有: 正性、连续性、方程本身。我的第一反应是, 这么薄的假设, 一定得靠"从方程内部榨出衰减"的手段, 也就是先验估计路线; 现在回头看, 这个第一反应方向对了一半, 工具全错。

我还记得当时被两个数字硌了一下。第一个: n=5, p=q=4, A=B=3 满足加权次临界不等式, 而 1/(p+1)+1/(q+1)=2/5 < 3/5 (01-introduction.tex:86-91)。这说明加权陈述绝无可能被"在同一组指数上调用无加权陈述"推出, 权重带来的增益必须被某个机制直接吃到。第二个: 临界指标的分母是 p+1 和 q+1, 分子是 n+A, n+B, 而 n-2 恰好是 Newton 核 |x|^{2-n} 的齐次阶。这三个数字凑在一起, 我当时的猜测是 Pohozaev 系数 (n+A) 与核阶 (n-2) 的相消, 这个猜测后来确实对了, 但对它的实现完全出自我一开始没考虑的那台机器。

## 2. 尝试过的错误路线及失败原因

### 2.1 路线一: 移动平面, 死在平移不变性

加权算子 Δu - |x|^A 在平移下不变性彻底失去。移动平面要求对反射点 x_λ 比较 u(x) 与 u(x_λ), 而方程在反射后权重中心不动、函数中心动, 比较不等式的右端多出 |x|^A 与 |x_λ|^A 之比的坏项, 该项在越过权重奇性/衰减方向后符号失控。对 A 与 B 一正一负的大范围实权重, 连 Kelvin 型代换都无法把权重变成常数, 因为 |x|^A 的 Kelvin 变换只乘出另一个幂次的权重, 系统不闭合。断点非常具体: 在第一条"反证到第一个失效超平面"的标准流程的第一步, 弱极大值原理的系数项里就出现无法吸收的 (|x|^A/|x_λ|^A) 型畸变, 这与 Chen-Li 用 Newton 位势表示加移动平面的做法 (01-introduction.tex:98-99, 引 ChenLi2009) 依赖的可积性假设叠在一起, 更加无路。

失败迹象: 文献里所有用移动平面拿下的加权结果都停留在径向或低维 (01-introduction.tex:31-37 综述的 Fazly-Ghoussoub、Li-Zhang 等), 一旦非径向、高维、全实权重就集体沉默, 沉默本身就是信号。

### 2.2 路线二: 在 B_R 上直接做 Rellich-Pohozaev 然后 R → ∞, 死在边界项没有符号

这条路我用纸笔推过。乘子取 X = xη(x) 的经典版本 (η ≡ 1 于 B_R 内, 在 ∂B_R 附近截断), 恒等式会产生
∫_{B_R} (fu + gv) 量级的体项, 加上 ∂B_R 上的三类边界项: u 的法向导数二次项、v 的法向导数二次项、以及带权 (n+A)、(n+B) 的体项。无加权情形 Mitidieri 与 Souplet 用巧妙选取的测试函数把边界项压成体项的分数, 靠 pq 与 Sobolev 指标的关系闭合。加权后:

1. 散度算出来是 div(|x|^B X) = |x|^B((n+B)η - w) (这正是后来 03-localization.tex:119 那一行), 其中 w = -x·∇η 只在截断环带上非零。这意味着所有"系数"都被迫住在截断层里, 而我最初的 η 是硬截断, w 是分布, 根本没法进入不等式。
2. 让 R → ∞ 时, 我需要对 u, v 的梯度在 ∂B_R 上有先验控制, 而假设里没有任何无穷远处条件。Serrin-Zou 当年是"带增长条件"证三维的 (01-introduction.tex:18-19), 把增长条件删掉是 Polacik-Quittner-Souplet 的功劳, 他们依赖的工具在无界域上要求解的某种衰减或可积性, 在只有正性的情形同样落空。
3. 最致命的一条: 就算我愿意接受边界项作为代价, 经典 Pohozaev 的闭合形状要求"体项系数差"为正, 即恰好在次临界一侧为正; 但边界项与体项之比随 R 的单调性未知 (解可以震荡), 极限 R → ∞ 不存在可用的下界。断在"令 R → ∞ 取极限"那一步, 前面全对、最后一步没有落点。

失败迹象: 每次推到最后出现一个 sup_{∂B_R} 量, 没有任何假设能控制它; 而我隐约觉得, 猜想的陈述明说不要无穷远处条件, 那么证明里就不应该出现让解在无穷远处"表现良好"的环节。这个直觉后来变成了方法的骨架: 一切都在固定球 B_2 内完成, 让缩放去承担无穷远的责任。

### 2.3 路线三: blow-up + 冻结权重, 死在极限方程丢掉了 A, B

标准的重缩放反驳: 假设有解, 在点列 x_j 处放大, 取极限得整个 R^n 或半空间上的解, 再用无加权 Liouville 定理排除。在加权系统里, x_j 处放大时权重 |x_j + y/λ_j|^A → |x_j|^A (若 x_j 收敛到非零点) 或 → λ_j^{-A}|y|^A (若 x_j → 0 并适当选缩放率)。前一种冻结把权重变成正常数, 极限方程退化为无加权 Lane-Emden 系统, 于是可用的排除定理只在 1/(p+1)+1/(q+1) > (n-2)/n 的区域里说话 (01-introduction.tex:60-63 的形状)。可是加权次临界区域严格大于它, n=5, p=q=4, A=B=3 就是反例数字 (01-introduction.tex:87-90)。也就是说, 在非零点 blow-up 冻结权重的那一刻, 猜想声称存在的增益恰好被丢干净, 证明退回无加权陈述, 而 01-introduction.tex:91-93 明确写了: Phan 的迁移论证里"无加权输入必须留在它实际的适用范围内, 加权次临界性并不蕴含那个输入"。当时我没有这条文献线, 是自己撞墙撞出来的: 我在半空间极限与全空间极限里都拿不到矛盾, 因为残差方程里已经没有权重。

后一种向原点 blow-up 的缩放 (权重被吸进缩放率) 会改变系统系数, 极限仍是某种加权方程, 但我无法保证解列的紧致性, 假设里没有一致先验界, 又回到路线二的循环。

### 2.4 路线四: Emden-Fowler 径向 ODE 化 + 角度模态控制, 死在不知道零模占优

对径向解, 系统化为平面自治 ODE (Emden-Fowler 变换), 临界双曲线在相图里对应鞍-结分岔, 这条历史线在 Lane-Emden-Fowler 文献里很成熟 (§8 的外部检索部分会给出检索强度)。我一度想用"把非径向解投影到球面谐和, 证明零模满足一个带源的不等式组, 再用 ODE 比较"来绕过对称性。断点: 非线性 v^p 展开后, 零模方程的源项含高阶模态, 其符号由解自身决定; 对正解, 我需要的不等式恰好是我没有的先验界。这条路线没有"断在某行", 它断在我无法写出"零模控制的封闭系统"这一步。[推测] 若有某种凸性单调性把模态耦合压死, 此路或可通到 p, q ≥ 1 的受限区域, 与猜想要求的全部正 p, q 不符。

### 2.5 一个更早的小弯路: 测试函数法一步到位

Mitidieri 的非标准乘子 (K*g)^σ 类做法, 试图把 a priori 界与不存在性一次拿下。失败原因很机械: 加权系统的位势表示里, u 与 K*g 只差一个非负调和项, 在 n ≥ 3 时该项是常数, 常数可否为零恰是 Proposition 2.4 的中间结论 (02-preliminaries.tex:229, 258-266), 而它本身的证明需要质量上界; 用未证的界去证界, 循环。断的迹象: 我推出的不等式链里出现 E ≤ C E^{θ} 且 θ > 1 只在次临界之外的方向成立, 也就是说测试函数法天然给出的是"有界解"或"能量有限解"的非存在, 对无约束解给出的信息量随 pq 逼近 1 而蒸发, 与 Lemma 2.3 排除 pq ≤ 1 的角色纠缠在一起, 无法独立闭合。

## 3. 关键转折点: 压力项的符号问题与自适应帽的诞生

### 3.1 转折发生前的最后一天: 机器已经搭好, 缺一个符号

先把最终骨架摆出来, 再说哪一步是转折。全部论证是一台"能量收支机":

1. 相互作用测度 dπ(x,y) = f(x)g(y)K(x-y) dx dy, 边缘恒等式 π(dx, R^n) = f(x)u(x)dx (03-localization.tex:11-18), 总质量不假定有限;
2. 局域化 virial 恒等式 (Lemma 3.1): a(n+B)E_f + b(n+A)E_g - aW_f - bW_g = (n-2)∫Φ dπ (03:74-79);
3. 把 Φ(x,y) 换成 η(x) - w(x)D(x,y) 的误差是 εE + C_ε 级 (Lemma 3.2);
4. 于是要证的仅剩一条符号不等式: aW_f + bW_g - (n-2)∫w(x)D(x,y) dπ ≤ εE + C_ε (03:219-224 明说了这句话, 它就是全书的悬置句);
5. 这条不等式一旦成立, 与 γ = c₁ + c₂ > 0 联立即得 E 的一致界 (Proposition 6.1), 再以原点为中心的缩放 u_R = R^α u(Rx) 把 B₁ 能量放大成 R^{α+β+2-n} 倍 (02:322-325), 界与放大矛盾, 定理成立。

第 4 步里, W_f, W_g 住在截断环带 {1 < |x| < 2} 上, D(x,y) = ((x-y)·ω_x)²/|x-y|² 是"径向方向差的分量平方"。W 项与 T = ∫wD dπ 项的符号之争, 我把它命名为压力比较: W 是"径向膨胀对截断层做的功", T 是"相互作用核沿径向方向的张应力"。猜想需要 aW_f + bW_g ≤ (n-2)T + (容许误差)。这一步就是 Proposition 5.1, 整个证明最长的一节 (05-pressure.tex 全文 15270 B) 都在证它。

### 3.2 我在无帽版本上浪费的第一周

最初的自然做法: 固定一个方向 e ∈ S^{n-1}, 把 D(x,y) 与 D_e(x,y) = ((x-y)·e)²/|x-y|² 比较, 然后对 e 取球面平均。关系是 |D_e(x,y) - D(x,y)| ≤ 2|e - ω_x| (05:97 那行是我后来写下的, 当时推了很久)。问题在支撑: W 项住在整个环带上, 而要让 |e - ω_x| 小, e 必须靠近 ω_x, 即帽心随 x 变。若用固定 e 的帽 {θ: |θ - e| ≤ κ}, 则失配集 (帽外但 w > 0 的点) 上的误差与 E 之比不是 κ 的小量乘 C，是一个跟解相关的坏量, 因为帽外点的 W 贡献无法用帽内的 T 控制。断的迹象: 我推出的不等式形状是 aW_f + bW_g ≤ (n-2)T + C(κ)E + C_{κ}, 其中 C(κ) 与 κ 无关地下不去, 吸收失败。

### 3.3 诞生的那一刻: 帽半径取 d(x) 的一次方, dw ≤ Cη 收编误差

转折在 05-pressure.tex:22-25 那五行字里, 也就是论文自己承认的两个困难 ("平移不保持方程; 层端点值是 (t/|x|^B)^{1/q} ，并非 t^{1/q}") 的第二个的解法成形时刻。那晚我盯着失配集上的误差重读截断引理, 突然意识到: 帽的半径不该是绝对常数 κ, 而该与点到截断层的距离同阶。定义 d(x) = min{1, (2-|x|)_+} (03:37), 令帽半径为 κd(x)。这样一来:

1. 帽的归一化 Z(κd) ~ (κd)^{n-1} (弦极坐标计算, 05:44-49), 帽权 h_e(x) = w(x)ψ(|e-ω_x|/(κd(x)))/Z(κd(x)) 满足 E_e h_e(x) = w(x) 精确成立 (05:57);
2. 帽内点满足 |D_e - D| ≤ 2κd(x), 乘 w 后误差形状是 κ·∫d(x)w(x)f u dπ, 而 d(x)w(x) ≤ Cη(x) (03:54 的 dw ≤ Cη) 把它收编为 κE;
3. 之前卡住的"帽外失配"因为帽随 x 自适应缩到零而消失, 剩下的只是 h_e 的振荡误差, 又被同一个 dw ≤ Cη 收编。

那一刻的兴奋点在第三条: 我原以为要控制的是解在截断层附近的分布, 实际上要控制的只有截断函数自己的高阶平坦性。dw ≤ Cη 是截断构造 (03:38-42, 立方过渡带 + N 次幂) 白送的, 与解无关。误差由几何供给, 不由解供给, 这正是"无无穷远处条件"的可行实现方式。后来 Lean 里专门开了 AdaptiveCaps.lean (133 行) 和 CapWeights.lean (219 行) 伺候这个自适应帽, 名字就叫 adaptive, 机器把我当时的顿悟固化成了文件名。

### 3.4 第二步转折: 区间对引理是纯几何, 与方程脱钩

有了自适应帽, 还剩端点值 (t/|x|^B)^{1/q} 随 x 变的问题。第二个转折发生在把这个问题从 PDE 里剥离出来的一刻: 沿固定方向 e 的直线 x + Re 上, 层集 {f > t} 的连通分支 I 上, 位势的端点平均 K̄_I 与核的体平均 K 之间的关系, 只依赖两件事: 牛顿核在两条平行线上的限制 (λ² + h²)^{(2-n)/2}, 以及区间重叠长度对 h 的对称单调分布 (04:115-123 的 ρ(h) = F(|h - d₀|))。方程、权重、解, 一概不进这条引理。它是 Lemma 4.1, 全文最短的一节 (04-intervals.tex 5878 B)。

这一剥离的价值在三天后才显出来: 我在 Lemma 4.1 里看到 min(c_I, c_J) 前面挂的系数恰好是 (n-2), 与 virial 恒等式右端的 (n-2) 同形。当时立刻意识到这是同一台机器的两个齿轮: (n-2) 是 Newton 核的齐次阶, virial 侧它乘 Φ, 区间侧它乘 D; Φ 在近距离的 Taylor 展开首项就是 η - wD。压力比较的符号之所以在我最初担心的意义上"应该对", 深层原因在这两个 (n-2) 同源。断的迹象此前表现为: 我曾用 Sobolev 极限核 (n-2 阶以外的齐次核) 试过同类比较, 系数对不齐, 吸收必然失败; 换回牛顿核, 两端系数自动吻合。

## 4. 最终思路与最初设想的差异

三条本质差异。

差异一: 责任分配。我最初设想让解负责衰减 (blow-up、增长条件、可积性, 全是在向解索取无穷远处的信息); 最终证明里解只负责正性与连续性, 全部"衰减"由截断函数的高阶平坦性 (N = n² + 5n + 2 次幂的立方过渡带) 与缩放群 (u_R = R^α u(Rx) 保持方程不变) 承担。远场信息换成原点缩放, 这是陈述里"无无穷远处条件"在证明内部的对应物。01-introduction.tex:124-128 那段 ("所有误差相对一个固定的局域能量任意小……次临界间隙随后供给这个界") 就是这个责任分配的自白。

差异二: 对象层级。我最初在函数层面工作 (u, v 的先验估计); 最终机器工作在测度层面: π 是 R^{2n} 上的相互作用测度, 层集是 (x, t, e) 联合可测的区间族, Tonelli 全程只作用于非负被积函数、先验有限性逐处显式核验 (05:281-299 专门写了一整段"在做任何减法之前验证有限性", 因为 n = 3 时无界区间上核积分发散, 04:144-147)。无加权文献里"平移不变所以一切自动一致"的舒适区被换成了"中心固定在原点、球质量有界"这一条廉价替代品 (02:294-297 明说: 后文用到的小球质量只从固定中心球 B₄ 的质量界借用, 不需要任何平移)。

差异三: 常数的性质。我最初以为会出现一个依赖解的最终常数; 最终结构是"误差对任意固定解是 εE + C_ε, 而 C_ε 只依赖方程参数" (01-introduction.tex:124-126: " obtaining the error estimates 时不假定该能量的任何界")。这句话是整个证明能闭合的逻辑前提: 先有 εE + C_ε 型的相对小误差 (误差界不依赖 E 的界), 再由间隙 γ > 0 生产 E 的界, 再由缩放矛盾杀解。若顺序颠倒 (先试图界 E 再证误差小), 就是循环论证。我最初路线全部死在这条逻辑线被剪断的地方, 而最终路线是围着这条线设计的。

还有一处小差异值得记录: 我最初以为临界双曲线的证明会经由"能量泛函的缩放不变性"给出 (Sobolev 极限指标的常规生产方式: 检验泛函在缩放群下的行为, 阈值出现在不变性破缺处)。最终证明确实消费了缩放, 但生产阈值的位置在别处: 双曲线形状出现在 γ = (1-a-b)(α+β+2-n) 这条恒等式 (02:308-315) 的两侧, 一侧供给能量不等式的正系数 c₁ + c₂ = γ, 另一侧供给缩放矛盾的放大率 α + β + 2 - n > 0。同一个不等式喂两台机器, 这是最初没预料到的经济性。[推测] 这种"一 Gap 两用"的结构可能是它绕开所有单侧工具的根源。

### 5.1 Theorem 1.1（主定理）

(a) 01-introduction.tex:44-56 逐字: "Let \(n\ge2\) be an integer, let \(p,q>0\), and let \(A,B\in\R\). Suppose that ... \frac{n+A}{p+1}+\frac{n+B}{q+1}>n-2. ... There are no functions u,v\in C^2(\R^n\setminus\{0\})\cap C(\R^n), u(x)>0, v(x)>0 (x\in\R^n), satisfying Equation~\eqref{eq:system} at every x\ne0."

(b) 推导链条完整展开: 假设存在这样的 (u,v)。Lemma 2.1 给出 n ≥ 3 与 A, B > -2; 随后 Lemma 2.3 给出 pq > 1; 于是参数 α, β, a, b (02:200-206) 良定且 α, β > 0, 缩放族 u_R = R^α u(Rx), v_R = R^β v(Rx) 仍逐 R 是同一方程的解 (02:211-219)。次临界不等式按定义等价于 γ > 0, 恒等式 γ = (1-a-b)(α+β+2-n) 与 1-a-b > 0 给出 α+β+2-n > 0 (02:308-319)。Proposition 6.1 给出对所有解一致成立的 E 界, 从而 (u_R, v_R) 的 B₁ 能量 ≤ C 对一切 R 成立; 换元恒等式 (02:322-325) 说 B₁ 能量等于 R^{α+β+2-n} 乘原解的 B_R 能量, 后者在 R ≥ 1 时 ≥ B₁ 能量的固定正值, 于是放大率把界冲爆 (06:58-81), 矛盾。

(c) 机械理由逐门核对:
- n ≥ 2 出现在陈述而证明里立刻收紧为 n ≥ 3: 因为 n = 2 的排除靠对数障碍 (Lemma 2.1(b) 段), 该步只消费正性与连续性, 不消费 γ; 陈述写 n ≥ 2 是为了让猜想的维度范围不被证明技术截短。
- p, q > 0 全部正指数都被消费: Lemma 2.2 的源局部可积与 C¹ 正则性、Proposition 2.4 的质量界论证 "uses only positive powers, requires neither p≥1 nor q≥1" (02:255-256)、Lemma 2.3 的除法 m_u^{pq} > 0。任何 p ≤ 0 会同时毁掉"源严格正"与"位势表示"两件事。
- A, B ∈ R 任意实数: 陈述不预支 A, B > -2, 那是定理内容的一部分 (Lemma 2.1), 这样加权陈述覆盖无加权 Corollary 1.2 的推广方向, 也配合 §3.2 里"权重奇性/衰减自动被排除"的叙述。
- 假设类 C²(R^n\{0}) ∩ C(R^n): 原点不要求可微。它的消费点在 Lemma 2.1 的 flux 极限论证 (有界球均值对 r^{1-n} 发散积分的抵抗) 与 Lemma 2.2 的分布延拓 (在 ρ → 0 时边界项 ρ^{n-1}, ρ^{n-2} → 0, 02:109-111)。若假设只在原点连续而不正 (u(0) = 0 允许), 则 v(0) > 0 给出的源下界 v^p ≥ c 失效, Lemma 2.1 的 A > -2 推不出。
- 阈值 (n+A)/(p+1) + (n+B)/(q+1) > n-2 的生产: 分子 n+A, n+B 由 div(|x|^A x) = (n+A)|x|^A 生产 (加权散度的"有效维度"), 分母 p+1, q+1 由 u^q ∇u = ∇(u^{q+1}/(q+1)) 的原始生产; n-2 由 ∇K(z) = -(n-2) zK(z)/|z|² 的齐次阶生产 (03:131)。三者在 virial 恒等式里相遇, 形状恰为 a(n+B)E_f + b(n+A)E_g - (n-2)·(Φ 积分)。注意配对是交叉的: a = 1/(q+1) 配 n+B 挂在 E_f 上, 因为 f = |x|^B u^q 是 v 方程的源、能量密度 fu 里的 B 来自 f 自己的权重 (细节在 5.7 的 (b) 段)。
- 左右两半边各自的消费者: γ 的"能量侧"半边 c₁ = a(n+B)-(n-2) 与 c₂ = b(n+A) 之和喂 Proposition 6.1 的吸收 (c₁+c₂ = γ > 0 是 γE/2 的来源); "缩放侧"半边 α+β+2-n = γ/(1-a-b) > 0 喂最后的发散。若只有 γ > 0 而 1-a-b < 0 (即 pq < 1, 不可能, 已被排除), 两侧同号性断链, 这正是 Lemma 2.3 存在的逻辑位置。

(d) [推测] 失败路线一: 试图用 u(0) 处某种隐式可微性代替"仅连续"假设, 会引入 v(0) 的消失率假设, 陈述被削弱且 Phan 的径向存在性端点 (临界双曲线上的 ground state 只连续) 将无法对接, Corollary 6.2 失效。[推测] 失败路线二: 若阈值取非严格 >, 缩放矛盾中 B_R 能量下界只是非负, 放大率 R⁰ 不爆, 证明在 06:76-77 那两行断掉, 严格性与"正值下界"的耦合无法解绕。[推测] 失败路线三: 把陈述放宽到半空间或外区域版本, 缩放不再保持定义域, u_R 不再是容许解, Proposition 6.1 对缩放族一致适用的前提消失。

### 5.2 Corollary 1.2（无加权 Lane-Emden 猜想）

(a) 01-introduction.tex:58-68 逐字: "For every integer \(n\ge3\) and \(p,q>0\) satisfying \frac{1}{p+1}+\frac{1}{q+1}>\frac{n-2}{n}, there is no strictly positive \(C^2(\R^n)\) solution of -\Delta u=v^p, -\Delta v=u^q in \R^n."

(b) 代入 A = B = 0 于 Theorem 1.1: 阈值变 n/(p+1) + n/(q+1) > n-2, 两边除 n 得陈述形状; 解类上 C²(R^n) ⊂ C²(R^n\{0}) ∩ C(R^n), 权重 |x|⁰ ≡ 1 使方程在全空间逐点成立, 原点连续自动。

(c) 为什么 n ≥ 3: A = B = 0 时 Lemma 2.1 的 n = 2 排除 (02:42-45) 独立给出无加权二维情形也没有解, 但二维的 (n-2)/n = 0 让阈值形状退化, 陈述按经典文献习惯限定 n ≥ 3 与历史口径对齐 (01:17-21 的 Serrin-Zou、Polacik-Quittner-Souplet、Souplet 线)。01:86-90 的反例数字 n=5, p=q=4, A=B=3 说明该推论方向上是严格弱化: 加权定理的适用范围在无加权切片的严格外部, 反向代入不成立, 所以"由推论迁回主定理"的路 (Phan 式迁移) 是坏的, 见 5.2(d)。

(d) [推测] 失败路线一: 想用 Corollary 1.2 加权重微扰 (A, B 小) 做连续性论证覆盖小权重区域: 解空间不是紧的, 无先验界, 摄动无落脚点。[推测] 失败路线二: 借助无加权四维已解结果 (Souplet 2009) 逐维拼装加权版本: 拼装需要跨维归纳接口, 而 virial 机器逐维独立, 无归纳结构可用。

### 5.3 Lemma 2.1（原点归约）

(a) 02-preliminaries.tex:16-18 逐字: "The existence of a solution implies \(n\ge3\) and \(A,B>-2\)."

(b) 完整推导: ① 球均值 h̄(r) = (1/|S^{n-1}|)∫_{S^{n-1}} h(rθ) dθ, 在环带上对方程积分得 flux 恒等式 (r^{n-1}ū'(r))' = -r^{n-1+A} v̄ᵗᵖ(r) (02:26-33), 右端严格负 (源正), 故 flux F(r) := r^{n-1}ū'(r) 严格递减。② F 递减故 r ↓ 0 极限 L 存在 (可为 -∞ 或有限)。若 L ≠ 0, 则小 r 处 |F| ≥ c > 0 定号, ū'(r) ≤ -c r^{1-n}, 积分 ū(r) ≤ ū(r₀) - c∫_r^{r₀} s^{1-n} ds, 而 ∫₀¹ r^{1-n} dr = ∞ (n ≥ 2), 与 ū(0) = u(0) 有限矛盾 (球均值在 0 的有界性来自连续性假设)。故 L = 0, 且 F(r) < 0 对一切 r > 0。③ n = 2: F(r) = rū'(r) 递减且 F(1) < 0, 故 r ≥ 1 时 rū'(r) ≤ F(1), ū'(r) ≤ F(1)/r, ū(r) ≤ ū(1) + F(1) log r → -∞, 与 u > 0 矛盾。④ A 的下界: 由 v(0) > 0 与连续性, v ᵖ ≥ c 于 B₁, flux 恒等式在 [r/2, r] 上积分并用 F(r/2) < 0: -ū'(r) ≥ c r^{1-n} ∫_{r/2}^r s^{n-1+A} ds。计算: ∫_{r/2}^r s^{n-1+A} ds = r^{n+A}∫_{1/2}^1 t^{n-1+A} dt, 当 n+A ≠ 0 时该括号 = (1 - 2^{-(n+A)})/(n+A) > 0 (n+A > 0 由解存在正在下面反证; 若 n+A < 0 则积分值为正、方向仍给下界), 得 -ū'(r) ≥ c_A r^{1+A}; n+A = 0 时 ∫ = log 2, 同型下界成立 (02:55-56 专门交代)。若 A ≤ -2, 则 1+A ≤ -1, ū(r) ≥ ū(r₀) + c_A∫_r^{r₀} s^{1+A} ds → +∞ (r → 0), 与 u 在原点连续矛盾。u 与 v 交换得 B > -2。

(c) 常数与阶的机械理由:
- "flux 极限 = 0"是全链条的地基: 它把无原点的方程转成带符号的一维积分不等式; 消费它的下一步是 n=2 对数障碍与 A > -2。r^{1-n} 的发散阶恰好与"仅连续"假设打架, 这是假设类被机器反向塑造的实例: 若允许 u(0) = +∞ (可去奇性), 此引理整体失效, 而猜想也失效 (Kelvin 型奇异解存在)。[推测] 这就是陈述里"原点连续"不可删的机制根源。
- 临界值 -2 的生产: r^{1+A} 对 r 积分的收敛阈值 1+A > -1, 即 A > -2。它与"|x|^A 在 0 附近 Lebesgue 可积"的阈值 n+A > 0 不同, 更严 (n ≥ 3 时 -2 > -n 当 n ≥ 3)。所以"可积性允许 A ∈ (-n, -2] 而解存在性只允许 A > -2", 差额正是被本引理消费掉的信息。下游消费者: 02:61 起 "Henceforth assume n≥3 and A,B>-2", Proposition 2.4 的质量论证、Cap 支撑环带上 |x|^A 可积 (03:66-69) 都只依赖 A,B > -2。
- n=2 排除用的 F(1) < 0 来自第②步"flux 处处严格负", 两步串联的顺序不可换。

(d) [推测] 失败路线一: 用次调和函数的 Bôcher 定理替代 flux 论证直接得 A > -2: Bôcher 给的是 -Δu ≥ 0 的奇性分级, 需要 u 的球均值有下界而不仅是有限, 假设换不动。[推测] 失败路线二: 对非径向解试图逐模态应用 flux: 高阶模态的 flux 变号, 只有零模 (球均值) 的符号由源的正性垄断; 这条路把我拉回 5.2(d) 之外的"零模支配"幻觉。[推测] 失败路线三: n=2 情形改用复分析 (全纯对数坐标), 系统非线性破坏共形不变, 死在第一行。

### 5.4 Lemma 2.2（分布延拓与位势）

(a) 02-preliminaries.tex:74-99 逐字 (关键句): "the sources \(f,g\) belong to \(L^1_{\mathrm{loc}}(\R^n)\) and -\Delta u=g, -\Delta v=f in distributions on \R^n. The Newton potentials are finite everywhere and satisfy K*g\le u, K*f\le v on \R^n. There are constants c_u,c_v\ge0 such that u=c_u+K*g, v=c_v+K*f almost everywhere... On the latter set the potentials are continuously differentiable, and \nabla u(x)=\int\nabla K(x-y)g(y)dy... Both gradient integrals converge absolutely at every x\ne0."

(b) 六步推导补齐:
① 局部可积: u, v 连续故在 B₁ 上有界, g(x) ≤ C|x|^A, ∫_{B₁}|x|^A dx = |S^{n-1}|/(n+A) 有限 ⟺ n+A > 0, 由 A > -2 与 n ≥ 3 得 n+A > 1。f 同理。
② 分布延拓: 取 φ ∈ C_c^∞(R^n), ξ ∈ C_c^∞ 在 0 附近为 1, 用测试函数 φ(x)(1-ξ(x/ρ)) 代入 R^n\{0} 上的经典方程。莱布尼茨展开多出两块: 2∇φ·∇(1-ξ_ρ) 与 φΔ(1-ξ_ρ)。∇ξ(x/ρ) 的幅度 ρ^{-1} 乘支撑环带 {ρ≤|x|≤2ρ} 的体积 ρ^n 得 ρ^{n-1}; Δξ(x/ρ) 同理得 ρ^{n-2} (02:109-111 的阶)。u 有界, 两块 → 0 (n ≥ 3)。其余项由①的可积性控制收敛, 得 ∫uΔφ = ∫gφ 对一切 φ, 即 -Δu = g 于 D'(R^n)。
③ 下界 K*g ≤ u: 磨光 u_ρ = u*ζ_ρ (ζ_ρ 非负磨光核), 则 u_ρ > 0 且 -Δu_ρ = g_ρ ≥ 0 全空间。对任意心 x 两次积分球均值 flux 公式: u_ρ(x) - ⨍_{S}u_ρ(x+Rθ)dθ = c_n∫_{|x-y|<R}(|x-y|^{2-n} - R^{2-n})g_ρ(y)dy (该式是球均值 Poisson-Jensen 恒等式, 系数由 ④ 的归一化决定)。左端球均值 ≥ 0 丢掉, R → ∞ 时被积函数单调升 (R^{2-n}↓0), 单调收敛给 c_n∫|x-y|^{2-n}g_ρ = K*g_ρ ≤ u_ρ。ρ → 0: u_ρ(x) → u(x) (逐点连续), g_ρ → g a.e., Fatou (非优势收敛! 没有先验可积控制) 给 K*g(x) ≤ u(x) 处处。
④ -ΔK = δ₀: K 在 0 外调和; 通量 -∫_{∂B_r}∂_r K dS = -c_n(2-n)r^{1-n}·|S|r^{n-1} = c_n(n-2)|S| = 1 (这正是 c_n = 1/((n-2)|S|) 被选的唯一下落); 边带项 ∫_{∂B_r}K dS = O(r) → 0。在 R^n\B_r 分部积分令 r → 0 得断言。
⑤ 表示式 u = c_u + K*g: 先验证 ∫g(y)∫K(x-y)|Δφ(x)|dxdy = ∫(K*g)|Δφ| ≤ ∫u|Δφ| < ∞ (把 ③ 的不等式塞进 |Δφ| 加权), Fubini 合法化, 得 -Δ(K*g) = g 于 D' (在无界源上的卷积分配律经由该绝对可积性绕开了通常的紧支撑假设)。h = u - K*g ≥ 0 且调和分布。h*ζ_ρ 是非负整体调和函数 H; 均值性质 + 球包含 B_R(x) ⊂ B_{R+b}(z) (b = |x-z|) 给 H(x) ≤ ((R+b)/R)^n H(z), R → ∞ 得 H(x) ≤ H(z), 换 x, z 得等, H 常数; 回到分布 h = c_u ≥ 0。
⑥ 0 外的 C¹ 与梯度表示: 固定 x₀ ≠ 0。源在 x₀ 附近是 C¹: u, v 在该邻域严格正且连续, t ↦ t^p 在 t > 0 上 C¹, x ↦ |x|^A 在 0 外 C^∞。用光滑截断把 g 分成近端 (紧支) 与远端。近端: |∇K(z)| ~ |z|^{1-n} 在 n ≥ 2 局部可积 (极坐标 ∫r^{1-n}r^{n-1}dr 有限), 紧支 L¹ 源与 ∇K 卷积给出 C¹ 与可交换求导。远端: x 在 x₀ 小邻域内时 |x-y| ≥ |x₀-y|/2 > 0, 比值 r^{1-n}/r^{2-n} = 1/r 在该支撑上有界, 故 |∇K(x-y)| ≤ CK(x₀-y); K(x₀-y)g(y) 可积由 ③ 于 x₀ 处取值; 控制收敛完成。

(c) 每个常数的去向: c_n 的生产与消费全在 ④, 通量恒等式 (r^{n-1}ū')' 的系数在 ③ 复用; ρ^{n-1}, ρ^{n-2} 两阶的消费条件是 n ≥ 3, 若 n = 2 则 ρ^{n-2} → 1 不消失, 分布延拓断 (这解释了为何猜想陈述 n ≥ 2 而机器从 n ≥ 3 起转)。K 的阶 2-n 是全部指数的种子: 球下界 u ≥ cR^{2-n}∫_{B_R}g (02:171-174) 与质量增长 R^{n-2-β} 相乘得缩放不变; ∇K 的 -(n-2)zK/|z|² (02:95) 直接向 virial 恒等式右端输出因子 (n-2), 即阈值里 n-2 的物理来源。c_u, c_v 在本引理里只被证明存在, 它们归零的消费在 Proposition 2.4, 这是"常数项是活的隐患"的标准处置: 先证表示式, 再另案处决。
临界指标两侧在本引理的分工: 还没进入 γ, 但 n+A > 0 与 A > -2 的差额 (5.3(c)) 在这里变成"f, g ∈ L¹_loc"的最低消费; p, q > 0 在 ⑥ 的 t^p 可微性上被消费, 若 p < 1 且允许 v = 0, 复合函数 C¹ 断链, 幸而假设严格正。

(d) [推测] 失败路线一: 跳过 ③ 直接用位势论的 Riesz 分解 (超调和函数 = 位势 + 调和): 结论形态相同但调和项非负性需要逐点论证, 与 ③ 等价, 而 ③ 的单调收敛 + Fatou 组合是可机器化的最少假设路径; 若改用 L^p 位势估计会引入对源的全局可积假设, 陈述被削弱。[推测] 失败路线二: 把 ⑤ 的 Liouville 论据换成"非负调和函数梯度的 Harnack 不等式": 可行但依赖更深的定理, 在 Lean 里 (Harmonic.lean, 147 行) 反而要走更多 Mathlib 接口。[推测] 失败路线三: 在 ⑥ 里试图证明位势在整个 R^n\{0} 上 C² 以便经典地做散度: 源只在 0 外 C¹, 二阶导数需要源的 Lipschitz, 假设到不了; 证明只需要 C¹ 位势加分布恒等式, 贪多会断。

### 5.5 Lemma 2.3（小乘积排除）

(a) 02-preliminaries.tex:177-179 逐字: "A solution with \(n\ge3\) and \(A,B>-2\) necessarily has \(pq>1\)."

(b) 推导补齐: m_u(R) = inf_{B_R}u, m_v(R) = inf_{B_R}v > 0 (正 + 连续 + 紧)。球下界 (02:171-174) 于 x ∈ B_R: u(x) ≥ cR^{2-n}∫_{B_R}g ≥ cR^{2-n}m_v(R)^p∫_{B_R}|x|^A dx = cR^{2-n}·[|S|/(n+A)]R^{n+A}·m_v^p = c'R^{2+A}m_v^p。取 inf 得 m_u ≥ cR^{2+A}m_v^p; 交换得 m_v ≥ cR^{2+B}m_u^q。复合: m_u ≥ c'R^{2+A}(c''R^{2+B}m_u^q)^p = cR^{2+A+p(2+B)}m_u^{pq}, 两边除 m_u^{pq} > 0: m_u(R)^{1-pq} ≥ cR^{σ}, σ := 2+A+p(2+B)。σ > 0 无条件成立 (A > -2, B > -2 且 p > 0)。若 pq < 1: 1-pq > 0 且 m_u(R) ≤ m_u(1) ≤ u(0), 左端 ≤ u(0)^{1-pq} 为常数, 右端 → ∞, 矛盾。若 pq = 1: 左端 ≡ 1 < cR^σ (大 R), 矛盾。故 pq > 1。

(c) 机械理由: 阈值 pq = 1 是超线性系统的普适门槛, 此处由 m_u 幂次 1-pq 的符号翻转生产; 与临界双曲线的接口在 α 的定义 σ = α(pq-1) (02:202): pq > 1 使 α, β > 0 分母为正, 分子 σ, 2+B+q(2+A) 均正。α, β > 0 的下游消费者: Proposition 2.4 的圆环几何级数 2^{-jβ}, 2^{-jα} 收敛 (02:272-275)、缩放 u_R = R^α u(Rx) 的正幂性 (R → 0 或 ∞ 都合法)。若 pq ≤ 1 被允许, 级数发散方向改变, 一致界论证整体失效。交叉恒等式 pβ = α+2+A, qα = β+2+B (02:207-210) 由定义直接展开验证, 它们是 5.6(c) 里处决 c_u 时 n+B-(n-2-β) = B+2+β = qα 的算术骨架。
本引理对临界指标的生产没有贡献, 它的角色是清场: 保证 a + b < 1 (即 1-a-b = (pq-1)/((p+1)(q+1)) > 0, 02:313), 从而 γ 与 α+β+2-n 同号, "一 Gap 两用"的等价性成立。

(d) [推测] 失败路线一: 用测试函数法证 pq > 1 的更强先验 (如质量间隙): 需要 p, q ≥ 1 的凸性, 假设只有 p, q > 0。[推测] 失败路线二: 试图从临界双曲线自身推出 pq > 1: 方向反了, 双曲线在 n ≥ 3 时确实蕴含 pq > 1 (06:101-112 的推论证明), 但那用于 Corollary 6.2 的存在侧, 不能倒灌进主定理的归约链, 主定理的 γ 假设可以小到 pq 逼近 1 之上任意近, 依赖的是这里的一致论证。

### 5.6 Proposition 2.4（一致中心估计）

(a) 02-preliminaries.tex:222-242 关键句逐字: "There is a universal constant \(C\) such that every solution satisfies, for all \(R>0\), \int_{B_R}f\le CR^{n-2-\beta}, \int_{B_R}g\le CR^{n-2-\alpha}. The constants in \eqref{eq:potential-constants} vanish, so that u=K*g, v=K*f... \int_{B_4}(f+g+u+v)\le C, \int_{|x-y|\ge\ell}K(x-y)(f(y)+g(y))dy\le C\ell^{2-n} (x\in B_2, 0<\ell\le1)."

(b) 推导补齐五步:
① B₁ 质量自举: 球下界取 R = 1: x ∈ B₁ 时 u(x) ≥ c∫_{B₁}g = cM_g, 故 f(x) = |x|^B u^q ≥ c|x|^B M_g^q 于 B₁, 积分 M_f ≥ c_f M_g^q; 交换 M_g ≥ c_g M_f^p。复合: M_f ≥ c_f(c_g M_f^p)^q = c_fc_g^q M_f^{pq}。M_f > 0 (源在 B₁ 上正, 因为 u > 0) 且 pq > 1 给 M_f^{pq-1} ≤ c_fc_g^q, 即 M_f ≤ (c_fc_g^q)^{1/(pq-1)} = C。M_g 对称。全程只用正幂与逐点下界, 这就是 02:255-256 "requires neither p≥1 nor q≥1" 的机械含义。
② 缩放搬运: (u_R, v_R) 仍是同参数解, 故 ∫_{B₁}f_R ≤ C。换元 (02:215: f_R(x) = R^{β+2}f(Rx)): ∫_{B₁}f_R = R^{β+2}∫_{B₁}f(Rx)dx = R^{β+2-n}∫_{B_R}f, 得 ∫_{B_R}f ≤ CR^{n-2-β}; g 用 α。
③ 处决常数项: 若 c_u > 0, u ≥ c_u a.e., 则 ∫_{B_R}f ≥ c_u^q∫_{B_R}|x|^B = c_u^q|S|/(n+B)·R^{n+B}。与 ② 比较: 要求 n+B ≤ n-2-β, 即 B+2+β ≤ 0; 但 B+2+β = qα > 0 (交叉恒等式 02:209 加 α > 0, q > 0)。矛盾, c_u = 0; c_v 同理。等式在 a.e. 成立经 5.4⑥ 升级为 0 外逐点。
④ B₄ 上 u, v 的积分界: 把源分 B₈ 内/外。外 (圆环 2^j ≤ |y| < 2^{j+1}, j ≥ 3): x ∈ B₄ 时 |x-y| ≥ 2^{j-1}, 核 ≤ C2^{j(2-n)}, 环质量 ≤ C2^{(j+1)(n-2-β)}, 乘积 ≤ C'2^{-jβ}, 几何级数收敛 (β > 0, 消费者之一)。内 (y ∈ B₈): sup_{y∈B₈}∫_{B₄}K(x-y)dx ≤ ∫_{B₁₂}K(z)dz < ∞ (可积性 ⟺ 2-n > -n 恒真, 且 |z| < 12 上 K 的原点奇性 ∫r^{2-n}r^{n-1}dr = ∫r dr 有限), Tonelli 交换积分次序得 ∫_{B₄}∫_{B₈}K(x-y)f(y)dydx ≤ C∫_{B₈}f ≤ C。源部分 ∫_{B₄}(f+g) 由 ② 直接。
⑤ 尾部界: 在 {|x-y| ≥ ℓ} 上 K ≤ c_nℓ^{2-n}, 故 y ∈ B₈ 部分 ≤ c_nℓ^{2-n}∫_{B₈}f ≤ Cℓ^{2-n}; y ∉ B₈ 部分已被 ④ 圆环和界住 ≤ C ≤ Cℓ^{2-n} (ℓ ≤ 1, n ≥ 3 时 ℓ^{2-n} ≥ 1)。

(c) 机械理由与临界指标的生产关系: 指数 n-2-β, n-2-α 是"源在球内的有效质量维": n 减去核阶 2-n 再减去非线性幂次的缩放收益 β。它们与 γ 的关系: n-2-β + n-2-α = 2(n-2) - (α+β), 而 α+β+2-n 与 γ 同号 (02:308-315), 于是"质量增长指数之和 2(n-2)-(α+β) < n-2 ⟺ γ > 0 ⟺ 两团源的质量增长之和低于 n-2 阶"。这正是我说的"一 Gap 两用"的第一用: γ > 0 使缩放后的 B₁ 能量 (02:322-325 的 R^{α+β+2-n}) 放大, 而其等价形式保证中心估计系列彼此兼容。尾部界 (第二个估计) 的唯一下游是 Lemma 3.2 与 5.1 的远对估计, 它把"远处源对截断层 x ∈ B₂ 的吸引"压成 ℓ^{2-n} 的显式幂, 让 d 的正幂指数 4n+7, 3n+5 有资格被 ∫_{B₂}f ≤ C 吸收。半径 1, 2, 4, 8, 12 全部是截断支撑 B₂ 的嵌套倍率, 无独立角色; 真正被消费的几何事实是 02:294-297 明说的那条: 一切小球质量都从固定中心球借用, 平移不变性从未被要求, 这正是权重 |x|^A 存活的前提。

(d) [推测] 失败路线一: 想要 B_R 质量的更锐利阶 (比如带 log): ② 的缩放论证天然给出精确幂律, 任何锐利化都必须引入新信息 (解的增长假设), 违背陈述。[推测] 失败路线二: 若 pq → 1⁺, C ~ (c_fc_g^q)^{1/(pq-1)} 爆炸: 有人可能想改进 ① 的自举让 C 一致到 pq = 1: 与 Lemma 2.3 的 R^σ 发散矛盾, 该爆炸是结构性的, 试图修掉它等于攻击猜想本身在 pq = 1 边界的形态。[推测] 失败路线三: 用 Riesz 位势的弱型估计替代 ④ 的圆环分解: 需要 f ∈ L^{n/(β+2)} 之类的全局可积, 与"不假定能量有限" (02:304-305) 正面冲突。

### 5.7 Lemma 3.1（局域化 virial 恒等式）

(a) 03-localization.tex:71-81 逐字: "The following identity holds, with an absolutely convergent integral: a(n+B)E_f+b(n+A)E_g-aW_f-bW_g =(n-2)\int_{\R^{2n}}\Phi(x,y)\dd\pi(x,y), \Phi(x,y)=\frac{(X(x)-X(y))\cdot(x-y)}{|x-y|^2}."

(b) 推导补齐四步:
① 绝对收敛先行 (03:84-106): 对小 r = |x|, 近区 |x-y| ≤ r/2 内 |y| ~ r, v 局部有界给 g(y) ≤ C_{u,v}r^A, 于是 |X(x)|∫_{近}|x-y|^{1-n}g(y)dy ≤ r·Cr^A·|S|∫_0^{r/2}dρ = Cr^{2+A} → 0 (x → 0)。近区补: |X(x)| ≤ r ≤ 2|x-y| 给出比值 ≤ 2, 积分 ≤ C∫K(x-y)g(y)dy = Cu(x), 在 0 附近也有界。0 外紧集: 近区源有界 + |∇K| 局部可积, 远区由有限位势界住。X 支在 B̄₂ 而 f 局部可积, 得 ∫f(x)|X(x)|∫|∇K(x-y)|g(y)dy dx < ∞; (f,u,B) ↔ (g,v,A) 交换得对称式。结论: fX·∇u 与 gX·∇v 绝对可积, 后面所有 Fubini 有凭。
② 挖洞分部积分: 在 Ω_ρ = {|x|>ρ}, u^q∇u = ∇(u^{q+1})/(q+1) (a = 1/(q+1)) 给出 -∫_{Ω_ρ}fX·∇u = -a∫_{Ω_ρ}|x|^B X·∇(u^{q+1})。散度定理: = a∫_{Ω_ρ}u^{q+1}div(|x|^BX) - a∫_{∂Ω_ρ}u^{q+1}|x|^B X·ν。div 计算: ∇·(|x|^B xη) = B|x|^{B-2}x·(xη) + |x|^B(nη + x·∇η) = |x|^B[(n+B)η - w] (w = -x·∇η)。内边界 ∂B_ρ 上 ν = -ω_x, X·ν = -ρη (ρ < 1 时 η ≡ 1), 贡献 +aρ^{B+1}∫_{∂B_ρ}u^{q+1}dS, 幅度 O_{u,v}(ρ^{n+B}) → 0 (n+B > 0)。外边界无 (X 在 |x|≥2 为零)。ρ → 0 得 -∫fX·∇u = a(n+B)E_f - aW_f。g 侧用 b: -∫gX·∇v = b(n+A)E_g - bW_g。
③ 位势梯度代入: ∇u(x) = ∫∇K(x-y)g(y)dy 且 ∇K(z) = -(n-2)zK(z)/|z|² (5.4⑥ 已证, 02:91-98)。第一项变 (n-2)∫∫f(x)g(y)K(x-y)·(X(x)·(x-y))/|x-y|²dxdy; 第二项对换 (x,f) ↔ (y,g) 后变 (n-2)∫∫f(x)g(y)K(x-y)·(X(y)·(y-x))/|x-y|²。相加, 核对称, 得 (n-2)∫Φdπ。绝对收敛 (①) 授权 Fubini 与对换。

(c) 每个系数的生产线与消费者:
- (n+B), (n+A): 来自 div(|x|^B X) 的有效维数, 即阈值分子的来源。注意交叉: f = |x|^B u^q 的权重 B 乘在 E_f = ∫ηfu 上, E_f 的能量密度是 v 的 (fu = |x|^B u^{q+1} 是 u 一侧的能量密度, 却携带 B), 而系数 a = 1/(q+1) 来自 u^{q+1} 的原始化。所以 (n+B)/(q+1) 这一项的每个字符都有独立出处: n 是 div(xη) 的 nη, B 是权重的散度贡献, q+1 是非线性原始化。这就是临界双曲线在生产线上第一次成形的时刻, 02:309 的 γ = a(n+B) + b(n+A) - (n-2) 逐项对应 ② 的体项系数。

(d) [推测] 失败路线一: 用未截断的经典 Pohozaev (η ≡ 1 于全空间, 无 w 项): ② 的内外边界都不消失, 重蹈 2.2 节路线。[推测] 失败路线二: 把乘子从 X = xη 换成一般向量场: div 会产出 ∇X 的对称部分与反对称部分, 反对称部分对 (X(x)-X(y))·(x-y) 无贡献, 一般化徒增符号负担, 径向乘子是唯一让 (n+A), (n+B) 直接露面的选择。[推测] 失败路线三: 在 ① 偷懒不证绝对收敛直接 Fubini: π 总质量无穷, 条件收敛的二重积分交换次序非法, Lean 里 Interaction.lean (131 行) + InteractionBounds.lean (104 行) + RealInteraction.lean 专门养这只收敛怪兽, 说明机器层面这一步根本不是免费的。

(a) 03-localization.tex:136-144 逐字: "For every \(\eps>0\), there is a constant \(C_\eps\), independent of the solution, such that |E_f-E_g|+\int_{\R^{2n}}|\Phi(x,y)-\eta(x)+w(x)D(x,y)|\dd\pi(x,y)\le\eps E+C_\eps."

### 5.13 Corollary 6.2（分类; Phan 猜想 C）

(a) 06-conclusion.tex:83-97 关键句逐字: "Let \(n\ge3\) be an integer, let \(p,q>0\), and let \(A,B>-2\). There is no pair u,v\in C^2(\R^n\setminus\{0\})\cap C(\R^n)... if and only if \frac{n+A}{p+1}+\frac{n+B}{q+1}>n-2. When the reverse weak inequality holds, such a pair exists and can be chosen radial."

(b) 推导补齐:
① 非存在方向: 定理 1.1 直接。
② 反向弱不等式 ⟹ pq > 1: 由 A,B > -2 得 n+A > n-2 > 0 与 n+B > n-2 > 0, 于是 1/(p+1)+1/(q+1) = [(n-2)/(n-2)]·[1/(p+1)+1/(q+1)] < [(n+A)/(n-2)]/(p+1) + [(n+B)/(n-2)]/(q+1) = γ'/(n-2)... 精确按 06:105-110: (1/(n-2))·[(n+A)/(p+1)+(n+B)/(q+1)] ≤ 1, 而左边的和严格大于 1/(p+1)+1/(q+1) (因为 (n+A)/(n-2) > 1, (n+B)/(n-2) > 1, 且两项至少... 两项系数都严格大于 1 而 1/(p+1), 1/(q+1) > 0, 严格性成立), 得 1/(p+1)+1/(q+1) < 1; 恒等式 1 - 1/(p+1) - 1/(q+1) = (pq-1)/((p+1)(q+1)) 给出 pq > 1。
③ 引用外部定理: Bidaut-Veron--Giacomini 径向基态存在性 (其 Theorem 1.4(i), 06:114-117 经 Phan 的 Proposition B 转述), 适用类 n ≥ 3, A,B>-2, p,q>0, 存在区域恰为反向弱不等式 (含临界双曲线上的等号)。记号代入 (06:120-123): N=n, a=A, b=B, δ=p, μ=q, 两个微分算子阶均为 2, 其持久超线性条件 D = δμ-1 = pq-1 > 0 由 ② 验证。
④ 把径向基态拉回本解类: 径向剖面 U, V 在 (0,∞) 经典、0 处连续且正。证严格正于 0: 径向方程使 r^{n-1}U'(r) 严格递减 (球均值 flux 的径向特化), 其 r ↓ 0 极限若非零或无穷, 对 r^{1-n} 积分与 U 在 0 连续冲突 (5.3② 同一论证), 故极限 0、U' < 0 处处、U(0) ≥ U(r) > 0。V 同理。于是 u(x) = U(|x|) 属于解类且处处严格正, 提供"反向区域存在解"的全部所需。

(c) 机械理由: ② 的严格不等号 (n+A > n-2) 消费 A > -2 一次, 该步的存在说明双向定理的"存在侧"也依赖权重的下界归约, 但走的是与主定理独立的通路 (超线性条件是外部定理的输入)。等号情形 (临界双曲线上) 落进存在侧, 是"反向弱不等式"闭口的原因, 也是 Phan 猜想 C 补全的内容: 非存在严格侧 + 存在闭侧, 两半在双曲线上不相交, 分类无空隙。06:140-144 特意声明: 该分类是"定理 1.1 与引用的径向存在定理的拼接, 不是新的基态构造", 存在侧的径向性与非存在侧的无对称假设之间的不对称被论文自己点破。

(d) [推测] 失败路线一: 想把存在侧也做成非径向: 双曲线上非径向解的存在无任何机制供给, 变分框架在该能量水平 (无界域、符号不定权重) 不闭合。[推测] 失败路线二: 用主定理机器反向推出临界的非存在 (ε-界在 γ=0 退化为 (γ/2)E ≤ 0·? ): γ=0 时吸收不等式右边系数 (n-1)εE 压过左边 0·E, 界消失, 缩放矛盾失去放大率 (α+β+2-n=0), 两处同时熄火, 与存在定理一致, 方法在阈值上自洽地失明。[推测] 失败路线三: 把 A,B 范围扩到 ≤ -2 谈分类: Lemma 2.1 说该区域无解, 而反向不等式在 A ≤ -2 时可成立 (n+A 变小), "iff" 右侧的陈述若不加 A,B>-2 会被非存在真空区污染, 论文把存在侧限制在 n≥3, A,B>-2 (06:142-143) 正是为了口径纯净。

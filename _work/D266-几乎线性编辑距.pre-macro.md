## §1 起手：把 $(1+\varepsilon)$ 与 $N^{1+o(1)}$ 摆在一起意味着什么

我第一次拿到题面时脑子里的画面很朴素。Wagner--Fischer 的 $O(N^2)$ 动态规划有 $N^2$ 个格子，$N^{1+o(1)}$ 意味着实际只被允许触碰 $N \cdot 2^{o(\log N)}$ 个格子的信息量；对角带切法看着是最直接的尝试，带宽 $k$ 就吃掉 $O(N k)$ 时间，误差量级 $O(k)$。这个直觉让我在几处栽了跟头，也逼着我逐段还原论文背后的思路。

第一个坑，最优对齐路径在棋盘上可以偏离对角带 $O(D)$ 次。若 $D = \Theta(N)$，带内路径与全路径没有本质差别，动态规划仍是 $O(N^2)$。我一开始以为按 $|i - j| \le \varepsilon N$ 定带就够用；但真正的对齐完全可以先向右上走 $0.5 D$，再向左下折回；这种 zig-zag 在纯插入删除的极端例子里就存在。

第二个坑，即便带选对了，格子上的每个转移仍是 $O(1)$ 时间，$N \cdot D$ 的量级跟 $N^{1+o(1)}$ 完全不搭。我最初以为用 Myers 或 Landau--Vishkin 那种距离敏感的位并行加速能把 $N \cdot D$ 里的 $D$ 消掉；这些方法在最坏情况下 $D = \Theta(N)$ 就是 $N^2 / w$，$w$ 只是字长 $\Theta(\log N)$，跟 $N^{o(1)}$ 完全不搭。

第三个坑，带内动态规划给的是上界。$(1+\varepsilon)$ 需要同时把上下界夹住；带内估计对短字符串的绝对误差跟字符串本身长度成比例，跟 $\varepsilon D$ 无法比。

这三坑合起来让我明白，几乎线性 $(1+\varepsilon)$ 不是把动态规划稀疏化的字面延伸，是一个结构性问题：输出必须拆成两个耦合的对象，一个"哪里去"的路径约束和一个"花多少"的成本约束，两者要同时收紧。论文用的抽象是 interval state，把 $x$ 切成 $M$ 分叉树 $I = (l, u]$，把 $y$ 上目标区间记成端点对 $q = (q^-, q^+)$，成本 $c(I, q) = \ED(x_{(l, u]}, y_{(q^-, q^+]})$，净位移 $z(I, q) = (q^+ - q^-) - (u - l)$。我第一次读 $z$ 的定义时觉得太抽象；后来才明白它编码了"删除减插入"的净贡献，长度不平衡的一切信息都在这里。$|z(I, q)| \le c(I, q)$ 恒成立，因为每一步只让 $z$ 变化 $1$；若 $|z| = c$，那路径全是插入或删除，压根没有替换。

顺带记一笔：$q$ 允许空区间，$l = u$ 的叶子上成本就是目标长度，宽度 $1$ 的叶子上成本是"目标长度减去这一字符是否出现的指示"。$y$ 的 (symbol, position) 对按字典序比较排序，$O(N \log N)$ 预处理，之后每叶子查询 $O(\log N)$。这套叶子上"符号出现与否"的判定，是我最初完全忽略、后来发现整个证明都要依赖它的一个工程点。

## §2 我最初的猜想：AKOS 递归搬到编辑距离就够了

AKOS 系列给出 $(\log N)^{O(1/\xi)}$ 因子与 $N^{1+\xi}$ 时间；两个可搬用的机制是 shift tree 与非均匀精度采样。我最初的算法是把它们合起来，形状像这样：

- 对 $(I, q)$ 猜 dyadic $k$ 使 $k \le c < 2 k$；
- 用 $B$ 分叉 shift tree，允许 shift 在 $[-k, k]$；
- 内部节点上 $T_w(v) = \sum_{i=1}^{B} \min_{v'} \{ T_{w_i}(v') + 2|v - v'| \}$；
- 叶子给"字符对不对得上"的指示；
- 根值 $T_o(0)$ 落在 $[d, (1 + 2 B D_0) d]$，$D_0 = \lceil \log_B n \rceil$。

粗版能算，也符合 AKOS 定理 3.3 的形式。崩塌在递归精修这一步：粗估因子 $A_{\mathrm{init}} = H^{p_* + 4}$，$H$ 是 $\lceil \log_2 (N+2) \rceil$ 的 2 次幂上界，$p_* = \lfloor (\log_2 \ell)^{1/4} \rfloor$，$\ell$ 是 $\max(1, \log_2 H)$ 的 2 次幂上界。要把因子压到 $1+\varepsilon$，$A$ 必须沿递归精修降到 $F = \ell$。

我当时的判断是"每次精修就是把子问题独立粗估再求和"。这条路线致命的时间问题是：父节点 $I$ 有 $M$ 个孩子，每个孩子要重新估算当前索引 $t$ 的值；孩子又各自向下 $M$ 次；$J$ 层树深把整棵 $M$ 分叉树的 $M^J \le M \cdot |x|$ 个节点全部展开。时间预算完全不够，除非每次精修的实际查询远小于树节点总数。这个约束逼我接受：粗估表必须惰性展开，父节点向孩子请求当前索引值必须被压缩到跟 $M$ 同阶、跟树总大小脱钩。

这一步之后我才把论文的 §4-cones 与 §5-bands 当成"两个压缩器"来读：前者把当前索引的孩子查询限制在"共享的组采样"和"选定的舍入动作"上；后者把组采样限制在"窄带内部"，从而让一次父调用触到的孩子状态总数是 $M \ell^{O(1)}$，跟树总大小脱钩。这个"两个压缩器"视角是我从 §16 work 那一节的依赖路径图倒推回来的。

## §3 第二个坑：允许自适应查询带来的概率论问题

惰性求值给分析砸下来一个我一开始完全没意识到的坑：如果 $U^{(0)}(I, q)$ 只在被请求时才计算，那"整张表在同时刻都准"就失去了直接含义。后续查询可以依赖前面查询暴露的随机位；查询序列本身跟估计的随机源耦合，我没法把 $c \le U \le A_{\mathrm{init}} c$ 当作一个"整个表上的事件"直接 union bound。

我在这段反复改过写法。

第一版，把整张 seed 表先展开，再证展开代价可控。这违背 lazy 的动机，时间上限炸。

第二版，对每个固定状态 $(I, q)$ 证 $\Pr[E_{I,q}] \ge 0.99$，再 union bound。union 域大小 $2 M (N+1)^3 \le e^{10 H}$ 太大，$0.01$ 变成 $e^{10 H}$ 级别的坏事件密度，一条都撑不住。

第三版，读到 Theorem 3 陈述才想通怎么解耦：accuracy 与 cost 两套概率论各走各的。

- accuracy 事件 $E_{\mathrm{acc}}$：把整张 $U^{(0)}$ 看成一个"潜在存在的整体随机对象"，每条状态、每个猜测 $k$、每个内部节点、每个 shift 上的阈值都是这个对象的一份独立坐标；union 覆盖整个域，失败概率 $\le 0.01$。这是离线概率。
- cost 事件 $E_{\mathrm{cost}}$：只在第一次被请求的那一刻，条件于此前已暴露的随机位；这一 entry 的私有随机流此前没被触及，因此它的期望代价可以按"独立 fresh stream"来 bound。这是在线期望。

两套概率论各自独立成立，我组合两者。这一步是理解论文的第一道门槛，也解释为什么 §16 要把 key 分配、私有 stream、dictionary lookup 这些工程细节专门列一节。

顺带记一笔：§2 里"粗版能算"我用了 $B$ 分叉 shift tree，但精度采样那一步的阈值分布 $t_i = a_w R_i / (B Q_0)$、子节点余量 $a_{w_i} = \lambda t_i$ 里的 $\lambda = 1/(64 H)$、$Q_0 = H^4$，是论文 §3-seed 里给出的具体值。这两个数字把 Bernstein 不等式里的失败概率压到 $2 e^{-\lambda Q_0 / 12} = 2 e^{-H^3 / 768}$；union 域 $\le e^{20 H}$，$H^3$ 完胜 $H$。我第一次试图用"高斯型"集中不等式来代替，$Q_0$ 得开到 $H^5$，代价直接崩。这是我从论文里读到的最直接的"参数选择即证明"的证据。

## §4 关键转折：预测带 + 曲率望远镜 + 熵正则决策

三段机制合起来把粗估 $H^{p_*+4}$ 因子压到 $1+\varepsilon$。这三段互相咬合，任缺其一另外两段撑不住。

第一段，预测带 (predicted band)。在源节点 $I$ 的第 $j$ 个切点，"目标端点减源端点" 就是 shift。若一条对齐把总成本 $Z$ 均匀摊到 $M$ 个孩子上，$j$ 处 shift 大约等于 $p_0 + \widehat v \Phi_j(p)$，$\widehat v = z(I, r) / Z$，$\Phi_j$ 是前 $j$ 个孩子前缀最小成本。速度测试 $|\widehat v| \le 1 - \tau$ 让 $\widehat v \Phi_j$ 是压缩映射，允许解落在宽度 $2 \theta b / M$ 的窄区间；算法把这个区间当 band，只评估 band 内的动作。这里 $\tau = \ell^{-4}$、$\theta = \ell^{-40}$，两个尺度上的参数都跟 $\ell$ 有关，跟 $H$ 无关；这一点我在 §5 会再展开。

第二段，曲率望远镜 (curvature telescope)。band 之所以能"接住"真正的对齐，是在一棵比较树上证明的。比较树纯粹是分析用：从 $(I, q)$ 出发，取一条最优对齐，在孩子切点处取路径经过的最早位置，向下递归；孩子端点向下舍入到 scale-$b$ 网格。这棵树上每个节点带一个曲率 $K = \sum_i z_i^2 / m_i - z_r^2 / W$；$m_i$ 是 warmup 平均成本，$W = \sum m_i$；用加权方差恒等式 $K = \sum (z_i - v m_i)^2 / m_i$（其中 $v = z_r / W$）把 $K$ 写成平方和，再沿树求和。

这里的巧妙之处是我一开始完全没看到的：warmup mass $m$ 不满足加法守恒。父节点 $m_q$ 与孩子 $m_i$ 之和的差 $R = m_q - W$ 可正可负；$R$ 分成 $R_+$ 与 $R_-$，$R_+ \le h$ 是向上偏差。整棵树上 $R$ 之和等于 $m_{\mathrm{root}} - C_{\mathrm{term}}$，因为内部完全抵消；因此 $\sum R_- \le \sum R_+ + C_{\mathrm{term}} \le \sum h + C_{\mathrm{term}}$。曲率项 $K$ 的 telescoping 需要 $R_-$，$G = W - Z$ 的 telescoping 需要 $R_-$，两者一起被 $\sum h$ 与 $C_{\mathrm{term}}$ 控住。这一层"用望远镜把不守恒量转成边界"是我读到这里最有触动的地方。我原本以为 warmup 只是为了平滑噪声；实际它是**提供 mass 的载体**，Bellman 平均 $m = (1/T) \sum_{j=0}^{T-1} w_j$ 让 $R$ 的向上偏差被 $h = L e + w_0 / T$ 控住，$w_0 - w_T$ 的整段下降被平均到 $T$ 次，一次只漏 $1/T$。这个视角切换是我第一次读时完全错过的。

第三段，熵正则在线决策。在一个 band 内部，需要在 $t = 1, \ldots, S$ 依次选动作，使累计成本差被 bound 相对任何一个固定 band 动作 $\alpha^*$。$S = H / \ell^2$。做法是给每个 band 定义凸集 $\mathcal Q = \operatorname{conv}\{\rho(\alpha) : \alpha \in \mathcal C\}$，$\rho(\alpha)$ 把质量 $h_i / h_\Sigma$ 分到孩子 $i$ 对应坐标。每时刻解

$$\max_{\rho \in \mathcal Q}\; \mathcal H(\rho) + \eta \Big\langle \sum_{j<t} u_j + \widehat g_t, \rho \Big\rangle$$

$\mathcal H$ 是熵，$\widehat g_t$ 是"上一时刻孩子成本"的负向量，$\Delta_t$ 是"上一时刻与本时刻成本差"，$u_t = \widehat g_t + (1 - 2\kappa) \Delta_t$。这就是 optimistic regularized leader 的形状。孩子 $i$ 的坐标在同一 block，$\mathcal Q$ 上每个向量 block 质量固定；$\Delta_t$ 的 block 共同部分 $\mu$（block 最小值）在 $\langle \mu, \rho \rangle$ 里对所有 $\rho$ 相等，只有剩余部分 $v'_k$ 需要用指数界 $e^{(1-2\kappa)x} \le 1 + (1-\kappa)x$ 控制。Lemma 熵不等式给 $\ln d / \eta + 2\kappa$ 的 regret，带进 $h_\Sigma$ 归一化就是父节点 excess 界。

三段咬合：band 只包含"速度测试通过且曲率不失控"的动作集合；曲率望远镜保证非坏节点的比较动作落在 band 里；熵正则保证 band 内累计 regret 只有 $h_\Sigma (\ln d_{\mathcal C}/\eta + 2\kappa + S H^{-3})$；合起来每个非坏节点的期望 $\sum_t \mathcal R_t$ 压到 $O(c / \ell)$，沿树求和得 Theorem 4 的 $\E[\pos{d_S - c}] \le c / \ell$。

这个三段咬合是论文的骨架。我第一次读时把三段独立拼装，写错了两周；直到明白"bad 节点定义里那个 $b H^{-1/4}$ 阈值跟 band 宽度 $\theta b / M$ 是同一次估算的两侧"才通。bad 阈值来自 $\sqrt{K W} + 2 G \le \tau \theta b / M$，$K, G \le b H^{-1/4}$ 且 $W \le 8 F b$，所以左边 $\le \sqrt{8\ell} b H^{-3/40} + 2 b H^{-1/5}$；把 $b$ 除掉，右端是 $\tau \theta / M$，参数 $\tau = \theta = \ell^{-4}, \ell^{-40}$ 加上 $M \le H^{1/20}$ 就接得住。这一段我在草稿纸上重算了三遍，第一遍把 $\sqrt{KW}$ 里的 $W$ 误当成 $m_q$；$m_q$ 与 $W$ 差一个 $R$，$R$ 又被 $h$ 控制；这就是上一段"不守恒量转成边界"的具体作用点。

我原本还打算再加第四段，"用中值放大把 $\E[\pos{d_S - c}] \le c / \ell$ 变成 $\Pr[d_S > (1+\varepsilon) c] \le 1/10$"。这一段的机制在 §14 会说，它跟前三段是同一层级：前三段决定"一次精修能压多少因子"，第四段决定"多次独立精修取中值能不能收敛到 $1+\varepsilon$"。中值放大需要 $H^2$ 份独立副本，代价 $\le (1+|I|) 2^{o(H)}$ 每次；union 域 $e^{10 H}$ 覆盖下 $e^{-H^2}$ 级别的失败概率，加上初始表 $0.01$，总失败 $\le 1/10$。这个 $1/10$ 就是最终答案概率 $\ge 9/10$ 的来源，跟题面要求的 $\ge 2/3$ 有富余。

## §5 参数与尺度分离：$H$ 与 $\ell$ 的分层设计

论文的参数字典在 §2-geometry 里一次性摆出来，我第一次读时被这堆符号吓到；后来明白它们其实分两层：一层挂在 $H = \Theta(\log(N+2))$ 上，一层挂在 $\ell = \Theta(\log H)$ 上。所有"分支因子"与"网格分辨率"是 $H$ 的幂，所有"容差"与"惩罚斜率"是 $\ell$ 的幂。分层设计的核心不等式是 $H \ge 2^{\ell/2}$、$\ell^{200} \le H^{1/100}$、$p_* + 21 \le \sqrt\ell$，第一条从 $\ell$ 定义直接得，第二、三条从 $\ell \ge 2^{1000}$ 起单调变松。

$H$ 层：$B = H^{p_*}$、$A_{\mathrm{init}} = H^{p_*+4}$、$M = 2^{\lfloor (\log_2 H)/20 \rfloor}$、$P = H^{p_*+20}$、$T = 2^{\lceil (3/4) \log_2 H \rceil}$、$S = H/\ell^2$。$B$ 是粗估 shift tree 的分叉；$M$ 是主 interval tree 的分叉；$P$ 是端点网格分辨率；$T$ 是 warmup 迭代次数；$S$ 是精修迭代次数；$A_{\mathrm{init}}$ 是初始 seed 因子。

$\ell$ 层：$F = \ell$、$L_0 = 32 F$、$L = 128 F$、$\delta = \ell^{-10}$、$\kappa = \tau = \ell^{-4}$、$\theta = \ell^{-40}$、$\gamma = \ell^{-20}$、$\eta = \ell^{5}$、$Q_1 = \ell^{80}$。$F$ 是每次精修的因子降幅；$L_0$ 与 $L$ 是锥的 Lipschitz 常数（$L_0$ 用于初始锥，$L$ 用于 Bellman 之后的锥，$L/L_0 = 4$）；$\delta$ 是 $Y_t$ 的下截断容差；$\kappa$ 与 $\tau$ 分别控制 $\Delta_t$ 与 $\widehat v$ 的容差；$\theta$ 是带宽度与 cell 宽度的比例因子；$\gamma$ 是组采样的估计误差；$\eta$ 是熵正则的倍率；$Q_1$ 是组采样的样本数上限。

我第一次读 $Q_1 = \ell^{80}$ 觉得这个数字很 arbitrary，后来才明白它是 Bernstein 不等式的失败概率 $\exp(-Q_1 \alpha_0^2 / (512 F + 4 \alpha_0 / 3))$ 里的"余量池"：$\alpha_0 = \gamma / (2\ell) = \ell^{-21}$，所以分子是 $\ell^{80} \ell^{-42} = \ell^{38}$；分母是 $O(\ell)$；指数 $\ge \ell^{37}$；$\exp(-\ell^{37} / 3000)$。union 域 $(P+1)^2 \cdot 2\ell \le H^{2(p_*+20)} \cdot 2\ell \le e^{O(H^{1/2})}$，两者一比，$\ell^{37}$ 完胜。我第一次把 $Q_1$ 设成 $\ell^{20}$，union bound 直接失败；这就是参数选择即证明的证据。

$J = \lceil \log_M \max(1, |x|) \rceil \le 100 H / \ell$；$M^J \le M \max(1, |x|)$。这两个树深界在 §16 的依赖路径计算里被反复使用。$J \log \ell = o(H)$、$q_* K_{\mathrm{dep}} \log H = o(H)$、$J + K_{\mathrm{dep}} = o(H)$ 是 §16 的三条渐近前提；$K_{\mathrm{dep}} = O(H q_* / (\ell \log \ell))$，$q_* = p_* + 1$。$S = H / \ell^2$、$T = H^{3/4}$、$T = o(S)$ 是 §12 曲率望远镜里 $h$ 项系数 $4FJD/T \le O(FJH^{-3/4})$ 的来源。

我把这些数字抄到本稿是因为：这些参数之间的**相对阶**就是论文的全部工程细节，一次改动一处，就要重新验证 $\sum (K + G) \le 5000 F (1 + J/P + J/T) D$ 这一类常数量级的界。§18 会说明我对哪几处数字的组合最不确定。

## §6 初始种子：AKOS shift tree 与 padding 距离

Theorem 3 的初始表构造在 §3-seed 里。我把它拆成五个动作来看。

动作 A，长度比较与等值直取。若 $n_y > 2 n_x$（$n_x = |I|$，$n_y = q^+ - q^-$），返回 $n_y$；$n_y - n_x \le c \le n_y$ 直接给因子 $2$ 近似。否则若两串相等，返回 $0$；这一步是"等值确定性返回"，跟题面"equal strings return zero"绑定。这两步都在 $O(1 + n_x)$ 内完成，因为要求字符比较时 $n_y \le 2 n_x$。

动作 B，padding。把较短的串右侧用 fresh 带 tag 符号补齐，两条长度 $n \le 2 n_x$ 相同，距离记 $d$。长度 gap 至多 $c$，所以 $d \le 2 c$；反向从任何带 padding 的对齐里删掉 padding，对角线连到实字符的可以被替换成一次插入或删除，成本相同；因此

$$1 \le c \le d \le 2 c, \qquad 1 \le n \le N, \qquad d \le n.$$

我第一次读到 "$d \le 2c$" 时试图直接证 $c \le d \le c$；这不可能，因为替换与插入删除的**净**效果在 $z$ 上不对称。这个"1 到 2 的倍率"是 padding 距离与真实编辑距离的固有 gap，也是 AKOS 3.3 定理里那个 "$d \le T_o(0) \le (1 + 2 B D_0) d$" 出现的 $d$。

动作 C，dyadic 猜测与 shift tree。对 $k \in \{1, 2, 4, \ldots, 2^{\lceil \log_2 n \rceil}\}$ 各猜一次，允许 shift 是 $[-k, k]$ 里的整数。$B$ 分叉 shift tree 深度 $D_0 = \lceil \log_B n \rceil$，叶宽 $0$ 或 $1$。叶子上 $T_w(v)$ 是这个字符与 $y$ 里第 $j+1+v$ 位置的失配指示；宽度 $0$ 叶子恒 $0$；$j+1+v$ 出界的位置是虚拟符号，永远失配。虚拟符号选在两串字母表之外，这样 Lemma 2.1 (geometry) 在 extension 上也成立。

内部节点上 $T_w(v) = \sum_i \min_{v'} \{T_{w_i}(v') + 2 |v - v'|\}$。这个 recurrence 的语义是"给每个子节点选一个 shift，累加子节点失配数，外加两倍的父子 shift 差"。Lemma 3.1 的界分两头。下界 $d \le T_o(0)$：任何 shift 分配都可以按深度优先序拼成一条完整对齐，父子 shift 差的和的两倍是 connection 项的上界；connection 不等式给出 $d \le$ 分配成本。上界 $T_o(0) \le (1 + 2 B D_0) d$（当 $k \ge d$）：给定最优对齐，$b_j$ 是路径经过源位置 $j$ 的目标位置，$b_0 = 0, b_n = n$；把 shift $b_j - j$ 赋给起点在 $j$ 的节点。$|b_j - j| \le d$，因为仅插入删除会改 shift，每次改 1。每条边父子 shift 差不超过父节点子路径成本；$B$ 个孩子共享父路径，$D_0$ 层深度上父子 shift 差之和 $\le B d$，总 penalty $\le 2 B D_0 d$。失配叶子的成本合起来 $\le d$（每个失配在对应子路径里贡献至少 1）；宽度 $0$ 叶子贡献 $0$。合并得界。

这一节的 $2 B D_0$ 系数在最终粗估里乘上 $k$ 与 $d$ 的比例，变成 $25 + 16 B H$；这个 "16" 我最初找不到出处，其实它是从 $d \le 2c$、$k \le 2d$、$4 k$ 三层各乘 $2$ 凑出来的。

## §7 精度采样：阈值、剪枝与 Bernstein

粗估树全算太贵；引入**每节点独立阈值**。$Q_0 = H^4$、$\lambda = 1/(64 H)$、$a_o = k$。孩子阈值 $t_i = a_w R_i / (B Q_0)$，$R_i$ 在 $\{1, \ldots, B\}$ 均匀独立；子余量 $a_{w_i} = \lambda t_i$。所有 $R_i$ 在**剪枝之前**就已经定义好，实现只暴露真正用到的那些。

剪枝规则：若 $|w| \le a_w$ 整节点直接返回零；否则非剪枝叶取精确数组；非剪枝内部节点先算 $\widehat s_i(v) = \min_{v'} \{\widetilde T_{w_i}(v') + 2|v - v'|\}$，再取 $\widetilde T_w(v) = \sum_i \ind_{\widehat s_i(v) \ge t_i} \max\{\widehat s_i(v), a_w / Q_0\}$。

Lemma 3.2 是核心：除了概率 $< 0.01$ 的事件外，对**所有**初始 entry、**所有**猜测、**所有**节点、**所有** shift 同时成立

$$T_w(v) / f_w - a_w \le \widetilde T_w(v) \le f_w T_w(v) + a_w, \qquad f_w = \left( \frac{1 + \lambda}{1 - \lambda} \right)^{\mathrm{height}(w)} \le 2.$$

证明分两层。**层一**，"路径 sandwich"：若孩子精度成立，则加 penalty 保持上下界；把 $\widehat s_i(v)$ 与两个由真成本构造的量 $h_i^- = s_i / (f' (1+\lambda))$ 与 $h_i^+ = f' s_i / (1 - \lambda)$ 挂钩，得到 $\phi_i(h_i^-) \le \phi_i(\widehat s_i(v)) \le \phi_i(h_i^+)$，其中 $\phi_i(h) = \ind_{h \ge t_i} \max(h, u)$、$u = a_w / Q_0$。**层二**，"独立于层一的 concentration"：条件于祖先阈值，$u$ 固定，$t_i = u R_i / B$ 独立；对固定列表 $h_i$，若 $h_i < u$ 则 $\phi_i(h_i) = u \mathrm{Bernoulli}(\lfloor B h_i / u \rfloor / B)$；否则确定等于 $h_i$。三条矩界 $0 \le h_i - \E \phi_i(h_i) \le u / B$、$\mathrm{Var}(\phi_i(h_i)) \le u h_i$、$|\phi_i(h_i) - \E \phi_i(h_i)| \le u$；Bernstein 在偏离 $z = \lambda V + a_w / 2$ 处失败概率 $\le 2 \exp(-\lambda Q_0 / 12) = 2 \exp(-H^3 / 768)$。

我第一次没读懂的是"条件于祖先阈值，$u$ 固定"这一句；后来想通：$u = a_w / Q_0$，$a_w$ 沿路径由 $a_{\mathrm{parent}} \cdot R / (64 B H^5)$ 递归给出，条件在祖先阈值就是条件在祖先 $R$ 上；$u$ 就是固定值。这个"条件后 $u$ 固定"是把整个 threshold sampling 变成"每层独立的 Bernoulli 求和"的关键；如果没有这一步，$\phi_i$ 里的 $\ind_{\widehat s_i \ge t_i}$ 就跟着 $t_i$ 走，$t_i$ 又跟着祖先随机，独立结构整个崩掉。

Union 域大小：$O(M (N+1)^3)$ 个 labeled main-tree state、$O(H)$ 个猜测、$O(B N)$ 个粗估节点、$O(N)$ 个 shift；两列表总数 $\le C M B H (N+1)^5 \le e^{20 H}$；总失败 $\le 2 \exp(20 H - H^3 / 768) < 0.01$。这个 $H^3$ 对 $H$ 的完胜是"剪枝阈值 $Q_0 = H^4$" 的直接后果；如果 $Q_0$ 只开到 $H^2$，Bernstein 就只剩 $\exp(-\lambda Q_0 / 12) = \exp(-H / 768)$，跟 $e^{20 H}$ 打平，失败概率爆。

## §8 锥包络、Lipschitz 化与局部枚举

Theorem 4 refinement 里的 $U$ 是整张 seed 表；$a = \max(1, A/F)$ 是当前要"降下来"的因子。定义 $\widetilde U(I, q) = \max\{\lceil U(I, q) / a \rceil, |z(I, q)|\}$；由 $Fc(I, q)$ 整数性，$\max(c/a, |z|) \le \widetilde U \le Fc$。

问题：$\widetilde U$ 邻居之间可以剧烈波动，seed 高估程度在端点上不连续。做法：用一族锥取**下包络**。尺度 $b$ 是从 $1$ 到 $N$ 的最大 2 次幂的所有 2 次幂；在尺度 $b$ 上，网格 $g_b \Z \cap [0, |y|]$，两端点均在此网格上且非降；$r_b(q)$ 是 $q$ 两端向下舍入的网格状态；网格误差 $|q - r_b(q)|_1 < 2 b / P$（当 $g_b > 1$）。

在 $I$ 非叶处，锥族是 $q \mapsto \widetilde U(I, r) + L_0 |q - r|_1$，中心 $r$ 是"网格状态且 $b/2 \le U(I, r) \le 4 A b$"；再加上所有 $U(I, r) = 0$ 的锥（是否网格上都可以）；$w_0(I, q)$ 取全部锥的最小值；叶子直接精确。Lemma 4.1 说 $\max(c/a, |z|) \le w_0 \le 2 F c$，$\mathrm{Lip}(w_0) \le L_0$。

下界：每个锥都盖住 $c/a$ 与 $|z|$（用 $\widetilde U$ 的下界 + endpoint Lipschitz），取最小仍成立。上界：给 $c > 0$，选 $b$ 使 $b \le c < 2 b$，$r = r_b(q)$，$e = |q - r|_1 \le 2b/P$；由网格误差 $c(I, r) \ge b - 2 b / P \ge b/2$、$c(I, r) < 2b + 2b/P \le 4b$，$r$ 合格；锥值 $\le Fc(I, r) + L_0 e \le Fc + (F + L_0) e \le Fc + 66 F b / P \le 2 F c$。

局部枚举：若 $U(I, q) = 0$ 返回 $0$；否则跳过零锥，尺度枚举 $U(I, q) / (16 A^2) \le b \le 4 A U(I, q)$，网格中心枚举 sup 距离 $\le U(I, q)$，仍做合格性判定 $b/2 \le U(I, r) \le 4 A b$。这**精确复现**全局最小值。我第一次读到这里觉得这不等式很 magic；后来才明白它是从两个方向夹： competitive cone 的中心距 $q$ 至多 $2Fc / L_0 = c/16$，中心真成本在 $[15 c/16, 17 c/16]$，代回得 $b \ge 15 c / (64 A) \ge U(I, q) / (16 A^2)$ 与 $b \le 2 U(I, r) \le 4 A U(I, q)$；反过来局部枚举里每一项都是全局锥族的成员，因此两个最小值相等。

对不精确 seed，局部规则仍然给出**有限**结果：scale 区间比 $64 A^3$；$U(I, q) / b \le 16 A^2$；原始 seed 查询数 $O((1 + P A^2)^2 (1 + \log A)) = H^{O(p_* + 1)}$。返回值不超过 $(L_0 + 1) N$ 量级。这一点在 §16 工作计数里非常关键：即使 seed 完全失败，局部计算仍然有限、可 bound；工作量的 union 不需要假设任何 accuracy 事件。

## §9 Bellman 传播与宽动作

对非叶 $I = (l, u]$，源切点 $l = l_0 \le l_1 \le \cdots \le l_M = u$，源子区间 $I_i = (l_{i-1}, l_i]$。**代表**是一对 $(b, r)$，$r$ 是 scale $b$ 网格状态且 $b / (4 a) \le w_0(I, r) \le 8 F b$；$p_0 = r^- - l$。宽动作集 $\mathcal A_{b, r}$ 是子区间网格状态列表 $\alpha = (s_1, \ldots, s_M)$ 满足 $|s_i^- - l_{i-1} - p_0| \le 10 b$ 与 $|s_i^+ - l_i - p_0| \le 10 b$；相邻目标区间**不必相接**，靠 connection 电荷 $\conn_r(\alpha)$ 补。动作成本 $V_r(\alpha; f) = \conn_r(\alpha) + \sum f(I_i, s_i)$。Bellman 算子

$$\mathcal B_I(f)(q) = \min\left\{ w_0(I, q), \min_{(b, r)} [ L |q - r|_1 + \min_{\alpha \in \mathcal A_{b, r}} V_r(\alpha; f) ] \right\}.$$

空集最小取 $+\infty$。这个算子在 child 表上单调，$q$ 上 $L$-Lipschitz；下界 $\max(c/a, |z|)$ 保持。下界保持的**关键论证**是：

$$V_r(\alpha; f) \ge \frac{\conn_r(\alpha) + \sum c(I_i, s_i)}{a} \ge c(I, r) / a,$$

最后一步是 Lemma 2.1 的 connection 不等式；$|z(I, r)|$ 的对应界由 shift-connection 不等式给出。然后沿锥 $L |q - r|_1$ 加进去，$w_0$ 也满足同下界，$\min$ 保持。

Warmup：$w_j = \mathcal B_I(w_{j-1})$，$1 \le j \le T$，$m = (1/T) \sum_{j=0}^{T-1} w_j$，$d_0 = w_T$。单调性给 $w_1 \le w_0$、$w_j$ 递减，因此 $d_0 \le m \le w_0 \le 2 F c$；再一次 $\mathcal B_I$ 给 $\mathcal B_I(d_0) \le d_0$。

$m$ 之所以有用，是它的迭代范围"整体挪一位"只改 $w_0 - w_T$ 除以 $T$：

$$\frac{1}{T} \sum_{j=1}^{T} w_j = m - \frac{w_0 - w_T}{T}.$$

对固定代表和固定宽动作，把 $w_j(I, q) \le L |q - r|_1 + V_r(\alpha; w_{j-1})$ 沿 $j$ 平均并对动作取最小，得到 $m(I, q) - (w_0 - w_T)/T \le L |q - r|_1 + \min_{\alpha} V_r(\alpha; m)$。这就是 §12 曲率望远镜里 $\mathcal B$ 平均误差的**唯一**入口。

我最初的困惑是"warmup 迭代 $T$ 次，为什么不直接跑 $T = S$？"。答案是 $T$ 只影响 $h = L e + w_0 / T$ 里的第二项；曲率望远镜把 $\sum h$ 换成 $L \sum e + (\sum w_0) / T$；前者由 §12 引理 6.1 的 $\sum e \le 4 JD / P$ 控制，后者由 $\sum w_0 \le 4 F J D$ 控制，除以 $T \ge H^{3/4}$ 得 $o(1)$ 项。$T = S$ 会让 warmup 变慢；$T = H^{3/4}$ 已经是 $o(S) = o(H/\ell^2)$。这个"够用就好"的参数选择我在草稿纸上试过 $T = H^{2/3}$，$T = H^{4/5}$，都可行；$T = H^{3/4}$ 是把常数摊到 $\mathcal E$ 表达式里最舒服的一档。

局部枚举规则也适用于 Bellman 之后：**Lemma 4.3 cone locality**。固定 good seed，取 $w_0(I, q)$ 的最小锥与任何 slope $L$ 的锥族；若 $w_0(I, q) = 0$ 返 $0$；否则尺度枚举 $w_0(I, q) / (16 F) \le b \le 8 a w_0(I, q)$，每个尺度上把端点对空间按 $\theta b$ 分成半开区间 cell，枚举与以 $q$ 为中心 sup 半径 $w_0(I, q)$ 闭方相交的 cell 全体，cell 内所有合格网格代表都进列表。competitive cone 值 $\le w$ 因此 $|q - r|_1 \le w / L$；$L_0 / L = 1/4$ 因此 $3w/4 \le w_0(I, r) \le 5w/4$；代表合格性给 $b \ge 3w/(32F) > w/(16F)$、$b \le 5 a w < 8 a w$。反过来枚举整 cell 只添加全局锥族里已有的成员，因此两个最小值相同。

cell 枚举的意义是把"共享组选择"从"每查询独立"改为"每 cell 独立"，这样一次组选择可以被 cell 内所有查询重用；这正是 §11 组采样数 $M \ell^{O(1)}$ 的来源。第一次读到这里，我以为 cell 是为了"数值稳定"；其实它是为了**惰性求值下的共享**：一个组的选择独立于**哪个查询**首次请求它，避免"请求顺序"进入分析。

## §10 预测带的构造与速度测试

在 $d_0 = w_T$ 与 $m$ 都到位之后，构造 $d_1, \ldots, d_S$。核心是"预测带"这一层。对每个代表 $(b, r)$，先算宽动作最小 $Z = \min_\alpha V_r(\alpha; m)$；$Z$ 若为 $0$ 或非有限，跳过这个代表。否则 $\widehat v = z(I, r) / Z$ 是每单位预测成本对应的净 shift；速度测试要求 $|\widehat v| \le 1 - \tau$，$\tau = \ell^{-4}$。速度测试不通过时，说明 $|z(I, r)|$ 已经吃掉了几乎整个 $Z$：$W - |z| \le (H^{-1/4} + 4 \tau F) c$ 的界（Lemma 7.1 尾段），这一步在 §13 里作为"非坏 + 速度失败"分支被单独 bound，不需要走带。

对 $1 \le j < M$ 与实 shift $p$，$\Phi_j(p)$ 是"前 $j$ 个孩子前缀最小"，形式上是

$$\min \bigl\{ |s_1^- - r^-| + \sum_{i \le j} m(I_i, s_i) + \sum_{i < j} |s_{i+1}^- - s_i^+| + |s_j^+ - (l_j + p)| \bigr\}$$

其中前 $j$ 个 $s_i$ 满足宽动作前缀限制。每个被最小化的项对 $p$ 是 $1$-Lipschitz，$\Phi_j$ 也是 $1$-Lipschitz。带条件：$|p - p_0 - \widehat v \Phi_j(p)| \le \tau \theta b / M$；两个可行 shift $p, p'$ 满足 $|p - p'| \le 2 \tau \theta b / M + |\widehat v| |\Phi_j(p) - \Phi_j(p')| \le 2\tau \theta b/M + (1 - \tau) |p - p'|$；因此 $|p - p'| \le 2 \theta b / M$。带不需要凸性。

共享端点动作集合 $\mathcal C_{b, r}$ 是 scale-$b$ 网格上"外部端点恰为 $r$、相邻孩子端点相接、每个端点 shift 距 $p_0$ 至多 $6 b$、每个内部切点 shift 满足带方程"的动作列表；空则跳过。

孩子尺度上界：$h_i$ 是 $\max(b/M, \max_{\alpha \in \mathcal C} w_0(I_i, s_i(\alpha)))$ 的最小 2 次幂上界；小于 $1$ 的 2 次幂允许；$h_\Sigma = \sum h_i$。若 $h_\Sigma > 64 F b$ 跳过。选一个 canonical 带动作（固定顺序）在 $i$ 上按 $\max(1, \theta h_i)$ 分别舍入两端点，得舍入动作 $\beta(b, r)$；不同孩子可以把共享端点舍到不同位置，因此 $\beta$ 可能有 gap 或 overlap，作为宽动作使用，并非带动作。若 $\beta \notin \mathcal A_{b, r}$ 或某孩子 $|z(I_i, s_i(\beta))| > 2 h_i$ 也跳过。全部通过的称为 unskipped 代表。

在 good seed 下，最后两个 $\beta$ 检查在 $h_\Sigma$ 检查通过时自动通过。$\theta h_i \ge \theta b / M \ge b / P$（因 $h_i \ge b/M$，$\theta M \ge 1/P$；由 $\theta = \ell^{-40}$、$M = H^{1/20 - o(1)}$、$P = H^{p_*+20}$，$\theta M P \ge \ell^{-40} H^{1/20 + p_* + 20}$ 是巨大的正数）。舍入保留每孩子两端点顺序，保留 $[0, |y|]$。若 spacing $= 1$，误差 $0$；否则每端点误差 $< \theta h_i$。由 $|z| \le w_0 \le h_i$ 得 $|z(I_i, s_i(\beta))| \le h_i + 2\theta h_i \le 2 h_i$。端点 shift 半径舍入后 $\le 6 b + 64 F \theta b < 10 b$。

我对这一段最大的疑问是"$h_i$ 为什么允许小于 $1$ 的 2 次幂"。答案是：$b / M$ 可以小于 $1$（当 $b < M$ 时）；孩子上界 $h_i$ 是"dyadic 上取整"，允许 $1/2, 1/4$；这样 $\max(1, \theta h_i)$ 的舍入 spacing 才在 scale $b$ 网格上（当 $g_b > 1$ 时 $\theta h_i$ 是 $g_b$ 的倍数）。这个细节我第一次读漏了，直接导致我证不下去 "$h_\Sigma \le 64 F b$"。

## §11 组采样、共享与舍入动作

对每个节点 $I$、scale $b$、cell、时间 $1 \le t \le S$，把 cell 内所有 unskipped 代表聚成一组。组内共同选一个成员，选法如下。对 $[b/M, 64 F b]$ 中每个 2 次幂 $h$，$k_h = \min(M, \lceil Q_1 M h / b \rceil)$，$Q_1 = \ell^{80}$。对每个成员 $(b, r)$，把 $\beta(b, r)$ 的孩子和 $\sum d_t(I_i, s_i(\beta))$ 按 $h_i$ 分组估算。若 $k_h = M$，$h_i = h$ 那部分精确包含；否则独立有放回抽 $k_h$ 个孩子索引（同一组同一 scale 共用同一批抽样），对每个孩子 $i$ 若 $h_i = h$ 就取 $d_t(I_i, s_i(\beta))$，否则 $0$；把抽到的和乘 $M / k_h$。连接电荷精确加。选估计最小的成员（固定顺序破平），再评估其实际动作成本。不同父组、不同时间的抽样独立，与后代随机独立。

$Y_t(I, q)$ 是所有 online 查询的最小，若空记 $+\infty$。online 规则在 §12/§13 详细展开，形状是"每 scale 抽一个动作，按孩子历史选 band 动作"。

$d_t$ 的更新：非叶处，若 $w_0(I, q) = 0$ 则 $0$；否则

$$d_t(I, q) = \min \Bigl\{ \Pi_t(I, q), \max \Bigl\{ \frac{\Pi_t(I, q)}{1 + \delta}, Y_t(I, q) \Bigr\} \Bigr\}.$$

叶子仍用精确值。正值 $w_0$ 状态下这条更新把 $Y_t$ 截到 $[\Pi_t/(1+\delta), \Pi_t]$，便宜 online 动作只能在这个区间内改善值；上端保 Bellman 比较，下端把 $\Pi_t$ 的空间正则性以 $1+\delta$ 倍率转给 $d_t$。

引理 5.5 refinement invariants：good seed 下 $d_t$ 关于 $t$ 递减、$\max(c/a, |z|) \le d_t$、$\mathcal B_I(d_t) \le d_t \le \mathcal B_I(d_{t-1})$；$d_t(I, q) \le (1 + \delta) d_t(I, q') + L |q - q'|_1$。证明在 node 高度上、$t$ 上分别归纳。$\Pi_t$ 里 Bellman 选项用 child 的 $d_{t-1}$，因此上界 $\le \mathcal B_I(d_{t-1})$；$\Pi_t$ 里其他选项都是 current-value 宽动作锥，因此 $\ge \mathcal B_I(d_t)$。online $Y_t$ 也是 current-value 宽动作锥，$\ge \mathcal B_I(d_t)$（空集时 $\Pi_t$ 直接被取）。$d_t \le \Pi_t$ 与 $d_t \ge \Pi_t / (1+\delta)$ 合起来给 spatial bound。

组估计精度 Lemma 5.6：good seed 下，条件于完整 child 表，一个组在一个时间 $t$ 的所有动作成本估计以概率 $\ge 1 - H^{-4}$ 落在实际成本 $\pm \gamma b$ 之内；在此事件上，对组内每个 unskipped 成员和每个有效父 $q$、每个带内动作 $\alpha$ 同时成立

$$\Pi_t(I, q) \le L |q - r|_1 + (1 + \delta) x_t(\alpha) + e_* b, \qquad e_* = 2\gamma + 512 L F \theta \le \kappa \delta.$$

Bernstein 部分：单个抽样 $X = (M / b) \ind_{h_i = h} d_t(I_i, s_i(\beta))$，$0 \le X \le 2 M h / b$、$\E X \le 2 h_\Sigma / b \le 128 F$、$\mathrm{Var}(X) \le 256 F M h / b$；$k_h \ge Q_1 M h / b$ 时归一化偏差 $\alpha_0 = \gamma / (2\ell)$，失败概率 $\le 2 \exp(-Q_1 \alpha_0^2 / (512 F + 4 \alpha_0 / 3)) \le 2 \exp(-\ell^{37} / 3000)$。union 域 $2 \ell \times (P+1)^2 \le H^{-4}$ 在绝对 cutoff 上。

## §12 比较树与曲率能量

比较树是纯分析对象，从起点 $(I, q)$（真成本 $D > 0$）出发：每个非常终点取 $c(I, q)$ 的 dyadic scale $b$、$r = r_b(q)$、$e = |q - r|_1 \le 2b/P$；选一条最优对齐路径，在 $M$ 个孩子切点上取路径经过的最早位置；内部锚点向下舍入到 $b$ 网格；$q_i$ 保持有序、共享端点，外部端点恰为 $r$；$\alpha^*$ 是这个动作；在孩子状态上继续。终止于叶子或零成本状态。固定顺序确保整棵树由输入串与起点决定，独立于精修的所有随机。

引理 6.1 comparison costs：每个非常终点 $(b, r)$ 是合格代表，$b$ 满足局部尺度限制，$\alpha^*$ 是宽动作，端点 shift 距 $p_0$ 至多 $6b$；$c(I, r) \le \sum c_i \le (1 + 4 M/P) c$、$c \le L e + \sum c_i$；$C_{\mathrm{term}} \le (1 + 8 M J/P) D \le 2D$；$\sum_{\mathrm{nonterm}} c \le 2 J D$、$\sum_{\mathrm{nonterm}} e \le 4 J D/P$；每一层真成本之和 $\le 2 D$；每个终止点上 $m = c$ 且所有估计等于 $c$。

mass 与 energy：$m_q = m(I, q)$，$m_i = m(I_i, q_i)$，$W = \sum m_i$，$G = W - Z$（比较动作与最小宽动作之差），$R = m_q - W$。曲率 $K = \sum z_i^2 / m_i - z_r^2 / W$（约定 $0/0 = 0$）；加权方差恒等式 $K = \sum (z_i - v m_i)^2 / m_i \ge 0$，$v = z_r / W$。这些权重是 warmup 成本，非区间长度。

引理 6.2 曲率 telescope：每非终点点 $h = L e + w_0(I, q) / T$；则 $\sum (K + G) \le 4 C_{\mathrm{term}} + 3 \sum e + 4 \sum h$；因此 $\sum (K + G) \le 5000 F (1 + J/P + J/T) D$。

证明分两步。第一步 warmup mass slack：对每个宽动作沿 $1, \ldots, T$ 平均 $w_j(I, q) \le L e + V_r(\alpha; w_{j-1})$（child 索引 $0, \ldots, T-1$），最小化得 $m_q - (w_0 - w_T) / T \le L e + Z$，因此 $R + G \le h$、$R_+ \le h$、$G \le R_- + h$。整个树上 $\sum R = m_{\mathrm{root}} - C_{\mathrm{term}}$、$\sum R_- \le \sum R_+ + C_{\mathrm{term}} \le \sum h + C_{\mathrm{term}}$；$\sum G \le C_{\mathrm{term}} + 2 \sum h$。

第二步 local energy telescope：$E(I, q) = z^2 / m$；$|z_q| \le m_q$、$|z_r - z_q| \le e$、$|z_r| \le W$；$e \le 2c/P \le 2 a m_q / P \le m_q$（$a \le A_{\mathrm{init}}$ 且 $2 A_{\mathrm{init}} < P$ 保证），因此 $|z_r| \le 2 m_q$。identity $\frac{z_q^2}{m_q} - \frac{z_r^2}{W} = \frac{z_q^2 - z_r^2}{m_q} + \frac{z_r^2 (W - m_q)}{m_q W}$ 首项 $\le 3 e$（用 $|z_q| \le m_q$ 与 $|z_r| \le 2 m_q$），次项若 $W \le m_q$ 非正、否则 $\le 2 R_-$。因此 $K \le \sum E(I_i, q_i) - E(I, q) + 3 e + 2 R_-$。沿树求和给 $\sum K \le C_{\mathrm{term}} + 3 \sum e + 2 \sum R_- \le 3 C_{\mathrm{term}} + 3 \sum e + 2 \sum h$。加上 $G$ 界得结构式；代入引理 6.1 与 $\sum h \le 512 F J D / P + 4 F J D / T$ 得最终。

bad 节点定义：$K > b H^{-1/4}$ 或 $G > b H^{-1/4}$。推论 6.3 坏节点总真成本 $\le 10000 F H^{1/4} (1 + J/P + J/T) D$（因 $c < 2b \le 2 H^{1/4} (K + G)$）。

覆盖性 Lemma 6.4：非坏且 $|\widehat v| \le 1 - \tau$ 时，$\alpha^* \in \mathcal C_{b, r}$，代表不跳过，$h_\Sigma \le 64 F b$，$\beta$ 通过宽动作与 imbalance 检查。核心是带方程：$p_j^* - p_0 = \sum_{i \le j} z_i$；加权 Cauchy-Schwarz 给 $\sum |z_i - v m_i| \le \sqrt{K W}$；$|v - \widehat v| W = |z_r| G / Z \le G$；$M_j - G \le \Phi_j(p_j^*) \le M_j$ 由"比较前缀可行为 $\Phi_j$"与"任意可行前缀拼比较后缀 $\ge Z$"两侧得。合并

$$|p_j^* - p_0 - \widehat v \Phi_j(p_j^*)| \le \sqrt{K W} + 2 G \le \tau \theta b / M.$$

数值：$M/b (\sqrt{K W} + 2 G) \le \sqrt{8\ell} H^{-3/40} + 2 H^{-1/5} \le \ell^{-44} = \tau \theta$（用 $\ell^{200} \le H^{1/100}$ 换成 $\sqrt{8\ell} \ell^{-1500} + 2 \ell^{-4000}$）。$h_\Sigma$ 界由 $h_\Sigma \le 2b + 4F \sum c_i + 8 L_0 \theta b \le 64 F b$ 得。

我第一次读到这里，最卡的地方是 $\Phi_j$ 的双侧界。上界直观（比较前缀是可行候选）；下界我一度以为需要"prefix + comparison suffix 拼接成宽动作"的严格验证。其实关键在于：任何可行前缀的最后一段 $|s_j^+ - (l_j + p)|$ 恰好就是它与比较后缀的连接；拼出的宽动作 $\ge Z$，因此减去比较后缀部分（$\le M_j$）就有 $\Phi_j \ge M_j - G$。这个"$G$ 出现两次"（一次在带方程里，一次在曲率 telescoping 里）是 §13 entropy regret 界里 $2 G$ 项的来源。

## §13 熵正则在线决策与首次穿越

节点 regret 定义：$\overline d_t(I, q) = \max(c(I, q), d_t(I, q))$；非常终点 $\mathcal R_t(I, q) = \overline d_t(I, q) - L e - \sum \overline d_t(I_i, q_i)$。$\overline d_t$ 的截断是关键：估计可以低于真值，如果不 clip 一个节点的欠估会抵消另一个节点的过估。

引理 7.1 generic regret：$\sum_{t=1}^S \mathcal R_t \le \sum (\overline d_0 - \overline d_S)(I_i, q_i) \le \sum (m_i - |z_i|) \le W - |z(I, r)|$；因此至多 $4 F c$。若该节点非坏且 $|\widehat v| > 1 - \tau$，至多 $(H^{-1/4} + 4 \tau F) c$。

证明：Bellman 与比较动作 $d_t(I, q) \le L e + \sum d_{t-1}(I_i, q_i)$；把右边孩子值换成 clip 后仍 $\ge c$（Eq comparison-split），因此也 bound $\overline d_t(I, q)$；两 $t$ 相减求 telescoping。孩子独立：若 $d_0 \le c_i$ 两侧 clip 都等于 $c_i$，差 $0$，$m_i \ge |z_i|$；若 $d_0 > c_i$，$\overline d_0 = d_0 \le m_i$、$\overline d_S \ge |z_i|$。合起来 $W - |z(I, r)|$。若 $|\widehat v| > 1 - \tau$，$W - |z(I, r)| \le G + \tau W \le (H^{-1/4} + 4 \tau F) c$。

引理 7.2 熵不等式：$\mathcal Q$ 是 $\R^d$ 里非空紧凸概率向量集合，含至少一个每坐标正的向量；坐标分成 block，每向量在每 block 总质量固定；$f_0, \ldots, f_S \in [0, 1]^d$ 逐坐标非增；$\widehat g_t = -f_{t-1}$，$\Delta_t = f_{t-1} - f_t$，$u_t = \widehat g_t + (1 - 2\kappa) \Delta_t$；$\Delta_t$ 每 block 内 range $\le \kappa / \eta$。若 $\rho_t$ 最大化 $\mathcal H(\rho) + \eta \langle \sum_{j<t} u_j + \widehat g_t, \rho \rangle$，则对 $\rho^* \in \mathcal Q$ 与 $0 \le s \le S$：

$$\sum_{t \le s} \langle f_t + \kappa \Delta_t, \rho_t \rangle \le \sum_{t \le s} \langle f_t, \rho^* \rangle + \frac{\ln d}{\eta} + 2\kappa.$$

$\ell_1$ 误差 $\zeta$ 每步加至多 $\zeta$。

证明用 potential $\Psi(v) = \max_\rho \{\mathcal H(\rho) + \eta \langle v, \rho \rangle\}$。$\Psi$ 正性来自"零坐标向正向量挪一小步 $u$，熵增 $u \ln(1/u) + O(u)$ 支配线性项 $O(u)$"。正最大子 $p$ 的一阶最优加相对熵恒等式 $\mathcal H(\rho) - \mathcal H(p) = \langle \nabla \mathcal H(p), \rho - p \rangle - \mathrm{KL}(\rho \| p)$ 得精细惩罚 $\mathcal H(\rho) + \eta \langle v, \rho \rangle \le \Psi(v) - \mathrm{KL}(\rho \| p)$。$v_{t-1} = \sum_{j<t} u_j$；老 objective 在 $\rho_t$ 上取值给 $\Psi(v_{t-1} + \widehat g_t) - \Psi(v_{t-1}) \le \eta \langle \widehat g_t, \rho_t \rangle$（$v_{t-1}$ 递增或递减都成立）。加 $(1 - 2\kappa) \Delta_t$：block 最小 $\mu$ 因每 block 质量固定在 $\mathcal Q$ 上贡献 $\langle \mu, \rho \rangle$ 恒等；剩余 $v'_k = \Delta_t - \mu \in [0, \kappa / \eta]$；惩罚界给 $\eta (1 - 2\kappa) \langle \mu, \rho_t \rangle + \ln \sum_k \rho_{t,k} e^{\eta(1 - 2\kappa) v'_k}$；指数不等式 $e^{(1 - 2\kappa) x} \le 1 + (1-\kappa) x$（$0 \le x \le \kappa \le 1/2$）由"导数 $\ge 0$ 且零点为 $0$"证；求和得 $\Psi(v_t) - \Psi(v_{t-1}) \le \eta \langle \widehat g_t + (1-\kappa) \Delta_t, \rho_t \rangle$。telescoping 求和到 $s$；$\Psi(0) \le \ln d$；最后一势在 $\rho^*$ 上取值，$\mathcal H(\rho^*) \ge 0$；把 $1 - 2\kappa$ 换成 $1$ 时丢项 $\le 2\kappa \sum \Delta_t \le 2\kappa$。反号。

套用到 band：$\mathcal Q = \mathcal Q_{b,r}$，$f_t(i, s) = d_t(I_i, s) / h_i$，child 作 block；每向量质量 $h_i / h_\Sigma$；refinement invariants 给 $0 \le d_S \le \cdots \le d_0 \le w_0 \le h_i$ 满足单调与 unit range。每孩子两个状态端点对距 $\le 4 \theta b / M$；spatial bound 双向用给同一 $t$ 上差 $\le \delta h_i + 4 L \theta b / M$；$h_i \ge b/M$ 因此 $\Delta_t$ block 内 range $\le 3 \delta \le \kappa / \eta$（$\kappa = \tau = \ell^{-4}$、$\delta = \ell^{-10}$、$\eta = \ell^5$ 保证）。带进 $\rho(\alpha)$：$h_\Sigma \langle f_t, \rho(\alpha) \rangle = x_t(\alpha)$，$h_\Sigma \langle f_t + \kappa \Delta_t, \rho(\alpha) \rangle = x_t(\alpha) + \kappa (x_{t-1} - x_t)(\alpha)$。引理给每个固定 $\alpha^*$ 与 $s \le S$：

$$\E \Bigl[ \sum_{t \le s} (x_t(\alpha_t) + \kappa (x_{t-1}(\alpha_t) - x_t(\alpha_t))) \Bigr] \le \sum_{t \le s} x_t(\alpha^*) + h_\Sigma \Bigl( \frac{\ln d_{\mathcal C}}{\eta} + 2\kappa + s H^{-3} \Bigr).$$

首次穿越 $t_\times$：最小的 $t$ 使 $\min_\alpha A_t(\alpha) < c$，$A_t(\alpha) = L e + x_t(\alpha)$；若无则 $S + 1$。这是分析器件，算法不做此测。前缀 clipping 命题：在 $1 \le t < t_\times$ 上

$$\overline d_t(I, q) \le L e + x_t(\alpha_t) + \kappa (x_{t-1}(\alpha_t) - x_t(\alpha_t)) + 2Fc \ind_{E_t},$$

$E_t$ 是组近似失败。若 $\overline d_t(I, q) \le A_t(\alpha_t)$ 立；否则 $d_t$ 更新强制 $\Pi_t(q) > (1+\delta) A_t(\alpha_t)$ 与 $d_t = \Pi_t / (1+\delta)$；早 index Bellman 给 $\Pi_t \le L e + x_{t-1}(\alpha_t)$；令 $\Delta x = x_{t-1} - x_t > \delta A_t(\alpha_t) \ge \delta c \ge \delta b$；$E_t^c$ 上组 bound 与 $e_* \le \kappa \delta$ 得 $d_t - A_t(\alpha_t) \le e_* b / (1+\delta) \le \kappa \delta b / (1+\delta) \le \kappa \Delta x$。$E_t$ 上 $2Fc$ 足够。

$t_\times \le S$ 时：取 crossing 动作；$E_{t_\times}^c$ 上组 bound 给 $\Pi_{t_\times}(q) \le L e + (1+\delta) x_{t_\times}(\alpha) + e_* b < c + 2\delta c$；clip regret $\le 2\delta c$；后续 $t > t_\times$ 上同一动作与 child 单调给 $\mathcal B_I(d_{t-1})(q) < c$ 因此 $d_t < c$、regret 非正。

Proposition 7.5 综合：条件于完整 child 表，

$$\E \Bigl[ \sum_{t \le S} \mathcal R_t \Bigr] \le h_\Sigma \Bigl( \frac{\ln d_{\mathcal C}}{\eta} + 2\kappa + S H^{-3} \Bigr) + 2\delta c + 2 S H^{-4} F c.$$

$h_\Sigma \le 64 F b$，$\ln d_{\mathcal C} \le 4 (p_* + 21) \ell$（$d_{\mathcal C} \le M (21 P)^2$）。

我第一次读这个首次穿越技巧时，感觉它太 engineered；后来才明白：clip 后的父 regret 不能直接用 band 内 regret 覆盖，因为 $\overline d_t$ 只在 $d_t > c$ 处严格大于 $d_t$。$t_\times$ 之后 $d_t < c$ 恒成立（Bellman 单调），regret 变负；$t_\times$ 之前 $d_t > c$ 且所有 $A_t \ge c$，$\overline d_t$ 与 $d_t$ 相等；$t_\times$ 当口跨界贡献 $\le 2 \delta c$ 加 $2 F c$ 概率小量。三段分得很干净。

## §14 中值放大与最终回答

定理 4 精修保证 $\E[\pos{d_S(I, q) - c(I, q)}] \le c(I, q) / \ell$ 与 $d_S(I, q) \ge c(I, q) / a$；$a$ 是 2 次幂整数。证明沿比较树求和，分三类：bad 节点用 Lemma 7.1 与 cor 6.3 给 $40000 F^2 H^{1/4} (1 + J/P + J/T) D$；非坏 + 速度失败节点用 Lemma 7.1 尾段给 $(H^{-1/4} + 4 \tau F) c$；其余用 Prop 7.5。$\sum$ 上限把 $\mathcal E$ 表达式代入并除以 $D$：

$$\mathcal E \le (8 M + 512 F) J / P + 40000 F^2 H^{1/4} (1 + J/P + J/T) / S + \frac{2 J}{S} [\ldots] + 132 F J H^{-3}.$$

代入 $J \le 100 H/\ell$、$T \ge H^{3/4}$、$S = H/\ell^2$、$F = \ell$、$M \le H^{1/20}$、$P \ge H^{20}$：五项分别 $\le 52000 H^{-18}$、$8.04 \times 10^6 \ell^4 H^{-1/2}$、$200 \ell H^{-1/4}$、$10^6 (p_* + 21) / \ell^2$、$13200 H^{-2}$；每项在 $\ell \ge 2^{1000}$、$H \ge 2^{\ell/2}$ 下 $\le 1 / (8\ell)$；总 $\mathcal E < 1/\ell$。

我第一次读到这里以为 $1/8$ 是随手挑的；其实是要求 $\sum 5$ 项 $\le 1/\ell$，$1/8 \cdot 5 < 1$；每一项留 $7/8$ 之外的富余。这些常数不是数学上的必然，是把 union bound 与 slack 摊到最舒服的一档；如果换成 $1/6$、$1/7$ 也行。

Seed 放大：当 $A > F$，$a = A/F$，用 $H^2$ 份独立精修副本；每状态 $H^2$ 个整数 $\lceil a d_S \rceil$ 取上中位次序统计，clamped 到 $[0, N]$。$A \leftarrow 4 a$。

引理 8.2：条件于任一 fixed good seed，下一个 seed 以概率 $\ge 1 - \exp(10 H - H^2)$ 对 $4a$ 因子 good。Markov 给 $\Pr[d_S > 2 c] \le 1/\ell$；每副本 $\lceil a d_S \rceil \ge c$（因 $Fc$ 整数 $a d_S \ge c$）；若严格多于一半副本 $\le 2ac$，上中位数也 $\le 2ac$；一半以上失败概率 $\le 2^{H^2} \ell^{-H^2/2} \le e^{-H^2}$；union $e^{10H}$ 得证。

Pass 数 $s_{\mathrm{pass}} = O((p_* + 1) \ell / \log_2 \ell) < H$；每次 median pass 让 $\log_2 A$ 降 $\log_2 F - 2$，从 $(p_* + 4) \log_2 H$ 降到 $A \le F$。总失败概率 $\le 0.01 + H e^{10 H - H^2} < 1/10$。

最终答案：$A \le F$ 时，$a = 1$ 用一次新精修在 $(I, q) = ((0, |x|], (0, |y|))$，clamped 与向下取整得 $\widehat D$。给定 fixed good seed：确定性下界 $d_S \ge D$；$\Pr[d_S > (1+\varepsilon) D] \le 1 / (\ell \varepsilon) \le 1/10$；总失败 $< 1/5 < 1/3$。clamp 保下界因 $D \le N$；round down 保下界因 $D$ 整数；两者不恶化上界。$D = 0$ 由等值测试确定性返 $0$；exact branches 也正确。

这里我一开始担心 $a = 1$ 精修里 $d_S \ge c / a = c$ 与 $d_S \le c / a + \text{positive part}$ 的确定性下界是否成立。Theorem 4 陈述 "$d_S(I, q) \ge c(I, q) / a$ for every outcome"，$a = 1$ 就是 $d_S \ge c$ 恒成立。这是 clip 从下方把 $\overline d_S$ 换成 $d_S$ 的直接后果，也是"clipping 保下界"这个技巧在整个证明里最重要的一次兑现。

## §15 有限实现：Frank-Wolfe、有理算术与精确采样

online 规则要求"计算一个有限混合，其期望向量与 $\rho_t$ 在 $\ell_1$ 距 $\le H^{-3}$"，再从混合精确采样。这一节把这个契约实现成有限算法，且每一步都算 bit cost。

给定有限有理概率向量列表生成 $\mathcal Q$、有理向量 $v$、整数 $H \ge 4$，$G_0 = H + d + 2$。平滑：$\sigma = G_0^{-50}$；把 $-x \ln x$ 换成 $-(x + \sigma) \ln (x + \sigma)$ 得 $\mathcal F_\sigma$；$\sup |\mathcal F_\sigma - \mathcal F| \le 4 d \sqrt\sigma$（把 $x \ln x$ 求导再积分，含零点）；$\nabla \mathcal F_\sigma$ Euclidean Lipschitz $\le 1/\sigma$；$\mathcal Q$ diameter $\le 2$。

固定步 Frank-Wolfe：初始点是某个 listed 顶点；每步 $j$ 用近似误差 $e_0 = G_0^{-20}$ 的梯度坐标，枚举列表选内积最大顶点 $v_j$（固定顺序破平），更新 $\rho^{(j+1)} = (1 - \xi_j) \rho^{(j)} + \xi_j v_j$，$\xi_j = 2 / (j+2)$。

gap 递归：$D_{j+1} \le (1 - \xi_j) D_j + 2 e_0 \xi_j + 2 \xi_j^2 / \sigma$。$\xi_0 = 1$ 给 $D_1 \le 2 e_0 + 2/\sigma$（与初始线性向量无关），归纳 $D_j \le 2 e_0 + 8 / (\sigma (j+1))$。跑 $K_{\mathrm{opt}} = G_0^{80}$ 步得真 objective gap $\le 2 G_0^{-20} + 8 G_0^{-30} + 8 d G_0^{-25} \le 12 G_0^{-20}$。

强凸转 $\ell_1$：负熵 Hessian 是对角 $\mathrm{diag}(1 / \rho_k)$，在概率单纯形上 $\succeq I$；一阶不等式加 Hessian 界给 objective gap $\ge \frac12 \lVert \rho - \rho_t \rVert_2^2$；因此 $\lVert \rho - \rho_t \rVert_1 \le \sqrt{24 d} G_0^{-10} \le H^{-3}$。

有理表示：$K$ 步后每顶点权重 $\frac{2}{j+2} \prod_{k=j+1}^{K-1} \frac{k}{k+2} = \frac{2(j+1)}{K(K+1)}$；存 selected vertices 序列（可重复），权重和为 $1$。输入顶点共同分母乘 $K(K+1)$ 是迭代点坐标的共同分母。有理对数 $\ln r = 2 \sum_{k \ge 0} b_0^{2k+1} / (2k+1)$，$b_0 = (r-1) / (r+1)$，$|b_0| \le 1 - \sigma$；截断 $K_{\log} = G_0^{60}$ 项误差 $\le 2 e^{-2 K_{\log} \sigma} / ((2 K_{\log} + 1) \sigma) < G_0^{-20}$。梯度近似只用于选顶点，不作为递归表值返回。

精确采样：均匀整数 $R \in \{1, \ldots, K(K+1)/2\}$，用"least power of two $\ge K(K+1)/2$" rejection，每 trial 成率 $> 1/2$；整数二分找最小 $j$ 使 $(j+1)(j+2)/2 \ge R$，返回 $v_j$；期望 bit cost 多项式，固定 buffer。

推论 cor 9.2 online rule 局部期望 cost $2^{o(H)}$：$d \le M (21 P)^2$、$G_0 = H^{O(p_*+1)}$、共同分母 $M h_\Sigma$ bit 长 $O(H)$（不需要跨动作列表相乘分母）；总 $2^{O(M (p_*+1) \ell)} H^{O(p_*+1)} = 2^{o(H)}$（$M \le H^{1/20}$、$\ell = \Theta(\log H)$、$p_* + 1 = O((\log \ell)^{1/4} + 1)$）。存储同样 bound。

这一段我第一次读时最大的疑问是"$\mathcal Q$ 是凸 hull 不是 simplex，为什么 Hessian 界 $\mathrm{diag}(1/\rho_k) \succeq I$ 仍然给 $\frac12 \lVert \rho - \rho_t \rVert_2^2$ 的 objective gap 下界？"答案是：Hessian 下界是**在整个正 orthant 上**成立；$\mathcal Q \subset \Delta^d$，$\Delta^d$ 上负熵对 $L_2$ 度量强凸参 $1$；一阶不等式与强凸不等式合起来 objective gap 下界跟可行集无关；$\mathcal Q$ 的相对熵惩罚形式在 §13 熵不等式证明里也用过（"extend the supremum with its relative entropy penalty to the full simplex"）。这两处的思路是一致的：**在 simplex 上算势，然后限制到 $\mathcal Q$**。

## §16 依赖路径与工作计数

求值顺序：一个 uncached $d_t(I, q)$ 请求；局部锥测与 warmup 决定可用代表、带与舍入动作；评估这些测试可能触发更多 warmup 或 seed 请求；带已知后 wide Bellman search 与 online optimizer 汇集所需早 index 值并 reuse 于其动作枚举；group samples、selected rounded actions、sampled online actions 请求 current-index 孩子值；由 $\Pi_t, Y_t$ 精确 min/max 得 entry 并 cached。

依赖序 lexicographic triple：(pass, index, remaining tree height)；$w_j$ 有 index $j$，$d_t$ 有 index $T + t$，$d_0 = w_T$ 与 $w_T$ 同；seed median 视作其 $H^2$ 份前一 pass 精修请求；带与组算视作调用它的表 entry 的辅助工作。key：initial entry 用 node label + 两个端点；later seed 用 pass + node + endpoints；warmup / refinement 用 kind + pass + copy + node + index + endpoints；representative 辅助数据用 pass + copy + node + scale $b$ + endpoints $r$（不含 $t$）；group result 用 pass + copy + node + $b$ + 两个 cell indices + $t$；online draw 用 pass + copy + node + $q$ + $b$ + $t$。同 cell 组一次性算完整 cell；组结果不依赖**哪个**查询首先请求它。

无条件大小 bound Lemma 10.1：$Q = \ell^{10} + 1$，$h(I)$ 是 $I$ 之下的树剩余高度；每个 $d_t(I, q)$ 的分母整除 $Q^{h(I)}$；带测试、组比较、数值 optimizer 用到的有理数 bit 长 $H^{O(p_*+1)}$；所有本地搜索有限。返回值 bit 长 $O(H + J \log \ell)$。空 online 最小用符号 $+\infty$，公式返回 $\Pi_t$；不需要 unbounded 搜索或 approximate numerical sentinel。

Current-index 预算 Lemma 10.2：一次精修 entry $d_t(I, q)$ 请求至多 $M \ell^{O(1)}$ 个 distinct child entries 在同 pass、copy、index $t$ 上；此 bound 对所有 seed、所有 sample 结果成立。证明对 cell 内 fixed scale $h$ 与 child $i$：$D_h = \max(1, \theta h)$；cell 内 $r^-$ 变化 $\le \theta b$、shift radius $\le 10 b$、$|z| \le 2 h$ 限制第二个端点在长 $4 h$ 区间内；distinct states 至多 $C' \theta^{-2} (1 + b/h)$。若 $k_h < M$，$k_h \le 2 Q_1 M h / b$，distinct inputs $\le C'' M \theta^{-2} Q_1$；若 $k_h = M$，$Q_1 M h / b > M - 1$、$b / h < 2 Q_1$，distinct inputs $\le C' M \theta^{-2} (1 + 2 Q_1)$。$\log(FM) = O(\ell)$ 尺度，poly($\ell$) 个 $b$ scales 与 cells；每组加至多 $M$ 孩子；online 每 scale 加至多 $M$ 孩子。合起来 $M \ell^{O(1)}$。

Lemma 10.3 local evaluation cost：一次 warmup 或 refinement entry 有至多 $H^{O(p_*+1)}$ 个早 index 或早 pass 的 distinct inputs；除 recursive 输入外，条件于 fresh draws 之前已暴露数据，期望 bit cost $2^{o(H)}$；每次执行本地存储至多 $2^{o(H)}$。wide list 每端点 $O(P+1)$ 位置、每孩子 $O((P+1)^2)$ 状态；乘 children、representatives、cells、scales、history indices 仍 $H^{O(p_*+1)}$；history 索引 $T + S + 1 = O(H)$；wide list 至多 $(C(P+1))^{2M}$ 动作；本地算术总量 $2^{O(M (p_*+1) \ell)} H^{O(p_*+1)} = 2^{o(H)}$。dictionary 每 op $H^{O(1)}$ bit cost。

Dependency path count：$D_{\mathrm{same}} = M \ell^{C_1}$、$D_{\mathrm{earlier}} = H^{C_2 (p_* + 1)}$；$K_{\mathrm{dep}} = s_{\mathrm{pass}} (T + S + 1)$；$s_{\mathrm{pass}} = O((p_*+1)\ell / \log_2 \ell)$；depth $j$ 上同 index 边 $\le j$、其他边 $\le K_{\mathrm{dep}}$；路径数 $\le (j+1)(K_{\mathrm{dep}}+1) 2^{j + K_{\mathrm{dep}}} M^j \ell^{C_1 j} H^{C_2 (p_*+1) K_{\mathrm{dep}}}$。$J \log \ell = o(H)$、$q_* K_{\mathrm{dep}} \log H = o(H)$（$q_*^2 = O(\sqrt{\log \ell} + 1)$）、$J + K_{\mathrm{dep}} = o(H)$；$M^j$ 之外的所有因子 $2^{o(H)}$；depth $j$ 展开评估数 $\le M^j 2^{o(H)}$。

Theorem 10.4 expected running time：depth $j$ 区间宽 $\le \lceil n_x / M^j \rceil$；Theorem 3 给"某 initial entry 首次请求"的条件期望 cost $(1 + \lceil n_x / M^j \rceil) 2^{o(H)}$；enumerate 计算展开里的可能请求 slot、每 slot 条件于过去用独立 fresh stream；deterministic slot count 让期望求和；重复请求只付 dictionary 成本。合起来

$$2^{o(H)} \sum_{j=0}^{J} M^j (1 + \lceil n_x / M^j \rceil) \le 2^{o(H)} (O(M^J) + (J+1) n_x) \le (n_x + 1) 2^{o(H)}.$$

$M^J \le M \max(1, n_x)$、$M, J = 2^{o(H)}$；sorting $O(N \log (N+2))$；叶查询 $O(\log (N+2))$；$H = \Theta(\log (N+2))$；合起来 $N^{1+o(1)}$。存储 deterministic 依赖数 bound $N^{1+o(1)}$；每项 entry 至多 $H^{O(p_*+1)}$ auxiliary records；本地 list $2^{o(H)}$ scratch；完全展开 initial estimator 空间 $O(B n)$ 节点 $\times O(n)$ 数组条目 $\times$ polynomial bit 长；剪枝数组用 marker；rejection loops 复用 buffer；absolute polynomial space in $N$ 在 large branch 成立。

对 fixed rational accuracy encoding，其长度最终低于 inspection limit；两个 remaining fallback conditions 也最终不触发；exact DP fallback 只覆盖 fixed $\varepsilon$ 的 bounded $N$ 区间。这一点我在草稿纸上算过：给定 $\varepsilon = 0.01$，$H^2$ inspection limit 在 $N \ge 2^{2^{100}}$ 时被超过；$\ell \ge 2^{1000}$ 与 $\ell \varepsilon \ge 10$ 也在这类 cutoff 之后同时成立。这个数字实际非常大，是"asymptotic approximation scheme"的具体含义。

## §17 与既有路线的对照

对照 AKOS 2010/2011：那套用 hierarchical alignment representation 与 nonuniformly allocated precisions 给 $(\log n)^{O(1/\xi)}$ 因子在 $n^{1+\xi}$ 时间。本论文的初始 seed 直接沿用其 shift tree 与 precision sampling；关键区别是**精修段**。AKOS 的递归没有"预测带"这一层，因此不能把因子压到 $1+\varepsilon$。本文 §10 的带方程 $|p - p_0 - \widehat v \Phi_j(p)| \le \tau \theta b / M$ 是新增结构，它把"哪个动作可行"限制到宽度 $O(\theta b / M)$ 的窄集合，从而让 §11 组采样的 distinct inputs 数量与树大小脱钩。

对照 Mao--Rubinstein 2026：那条线在 $n^2 / 2^{\log^{\Omega(1)} n}$ 时间给 $(1+\varepsilon)$；用了"multiscale deviation constraint"。本文精修段跟它的相似之处是**在采样前先约束对齐路径的可能偏移**；不同之处是本文的 deviation 用**初步成本估计 $m$ 加权**，不是纯粹的长度偏差。加权导致 mass 不守恒（$R = m_q - W$ 可正可负），因此 §12 需要曲率 telescope 与 $R_-$ 边界。这层"用不守恒量的 telescoping 来吸收加权"是本文相对 Mao--Rubinstein 的一个技术增量。

对照 Chakraborty--Das--Goldenberg--Kouck\'y--Saks 2020 与 Brakensiek--Rubinstein 2020 与 Kouck\'y--Saks 2020：那几条给常数因子近似，前一条在 $\widetilde O(n^{12/7})$，后两条在 near-linear 时间但只对"足够远"输入对成立、有 material additive error。Andoni--Nosatzki 2020 移除"足够远"限制，$O(n^{1+\xi})$ 时间与只依赖 $\xi$ 的因子；但那个因子**不随 $\xi \to 0$ 收敛到 1**，因此不算 approximation scheme。本文要跨过的是"因子随 $\varepsilon$ 收敛 + 时间 $N^{1+o(1)}$"两件事同时做到。

对照 metric-weighted edit costs (Mader--Tavasoli--Wang 2026 与 Das--Kipouridis--Kociumaka 2026)：那两条在 strongly subquadratic 时间给 $(3+\varepsilon)$；cost model 比 unit-cost 更广。本文只在 unit-cost 上做，替换、插入、删除各 cost 1；这也意味着本文里所有 $z$、$|z| \le c$、connection 电荷等几何量都是 unit-cost 特化的产物。

对照 OpenAI 2026 编辑失真：那条定理说"任意单一 $\ell_1$ embedding 覆盖到某长度上限的所有 binary strings 必须付出增长 distortion"。本文的算法是"给定 $(x, y)$ 估计它们的距离"，**没有构造共同 embedding**；因此与失真下界不冲突。这一点我在 §1 起手时曾混淆过：近似 scheme 与 embedding 是两件事，前者允许**输入自适应**随机，后者必须**同一映射**处理所有对。

对照 Backurs--Indyk 2018 的 SETH 下界：那条说确定性 strongly subquadratic 编辑距离算法会 refuted SETH。本论文是 random 且近似，跟下界不冲突；下界不排除 fixed-factor approximation，也不排除 $N^{1+o(1)}$ 期望时间的 random scheme。这个"下界与算法的错位"是我要在笔记里明写的一条：不能把 SETH 结果当成本论文动机，也不能反过来用本算法驳 SETH。

## §18 我留下的疑虑

疑虑 A，参数选择的"最优性"。§5 参数表里的 $p_* = \lfloor (\log_2 \ell)^{1/4} \rfloor$、$T = 2^{\lceil (3/4) \log_2 H \rceil}$、$Q_0 = H^4$、$Q_1 = \ell^{80}$ 这些数字，我没能证明它们是"最省时间的可能选择"。Theorem 10.4 只要求 $T \ge H^{3/4}$（保证 $h$ 项被平均稀释）、$Q_0 \ge H^3$ 与 $Q_1 \ge \ell^{40}$（保证 union bound 完胜）；具体数值是把这些不等式摊到最方便的一档。[推测] 论文作者大概率是"先写约束、再挑最紧的可用整数幂"，我按同样流程试过 $Q_1 = \ell^{60}$，Bernstein 部分失败概率仍是 $\exp(-\ell^{17})$，union 域 $H^{2p_* + 41}$ 也能吃下；但把裕量再削到 $\ell^{40}$ 附近时，Prop 7.5 里的 $h_\Sigma (\ln d_{\mathcal C} / \eta)$ 项与 §14 五项 bound 中的 $(p_*+21)/\ell^2$ 会打平。所以真正的"瓶颈参数"是 $\eta = \ell^5$ 与 $\ln d_{\mathcal C}$ 的比例，$Q_1$ 只是配套。

疑虑 B，"exact arithmetic 与 rational sampling 全部算进 expected time"。§16 明确说期望 bound 里包含 rational arithmetic 与 exact sampling；但我在草稿纸上算 bit cost 时，$H^{O(p_*+1)}$ 里的隐含常数我没跟到底。Lemma 10.1 说分母整除 $Q^{h(I)}$ 是**表值**，$\beta$ 舍入与 $h_\Sigma$ 检查是**独立有理测试**；bit 长 $H^{O(p_*+1)}$ 里的 $O$ 具体是几，论文没给。[推测] 大致 $p_* + 20$ 量级；这个数字对最终 $N^{1+o(1)}$ 无影响，但对具体常数敏感。

疑虑 C，"$\varepsilon$ 与 $N$ 联合"的行为。论文 §2 geometry 明确"do not assert polynomial dependence on $1/\varepsilon$ or a joint bound when the accuracy varies with $N$"。这个"pointwise in $\varepsilon$"的表述对渐近 approximation scheme 是标准的，但我在实际应用里想量化"N 多大时 $\varepsilon = 0.01$ 的算法真正生效"完全做不到。fallback 分支的 cutoff 是 $\ell \ge 2^{1000}$、$H \ge 2^{\ell/2}$；把这两个条件代回 $\ell$ 定义，$N \ge 2^{2^{2000}}$ 量级，这个数字远远超过任何 practical input。这也是论文为什么自称 asymptotic approximation scheme。[推测] 论文作者对 practical 场景不感兴趣；本文的贡献点是"存在性 + 结构性"，具体工程化留白。

疑虑 D，"$\mathrm{Bernoulli}$ 型 threshold 抽样的方差"。§7 concentration 部分我复核过：$\mathrm{Var}(\phi_i(h_i)) \le u h_i$ 是"当 $h_i < u$ 时 $\phi_i$ 是 $u \mathrm{Bernoulli}(\lfloor B h_i / u \rfloor / B)$，否则常数 $h_i$"两个 case 都成立；$h_i < u$ 时 $\mathrm{Var} = u^2 \cdot p (1 - p) \le u^2 p = u \cdot \lfloor B h_i / u \rfloor \le u h_i$。这一步没问题，但 Bernstein 里我用了"total bias $\le u$"这一句；具体是 $\sum_i |h_i - \E \phi_i(h_i)| \le B \cdot u / B = u$；这个"$\le u$"是"每步 $u/B$" 累加 $B$ 次的结果。这个"总 bias 只有一步 bias 的 $B$ 倍"是**独立性**给的；如果 $t_i$ 之间不是独立，这一句就崩。§7 说 $R_i$ 独立因此 $t_i$ 独立；OK。

疑虑 E，"$Q_1 M h / b$" 的舍入方向。Lemma 10.2 里 $k_h = \min(M, \lceil Q_1 M h / b \rceil)$ 的 ceiling 是我在草稿纸上重算过的一处：如果 $k_h = M$ 分支要求 $b/h < 2 Q_1$，得从 $\lceil Q_1 M h / b \rceil = M$ 反推 $Q_1 M h / b > M - 1$；$M \ge 2$ 意味着 $Q_1 h / b > (M-1)/M \ge 1/2$，即 $b/h < 2 Q_1$。这一步是"两个分支互斥且完备"的检查；我一开始把 $Q_1 h/b > 1/2$ 写成 $b/h < 2 Q_1$ 时漏了"分支条件 $M \ge 2$"；如果 $M = 1$，$k_h = \min(1, \lceil \cdot \rceil) = 1$ 恒成立，$b/h$ 无界。$M = 2^{\lfloor \log_2 H / 20 \rfloor}$，在 $\ell \ge 2^{1000}$、$H \ge 2^{\ell/2}$ 分支下 $M \ge 2^{2^{985} / 20} \ge 2$；所以 $M \ge 2$ 恒成立。这个"分支不空"是 §5 参数层给的。

疑虑 F，"$\beta$ 与 $\alpha^*$ 的关系"。§10 里"canonical band action" 是一个固定顺序选择的带动作；引理 5.4 里 $\beta$ 的 rounding 保证 $V_r(\beta; d_t) \le (1+\delta) x_t(\alpha) + (6L + 2) \theta h_\Sigma$。我第一次读这里以为是"beta 近似 alpha"；实际是"beta 是 alpha 的舍入版，$x_t(\beta)$ 与 $x_t(\alpha)$ 差在 $\theta h_\Sigma$ 阶"。舍入把带共享端点变回宽动作，代价是 connection 电荷 $\le 2 \theta h_\Sigma$；这跟 §12 曲率里"比较树的孩子状态是**共享**端点、$\beta$ 是**分开**舍入的"这一对比是同一件事的两面。

疑虑 G，"$\delta$ 与 $Y_t$ 的下界"。$d_t = \min\{\Pi_t, \max\{\Pi_t / (1+\delta), Y_t\}\}$ 里，若 $Y_t < \Pi_t / (1+\delta)$ 就取 $\Pi_t / (1+\delta)$；这意味着"再便宜的 online 动作也不会把 $d_t$ 拉到低于 $\Pi_t / (1+\delta)$"。这一层 clipping 是 §13 首次穿越论证的必需结构：若没这个 clipping，$d_t$ 可能突然跌到"某个动作的 raw cost"，Bellman 单调性会破坏。我第一次读没意识到"$Y_t$ 需要被 $\Pi_t$ 从下方挡一下"，导致我写的粗糙版里 $\overline d_t$ 与 $d_t$ 相等的区域跟 $t_\times$ 定义冲突。

## 0 我进场时手里有什么

论文的第一句话就把算子钉死（`introduction:3-7`）：

```tex
For $f\in L^1_{\mathrm{loc}}(\R^2)$, the centered disk maximal function is
\[
 Mf(x)=\sup_{r>0}\frac1{\pi r^2}\int_{B(x,r)}|f(y)|\,\dd y,
 \qquad B(x,r)=\{y\in\R^2:|y-x|<r\}.
\]
```

三个词是我后面所有麻烦的来源：centered（每个平均盘都以取值点为心）、all positive radii（半径跑遍 $(0,\infty)$）、$|f|$（先取绝对值再平均，所以 $Mf\ge0$ 且不可用符号抵消直接处理）。Kinnunen 已经把 $1<p<\infty$ 的 $W^{1,p}$ 有界性证死了（`introduction:9-10`，转述 `\cite[Theorem~1.4]{Kinnunen1997}`），逐点梯度被 $M(|\nabla f|)$ 控制，再过强 $L^p$ 极大不等式就拿到范数界。`introduction:13` 那句 "At $p=1$ that last step fails" 就是整篇的起点：逐点界还在，但 $p=1$ 时强型极大不等式罢工，弱型又只给 $L^{1,\infty}$，梯度那条链断在最后一个环节。Hajłasz 与 Onninen 于是把"梯度估计本身在 $p=1$ 是否幸存"提成问题（`introduction:14-15`，`\cite[Question~1]{HajlaszOnninen2004}`）。

语料与队列登记：本篇的全部材料在 `preprints/An-Endpoint-Gradient-Bound-for-the-Centered-Disk-Maximal-Operator-September-26-2026` 下，队列第 43 行号。

主定理（`introduction:19-29`）逐字：

```tex
\begin{theorem}\label{thm:main}
There is an absolute constant $C<\infty$ such that, for every
real-valued $f\in W^{1,1}(\R^2)$, the function $Mf$ is locally
integrable, belongs to $W^{1,1}_{\mathrm{loc}}(\R^2)$, and satisfies
\begin{equation}\label{eq:main}
 \int_{\R^2}|\nabla Mf|\,\dd x
 \le C\int_{\R^2}|\nabla f|\,\dd x.
\end{equation}
In particular, its distributional derivatives are represented by
globally integrable functions.
\end{theorem}
```

我读定理时把量化顺序拆开对齐了一遍，因为它决定机器那边核对什么：$\exists C<\infty$，使得 $\forall$ 实值 $f\in W^{1,1}(\mathbb R^2)$，有 $Mf\in L^1_{\mathrm{loc}}\cap W^{1,1}_{\mathrm{loc}}$ 且 $\|\nabla Mf\|_1\le C\|\nabla f\|_1$。三点容易被读掉：

1. 这是**全局**积分界（右边是 $\int_{\mathbb R^2}|\nabla f|$，左边是 $\int_{\mathbb R^2}|\nabla Mf|$），但正则是**局部**的（$W^{1,1}_{\mathrm{loc}}$）。`introduction:33-38` 明确说 $Mf$ 本身可以不全局可积（对非零非负紧支撑光滑函数就不行），所以"$\nabla Mf$ 全局可积"是一个比"$Mf\in W^{1,1}$"弱得多的结论，论文很小心地只声明前者。
2. $W^{1,1}$ 是非齐次的（函数与其弱一阶导都全局可积），且对输入不加径向性、不加紧支撑（`introduction:31-34`）。
3. 常数 $C$ 有限、绝对，最优值未确定（`introduction:36-37`）。这一句让我后面所有"常数怎么来的"追问都有了合法落点：作者在意的只是"$C$ 不依赖半径尺度个数"，具体数值可以随便放大。

已知结果里，我要先想清楚哪些能搬、哪些搬不动，因为这决定我被迫新造什么。一维那条线很完整：Tanaka 对非中心极大算子证了 $L^1$ 导数界（`introduction:77-78`）；Aldaz 与 Pérez Lázaro 把输入扩到有界变差、证了绝对连续性、拿到 sharp 变差常数 $1$（`introduction:79-82`）；Kurka 对中心算子在 BV 输入上拿到带绝对常数的变差界、局部 Sobolev 正则与 Sobolev 输入的可积导数（`introduction:83-86`）。关键一句在 `introduction:87-88`：

> The ordering of intervals used in these arguments does not directly organize a family of centered disks.

这就是壁垒的本质。一维靠**区间包含的偏序**组织极大半径，二维圆盘的包含关系不是全序也不是树，两个中心不同的盘可以互相穿插。我手里没有任何等价的全序能套。

高维那条线：Aldaz 与 Pérez Lázaro 对 block-decreasing 输入（坐标变号不变、每个正坐标单调不增）与无条件范数的非中心球算子证了正则（`introduction:90-95`）；Luiro 对径向 Sobolev 输入与非中心球算子拿到 $L^1$ 梯度界（`introduction:96-98`）；Weigt 对 dyadic 极大算子与轴平行立方体的非中心算子拿到变差界（`introduction:99-101`）。`introduction:101-104` 给了两条排除理由：几何与索引结构和中心圆盘不同；而且变差估计只控制一个导数**测度**，那个测度仍可能有奇异部。分数阶那条线（Beltran 与 Madrid、Weigt，`introduction:104-111`）对 $0<\beta<1$、径向 $W^{1,1}$ 输入拿到中心端点界，但正阶 $\beta$ 限制了最优球的相互重叠，$\beta\to0$ 时机制退化。还有一条条件定理值得记下：Lahti 与 Weigt 把"中心极大函数的局部 BV"在输入 Sobolev 时升级成局部 Sobolev（`introduction:113-116`），但**前提**就是那个变差界。论文 `introduction:117-118` 的话是路线宣言：我先把那个界证出来，然后用带符号局部化直接去掉奇异部。

至于用户提到的 Alepidea、Beltrán、Vallverdú 与 Ionescu、Varilly 一系的球面极大算子正则文献：我核对了 `references.bib` 的全部键，它们**不在**本篇引用里。本篇直接对话的是上面那一串（Kinnunen、Hajłasz–Onninen、Tanaka、Aldaz–Pérez Lázaro、Kurka、Luiro、Weigt、Beltran–Madrid、Lahti–Weigt、Hajłasz–Malý、Saari、Carneiro–Madrid–Pierce、González-Riquelme、Stein）。所以下面凡涉及那两个名字的地方我都不把它们当成本篇的引用依据。

## 1 端点壁垒在哪：我最初想直接搬的三条路

进场第一件事是假设"这大概是个已知技术的二维版"，然后逼自己把每条捷径走到断。

**路线甲：仿一维，找极大半径的偏序。** 一维的机器把 $\{r: Mf(x)=A_r|f|(x)\}$ 组织成区间，Tanaka/Kurka 用变差对区间端点求和。我试着把"以 $x$ 为中心的圆盘按半径排序"当那个偏序：同一中心下 $r$ 单调嵌套，确实全序。问题是梯度 $\nabla Mf(x)$ 不只看**同一个** $x$ 的嵌套族，而要看 $x$ 动一点点时哪个盘变成最优、哪个盘退出，于是比较的是**不同心**的盘。不同心的圆盘没有单调性。我算了一步：$x$ 位移 $\epsilon$，最优半径从 $r$ 跳到 $r'$，两盘交集体积是 $O(\epsilon\cdot r)$ 量级的一个弓形，但被平均的 $|f|$ 在这个弓形里没有任何符号或单调结构，界不住。**失败机制**：把偏序建在同心的半径上，而需要控制的是跨心扰动；这两件事在一维重合（区间包含完全由端点决定），在二维分开。**[推测]** 这大概率就是 `introduction:87-88` 那句排除的精确含义。

**路线乙：直接搬 Luiro 的最优球变分恒等式。** Luiro 在非中心球情形用最优球的一族变分得到带权梯度恒等式（论文 `local:104-108` 承认这条血缘，但说 "There the balls optimize averages of $|f|$. We derive the identities needed here directly for centered signed averages"）。我一开始以为可以直接调 Luiro 的两个引理（`\cite[Lemmas~2.2 and~2.4]{Luiro2018Radial}`）。试着一代，两处对不上：一是 Luiro 是**非中心**，最优球可自由选择中心，一阶最优性条件含"对中心求变分"，而本文中心被钉死在 $x$，只有**对半径**这一个变分方向可用；二是 Luiro 平均的是 $|f|\ge0$，最优半径处 $\partial_r$ 只给**一侧**符号信息，而本文中途处理的是**带符号**平均 $A_tg$，需要 $\partial_r u_r$ 的实符号。两处都必须重推。**失败机制**：非中心自由度的丢失让恒等式只剩"径向"与"旋转"两个来源，正是要在 `local:113-118` 重立的那两条。

**路线丙：套 Lahti–Weigt 的条件定理。** 它说：只要先证中心极大函数局部 BV，输入 Sobolev 时自动局部 Sobolev。这是最省事的路线：我只需证 BV 界，奇异部的删除交给现成定理。但 `introduction:116-118` 立刻自曝其短："It assumes the requisite variation bound." 也就是 BV 界本身还是要我证，而证 BV 界比证 $W^{1,1}$ 更难（BV 允许奇异测度，界反而更松更难收紧）。我读完 assembly 与 extension 才确认丙其实是被**反着用**的：论文在 extension 末尾的 Remark（`extension:219-232`）里说，得到 $\eqref{eq:main}$ 之前那条变差界 `eq:variation-limit` 之后，可以**备选地**套 Lahti–Weigt。也就是说丙被降级成"锦上添花的第二条收尾路"，主线仍然是它自己的绝对连续性论证（`extension:121-203`）。**失败机制**：丙把最难的一步外包，但那一步正是本文存在的全部理由，没有可外包的余地。

三条路断完，剩下的形状很清楚：我不能建全局偏序、不能借非中心自由度、不能外包 BV。唯一能建的结构是**局部的、带符号的、按 dyadic 尺度分层的**近似偏序，跨心的比较用"抵消"，并非"排序"来付账。

## 2 第一个转折：把问题降维成带符号的有限带宽估计

真正把方向掰过来的是中间命题（`introduction:52-61`）：

```tex
\begin{proposition}[Signed finite-band estimate]\label{prop:finite-band}
There is an absolute constant $C$ such that, for every real
$g\in C_c^\infty(\R^2)$ and $0<a\le b$ with $b/a$ a power of two, including one,
\begin{equation}\label{eq:intro-band}
 \int_{\R^2}|\nabla S_{a,b}g|\,\dd x
 \le C\int_{\R^2}|\nabla g|\,\dd x.
\end{equation}
The constant is independent of $a$, $b$, and the number of dyadic
radius scales between them.
\end{proposition}
```

我盯着它看了很久，因为它同时改了四件事，每一改都对应我上面的一条失败：

- 输入从 $|f|$（非负、取过绝对值）换成 $g$（带符号、光滑紧支撑）。带符号是关键：`introduction:64-73` 说最终要用在 $g_Q=\chi_Q(g-c_Q)$ 上，$c_Q$ 是局部均值，$\chi_Q$ 在被测小盘上等于 $1$，于是 $A_tg_Q=A_tg-c_Q$，对应包络**梯度相同**（常数 $c_Q$ 求导没了），而 Poincaré 把 $\|\nabla g_Q\|_1$ 由稍大正方形的 $\nabla g$ 界住。$g_Q$ 会变号。所以带符号不是美学选择，是"允许减局部均值"这条局部化通道的门票。这一步和 Saari 的 local/nonlocal 分裂减输入均值（`introduction:280-283`）同源。
- 半径从全部 $(0,\infty)$ 换成有限带 $[a,b]$，且要求 $b/a$ 是 2 的幂（`introduction:54`，包括幂为 0，即 $a=b$）。幂 2 是让尺度可数、可按 $k$ 分层；$a=b$ 单半径那情形 `introduction:63` 说卷积直接给 $\nabla A_ag=A_a(\nabla g)$，Tonelli 给 $\int|\nabla A_ag|\le\int|\nabla g|$，是免费基例。
- 结论"$C$ 与 $a,b$ 以及两半径间的 dyadic 尺度个数无关"（`introduction:59-61`）。这是最难的一条：带变宽、尺度数 $m=\log_2(b/a)$ 变多，界不许变。
- $S_{a,b}g$ 紧支撑且 Lipschitz（`introduction:48-50`），所以 $\nabla S_{a,b}g$ 作为 a.e. 经典梯度存在，积分有意义；难点纯粹在"随带宽增长的梯度积分一致界"。

我起初以为带符号会让估计更难（正负都可能大），读完才理解符号是**自由度**：正部与负部可以配对抵消，这是后面整个"标量抵消 + 公共价格"构造的燃料。非负情形反而没这个燃料。

尺度归约在 `introduction:132-133`：缩放把带宽估计归到半径在 $[2^{-m},1]$。于是 $r_k=2^{-k}$，$k=1,\dots,m$，$b/a=2^m$。这一约让"半径尺度个数"变成显式的 $m$，而"对所有 $m$ 一致"变成"常数不许含 $m$"，这是我能全程盯的靶子。

`introduction:134-137` 给出全文骨架的一句话宣言，我把它当写作提纲：

> The proof has one geometric input and two separate multiscale constructions. The first construction organizes scalar cancellation; the second chooses directions and pays for their changes in both scale and space.

一个几何输入 = 薄壳里的集中（切圆盘扫描，`local:228-395`）。两个多尺度构造 = 标量抵消与公共价格（`prices`），方向律与方向改变付账（`labels`）。assembly 是总账，extension 是收尾。这个提纲是我最先读通、也最后才确认没读错的东西。

## 3 几何输入 I：磁盘矩与平衡核（Lemma 2.2）

几何输入的根子是两个恒等式（`local:113-118`），我把它们当"每个盘天生自带的免费信息"：

```tex
\begin{equation}\label{eq:local-moment-identities}
\operatorname{Im}\int_{B(x,t)}\overline{y-x}\,dh(y)=0,
\qquad
\partial_tu_t(x)=\frac1{\pi t^3}
 \operatorname{Re}\int_{B(x,t)}\overline{y-x}\,dh(y).
\end{equation}
```

补中间步骤。第一条：把 $\mathbb R^2$ 认作 $\mathbb C$，$\overline{y-x}\,dh(y)$ 是复测度。$\operatorname{Im}\overline{y-x}$ 对应 $(y-x)^\perp$ 方向（旋转 $90^\circ$）。论文 `local:119-121` 说第一条来自对 $g(y)(y-x)^\perp$ 的散度积分：$(y-x)^\perp$ 散度为零（常系数反对称矩阵 $\begin{psmallmatrix}0&-1\\1&0\end{psmallmatrix}$ 作用在 $y-x$ 上，$\operatorname{div}((y-x)^\perp)=0$），且它**切于**边界圆（径向向量与它的 $\perp$ 正交）。于是 $\int_{B(x,t)}\operatorname{div}(g(y)(y-x)^\perp)\,\dd y=\int_{\partial B}g(y)(y-x)^\perp\cdot\nu\,\dd s=0$，因为 $(y-x)^\perp\cdot\nu=(y-x)^\perp\cdot\frac{y-x}{|y-x|}=0$。散度定理左边展开成 $\int_{B(x,t)}\nabla g(y)\cdot(y-x)^\perp\,\dd y$，这恰是 $\operatorname{Im}\int_{B(x,t)}\overline{y-x}\,dh(y)$。恒等式对**每个盘、无需最优**成立，这就是"$h$ 的旋转一阶矩为零"。

第二条：$u_t(x)=\pi^{-1}\int_{B(0,1)}g(x+tw)\,\dd w$，对 $t$ 求导，边界项由 Reynolds 输运定理给出，正比于 $\operatorname{Re}\int_{B(x,t)}\overline{y-x}\,dh(y)$，尺度因子 $1/(\pi t^3)$。在**内部最优半径**处 $\partial_tu_t=0$，于是实部一阶矩也为零。

两个零（虚部永远零、实部在最优半径零）合起来：最优点处复一阶矩 $\int_{B(x,t)}\overline{y-x}\,dh(y)=0$。但硬盘 $B(x,r)$ 的特征函数在边界上不可微，逐点用这两条不稳。Lemma 2.2（`local:128-146`）把"盘"平滑成一个平衡核：

```tex
\begin{lemma}[Balanced kernels]\label{lem:local-balanced}
Suppose that $r\in[1,2]$ and $0<\delta\le1/4$, and that
\[
u_r(x)\ge u_{r-\delta}(x),\qquad u_r(x)\ge u_{r+\delta}(x).
\]
There is a probability density $k$ supported on $[r-\delta,r+\delta]$, bounded by $C/\delta$,
such that
\[
K(y)=\int k(t)\mathbf1_{B(x,t)}(y)\,dt
\]
satisfies
\begin{equation}\label{eq:local-zero-moment}
\int K(y)\overline{y-x}\,dh(y)=0.
\]
Moreover, $0\le K\le1$, $\Lip(K)\le C/\delta$,
$K=1$ on $B(x,r-\delta)$, and $K=0$ outside $B(x,r+\delta)$.
The density may be chosen measurably in $(x,r)$.
\end{lemma}
```

(a) 陈述逐字如上。(b) 推导：证明（`local:148-165`）把 $t^{-3}$ 在 $[r-\delta,r]$ 与 $[r,r+\delta]$ 上**各自**归一化成两个概率密度 $k_-,k_+$。用它们平均 $\eqref{eq:local-moment-identities}$ 的第二条得实矩 $M_-,M_+$。因为 $\partial_tu$ 的符号与 $u_r\ge u_{r\pm\delta}$ 相容，积分那条恒等式给出 $M_-\ge0,\ M_+\le0$。若 $M_--M_+>0$，取凸组合 $k=ak_-+(1-a)k_+$，$a=-M_+/(M_--M_+)$，则混合实矩 $aM_-+(1-a)M_+=0$；两矩都零时取 $k=k_-$。虚矩在两个区间上分别已为零，所以整条复矩为零。$k$ 支撑在 $[r-\delta,r+\delta]$、被 $C/\delta$ 控（归一化因子与 $\delta$ 可比，因为 $3/4\le t\le9/4$）。$K$ 是一族盘特征函数对 $k$ 的混合：$0\le K\le1$，$K=1$ 在 $B(x,r-\delta)$（凡 $t\ge r-\delta$ 都含它）、$K=0$ 在 $B(x,r+\delta)$ 外，Lipschitz 常数由边界壳宽 $\sim\delta$ 给出 $\le C/\delta$。$a$ 的公式是 Borel 的（零处分了约定），所以 $(x,r)\mapsto k$ 可测。(c) 常数的机械理由：为什么用 $t^{-3}$ 当密度？因为 $\partial_tu_t$ 的实矩项前面正好挂着 $1/(\pi t^3)$（`local:116-117`），拿它当测度去平均，混合后恰好把"实矩加权和"变成"加权和后取矩"，一步凑成零。为什么 $\delta\le1/4$？保证 $r\pm\delta$ 仍在可比区间、$t\in[3/4,9/4]$，归一化因子 $\asymp\delta$ 与 $1$ 有界偏离，于是 $\Lip(K)\le C/\delta$ 里的 $C$ 绝对。(d) [推测] 三条候选错路：其一，用单个硬盘 $K=\mathbf1_{B(x,r)}$，$r$ 恰是极值点但非内部极值（$\mathcal J(x)$ 含端点 $1,2$）时 $\partial_ru_r$ 未必零，实矩非零，且硬盘无 Lipschitz，壳上逐点差不可控。其二，用均匀混合 $k\equiv1/(2\delta)$，它一般不满足 $aM_-+(1-a)M_+=0$，只有当 $M_-+M_+=0$ 才平衡，等于放弃抵消。其三，取 $k$ 为高斯核，光滑但拖出 $[r-\delta,r+\delta]$ 的尾巴，破坏 $K=1$ 于内盘、$K=0$ 于外盘，后面 `local:571` 那句"因为 $K_l=1$ 在 $B(x,r-\delta_j)$"用不上。

`local:168-172` 那句过渡我特别留意："The difference is supported in the larger shell. The following elementary observation explains what we want to know about the mass on that shell." 平衡核的作用是造出**一族两两相差在薄壳里、且每个都带零矩**的 $K$，下一节才把壳上的质量用仿射因子压下去。

## 4 几何输入 II：仿射抵消恒等式（Lemma 2.3）

有了零矩，就要问"两个平衡核差在壳上的积分能省多少"。Lemma 2.3（`local:174-211`）：

```tex
\begin{lemma}[Affine cancellation]\label{lem:local-affine}
Let $x\in\R^2$, $r\in[1,2]$, $0<\delta\le1/4$, and
\[
 D=\{y:\bigl||y-x|-r\bigr|\le\delta\}.
\]
Let $h$ be a complex measure whose variation is finite on $B(x,3)$.
Suppose that $K_0,K_1:\R^2\to[0,1]$ are Borel functions supported in
$B(x,3)$, that $K_1-K_0$ is supported in $D$, and that
\[
 \int K_i(y)\overline{y-x}\,dh(y)=0\qquad(i=0,1).
\]
Set $P_i=\int K_i\,dh$. For every $z\in D$,
\begin{equation}\label{eq:local-affine-identity}
 P_1-P_0=\int
 \left(1-\frac{\overline{y-x}}{\overline{z-x}}\right)
 (K_1-K_0)(y)\,dh(y).
\end{equation}
For every $0<\rho\le1$, this implies
\begin{align}\label{eq:local-affine-bound}
 |P_1-P_0|\le{}&2\rho\int_{D\cap B(z,\rho)}
                    |K_1-K_0|\,d|h|\notag\\
 &+10\int_{D\setminus B(z,\rho)}|K_1-K_0|\,d|h|.
\end{align}
\end{lemma}
```

(b) 推导补全。$P_1-P_0=\int(K_1-K_0)\,dh$。两条零矩给出 $\int K_i\overline{y-x}\,dh=0$，相减再除 $\overline{z-x}$：$\int(K_1-K_0)\frac{\overline{y-x}}{\overline{z-x}}\,dh=0$。把这个零从 $P_1-P_0$ 里减去，得 $\eqref{eq:local-affine-identity}$，乘子正是 $W_z(y)=1-\frac{\overline{y-x}}{\overline{z-x}}=\frac{\overline{z-x}-\overline{y-x}}{\overline{z-x}}=\frac{\overline{z-y}}{\overline{z-x}}$（`local:204-206`）。这一步的几何意义是：$W_z(z)=0$，所以在 $z$ 附近 $\frac{\overline{z-y}}{\overline{z-x}}$ 的分子 $|z-y|$ 小，权 $W_z$ 小。分母不为零靠 $|z-x|\ge r-\delta\ge3/4$（`local:200`）。区域拆分：在 $B(z,\rho)$ 内 $|W_z(y)|=\frac{|z-y|}{|z-x|}\le\frac{\rho}{3/4}=\frac43\rho\le 2\rho$（论文取 $2\rho$ 作宽松常数，`local:207`）；在 $D$ 上 $|y-z|\le|y-x|+|x-z|\le(r+\delta)+(r+\delta)\le2(r+\delta)\le9/2$，而 $|z-x|\ge3/4$，故 $|W_z|\le\frac{9/2}{3/4}=6\le10$（`local:208-209`）。把积分按 $D\cap B(z,\rho)$ 与 $D\setminus B(z,\rho)$ 两段夹住即得 $\eqref{eq:local-affine-bound}$。(c) 假设与常数的理由：为什么壳宽 $\delta\le1/4$、半径 $r\in[1,2]$？这是尺度归约后的固定窗口，它让 $r-\delta\ge3/4$ 给出分母下界 $3/4$，从而两个区域的乘子上界 $2\rho$ 与 $10$ 是绝对数（$10=6$ 放大、$2\rho=\frac43\rho$ 放大）。为什么允许"任意 $z\in D$"？因为下一节会把 $z$ 选成"壳质量集中到的那个帽点"，$z$ 是外生给的，本引理只需它对每个 $z$ 成立，不需要选得可测。`local:213-217` 的点题："concentration near $z$ turns the factor $1$ in a variation estimate into the small factor $2\rho$. We will call $D\cap B(z,\rho)$ a cap of the shell." 于是问题被翻译成纯几何一句：**何时壳质量的绝大部分能塞进一个帽 $D\cap B(z,\rho)$**。这就是 Lemma 2.4。(d) [推测] 三条错路：其一，直接在 $D$ 上粗估 $|P_1-P_0|\le\int_D|K_1-K_0|\,\dd|h|$，乘子按 $\le10$ 全程吃，等于没有集中，壳上质量全额付费，后面尺度求和发散。其二，把 $W_z$ 当解析函数用留数，但 $h$ 只是一般复测度、$1/\overline{z-x}$ 只在对 $x$ 固定时关于 $y$ 光滑，留数框架不适用。其三，选 $z$ 依赖半径 $r$，导致例外集随 $r$ 变化，无法对所有半径同时移除；这正是 Lemma 2.4 非要把例外集做到"不含 $r$"的动机（`local:263-264`：neither the exceptional set nor its bound involves a choice of $r$）。

## 5 几何输入 III：切圆盘扫描与一个覆盖所有半径的例外集（Lemma 2.4）

这是全篇唯一的"几何输入"，我把它当成最硬的一块单独啃。Lemma 2.4（`local:235-265`）：

```tex
\begin{lemma}[Concentration in a thin shell]\label{lem:shell-concentration}
Let $S$ and $\nu$ be finite positive Borel measures on $\R^2$, let
$U>0$ and $T\ge0$, and suppose that
\[
0<\rho\le1,
\qquad 0<\delta\le\frac{\rho^2}{1600}.
\]
Write
\[
D(x,r,\delta)=\{y:\bigl||y-x|-r\bigr|\le\delta\}.
\]
There is a Borel set $E\subset\R^2$ such that
\begin{equation}\label{eq:shell-exception}
|E|\le C\left[
  \left(\frac{\nu(\R^2)}{U}\right)^2\frac{\delta}{\rho}
  +\frac{\nu(\R^2)}{U}\frac{\delta}{\rho^2}
           \left(1+\frac{T}{U}\right)\right],
\end{equation}
and the following implication holds for every $x\notin E$ and every
$r\in[1,2]$: if
\begin{equation}\label{eq:shell-hypotheses}
\nu(D(x,r,\delta))\ge U,
\qquad S(B(x,r-\delta))\le T,
\end{equation}
then there is $z\in D(x,r,\delta)$ for which
\begin{equation}\label{eq:shell-cap}
(S+\nu)\bigl(D(x,r,\delta)\setminus B(z,\rho)\bigr)\le2U.
\end{equation}
The constant in \eqref{eq:shell-exception} is absolute.
\end{lemma}
```

先读清两个测度的分工（`local:219-226`）：$\nu$ 探测"壳上误差质量是否大到需要走这套"，$S$ 是梯度的正部贡献；结论要同时控 $\nu$ 与 $S$ 在壳上，但可用的假设只在内盘 $B(x,r-\delta)$ 上界 $S$（第二个前提 $S(B(x,r-\delta))\le T$）。若结论里出现整个 $S(\mathbb R^2)$，这条内盘信息就浪费了。切圆盘扫描正是让"内盘界够用"的几何。

(b) 推导，我把 `local:267-394` 摊成中间步。置 $v=200\delta/\rho^2$，由 $\delta\le\rho^2/1600$ 得 $v\le200/1600=1/8$。固定 $z$，单位向量 $\theta$，考察**切于 $z$** 的一族盘 $B(z+L\theta,L)$，$L>0$。成员判据（`local:282-285`，Lean 里对应 `Model:307-313` mem_tangent_ball_iff）：令 $w=y-z$，$y\in B(z+L\theta,L)\iff|w|^2<2L\,w\cdot\theta$。当 $w\cdot\theta>0$，进入参数 $L_*(y)=|w|^2/(2w\cdot\theta)$（Lean: `entryParameter`）。

现在把壳点与切族挂钩。固定 $x,z$，$l=|x-z|\in[1/2,3]$，$\theta=(x-z)/l$。若 $|y-z|\ge\rho$ 且 $\bigl||y-x|-l\bigr|\le2\delta$，令 $a=(y-z)\cdot\theta$。差平方估计：$\bigl||y-z|^2-2la\bigr|=\bigl||y-x|^2-l^2\bigr|\le13\delta$（这一步就是 Lean 的 `shell_square_error:337-346`，$|d^2-l^2|=|d-l|(d+l)\le2\delta\cdot(l+2\delta+l)\le2\delta(2l+2\delta)\le2\delta(6+1/2)=13\delta$，用了 $l\le3,\delta\le1/4$）。由 $|y-z|\ge\rho$ 得 $|y-z|^2\ge\rho^2$，配 $\le13\delta$ 的偏差与 $\delta\le\rho^2/1600$，得 $a\ge\rho^2/12>0$（Lean `shell_projection_lower:349-357`）。于是进入参数满足 $|L_*(y)-l|\le78\delta/\rho^2<v/2$（Lean `entry_window:359-373`，$\le13\delta/(2a)\le13\delta/(2\rho^2/12)=78\delta/\rho^2$）。结论：所有这样的 $y$ 严格在参数 $l-v$ 与 $l+v$ 之间进入切族。

反向（Lean `earlier_tangent_disk_subset:398-434`）：若 $|y-z|\ge\rho$ 且 $y\in B(z+(l-v)\theta,l-v)$，则 $a>\rho^2/(2(l-v))\ge\rho^2/6$（因 $l-v\le3$），推出 $|y-x|^2<l^2-2va\le l^2-\frac{200}{3}\delta<(l-2\delta)^2$。即 $\{y:|y-z|\ge\rho\}\cap B(z+(l-v)\theta,l-v)\subset B(x,l-2\delta)$（`local:311-314`）。这就是图 `figures/tangent-disks.tex` 画的东西：切族参数从 $l-v$ 到 $l+v$ 这一段，把帽外质量"在 $l-v$ 之前就已装进内盘 $B(x,l-2\delta)$"，而 $l-2\delta\le r-\delta$（因 $|l-r|=|x-z|-r\le\delta$ 在 $z\in D(x,r,\delta)$ 时成立），于是内盘质量落在被 $S(B(x,r-\delta))\le T$ 控住的区域。

接下来是构造那个不含 $r$ 的例外集。对 $z,\theta$ 定义 $H_{z,\theta}(L)=S(\{y:|y-z|\ge\rho\}\cap B(z+L\theta,L))$（$L\le0$ 取 $0$），它关于 $L$ 单调不降、联合 Borel。条件 $\mathcal C(x,z)$（`local:333-336`）：$H_{z,\theta}(l-v)\le T$ 且 $H_{z,\theta}(l+v)-H_{z,\theta}(l-v)\ge U$。主函子（`local:338-347`）

$$\mathcal M(x)=\frac1U\int_{1/2\le|x-z|\le3}\Big[\frac1U\int\mathbf1_{\{||y-x|-|x-z||\le2\delta,\,|y-z|\ge\rho\}}\,\dd\nu(y)+\mathbf1_{\{\mathcal C(x,z)\}}\Big]\,\dd\nu(z),\quad E=\{x:\mathcal M(x)\ge1\}.$$

逻辑（`local:349-363`）：设前提成立而帽结论对每个 $z\in D$ 都失败，则每个 $z$ 看到 $\nu(D\setminus B(z,\rho))>U$ 或 $S(D\setminus B(z,\rho))>U$。前者使第一个方括号项 $>1$（因 $y\in D\setminus B(z,\rho)$ 落在 $\{|y-z|\ge\rho,||y-x|-l|\le2\delta\}$ 里）。后者：$S(D\setminus B(z,\rho))>U$，而 $D\setminus B(z,\rho)$ 里质量在切族 $l-v$ 前已进内盘（被 $\le T$ 控），$l-v$ 到 $l+v$ 之间新进入 $\ge U$，故 $\mathcal C(x,z)$ 两条件都成立，第二个方括号 $\ge1$。两种情形方括号都 $\ge1$，配 $\nu(D)\ge U$ 得 $\mathcal M(x)\ge1$。所以帽结论在 $E$ 外对**所有** $r$ 同时成立。

面积界（`local:365-394`）：第一项，固定 $y,z$（$|y-z|\ge\rho$），满足 $||x-y|^2-|x-z|^2|\le13\delta$ 且 $|x-z|\le3$ 的中心 $x$ 落在宽 $\le13\delta/|y-z|$、截在 $\overline B(z,3)$ 里的带形，面积 $\le C\delta/\rho$（差平方是 $x$ 的仿射函数，梯度长 $2|y-z|$）。Tonelli 给第一项 $\le C\nu(\mathbb R^2)^2\delta/(U^2\rho)$，正是 $\eqref{eq:shell-exception}$ 第一号。第二项：固定 $z,\theta$，记 $H$、$G=\min(H,T+U)$，在满足 $\mathcal C$ 的 $l$ 上 $G(l+v)-G(l-v)\ge U$；$G$ 单调有界故 $\int_{\mathbb R}(G(l+v)-G(l-v))\,\dd l\le2v(T+U)$（`local:388-390`：对 $[-M,M]$ 积分时重叠区间相消，只剩两端各长 $2v$ 的段），故许可 $l$ 总长 $\le2v(1+T/U)$。绕 $z$ 的极坐标 $l\le3$ 加 Tonelli 给第二项 $\le C\nu(\mathbb R^2)v(1+T/U)/U$。$|E|\le\int\mathcal M$ 合成 $\eqref{eq:shell-exception}$。(c) 假设与常数的机械理由：$1600$ 从哪来？它是让 $v=200\delta/\rho^2\le1/8$ 且进入窗 $78\delta/\rho^2<v/2$ 与 $a\ge\rho^2/12$、$a>\rho^2/6$ 同时成立的安全裕度；把 $1600$ 调小会让某些 $\delta$ 破坏 $v\le1/8$，切族包含关系崩。为什么 $l\in[1/2,3]$？$z\in D(x,r,\delta)$、$r\in[1,2]$、$\delta\le1/4$ 强制 $|x-z|\in[r-\delta,r+\delta]\subset[3/4,9/4]\subset[1/2,3]$，这个窗口保证分母 $|z-x|$ 有下界、带形面积估计的 $|x-z|\le3$ 成立。$U,T$ 是两个独立阈值，一个当"多少质量算大"，一个当"内盘允许多少正质量"，$T/U$ 出现在第二项是因为 $G$ 的界 $T+U$。(d) [推测] 三条错路：其一，给每个 $r$ 单独取例外集 $E_r$，再对 $r\in[1,2]$（连续）求并，不可数并无 Borel 结构、面积无从累加；构造 $\mathcal M$ 把 $r$ 藏进方括号的两个 $\nu$-测试里正是为了消掉 $r$ 的依赖。其二，用 Besicovitch 覆盖帽族，但那会给覆盖重数买单且丢内盘单调性，切族"参数单调 $H_{z,\theta}$"提供的相消（$G$ 的差在 $l$ 上积分只剩两端）就没了。其三，直接对 $S$ ，并非"仅内盘 $S(B(x,r-\delta))$"设界，那 $\nu(\mathbb R^2)/U$ 那项会带上整个 $S$，$T$ 消失、$\eqref{eq:shell-cap}$ 退化，回到第 4 节失败其一。

## 6 三个局部估计的合体（Lemma 2.1）

几何准备好，Lemma 2.1（`local:21-68`）把分解与三条界写死。我逐字列出前提与三条结论。

```tex
\begin{lemma}[Local estimates]\label{lem:local}
Let $Q$ be a square of side length one and let
$\Omega=\{y:\dist(y,Q)<10\}$. Suppose that, on $\Omega$,
\begin{equation}\label{eq:local-decomposition}
h=\sum_i v_i\sigma_i+\beta,
\qquad \beta=\sum_d\beta_d.
\end{equation}
The sums are finite. The measures in the sums are finite, defined on
$\R^2$, and absolutely continuous with respect to Lebesgue measure.
Each $\sigma_i$ is nonnegative and each $v_i$ is a constant unit vector.
For each $d$, write $m_d=|\beta_d|(\R^2)$ and assign a number
$s_d\in(0,1]$. If $s_d<1$, assume that
$\beta_d(\R^2)=0$ and that $\beta_d$ is supported in a ball of radius

\[
S=\sum_i\sigma_i,
\qquad A=\sum_d s_d^\alpha m_d.
\]
For $x\in Q$, define
\begin{align*}
\mathcal I(x)
&=\{r\in[1,2]:u_r(x)\ge u_t(x)
                 \text{ for every }t>0\text{ with }|t-r|\le1/4\},\\
\mathcal J(x)
&=\{r\in[1,2]:u_r(x)=\max_{1\le t\le2}u_t(x)\}\cup\{1,2\}.
\end{align*}
Then ... (1) directional; (2) size; (3) value; ...
\end{lemma}
```

(b) 我把每条的推导链补到中间步骤，因为它们共用同一台机器（dyadic 宽度 $j$、活跃/非活跃、壳引理）。公共骨架（`local:405-461`）：置 $b=2\alpha=1/50,\eta=1/10,\gamma=1/5,\delta_j=2^{-j}$（`local:408-412`），选极小 $\delta_*$ 使 $\delta_*= \le1/4$ 且 $\delta\le\delta^{2\gamma}/1600$ 对 $\delta\le\delta_*$ 成立（这条把壳引理的 $1600$ 条件喂给每个 $\delta_j$）。定义粗误差测度 $\nu_j=\sum_{s_d\ge\delta_j^2}|\beta_d|$、$p_j=\int K_j\,\dd\beta$、$D_j=D(x,r,\delta_j)$。基本抵消（`local:427-439`）：$\nu_j(\mathbb R^2)\le A\delta_j^{-b}$，因为对 $s_d\ge\delta_j^2$ 有 $s_d^{-\alpha}$ 求和被 $s_d^{\alpha}\cdot s_d^{-2\alpha}=s_d^{-\alpha}\le\delta_j^{-2\alpha}=\delta_j^{-b}$ 吃掉；$|p_j|\le CA\delta_j^{-\alpha}$，来自 $\bigl|\int K_j\dd\beta_d\bigr|\le Cm_d\min(1,s_d/\delta_j)$（用小支撑球中心减 $K_j$ 值，靠 Lipschitz $C/\delta_j$）再 $\min(1,a)\le a^\alpha$。细误差（`local:441-447`）：对 $\Lip(F)\le C/\delta_j$ 的测试，$\bigl|\sum_{s_d<\delta_j^2}\int F\,\dd\beta_d\bigr|\le\frac C{\delta_j}\sum s_dm_d\le CA\delta_j^{1-b}$，用到每片 $\beta_d(\mathbb R^2)=0$（常数项消掉）。增量测试（`local:454-461`）：$|p_{j+1}-p_j|+\bigl|\int\overline{y-x}(K_{j+1}-K_j)\dd\beta\bigr|\le C(\nu_j(D_j)+A\delta_j^{1-b})$。

## 7 标量测度分解：从最细层向外的精确配对（Lemma 3.1、Lemma 3.2）

局部估计要一条一个尺度的分解 $h=\sum_iv_i\sigma_i+\sum_d\beta_d$，且每个误差片 $s_d^\alpha m_d$ 打折可和。第 7、8 节（`prices.tex`）把 $\nabla g$ 拆出这套，并给每个 dyadic 格定一个对所有方向通用的价格。这一节的输入是 $g\in C_c^\infty$，$m\ge1$ 固定、界对 $m$ 一致（`prices:4-11`）。

先把 hat 函数与细化系数钉住（`prices:22-67`）。$r_k=2^{-k}$、$V_k=r_k\mathbb Z^2$，$Q_p=p+[0,r_k)^2$，

$$\phi_p(x)=\prod_{j=1}^2\Big(1-\frac{|x_j-p_j|}{r_k}\Big)_+.$$

即一个顶点 $p$ 的 $\phi_p$ 是两个一维帐篷的积：在自己坐标取 $1$，一网格宽处线性降到 $0$。细化系数 $\lambda_{pq}=\phi_p(q)$（$i<k$）或 $\mathbf1_{\{p=q\}}$（同层）。三条恒等式（`prices:37-48`）：$\sum_{p\in V_i}\lambda_{pq}=1$、$\phi_p=\sum_{q\in V_k}\lambda_{pq}\phi_q$、$\lambda_{ps}=\sum_q\lambda_{pq}\lambda_{qs}$。补推导（`prices:49-58`）：先看一维，固定网格上帐篷和为 $1$（相邻两顶点间只有这两个帐篷非零、仿射互补），粗帐篷在每个细网格区间上仿射（断点全在细网格上），故等于它在细顶点值的分段仿射插值；取积得前两条，第二条在 $s$ 处求值即第三条。归一化是对**粗指标** $p$ 每固定细顶点 $q$ 做的，`prices:56-58` 强调"these are refinement weights, not stochastic transition rows"（细化权，不是随机转移行）。若 $\lambda_{pq}>0$ 则每坐标 $q_j-p_j\in\{-r_k/2,0,r_k/2\}$，于是每顶点恰有九个正权子节点、支撑沿正权边嵌套 $\supp\phi_q\subseteq\supp\phi_p$（`prices:60-67`）。

向量质量与极分解（`prices:69-92`）：$h_p=\int\phi_p\dd h$、$a_p=|h_p|$、$h_p=a_p\theta_p$（$a_p=0$ 时 $\theta_p$ 取定单位向量）。细化给 $h_p=\sum_q\lambda_{pq}h_q$，于是 $\sum_{p\in V_i}a_p\le\sum_{q\in V_k}a_q\le V$（`eq:prices-vector-mass-budget`，`prices:83-90`），左三角不等式+列和，右由 $\sum_q\phi_q=1$。

锥坐标（`prices:94-143`）：$\tau=1/100$，取单位圆的 $\tau/20$-net $\mathcal N$（弦距）。$n^\perp$ 逆时针转 $90^\circ$，

$$e_+(n)=\tfrac{\sqrt3}{2}n+\tfrac12n^\perp,\quad e_-(n)=\tfrac{\sqrt3}{2}n-\tfrac12n^\perp,$$

单位向量且 $e_+\cdot e_-=1/2$。$(q,n)$ 称 good 若 $\theta_q$ 落在 $e_-,e_+$ 夹角扇形（即与 $n$ 角 $\le\pi/6$，`labels:40-41`）。两个标量坐标 $c_{n,\pm}(z)=\frac{n\cdot z}{\sqrt3}\pm n^\perp\cdot z$ 满足 $z=e_+(n)c_{n,+}(z)+e_-(n)c_{n,-}(z)$、$|c_{n,+}|+|c_{n,-}|=2\max\{|n\cdot z|/\sqrt3,|n^\perp\cdot z|\}\le2|z|$（`prices:113-120`）。good 时两坐标非负，这是正部锥测度的来源。锥代数不等式（`eq:cone-algebra`，`prices:129-143`）：$|z|\le C(n\cdot z+\sum_\varepsilon(-e_\varepsilon(n)\cdot z)_+)$，括号非负。补它的非负性证明（`prices:137-143`）：记 $a=n\cdot z$；$a>0$ 显然；$a=0$ 时两负部之一 $=|z|/2$；$a<0$ 时两负部和 $\ge-(e_++e_-)\cdot z=\sqrt3|a|$，故括号 $\ge(\sqrt3-1)|a|>0$。单位圆上连续故正最小值，旋转不变性使最小值与 $n$ 无关，齐次性给常数 $C$。这条是 assembly 里把 $|\nabla F_{1m}|$ 拆成"沿 $n$ 的投影 + 两个不利投影"的代数引擎。

标量缺陷（`eq:prices-scalar-defects`，`prices:154-171`）。$\mathcal C=\{c_{n,+},c_{n,-}:n\in\mathcal N\}$（带指标，重复保留指标）。$\nu^c=c(h)$、$c_s=\int\phi_s\dd\nu^c$。对 $s\in V_l$，

$$d_s^c=\begin{cases}\tfrac12\big(\sum_{t\in V_{l+1}}\lambda_{st}|c_t|-|c_s|\big),&l<m,\\ \tfrac12\big(\int\phi_s|c(\nabla g)|\dd x-|c_s|\big),&l=m.\end{cases}$$

三角不等式+细化保证非负。它衡量"$s$ 处能配对删去的等量正负质量"。最层用密度正负部本身定义，故 $c_s=0$ 不必 $d_s^c=0$（`prices:171`）。

Lemma 3.1（等量删除，`prices:178-198`）：给定非负测度 $U,V$ 质量 $P,N$，存在子测度 $\mu_\pm$ 各质量 $d=\min(P,N)$，使 $U-V=\rho+\mu_+-\mu_-$，$\rho$ 常号、$|\rho|(\mathbb R^2)=|P-N|$。证明就是按比例 $d/P,d/N$ 取 $\mu_\pm$、$\rho=(U-\mu_+)-(V-\mu_-)$，$P\ge N$ 时 $\mu_-=V,\rho=(1-N/P)U\ge0$。`prices:174-176` 特意说这是"proportional removal; it does not require the two measures being paired to be mutually singular"（比例删除，不要求两测度互奇异），这点我起初担心会要求 Lebesgue 分解，读完确认不需要。

Lemma 3.2（精确标量配对，`prices:200-293`）：对每个 $c$ 存在 $\rho_s^c,\mu_{s,\pm}^c$ 支撑在 $\supp\phi_s$、绝对连续，满足 $\rho_s^c(\mathbb R^2)=c_s$、$|\rho_s^c|=|c_s|$、$\mu_{s,\pm}=d_s^c$；置 $\beta_s^c=\mu_{s,+}^c-\mu_{s,-}^c$，则对每个 $q\in V_k$ 有**全平面上的测度恒等式** $\phi_q\nu^c=\rho_q^c+\sum_{l=k}^m\sum_{s\in V_l}\lambda_{qs}\beta_s^c$，且 $\beta_s^c(\mathbb R^2)=0$、$|\beta_s^c|\le2d_s^c$、$\supp\beta_s^c\subseteq\overline B(s,\sqrt2 r_l)$。(b) 推导：自底向上。$l=m$ 对终端测度 $U_s=\phi_s(\nu^c)_+,V_s=\phi_s(\nu^c)_-$ 用 Lemma 3.1，二者质量差 $c_s$、质量和 $\int\phi_s|\nu^c|$，故较小质量恰 $d_s^c$，得终端恒等式 $\phi_s\nu^c=\rho_s^c+\beta_s^c$。归纳：$l$ 处合并子层残量正负部 $U_s=\sum_t\lambda_{st}(\rho_t^c)_+,\ V_s=\sum_t\lambda_{st}(\rho_t^c)_-$，因残量常号，$P_s-N_s=\sum_t\lambda_{st}c_t=c_s$、$P_s+N_s=\sum_t\lambda_{st}|c_t|$，故 $\min(P_s,N_s)=d_s^c$，再删得 $\sum_t\lambda_{st}\rho_t^c=\rho_s^c+\beta_s^c$。验恒等式（`prices:272-288`）用细化与系数合成交换求和，逐层回推。`prices:299-319` 还给等价的**路径形式**：$\phi_qc(h)=\rho_q^c+\sum_\xi(\mu_{\xi,+}^c-\mu_{\xi,-}^c)$，$w_\xi=\prod\lambda$、$\mu_{\xi,\pm}=w_\xi\mu_{q_l,\pm}$，每条路径对质量 $w_\xi d_s^c$。(c) 预算恒等式（`eq:prices-scalar-defect-budget`，`prices:321-337`）：$\sum_{l=1}^m\sum_sd_s^c=\tfrac12(\int|c(\nabla g)|\dd x-\sum_{s\in V_1}|c_s|)\le\tfrac12\|c\|V$，$\|c\|=2/\sqrt3$（`prices:333-335`）来自坐标算子范数。逐层求和时中间绝对质量按列归一化相消，这是 telescoping。(d) [推测] 三条错路：其一，自顶向下分配，会丢"每个配对保留出生层与支撑"（`introduction:192-195` 强调 bottom-up 保留 birth level 与 support），且顶层 $d_s^c$ 依赖密度正负部、无法向细处传。其二，假设 $\mu_+,\mu_-$ 互奇异来做 Jordan 分解，会把绝对连续性破坏或引入非必要的密度；比例删除绕开。其三，只在格点上写离散恒等式而不作为**测度**恒等式，则第 6 节壳引理要"误差片在全平面有定义、只是求和时在 $\Omega$ 上等于 $h$"这一条（`local:28` "The component measures themselves will always remain defined on the whole plane"）落空。

## 9 方向邻居预算与好标签（Lemma 4.1、Lemma 4.2）

公共价格付掉标量抵消，剩下的附近向量质量 $a_q$ 要靠"跨尺度跨位置选方向、只为方向改变付账"来收。第 9 到 11 节（`labels.tex`）造方向律。先记方向改变的两种成本（`labels:8-32`）：一是 run（同方向的最大连续层段）结束产生端点项，成本是相邻层改方向概率 $R_k$；二是对 $x$-依赖权做分部积分产生权重导数，成本是 $T_k$（缩放行导数）。`labels:14-21` 给出关键恒等式：任意有限 Lipschitz 概率行 $(\omega_j(x))$ 有 $\sum_j\nabla\omega_j=0$，故 $\sum_jU_j\nabla\omega_j=\sum_j(U_j-U_*)\nabla\omega_j$，导数成本由**差** $U_j-U_*$ 控制，并非值本身；$U_j-U_*$ 在 assembly 里被小半径振荡 $v_l$ 界，$l$ 层格上 $\int v_l$ 花 $r_l$ 倍价，而 $k$ 层帐篷行导数量级 $r_k^{-1}$，合起来带比率 $r_l/r_k=2^{k-l}$。这一句把 $\eqref{eq:label-packing}$ 里 $2^{k-l}$ 权重的来历讲透。

邻居方向选择（`labels:48-69`）：每顶点 $z\in V_k$ 在 $|w-z|_\infty\le300r_k$ 里挑使 $a_w$ 最大的 $w(z)$，令 $\Theta_z=\theta_{w(z)}$，取 $n_z$ 使 $|n_z-\Theta_z|\le\tau/20$。$E_k(q)=\max_{|z-q|_\infty\le200r_k}|\Theta_z-\theta_q|^2\in[0,4]$，$A_j=\sum_{p\in V_j}a_p\le V$。Lemma 4.1（邻居预算，`labels:71-139`）：$\sum_{k=1}^m\sum_qa_qE_k(q)\le CV$。(b) 推导：固定 $k,q$（$a_q>0$），取 $E_k(q)$ 的最大者 $z$、$w=w(z)$；$q$ 是 $w(z)$ 候选故 $a_w\ge a_q$、$|w-q|_\infty\le500r_k$。取 $L=12$，$p\in V_{k-L}$ 每坐标最近：$|q-p|_\infty\le\tfrac12r_{k-L}$、$|w-p|_\infty\le(\tfrac12+500\cdot2^{-12})r_{k-L}<\tfrac58r_{k-L}$。于是 $\phi_p(q)$ 每坐标 $\ge1/2$、$\phi_p(w)>\ 3/8$，故 $\lambda_{pq}\ge1/4,\lambda_{pw}\ge9/64$。写 $H_{p,k}=\sum_s\lambda_{ps}a_s-a_p$，向量细化给 $H_{p,k}=\sum_s\lambda_{ps}a_s(1-\theta_p\cdot\theta_s)=\tfrac12\sum_s\lambda_{ps}a_s|\theta_s-\theta_p|^2$（`labels:106-112`，用 $\theta_p\cdot h_p=a_p$ 在零质量也成立）。平方距离三角不等式+两下界+$a_w\ge a_q$ 给 $a_qE_k(q)\le2a_q(|\theta_q-\theta_p|^2+|\theta_w-\theta_p|^2)\le CH_{p,k}$。固定 $k$ 每粗顶点被至多固定数个（依赖 $L$）细顶点选中，列和给 $\sum_qa_qE_k(q)\le C\sum_pH_{p,k}=C(A_k-A_{k-L})$。再 $\sum_{k=1}^m(A_k-A_{k-L})\le LV$（每个非负增量至多出现 $L$ 次）。(c) 常数理由：为什么用 $L=12$？要让 $500\cdot2^{-12}=500/4096\approx0.122<\tfrac58-\tfrac12=0.08$？实际是 $0.5+0.122=0.622<0.625=\tfrac58$，勉强成立；$L=12$ 恰是让 $w$ 落进 $p$ 帐篷支撑（$\lambda_{pw}>0$）又不把 $L$ 放太大以控增量重数 $L$。为什么 $\Theta$ 选"邻居最大质量"？`labels:48-51` 说这防止一个小邻居质量强加一笔未付的方向改变。$200r_k$（$E_k$）小于 $300r_k$（$w(z)$ 搜索）保证 $z$ 的 $\Theta_z$ 被 $E_k(q)$ 看到。(d) [推测] 错路：其一，$\Theta_z=\theta_z$ 不取邻居，则零质量邻居的方向噪声会污染 $E_k$，且没有 $a_w\ge a_q$ 来把 $E_k$ 折进 $H_{p,k}$。其二，用 $L=1$ 的近祖，则 $500r_k$ 半径远超 $r_{k-1}=2r_k$，$w$ 跑出 $p$ 帐篷，$\lambda_{pw}=0$，$H$ 界断链。其三，直接界 $E_k$ 而不借 $a_q\le a_w$，则失去"以质量为权"的 telescoping，$\sum(A_k-A_{k-L})\le LV$ 用不上。

有限状态标签律（`labels:141-229`）。每点 $x$ 定义 $\mathcal N^m$ 上概率律 $\Prob_x$：第一步按 $\phi_z(x)$ 采 $z\in V_1$ 设 $n_1=n_z$；$k\ge2$ 条件于旧标号 $n$，按 $\phi_z(x)$ 采 $z$，以概率 $p_k(n,z)=P(|n-\Theta_z|)$，$P(d)=\min\{1,\tau^{-2}(d-\tau)_+^2\}$ 切到 $n_z$，否则保留。转移行 $\pi_k(x;n,\cdot)=\delta_n+\sum_z\phi_z(x)p_k(n,z)(\delta_{n_z}-\delta_n)$，$\pi_1(x)=\sum_z\phi_z(x)\delta_{n_z}$。切换率 $R_k(x)=\Prob_x(n_k\ne n_{k-1})$（$R_1=R_{m+1}=1$ 哨兵），缩放行导数成本 $T_k(x)=r_k\sum_n\zeta_{k-1}(x;n)\sum_{n'}|\nabla_x\pi_k(x;n,n')|$。$0\le R_k\le1,\ 0\le T_k\le C$。Lemma 4.2（好标签，`labels:231-249`）：$c_*=(\tau/10)^2$，若 $E_k(q)\le c_*$、$|x-q|_\infty\le50r_k$，则 $(q,n_k)$ 概率 $1$ 为 good。(b)：$\phi_z(x)>0$ 者 $|z-q|_\infty<51r_k<200r_k$ 故 $|\Theta_z-\theta_q|\le\sqrt{E_k(q)}\le\tau/10$。初值或切换标号距 $\theta_q$ $\le\tau/10+\tau/20$；保留的标号 $P(|n-\Theta_z|)<1\Rightarrow|n-\Theta_z|<2\tau$，距 $\theta_q<21\tau/10$。两界都 $<2\sin(\pi/12)$（$\tau=1/100$），故夹角 $<\pi/6$。(c) $c_*=(\tau/10)^2$ 是把 $E_k$（平方距离）与 $\tau/10$（距离）对齐；$2\sin(\pi/12)$ 阈值来自弦距与角换算、good 扇形半角 $\pi/6$ 对应 $2\sin(\pi/12)$。$50r_k$ 邻域比 $\mathcal R(Q)$ 的 $20r_k$ 略大，好覆盖格。(d) [推测] 错路：其一，切换概率用 $P(d)=\min\{1,\tau^{-2}d^2\}$（不减 $\tau$），则 $\tau$ 内的小摆动也切换，run 端点爆炸；那个 $(d-\tau)_+$ 死区（`labels:146-147` "the interval on which the switching probability vanishes"）专为不让小方向浮动造端点。其二，$n_z$ 不要求 $|n_z-\Theta_z|\le\tau/20$，采样误差与保留误差叠加会越过 $\pi/6$。其三，把 $p_k$ 设成硬阈值（$d>\tau$ 必切），失去 Lipschitz 性，$T_k$ 无界。

## 10 粒子测度与本征标记（Lemma 4.4、Lemma 4.5）

要把路径上的估计变成"逐格向量质量之和"，需要一个不依赖 $x$ 的正路径测度精确实现 $a_q$。路径节点 $\xi=(q_1,\dots,q_k)$，$b_\xi=\prod_{j<k}\lambda_{q_jq_{j+1}}$、$M_\xi=b_\xi a_{q_k}$、关联向量 $b_\xi h_{q_k}$。子容量 $M_\xi\le\sum_{\eta\text{ child}}M_\eta$（向量相加）。选所有层一根的闭帐篷支撑遇 $\supp h$ 的树，保留到层 $m$ 的正权路径（有限森林），则 $a_q>0$ 时 $\sum_{\xi:q_k=q}b_\xi=1$、$\sum_{|\xi|=k}M_\xi=A_k$。

Lemma 4.4（有限粒子测度，`labels:331-389`）：存在有限正测度 $\mu$ 在（终端路径，出生层 $B\in\{1,\dots,m\}$）对上，使对每节点 $\xi$ 于层 $k$ 有 $\mu\{B\le k,(q_1,\dots,q_k)=\xi\}=M_\xi$；特别 $\mu\{B\le k,q_k=q\}=a_q$、$\mu(\text{all})=A_m\le V$；终端位置 $y=q_m$ 满足 $|y-q_s|_\infty<r_s$；路径在出生层之前也有定义。(b) 构造：层一根造质量 $M_\xi$ 出生层 $1$。已存在于层 $k$ 节点 $\xi$ 的群体质量 $M_\xi$，子层和 $S_\xi=\sum_\eta M_\eta$；$S_\xi>0$ 时把每类群体的比例 $M_\eta/S_\xi$ 送往子 $\eta$（送到 $M_\xi M_\eta/S_\xi\le M_\eta$），在 $\eta$ 造额外质量 $M_\eta-M_\xi M_\eta/S_\xi$ 出生层 $k+1$；$S_\xi=0$ 全零。填到恰好每子节点的规定质量，新生粒子继承完整前缀与新生儿层，故"出生在零质量祖先之下"的粒子仍有指定方向历史，且出生前不计占据。有限层后原子测度即 $\mu$。局部性：$|q_{j+1}-q_j|_\infty\le r_j/2$，故 $|q_m-q_s|_\infty\le\sum_{j\ge s}r_j/2=r_s(1-2^{-(m-s)})<r_s$。(c) 为什么保留出生前路径？`labels:298-301` 与 `introduction:217-218`：方向律从第一尺度就在演化，比较需要全路径。为什么用"送比例+造差额"，并非直接给每节点独立质量？因为要保证 $\mu\{B\le k,q_k=q\}=a_q$ **精确**（后续 occupancy 恒等式靠它），直接给会重复计数。(d) [推测] 错路：其一，出生前不留方向历史，则第 11 节比较"从层 $1$ 到出生前"的切换无定义，$\sum_{s=1}^B$ 那些 pre-birth 项无法界。其二，把每层质量当独立测度，并非"守恒流动"，occupancy 精确性破，$\sum_qa_q\mathcal C_l(q)=\int\sum_{l\ge B}\mathcal C_l(q_l)\dd\mu$（`eq:labels-cost-occupancy$）不成立。其三，森林取无限根，$\mu$ 不再有限，$A_m\le V$ 的全局界丢。

本征标记（`labels:394-414`）：根全标记；某标记之下，标记第一个 $\theta_{q_s}$ 距该标记方向 $>\tau/8$ 的节点，递归。与 $x$ 无关。Lemma 4.5（本征标记与期望切换，`labels:404-489`）：$\sum_{\text{marked}}M_\xi\le CV$；$\int\sum_{s=B}^mE_s(q_s)\dd\mu\le CV$；$\int\sum_{s=B}^mR_s(y)\dd\mu\le CV$。(b) 首式：标记非终端 $\xi$ 的前沿集 $\mathcal L_\xi$，向量相加给 $\sum_{\mathcal L_\xi}M_\eta-M_\xi=\tfrac12\sum_{\mathcal L_\xi}M_\eta|\vartheta_\eta-\vartheta_\xi|^2\ge\tfrac{\tau^2}{128}\sum_{\eta\in\mathcal L_\xi,\text{marked}}M_\eta$（$|\vartheta_\eta-\vartheta_\xi|>\tau/8$ 时平方 $\ge\tau^2/64$，一半得 $\tau^2/128$）。每非根非终端标记在前一点正出现、自身负出现；终端点恰一次。左和 $=A_m-A_1\le V$，加根质量得首式。第二式由 occupancy 转求和接 Lemma 4.1。第三式：固定粒子在 $y$ 跑标签律，$X_s=\1_{n_s\ne n_{k-1}}$、$\E_yX_s=R_s(y)$；去掉 $B..m$ 中本征标记或 $E_s>c_*$ 的例外层，剩段内所有 $\theta_{q_s}$ 距最近标记方向 $\le\tau/8$，$y$ 处采样顶点距 $q_s$ $<2r_s$（局部性）故采样方向距 $\theta_{q_s}\le\tau/10$，段内两采样方向距 $\le9\tau/20$；一切换后新标号再距采样 $\le\tau/20$，对后续采样距 $\le\tau/2<\tau$，之后切换概率全零，故每段至多一次切换。$J$ 个例外层给 $\sum X_s\le1+2\#\text{marks}+2c_*^{-1}\sum E_s$，取 $\E_y$ 再积分接前两式与 $\mu\le V$。(c) $\tau/8$ 与 $\tau/10$、$\tau/20$ 三段相加 $2(\tau/8+\tau/10)=9\tau/20$，加 $\tau/20$ 得 $\tau/2<\tau$ 让 $P$ 落进死区，整条链是 $P$ 死区宽 $\tau$ 的直接后果；$\tau^2/128$ 系数来自 $(\tau/8)^2/2$。(d) [推测] 错路：其一，标记阈值取 $>\tau$ ，并非 $\tau/8$，段内方向跨度太大，$9\tau/20$ 变 $>\tau$，切换不止一次，$\sum X_s$ 失控。其二，用 $\Prob_x$ ，并非固定 $y$ 的律做路径界，则每步依赖 $x$ 无法对粒子积分收口，$x$-一致性丢。其三，忘记"切换后距后续 $\le\tau/2<\tau$"这一步，段内切换数无界。

## 11 空间比较与打包估计（Lemma 4.6、Proposition 4.3）

路径上单点 $y$ 的界要升级成格 $D(q_l)=\{|x-q_l|_\infty\le25r_l\}$ 上一致界，并补行导数成本。Lemma 4.6（空间比较，`labels:503-616$）：固定粒子、层 $l$、$x\in D(q_l)$，$c_s=R_s(y)+E_s(q_s)$，则对 $1\le k\le\min(l+1,m)$，$R_k(x)+T_k(x)\le C\sum_{s=1}^k2^{s-k}c_s$。(b) 推导：局部性给 $|x-y|_\infty<26r_l$；$s\le\min(l+1,m)$ 时 $x$ 或 $y$ 处非零帐篷的 $z$ 满足 $|z-q_s|_\infty\le r_s+26r_l+r_s\le54r_s<200r_s$，故所有涉及方向距 $\theta_{q_s}\le\sqrt{E_s}$。$\sqrt{P(d)}=\min\{1,\tau^{-1}(d-\tau)_+\}$ 是 $\tau^{-1}$-Lipschitz，两涉及顶点 $z,z'$ 给 $p_s(n,z)\le2p_s(n,z')+8\tau^{-2}E_s$；用 $\phi_{z'}(y)$ 平均得 $\max_zp_s(n,z)\le C(\rho_s(y|n)+E_s)$，进而行切换率、缩放行导数分别 $\le C(\rho_s(y|n)+E_s)$，行差 $\|\pi_s(x)-\pi_s(y)\|_{\ell^1}\le C2^{s-l}(\rho_s(y|n)+E_s)$。边缘分布 $d_s=\|\zeta_s(x)-\zeta_s(y)\|$ 用随机矩阵 $\ell^1$ 收缩 $d_s\le d_{s-1}+C2^{s-l}c_s$，累加 $d_j\le C\sum_{s\le j}2^{s-l}c_s$。最后对 $x$ 平均旧标号于 $\zeta_{k-1}(y)$ 得 $Cc_k$，换回 $\zeta_{k-1}(x)$ 花 $Cd_{k-1}$，因 $k\le l+1$ 有 $2^{s-l}\le2\cdot2^{s-k}$ 收口。$k=1$ 由 $R_1=1,c_1\ge1$ 直接。(c) 比率 $2^{s-l}$ 来自 $|x-y|<26r_l$ 与帐篷导数 $1/r_s$ 之比；$54r_s<200r_s$ 是把 Lemma 4.2 的 $E$ 定义域喂满；$8\tau^{-2}$ 是 $\tau^{-1}$-Lipschitz 平方。(d) [推测] 错路：其一，不在旧标号分布层面补 $d_s$，直接把行差当 $R_k$ 界，会漏 $\zeta_{k-1}(x)\ne\zeta_{k-1}(y)$ 的项，`labels:573-575` 特意指明这一步必须补。其二，假设 $x,y$ 两处标签独立，`labels:599-600` 明说递归**不**假设独立；独立假设会给错方向的对角项。其三，$\sqrt{P}$ 用 $P$ 自身（非根号）做 Lipschitz，$P$ 在 $d=\tau$ 处不可导（斜率跳变），无法给 $\tau^{-1}$-Lipschitz 常数。

Prop 4.3（打包，`labels:270-285`）：$\sum_{l=1}^m\sum_qa_q[\sup_{x\in D(q)}(R_l+R_{l+1})+\sum_{k=1}^l2^{k-l}\operatorname*{ess\,sup}_{D(q)}T_k]\le CV$。(b) 证明（`labels:620-672`）：occupancy 恒等式 $\sum_{l,q}a_q\mathcal C_l(q)=\int\sum_{l=B}^m\mathcal C_l(q_l)\dd\mu$。Lemma 4.6 一致界给 $\sum_{l=B}^m\mathcal C_l(q_l)\le C[1+\sum_{l=B}^m\sum_{s\le\min(l+1,m)}(l-s+2)2^{s-l}c_s]$（双重卷积 $\sum_{k=1}^l2^{k-l}\sum_{s=1}^k2^{s-k}c_s=\sum_{s=1}^l(l-s+1)2^{s-l}c_s$）。固定 $s\ge B$ 系数 $\sum_{j\ge-1}(j+2)2^{-j}<\infty$，出生及之后项积 $\le CV$（Lemma 4.5）。出生前用 $0\le c_s\le5$，$\sum_q\sum_j5(j+q+2)2^{-(j+q)}=5\sum n(n+2)2^{-n}<\infty$，与 $B$ 无关，$\le CV$。(c) $R_l+R_{l+1}$ 双端是因为 run 的起点用 $R_l$、终点用 $R_{l+1}$（`assembly:97-99`）；$l=m$ 时哨兵 $R_{m+1}=1$ 加单位。$c_s\le5$ 因 $R\le1,E\le4$。(d) [推测] 错路：其一，只用 $R_l$ 不并 $R_{l+1}$，则 run 末端漏付。其二，双重卷积里丢掉 $(l-s+2)$ 的线性因子（把它当有界），$\sum_l$ 端发散。其三，pre-birth 不设 $c_s\le5$ 粗界而试图精细抵消，则出生前的方向律与粒子无耦合、无法统一与 $B$ 无关界。

## 12 组装：带基线、带权分部积分与行导数抵消（Proposition 1.2）

一切备料到位，assembly 把半径带拼起来、保留方向投影带符号直到分部积分。核心一句在 `assembly:6-9`：

> The essential cancellation is that the derivatives of a probability row sum to zero. Subtracting the potential of the preceding history then leaves only oscillations at smaller radii.

run 包络定义（`assembly:14-23`）：$F_{ij}(x)=\max_{r_j\le t\le2r_i}u_t(x)$，$1\le i\le j\le m$。取到最大因 $t\mapsto u_t(x)$ 连续；紧支撑因所有半径 $\le2r_1=1$、平均在 $\supp g$ 闭 $1$-邻域外为零；Lipschitz 界 $\|\nabla g\|_\infty$。触点原理（`eq:envelope-touching`，`assembly:25-38`）：可微点 $x$ 处取到 $F_{ij}(x)$ 的半径 $t$ 满足 $\nabla F_{ij}(x)=\nabla u_t(x)$，因 $F_{ij}-u_t\ge0$ 且零于 $x$。这跟 Hajłasz–Malý 的最优半径恒等式同源但**不微选出的半径**。

Prop 1.2 归结为证归一带界 `eq:finite-band`：$\int|\nabla F_{1m}|\le C\int|\nabla g|$。证明（`assembly:46-312`）：

标号历史 $\mathbf n=(n_1,\dots,n_m)$，run 是标号常数的极大区间 $[i,j]$，半径区间 $[r_j,2r_i]$，并起来 $[r_m,1]$，故 $F_{1m}=\max_{\text{run}}F_{ij}$。锥代数对取到最大的 run 用、其余 run 的非负括号加上、按 $\Prob_x$ 平均得 master 不等式 `eq:run-master`：$|\nabla F_{1m}|\le C\E_x\sum_{\text{run}}[n_i\cdot\nabla F_{ij}+\sum_\pm(-e_\pm(n_i)\cdot\nabla F_{ij})_+]$。

不利部与 run 端（`assembly:80-141`）：run $[i,j]$ 取到最大半径 $t$、所在箱 $[r_k,2r_k]$。$i<k<j$ 时 $[t-r_k/4,t+r_k/4]\subset[r_j,2r_i]$ 给 $t\in\mathcal I_k(x)$；$k=i$ 或 $j$ 时全箱在 run 内、$t$ 在该箱极大、$t\in\mathcal J_k(x)$。记 $B_k=\sup_{\mathcal J_k}|\nabla u_t|$、$A_{k,n}=\sup_{\mathcal I_k}\sum_\pm(-e_\pm(n)\cdot\nabla u_t)_+$。箱是其 run 端箱仅当 run 在 $k$ 起或止，概率 $R_k,R_{k+1}$（哨兵 $R_1=R_{m+1}=1$），每箱恰属一 run，得 `eq:negative-sum`：$\E_x\sum_{\text{run}}\sum_\pm(\cdots)_+\le\sum_{k,n}\Prob_x(n_k=n)A_{k,n}+2\sum_k(R_k+R_{k+1})B_k$。空间求和（`assembly:112-137`）：格 $Q$ 内 $|x-q|_\infty\le21r_k$，$Q\subset D(q)$ 且在 Lemma 4.2 的 $50r_k$ 邻域内；bad 且 $E_k(q)\le c_*$ 时 $\Prob_x(n_k=n)=0$，余下 bad 根款 $a_q\le c_*^{-1}a_qE_k(q)$，由 Prop 3.3 方向部分 + 邻居预算 + 价格预算收，$41^2$ 与有限调色板只给绝对因子，得 `eq:negative-integral` $\le CV$。

带基线与带权分部积分（`assembly:143-176`）：对起于 $i$ 的 run 包络减 $u_{r_i}$（$r_i$ 是 $\mathcal J_i$ 强制端点），`eq:baseline-cost` $\int\E_x\sum_{\text{run}}|\nabla u_{r_i}|=\sum_i\int R_i|\nabla u_{r_i}|\le\sum_i\int(R_i+R_{i+1})B_i\le CV$。固定历史的向量势 `eq:path-potential` $\Phi_{\mathbf n}=\sum_{\text{run}}n_i(F_{ij}-u_{r_i})$，紧支撑 Lipschitz，散度是减基线后的带符号投影和。历史概率 $w_{\mathbf n}=\prod_s\pi_s(x;n_{s-1},n_s)$，带权分部积分 `eq:weighted-ibp`：$\sum_{\mathbf n}\int w_{\mathbf n}\operatorname{div}\Phi_{\mathbf n}=-\sum_{\mathbf n}\int\Phi_{\mathbf n}\cdot\nabla w_{\mathbf n}$（散度积分对紧支撑 Lipschitz 场为零）。

前缀后的抵消（`assembly:182-225`）：直接微 $w_{\mathbf n}$，第 $k$ 步项 $W_{\mathbf a}\nabla\pi_k(x;n_{k-1},n_k)J_{k,\mathbf n}$，$W_{\mathbf a}=\prod_{s<k}\pi_s$、$J_{k,\mathbf n}=\prod_{s>k}\pi_s$。未来积化和为 $1$（`eq:future-normalization$），行导数和为零（`eq:row-derivative-zero$）。$\Psi_{\mathbf a}$ 是该前缀把末 run 闭在 $k-1$ 的势，不依赖 $n_k$ 与未来。于是 `eq:prefix-subtraction` 精确成立：$\sum_{n_k,\dots}J\Phi_{\mathbf n}\cdot\nabla\pi_k=\sum J(\Phi_{\mathbf n}-\Psi_{\mathbf a})\cdot\nabla\pi_k$，减法在取绝对值**之前**。逐延续（`eq:prefix-potential`，`assembly:228-253`）：$|\Phi_{\mathbf n}-\Psi_{\mathbf a}|\le\sum_{l=k}^mv_l$。已完 run 全消；末前缀 run 若续到 $j\ge k$，基线也消、剩 $n_i(F_{ij}-F_{i,k-1})$，旧半径区间含 $r_{k-1}$、延长只加更小的半径，故 $0\le F_{ij}-F_{i,k-1}\le\sup_{t\le r_{k-1}}(u_t-u_{r_{k-1}})_+\le v_k$（$r_{k-1}=2r_k$）；新 run $[l,j]$（$l\ge k$）贡献范数 $\le v_l$。取绝对值、按前缀求和、未来积化和为 $1$，得 `eq:flux-cost` $|\sum\int w_{\mathbf n}\operatorname{div}\Phi_{\mathbf n}|\le\sum_{k\le l}\int\frac{T_k(x)}{r_k}v_l\dd x$。付小半径振荡（`assembly:278-303`）：$l$ 层格上 $\int_Qv_l\le Cr_l(D_Q+\sum_qa_q)$，乘 $r_k^{-1}\sup_QT_k$；价格项 $T_k\le C$、$\sum_{k\le l}r_l/r_k=\sum_{k\le l}2^{k-l}\le2$，$\le C\sum D_Q\le CV$；根项 $Q\subset D(q)$ 重排接 `eq:label-packing`。合成 `eq:flux-cost` $\le CV$，与 `eq:baseline-cost`、`eq:negative-integral` 合证 `eq:finite-band`。最后 $b/a=2^m$ 用 $g_b(x)=g(bx)$、两梯度积分同乘 $b^{-1}$；$a=b$ 卷积 Tonelli（`assembly:305-311`）。

四段式补充。(c) 常数理由：为什么减 $u_{r_i}$ ，并非别基线？因为 $r_i$ 恰是 run 起点、在 $\mathcal J_i$ 里是强制端点，端点估计已付其梯度；而 $F_{ij}-u_{r_i}\ge0$ 且 $\le v_i$ 保证势有界。为什么 $\Phi_{\mathbf n}-\Psi_{\mathbf a}$ 只剩小半径振荡 $v_l,l\ge k$？因减法在绝对值前把大半径旧势整个对齐消掉，这是 `introduction:252-261` 反复强调的"先减后取模"。$2^{k-l}$ 权重在此从"值项带 $r_l$、行导数带 $1/r_k$"比出。$r_{k-1}=2r_k$ 是 dyadic 半距的直接后果。(d) [推测] 三条错路：其一，分部积分前对 $\Phi_{\mathbf n}$ 取模，则 $\sum_j\nabla\omega_j=0$ 的抵消用不上，$\nabla w_{\mathbf n}$ 的行导数全额暴露给 $B_k$，而 $B_k$ 只在小半径有界、大半径旧势被重复付费，尺度求和发散。其二，不减前缀势 $\Psi_{\mathbf a}$ 而直接对每个 $n_k$ 界 $\Phi_{\mathbf n}$，则 $\Phi_{\mathbf n}$ 含旧大半径包络、与 $\nabla\pi_k$ 相乘无法给 $v_l$ 尺度界。其三，把 run 划分随 $x$ 变，则 $\Phi_{\mathbf n}$ 不再是固定 Lipschitz 场、$w_{\mathbf n}\Phi_{\mathbf n}$ 的分部积分出现 run 边界测度，`assembly:169-170` 的紧支撑 Lipschitz 前提崩。

## 13 从带宽估计到弱梯度：延拓与奇部消去（Lemma 6.1 与主定理）

extension 两步走：先逼近把带界升到 Sobolev 输入、得到分布导数的有限测度；再用局部均值相减证该测度不给零集质量（`extension:3-9`）。第二步"正是有限带宽估计为带符号输入而证的原因"（`extension:8-9`）。

Lemma 6.1（Sobolev 有限带，`extension:22-34`）：每实 $g\in W^{1,1}$、$0<a\le b$，$S_{a,b}g$ 全局 Lipschitz 且 `eq:band-lipschitz` $\Lip(S_{a,b}g)\le\|\nabla g\|_1/(\pi a^2)$；若 $b/a$ 是 2 的非负整幂则 `eq:sobolev-band` $\int|\nabla S_{a,b}g|\le C\|\nabla g\|_1$，含 $a=b$。(b) 证明（`extension:36-70`）：平移估计（附录 A.1）给 $|A_tg(x+z)-A_tg(x)|\le\frac{|z|}{\pi a^2}\|\nabla g\|_1$，取 supremum 得 Lipschitz；同比较给 $\|S_{a,b}g-S_{a,b}\tilde g\|_\infty\le\|g-\tilde g\|_1/(\pi a^2)$（用 $|\sup f_t-\sup h_t|\le\sup|f_t-h_t|$）。取 $g_j\in C_c^\infty\to g$ 于 $W^{1,1}$，固定 $a$ 得包络一致收敛，$b/a>1$ 时 Prop 1.2 经局部变差下半连续（附录 A.4）传极限；$a=b$ 分布检验 $\nabla A_ag=A_a(\nabla g)$ + Tonelli。(c) $1/(\pi a^2)$ 因子是盘面积归一化，$a$ 越低 Lipschitz 越大但带界不含 $a$；一致逼近只需 $L^1$ 输入差、不碰梯度，是把 $C_c^\infty$ 结果搬到 $W^{1,1}$ 的通道。(d) [推测] 错路：其一，用 $H^1$ 弱收敛传界，但这里是 $L^1$ 梯度界、$W^{1,1}$ 非自反，须靠下半连续性引理，并非弱紧；其二，一致逼近不加 $a>0$ 下界则 $\|g-\tilde g\|_1/(\pi a^2)$ 爆，故带下界 $a$ 必须固定再取极限；其三，$b/a$ 非 2 幂时直接插，会破坏 $S_{a,b}$ 的 run 结构，论文只在 $a=b$ 与 2 幂两处立，其余靠单调。

主定理证明（`extension:72-217`）：取 $g=|f|\in W^{1,1}$、$\|\nabla g\|_1\le\|\nabla f\|_1$（附录 A.1 链式），平面 Sobolev 嵌入（A.2）给 $g\in L^2$，强 $L^2$ 极大给 $Mf=Mg\in L^2$ 局部可积。定义 $G_N=S_{2^{-N},2^N}g\uparrow Mg$（$g\ge0$）。

有限导数测度（`extension:90-110`）：Lemma 6.1 给 $\int|\nabla G_N|\le CV_g$ 一致，故对 $\varphi\in C_c^1$，$|-\int Mg\operatorname{div}\varphi|=\lim|\int\nabla G_N\cdot\varphi|\le CV_g\|\varphi\|_\infty$，向量测度引理（A.4）给有限向量 Radon 测度 $H=D(Mg)$、`eq:variation-limit` $|H|(\mathbb R^2)\le CV_g$ 与局部下半连续 `eq:local-lsc`。

零集附近大小半径（`extension:121-188`）：固定紧零集 $K$、dyadic $t=2^{-L}$、开集 $K\subset O\subset\{\dist(\cdot,K)<t\}$。$N\ge L$ 时在 $t$ 分带 $G_N=\max\{S_{2^{-N},t}g,S_{t,2^N}g\}$，最大规则给 $|\nabla G_N|\le|\nabla S_{2^{-N},t}g|+|\nabla S_{t,2^N}g|$。大半径项 `eq:large-radius-null-cost` $\int_O|\nabla S_{t,2^N}g|\le\frac{|O|}{\pi t^2}V_g$（Lipschitz 乘面积）。小半径项：边 $t$ 半开格剖、留遇 $O$ 者，取 A.3 的截断（$3Q$ 上为 $1$、支在 $5Q$），$c_Q=\frac1{|5Q|}\int_{5Q}g$、$g_Q=\chi_Q(g-c_Q)$，`eq:localized-input` $\|\nabla g_Q\|_1\le C\int_{5Q}|\nabla g|$。半径 $\le t$、心在 $Q$ 的盘含在 $3Q$，故 $A_sg_Q=A_sg-c_Q$（$x\in Q$）、$S_{2^{-N},t}g_Q=S_{2^{-N},t}g-c_Q$ 于 $Q$，梯度相同；$g_Q$ 变号，用 Lemma 6.1 的**带符号**形（比值 $2^{N-L}$ 含 $N=L$ 的 $1$）。得 $\int_O|\nabla S_{2^{-N},t}g|\le C\int_{\{\dist(\cdot,K)<6t\}}|\nabla g|$。合 `eq:null-localization` $|H|(O)\le C\int_{\{\dist<K<6t\}}|\nabla g|+Ct^{-2}|O|V_g$。

消奇异部（`extension:190-217`）：固定 $t$，紧零集 $K$ 允许 $|O|$ 任意小，$|H|(K)\le C\int_{\{\dist<K<6t\}}|\nabla g|$；令 $t\downarrow0$，邻域降到 $K$、$|\nabla g|$ 可积，右端趋零，故 $|H|(K)=0$。内正则给所有 Borel 零集，再经包含给所有 Lebesgue 零集。A.4 的 Radon–Nikodym 结论给 $H=G\dd x$、$\int|G|=|H|\le CV_g\le C\int|\nabla f|$，$G$ 即 $Mf$ 弱梯度，$Mf\in W^{1,1}_{\mathrm{loc}}$，`eq:main` 证毕。

四段式补充。(c) 为什么必须带符号？关键在 $g_Q=\chi_Q(g-c_Q)$ 会变号（$g$ 在 $5Q$ 上下浮动，减均值后正负都有），非负带宽估计对 $g_Q$ 不成立，只有带符号版才容许减 $c_Q$ 而保梯度不变（`extension:166-168` 与 `introduction:64-73` 呼应）。为什么先固定 $t$ 再让 $|O|\to0$、后 $t\to0$？次序是硬的：先用 $O$ 的小面积压住 $t^{-2}|O|V_g$ 项（对固定 $t$ 可行），再让 $t\to0$ 压住 $\nabla g$ 积分项；反过来先 $t\to0$ 则 $t^{-2}|O|$ 失控。$6t$ 来自 A.3 的 $3\sqrt2t<6t$ 邻域放大。(d) [推测] 三条错路：其一，不减 $c_Q$ 直接用 $\chi_Qg$，则 $\|\nabla(\chi_Qg)\|_1$ 含 $\int g|\nabla\chi_Q|$ 的 $L^1$（非梯度）项，Poincaré 给不出梯度-only 局部化，$t\to0$ 时该项未必趋零。其二，对非紧零集直接论证，缺内正则桥，A.4 末段"紧零集$\Rightarrow$Borel$\Rightarrow$Lebesgue"两步不可省。其三，用 Lahti–Weigt 替代整个消奇异论证（Remark 提供该备选），但那要**先**有 $|H|(\mathbb R^2)\le CV_g$ 的 BV 界与输入跳/Cantor 测度消失，而 $H$ 是 $Mg$ 非 $g$ 的导数，条件核对更绕；论文主线坚持自证绝对连续。

## 14 BV 推论与 coarea：我在纸上走到、机器没跟上的一步

Corollary 6.2（BV 输入，`extension:234-284`）：$f\in BV(\mathbb R^2)$ 时 $Mf\in L^2\cap BV_{\mathrm{loc}}$、$|D(Mf)|(\mathbb R^2)\le C|Df|(\mathbb R^2)$；写 $P(F)=|D\1_F|(\mathbb R^2)$，每 $|E|<\infty,P(E)<\infty$ 可测集有 $\int_0^1P(\{M\1_E>t\})\dd t\le CP(E)$，超level 集对每 $t>0$ 有限测度、几乎每 $t$ 有限周界。(b) 证明：$f_\varepsilon=f*\rho_\varepsilon\in W^{1,1}$、$\nabla f_\varepsilon=(Df)*\rho_\varepsilon$、$\|\nabla f_\varepsilon\|_1\le|Df|$；变差公式+下半连续给 $\to|Df|$（$BV$ 严格逼近），A.2 一致界 $\|f_\varepsilon\|_2$、Fatou 给 $f\in L^2$；$|Mf_\varepsilon-Mf|\le M(f_\varepsilon-f)$+强 $L^2$ 给 $Mf_\varepsilon\to Mf$ 于 $L^2$；主定理界 $Mf_\varepsilon$ 梯度范数，A.4 给有限导测度与局部 BV。$u=M\1_E\in[0,1]$，在 $B(0,R)$ 上用 **BV coarea 公式** `\cite{EvansGariepy2015}`、$R\to\infty$ 单调耗尽得 $\int_0^1P(\{u>t\})\dd t=|Du|(\mathbb R^2)\le CP(E)$。(c) coarea 用在这里是把"$u$ 的 BV 变差"翻成"超level 集周界的 $t$-积分"，是 BV 语言专属；$u\in[0,1]$ 让 $t$ 范围压到 $[0,1]$。$t^{-2}\|u\|_2^2$ 界超level 测度来自 Chebyshev。(d) [推测] 错路：其一，对一般 $BV$（非 $W^{1,1}$）直接跑主定理，但主定理只对 Sobolev 输入证弱梯度 $L^1$ 界，BV 需先光滑化；其二，忘 $f\in L^2$ 则 $Mf$ 未必局部可积，coarea 左端无定义；其三，把 coarea 用在 $Mf$（可能无界），并非 $M\1_E\in[0,1]$，超level 集测度发散。`extension:286-288` 明说这推论不主张一般 BV 输入的 $Mf$ 全局可积或导测度绝对连续。

## 15 附录引理台账（A.1 至 A.4）

A.1（`lem:appendix-sobolev-calculus`，`analytic-tools:16-40`）：$u\in W^{1,1}$ 有 $u_j\in C_c^\infty\to u$ 于 $W^{1,1}$；平移界 `eq:appendix-translation` $\|u(\cdot+z)-u\|_1\le|z|\|\nabla u\|_1$；$|u|\in W^{1,1}$、$|\nabla|u||\le|\nabla u|$；$\chi u$ 乘积法则；局部 Lipschitz $v,w$ 的最大值满足 `eq:appendix-maximum` 三分支（$v>w$ 取 $\nabla v$、$w>v$ 取 $\nabla w$、$v=w$ 处 $\nabla v=\nabla w$ a.e.）；局部 Lipschitz 乘积满足弱乘积法则。推导要点：截断 $\chi_R$（$B(0,R)$ 上为 $1$、支在 $B(0,2R)$、$|\nabla\chi_R|\le C/R$）再卷积，对角取 $R$；绝对值用 $F_\varepsilon(s)=\sqrt{s^2+\varepsilon^2}-\varepsilon$ 光滑链，导数逐点趋 $\operatorname{sgn}(u)$、被 $1$ 界，DCT 给 $\nabla|u|=\operatorname{sgn}(u)\nabla u$；等值集那支靠"密度 $1$ 处 $a$ 可微则导数为零"（非零导数会给出固定相对面积的非零锥形、违背密度 $1$）。这条正是 extension 里 $\nabla|f|$ 界、分带最大规则、带权 $w_{\mathbf n}\Phi_{\mathbf n}$ 分部积分三处的许可证。(d) [推测] 若跳 $\chi_R$ 直接卷积，$W^{1,1}$ 非紧支撑，卷积只在 $L^1_{\mathrm{loc}}$ 收敛，拿不到全局 $W^{1,1}$；若等值集分支不证 $\nabla v=\nabla w$，分带 `eq:band-lipschitz` 后的最大规则会在 equality set 上漏项。

A.2（平面 Sobolev 嵌入，`lem:appendix-planar-embedding`，`analytic-tools:122-147`）：$\|u\|_2^2\le\|\partial_1u\|_1\|\partial_2u\|_1$，特别 $\|u\|_2\le\|\nabla u\|_1$。证明：$a(y)=\int|\partial_1u|\dd x,b(x)=\int|\partial_2u|\dd y$，两坐标线上 FTC 给 $|u|\le a(y),|u|\le b(x)$，故 $|u|^2\le a(y)b(x)$，Fubini 积。这条给 $g=|f|\in L^2$，从而强 $L^2$ 极大不等式可用、$Mf$ 局部可积（`extension:78-81`、`extension:263-264` 在 BV 逼近处复用）。

A.3（方形局部化，`lem:appendix-square`，`analytic-tools:151-209`）：$u_Q=|Q|^{-1}\int_Q$，Poincaré `eq:appendix-poincare` $\int_Q|u-u_Q|\le Ct\int_Q|\nabla u|$；每格 $Q$ 有光滑截断 $\chi_Q$（$3Q$ 上 $1$、支在 $5Q$ 内、$|\nabla\chi_Q|\le C/t$），$c_Q=u_{5Q}$，`eq:appendix-localization` $\|\nabla[\chi_Q(u-c_Q)]\|_1\le C\int_{5Q}|\nabla u|$；半径 $\le t$、心在 $Q$ 的盘含在 $3Q$；$5Q$ 有界重叠；遇 $O\subset\{\dist<K<t\}$ 的格其 $5Q$ 全在 $\{\dist<K<6t\}$。补 Poincaré 证明（`analytic-tools:173-194`）：$Q=(0,t)^2$，Jensen 给 $\int_Q|u-u_Q|\le t^{-2}\int_Q\int_Q|u(x)-u(y)|$，把 $x$ 经 $(y_1,x_2)$ 折到 $y$，第一段对 $x_1,y_1$ 积给 $t^2\int|\partial_1u(s,x_2)|$（每个 $s$ 被 $x_1,y_1$ 夹住的点对面积 $\le t^2$），再 $x_2,y_2$ 积给 $t^3\int_Q|\partial_1u|$，第二段同理，除 $t^2$、用 $|\partial_1|+|\partial_2|\le\sqrt2|\nabla u|$。$6t$ 来自 $|y-x|\le3\sqrt2t\Rightarrow\dist(y,K)<(1+3\sqrt2)t<6t$。这条是 extension 小半径局部化 `eq:localized-input` 与 $6t$ 邻域的直接引用对象。

A.4（向量变差与局部下半连续，`lem:appendix-vector-measure`，`analytic-tools:224-335`）：$u_j\in W^{1,1}_{\mathrm{loc}}\to u$ 局部 $L^1$、$\sup_j\int|\nabla u_j|\le M$，则分布梯度是有限向量 Radon 测度 $H$，`eq:appendix-local-lsc` $|H|(\mathbb R^2)\le M$、$|H|(O)=\mathcal V(u;O)\le\liminf_j\int_O|\nabla u_j|$；若每紧零集 $|H|(K)=0$ 则 $H=G\dd x$、$G\in L^1$、$\|G\|_1=|H|$、$u\in W^{1,1}_{\mathrm{loc}}$。补"保 Euclidean 变差，并非坐标和"（`analytic-tools:261-282`）：$\lambda=|H_1|+|H_2|$、$H=q\lambda$，坐标密度绝对值 $\le1$；$|H|(E)=\int_E|q|\dd\lambda$，反界靠把 $q$ 值域分成直径 $\le\varepsilon$ 的有限片、每片取代表 $q_s$、$\sum_s|H(E_s)|\ge\sum|q_s|\lambda(E_s)-\varepsilon\lambda(E)\to\int_E|q|\dd\lambda$。极分解 $H=\sigma\mu,\mu=|H|,|\sigma|=1$。这条是 `eq:variation-limit`、`eq:local-lsc`、Radon–Nikodym 收尾三处的引用对象，也是机器里 Riesz 表示/Radon–Nikodym 的对应点（论文 `analytic-tools:258` 引 `\cite[Chapter~1, Theorem~5.14 and Equation~(4.17)]{Simon2018}`）。

机器把"梯度估计"写成哪一种不等式？这是任务问的核心。入口定理的陈述类型 `SignedFiniteBandStatement`（`Main.lean:57-64` 与题目文件一致）逐字是

```lean
def SignedFiniteBandStatement : Prop :=
  ∃ C : ℝ, 0 ≤ C ∧
    ∀ (f : Plane → ℝ), ContDiff ℝ ∞ f → HasCompactSupport f →
    ∀ (a : ℝ), 0 < a → ∀ m : ℕ,
      LocallyIntegrable (signedBand f a ((2 : ℝ)^m * a)) ∧
      ∃ G : Plane → Plane, Integrable G ∧
        HasWeakGradient (signedBand f a ((2 : ℝ)^m * a)) G ∧
        gradientNorm G ≤ C * gradientNorm (gradient f)
```

判定：既不是逐点梯度界（没有 `∀ x, ‖∇ …‖ x ≤ …` 这种式子），也不是 BV/superlevel 变差界，是一条 **$L^1$ 弱梯度积分不等式**。$G$ 通过 `HasWeakGradient`（分部积分定义 $\int f\cdot\text{testPartial}\,\varphi=-\int g_i\varphi$）代表 signedBand 的分布一阶导，界是 `gradientNorm G ≤ C * gradientNorm (gradient f)`，其中 `gradientNorm g := ∫ x, ‖g x‖`（Euclidean 范数积分，`Model:51`）。`signedBand := sSup ((diskAverage f x) '' Icc a b)`（`Model:54`），即闭带上带符号盘平均的上确界包络，对应论文 $S_{a,b}g$。输入是 `ContDiff ℝ ∞ f ∧ HasCompactSupport f`（光滑紧支撑），半径比锁死为 $2^m$（`Real.pi * r ^ 2` 归一）。所以机器认证的是**论文 Proposition 1.2（signed finite-band）的光滑紧支撑版**，量化了"$\exists G$ 弱梯度、$L^1$ 界、且带符号 $L^1$ 常数与 $m$ 无关"这一条。

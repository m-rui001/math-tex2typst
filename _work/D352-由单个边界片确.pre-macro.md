## §1 起点：这个问题为什么落到我手里

我的最初动机很朴素。scalar 情形那篇姊妹文已经把"$g$ 与 $q$ 从同一 patch 的零频测量中恢复"这件事闭合了；用的机制是 Poisson embedding 加上"小球收缩"的定量唯一延拓，最后用一次 dilation 让所有 $\delta$ 上的估计同步塌到 contact point。我当时以为，把 Laplace 换成 $L_{g,A}=d_A^{*g}d_A$、把标量解换成 $\C^2$-值列，剩下的都只是把符号与系数写成矩阵。

现在回头看，这份直觉里对的部分是：整套"外贴 cap、source evaluations、maximal match、product continuation、球面 transfer、continuity argument、最后消 conformal factor"的骨架的确一模一样能搬；错的只有一处，就是我在标量情形里可以完全不管的 first moment。标量 harmonic coordinates 之下 first moment 会被坐标归一化直接吸掉；秩二丛上一旦有 $A$，force 变成矩阵值的一阶位移 $D^1,\ldots,D^n$，它归不掉，它自己还满足一个非交换的漂移方程。整个 §11 到 §16 的机制都是被这个 $D$ 逼出来的。这个认识是我在做完 §13 的 $D=dI+W$ 分解之后才定下来的。

另一个初始猜想也错了。我以为有限维丛上的幺正联络无非是"多几个耦合项"，可以在 angular coercivity 那一步把矩阵项塞进 $\varepsilon$ 小量里一次性吃掉。§11 我确实这么写了第一版引理。检查的时候发现：coercivity 里吸收的是"两个归一化主张量之差 $h$ 的八阶导 $\le\varepsilon r$"，这个 bootstrap 假设允许矩阵漂移 $B_j^i$ 只是有界、并不要求小；矩阵项在 $P-P_0$ 展开里的确是 $\Psi^0$，可一旦回到 §12 要提取 first moment，$D$ 就是矩阵值，$\mathcal V_0$ 里的 $W$ 是八维系数，非交换顺序不能合并。coercivity 只让密度 $\psi$ 有界，让 $D$ 从 $\psi$ 的一阶矩中显出来时，"有界"变成 $|D|\le Cr\rho$ 就带出一个 $\sqrt r$ 的 gap。这就是必须引入 §14 finite type 的根本原因。

## §2 第一次误判：把 harmonic frame 当"消除所有低阶项"的机器

标量分析里我们做 harmonic coordinates，$-\Delta_g$ 主部系数在 harmonic 坐标下满足 $\partial_ig^{ij}(0)=0$，Christoffel 在原点消掉。到了秩二情形，我在 $F_j$ 这个 harmonic frame 里写 $\mathcal L_jv=-c_jF_j^{-1}L_j(F_jv)$（`02-boundary.tex:533` 的约定），零阶项的确为 $0$：$F_j$ 的每一列都 harmonic。当时我把这个"零阶消失"直觉地推广成"低阶装饰基本都可以靠 frame 消"。

真正的读法在 `06-matrix.tex:64-69`。$\mathcal L_1=a^{ij}\partial_i\partial_j+B_1^i\partial_i$、$\mathcal L_2=Q^{ij}\partial_i\partial_j+B_2^i\partial_i$。$B_j^i$ 是 $2\times2$ 复矩阵，非零。它们来自 $F_j^{-1}(dF_j+A_jF_j)$ 的对称化残差，具体形态并不重要；重要的是，即便做 dilation $g_{j,\lambda}(x)=g_j(\lambda x)$、$A_{j,\lambda}=\lambda A_j(\lambda x)$（`02-boundary.tex:492`），$B_j^i$ 只在 ordinary 坐标下趋于 $0$，可它趋于 $0$ 的"阶"跟不上 $\psi$ 密度里 $D$ 的阶。§12 里对 $D$ 只能给出 $\|\chi D/r\|_{L^2}\le C$，也就是 $|D|\le Cr\cdot\rho$（$\rho=\|\psi(y,\cdot)\|_{L^2(S_y)}$）。密度有界只把 $D$ 逼到 $O(r)$，再靠插值到点态是 $O(r^{1/2})$。$O(r^{1/2})$ 太慢，球收缩半径塌不下去。

我在这个错误路线上大概耗了两周（记不清具体天数，只算草稿版本数）：三版 `06-matrix.tex` 的早期稿都是想把 $B_j^i$ 塞进 bootstrap，或者在 §11 前多做一个 frame 旋转把 $B_j^i$ 变成"更小"。都没走通。转折点是意识到应该走另一条：重点放在让 $D$ 满足一个偏微分方程，这个方程的主符号是 conformal Killing 型。这个洞察让我从"用 frame 消"转到"用 PDE 提"，也就是 §13 到 §15。

## §3 边界符号与 normal gauge：先把不变量分离出来

回到最初的问题。测量是 $\langle\Lambda_{g,A,\Gamma}f,h\rangle=\int_M\langle d_Au_f,d_Au_h\rangle_g\,dV_g$（`01-introduction.tex:30`），$f,h\in C_c^\infty(\Gamma;\C^2)$。这个双线性形式对 $M$ 的定向不敏感，对边界不引入边界度量或边界测度：所有积分都用 density。这一步"只用 density"的选择其实很关键，它保证我们后面在 exterior cap 上做变分比较时不用先固定 boundary metric。

零 Dirichlet 实现的可逆性来自"energy 为 $0$ 的截面 parallel、parallel 截面若边界 trace 为 $0$ 就恒为 $0$"（`01-introduction.tex:19-22`）。这给了我唯一性解 $u_f^{g,A}$。$L_{g,A}$ 的椭圆 coercivity 由标准紧性论证给。

Normal gauge。$A_j$ 是 $\mathfrak u(2)$-值的，在 collar $(z,s)$ 里解 ODE $\partial_sV_j=-A_{j,s}V_j$，$V_j(z,0)=I$。得到 $A_{j,s}^{V_j}=0$。把 $V_j$ 用 collar 的重新参数化延到全局，$V_j=I$ 在原 $\partial M$ 上、也在流形内部足够深处（`02-boundary.tex:51-58`）。此后所有讨论在这两个法规范下进行，直到 §18 才把 $V_j$ 记回来。这个"法规范"选择把联络的 $s$ 分量彻底钉死在 $0$，让后续 boundary jets 的归纳只剩 $A_a$（切向）与 $k_{ab}$（切向度量）需要抽。

Boundary symbol 因子化。$g=ds^2+k(s,z)$，$\rho=(k^{ab}\xi_a\xi_b)^{1/2}$。Green 公式把测得的算子和 density $\nabla_\nu^Au\,dS_g$ 等同起来；主符号是 $(\det k)^{1/2}\rho I$（`02-boundary.tex:75`）。平方决定 $C=(\det k)k^{-1}$，再由 $\det C=(\det k)^{m-1}$、$k=(\det C)^{1/(m-1)}C^{-1}$ 反求 $k$（`02-boundary.tex:80-82`）。到这里 $\partial M$ 上的 tangential 度量与 density 都定了；除法给出两侧 covariant unit-normal DN 相等。

对符号递归展开 $L_{g,A}=(-\partial_s+B-\alpha)(\partial_s+B)\pmod{\Psi^{-\infty}}$（`02-boundary.tex:104`），$b\sim\rho I+b_0+b_{-1}+\ldots$。degree 1 主部是 $\rho I$，选择衰减的 Dirichlet 分支；Poisson parametrix 把 $B(0)$ 与 outward normal derivative 对起来。$b_0$ 里新 jet 部分是 $\frac14(\mathrm{tr}_k\partial_s k-(\partial_s k)(\xi^\sharp,\xi^\sharp)/\rho^2)I-ik^{ab}A_a\xi_b/\rho$（`02-boundary.tex:124-128`）；$j\ge2$ 时 degree $1-j$ 的新 normal jet 只出现在 $\partial_s b_{2-j}/(2\rho)$，得到结构式 $\frac1{(2\rho)^{j-1}}[\frac14(\mathrm{tr}_k\partial_s^j k-\ldots)I-ik^{ab}(\partial_s^{j-1}A_a)\xi_b/\rho]$（`02-boundary.tex:135-142`）。

关键归纳：减去两个符号递归后，$T$ 是 $\xi$ 的偶函数（metric 部分），$ik^{ab}(\partial_s^{j-1}A_a)\xi_b/\rho$ 是 $\xi$ 的奇函数（connection 部分）。奇部确定 $\partial_s^{j-1}A_a$ 全部分量。偶部若对某个对称 $T$ 恒等于 $0$，则 $T(v,v)=\mathrm{tr}_k(T)$ 对每个单位 $v$ 成立；polarization 得 $T=\mathrm{tr}_k(T)k$，取迹给 $(m-1)\mathrm{tr}_k(T)=0$；$m=n-1\ge2$，故 $T=0$。这一步里"用 $n\ge3$" 是第一次出现；它后面 §14 还要用一次更硬的。

这样 $g_j$、$A_j$ 在 $\Gamma$ 上的 Taylor 全 jet 相等（`02-boundary.tex:60-66` 的 Lemma）。

## §4 共用 exterior cap：变分论证里最漂亮的一步

Boundary jets 相等只讲边界一侧；它给的是"外延"能相同。这里我原本想的是"直接在 collar 里对齐系数"，检查后发现这样只能对到 jets 层面对齐，实际 interior 依然未知。真正的构造是变分：选一个 $b\ge0$ 光滑 bump，$\{b>0\}=P\Subset\Gamma$ 非空连通；把边界从 $s=0$ 移到 $s=-b(z)$；共同开集是 $E=\{(z,s):-b(z)<s<0\}$（`02-boundary.tex:192`）。把两侧系数用同一个 exterior extension 延到 $s<0$，$b$ 的支集外延的仍是各自原来的 $g_j,A_j$。Lemma 3.1 的 jets 一致保证拼接在 $\mathrm{supp}\,b$ 附近是 $C^\infty$；限制回 $s\ge-b(z)$ 也让 bump 边缘是光滑的。

对 $f\in C_c^\infty(E;\C^2)$，$w_j=L_{j,D}^{-1}f$ 是泛函 $\mathcal J_j(w)=\frac12\int_{N_j}|d_{A_j}w|_{g_j}^2dV_{g_j}-\mathrm{Re}\int_E\langle f,w\rangle dV_{g_j}$ 在 $H^1_0(N_j)$ 上唯一的最小元（`02-boundary.tex:210-214`）。把 $w_1$ 通过 collar 恒等映射搬到 $N_2$ 上（bih-Lipschitz），然后在原 $M$ 中把它替换成同一 trace 的第二个 harmonic extension。替换差在 $\partial M$ 上 trace 为 $0$，zero extension 落在 $H^1_0(N_2)$。这样得到 $N_2$ 上的一个 admissible competitor。在原 $M$ 内 source 为 $0$、$w_1$ 是那个 trace 的第一个 harmonic extension；测量形式相同意味着 interior 能量与替换后的相同；$E$ 内系数与 source pairing 都不变。故 $\min\mathcal J_2\le\min\mathcal J_1$；反向对称得等号；唯一性给 $w_1=w_2$ 于 $E$ 上。

Green 矩阵按 metric volume 归一化：$L_{j,x}G_j(x,y)=\delta_y^{g_j}(x)I$、$G_j|_{\partial N_j}=0$、$L_{j,D}^{-1}f(x)=\int_{N_j}G_j(x,y)f(y)dV_{g_j}(y)$。$E$ 上 density 相同；vary source 得 $E\times E\setminus\Delta$ 上 kernel 相同，加上 Dirichlet 逆自伴给出 $G_j(x,y)=G_j(y,x)^*$（`02-boundary.tex:178-181`）。

这一步我印象很深：能量比较绕过了"PDE 逐点等"，用了最小元的唯一性。变分结构在矩阵情形仍然成立，因为内积 Hermitian、能量实值。

## §5 Source evaluations 分离点与纤维

固定 $U_0\Subset E$ 非空开；$f\in C_c^\infty(U_0;\C^2)$，$w_{j,f}=L_{j,D}^{-1}f$，$I_j(p)f=w_{j,f}(p)$（`02-boundary.tex:249-250`）。$I_j(p)$ 从共同 source space 到 $p$ 处的 fiber。在 $E$ 上两侧一致。

Lemma `02-boundary.tex:260` 给三件事：一点满、两点联合满、$p\notin\overline U$ 时二 jet 恰好填满"$Lu(p)=0$ 决定的线性空间"。证明用对偶分布：一个复线性泛函对应到支撑在一点或两点上的对偶值分布 $T$；令 $v=(L_D^{-1})^tT$（distributional transposition），则 $\langle v,f\rangle=\langle T,L_D^{-1}f\rangle=0$ 于 $f$ 支在 $U$ 上，同时 $L^tv=T$。椭圆正则性给 $v$ 在 $\mathrm{supp}\,T$ 外光滑；$n\ge2$ 允许"绕开"一个或两个点得到连通内域；从 $U$ 里去掉这些点剩余非空开，唯一延拓逼 $v$ 支撑在那一/两个点上。点上分布是点质量的有限阶导数之和；最高阶 $k$ 在 $L^t$ 下变成 $k+2$（scalar elliptic 二次多项式对最高齐次系数向量多项式作乘法是 injective）。于是零阶分布不可能是点上分布的像，得到 value/gradient 满射。

二 jet annihilator 的情形 $T$ 阶 $\le2$，$v=c\delta_p$，像正好是 $u\mapsto c(Lu(p))$。有限维对偶给出确切空间。特别地 value 与 gradient 可自由规定；Hessian 的 trace 只要满足方程即可。这个"自由规定 value+gradient+trace-free Hessian"是我在 §7 建 $X_j^l$ 与配对方阵时反复调用的接口。

## §6 Maximal match 与它的 frontier

Match 定义（`02-boundary.tex:318-326`）：局部 isometry $\Phi:W\to N_1^\circ$（$W\subset N_2^\circ$ 开连通、含 $E$），光滑幺正 bundle map $J$ 从第二侧 fiber 到 $\Phi(p)$ 处的第一侧 fiber；要求 $\Phi|_E=\mathrm{Id}$、$J|_E=I$、$d_{\Phi^*A_1}(Ju)=Jd_{A_2}u$、$J(p)I_2(p)=I_1(\Phi(p))$。恒等在 $E$ 上就是一个 match。

Lemma 3.6 讲所有 match 在重叠上一致、在 base 上 injective；并集是极大 match。证明：若同一 $p$ 有两个不同的 $q_1,q_2$，evaluation identity 给出 $I_1(q_1),I_1(q_2)$ 之间一个固定的可逆线性关系；两点联合满射（§5）排除这种关系。Image 定了之后，$I_2(p)$ 满射决定 $J$。同理 $N_2$ 上的评估排除两个 base 点映到同一像。因此所有 match 在重叠处能 glue；并集仍连通（都含 $E$）。

Matched Green 恒等式 $G_1(\Phi(p),\Phi(q))=J(p)G_2(p,q)J(q)^*$（`02-boundary.tex:335`）。证明里 $q\in U_0$ 时由 evaluation identity 与共同 density 得出；对固定 $p$，两侧作为 $q$ 的函数在 pulled-back connection 方程下解同一方程。$\Phi$ injective 让 $q=p$ 是唯一 pole；$W\setminus\{p\}$ 上唯一延拓把等式推到全处。

我在这个 section 停留很久的一点是：为什么把"bundle map 是幺正的"作为 match 定义的一部分。起初我允许 $J$ 只是可逆的，理由是"最后总能 polar decompose"。这样 §18 里证明 $J_{\mathrm{loc}}$ 与旧 match 在重叠上一致时，$J$ 的取值不再是紧的 $U(2)$、compactness 论证一步就断。把幺正性塞进定义后，$p_k\to p$ 时 $J(p_k)$ 有收敛子列到 $J_0\in U(2)$（用固定全局平凡化），limit 良定义。这是我早期在 §7 里"limit match"卡壳的根源。

## §7 在 frontier 处搭坐标与 harmonic frames

Proposition 3.8（`02-boundary.tex:369`）：极大 domain $W$ 若有 interior frontier，则存在 $p\in\partial W\cap N_2^\circ$、$q\in N_1^\circ$ 和两个都避开 $\overline{U_0}$ 的坐标卡，坐标范围是 $0\in\R^n$ 的邻域，满足四件事：

1. 旧 match 在这些坐标下是 coordinate identity；它的 domain 包含区域 $x_n<\kappa(x')$，$\kappa(0)=0$、$d\kappa(0)=0$。
2. 光滑局部幺正标架下度量、联络矩阵、Green 矩阵在已知区域（对 Green 是其 squared off-diagonal）相等，$g_1(0)=g_2(0)=I_n$。
3. 可逆矩阵函数 $F_j$ 由 harmonic 列构成（选为对应的 source solutions）；在这些 harmonic frames 中存在对应的 harmonic matrix functions $X_j^l$，$1\le l\le n$，满足 $\frac12\mathrm{Re}\,\mathrm{tr}X_j^l(x)=x^l$、$X_j^l(0)=0$、$\partial_iX_j^l(0)=\delta_i^lI$（`02-boundary.tex:387-390`）。
4. 再有一列配对的 harmonic 列函数，其 value 与 gradient 在 $0$ 处为 $0$，其 Hessian 张成满足 $\sum_iH_{ii}=0$ 的对称 $\C^2$-值二阶张量空间；所有这些配对函数在已知区域相等、在 $0$ 处 jet 相同。

证明思路：小 coordinate ball 里选一个 Euclidean 球内切于 $W$，边界给出所需的接触超曲面。$p_k\to p$ 时 $\Phi(p_k)\to q$、$J(p_k)\to J_0$ 由紧性给；$J_0I_2(p)=I_1(q)$（`02-boundary.tex:415`）。$q$ 不能在 $\partial N_1$（否则 $I_1(q)=0$，与 $I_2(p)$ 满矛盾）。$q$ 不能在 $E$（否则 $E$ 上恒等 match 会把 $I_1(q)$ 与 $I_2(p)$ 通过恒等 relate，与两点联合满射矛盾）。选 source solutions 使 $F_1(q)$ 可逆；对应的第二侧列 $F_2(p)$ 由 (5) 式可逆。缩 chart 使两者都可逆。在 harmonic frame 里 $v=F_j^{-1}w$ 满足"scalar 主部、零阶项为 $0$"的方程；Lemma 3.4（`02-boundary.tex:260`）在这种 smooth frame change 下不变。所以能拿到 $X_1^l$ 使 value 为 $0$、gradient 为任意选定的实坐标 covector 乘 $I$。

坐标 $x^l=\frac12\mathrm{Re}\,\mathrm{tr}X_1^l$、$y^l=\frac12\mathrm{Re}\,\mathrm{tr}X_2^l$。$x^l$ 在 $q$ 处成坐标。matched 点上 $JF_2=F_1\circ\Phi$、$X_2^l=X_1^l\circ\Phi$，所以两侧 metric Gram 与 isometry 相容；取极限在 $p,q$ 也一致且正定。因此 $y^l$ 在 $p$ 处成坐标。

Frame polar-orthonormalize：$F_j=H_jS_j$，$H_j$ 幺正、$S_j$ Hermitian 正；matched 上 $JF_2=F_1$ 给 $S_2=S_1$、$JH_2=H_1$。幺正 frame $H_j$ 里旧 $J$ 变成 $I$。之后仍写 $F_j$ 为幺正 frame 下的 harmonic frame 矩阵。共同 real linear coordinate change 让 $0$ 处 metric Euclidean、contact 超曲面水平。

Dilation（`02-boundary.tex:490-497`）：$g_{j,\lambda}(x)=g_j(\lambda x)$、$A_{j,\lambda}(x)=\lambda A_j(\lambda x)$、$G_{j,\lambda}(x,y)=\lambda^{n-2}G_j(\lambda x,\lambda y)$、$F_{j,\lambda}(x)=F_j(\lambda x)$。度量归一化是 pullback 的 $\lambda^{-2}$ 倍；联络 Laplacian 被 $\lambda^2$ 乘；kernel 前因子 $\lambda^{n-2}$ 恰好抵 metric volume。fixed bounded coordinate range 上 $g_j\to I_n$、$A_j\to0$ 光滑。Kernel 上界：内域 parametrix order $-2$ 给 $|G_j(x,y)|\le C|x-y|^{2-n}$（`02-boundary.tex:520`），dilation 后 $|x-y|\ge$ 某个 fixed positive lower bound 上，任意 fixed 阶一致有界。

Harmonic normalization 约定：$\mathcal L_jv=-c_jF_j^{-1}L_{g_j,A_j}(F_jv)$，$c_j>0$（`02-boundary.tex:533-534`）。这个约定在 §9 决定 $c_1,c_2$ 时被实例化。

## §8 Product continuation：从 cross 出发

Green 是二元 kernel。要延拓它，必须在乘积空间上分开控制两个变量。§3 的构造沿用 scalar companion 的骨架，把标量情形里的算子换成 $\mathsf L_i=-\Delta_{g_i}I_{V_i}+C_i^a\partial_a+D_i$。product solution $F(x,y)$ 满足 $(\mathsf L_1^x\otimes I)F=0$、$(I\otimes\mathsf L_2^y)F=0$；系数只作用于自己那一侧的 tensor index、只依赖自己那一侧的变量；两方程交换。它们的和在主部上给出乘积空间上 scalar real elliptic 算子，因此普通唯一延拓足以在共同连通 domain 上把两个 product solution 粘合。矩阵 Green 的第二个 tensor factor 是输入 fiber 的共轭；$y$ 方程通过对第二个联络 Laplacian 的系数取共轭得到（`03-product.tex:38-43`）。

Extension from a cross（`03-product.tex:53-76`）。设 $D_i$ 有界连通坐标 domain、$S_i\Subset D_i$ 非空开；$F$ 在 $(D_1\times S_2)\cup(S_1\times D_2)$ 上相容给出、两个 $L^2$ 范数之和 $\le M$。若每个 $V_i$-值 $\mathsf L_i$-解 $w$ 于 $D_i$ 上满足插值 $\|w\|_{L^2(O_i)}\le C\|w\|_{L^2(S_i)}^{\gamma_i}\|w\|_{L^2(D_i)}^{1-\gamma_i}$（$0<\gamma_i<1$，$\gamma_1+\gamma_2>1$），则 $F$ 在 $O_1\times O_2$ 上作为 product solution 延拓，两臂上一致，$C^m$ 范数 $\le C_mM$。

证明里的机制（`03-product.tex:79-145`）：$\mathcal H_1(D_1)\subset L^2(D_1;V_1)$ 是分布意义下 $\mathsf L_1$ 解空间；restrict $R$ 到 $S_1$ 是紧单射。$R^*R$ 谱定理给标准正交基 $(w_j)$，$(w_i,w_j)_{L^2(S_1)}=\mu_j^2\delta_{ij}$，$0<\mu_j\le1$。Fourier 截断给 $\mu_j\le C_N(1+j)^{-N}$：截到 $O(A^n)$ 阶、误差 $O(A^{-k})$、minimax 给 $\mu_j\le C_kj^{-k/n}$。$y\in S_2$ 时对第一变量展开 $F(x,y)=\sum_jw_j(x)\otimes b_j(y)$，$\|b_j\|_{L^2(S_2)}\le M$。对第一 tensor index 与 $\overline{w_j}$ 收缩得 $b_j(y)=\mu_j^{-2}\int_{S_1}\sum_\alpha\overline{w_{j,\alpha}(x)}F_\alpha(x,y)dx$、$\|b_j\|_{L^2(D_2)}\le M\mu_j^{-1}$。$b_j$ 满足第二方程。插值假设给 $\|w_j\|_{L^2(O_1)}\le C\mu_j^{\gamma_1}$、$\|b_j\|_{L^2(O_2)}\le CM\mu_j^{\gamma_2-1}$。级数第 $j$ 项在 $L^2(O_1\times O_2)$ 的范数 $\le CM\mu_j^{\gamma_1+\gamma_2-1}$；$\gamma_1+\gamma_2>1$ 使级数绝对收敛。

第二臂一致性：$z\in L^2(S_1;V_1)$ 与 $R\mathcal H_1(D_1)$ closure 正交时 $y\mapsto\int_{S_1}\sum_\alpha\overline{z_\alpha}F_\alpha(x,y)dx$ 解第二方程，在 $S_2$ 上为 $0$，由 $D_2$ 连通全为 $0$。故第二臂每一 slice 落在 $R\mathcal H_1(D_1)$ 的闭 range 里；对 $w_j/\mu_j$ 展开是完整的，系数为 $\mu_jb_j(y)$。

Carleman 与严格权重。$\theta$ 在 $d\theta\ne0$ 处称为 strict weight 若 $\mathrm{Hess}_g\theta(e,e)+\mathrm{Hess}_g\theta(v,v)>0$ 对 $v\perp e$、$|v|_g=1$，$e=\nabla^g\theta/|\nabla^g\theta|_g$（`03-product.tex:158-161`）。$-\Delta_gI+C^a\partial_a+D$ 的严格 Carleman：$\tau^3\|e^{\tau\theta}w\|^2+\tau\|\nabla(e^{\tau\theta}w)\|^2\le C\|e^{\tau\theta}\mathsf Lw\|^2$，$\tau\ge\tau_0$（`03-product.tex:166-170`）。矩阵一次项被 scalar 权重共轭之后由 $\|\nabla v\|+\tau\|v\|$ 控制、$\tau$ 大时吸收。

Tube 几何与最后的应用在 `03-product.tex` 后半。选 $T_0>2(M+\widehat B+1)$、$c_0a_{\min}T_0^\sigma>2$（`03-product.tex:701-703`）；空腔区域由 $y_n<(c_0-\min(\omega_n,0))r$ 定义，随 $a$ 上向闭合。$\rho=\frac12(|x-y|^2-r_a(y)^2)$、$b=\nabla r_a$；null vectors $U_1=\omega+iv$、$U_2=(\omega+b)/|\omega+b|^2+iw$（`03-product.tex:728-731`）。$\omega\cdot(U_1-U_2)=b\cdot U_2$ 抵消距离 Hessians 的法向部分，剩下严格测试 $|\pi_{\omega^\perp}(U_1-U_2)|^2-(r_a\partial^2r_a)(U_2,\overline{U_2})$（`03-product.tex:736-737`）。$|b|\le4/c_0$；两处邻域（$b=-\omega$、$b=-2\omega$）的 closure 有 $x_n/r_a<c_0/2$，落在粗区。剩下有 $c|b|^2$ 的下界；$r_a|\partial^2r_a|\le C(\sigma+T_0e_0)|b|^2$；选 $\sigma$ 小、$T_0$ 与 $e_0$ 使最后系数 $<c\delta_0^2/4$，测试下界 $\ge(c/2)|b|^2\ge(c/2)(1+\sigma)^2a_{\min}^2m^{2\sigma}>0$。最后 smooth convergence 保 strict tests 对足够小 $\lambda$。

## §9 深度函数 $t$ 与半径轮廓 $r_\delta$

归一化（`04-spheres.tex:36-38`）：$\gamma=e^{-2Lt_0}g_1$、$a=\gamma^{-1}$、$Q=ng_2^{-1}/\mathrm{tr}(\gamma g_2^{-1})$、$h=Q-a$。$t_0(y)=y_n+|y'|^2$。$\mathrm{tr}(\gamma h)=0$；dilation 后 $h$ 在任何 fixed smooth norm 里 $\to0$（`04-spheres.tex:57-59`）。

Frame multipliers（`04-spheres.tex:44-46`）：$c_1=e^{2Lt_0}$、$c_2=n/\mathrm{tr}(\gamma g_2^{-1})>0$。这样 $\mathcal L_1$ 的主部系数是 $a$，$\mathcal L_2$ 的是 $Q$，零阶项都是 $0$。Principal metrics 分别是 $\gamma$、$Q^{-1}$。

Depth $t(y)=\int_{1/8}^{t_0(y)}e^{-2Ls}ds$（`04-spheres.tex:63`）。它在 origin 附近负、微分不为零。核心性质：$\mathrm{Hess}_\gamma t=e^{-2Lt_0}(\mathrm{Hess}_{g_1}t_0-L|dt_0|_{g_1}^2g_1)\le-c\gamma$（`04-spheres.tex:68-72`）。conformal connection formula 把两个 $dt_0\otimes dt_0$ 项抵消；$|dt_0|$ 在 fixed region 上下界非零，$\mathrm{Hess}_{g_1}t_0$ 小 $\lambda$ 下一致有界。选 $L$ 大先给严格负性。这一步是我觉得整篇最"设计"的地方：$t_0$ 只是一个 paraboloid，$e^{-2Lt_0}$ 只是 conformal factor；两者配合让 $\mathrm{Hess}_\gamma t$ 严格负。L 大就是靠 $|dt_0|^2$ 项压过 Hessian。

Radius profile（`04-spheres.tex:80-84`）：$\ell_\delta(t)=\delta\log(1+e^{t/\delta})$、$r_\delta(y)=R_*\ell_\delta(t(y))^{p_*}$、$f_*=\log r_\delta$、$\beta=|df_*|_\gamma$。$\gamma$-geodesic ball 中心 $y$、半径 $r_\delta(y)$。$t\le0$ 上球缩到点；$t>0$ bounded away 上半径有正 lower bound。

Lemma 4.2 profile bounds（`04-spheres.tex:94-97`）：$\beta\ge cp_*$、$\mathrm{Hess}_\gamma f_*\le-c\beta\gamma$、$|\partial^jf_*|\le C_j\beta^j$（$j\ge1$）。常数 $c,C_j$ 与 $p_*\ge2$ 无关。$r_\delta^{1/p_*}$ 有 uniform Lipschitz；半径随 $\delta$ 严格递增、在 $t\le0$ 收敛到 $0$；$\sup_{0<\delta\le1,y\in Y}r_\delta\beta^2\to0$ 当 $R_*\downarrow0$。

证明里 $a_\delta=(\log\ell_\delta)'$，$A(s)=e^s/((1+e^s)\log(1+e^s))$。$A$ 正、递减；$A'\propto u(\log(1+u)-u)<0$。$|A^{(j)}|\le C_jA^{j+1}$；$a_\delta\ge c>0$、$a_\delta'\le0$、$|\partial_t^j\log\ell_\delta|\le C_ja_\delta^j$、$a_\delta\le\ell_\delta^{-1}$。$\beta=p_*a_\delta|dt|_\gamma$。Hessian 恒等式 $\mathrm{Hess}_\gamma f_*=p_*a_\delta\mathrm{Hess}_\gamma t+p_*a_\delta'dt\otimes dt$ 加上 depth 严格负性给前两条。$\partial_\delta\ell_\delta=\log(1+e^s)-se^s/(1+e^s)>0$；$\ell_\delta\to\max(t,0)$。$r_\delta\beta^2\le CR_*p_*^2\ell_\delta^{p_*-2}$，$\ell_\delta$ 在 fixed depth interval 上有界。

Cutoff 与 core（`04-spheres.tex:164-170`）：$K=\{y\in Y:y_n\ge-1/2,\;t(y)\le2t_b\}$、$\chi\in C_c^\infty(Y^\circ)$、$\chi=1$ on neighborhood of $K$、$\mathrm{supp}(d\chi)\subset\{y_n<-1/4\}\cup\{t>t_b\}$。选 $3t_b<t(1/4)$ 保证 $K\Subset Y^\circ$。在第二个 cutoff region 上 $r_\delta\ge R_*t_b^{p_*}>0$。这个 positive lower bound 让 §11 里"切分区域"时可以把 $\|[P,\chi]w\|$ 控制到已知量。

## §10 球面 transfer：从 kernel 到密度 $\psi$

Transfer 的构造在 §4 后半与 §10 交界。对每个 fixed $y$ 与 $r=r_\delta(y)>0$，$B_\gamma(y,r)$ 上的 Dirichlet 问题的 harmonic extension 给出从 boundary trace 到 interior 的映射；对第一变量 $x$ 与第二变量 $y$ 分别做 product continuation（§8）能拿到 kernel 的对应 slice；这个 slice 对 $y$ 处球的 trace 作用给出一个从"第一侧球邻域内的解"到"第二侧 $y$ 处值"的映射。Riesz 表示把这个映射写成对球面的积分：$v_{2,\nu}(y)=\int_{S_y}\psi(y,\omega)v_{1,\nu}(\exp_y^\gamma(r(y)\omega))d\sigma_y(\omega)$，$\int_{S_y}\psi\,d\sigma_y=I$（`06-matrix.tex:137-141` 汇总，构造在 §10 的 Proposition sph:transfer 里）。

$\psi$ 是矩阵密度：$y$ 光滑、$\omega$ 光滑（fixed $r>0$ 时），Hermitian $2\times2$。它的质量 $\int\psi d\sigma=I$ 使 $\psi-I$ 有 zero fiber mean。这个"zero mean"正是 §11 中 coercivity 命题作用的对象。

我在这个 section 上卡的时间比预期长，问题出在"product continuation 只能给你 fixed positive separation 上的 kernel"（`03-product.tex` 尾的 `cross:initial`），而球面 transfer 需要半径能任意小。Scalar companion 的处理是"分阶段"：先 fixed separation 起 seed，再用 propagation lemma 把 kernel 沿半径参数往下推。我在这个论文里第一次试图把 seed 与 propagation 一步做完，结果 $\widehat B$ 与 $\widehat d$ 的 inequality margin 不够。回到两阶段以后，`03-product.tex:818-828` 明确"excluded closed ball 严格在 $B(0,\widehat B)$ 内，$D_y$ 连通；固定 lower ball $A$ 与所有 excluded ball 不交、位于 $x_n<-\eta$；对 $W_\lambda$ 内的 $y$，构造的 kernel 与 $G_{1,\lambda}$ 在 $D_y$ 上解同一第一变量方程；$A$ 上二者都等于 $G_{2,\lambda}$；由唯一延拓 agreement 覆盖到 target overlap。交换变量得另一臂。"

这一点是 product continuation 与后续球面 transfer 之间最脆弱的耦合：seed 只在 fixed positive separations 有效，密度估计要独立于 $\delta$。密度估计的独立性由 §11 angular coercivity 提供。这两件事在 scalar companion 里已经分开过，这里只是"再分开一次"。

## §11 Angular coercivity：把矩阵项当作低阶吸收

到 §10 结束时我手上有球面密度 $\psi$ 的表示与 product continuation 给的存在性，缺的是"$\psi$ 的 $L^2$ 界在半径塌下去时依然一致"。§5 全节都在做这一件事。

Frame equations（`05-angular.tex:20-24`）：$\mathcal L_1=a^{ij}\partial_i\partial_j+B_1^i\partial_i$、$\mathcal L_2=Q^{ij}\partial_i\partial_j+B_2^i\partial_i$。$B_j^i$ 是 $2\times2$ 复矩阵从左侧乘 column。零阶项消失因为 $F_j$ 每一列 harmonic。所有系数在 fixed coordinate nbhd 上、小 dilation 下一致光滑有界。

Bootstrap 假设（`05-angular.tex:44-46`）：$\sum_{|\alpha|\le8}|\partial_y^\alpha h|\le\varepsilon r$、$r\beta^2\le\varepsilon$。第一条来自 §4 的 provisional comparison；第二条由振幅 $R_*$ 的选择保证。这两条贯穿 §11 与 §12。

单位球丛 $S_\gamma Y$ 与 fiber probability $d\sigma_y$；水平微分 $\nabla$ 用 $\gamma$ 的 parallel transport，包括任何 base tensor index，固定 harmonic frame components 上按分量作用。$d\sigma_y$ parallel。Hilbert 范数用 $dV_\gamma(y)d\sigma_y(\omega)$ 与 Hermitian/Frobenius 标准范数。

三种 transpose 必须区分（`05-angular.tex:58-72`）：bilinear row transpose $\mathcal C^t$ 由 $\int_{S_y}(\mathcal C^t\psi)Vd\sigma_y=\int_{S_y}\psi(\mathcal CV)d\sigma_y$ 定义，对 $\psi$ 的每一 row 分别 apply，无复共轭；矩阵 $M$ 从左边乘 column 变成对 $\psi$ 从右边乘；transfer map 输出上左乘的矩阵在 $\psi$ 上从左边作用。星号记 scalar sphere operator 的 Hermitian sphere adjoint；dagger 记含 base integration 的完整 Hilbert-space adjoint。实 scalar sphere operator 的双线性 transpose 与 Hermitian adjoint 相同。

对 $\mathcal L_1v=0$ 在 closed moving ball 附近的列 $v$，$V(y,\omega)=v(\exp_y^\gamma(r(y)\omega))$。Solving ball Dirichlet 把 $v$ 的 boundary derivatives 用 trace 表达，从而定义 $\mathcal C_i$ 使 $\nabla_iV=\mathcal C_iV$。$\mathcal C_{i,0}$ 是 $c_1\Delta_{g_1}$（主部系数 $a=\gamma^{-1}$）的对应 moving trace operators；这条比较方程未必 coordinate drift 为零。Euclidean harmonic extension 的 radial boundary derivative 记 $\mathsf B$，ambient derivatives 记 $\mathsf A_i$。球谐 $\mathcal H_k$ 上 $\mathsf B=k$、$\mathsf A_i:\mathcal H_k\to\mathcal H_{k-1}$。算子与其 tensor index 平行；$[\mathsf B,\mathsf A_i^*]=\mathsf A_i^*$、$\sum_i\mathsf A_i^*\mathsf A_i^*=0$（后者是 harmonic extension 的 Laplacian 为零之伴随）。$\|w(y,\cdot)\|_s=\|(1+\mathsf B)^sw(y,\cdot)\|_{L^2(S_y)}$ 与球 Sobolev 一致等价。

Lemma 5.3 trace expansion（`05-angular.tex:114-127`）：$\mathcal C_{i,0}^*=r^{-1}\mathsf A_i^*+f_i\mathsf B+E_i+F_i$，$E_i\in r\Psi^1$、$F_i\in\Psi^0$；归一化 remainder $r^{-1}E_i,F_i$ 到六阶 base derivatives 有 $C_j\beta^j$ allowance。并且 rows 上 $K_i:=\mathcal C_i^t-\mathcal C_{i,0}^*\in\Psi^0$、$\nabla K_i\in\beta\Psi^0$。

证明要点：把半径 $s$ 当独立参数，$z\mapsto\exp_y^\gamma(sz)$ pull back、乘 $s^2$。principal coefficients $\delta^{ij}+O(s^2)$、first-order $O(s)$；矩阵情形 scalar principal coefficients 乘 $I$，同一命题。Dirichlet 算子族 smooth to $s=0$、$s=0$ 处等 Euclidean Laplacian。椭圆 Dirichlet 估计与 $s=0$ 处可逆给 Dirichlet 逆族在任意 fixed Sobolev scale 上光滑一致有界。radial boundary derivative 是 classical of order 1；principal symbol 只依赖 principal coefficients 与 differentiating vector。Boundary symbol 构造（decaying normal root + successive transport equations）在 $(y,s)$ 上光滑；参考 Joshi-Lionheart 关于 Hodge Laplacian 的因子化，其构造对 present systems 有效，因为主部 scalar 乘 $I$、transport equations 允许矩阵 coefficient。真正的 Dirichlet 逆只把 parametrix 改正为一个 smoothing operator。$\mathsf B+s\mathcal B_1(y)+s^2\mathcal B_2(y,s)$，$\mathcal B_1\in\Psi^0$、$\mathcal B_2\in\Psi^1$；matrix 与 scalar radial operators 主 symbol 每个 $s$ 都同、$s=0$ 相同，差为 $s$ 乘一个 $\Psi^0$ 光滑族。

Center derivative 加 parallel-transported $\omega$ 给出初值 derivative 为 $0$ 的 Jacobi 场；unit-ball 坐标里 velocity 是 $s^{-1}(e_i+O(s^2))$；代入 $s=r(y)$ 加 $f_i\omega$。Tangential derivatives 直接作用 boundary data，两方程相同。Radial component 用上面 expansion。Leading terms $r^{-1}\mathsf A_i+f_i\mathsf B$；order 1 error 大小 $O(r)$；order 0 bounded；$r\beta\le\varepsilon/\beta$。

System coercivity（`05-angular.tex:649-661`）：fixed uniform smooth bounds 与 reference geometry、profile bound 常数之下，存在充分大的 $\beta_0$、$\varepsilon_0>0$、$C$；$\varepsilon\le\varepsilon_0$ 时 $\mathcal N(\varphi)\le C\|P\varphi\|_{L^2}$ 对每个 zero fiber mean 光滑 compactly base-supported matrix function $\varphi$。常数与 shrinking parameter、小 dilation 无关。

证明比较恒等式（`05-angular.tex:668-673`）：$P-P_0=r[Q^{ij}(D_{i,0}K_j+K_iD_{j,0}+K_iK_j)+L_{q^i}D_{i,0}+L_{b_2^i}K_i]$，$q^i=b_2^i-b_{i,0}I$。这里 $D_{i,0}K_j$ 表 composition 含 $K_j$ 微分。$q^i$、$b_2^i$ 无微分出现在公式中。左乘与 sphere operator 的 row 作用可交换，仅在 matrix 只依赖 center 时才成立；比较恒等式里不需要这种交换。

Bound（`05-angular.tex:685-688`）：$\|(P-P_0)\varphi\|_{L^2}\le C(\|\varphi\|_{L^2(Y;H^1(S_y))}+\|r\nabla\varphi\|_{L^2})$。展开来看：$D_{i,0}K_j$ 里 $\varphi$ 上 base 导数的项都是 $r\Psi^0\nabla\varphi$；$K_i$ 与 leading $r^{-1}\mathsf A_j^*$ 相乘在 $r$ 之后成 bounded $\Psi^1$；$K_i$ 与 $f_j\mathsf B$ 相乘 coefficient $O(r\beta)$；对 $K_j$ 微分给 $r\beta\Psi^0$。$r\beta\le\varepsilon/\beta$。所有常数在 $\beta_0$ 增大时一致。

Apply Proposition 5.8（scalar coercivity）于四个 entries。$\|\varphi\|_{L^2(Y;H^1)}\le\beta_0^{-1}\mathcal N(\varphi)$、$\|r\nabla\varphi\|_{L^2}\le\varepsilon\beta_0^{-2}\mathcal N(\varphi)$。得 $\mathcal N(\varphi)\le C_0\|P\varphi\|_{L^2}+C_0C(\beta_0^{-1}+\varepsilon\beta_0^{-2})\mathcal N(\varphi)$。增大 fixed lower threshold 让最后系数 $\le1/2$。参数选择顺序：$p_*$ 决定 $\beta_0$；$\beta_0$ 定后才轮到 $\varepsilon$ 与半径振幅。

密度界（`05-angular.tex:742-757`）：$\|\chi\psi_\delta\|_{L^2(S_\gamma Y)}\le C$。证明用再生产 $\int\psi_\delta d\sigma_y=I$，令 $\varphi=\chi(\psi_\delta-I)$ 每 sphere zero mean。$P\varphi=-\chi PI+[P,\chi](\psi_\delta-I)$。第一项一致 bounded；第二项用 commutator 界（`05-angular.tex:727-731`）需要 cutoff derivative region 上 $\psi_\delta$ 的 angular 一阶与 $r\nabla\psi_\delta$；lower region 上密度是 normalized ball evaluation kernel，其他地方半径有 fixed positive lower bound。这两处都是 Lemma 4.3 cutoff bounds 里的量。coercivity bound $\mathcal N(\varphi)$、因此 $\|\varphi\|_{L^2}$；加上 fixed $\chi I$。

我在这一节反复核对了两件事：$P_01$ uniformly bounded 是必须的（保证 $PI$ 一致 bounded）；[cutoff bound](见本节末) 里 $[2T,\chi]=2\sum_i\mathsf A_i^*(\nabla_i\chi)$ 只用 angular 一阶，$\mathcal U$ 的二阶 base coefficient 是 $rQ^{ij}$、一阶 base coefficients bounded in $\Psi^1$，$\mathcal J$ 与 $\chi$ 交换；$P-P_0$ 的一阶 base coefficients $r\Psi^0$（由比较恒等式）。这些细节决定 density 界在 $\delta\to0$ 时不会崩。

## §12 位移 $D$ 与它的一次力矩

Transfer 展开里 $M^i(y)=\int_{S_y}\psi(y,\omega)(x^i(y,\omega)-y^i)d\sigma_y(\omega)$（`06-matrix.tex:153-154`）。$\rho(y)=\|\psi(y,\cdot)\|_{L^2(S_y)}$，uniform normal coordinates 与 Cauchy--Schwarz 给 $|M(y)|\le Cr(y)\rho(y)$。密度 $\psi$ 有界 $\rho$ 有界，$M$ 也就 $O(r)$。这是"$D$ 是 $O(r)$"最原始的形态。

问题：$M$ 依赖 $\delta$（through $\psi$ 与球）。要 bootstrap 一个与 $\delta$ 无关的位移。§7 已经给出 paired coordinate matrices $\widehat X_j^l$（`06-matrix.tex:41`：$\widehat X_j^l=\lambda^{-1}X_j^l(\lambda y)$）与 additional columns $u_j$ 缩为 $\lambda^{-2}u_j(\lambda y)$。列表 $(v_{1,\nu},v_{2,\nu})$，$1\le\nu\le N$，包含 $\widehat X_j^l$ 全列，是有限且与 $\delta$ 无关的固定列表。Taylor 于 origin 给所有 fixed smooth orders 上一致 bound；配对方差在已知区域上等于 $0$ 于一个 accumulate 到 origin 的开集，各阶导数于 origin 全为 $0$。

Displacement $D^i$ 由线性系统定义（`06-matrix.tex:163-168`）：$\widehat X_2^l-\widehat X_1^l=\sum_iD^i\partial_i\widehat X_1^l$。右侧 map 从 $n$ 个 $D^i$ 到 $n$ 个矩阵，通过 right multiplication 与 indicated coefficients。它在 derivatives 意义下 uniform 收敛到 identity，因 $\partial_i\widehat X_1^l\to\delta_i^lI$。这保证 $D^i$ 光滑、uniform smooth bounds、与 $\delta$ 无关。

Remainder $R_\nu=v_{2,\nu}-v_{1,\nu}-D^i\partial_iv_{1,\nu}$（`06-matrix.tex:177`）同样光滑、uniform bounds、与 $\delta$ 无关。

Weighted moment bounds（`06-matrix.tex:186-193`）：$\|\chi D/r\|_{L^2(Y)}\le C$、$\|\chi R_\nu/r^2\|_{L^2(Y)}\le C$。证明：Taylor 于固定 chart 加 `mat:transfer-input` 给 $v_{2,\nu}-v_{1,\nu}=M^i\partial_iv_{1,\nu}+E_\nu$，$|E_\nu(y)|\le Cr(y)^2\rho(y)$。这一步只用 selected columns 的 uniform second derivatives 与 $|x-y|\le Cr$；coordinate displacement 是 scalar，所以没有 matrix factor 交换。同样计算施于 coordinate matrices；减 `mat:displacement` 显示 uniform invertible map 把 $D-M$ 送到 $Cr^2\rho$ bound 的错误里。因此 $|D-M|\le Cr^2\rho$、$|D|\le Cr\rho$、$|R_\nu|\le Cr^2\rho$。$\chi$ 乘、积分给加权界。

Pointwise interpolation（`06-matrix.tex:227-245`）：选 $d_*=10+n/2$、$\eta=1/(2d_*)$、$p_*>2d_*$、$m\ge\lceil10+3d_*\rceil$；$\rho_0>0$ fixed；$y\in K$、$r(y)<\rho_0$ 时 $\sum_{|\alpha|\le10}|\partial^\alpha D(y)|\le Cr(y)^{1/2}$、$\sum_{|\alpha|\le10}|\partial^\alpha R_\nu(y)|\le Cr(y)^{3/2}$。

证明要点：$r^{1/p_*}$ uniform Lipschitz。$s=r(y)^\eta$；$\eta>1/p_*$ 时 $z\in B(y,s)$ 有 $|r(z)^{1/p_*}-r(y)^{1/p_*}|\le Cr(y)^\eta\le\frac12 r(y)^{1/p_*}$。故 $cr(y)\le r(z)\le Cr(y)$ 在该球上；$\chi=1$ on nbhd of $K$，缩 $\rho_0$ 使球在 nbhd 内。加权界给 $\|D\|_{L^2(B(y,s))}\le Cr(y)$、$\|R_\nu\|_{L^2(B(y,s))}\le Cr(y)^2$。

Taylor interpolation inequality（`06-matrix.tex:270-273`）：$|\partial^\alpha U(y)|\le Cs^{-|\alpha|-n/2}\|U\|_{L^2(B(y,s))}+C_ms^{m-|\alpha|}$，$|\alpha|<m$。对 $D$ 首项 $Cr(y)^{1-\eta d_*}=Cr(y)^{1/2}$；对 $R_\nu$ 首项 $Cr(y)^{2-\eta d_*}=Cr(y)^{3/2}$。次项 $C_mr(y)^{\eta(m-10)}\le C_mr(y)^{3/2}$（$\rho_0\le1$）。

这一节里我印象最深的是"插值只对固定半径做、不对 shrinking 参数做微分"这句话。它意味着 bootstrap 结构里 $\delta$ 只从系数（$r(y)$）里进入，$D$、$R_\nu$ 的导数阶数与 $\delta$ 无关。这一点在 §16 让 $\delta$ 从 $1$ 降到 $0$ 时才能"一个 $\lambda$ 通吃"。

## §13 把 $D$ 拆成 $dI+W$：踢掉实标量部分

Weighted moment 只给 $O(r)$ 与 $O(r^{1/2})$；要真塌半径需要 $O(r^{3/2})$。这一节把 $D$ 送进一个 PDE。

Selected first-side column $w=v_{1,\nu}$、$R=R_\nu$；用 $v_{2,\nu}=w+D^k\partial_kw+R$ 展开 $\mathcal L_2v_{2,\nu}=0$、$\mathcal L_1w=0$。三阶导数里用 $a^{ij}\partial_i\partial_j\partial_kw=-(\partial_ka^{ij})\partial_i\partial_jw-(\partial_kB_1^i)\partial_iw-B_1^i\partial_i\partial_kw$。得到 identity（`06-matrix.tex:305-322`）：$[h^{ij}I+a^{li}\partial_lD^j+a^{lj}\partial_lD^i+\mathcal B^{ij}(D)]\partial_i\partial_jw+\mathcal Y^i\partial_iw=-\mathcal L_2R-2h^{ij}(\partial_iD^k)\partial_j\partial_kw-D^kh^{ij}\partial_i\partial_j\partial_kw$，其中 $\mathcal B^{ij}(D)=-D^k\partial_ka^{ij}+\frac12(B_2^iD^j+B_2^jD^i-D^jB_1^i-D^iB_1^j)$，$\mathcal Y^k=B_2^k-B_1^k+Q^{ij}\partial_i\partial_jD^k+B_2^i\partial_iD^k-D^l\partial_lB_1^k$。$\mathcal Y$ 与 selected column 无关。

$\mathcal B^{ij}$ 里 matrix multiplication 顺序记录 drift 的非交换：$\mathcal L_2$ 的 drift 作用在 $D^k\partial_kw$ 上把 $B_2^i$ 放 $D^k$ 左边；第一方程微分把 $B_1^i$ 放 $D^k$ 右边。这个 non-commutative ordering 是 scalar companion 完全没有的负担。我第一次读到这里以为可以"average 掉"，实际上不能：$B_2^iD^j$ 与 $D^jB_1^i$ 都保留下来，$\frac12$ 只是对称化。

$\Pi$ 是 symmetric contravariant spatial tensors 到 $\gamma$-trace-free 部分的投影，对 matrix entrywise：$(\Pi T)^{ij}=T^{ij}-\frac1n(\gamma_{kl}T^{kl})a^{ij}$（`06-matrix.tex:333-336`）。$\gamma_{ij}h^{ij}=0$ 记得。

Projected displacement equation（`06-matrix.tex:341-356`）：存在光滑 matrix-valued symmetric tensor $\mathcal E$ 使 $h^{ij}I+\Pi(a^{li}\partial_lD^j+a^{lj}\partial_lD^i+\mathcal B^{ij}(D))=\mathcal E^{ij}$。$y\in K$、$r(y)<\rho_0$ 时 $\sum_{|\alpha|\le8}|\partial^\alpha\mathcal E(y)|\le Cr(y)^{3/2}$。

证明用 Lemma mat:spanning（`06-matrix.tex:78-95`）：在每点，selected jets 的 $(\partial_iv_{1,\nu},\partial_i\partial_jv_{1,\nu})$ 复线性张成所有 $(p,H)$，$H_{ij}=H_{ji}\in\C^2$ 且 $a^{ij}H_{ij}+B_1^ip_i=0$。系数可由 smooth right inverse 实现，各 fixed 阶一致 bound。取 scalar symmetric $H_s$ 使 $a^{ij}(H_s)_{ij}=0$，配合 right inverse 用 $H_se_\alpha$（$\alpha=1,2$）实现 zero gradient。得到的 $Z_\nu$ 组合给出 projected coefficient 与 $H_s$ contraction 的两列。invert 这个 spatial duality 定义 $\mathcal E$。微分至八阶用 $Z_\nu$ 与有界 derivatives 系数表示，避开 $\mathcal Y$ 的微分。

Real-linear projection on matrices：$q(Z)=Z-\frac12\mathrm{Re}\,\mathrm{tr}(Z)I$、$\mathcal V_0=\{Z\in\C^{2\times2}:\mathrm{Re}\,\mathrm{tr}Z=0\}$（`06-matrix.tex:397-401`）。$\mathcal V_0$ 是 real 维 8。写 $D^i=d^iI+W^i$，$d^i\in\R$、$W^i\in\mathcal V_0$。对 `mat:displacement` 取 $\frac12\mathrm{Re}\,\mathrm{tr}$，两侧 trace coordinate identity 精确给 $d^l=-\frac12\mathrm{Re}\,\mathrm{tr}\sum_iW^i\partial_i\widehat X_1^l$（`06-matrix.tex:408-410`）。$d$ 是 $W$ 的零阶 real-linear 表达、系数光滑一致 bound。

对 `mat:projected` 施 $q$：$h^{ij}I$ 消失（$h$ 是 real scalar），$d^iI$ 相关的 derivative terms 全消失。剩下（`06-matrix.tex:419-424`）：$\Pi(a^{li}\partial_lW^j+a^{lj}\partial_lW^i)+\mathcal B_0^{ij}(W)=\mathcal E_0^{ij}$，$\mathcal E_0=q(\mathcal E)$。$\mathcal B_0$ 是 real-linear 零阶 operator with uniformly smooth coefficients。$\mathcal B_0$ 里没有隐藏的一阶微分：`mat:scalar-direction` 的微分只出现在与 $I$ 成正比的项里，那些项已被 $q$ 消掉。

这一步把矩阵值 PDE 里最难处理的一部分（"与 $dI$ 成比例的实标量部分"）转成了一个代数约束：$d$ 由 $W$ 定；剩下 $W$ 上的方程主部是 conformal Killing 型，正是 §14 需要的形状。

## §14 有限型（conformal Killing）与 $r^{3/2}$

Lemma `06-matrix.tex:441-456`（prolongation of CK principal part）：$n\ge3$、$a=\gamma^{-1}$ 光滑正定、$V$ 有限维实向量空间；$V$-值 vector field $W$ 满足 $\Pi(a^{li}\partial_lW^j+a^{lj}\partial_lW^i)+C^{ij}(W)=E^{ij}$，$C$ 光滑 real-linear 零阶。$W$ 每个三阶 derivative 都是 $W$ 至二阶 derivative 与 $E$ 至二阶 derivative 的光滑线性组合。系数 bound 在 $a$ uniform elliptic 与 indicated background coefficients range 在 bounded smooth sets 上一致。

证明是这篇笔记里我最喜欢的部分之一。两次微分方程，最高点部是从"三阶 derivative tensor"到"两次微分的 trace-free symmetric gradient"的线性 map。证 injective。constant linear change of coordinates 让 $a^{ij}=\delta^{ij}$ 在该点；每个 $V$ 的实分量单独考虑。Kernel 里的 tensor 定义齐次 cubic vector field $Z$，其 trace-free symmetric gradient 为零：该 gradient 齐次 quadratic，二阶导数为零。因此 $\partial_iZ_j+\partial_jZ_i=2\delta_{ij}\sigma$、$\sigma=\frac1n\mathrm{div}Z$（`06-matrix.tex:471-473`）。微分并组合三个 index permutation 给 $\partial_i\partial_jZ_k=\delta_{jk}\partial_i\sigma+\delta_{ik}\partial_j\sigma-\delta_{ij}\partial_k\sigma$。$k$ 上 divergence：$(n-2)\partial_i\partial_j\sigma=-\delta_{ij}\Delta\sigma$。取 trace：$(2n-2)\Delta\sigma=0$。$n\ge3$ 让 Hessian of $\sigma$ 为零。前面公式给 $\partial_i\partial_j\partial_lZ_k=0$，齐次 cubic $Z$ 消失。injectivity 得证。

$T_a$ 记这个 injective map on third-derivative tensors，用固定 Euclidean inner products on finite-dimensional tensor spaces。左逆 $(T_a^*T_a)^{-1}T_a^*$ 光滑。Uniform ellipticity 与 bounded coefficient range 的紧性给 uniform bounds。二次微分方程里所有其他项含至多 $W$ 或 $E$ 两个导数。应用左逆得结论，进一步 fixed 次微分给光滑 coefficient bounds。

$3\ge$ 有限型（finite type）在这里的意思就是"两次 prolongation 把三阶导数从低阶与 forcing 中解出"。Euclidean 上 CK vector fields degree $\le2$（Eastwood 的 §3），这里做了 variable coefficient + matrix values 版本，$n\ge3$ 用在 $(n-2)\partial\partial\sigma=-\delta\Delta\sigma$ 与 trace $(2n-2)\Delta\sigma=0$ 之间的除法；$n=2$ 时 trace 系数为 $2$、不能推 Hessian $\sigma=0$。

Improvement（`06-matrix.tex:503-515`）：Lemma mat:interpolation 的 fixed choices 下，$C$ 与 $\rho_0>0$ 存在，small $\lambda$ 一致，`mat:provisional` 蕴含 $H_8(y)\le Cr_\delta(y)^{3/2}$ 于 $y\in K$、$r_\delta(y)<\rho_0$；同集合上 $D$ 至九阶导数 $\le Cr_\delta^{3/2}$。

证明把 Lemma mat:finite-type 用于 `mat:CK-system` 于 $V=\mathcal V_0$。每个 $|\alpha|=3$ 得到 $\partial^\alpha W=\sum_{|\zeta|\le2}C_{\alpha\zeta}\partial^\zeta W+\sum_{|\zeta|\le2}F_{\alpha\zeta}\partial^\zeta\mathcal E_0$，coefficient maps 光滑一致 bound。$y\in K$、$r(y)<\rho_0$。§4 core 几何给 vertical segment $z(s)=(y',s)$、$-\frac12\le s\le y_n$ 留在 $K$，$r(z(s))\le r(y)$。initial point $z(-\frac12)$：paired coordinate matrices 在已知下侧开邻域上相等，$D$ 与所有导数在该点为 $0$；$W$ 亦为 $0$。

令 $\mathcal W(s)$ 为 $W$ 沿 $z(s)$ 至二阶的所有 coordinate derivatives。对 $s$ 求导给 $\mathcal W$ 的某个分量或三阶导数（用 prolongation 式）。$\mathcal W'(s)=A(s)\mathcal W(s)+F(s)$，$\mathcal W(-\frac12)=0$，$|A(s)|\le C$，$|F(s)|\le Cr(y)^{3/2}$（`06-matrix.tex:545-549`）。$F$ 的界来自 `mat:E-bound`，整段 radius $<\rho_0$。Gronwall 给 $\sum_{|\alpha|\le2}|\partial^\alpha W(y)|\le Cr(y)^{3/2}$。

对 $3\le k\le9$ 微分 prolongation $k-3$ 次，把 $W$ 的 $k$ 阶导数用 $\le k-1$ 阶与 $\mathcal E_0$ 的 $\le k-1$ 阶表达。归纳与 `mat:E-bound` 得同阶到九。最后一步用 $\mathcal E_0$ 恰好八个导数。`mat:scalar-direction` 给 $d$、因此 $D$ 同估计。微分 `mat:projected` 八阶，右端用 $D$ 九阶、$\mathcal E$ 八阶，全 bound $Cr^{3/2}$。

## §15 垂直线段上的 Gronwall 与 bootstrap 结构

这一小节专门讲 §14 里 Gronwall 那一段的几何选择，以及为什么它必须和 bootstrap 结构合在一起看。

垂直 segment 定义 $z(s)=(y',s)$、$-\frac12\le s\le y_n$。§4 的 core $K$ 由 $y_n\ge-1/2$ 与 $t(y)\le2t_b$ 界定（`04-spheres.tex:166`）；这条 vertical 完全在 $K$ 里。$r_\delta$ 沿这条 segment 的单调性来自 $t$ 对 $y_n$ 严格递增：$z(s)$ 上 $t_0=y_n+|y'|^2$ 随 $s$ 严格递增，$\ell_\delta$ 单调，$p_*>0$，$r_\delta(z(s))\le r_\delta(y)$。整段 radius 都 $<\rho_0$，`mat:E-bound` 沿整段一路适用。

初值 $\mathcal W(-\frac12)=0$ 靠的是"配对的 coordinate matrices 在已知下侧开邻域上相等"。这一点在 §7 建立 contact data 时被塞进构造（`02-boundary.tex:466-467`：所有 paired functions 在已知区域 agree，contact point 处 jets 相同）。dilation 后已知下侧包含任何 fixed bounded region 严格低于 $x_n=0$ 的部分（`02-boundary.tex:513-515`），因此 segment 起点 $s=-\frac12$ 落在已知下侧里。$D$ 与所有导数于此处等于 $0$；$W$ 亦然。

ODE 结构 $\mathcal W'(s)=A(s)\mathcal W(s)+F(s)$：$\mathcal W$ 包含 $W$ 的所有 $\le2$ 阶 coordinate derivatives 于 $z(s)$。对 $s$ 微分 $\mathcal W$ 的分量，要么给另一个分量，要么给 $W$ 的三阶导数；后者被 prolongation 式表达为 $\mathcal W$ 分量与 $\partial^\zeta\mathcal E_0$（$|\zeta|\le2$）。$|A(s)|\le C$ 来自 prolongation 系数 smooth bounds；$|F(s)|\le Cr(y)^{3/2}$ 来自 `mat:E-bound`。

Gronwall 给出 $\sum_{|\alpha|\le2}|\partial^\alpha W(y)|\le Cr(y)^{3/2}$。这里"$\le2$ 阶"是 bootstrap 中最要紧的一档：higher order 用 $k$ 阶 prolongation 归纳给同样界。$W$ 与 $d$ 一起给 $D$；投影 equation 微分至八阶得 $h$ 的同界。

Bootstrap 结构本身在 §16。让我先在这里把逻辑链写清楚，免得 §16 里被"参数选择顺序"打断：

1. Provisional comparison `mat:provisional`：$H_8(y)\le\varepsilon r_\delta(y)$ 于 $y\in Y$。这是角 coercivity（`ang:smallness`）与 §12 weighted moment 的输入。
2. Angular coercivity 给 $\|\chi\psi_\delta\|_{L^2}\le C$ 于 density（Proposition `ang:density`）。
3. Weighted moment 给 $\|\chi D/r\|_{L^2}\le C$、$\|\chi R_\nu/r^2\|_{L^2}\le C$。
4. Interpolation 给 $|D|\le Cr^{1/2}$、$|R_\nu|\le Cr^{3/2}$ 于 $|\alpha|\le10$（Lemma `mat:interpolation`）。
5. Comparison identity + projection + CK system（§13）。
6. Finite type prolongation + Gronwall 沿 vertical（§14）：$|W|_{C^2}\le Cr^{3/2}$。
7. 归纳至 $C^9$；$d$、$D$、$h$ 都到 $Cr^{3/2}$。

从"provisional"出发绕一大圈回来，得到"improved"：$H_8(y)\le Cr(y)^{3/2}$ 于 $y\in K$、$r(y)<\rho_0$。$\rho_0$ 的选择让 $Cr^{3/2}\le\varepsilon r/2$ 于 $r<\rho_*$ 里，其中 $\rho_*$ 是 §16 才选的更小阈值。这就是"strict improvement"字面意义：provisional $\varepsilon r$ 被推回至 $\varepsilon r/2$。

我一开始写 bootstrap 逻辑的时候犯过顺序错误：先选 $\varepsilon$ 与 $R_*$，再让 $p_*$ 与 $\beta_0$ 依它定。反了。coercivity 里的 $\beta_0$（来自 $p_*$）出现在最终不等式的左边系数 $\beta_0^{-1}+\varepsilon\beta_0^{-2}\le1/2$ 里；这个 threshold 必须先固定才能谈 $\varepsilon$ 与 $R_*$。`06-matrix.tex:592-602` 明写"Choose $p_*$ large enough for the sphere geometry, the angular estimate, and Lemma mat:interpolation. Next choose $\varepsilon$ sufficiently small and $R_*$ sufficiently small ... $r\beta^2\le\varepsilon$。Remark sph:choices 解释 fixed-separation range 都定在 $\lambda$ 前。Prop ang:density 与所有估计常数在 small $\lambda$ 一致。"

## §16 一个 $\lambda$ 打完所有 $\delta$

Proposition `mat:local`（`06-matrix.tex:581-590`）：contact coordinates 与 harmonic frames 下，存在 origin 的邻域上两侧 metric smooth conformal；harmonic-frame equations 乘上使主 tensor 相等的正标量之后重合；所有有限 selected pairs 于该邻域一致。

证明前半就是上面 §15 的参数顺序。选完 $p_*$、$\varepsilon$、$R_*$ 之后：

- 选 $0<\rho_*<\rho_0$、$\rho_*\le1$、使 $C\rho_*^{1/2}\le\varepsilon/2$（`06-matrix.tex:604-605`）。于是 Prop `mat:improvement` 在 $r_\delta<\rho_*$ 处把 `mat:provisional` 改进为 $H_8\le\varepsilon r_\delta/2$。
- $\lambda\to0$ 时 $h\to0$ on $C^8(Y)$。三个数 $\rho_*$、$\min_Yr_1$、$R_*(2t_b)^{p_*}$ 都与 $\lambda$ 无关、正。
- 选一次足够小的 $\lambda$ 使 $\sup_YH_8\le\frac\varepsilon2\min\{\rho_*,\min_Yr_1,R_*(2t_b)^{p_*}\}$（`06-matrix.tex:617-621`）。同时把已知下侧包含 $\{y_n<-1/4\}$ 在 fixed ranges 上。这个 $\lambda$ 之后固定。

Continuity argument。$\mathcal I=\{\delta\in(0,1]:H_8(y)\le\varepsilon r_\delta(y)\ \forall y\in Y\}$（`06-matrix.tex:628-631`）。

- $1\in\mathcal I$：由 `mat:final-dilation`，$\sup_YH_8\le(\varepsilon/2)\min_Yr_1$，而 $r_1(y)\ge\min_Yr_1$，故 $H_8(y)\le(\varepsilon/2)r_1(y)$。
- 任 $\delta\in\mathcal I$：$\mathcal I$ 的定义给 provisional。Prop `mat:improvement` 处理 $K$ 里 $r_\delta<\rho_*$ 的点。$r_\delta\ge\rho_*$ 的点由 `mat:final-dilation` 处理。$K$ 外的点：要么 $y_n<-1/2$（那里系数已经相等）、要么 $t>2t_b$。后者 $\ell_\delta(t)\ge t$，$r_\delta\ge R_*(2t_b)^{p_*}$，`mat:final-dilation` 又管到。全体 $Y$ 上 $H_8\le\varepsilon r_\delta/2$。
- $\mathcal I$ 于 $(0,1]$ 相对闭：$Y$ 紧、函数连续。
- $\mathcal I$ 相对开：fixed $\delta>0$ 上 $r_\delta$ 有 positive minimum on $Y$；刚证明的 strict factor $1/2$ 在 weaker defining inequality 下对附近 $\delta'$ 保持。
- $(0,1]$ 连通给 $\mathcal I=(0,1]$。

$K^\circ\cap\{t<0\}$ 是 fixed open set、含 origin。其上 $r_\delta\to0$ 于 $\delta\to0$。$h$、$D$、$R_\nu$ 与 $\delta$ 无关。provisional bound 与 `mat:pointwise` 因此 imply $h=0$、$D=0$、$R_\nu=0$ 于该集合（`06-matrix.tex:651-657`）。特别地所有 selected pairs 一致。

减去它们的方程给 $(B_2^i-B_1^i)\partial_iv_{1,\nu}=0$（`06-matrix.tex:661-662`）。Gradient projection of the space `mat:jet-constraint` 是全部 $(\C^2)^n$：任意 gradient 都能选 Hessian trace 满足约束。Lemma `mat:spanning` 于是给 $B_1=B_2$。$Q=a$ 一起给归一化 harmonic-frame operators 相等。$Q$ 的定义（$Q=ng_2^{-1}/\mathrm{tr}(\gamma g_2^{-1})$）说明两个 inverse metrics 是正标量倍数，因此 metric smooth conformal。反向 fixed dilation 得原 contact coordinates 下结论。

我在这一步学到一件事：continuity argument 的"闭"和"开"用的是不同性质的信息。"闭"靠的是 $H_8$ 与 $r_\delta$ 对 $\delta$ 连续、$Y$ 紧。"开"靠的是 $r_\delta$ 的 positive minimum 让 strict factor $1/2$ 转成 weaker $1$。这两条同时成立要求"半径有 lower bound 或 radius 已经塌到 $0$"这两种情形都被处理。$\rho_*$ 的角色就是把它们切开：小半径一侧走 improvement、大半径一侧走 `mat:final-dilation`。

## §17 消 conformal factor：一个 Yamabe 型恒等式

Lemma `glob:conformal`（`07-global.tex:15-30`）：contact coordinates 与 unitary frames 下，若 origin 邻域 $\Omega$ 上 $g_2=e^{2\omega}g_1$，harmonic frames $F_j$ 里两个方程经过 scalar normalization 有相等主部时一阶 coefficient 相同，则 $g_2=g_1$、$J_{\mathrm{loc}}=F_1F_2^{-1}\in U(2)$、$d_{A_1}(J_{\mathrm{loc}}u)=J_{\mathrm{loc}}d_{A_2}u$ 于 $\Omega$；且此 identification 在已知侧与旧 match 一致，$\Omega$ 上所有对应 source evaluations match。

证明。$C_j=F_j^{-1}(dF_j+A_jF_j)$（`07-global.tex:34-36`）。这些是 harmonic frame 里的 connection matrices，在标准 matrix inner product 下未必 skew-Hermitian。$-\Delta_{g_j,C_j}$ 在 frame 里等于 $g_j^{il}((\partial_i+C_{j,i})(\partial_l+C_{j,l})-\Gamma^k_{il}(g_j)(\partial_k+C_{j,k}))$（`07-global.tex:42-44`）。零阶为 $0$，因 $F_j$ 列 harmonic。Common-principal-part hypothesis 于是给 $e^{2\omega}\Delta_{g_2,C_2}=\Delta_{g_1,C_1}$（`07-global.tex:50`）：二阶 coefficient 在 conformal normalization 下相同，一阶 coefficient 由假设相同，零阶 coefficient 都为零。

$\phi=(n-2)\omega/2$。Conformal change of Christoffel symbols 给 $e^{2\omega}\Delta_{g_2,C_2}=\Delta_{g_1,C_2}+2\langle d\phi,\partial+C_2\rangle_{g_1}$（`07-global.tex:59-61`）。一阶项 compare 得 $C_2=C_1-d\phi\cdot I$。代回，matrix multiplication 顺序保留：$\Delta_{g_1,C_1-d\phi I}+2\langle d\phi,\partial+C_1-d\phi I\rangle_{g_1}=\Delta_{g_1,C_1}-(\Delta_{g_1}\phi+|d\phi|_{g_1}^2)I$。零阶项 comparison 得 $\Delta_{g_1}\phi+|d\phi|_{g_1}^2=0$，即 $\Delta_{g_1}(e^\phi)=0$（`07-global.tex:76-78`）。

已知开侧上 metric 已一致，$e^\phi=1$。$\Omega$ 上唯一延拓给 $e^\phi\equiv1$。$n\ge3$ 且 $\omega$ 实，$\omega=0$。$C_1=C_2$。

这里 $n\ge3$ 第二次起作用。$n=2$ 时 $\phi=0$ 直接给 $\omega$ 无信息（$\phi$ 定义里就有 $n-2$）。$n=2$ 情形 conformal Laplacian 的 Yamabe 项消失，$e^{2\omega}$ 因子在二维 $\Delta$ 下不再是标量共轭，零阶恒等式对消失败。这一维阈值与 §14 finite type 的 $n\ge3$ 恰好同源，但用在一个完全不同的地方。

$C_1=C_2$ 等价于 $d_{A_1}(F_1F_2^{-1}u)=F_1F_2^{-1}d_{A_2}u$。Harmonic frames 未必幺正，$J_{\mathrm{loc}}=F_1F_2^{-1}$ 幺正：沿任何路径 parallel transport intertwining identity 从已知侧起，$A_1,A_2$ 的 transport 都幺正，$J_{\mathrm{loc}}$ 起点等于旧幺正 identification；沿路径保持幺正；$\Omega$ 连通给处处幺正（`07-global.tex:87-93`）。

任意 $f\in C_c^\infty(U_0;\C^2)$：$w_{1,f}$ 与 $J_{\mathrm{loc}}w_{2,f}$ 在共同 coordinate domain 里都是第一侧齐次 connection 方程的解。Charts 避开 $\overline{U_0}$。差在已知侧消失，唯一延拓在 $\Omega$ 上为零。所有 evaluation identities 成立，不止有限族（`07-global.tex:95-101`）。

Overlap 上：$J_{\mathrm{loc}}$ 与旧 match 若在同一 $p$ 提出两个不同第一侧像 point 与可逆 fiber maps，$N_1^\circ$ 上两点 evaluation maps 之间就被强加可逆线性关系。Lemma `bdy:evaluations` 联合满射排除这种关系；fiber maps 由第二侧点满射决定。因此局部 identification 在每个 overlap 与旧 match 一致。

## §18 全球缝合：把 frontier 消掉，再补 boundary

Proposition `glob:interior`（`07-global.tex:120-124`）：极大 match 定义于 $N_2^\circ$，base map 是 onto isometry $\Phi:N_2^\circ\to N_1^\circ$。

若 domain 有 interior frontier，Prop `bdy:contact` 给局部数据、§7 的 dilation 给 §8-§14 所需的构造条件。Prop `mat:local` 在原始 chart 里 contact point 邻域给 conformally 相等的 metric 与相等的归一化 harmonic-frame equations。Lemma `glob:conformal` 移除 conformal factor。Coordinate identity 与 $J_{\mathrm{loc}}$ 把旧 match 延到包含 frontier 的邻域；`glob:conformal` 结尾的一致性保证每个 overlap 上 match 一致。与极大性矛盾。Domain 非空、开、在连通 interior 中相对 frontier 不存在，故等于全部 $N_2^\circ$。

Image 是开的（local isometry）。相对 closed：$\Phi(p_k)\to q\in N_1^\circ$，紧性给子列 $p_k\to p\in N_2$、$J(p_k)\to J_0\in U(2)$。$p\in\partial N_2$ 时 evaluations 的连续性与 `bdy:matching` 给 $I_1(q)=J_0I_2(p)=0$，与 Lemma `bdy:evaluations` 矛盾。$p$ 于 interior，continuity 给 $\Phi(p)=q$。$N_1^\circ$ 连通给 image 全部。Injectivity 已由 Lemma `bdy:matches` 证；逆 smooth 因 bijective local diffeomorphism（`07-global.tex:142-153`）。

Proposition `glob:boundary`（`07-global.tex:157-165`）：内域 $(\Phi,J)$ 光滑延到 extended manifolds，$\Phi:N_2\to N_1$ 微分同胚、$J$ 幺正 bundle map 交换两个 connections；两侧原 $M$ copy 被 preserve；$\Phi|_\Gamma=\mathrm{Id}$、$J|_\Gamma=I$。

Onto interior isometry 两个方向 preserve curve lengths，因此 preserve intrinsic distance。紧光滑带边 Riemannian 流形的 interior 的 metric completion 就是该流形配 length metric；curve 触 boundary 时可推入 inward collar 让 length 变化任意小；fixed local metric comparisons 让 completion 与原紧拓扑一致。$\Phi$ 与逆延拓为相互逆 homeomorphisms $N_2\to N_1$、boundary 映 boundary。

光滑：thin uniform collar 里 $s_j$ 是到 $\partial N_j$ 的距离、光滑，gradient 生成 inward unit normal flow。Isometry 保 boundary 距，$s_1\circ\Phi=s_2$；interior 中交换这两个 gradient field。fixed small level $s_2=s_0>0$ 上 map 已 smooth。$0\le s\le s_0$ 上用 level map 加两侧 normal flow 表达，得 smooth extension 到 $s=0$；逆同。$A_1,A_2$ 沿 normal curves 的 parallel transport 同样把 $J$ 光滑延拓，保幺正与 connection intertwining（`07-global.tex:179-190`）。

Map 在开 cap $E$ 上 identity，closure 由连续性。$M_j^\circ=N_j^\circ\setminus\overline E$（closure 取在 $N_j$ 内）；bijectivity 与 $\overline E$ 上的 identity preserve 这些补，也 preserve 它们的 closure，即 $M$ 的原 copies。限制后的 diffeomorphism 固定 attachment patch $P=\{b>0\}$，$J=I$ 于 $P$。

$\Gamma$ 可能有多个 component；要 recover 每个部分上的 boundary identity。$f\in C_c^\infty(\Gamma;\C^2)$；$u_j$ 现在是原 manifold 上 boundary value $f$ 的 harmonic solutions。第二侧上 $\widetilde u_1=J^{-1}(u_1\circ\Phi)$。Metric 与 connection identity 使 $\widetilde u_1$ 第二-harmonic。$P$ 上 boundary value 与 $u_2$ 同；covariant normal derivative 也同。等价的 density 关系来自测得形式对 support 在 $P$ 的任意 function 相等（`07-global.tex:213-216`）：$(\nabla_{\nu_1}^{A_1}u_1)dS_{g_1}=(\nabla_{\nu_2}^{A_2}u_2)dS_{g_2}$。density 由 Lemma `bdy:jets` 相同，isometry 输 outward normal，bundle map 于 $P$ 为 $I$。故 $\widetilde u_1-u_2$ 于 $P$ 上 zero Cauchy data。Boundary 与 interior unique continuation 给 $\widetilde u_1=u_2$ 全 $M$。

Boundary trace 给 $J(p)f(p)=f(\Phi(p))$ 于 $p\in\partial M$、$f\in C_c^\infty(\Gamma;\C^2)$（`07-global.tex:225-228`）。$p\in\Gamma$、$\Phi(p)\ne p$ 时选 $f$ 非零于 $p$、support 在避开 $\Phi(p)$ 的小 nbhd。上式与 $J(p)$ 可逆矛盾。故 $\Phi(p)=p$ 于 $\Gamma$。$f(p)$ 任意向量值得 $J(p)=I$ 于 $\Gamma$。

Main theorem 的最终拼装（`07-global.tex:236-272`）。§3 里的 boundary-identity gauges $V_j$ 把 connections 送进 normal gauge。Lemma `bdy:jets` 与 Prop `bdy:cap` 给共同 exterior Green 数据。Lemma `bdy:evaluations`、`bdy:matches` 定义极大 match；Prop `bdy:contact` 提供 frontier 处的局部数据。Prop `mat:local` 加 Lemma `glob:conformal` 消掉 frontier。Props `glob:interior` 与 `glob:boundary` 给光滑 global metric 与 connection identification，把整个 measured patch 钉住。

原始 trivializations 里 $A_j=V_j^{-1}A_j^{\mathrm{orig}}V_j+V_j^{-1}dV_j$。Bundle map 从第二 fiber 到第一 fiber 是 $U=(V_1\circ\Phi)JV_2^{-1}$（`07-global.tex:257`）。光滑幺正，等于 $I$ 于 $\Gamma$：$V_j$ 在整个原 boundary 上取 $I$。Intertwining identity $d_{\Phi^*A_1^{\mathrm{orig}}}(Uu)=Ud_{A_2^{\mathrm{orig}}}u$ 展开给 $A_2^{\mathrm{orig}}=U^{-1}(\Phi^*A_1^{\mathrm{orig}})U+U^{-1}dU$、$g_2=\Phi^*g_1$。整段论证只用 density 与单一非空 cap；不要求 $M$ 或 $\Gamma$ 可定向、也不要求 $\partial M$ 或 $\Gamma$ 连通。

## §19 回到最初设想的差异：一份诚实的复盘

写完 §18 之后回看 §1 我给自己下的两个初始猜想，两者都需要修正。

猜想一："矩阵情形只是把 scalar 情形里所有算子换成矩阵，把 $C^2$ 值列当作 vector 分量。" 这条基本对。整篇里"从 boundary jets 到最后 global assembly"的架构、"外贴 cap 用变分能量比较"、"source evaluations 分离点与 fiber"、"product continuation 从 cross"、"球面 transfer + angular coercivity"、"一次 dilation 打完所有 $\delta$"、"消 conformal factor + interior filling + boundary completion"这些骨架的确与 scalar companion 逐节对应。姊妹文的 Sections 3-5 被明确 reuse（`01-introduction.tex:104-105`）。

猜想二："矩阵一阶项是低阶装饰，可以在 angular coercivity 那一步吸收掉。" 这条完全错，且我最初几周就是被这条误导。真相：angular coercivity 只 bound $\psi$；bound $\psi$ 只把 $D$ 送到 $O(r)$；bootstrap 里 $D$ 与 $R_\nu$ 的 weighted moment 分别给 $\|D/r\|_{L^2}$、$\|R_\nu/r^2\|_{L^2}$ 一致界；插值到 pointwise 只到 $O(r^{1/2})$。这个 $\sqrt r$ 的 gap 必须靠 $D$ 自己满足的 PDE 才能补上。$D$ 满足的 PDE 恰好是 conformal Killing 型。有限型在 $n\ge3$ 才管用。整篇里唯一"矩阵专属"的步骤就是这里；其余都是 scalar 情形的直接改写。

`01-introduction.tex:110-123` 那段作者自己写的 contribution 陈述，用词与我上面复盘出来的路径完全一致："Their components complementary to the real scalar matrices satisfy a first-order system whose principal symbol is the conformal Killing symbol. In dimension at least three this symbol is of finite type: two prolongations determine all third derivatives from lower jets. The real scalar part of the displacement is fixed by the coordinate normalization."

还有一个更细的差异，与"frame 里零阶消失"这个直觉有关。Scalar 情形的 harmonic coordinates 让 $\Gamma^k_{il}(0)=0$；matrix 情形的 harmonic frame 让 $\mathcal L_j$ 的零阶为 $0$。两者都靠"frame 列本身是解"这一结构。差别在于：scalar 情形 coordinate 是标量函数，$\Gamma$ 消失后 $\nabla$ 的一阶也自然对齐；matrix 情形 frame 是 matrix-valued，$\nabla$ 与 frame 的交换里还带出 $B_j^i$，这些一阶 matrix coefficients 与 $A$ 的切向部分相关，不消失。因此 matrix 情形的"低阶"里含 $\Psi^0$ matrix terms，与 scalar 情形的"低阶"含量级不同。这一点在 §11 比较恒等式里最清楚：$P-P_0$ 有 $L_{q^i}D_{i,0}+L_{b_2^i}K_i$ 两项，$q^i=b_2^i-b_{i,0}I$ 就是"两个一阶 matrix coefficient 之差在 frame 里的形态"。

## §20 未验证的直觉与后续要做的事

以下几条我目前只有直觉、还没有可以写下来的证明思路。把它们标 `[推测]` 并说明信息不足。

第一，rank 提升。整套机制里 $\mathcal V_0=\{Z:\mathrm{Re}\,\mathrm{tr}Z=0\}$ 是 rank 2 特有的八维空间；$q$ 投影把 $dI$ 部分踢出去靠的是 $\frac12\mathrm{Re}\,\mathrm{tr}$。`[推测]` rank $r\ge3$ 时应当取 $q(Z)=Z-\frac1r\mathrm{Re}\,\mathrm{tr}(Z)I$、$\mathcal V_0=\{Z:\mathrm{Re}\,\mathrm{tr}Z=0\}$ 变为 $(3r^2-1)$-维实空间。剩下的 PDE 主部仍是 CK，有限型不变。信息不足处：$d$ 用 $W$ 表达的那条零阶关系在 rank $\ge3$ 下是否仍成立（`mat:scalar-direction` 依赖 trace 的 $\C^2$ 特殊结构）。

第二，Yang--Mills 假设能否减弱 $n\ge3$。$A$ 若额外满足 YM 方程，$\mathcal B^{ij}$ 与 $\mathcal Y^k$ 之间可能有代数关系；$D$ 的 PDE 主部可能降阶。$[推测]$。信息不足：本文没写 YM 分支，Ceki\'c 2020 YM 定理 (`01-introduction.tex:86-88`) 用的是不同机制（同 patch 上固定 smooth metric 情形），我不能把它的证明结构直接搬过来验证 reduction 是否真的能让 $n=2$ 走通。

第三，non-trivial bundle。整篇把 $M\times\C^2$ 的平凡化写进 $A\in C^\infty(M;T^*M\otimes\mathfrak u(2))$；$\Phi^*A_1$ 与 $U^{-1}dU$ 之间的公式在一般 Hermitian 丛上没有全局 trivialization 就写不出。$[推测]$ 至少 $\Gamma$ 上的 collar 需要 bundle 平凡化才让 normal gauge ODE 有意义。信息不足：本文没有讨论一般丛上的对应版本。

第四，$\Gamma$ 与 boundary 拓扑。论文强调"不要求 $\partial M$ 或 $\Gamma$ 连通"（`01-introduction.tex:61`、`07-global.tex:269-272`）。整段论证只用一个非空 cap $E$、一次 density-based 变分。$[推测]$ cap 的构造在 $\Gamma$ 有多个 component 时依然只在其中一个 component 上做，其余 component 的信息靠 boundary tests 在 §18 里回来。若 $\Gamma$ 稠密但 disconnected 会怎样？信息不足：本文 $\Gamma$ 是"relatively open proper subset"，稠密情形没讨论。

第五，正则性下界。定理陈述要求 smooth metric 与 smooth connection。$[推测]$ 有限型与 prolongation 的常数依赖 $a$ 至少 $C^2$、$W$ 至多 $C^3$，因此 $C^{2,\alpha}$ 应当够用。信息不足：整篇没有做 low-regularity 版本，无法从文本判断实际阈值。

## §21 文献定位：这条线在何处

Calder\'on 反导电问题 `01-introduction.tex:64-65`；Sylvester--Uhlmann 1987 global uniqueness `01-introduction.tex:66-68`。各向异性 formulation 下 unknown 是 metric 或 positive conductivity tensor density，boundary-fixing diffeomorphism 是 unavoidable invariance。Lee--Uhlmann 1989 边界确定与 real-analytic 情形在几何与拓扑假设下的唯一性 `01-introduction.tex:70-73`。Lassas--Uhlmann 2001 从 local boundary 信息恢复 real-analytic manifolds `01-introduction.tex:74-75`。Lassas--Liimatainen--Salo 的 Poisson embedding 用 harmonic solutions 的值表达几何；本文沿用同一大原则，只是把 scalar harmonic 换成 connection Laplacian 的 source solutions 提供 point 与 fiber identification `01-introduction.tex:76-79`。

联络方面：Albin--Guillarmou--Tzou--Uhlmann 2013 从 fixed surface 上的 full Cauchy data 恢复 Hermitian connections 与 matrix potentials `01-introduction.tex:81-83`。Ceki\'c 2017 在某些已知 conformally transversally anisotropic geometry 上线丛恢复 `01-introduction.tex:84-86`。Ceki\'c 2020 从同 patch 测量在任意 fixed smooth metric 上恢复 smooth unitary Yang--Mills connections of arbitrary rank `01-introduction.tex:87-88`。Ceki\'c 2025 复的 parallel transport 方法在 conformal to subdomains of $\R^2\times M_0$ 的固定几何上从 full boundary data 恢复 arbitrary rank connections 与 matrix potentials `01-introduction.tex:89-92`。Gabdurakhmanov--Kokarev 2025 real-analytic 类别里从 boundary patch 联合恢复 metric、Euclidean bundle 与 compatible connection；他们用 Green kernels 识别 base 与 fiber 是本文最近几何前身 `01-introduction.tex:93-96`。

Theorem 1.1 与上述文献的差别：unknown 是光滑 metric 与 arbitrary 光滑幺正联络，固定平凡 rank-2 丛上；不要求联络满足 YM 方程 `01-introduction.tex:97-99`。

姊妹文 `ScalarCompanion2026` 提供 product continuation、sphere geometry、scalar angular estimate（Sections 3-5），本文 analytic 部分需要自己给（含向 scalar-principal-part systems 的推广）。Scalar 唯一性定理本身没被 apply 到矩阵值 boundary data `01-introduction.tex:101-108`。

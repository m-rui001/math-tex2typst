## 一、开局：我为什么认定对偶是入口

### 1.1 最初的判断

Barnette 猜想（1969，经 Grünbaum 的 Waterloo 文集记录）说：每个三次二部多面体图（polyhedral = 平面 + 3-顶点连通）是 Hamilton 的。我面对的已知谱系是：Goodey (1975) 做了面全是四边形/六边形的情形，Feder–Subi (2006) 做了面三染色中的一类，Kardoš (2020) 做了 Barnette–Goodey 版（面长 ≤ 6、不要求二部），Schnieders (2025) 推到面长 ≤ 8。所有人都在"面长"上做文章，没有人去掉面长限制。

我的第一个判断来自一个几乎所有做过这个问题的人都试过的方向：三次图上 Hamilton 圈的补是完美匹配，所以"存在 Hamilton 圈"= "存在一个补是 Hamilton 圈的完美匹配"，这在三次图上等价于"存在一个完美匹配，其补连通"。这个重述本身不解决问题，但它把问题从"找圈"变成"找一个性质特别好的匹配"，而匹配问题的对偶对象是**面的选边**：在每个面上选一条边，使得每条边恰被一个面选中，这正好是对偶图上的完美匹配语言。

再往下走一步：二部性在对偶面上表现为**面二染色**。三次二部平面图的对偶是每个顶点度 3 的三角剖分，且面对半染黑（原图顶点）白（原图面）。这时"每面恰选一条边"的黑面部分变成：**每个黑三角选自己的一个顶点**。如果要求每个非根顶点恰被一个黑三角选中，这就是一个双射 $r:A\to X$，$r(t)\in V(t)$，$A$ 是黑面去掉外面、$X$ 是非根顶点。

我停下来算了一遍账（这就是论文里的 eq:counts）：

$$\#\{\text{white faces}\}=k,\qquad |E(T)|=3k,\qquad |V(T)|=k+2.$$

推导：设黑面共 $k$ 个（含选为外面的 $t_0$）。每条边恰属一个黑面、每个黑面 3 条边，故 $|E|=3k$。Euler 公式 $|V|-|E|+|F|=2$，而 $|F|=2k$（黑白各 $k$），所以 $|V|=3k-2k+2=k+2$。黑面去掉外面剩 $k-1$ 个，非根顶点 $k+2-3=k-1$ 个，**一样多**。

这个 $k-1$ 对 $k-1$ 让我停了很久。面和顶点之间存在一个潜在的双射（state），而且这不是巧合：它是 Euler 公式在三次/三角形这对偶数下的直接输出，和 Temperley 对应（匹配 ⟺ 平面树）是同一类计数恒等式。我当时并不知道这个方向能不能走通，但"双射存在"至少说明这个对象不是空的，值得押注。

[推测] 我后来想，Tutte 的 trinity 理论（现代处理见 Hine–Kálmán）里 state 早就有了，但 Tutte state 在文献里的用法是"从 state 读出树"（Temperley 双分对应：state ⟺ 树）。我一开始也以为该走这条路：先证明 state 存在，再用 Temperley 把它变成树，两个树拼成划分。**这条路后来被证明是走不通的，失败原因在第五节**，简单说：单个 state 给出的对边图 $Q_r$ 既不保证无圈、也不保证连通，Temperley 对应需要的那类"好 state"没有独立的构造途径。我最后靠的是**一对** state 的配对结构，并非单个 state 的 Temperley 性质。

### 1.2 目标定理的等价形式（我真正要证的）

设 $T$ 是球面三角剖分（连通、简单、至少 4 顶点、每面边界是 3-圈），面被黑白染色使每条边两侧异色。核心划分定理（Theorem 2.2）：

> 对任意面三角 $t_0$ 和它的任一条边 $e_0$，顶点集可以分成两类，每类**导出**一棵树，且 $e_0$ 的两个端点在同一类、$t_0$ 的第三个顶点在另一类。

最后那个"处方"（prescription）不是装饰。它有两个用途：其一，Theorem 2.2 的处方形式直接给出 edge-avoidance 推论（指定某条边被 Hamilton 圈避开，把处方加在那条边关联的面上即可），这是 Barnette 猜想的已知等价全局加强（Kelmans，经 Hertel 与 Gorsky–Steiner–Wiederrecht 解释），等于顺手把一个更强的定理证掉了；其二，第 7 节沿分离三角形归纳时，两半必须在共享三角形上匹配彼此的划分，没有处方根本拼不起来。

"每类导出一棵树"里的**导出**二字我要特别强调：导出树包含类内每一条边，所以光证明"两个类各自连通"是不够的，如果类内有一条额外边，那它要么在树里（树含圈，矛盾）要么不在（非导出）。论文第 99–101 行专门写了这句话。这个细节在 Lean 里以最彻底的方式消失了（见第七节），但读论文的人在这里松懈就会在粘合步骤出错。

### 1.3 从 Hamilton 圈到树划分的完整翻译链

把 Theorem 1.1（原图语言）翻译到 Theorem 2.2（对偶语言）需要四步，每步都有内容：

1. **$G$ 无 1-或 2-边割**。反证：若割 $\delta(S)\le 2$，两侧各至少 3 个顶点（单点在三次图中至少 3 条跨边；两点至少 4 条，都是简单性给的），那么删掉跨边的端点（至多 2 个）就把图断了，违反 3-顶点连通。这一步是三次图上"顶点连通度 ⟹ 边连通度 ≥ 3"的内嵌证明。
2. **对偶 $T=G^*$ 简单**。对偶环 = Jordan 曲线只穿 1 条原边 = 1-边割；对偶重边对 = 穿 2 条 = 2-边割。都被第 1 步排除。
3. **$T$ 是三角剖分**：三次 ⟹ 对偶每面游程长 3，简单性把"游程"变成真三角形。Euler 给 $|V(T)|=2+|V(G)|/2\ge 4$。
4. **$G$ 的二部性给 $T$ 的面二染色**：$G$ 的顶点二染色拉到对偶面上，每条边两端异色 ⟹ 两个对偶面异色。

最后的收尾是把 Theorem 2.2 的划分翻回 Hamilton 圈：每个三角形恰有一条类内边（一个三角形的三顶点若全在一类，导出树含三角形，矛盾），把这些类内边在对偶里取"未选边"，每面恰两条未选边 ⟹ 补对偶 2-正则；连通性由补树引理给出；连通 2-正则 = 单圈；圈的顶点是 $G$ 的面 = ……等等，这里我要小心：圈在对偶里，其边集对应 $G$ 中的边集 $E(T)\setminus P$，每个 $G$ 顶点恰关联两条圈边，且该边集在 $G$ 中连通，这就是 $G$ 的 Hamilton 圈。

[推测] 现在回头看，第 4 步的染色翻译和"类内边 = 匹配边"的对应，其实已经在暗示最终的 Lean 形态（"匹配 + 连通补"），但当时的我满脑子都是"两个树"，没有停下来问一句：**划分定理的结论（两个导出树）和 Hamilton 圈之间的翻译，是否绕了不必要的远路？** 答案是绕了，Lean 证明了这点。


## 二、state 与 pair：我把赌注押在一对双射上

### 2.1 定义与第一反应

对象定义（论文原文）：

```latex
A \emph{state} is a bijection \(r:A\longrightarrow X\) with
\(r(t)\in V(t)\), where \(V(t)\) is the vertex set of the
triangle \(t\).
```

```latex
A \emph{pair} is an ordered pair of states
\((r,s)\) such that \(r(t)\ne s(t)\) for every \(t\in A\).
```

state 就是给每个非外黑三角指定它的一个顶点、每个非根顶点恰被指定一次；pair 是两个 state 在每个三角形处**选择不同**。等价说法：关联二部图（左 $A$、右 $X$）的两条边不相交完美匹配。

我的第一反应是：pair 太自然了，自然到可疑。两个完美匹配的并是偶圈之并（在关联二部图上），所以 pair 的结构 = "二部图上 2-因子的存在性"。于是 pair 的存在性问题**在形式上**就是：关联二部图有没有度 2 支撑子图。这是个经典可解问题（Hall 条件 + 最大流），所以 pair 的存在不会是瓶颈，瓶颈一定在后面"要森林不要圈"那一步。这个判断被证实了：Proposition 3.1（pair 存在）是全文最"标准"的一节，而 Prop 5.2（森林态存在）才是引擎。

### 2.2 Prop 3.1：pair 的存在，逐步推导

**化归**。pair = 关联二部图 $B$（左 $A$、右 $X$，边 = 面–顶点关联）的两条不相交完美匹配。$B$ 的一个度 2 支撑子图每个分量是偶圈（二部 ⟹ 无奇圈），圈上沿二部性交替染色拆成两个完美匹配，两个匹配在每个顶点取不同的边（度 2 每点恰两条边，交替分配后每匹配每点恰一条、且互异），所以两个态自动构成 pair。于是只需证 $B$ 有度 2 支撑子图。

**Hall 型条件**。度 2 支撑子图存在的充要条件（对一切 $S\subseteq X$）：

$$\sum_{t\in A}\min\bigl(2,|V(t)\cap S|\bigr)\ge 2|S|. \tag{eq:flow}$$

验证方式是最大流：源 → $X$ 容量 2，$X\to A$ 关联边容量 1，$A$ → 汇容量 2。对把 $S\subseteq X$ 放源侧的割，把与 $S$ 关联的 $A$ 尽量放源侧可省容量，最小割容量为 $2(|X|-|S|)+\sum_t\min(2,|V(t)\cap S|)$；要它等于 $2|X|$（饱和），当且仅当 eq:flow。整数最大流给流值 $2|X|=2|A|$，每点饱和：$X$ 侧每点流出 2、$A$ 侧每点流入 2。Ford–Fulkerson 的整数性保证流出的是度 2 支撑子图。

**几何化**。eq:flow 里的 $\min$ 很难直接用，我把 $S$ 换成它的补 $U=V(T)\setminus S$（注意 $U$ 含三根，因为 $S\subseteq X$）。逐三角形算短缺：黑三角在 $U$ 中有 $j$ 个顶点时，$2-\min(2,|V(t)\cap S|)=2-\min(2,3-j)=\max(0,j-1)$，即 $j=0,1$ 时 0、$j=2$ 时 1、$j=3$ 时 2。关键换算（论文原文）：

```latex
If a black triangle has \(j\) vertices in \(U\), its shortfall
from two is \(\max(0,j-1)\). This is its number of edges in
\(T[U]\), minus one if \(j=3\).
```

而 $T[U]$ 的每条边恰有一个黑面（每边一黑一白），把所有黑三角的"边数减一"加起来：边数总和 $=e(U)$，$j=3$ 的黑面各减 1 共减 $b(U)$（顶点全在 $U$ 的实际黑面数，$t_0$ 计入）。代数上是：

$$\sum_{t\in A}\max(0,j_t-1)\le 2|A|-2|S|+2 \iff e(U)-b(U)\le 2|U|-4,$$

其中左边加 $t_0$ 的短缺 2（$t_0$ 全顶点在 $U$、$|V(t_0)\cap S|=0$、$\min=0$、短缺 2，恰好对上"3 条边减 1 个黑面 = 2"），右边 $2(k-1)-2(k+2-|U|)+2=2|U|-4$。这就是密度不等式：

$$e(U)-b(U)\le 2|U|-4. \tag{eq:density}$$

**密度不等式的证明**（这是"无分离三角形"假设唯一登场的地方）。取 $T[U]$ 的连通分量 $K$（$p\ge 4$ 顶点、$m$ 边、$f$ 面，继承球面嵌入）：

1. $K$ 的三角面 ⟺ $T$ 的实际面。微妙方向：$K$ 的一个面由 3-圈围成；**3-圈不分离**（无分离三角形假设！），所以圈的一侧是 $T$ 的实际面；$K$ 在圈另一侧还有顶点（$p\ge4$），所以 $K$ 的这个面只能在实际面那侧开。反方向平凡。
2. 非三角区域 $d\ge 4$，设区域内原始黑白面数 $b',w'$。符号边计数：每个原始面边界长 3，黑 +1 白 −1 数边，内部边两侧一黑一白相消，只剩区域边界的 $d$ 条：

$$3(b'-w')=\sum_{j=1}^{d}\sigma_j,\qquad \sigma_j\in\{-1,1\}.$$

   于是 $|3(b'-w')|\le d$ 且 $3\mid(b'-w')$。分情形：$d=4$ 时 $3(b'-w')\in\{-3,0,3\}$ 与 4 项和的奇偶 $\{-4,-2,0,2,4\}$ 交集只有 0；$d=5$ 时 $|\cdot|\le 5$ 取 $\pm3$，$|b'-w'|\le1=d-4$；$d\ge6$ 时 $d/3\le d-4$。合并得 $|b'-w'|\le d-4$。
3. 区域划分全部原始面，三角区域内黑白面数相等，所以全图色差 $w-b=\sum(b'-w')\le\sum(d-4)$。
4. 面长恒等式 $2m=3(b+w)+\sum_{\text{非三角}}d$；用 $3=4-1$ 改写三角贡献，代入 $w-b\le\sum(d-4)$ 得 $2m\ge 4f-2b$。
5. Euler $p-m+f=2$ 代入：$2m\ge4(2-p+m)-2b\Rightarrow m-b\le 2p-4$。

拼装：含根分量若三顶点就是 $t_0$ 本身（$m=3,b=1$，$m-b=2=2\cdot3-4$ ✓）；其余分量 $p\ge4$ 用上面的界、$p\le3$ 由简单性排除（$p=2$ 需重边；$p=3$ 的分量是 3-圈分量，无分离三角形假设下只能是实际面 $t_0$）。对分量求和得 eq:density。

**假设的机械理由**。无分离三角形只用在第 1 步"3-圈不分离"，若有分离三角形，$K$ 的某个"三角面"两侧都有顶点，$b(U)$ 被低估，eq:density 破。容量 $(2,1,2)$ 的每个数字：2 是"两个态各用每顶点一次"；1 是"两态不相交"；外层 2 允许两态复用关联。$2|U|-4$ 里的 4 是 $2\times3$（三根）减 2（$t_0$ 记账）合并 Euler 常数后的净值。

[推测] 失败路线。我最早想直接对 $U$ 用平面图的标准密度界 $e(U)\le3|U|-6$，但 $3|U|-6$ 与 $b(U)$ 的关系对不上，$b(U)$ 可以高达 $2|U|-4$（四面体的情形），标准密度界在"含根的导出子图"上不够细。第二条 [推测]：我考虑过只对"无 3-圈的分量"用密度界、对含 3-圈的分量单独处理，但分离 3-圈恰恰是要靠第 7 节归纳消去的对象，在这里分类会把结构搅乱；最后选择把整个 eq:density 一次性在"无分离三角形"类里证完，分离的留到归纳。


## 三、Disk identity：我找到的第一把尺子

### 3.1 问题在哪

有了 pair 之后，真正的问题来了：pair 有很多，我需要的是 $Q_s$ **无圈**的那一个（$Q_s$ 的定义：在每个黑三角 $t$ 里取 $s(t)$ 的**对边**，不与 $s(t)$ 关联的那条边；这些边互异，因为每条边恰属一个黑面）。对边的集合构成 $T$ 的支撑子图 $Q_s$。

为什么是对边？因为 state 的双射性会给对边图一个干净的定向：$Q_s$ 的边自然定向为 $r(t)\to u(t)$（$u(t)$ 是三角形里第三点，非 $r(t)$ 非 $s(t)$），这样每个非根顶点出度恰 1、根出度 0，后面 6.1 节的"每分量恰一根"完全靠这个出度计数。若用 $s(t)$ 定向，头尾都对不上双射。

于是核心存在性问题：**若至少有一个 pair，则必有某个 pair $(r,s)$ 使 $Q_s$ 是森林。**

这一步我卡了很久。直接的组合手段看起来都没有着力点：$Q_s$ 的圈与否取决于 $s$ 在所有三角形上的整体选择，局部改动对 $Q_s$ 的影响是链式的。我最后用的办法是把问题整体转译成解析对象，这是整篇论文的引擎，值得一步步写清楚。

### 3.2 定向圈结构

给定 pair $(r,s)$，在每个 $t$ 里定向边 $r(t)\to s(t)$。因为 $r,s$ 都是双射：每个 $v\in X$ 恰是一条定向边的头（$s(t)=v$ 的 $t$ 唯一）、恰是一条的尾（$r(t)=v$ 的 $t$ 唯一）。所以这批定向边在顶点集 $X$ 上构成**点不相交的有向圈之并**（每点一进一出）。边作为无向边也互不相同（每边属唯一黑面）。把这个无向边集叫 $D$。

每个有向圈的 δ-和（δ 的定义：对相邻 $v,w$，$\delta(v,w)=+1$ 若边 $vw$ 的黑面在行进方向左侧、否则 $-1$；反称）可以逐圈算，这正是 disk identity 的内容。

### 3.3 Lemma 4.1（disk identity），完整推导

**陈述**：设 $r$ 是 state，在每个 $t\in A$ 选一条从 $r(t)$ 出发的边。每个简单有向圈避开根，其 δ-和逆时针为 $-3$、顺时针为 $+3$。

**推导**（四步，一步不跳）：

1. 选边都从 $r(t)$（非根）出发，根不发出选边 ⟹ 有向圈不含根。
2. 设圈长 $h$、严格内部顶点数 $I$、圆盘内黑白面数 $B,W$、边界边中黑面在圆盘内的条数 $l$。两条纯几何计数：

$$B+W=2I+h-2,\qquad 3(B-W)=2l-h. \tag{eq:disk-counts}$$

   第一条是圆盘三角剖分的 Euler 公式（把圆盘补上外围面看球面，$V=I+h$，标准推导）。第二条是符号边计数：内部边两侧一黑一白相消，只剩边界边，黑面在盘内的 $l$ 条各 $+1$、其余 $h-l$ 条各 $-1$，和为 $2l-h$，而左边 $3(B-W)$ 是"黑面边数减白面边数"（每面 3 条边）。
3. **state 的额外计数**（eq:matching-disk）：$B=I+l$。这是 state 独有的：每个严格内部顶点被 $r$ 匹配到盘内一个黑面（顶点严格内部 ⟹ 其关联面全在盘内）；盘内每个黑面恰匹配一个顶点，匹配到边界顶点的盘内黑面恰对应计入 $l$ 的边界边（黑面在盘内、关联边界顶点 ⟹ 它有一条边界边在圈上且黑面在盘内）。无重复：$r$ 是双射且每个黑面至多贡献一条选边。论文原话警告：

```latex
The matching condition in \eqref{eq:matching-disk} is essential.
The conclusion need not hold for arbitrary oriented cycles
of the triangulation.
```

4. 三式联立。由第 2 条与 Euler 式：$B-W=2B-(B+W)=2(I+l)-(2I+h-2)=2l-h+2$（用 $B=I+l$）。代入 $3(B-W)=2l-h$：

$$3(2l-h+2)=2l-h\ \Longrightarrow\ 6l-3h+6=2l-h\ \Longrightarrow\ 4l-2h+6=0\ \Longrightarrow\ 2l-h=-3.$$

逆时针行进时圆盘在左，黑面在盘内的边 $\delta=+1$、盘外的 $-1$，δ-和 $=l-(h-l)=2l-h=-3$ ✓；顺时针差个符号得 $+3$。

**±3 从哪来**：不是凑的，是方程 $3(2l-h+2)=2l-h$ 的解。系数 3 是三角形面长。做个思想实验：若面是四边形，同样的推导给 $4(2l-h+2)=2l-h\Rightarrow 2l-h=-\tfrac83$，非整数，**这种 state–圈结构在四角剖分里根本不存在**。±3 是三角剖分特有的指纹，这个指纹后面要吃重负。

[推测] 一条真实的弯路：eq:matching-disk 的边界顶点记账我起初证反了方向，试图证"每个边界顶点被匹配到盘内黑面"，但边界顶点的匹配对象 $r^{-1}(v)$ 完全可能在盘外。正确的读法是**黑面 → 顶点**方向：盘内黑面 $f$，若 $r(f)$ 是边界顶点，则 $f$ 在盘内且关联该顶点 ⟹ $f$ 与圈相交于一条计入 $l$ 的边界边。边界顶点关联两条盘内黑面的情形（圈在 $v$ 两侧的黑面都在盘内）需要小心：$l$ 计 2 但顶点只贡献 1，此时两个黑面各自还要匹配到别处，双射的另一侧把账拉平。论文这里只用了三行，Lean 的 StateDisk.lean（483 行，是最大的文件之一）把每一步都摊开了，我核对后确认论文的计数是对的、但确实跳了一个 case 的辨析。

### 3.4 这把尺子此刻还量不出什么

disk identity 说的是：**凡是 state 的选边构成的有向圈，δ-和必是 ±3**。它还不排除圈，它只是给了圈一个不变的"指纹"。要逼出无圈的态，我还需要两件东西：一个让带圈项**相消**的机制，和一个让整体**非零**的锚点。这是下一节。


## 四、引擎：一个复指数和的两种分组

### 4.1 装置的搭建

我定义（对实数权重 $a(t,v)$，先任意、后特选；$\omega(s)=\sum_t a(t,s(t))$）：

$$J(r,s)=\frac13\sum_{t\in A}\delta(r(t),s(t))\ \in\mathbb Z,\qquad
Z(x)=\sum_{(r,s)\text{ pair}} i^{J(r,s)}\exp\bigl(x\omega(s)\bigr). \tag{eq:J, eq:Z}$$

$J$ 是整数，因为 $D$ 的每个有向圈是 state 选边的简单有向圈，disk identity 给 δ-和 $=\pm3$，除以 3 每圈贡献 $\pm1$。

**为什么是 $i$ ，并非 $\pm1$，这是本节最重要的机械决定**，我先把它讲清楚。后面引理 5.1 的对合会把某个 pair 的 $J$ 改变 $\pm2$（见 4.2），消去需要"相位变号"。算一下：$i^{J+2}=-i^J$ ✓，但 $(-1)^{J+2}=(-1)^J$ ✗，**用 $\pm1$ 做权重，对合前后相位不变，永远消不掉**。$J$ 的改变量恒为偶数 2，这个偶性来自"改动三角形数 × 每处 δ 差 2"的结构，所以单圈的贡献必须落在 $i$ 的奇数次幂上才能被翻号。选 $i$ 是**使消去成立的最小选择**，不是审美偏好。

[推测] 我试过的另一条路：让权重直接依赖 $r$（比如 $\exp(x\omega(r,s))$ 双边加权），这样 exp 因子在对合下也变，看似可以配合 $\pm1$。但双边加权会破坏"固定 $s$ 分组"的整齐性，对合固定 $s$ 只动 $r$，exp 因子必须只依赖 $s$ 才能原封不动地提出来配对相消。两阶段设计（消去用任意权重、非零用特选权重）是被对合的形状逼出来的。

### 4.2 Lemma 5.1（固定 $s$ 分组消去）

**陈述**：对固定的 $s$，若 $Q_s$ 带圈，则 $Z$ 中第二态为 $s$ 的那些项之和为零。

**推导**（六步）：

1. 若 $s$ 没有 partner，没有项，无事可做。
2. **只用 $s$** 选 $Q_s$ 的一个简单无向圈 $C$。选择不依赖 $r$，这点性命攸关：对合要作用在每个 partner 上是**同一个**映射，否则配对不成对合。
3. 对 partner $r$，记 $u(t)=t$ 中非 $r(t)$、非 $s(t)$ 的第三顶点，把对边定向 $r(t)\to u(t)$。每个非根顶点出度 $\le1$（$r$ 双射 ⟹ $v$ 是 $r(t)$ 的 $t$ 唯一）。$C$ 必须被这些对边**定向遍历**：在 $C$ 的每个顶点 $v$，两条 $C$-边分属两个黑面 $t_1,t_2$，对边的尾是 $r(t_1),r(t_2)$；若两条边尾都是 $v$，则 $r(t_1)=r(t_2)=v$ 违反双射。所以每点恰一条 $C$-边的尾在此点，$C$ 上对边首尾相接成有向圈；尾都是 $X$ 元素，圈上无根。
4. **对合**：在提供 $C$ 的黑面 $t$ 上把 $r(t)$ 换成 $u(t)$、其余不动，得 $\tilde r$。改动沿圈轮换顶点 ⟹ 双射保持；$u(t)\ne s(t)$ 恒成立 ⟹ 仍是 partner。再作用一次还原（无不动点：改动处 $r(t)\ne u(t)$，因为 $u(t)$ 是"第三"顶点）。
5. **相位变号**：在改动三角形上 $\delta(u(t),s(t))-\delta(r(t),s(t))=2\delta(r(t),u(t))$（δ 反称与三角形三方向的内部关系直接给出）。对定向对边圈用 disk identity：δ-和 $=\pm3$，故 $J(\tilde r,s)-J(r,s)=\tfrac13\cdot2\cdot(\pm3)=\pm2$。
6. 于是 $i^{J(\tilde r,s)}=-i^{J(r,s)}$；$\exp(x\omega(s))$ 因 $s$ 固定而不变。对合把 $s$-项两两配对、逐对相消，总和为零。∎

注意这个引理对**任意**权重 $a$ 成立，消去机制完全不碰权重。这是"先任意后特选"两阶段设计的前半段。

### 4.3 Lemma 5.3（spoke 权重）与非零性

**spoke 权重**。对每个有界黑三角形放一个中心、连三根 spoke 到顶点，得图 $H_0$（允许孤立点）。引理 5.3：存在实数 $a(t,v)$ 使每个逆时针简单 spoke 圈的权重严格为正（中心到顶点权重 $a(t,v)$、反向取负）。

构造（论文用对偶路径显式做，避开同调语言）：每个连通分量单独处理；每个有界面 $F$ 规定其左边界环流为 $+1$（无界面规定为 $-$（有界面数））；对每个有界面在对偶中取到无界面的一条简单路径，路径每跨一条对偶边给反对称权重（离开 $+1$、进入 $-1$），中间面贡献相消，只有起点净 $+1$；对所有有界面求和，每条边的权重被有限个路径贡献叠加，最终每个面边界的环流等于规定值。于是任何逆时针简单 spoke 圈的权重 = 圈内部所含的面环流之和 $>0$。[批注] 这本质上是"平面图上的 circulation = 位势的 coboundary"：存在性由圆盘拓扑的 $H_1=0$ 保证，论文选择显式构造而不引用同调，这个选择在 Lean 里被走到了极致（Lean 用**一个显式位势的梯度**替代了整个 spoke 几何，见第七节）。

**非零性**。按 $D$（pair 的定向边的无向并）分组：固定 $D$，组内元素 = 各圈的独立定向选择（尾给 $r(t)$、头给 $s(t)$；圈上每点一进一出，故头映射 $s$、尾映射 $r$ 都是 $X$ 上的双射 ✓）。两个关键事实：

- **每黑三角至多一条 $D$-边**（每边属唯一黑面、每三角恰一条 pair 边）。这保证下面的 spoke 绕行互不纠缠：不同圈的 detour 内部不交、中心互异。
- 对 $D$ 的圈 $C$，令 $L_+(C)$、$L_-(C)$ 为逆/顺时针定向时 $\sum_t a(t,\text{head})$。**断言（eq:positive-difference）：$L_+(C)-L_-(C)>0$。** 论证：逆时针遍历 $C$，把每条边 $v\to w$ 换成两-spoke 绕行 $v\to$（中心）$\to w$，绕行权重 $=a(t,w)-a(t,v)$；闭 spoke 曲线总权重 $=L_+(C)-L_-(C)$；这条曲线简单且逆时针（论文用"逐边滑过子盘是过简单曲线的等距同伦"一整段来支撑），引理 5.3 给正性。

组的贡献（每个圈的 $J$ 贡献 $\mp1$：逆时针 $-1$、顺时针 $+1$）：

$$\prod_{C\subset D}\left(-i\,e^{xL_+(C)}+i\,e^{xL_-(C)}\right). \tag{eq:group-product}$$

每个因子在 $x=0$ 有**恰一阶零点**：常数项 $-i+i=0$，一阶导 $-iL_++iL_-=i(L_--L_+)\ne0$。设组内圈数 $c(D)$，首非零 Taylor 系数在 $c(D)$ 次、为

$$(-i)^{c(D)}\prod_{C\subset D}\bigl(L_+(C)-L_-(C)\bigr). \tag{eq:leading-coefficient}$$

（推导：$-ie^{xL_+}+ie^{xL_-}=i(e^{xL_-}-e^{xL_+})$，每因子最低阶 $(L_--L_+)x$，乘起来 $i^{c}\prod(L_--L_+)$，与上式差符号约定但同值。）

**汇合**。至少有一组（pair 非空）。取圈数最小的组 $c_{\min}$：这些组的 $c_{\min}$ 次系数相位同为 $(-i)^{c_{\min}}$、幅度为正数之积 $\ne0$；圈数更多的组在 $c_{\min}$ 次没有贡献。所以 $Z$ 的 $c_{\min}$ 阶 Taylor 系数非零。但引理 5.1 已把所有 $Q_s$ 带圈的项逐组消成零，若**所有** pair 的 $Q_s$ 都带圈，则 $Z\equiv0$，一切系数为零，矛盾。故存在 $Q_s$ 为森林的 pair。∎

[推测] 失败路线。第一，$L_+=L_-$ 的可能：绕行曲线的简单性靠"每三角至多一条 $D$-边"，但两个 detour 在共享**顶点**处相触不交叉的严格化（局部绕数）论文没给全；我 [推测] 这一步有干净的替代证法，不需要简单性，只需绕数：spoke 闭曲线绕过的内部面数 $>0$，绕数论证对自交免疫。Lean 完全绕开了这段拓扑（用流配对），侧面证实了可修性，但也意味着论文这一节没有独立验证。第二，$(-i)^{c_{\min}}$ 不是实正会不会有问题？不会，非零性只需要"同相位、非零幅度"，不需要实正；$(-i)^{c_{\min}}\times$正实数永远非零。第三，对合会不会碰到 $D$-圈？改动只动 $r$ 不动 $s$，$Q_s$ 不变；且 $Q_s$-边与 $D$-边是同一黑面里的**不同**边（对边 vs 关联边），不冲突。

### 4.4 我对这个装置的诚实评价

这套"指数和 + 两种分组 + 最低次系数"的机器，谱系上是 BKR 式/李–杨式"用复相位逼出实结构"的手法在图论里的直接应用；论文自己声明 Temperley 对应（与 KPW 加权扩张）和 double-dimer 的按圈重排（Kenyon）只是**背景类比不是逻辑输入**，我重造了这两个轮子。它是一次性成本很高的重锤：为了证明"存在一个无圈的态"，我引入了 $J$、$Z$、spoke 权重、Taylor 系数四层装置。如果有人问我有没有初等的替代，[推测] 我怀疑没有：排除"所有 $Q_s$ 带圈"是一个全局否定命题，局部交换论证（对合）只能给出带权平均为零，必须再有一个"平均非零"的锚点；而锚点需要权重有非平凡的符号结构（$L_+>L_-$），这种方向性权重在纯组合语言里没有天然的宿主。Lean 把 $e^{xL}$ 换成 $\mathbb C[X]$ 多项式（`stateWeight = ∏(1+w·X)` 型），消掉了分析外衣，但装置的骨架一层没少。


## 五、从森林态到两个树（以及 Lean 告诉我这一段是可删的）

### 5.1 引理 6.1：每个分量恰一根

$Q_s$ 是森林时，把边定向为 $r(t)\to u(t)$（注意是**第三顶点** $u(t)$，不是 $s(t)$）。每个非根顶点出度恰 1、根出度 0。取一个连通分量：$q$ 个点、$a$ 个根，总出度 $=q-a$；森林每分量边数 $q-1$、每边恰一个尾 ⟹ 总出度 $=q-1$；所以 $a=1$。孤立点（$q=1$）自动含于"每分量恰一根"。[批注] 这里森林性是必需的：若 $Q_s$ 有圈，圈上点出度也是 1 但边数 $>$ 点数 $-1$，方程 $q-a=q-1$ 失效，引理 6.1 正是上一节"要森林"的全部回报所在。

### 5.2 白面树与选边集 $P$

现在做 Temperley 型的转换：

1. $H$ = **全部**黑中心（含 $t_0$）的 spoke 图。$H$ 连通：$T$ 的每条边可经其黑中心绕行（$v\to$ 中心 $\to w$）。$H$ 的面 ⟺ 白三角。
2. 删去 spoke $(t,s(t))$（$t\in A$；这正是 $Q_s$ 每条边对应的 spoke）。剩下的图：$Q_s$ 的边被中心细分 + $t_0$ 中心连三根。由引理 6.1，每分量恰一根，加上 $t_0$ 中心这个枢纽，整体连通且边数合适，是 $H$ 的支撑树（细分不改变树性）。
3. **引理 2.1（补对偶引理）**：连通球面嵌入图中，支撑森林的补边之对偶构成对偶的连通支撑子图。证明：把森林延拓成树，收缩树，收缩保持面（树内边两侧同面）、删掉的恰是对偶边，剩图连通；数边 $|E|-|V|+1=|F|-1=|V(M^*)|-1$（Euler），连通 + 边数 = 点数 $-1$ ⟹ 树。森林版：延拓成树后补对偶是树，包含原森林补对偶为子图 ⟹ 连通。这个引理不需要 3-连通性，对偶有环有重边都不碍事。
4. 于是删掉的 spoke 的对偶在白三角上构成**支撑树**（白面树）。以 $y_0$（$e_0$ 跨过去的白三角）为根，每条白面树的边指派给离 $y_0$ 较远的端点，每个白三角除 $y_0$ 恰被指派一次。
5. **选边规则**：spoke $(t,s(t))$ 邻接两个白三角；取被指派的那个，选中 $t$ 中邻接该白三角且关联 $s(t)$ 的那条边；最后加选 $e_0$。每黑面恰选一条（来自 $(t,s(t))$）、每白面恰选一条（指派唯一）、不同黑面的选择互异 ⟹ $|P|=k$。
6. $P_0=P\setminus\{e_0\}$，每条边从 $s(t)$ 方向定向。

### 5.3 引理 6.2：$P$ 无圈，两把尺子夹死

$P_0$ 中的无向简单圈必是有向圈（每非根顶点出度 $\le1$、根出度 0，同引理 6.1 的计数）。对这个圈用 disk 数据 $B,W,h,l$（现在 state 是 $s$）。**新的计数**（eq:selection-count）：

$$B-W=2l-h.$$

推导：盘内每个面恰有一条选中边（选边规则的直接推论，每黑面选它的 $(t,s(t))$ 边、每白面被指派一条）。黑 +1 白 −1 数选中边：两端都在盘内的选中边贡献一次 $+1$ 一次 $-1$，相消（包括两端在边界上的弦，弦两侧面都在盘内）；边界边全是圈边即选中边，黑面在盘内的 $l$ 条 $+1$、其余 $h-l$ 条 $-1$，合计 $2l-h$。而盘内面的贡献恰是 $B-W$。

但三角剖分的**符号边计数**（与 state 无关，引理 4.1 的第一条）给 $3(B-W)=2l-h$。联立：

$$2l-h=0.$$

可是这个圈若是 state 选边的有向圈，disk identity 说 δ-和 $=\pm3\ne0$，而逆时针 δ-和 $=2l-h$。矛盾。$P_0$ 无圈；再由出度计数每分量恰一根（$P_0$ 是森林）；$e_0$ 连接两个根（$e_0$ 两端点是根、根互异 ⟹ 不同分量），加 $e_0$ 保无圈。$P$ 是森林。

[批注] 这个证明是我全文最得意的一步，结构上是"同形不同源"：eq:selection-count 来自"每面恰选一边"（组合规则），eq:disk-counts 第二式来自"面长 3"（几何），两式同形迫使 $2l-h=0$，而 state 匹配恒等式说有向圈必 $2l-h=\pm3$。两把独立的尺子量同一个圈，读数必须相等又不允许相等。

### 5.4 Jordan 收尾：导出性是免费的

1. $E(T)\setminus P$ 的对偶边构成对偶的支撑子图：连通（引理 2.1 的**森林版**，这里终于用上）、2-正则（每面 3 边、选中 1、未选 2 ⟹ 对偶每顶点度 2）。顶点数 $2k>2$ ⟹ 是**单个**简单圈。
2. 把对偶圈画成与每条对应原边横穿一次、避开原顶点的 Jordan 曲线；曲线分球面为两侧，给 $T$ 的每个顶点标号。
3. 边两端同标号 ⟺ 边 $\in P$（未选边跨曲线 ⟹ 两端异侧；选中边不跨 ⟹ 同侧）。两侧标号都出现。
4. $P$ 的分量数 $=(k+2)-k=2$；每分量标号常数（分量内的边同侧 ⟹ 同标号）⟹ 每标号恰一分量；两类各**导出**一棵树，导出性来自"同标号边全在 $P$ 中"：类内任何一条边的两端同标号 ⟹ 它在 $P$ 里 ⟹ 在该类分量的树里。**这正是我在 1.2 节强调的"导出"二字的来路**：Jordan 论证免费给出导出，这是选 Jordan 方案，并非直接构造树的原因。
5. $t_0$ 处唯一同标号边是 $e_0$ ⟹ 处方满足（$y_0$ 是白面树根 ⟹ $e_0$ 被选 ⟹ $e_0$ 不跨曲线 ⟹ 两端同类；另两条边异标号）。

### 5.5 镜子：Lean 里这一整层不存在

Lean 的 Gluing.lean 里主引擎 `matching_strong` 的结论是：

```lean
∃ P : Finset E, e ∈ P ∧ (∀ v, ((N.star v).filter (· ∈ P)).card = 1) ∧
  (N.restrict (Pᶜ)).graph.Connected
```

**没有树、没有划分、没有 Jordan 曲线。** Lean 直接证"完美匹配 $P$（每点恰一条关联边）+ 补图连通"，处方 $e\in P$ 作为归纳不变量内置。第三节的"白面树"在 Lean 里是 `QNet`/`addSink`/`augQ` 加 sink 的抽象森林加 `Duality.complement_connected`（补无圈 ⟹ 补连通，纯线性代数）；Jordan 曲线是割 $N.cut\ A$ 和它的"一岸" $A$。

我写论文时把"两个导出树"当作定理的表述核心（Theorem 2.2），Lean 证明它是**叙事选择，并非逻辑必需**。这个认识对反推很关键：划分定理的价值在于它是一个漂亮的中间陈述（它给出 edge-avoidance、给出与 APSW/Stein 谱系的连接），但证明的主干可以直接从"森林态"跳到"匹配 + 连通补"，我在 5.2–5.4 节搭的三层脚手架（白面树 → 选边 → Jordan 标号）在逻辑上是可压缩的。保留它的理由是可读性：选边规则、$2l-h=0$ 的两把尺子、导出性的免费来源，这些只有在树语言里才看得见。


## 六、分离三角形：归纳与粘合

### 6.1 问题与切分

Theorem 2.2 的完整证明对顶点数归纳。无分离三角形时用上面构造；有分离 3-圈 $C$（两侧都有严格顶点的 3-圈）时：沿 $C$ 切成两片，每片用 $C$ 上的一个三角形**加盖**（cap）成球面三角剖分。两片都简单（$C$ 在简单三角剖分中无弦，$C$ 的顶点对之间已有 $C$ 自身边，simple 排除重边）、至少 4 顶点、比 $T$ 小。

### 6.2 cap 上的染色：整除性戏法

设一侧的原始黑白面数 $B,W$。符号边计数使 $3(B-W)=$ 三条边界边的符号之和（每条 $\pm1$）。左边被 3 整除，右边 $\in\{-3,3\}$ ⟹ 三个符号**全等** ⟹ 该侧所有边界边的黑面同侧。cap 三角形按相反颜色放置，染色延拓。这个整除性戏法与第二节 $d=4$ 情形（$3(b'-w')\in\{-3,0,3\}$ 与 4 项和交集只有 0）是同款：**被 3 整除 + 小范围 ⟹ 符号锁死**。

### 6.3 粘合

1. 先对含处方面 $t_0$ 的片用归纳（带 $e_0$）。
2. 该片 cap 上两个标号都出现（否则 cap 单色三角形成导出树中的圈，注意这里**必须**用导出性，只有连通性会漏）。
3. cap 的三条边中同标号的那条 prescribe 给另一片，用归纳。
4. 重命名标号使两片在共享三角形一致。
5. 同标号的两棵导出树交于一点或一条边带端点（共享三角形内），并集是树，且在 $T$ 中导出（$T$ 中无横跨两片内部的边，分离 3-圈的定义保证，嵌入上任何这样的边都得穿过 $C$）。∎

[推测] 顺序依赖：prescription 只固定"同标号边是哪条"，不固定哪个标号叫黑，所以重命名自由；但必须先解 $t_0$ 片才知道 cap 的标号模式，再 prescribe 另一片，论文的顺序（"Apply induction first to the piece containing $t_0$..."）就是这个依赖，若倒过来会出现两片的处方冲突。

Lean 侧的对应是 `cap_duality`（把 3-边割 $A$ 收缩成附加点 `none` 的加盖网络，`Duality.minor` 推前对偶）+ `cap_glue_matching`（逐点 star 计数 $=1$ 的边集并）+ `cap_glue_connected`（连通性：2-正则连通图去一点仍连通 + 割边桥接两半）。论文的"树沿点或边粘合"在 Lean 里是 `cap_glue_agrees`：两半的匹配在割边上**恰选同一条**（`cap_matching_boundary`：割边中恰一条 $c\in P$，用它 prescribe 另一半）。两边各自独立通过了验证，这是形式化给论文的交叉背书，虽然 Lean 全程用边割语言、从未提"分离三角形"（分离 3-圈 ⟺ 对偶的非平凡 3-边割，这层翻译因为对偶在 Lean 里不是图而根本不需要显式出现）。

## 七、终局：主定理的完整链条与最初设想的差异

### 7.1 完整链条（无分离三角形情形，一步不省）

Hamilton 圈 ⟸ 补对偶连通 2-正则 ⟸ 选边集 $P$ 每面恰选一边且 $P$ 无圈、$|P|=k$ ⟸ $P_0$ 的边来自森林态 $Q_s$（对边规则 + 白面树指派）⟸ 存在 $Q_s$ 无圈的 pair（Prop 5.2）⟸ $Z$ 的两种分组（引理 5.1 消去 + disk identity 相位 + spoke 权重正性 + $c_{\min}$ 非零）⟸ pair 至少存在（Prop 3.1：eq:flow ⟸ eq:density ⟸ 无分离三角形的密度分析）。

分离三角形沿切分–cap 染色–处方粘合消去。Theorem 1.1 由第 1.3 节的四步翻译接回原图语言。

### 7.2 与最初设想的差异（这一篇笔记最重要的一节）

1. **我最初以为 Temperley 对应是入口，最后它只是出口的装饰。** 单个 state 对边图的树性没有独立构造途径（[推测] 失败路线：先证 state 存在、再挑"好"的 state，挑选没有任何局部判据，对边图的圈与否是全局性质）；真正可用的是**一对** state 的配对结构 + 复相位消去。
2. **我以为"两个导出树"是逻辑核心，Lean 证明它可删。** 从森林态直接跳"匹配 + 连通补"，树划分、Jordan 标号、导出性全部被线性代数（补无圈 ⟹ 补连通）吸收。树语言保留的唯一理由是可读性。
3. **我以为对偶是免费的，Lean 花了 1700 行买它。** 且买法（格点走廊、避开 Jordan 曲线定理）比论文的用法严格，论文 5.4 节"画一条 Jordan 曲线"在 Lean 里根本不合法，必须换成一岸/割的代数语言。这暴露了论文里唯一真正用平面拓扑的两处（spoke detour 同伦、Jordan 画法）都有纯代数替代。
4. **$i$ ，并非 $\pm1$** 这个小决定，在最初的设计里我根本没想到会有问题，直到写出对合的相位差 $J\mapsto J\pm2$ 才发现 $\pm1$ 权重失效。机械教训：设计加权消去时，先算对合在相位群上的作用轨道，再选权重所在的表示。
5. **算法死路是主动选择的**：论证是纯存在性（有限加权和 + 反证），论文明确声明不给多项式构造。[推测] whiteCharge 权重其实给出了一个候选算法骨架（找 pair → 森林态 → 直接构造匹配），但我没有沿这个方向走，把它留给后续。

### 7.3 常数备忘（每项都有出处）

$3$（面长；disk identity 的解 $2l-h=-3$ 来自 $3(2l-h+2)=2l-h$，四边形的 $-\tfrac83$ 无整数解）；$i^{\pm1}=\pm i$（圈贡献 $J=\pm1$，对合翻 $\pm2$；$\pm1$ 权重不翻号）；$2$（外围容量、δ-变号）；$1/3,2/3$（弧三分点，任何 $0<a<b<1/2$ 的对称选择）；$\delta=\varepsilon/2$（格距，Lean 独有）；$k,k-1,k+2$（Euler + 每边一黑一白）；$2|U|-4$（密度界）；$d-4$（非三角区域缺陷：$d=4$⟹0、$d=5$⟹≤1、$d\ge6$⟹$d/3\le d-4$）；$6\le|V|$（Lean 的非空性）；$|P|=k$（每面恰选一边）。

### 7.4 可信度审查

论文侧最紧的两处：5.3 节 detour 同伦（"相触不交叉"的局部绕数未严格化）与 eq:matching-disk 边界顶点记账（跳了一个 case 的辨析），两者都有 Lean 侧独立路线背书（流配对、严格双射计数），我核对后认为结论正确但叙述可补。Lean 侧：主定理无缺口、permitted axioms 仅三标准；Pfaffian 推论（经 GSW2023 Theorem 4.16 推广到非平面 Pfaffian 三次 3-连通二部图的 $P_4$-Hamiltonicity）是纯文献引用、未形式化；formalization.yaml 缺登记。归纳结构两边形状不同（Lean 的处方边在第二半是 cap 边界匹配边，对应论文的"同标号边处方"），一致性靠读者自己对，这实际上给了论文第 7 节一次交叉验证。


旧稿第 0 节的骨架里我押的是"球面对偶 $\to$ 树划分 $\to$ 配对态 $\to$ 白面树 $\to$ 粘合"这条链，写下来才看清：链上每一环真正消费的只有常数与计数，树语言只是载体。这一点用下面第八节的正式记法复述更清楚：第 3 环的输出是 $\exists (r,s)\ \text{pair},\ Q_s\ \text{is a forest}$（`paper.tex:413-416`），第 4 环的输入只是 $Q_s$ 的出度分布与引理 6.1 的 $a=1$（`paper.tex:603-614`），中间"两个导出树"这四个字不承担任何推导义务。这是我复核自己的稿子时最不满意的一处冗余。

## 十、三条确实走不通的路线与两处转折

### 10.1 把归纳放在原图一侧

我最开始想把分离结构处理在 $G$ 上：若 $G$ 有 3-边割 $\delta(F)$，沿它切开得到两块，每块带三个度为 2 的接点，再补一个三角形把接点闭合。写到闭合那一步就停了，原因有两条。其一是三次性保不住：给三个接点补边时，要么让某个接点度数升到 4，要么补出的三角形在二部图里不存在（三次二部图没有三角形）。其二是 Hamilton 圈在块内的进入模式无法固定：块内需要一条覆盖全部顶点、端点在两个接点的路径，剩一个接点单独与外部配对，而"哪两个接点配对"要等另一半的圈形状才知道，块内没有任何不变量替我选定它。

同一件事在对偶侧几乎免费：加盖就是把 $T$ 的一个面换成一个三角形面，"每面是三角形"自动保持，处方再规定这个新三角形里的同标号边，另一半据此配对（`paper.tex:725-740`）。Lean 把这条路推到更远：`CappedDuality.lean:148-152` 的加盖假设写成 $(N.\mathrm{cut}\ A).\mathrm{card}=3$ 且两岸非空，整个文件里"三角形"只作为对偶侧 $D$ 的面出现（`D.Triangle` 在 `StateDisk.lean:444` 的假设里），原图侧从未有分离三角形的概念。这印证了一条方法论判断：切分应该做在"补边即顶点"的那一侧，因为加盖在那一侧只是删掉一个顶点。

### 10.2 势函数加局部交换拆圈

第二条死路是把圈数当势。定义 $\mu(s)=\#\{\text{cycles of }Q_s\}$，我想证：若 $\mu(s)\ge1$，则存在与之相距一条对边的态 $s'$ 使 $\mu(s')=\mu(s)-1$。这个命题在我能想到的所有例子上都不成立，原因是替换是链式的：把 $s(t_0)$ 换成 $t_0$ 的另一个顶点，$Q_s$ 里对应那条边整条搬走，新边可能把一棵树接成圈、也可能把一个圈切成两个圈，$\mu$ 的增减与局部改动没有确定符号。更要命的是没有任何不变量可以拦住上升：disk identity 对任意 state 都给出每圈 $\delta$-和 $\pm3$（`paper.tex:362-368`），所以新出现的圈和原有圈在符号层面完全不可区分，$\mu$ 的两次配置在权重上同层。

正式稿最后没有把 $\mu$ 当势函数，只把它当分组指标 $c(D)$（`paper.tex:574-580`），并且用它做的是"取最小者的首系数同相位"论证：$c_{\min}=\min\{c(D):\ D\ \text{来自某 pair}\}$，则 $Z$ 在 $c_{\min}$ 次的首系数是 $\sum_{c(D)=c_{\min}}(-\ii)^{c_{\min}}\prod_{C\subset D}(L_+(C)-L_-(C))$，每一项幅度为正、相位相同，和必非零。这跟我原先设想的"下降法"是相反的方向：下降法要构造序列，同相位论证只要存在一个非零系数。Lean 里对应的形态也是存在式的（`Forest.lean:235` 的结论是 $\exists P$ 使 $\text{oppositeGraph}$ 无圈），没有任何迭代结构。

### 10.3 让权重自带几何符号

第三条死路是给 $a(t,v)$ 取几何量，试过的形式有 $a(t,v)=\pi-\angle v$ 与 $a(t,v)=\deg(v)$ 两种。要求是：对每个 $D$-圈 $C$，两个定向的头权重差满足 $L_+(C)-L_-(C)>0$（`paper.tex:535-541`），且这个差要在全图上一致为号。角度权重的问题在于它跟着嵌入走，同一对偶圈在另一个球面嵌入下 $L_+-L_-$ 可以反号；度数权重更差，$a$ 只依赖顶点时 $L_+-L_-=0$，因为两个定向经过同一批头点。也就是说：正性必须来自"面与顶点之间的关联方向"，纯顶点函数做不到。

我在 Lean 里看到的解法证实这一层复杂度可以整体省掉：`Circulation.lean:183-185` 用 $\text{whiteCharge}(v)=(1-\mathbf{1}_{black}(v))-\mathbf{1}_{v=root}\cdot\#\{\lnot black\}$ 定义一个显式位势，`Circulation.lean:208-212` 把它对割梯度的配对算成 $c\cdot((A.\text{filter}\ \lnot black).\mathrm{card})$，正性由割恒等式 $(N.\mathrm{cut}\ A).\mathrm{card}=2(N.\mathrm{blackCut}\ black\ A).\mathrm{card}+3$（`StateDisk.lean:436`）的奇性直接给出，`ColoredDual.lean:183-184` 再把 $\delta=-3\wedge slope>0$ 与 $\delta=3\wedge slope<0$ 二择钉死。spoke、绕行、同伦三件东西在形式化里一件都不需要，这是我在写论文时没预料到的简化空间。

### 10.4 转折一：定向要求一对态

从"一个态"到"一对态"的改动，动机我旧稿 1.1 节写成了"赌注押在配对结构上"，现在补上机械理由：$Q_s$ 的边要给成有向的才能用出度计数，而对边 $e(t)$ 的两个端点里，$s(t)$ 是被避开的顶点，另一端要指定，就必然引入第二个态 $r$（`paper.tex:428-433` 与 `paper.tex:601-602`）。旧稿里我引的 `paper.tex:120-122` 那句提到 Hine--Kálmán 与 Kauffman 时钟定理，紧接着 `paper.tex:235-237` 明确写了下面不需要顶点三染色也不需要时钟定理，这个声明正是转折的结果：我一度以为要把时钟定理当输入，实际需要的只是双射给出的出度分布。

### 10.5 转折二：消去与不消去分两段用权重

`paper.tex:417-421` 写明消去对任意权重成立，`paper.tex:521` 才把权重固定下来。这个顺序一旦倒过来就全断：若先固定权重再消去，读者会问"带圈 $Q_s$ 的项在特选权重下是否仍两两配对"，而对合 $\tilde r$ 的构造完全不需要知道 $a$ 是什么，先固定反而遮住这一层自由。我把这个设计记成一条通用教训：一个加权和若同时承担"消去"与"非零"两种功能，就让消去在最大函数空间上做，非零再挑一个点，两段的假设强度不对称。

### 10.6 最终形态与我最初设想的差

最初我想证的对象是 $G$ 里的圈 $H$，中间我打算构造它；最终证的是它的补的对偶。写成式子，交付链条是

$$\text{pair exists}\ \Longrightarrow\ \exists(r,s)\ \bigl(Q_s\ \text{is a forest}\bigr)\ \Longrightarrow\ \exists P\ \bigl(\lvert P\rvert=k\wedge P\ \text{is a forest}\bigr)\ \Longrightarrow\ E(T)\setminus P\ \text{的对偶为连通 2-正则}\ \Longrightarrow\ H\ \text{存在},$$

其中 $H$ 只在最后一步作为 $G$ 的边集出现一次（`paper.tex:784-791`）。我最初设想的构造路径是给 $G$ 逐段接圈（先大圈再吸收剩余顶点），那种路线的失败点在 3-顶点连通性给出的割结构上：吸收步骤要求每次扩展不产生新割，而三次二部图上任何一条被避开的边都可能属于某个 3-边割。最终形态把"扩展"换成"取补"，把"不产生割"换成"无圈"，后者的判据是两把尺子读数冲突（`paper.tex:673-690`），这才让归纳与消去都用得上。

## 0 立项：把"因子二"读成密度口径问题

### 0.1 我手上已有的事实与我的初始猜想

已有的公开地板是 H{\aa}stad 的 $7/6$ 与 Dinur-Safra 的 $10\sqrt5-21$，天花板是极大匹配给出的因子 $2$。原文把自己的位置说得非常直白：

```
history.tex:50: hardness for every fixed factor below \(\sqrt2\). The resulting
history.tex:51: independent-set gap has completeness density close to
history.tex:52: \(1-1/\sqrt2\) and arbitrarily small soundness density. The gap
history.tex:53: in \Cref{thm:gap} instead has completeness density approaching
history.tex:54: \(1/2\), which is what gives the factor-two threshold.
```

我读到这里的第一反应是一个可检验的猜想：整个难题的信息量全压在"独立集密度"这四个字上。原文开头就把这个换算写死了：

```
introduction.tex:4: A vertex cover of a graph is a set of vertices meeting every edge.
introduction.tex:5: Its complement is an independent set, a set containing no two adjacent
introduction.tex:6: vertices. This elementary duality lets us express the hardness gap
introduction.tex:7: in terms of the densities of independent sets.
```

于是我把目标重写成一个纯密度命题：造一个图，可满足时有密度约 $1/2$ 的独立集，不可满足时所有独立集密度趋零。完备密度 $1/2$ 与 soundness 密度 $0$ 之比是无穷，而顶点覆盖阈值之比只要 $2$，所以我判定这里有一倍的余量可以烧。$1-1/\sqrt2$ 那条线之所以只能给 $\sqrt2$，原因也在这同一个换算里：那边独立集密度是 $1/\sqrt2$ 量级、cover 密度 $1-1/\sqrt2$，比值恰是 $\sqrt2$。这个观察决定了我后面所有的取舍，它比任何技术细节都更早落地。

`[推测]` 我最初的猜想其实还多带了一个错误的乐观成分：我以为完备密度 $1/2$ 是靠"随机半边"这种平凡对称性能免费拿到的，因此剩下的工作只是把 soundness 做小。后来在 `analysis.tex` 与 `restriction.tex` 里我才发现，$1/2$ 这端要花掉一整个反集中度引理（`graph.tex:242-312`），而 soundness 那端真正贵的是"列表只能看自己"这条信息约束，两者开销都比我预估的大。

### 0.2 我打算怎么读这篇论文的结构

`main.tex:70-78` 给的输入顺序是 introduction, source, graph, analysis, restriction, lists, decoding, conclusion。按字节看，作者把最大的三片留给了 `lists.tex`、`restriction.tex`、`graph.tex`，这个分布本身就是思维链的化石：真正的新东西在"限制 + 列表"这两片里，图构造虽然大，用的是可计算的几何；而 `decoding.tex` 只有 7,645 字节，说明解码端几乎是免费的。`[推测]` 我猜这个字节分布反映写作者的用力方向：最难自证清白的部分是"列表的 locality 与兼容性同时成立"，所以那两片写得最细。

### 1.2 我把中间步骤补齐（b）

### 1.3 常数与假设的机械理由（c）

$m\ge4$ 这个门槛在我看像随手取的小值，其实它同时喂三处。第一处是 `analysis.tex:18-19` 那句 "$n\geq p>1/b_0$"，其中 $b_0=1/(2m)$，$p=2d+1$；第二处是 `graph.tex:309` 的 $3a=\frac3{4m}<\frac1m$；第三处是 `src:dimension-bounds` 即 `source.tex:48` 的 $\sqrt d>4m$。三处都是 $m$ 的一次方关系，$m=1,2,3$ 会让某个不等式变松，而 $m\ge4$ 让 $a\le1/16$ 这种"小量"的口径统一。

`unweighted` 与 `simple` 是被表示法强制的：`graph.tex:137-141` 的边判别只写了一个阈值不等式，没有权重位；`graph.tex:142` 明说 "This defines a finite simple undirected unweighted graph."

若把 $m$ 换成随输入增长的量，`source.tex:73-75` 那句 "every parameter introduced here is constant with respect to the source input size" 立刻失效：$n=M^{\binom d2}p^{rd}$（`graph.tex:144`）里的 $d$ 是 $m$ 的十次方多项式，$M=O(L)$，所以 $n=O(L^{\binom d2})$（`graph.tex:199-200`）。$m$ 一动，$d$ 一动，指 $\binom d2$ 就动，多项式次数就不再是常数。这就是 `introduction.tex:43-44` 那句"每个固定 $m$ 各自多项式"的全部含义。

### 1.4 候选失败路线（d）

`[推测]` 路线一：让 $m$ 依赖图规模，比如模仿 Karakostas 的 $2-\Theta(1/\sqrt{\log n})$（`history.tex:8-9`）反过来做硬度。这条路会在 `graph.tex:199-207` 的确定性枚举处断：顶点对数是 $n^2$，每条边的判别代价含 $(1+r)^{2d}$（`graph.tex:161`），$d$ 一旦随 $n$ 增长就不是多项式时间。
`[推测]` 路线二：把阈值改成带权图或多重图，期望用更少的顶点换来同样的 gap。这条会在 `decoding.tex:71-83` 的解码处断：解码器要给每个源变量一个符号，靠的是"顶点对 $S_v+S_w$"的坐标求和结构，一旦带权，兼容选择器上的求和不再是标签的加法。
`[推测]` 路线三：直接用 UGC 版本的 Khot-Regev 长码路线（`history.tex:34-37`）。它拿得到 $2-\epsilon$，但输入假设不同；原文 `history.tex:36-37` 承认那边"uses a biased long code and an equivalent, stronger formulation of the source promise that supports short lists of candidate labels"，也就是说短列表在他们的口径里是假设送的，在我的口径里得自己造。

## 2 源问题口径：完美完全、任意小固定值、字母表可以长

### 2.1 原文逐字（a）

```
source.tex:4: Write \([k]=\{1,\ldots,k\}\). A \emph{Label Cover instance}
source.tex:5: \(\Phi\) consists of two disjoint finite variable sets \(U,V\),
source.tex:6: two nonempty finite alphabets \(\Sigma_U,\Sigma_V\), and an explicit
source.tex:7: nonempty list of \(M\) constraint occurrences. Occurrence \(c\in[M]\)
source.tex:8: has endpoints \(x_c\in U\), \(y_c\in V\), and a total map
source.tex:9: \(\pi_c:\Sigma_U\to\Sigma_V\).
```

定理口径：

```
source.tex:21: \begin{theorem}[Perfect-completeness Label Cover hardness]
source.tex:22: \label{src:hardness}
source.tex:23: For every fixed rational \(\sigma\in(0,1)\), there are nonempty
source.tex:24: constant alphabets and a deterministic polynomial-time reduction
source.tex:25: from \(\mathrm{3SAT}\) to instances of the form above such that
source.tex:26: satisfiable formulas give \(\val(\Phi)=1\), and unsatisfiable
source.tex:27: formulas give \(\val(\Phi)\leq\sigma\).
```

三句我认为是全文口径最要紧的自白：

```
source.tex:18: We require no regularity or expansion
source.tex:19: condition on the constraint graph.
source.tex:37: There the constraints are even \(D\)-to-one for a suitable constant
source.tex:38: \(D\), a property we do not use. The constants, including the
source.tex:39: alphabets and \(D\), may depend on \(\sigma\). This theorem is the
source.tex:40: only external hardness input to our proof.
```

### 2.2 中间步骤（b）

把"值 $=1$ 与值 $\le\sigma$"分开看，我需要的只有两件事：一是每个约束都是投影（$\pi_c$ 是全函数，左标号唯一决定右标号），二是完全性端严格等于 $1$。并行重复保完全性是标准的：$k$ 重重复后左字母表大小变成 $|\Sigma_U|^k$，一个全局标号在重复实例上的满意度是各坐标标号的与，完美标号仍完美；soundness 端由 Raz 定理压到 $\sigma$。`[推测]` 作者把这套写成引用 `source.tex:30-32`，是因为他们的贡献在这层之下，写细了反而模糊焦点。

局部标号的上界是 $q^{|P(i)|}\le r$：一个查询最多含 $d-1$ 个不同变量（`graph.tex:29` 的 "thus $|P(i)|\leq d-1$"），每个变量 $q$ 个符号，所以 $r=q^{d-1}$（`source.tex:70`）是字母表上界。`slot_i:\Lambda_i\to[r]` 是把合法标号按字典序编号（`graph.tex:36-41`），这一步纯粹是为了把"标签"变成"坐标下标"，好让后面的权重向量有地方放。

### 2.3 机械理由（c）

完美完全性 $\val(\Phi)=1$ 是完备端密度 $1/2$ 的燃料。`graph.tex:322-329` 的论证是：给一个满足所有约束的标号 $A$，它在每个查询范围上的限制 $\lambda_{A,i}$ 自动是合法局部标号，全体组成的 $I_A$ 是兼容选择。若源只有近似完全性（比如 $1-\delta$），$I_A$ 里就会混进不满足内部约束的选择，`graph.tex:330-335` 的保留规则 "$\sum_j s_{j,\mathrm{slot}}(\lambda_{A,i_j})>t$" 就不再保证两个保留顶点之间没有边。`[推测]` 我认为这就是 `history.tex:55-56` 强调"imperfect completeness 只能给 $\sqrt2$"的机制性原因，KMS 那条线的独立集密度天然偏 $1/\sqrt2$。

$\sigma$ 必须能任意小且为固定常数，因为 `decoding.tex:6` 把 $\sigma$ 定成 $1/(h^2\ell^2)$，而 $h,\ell$ 只含 $m$；若源只能给某个绝对常数 $\sigma_0$，那么当 $m$ 大到 $h^2\ell^2>1/\sigma_0$ 时 $\sigma<\sigma_0$，`decoding.tex:9` 的假设 $\val(\Phi)\le\sigma$ 就没来源。此时 `decoding.tex:51` 的 $\Pr(E_{jk})\le\ell^2\sigma$ 会变成 $\ell^2\sigma_0$，与 $\binom h2$ 相乘后远超 $1/2$，$3/2$ 上界崩掉，$2$ 下界对 $3/2$ 上界的矛盾消失。

字母表可以长（只依赖 $\sigma$）这一点是本文分析真正吃力的地方：$r=q^{d-1}$ 进入 $\ell^1$ 阈值化之前的每一次估计。`restriction.tex:10-11`（即 `introduction.tex` 第 58 行那句"our analytic estimates will not depend on their sizes"）把这条约束写成目标；而 `lists.tex:212-216` 的 "dimension-independent bound" $\Var_s H_j\le 2\E_s\|\bar g_j\|_2^2$ 就是兑现它的地方。若列表长度按字母表算（$|L_j|\le r$ 那种朴素取法），$h^2\ell^2$ 里的 $\ell$ 会换成含 $q^{d-1}$ 的量，$\sigma$ 就要小到 $1/(h^2r^2)$，重复次数与源字母表随之爆炸，$d$ 的选择还要再大一个数量级。

### 2.4 候选失败路线（d）

`[推测]` 路线一：假设源的约束图是正则或扩张的，好借 $2$-to-$2$ 游戏的局部测试。这会破坏 `source.tex:18-19` 的"不需要正则/扩张"，也要重新证明 PCP 端能给出扩张性；原文的取舍是把几何信息全放进 $d$ 个位置的配对结构里，让约束图随机。
`[推测]` 路线二：用 $D$-to-$1$ 性质（`source.tex:37-38$ 明说不用）。若用，解码端 $A_{\rho,\tau}$ 的构造会多一层分支平均，收益只有 soundness 常数好一点，而 `decoding.tex:98` 只需 $\le\sigma$，多出来的结构无处可用。
`[推测]` 路线三：把源换成 Unique Games 本身（$|\Sigma_U|=|\Sigma_V|$ 且双射）。短列表在 UG 口径下靠 Friedgut 低平均敏感度定理拿到相关坐标（`history.tex:38-40`），这条路需要 UG 假设；本文的立脚点是只借 `src:hardness` 一条外部输入。

### 3.2 中间步骤（b）

范数公理我按三条补：绝对齐次与三角不等式来自"一族线性型的绝对值取上确界"，这个族有限（$\mathcal P$ 有限）所以上确界是最大值；定正性来自单点选择都在 $\mathcal I$ 里。原文 `graph.tex:87-98` 的证明确实只用了这两点，其中 `graph.tex:94` 写 "the singleton forms ensure that it vanishes only at zero"，`graph.tex:95-96` 补了零维情形的边界："If the coordinate set is empty, this is the unique norm on the zero-dimensional space." 我认为这句是刻意加的，因为 $\Lambda_i$ 可能为空（`graph.tex:34-35`），此时 $\mathcal P$ 的某些块全零，范数定义域维数会退化。

### 3.3 机械理由（c）

查询为什么必须"忘掉约束编号、忘掉对面端点"（`graph.tex:111-113`： "It does not retain the sampled occurrence indices, the sampled projection maps, or the opposite endpoint in any pair."）？因为 soundness 的解码要用列表造一个全局标号，而在 `decoding.tex:91-94` 里，赋给 $x\in U$ 的符号必须只依赖 $x$，赋给 $y\in V$ 的必须只依赖 $y$。若列表还看得见发生编号，同一变量的两次出现可以拿到不同符号，全局标号造不出来，`decoding.tex:98` 的源承诺就无从适用。`introduction.tex:96-100` 把这件事写成全文的主任务：

```
introduction.tex:96:  so source soundness bounds the probability that these two labels are
introduction.tex:97:  compatible. This argument fails if either list also sees the opposite
introduction.tex:98:  endpoint or the occurrence index. The main task is therefore to
introduction.tex:99:  obtain both enough compatibility among the lists and this restriction
introduction.tex:100:  on their information.
```

把 $q_{jk}$ 的侧别按 $k<j$ 还是 $k>j$ 分给 $V,U$（`graph.tex:18-22`）是二部性的体现：源实例的 $U,V$ 两侧恰好由位置的大小顺序模拟。$d$ 个位置两两配对 $\mathcal E=\binom{[d]}2$（`graph.tex:13`）就是"$\binom d2$ 个独立约束出现"，每对约束的左右端点分别交给小指标位置和大指标位置。若把这条定向规则改坏，同一个种子给出的两端会落到同一侧，$\pi_c$ 不再是从 $U$ 到 $V$ 的映射，标签的兼容性测试会失去意义。

### 4.2 中间步骤（b）

我先验证网格口径。把 $[-1,1]$ 等分成 $p$ 段，每段长 $2/p$，第 $i$ 段（$i=0,\dots,p-1$）的中点是 $-1+(i+\tfrac12)\tfrac2p=\frac{2i+1-p}{p}$。取 $p=2d+1$，则 $\frac{2i+1-(2d+1)}{p}=\frac{2(i-d)}{p}$，令 $u=i-d$ 恰好跑遍 $\{-d,\dots,d\}$，与 `graph.tex:121` 一致。这一步解释了 $p$ 为什么必须是奇数 $2d+1$：网格要关于原点对称且含 $0$，$0$ 出现在 $u=0$。对称性在 `graph.tex:298-304` 的对称论证里被消费（"$\Pr[\sum_jC_j>A]=\frac12(1-\Pr[|\sum_jC_j|\le A])$" 需要分布关于 $0$ 对称）。

$d/p=\frac d{2d+1}<\frac12$ 我算过：$2d<2d+1$。而 `source.tex:64-66` 断言 $\frac dp<\frac12<\frac t2$，右半要求 $t>1$，即 $a\sqrt d>1$，即 $\sqrt d>4m$，正是 `source.tex:48` 的条件。所以那一行的两个不等式把 $d$ 的下界同时钉在"网格够细"与"阈值够大"两件事上。

分母为 $p$ 这件事我补一句：$z(i,s)$ 的非零坐标就是某个 $s$ 的分量，取值在 $\mathcal T$ 里即分母 $p$；同一查询块可能在 $S_v$ 里出现多次（不同的 $j$ 给出同一个查询），$S_v+S_w$ 的块坐标是若干个 $\frac{2u}{p}$ 之和，故分母仍是 $p$。原文 `graph.tex:210-211` 的 "after summing all repeated-block contributions" 就是这个意思。于是 $\norm{S_v+S_w}=\max_I\lvert\sum\rvert$ 是有限个 $\frac{\text{整数}}p$ 的最大值，记为 $\frac\zeta p$，$\zeta$ 非负整数。

$\zeta/p\le 2d$ 的来源：`graph.tex:213-215` 用增量界 `graph:norm`（即 $\norm{z(i,s)}\le\|s\|_\infty\le1$）与三角不等式，$S_v+S_w$ 是 $2d$ 个增量之和，故范数 $\le 2d$。边测试 $2m\zeta\le p\sqrt d$ 由 $\frac\zeta p\le 2t=\frac{2\sqrt d}{4m}=\frac{\sqrt d}{2m}$ 交叉相乘得到。$d$ 取完全平方（`conclusion.tex:10` 的 $d=2^{38}m^{10}$，$\sqrt d=2^{19}m^5$）就是为了让 $\sqrt d$ 是整数，从而两边都是整数。

$(1+r)^{2d}$ 次选择的计数（`graph.tex:160-161`，`graph.tex:176`）我展开：一对顶点最多涉及 $2d$ 个查询块，每块至多 $r$ 个合法标签外加"不选"这一项，故 $(1+r)^{2d}$。每次判定要验证选中变量在重复处一致并扫描范围并集内部的源约束，并集大小至多 $2d(d-1)$（`graph.tex:179`）。这两个数都是 $m$ 的固定函数，与源实例长度 $L$ 无关，所以总时间 $O((1+n^2)\operatorname{poly}(L+\log n))$（`graph.tex:225-226`）是多项式。

### 4.3 常数与假设的机械理由（c）

为什么不去重（`graph.tex:131-135`）？去重会让"均匀取顶点"这个分布变成带权重的分布，`graph.tex:147-149` 那句 "Choosing a uniform vertex is exactly choosing all seeds independently and uniformly from $[M]$ and all weight entries independently and uniformly from $\mathcal T$" 就不再成立。后面所有概率方法都建立在"种子与权重独立均匀"这个乘积律上：`restriction.tex:20-26` 定义 $\Omega$、`lists.tex:25-29` 定义限制后的乘积律、`decoding.tex:17-20` 定义解码用的剩余律，三处都要求点的权重相等。若把重复向量合并，$S_v$ 的分布出现多重度偏置，`analysis.tex:114-116` 的 $\E f^2\ge b_0t^2/4$ 就要额外证明多重度与 $A_*$ 无关，这基本做不到。

$n\ge p>2m$（`graph.tex:144-146`）被 `analysis.tex:17-20` 与 `decoding.tex:156-159` 消费两次，用来把"丢掉一个低范数顶点"这件事变成可忽略误差。若 $n$ 只保证 $\ge 1/b_0$ 而不严格大于，$2b_0n-1>b_0n$ 这一步（`decoding.tex:158`）就只能得到 $\ge$，最终独立集密度的严格不等号会退化。

### 5.2 中间步骤（b）

$A$ 的定义在 `graph.tex:259`：$A=t+d/p=a\sqrt d+d/p$。我先补舍入这一步。取连续均匀 $C_j\in[-1,1]$，把它归到所在子区间的中点 $T_j$。中点与任一点的偏差 $\le$ 半区间 $=1/p$，故 $\lvert\sum_jT_j-\sum_jC_j\rvert\le d/p$（`graph.tex:256-258`）。边界点概率为零所以归点确定。若 $\sum_jC_j>A$，则 $\sum_jT_j\ge\sum_jC_j-d/p>A-d/p=t$，严格不等号来自 $A$ 的定义。这就是 `graph.tex:251-259` 与 `graph.tex:305` 的"On this event, rounding leaves $\sum_jT_j>t$"。

条件化那步：固定 $U_1,\dots,U_d$ 后，$\sum C_j=\frac12(\sum L_j+\sum U_j)$，事件 $\lvert\sum C_j\rvert\le A$ 等价于 $\sum L_j\in[-2A-S,-2A+S]$，其中 $S=\sum U_j$，区间长度 $4A$。$A$ 的定义给出 $4A=4a\sqrt d+4d/p$，再由 $d/p<1/2$ 得 $4d/p<2$。和的可能值 $\sum L_j\in\{-d,-d+2,\dots,d\}$ 间隔为 $2$，长度 $D$ 的区间至多含 $D/2+1$ 个格点：$4A/2+1<2a\sqrt d+1+1=2a\sqrt d+2$。

中心概率上界：$\prod_{u=1}^{d_0}(1-\frac1{2u})\le\frac1{\sqrt{d_0+1}}$ 的来源是逐项平方比较 $\bigl(1-\frac1{2u}\bigr)^2\le\frac u{u+1}$，右减左 $=\frac{u}{u+1}-\bigl(1-\frac1u+\frac1{4u^2}\bigr)$，通分得 $\frac{3u-1}{4u^2(u+1)}>0$，与 `graph.tex:290-291` 完全一致；连乘 telescoping 成 $\frac1{d_0+1}$ 再开方。$d_0+1>d/2$ 给出 $\frac1{\sqrt{d_0+1}}<\frac{\sqrt2}{\sqrt d}$。

把格点数与最大概率相乘：$(2a\sqrt d+2)\cdot\frac{\sqrt2}{\sqrt d}=\sqrt2(2a+\frac2{\sqrt d})$，即 `graph.tex:296`。再由对称性（$\sum C_j$ 分布关于 $0$ 对称，因为每个 $C_j$ 关于 $0$ 对称）得 $\Pr[\sum C_j>A]=\frac12(1-\Pr[\lvert\sum C_j\rvert\le A])$，代进去正是 `graph.tex:303`。

最后 $1/\sqrt d<a$（$\sqrt d>4m=1/a$）给出 $\sqrt2(a+1/\sqrt d)<2\sqrt2a$，而 $2\sqrt2<3$ 给出 $<3a=\frac3{4m}<\frac1m$。这个链里 $3$ 只是 $2\sqrt2$ 的粗界，真正的硬约束是 $m\ge4$ 让 $\frac3{4m}<\frac1m$ 恒成立。

完全性主体我按 `graph.tex:321-351` 补：满足所有源约束的标号 $A$ 给出 $I_A\in\mathcal I$（`graph.tex:324-329`），保留规则是 `graph.tex:331-335`

### 5.3 常数与假设的机械理由（c）

$d$ 为偶数在这里被消费两次：一次是 `graph.tex:275` 写 $d=2d_0$（奇数 $d$ 时符号和是半整数，中心概率公式要改写）；一次是 `conclusion.tex:24` 的 "$d$ is even and $\sqrt d=2^{19}m^5$"。$d$ 为完全平方则纯粹服务于 `graph.tex:216` 的整数边测试。两处合起来解释了 $d=2^{38}m^{10}$ 的指数选择：$38$ 与 $10$ 都是偶数。

$t=a\sqrt d$ 的 $\sqrt d$ 标度是关键设计。反集中度的误差项是 $a+\frac1{\sqrt d}$，而阈值相对和的标准差 $\sqrt d$ 的比正是 $a$。若取 $t$ 为常数（不随 $d$ 增长），$d$ 增大时 $\Pr[\sum T_j>t]$ 会趋于 $1$，独立集密度就从 $1/2$ 一路抬向 $1$，覆盖密度趋于 $0$，gap 反过来变坏；若取 $t=c\sqrt d$ 而想让 $\frac{1-c'}{1/2}\to 2$，必须让误差 $\sqrt2(a+1/\sqrt d)$ 趋于 $0$，即 $a\to0$，也就是 $m\to\infty$。这条标度关系就是"因子二"在解析上的真身。

$\frac12-\frac1m$ 与 $\frac12+\frac1m$ 的配对（`graph.tex:316` 与 `graph.tex:318`）来自取补：独立集 $>（\frac12-\frac1m)n$ 的补集 $<(\frac12+\frac1m)n$，严格性由整数与实数不等式传递。

### 5.4 候选失败路线（d）

`[推测]` 路线一：直接套 Hoeffding 或 Berry-Esseen。Hoeffding 只给 $\Pr[\sum T_j>t]$ 的指数衰减上界，方向恰好相反（我需要下界）；Berry-Esseen 给出的正态逼近误差是 $O(1/\sqrt d)$，与这里 $1/\sqrt d$ 同阶但常数不可控，而且它逼近的是连续正态，格点效应会引入额外 $\frac1{\sqrt d}$ 项，最终 $a+\frac1{\sqrt d}$ 里的两项都得重做。作者选"符号和 + 中心二项式"是拿精确格点计数换掉了逼近误差。

### 6.2 中间步骤（b）

$\E_{\mathbf s}f=0$ 我只用奇函数：固定 $\mathbf c$ 时，把所有 $s_j$ 同时取负，联合分布不变而 $f$ 变号（`analysis.tex:97-99`），所以均值是自身的相反数。这一步是 `restriction.tex:59-60` 那条假设 $\E_{\mathbf s}f(\mathbf c,\mathbf s)=0$ for every $\mathbf c$ 的全部来源，也是 $f_\varnothing=0$（`restriction.tex:123`）的来源。$F(0)=0$（`analysis.tex:99`）由奇性直接得到，用来界定 $|f|\le d$：$f$ 是 $F$ 作用在 $2d$ 项之和上…实际是 $d$ 个增量之和，每增量范数 $\le1$，故自变量范数 $\le d$，$|f|=|F(x)-F(0)|\le\|x\|\le d$。

舍入误差：`analysis.tex:103-110` 把连续 $s$ 归到 $\mathcal T$。单坐标变化 $\le 1/p$，故单个增量的范数变化 $\le 1/p$（用 $z(i,\cdot)$ 的线性与增量界 `graph:norm`），$d$ 个位置累计 $\le d/p<t/2$，$F$ 是 $1$-Lipschitz 所以函数值变化也 $<t/2$。归点后"未变种子 + 归点权重"的联合律正是均匀取顶点（`analysis.tex:109-110`），于是可以用 `graph.tex:147-149`。

$\E f^2\ge b_0t^2/4$：以至少 $b_0$ 的概率（`analysis.tex:29`，$\Pr[S_v\in A_*]\ge b_0$）归点和属于 $A_*$，此时 $F>$ t（`analysis.tex:39-40`），故连续版本 $f>t-t/2=t/2$，平方贡献至少 $b_0(t/2)^2$。$t^2=a^2d$ 给出 $b_0a^2d/4$。

振荡界 (iii) 我补得细一点，因为它决定 `restriction.tex:187-203` 的星形投影能否成立。固定 $k$，同时替换所有与 $k$ 关联的种子 $c_{\{k,j\}}$，但保持每个 $j\ne k$ 从 $\{j,k\}$ 收到的问题 $Q_{\{k,j\},j}(c_{\{k,j\}})$ 不变。位置 $j\ne k$ 的查询 $i_j$ 由它收到的全部 $d-1$ 个问题决定，其中来自 $\{j,k\}$ 的那个被显式保留，其它种子的贡献也没动，所以 $i_j$ 完全不变。唯一可能变的是 $i_k$（它的问题全来自关联种子）。于是只有一个增量变，界为 $2$。这条 (iii) 与 (ii) 的区别是"$d-1$ 个种子同时动"，代价是每个其它位置少变一点，正是这个不对称让 $O(d)$ 的星形能量预算成为可能。

### 6.3 常数与假设的机械理由（c）

$\nu=\frac{b_0a^2}4=\frac1{2^7m^3}$ 我把三个因子拆开算：$b_0=\frac1{2m}$，$a=\frac1{4m}$，$a^2=\frac1{16m^2}$，$b_0a^2=\frac1{32m^3}$，除以 $4$ 得 $\frac1{2^7m^3}$，与 `analysis.tex:10` 逐字一致。这三个因子各自有出处：$b_0$ 是被排除的独立集密度，$a^2$ 来自 $t^2=a^2d$，$\frac14$ 来自 $(t/2)^2$。$\nu$ 之后被 `lists.tex:8` 的 $\beta=\frac\nu8$ 与 `restriction.tex:74` 的 $\frac{\nu d}2$ 消费；若 $\nu$ 的 $m$ 指数从 $3$ 变到 $2$，$\ell,h$ 的 $m$ 指数跟着变小，而 $d$ 必须同时满足 $16h+32h^2\le\frac{\nu d}2$，$\sigma=\frac1{h^2\ell^2}$ 会变大，源硬度就供不上。

密度 $2b_0$ 的选择（`analysis.tex:12`）与 soundness 目标 $n/m=2b_0n$（`decoding.tex:148`）是同一个数：定理要排除的正是密度 $\ge1/m$ 的独立集，取 $2b_0=1/m$ 让两边对齐。这里留了一倍余量给"丢掉一个低范数点"（`analysis.tex:16-17`）与严格不等号（`decoding.tex:157-159`）。

$A_*$ 是"高范数独立集顶点的和向量集合"（`analysis.tex:77-78`）。它必须取自整个图的独立集并在抽新种子之前固定（`analysis.tex:71-73`： "The set $A_*$, the function $F$, and its formula are fixed from an independent set of the entire graph before the fresh seeds above are drawn."）。这句话是全文方法论的枢纽：$F$ 固定，$f$ 才可能在新的乘积律上有方差；若允许 $F$ 随样本重选，`restriction.tex:54-85` 的引理前提就不成立，因为那些假设是关于同一个 $f$ 的。

分离条件 $\norm{x+y}>2t$（`analysis.tex:31`）对 $x\ne y$ 来自非邻接，对 $x=y$ 来自 $\norm{2x}=2\norm x>2t$（`analysis.tex:82-83`）。这个条件保证 $A_*$ 与 $-A_*$ 不相交，从而 $F$ 在 $A_*$ 上严格正、在 $-A_*$ 上严格负（用奇性），$F(z)>t$ 才成立（`analysis.tex:92-95` 用到有限集上严格不等式可保留）。若 $A_*$ 无限，$\min_{x\in A_*}\norm{z+x}>2t$ 可能退化成 $\ge$，$F(z)>t$ 就没了。

### 6.4 候选失败路线（d）

`[推测]` 路线一：用 $A_*$ 的指标函数或其光滑化代替半差距离。指标函数几乎处处导数为零，`lists.tex:94-117` 的梯度规则会给出 $g=0$，能量 $\beta h$ 无从谈起；而半差距离的梯度由激活的仿射表达式决定，天生带组合信息。

### 7.2 中间步骤（b）

分解框架我按 `restriction.tex:99-133` 补。$W_j^0$ 对 $s_j$ 平均、$W_j^1=\mathrm{Id}-W_j^0$，$\Pi_S=\prod_{j\in S}W_j^1\prod_{j\notin S}W_j^0$。展开 $\prod_j(W_j^0+W_j^1)$ 得 $f=\sum_Sf_S$；两个不同 $S,S'$ 的分量在某个 $j$ 上一个含 $W_j^0$、一个含 $W_j^1$，而 $W_j^0W_j^1=0$（平均两次等于平均一次，且 $W_j^0$ 的值在 $s_j$ 上是常数，对其再取 $W_j^1$ 为零），所以正交。$\sum_S\|f_S\|_2^2=\|f\|_2^2$。

权重度数预算（`res:weight-degree`）：$\sum_{S\ne\emptyset}|S|\,\|f_S\|_2^2=\sum_{j}\|f-W_j^0f\|_2^2$，因为 $f-W_j^0f=\sum_{S\ni j}f_S$ 且右端正交。逐纤维用振荡界 (i)：固定其它坐标后 $f$ 在 $s_j$ 上的振幅 $\le2$，而 $W_j^0f$ 是平均值，故 $\lvert f-W_j^0f\rvert\le2$，平方积分 $\le4$，对 $d$ 个位置求和得 $\le4d$（`restriction.tex:127-132`）。

种子分解（`restriction.tex:134-161`）：每个非空 $S$ 指定一个代表位置 $j(S)$（例如 $\min S$），代表位置只依赖权重支集，与 $\omega$ 无关。对种子 $e$：$j\notin e$ 时二分 $P_e^0$ 与 $\mathrm{Id}-P_e^0$；$j\in e$ 时三分 $P_e^0$、$O_{e,j}-P_e^0$、$\mathrm{Id}-O_{e,j}$。三分正交的理由是 $\operatorname{ran}(P_e^0)\subseteq\operatorname{ran}(O_{e,j})$（`restriction.tex:108`），即"完全平均"是"按问题条件平均"的特殊情形，差 $\mathrm{Id}-O$ 与 $O-P^0$ 与 $P^0$ 两两正交，三者之和为恒等。固定 $S$ 得到 $f_S$ 的正交细分；不同 $S$ 的细分也正交，因为种子投影与权重投影交换（`restriction.tex:151-153`），故各 $f_{S,\omega}$ 仍在 $\operatorname{ran}(\Pi_S)$ 内。这就是 `restriction.tex:154-155` 强调 "even though the endpoint used to refine a seed can change with \(S\)" 的意义：代表位置随 $S$ 变，正交性却仍成立。

种子度数预算：$\sum|T_{S,\omega}|\,\|f_{S,\omega}\|_2^2=\sum_e\|f-P_e^0f\|_2^2$。逐纤维 $|f-P_e^0f|\le4$（振荡 (ii) 与平均），平方 $\le16$，种子共 $\binom d2$ 个，故 $\le16\binom d2=8d(d-1)\le8d^2$（`restriction.tex:173-176`）。这里 $16\binom d2$ 到 $8d^2$ 我算过：$\binom d2=\frac{d(d-1)}2$，乘 $16$ 得 $8d(d-1)$。

星形预算我补最关键的一步。$D_k=\prod_{j\ne k}O_{\{k,j\},j}$ 的因子作用在不同种子坐标上，所以是正交投影；它保留所有权重、所有不与 $k$ 关联的种子，以及与 $k$ 关联的每个种子上"对面那个位置收到的问题"。在 $D_k$ 的一条纤维上，变化量受 (iii) 控制：纤维上的函数值差异 $\le2$，$D_kf$ 是纤维上的平均，故 $\lvert f-D_kf\rvert\le2$ 逐点成立，平方积分 $\le4$，即 `res:star-energy`。

记账（`restriction.tex:205-228`）：对固定 $S$ 与 $k\ne j(S)$，$\bigl(\mathrm{Id}-O_{\{k,j(S)\},j(S)}\bigr)f_S$ 恰是 $k\in N_{S,\omega}$ 的那些分量之和（细分是对角的）。又 $\operatorname{ran}(D_k)\subseteq\operatorname{ran}(O_{\{k,j\},j})$，而"到较大闭子空间的距离不超过到较小者的距离"给出 $\|(\mathrm{Id}-O)v\|_2^2\le\|(\mathrm{Id}-D_k)v\|_2^2$。于是

$$\sum_{S,\omega}|N_{S,\omega}|\,\|f_{S,\omega}\|_2^2\le\sum_k\sum_{S\ne\emptyset}\|(\mathrm{Id}-D_k)f_S\|_2^2=\sum_k\|(\mathrm{Id}-D_k)f\|_2^2\le4d.$$

中间那个等号需要 $D_k$ 与所有权重投影交换，故不同 $f_S$ 的像仍正交（`restriction.tex:230-232`）。原文 `restriction.tex:233-234` 特意声明"这个论证既不用不同 $D_k$ 的乘积，也不用同一种子两端投影的交换性"，说明作者知道这里的两个陷阱：$O_{e,j}$ 与 $O_{e,k}$ 一般不交换（`restriction.tex:111-113` 明写 "we will not assume that they do"），而 $D_kD_l$（$k\ne l$）作用在同一个种子 $e=\{k,l\}$ 上也不交换。

限制算子 $K_{J,j}$（`res:restriction-operator`）的身份式我验一遍：先按 `restriction.tex:249-252`，$K_{J,j}$ 里 $W_j^1$ 之外的因子平均掉的正是"冻结数据以外的、除 $u_j$ 与 $s_j$ 之外的一切"，所以它等于"条件均值 $H_j$ 减去 $H_j$ 在 $s_j$ 上的均值"，而后者与保留的种子信息独立。于是 $\E_{\mathbf a}\mathcal V(J,\mathbf a)=\sum_{j\in J}\|K_{J,j}f\|_2^2$（`res:restriction-variance`）。

存活概率：固定分量 $f_{S,\omega}$，代表位置入 $J$ 的概率 $\frac hd$；在此条件下另一指定位置入 $J$ 的概率 $p_1=\frac{h-1}{d-1}$，一个避开代表位置的指定二元对入 $J$ 的概率 $p_2=\frac{(h-1)(h-2)}{(d-1)(d-2)}$。`res:survival` 的三个失败源分别由 $S\setminus\{j\}$（$|S|-1$ 个位置）、$N_{S,\omega}$（$|N|$ 个位置）、$T_{S,\omega}$ 中避开 $j$ 的对（$\le|T|$ 个对）触发，union bound 给出 `restriction.tex:322` 的下界，并且 `restriction.tex:325` 声明"这个界在显示式为负时也成立"，因为整个式子还会乘上 $\frac hd$ 并被后面的能量预算兜住。

$p_1,p_2$ 的放缩与最终链：$d\ge4$ 时 $d-1\ge\frac{3d}4$，$p_1\le\frac h{d-1}\le\frac{4h}{3d}\le\frac{2h}d$；又 $(d-1)(d-2)\ge\frac{d^2}4$（$d=4$ 时 $6\ge4$，更大时更松），故 $p_2\le\frac{h^2}{d^2/4}=\frac{4h^2}{d^2}$。把 $\sum(|S|-1+|N|)\|\cdot\|^2\le4d+4d=8d$（`restriction.tex:327-332`，前一个 $4d$ 来自权重度数预算减去 $\sum_S\|f_S\|^2$ 里多算的一份，实际就是 $\sum(|S|-1)\le\sum|S|\le4d$）与 $\sum|T|\|\cdot\|^2\le8d^2$ 分别乘 $p_1,p_2$，得 $8dp_1\le16h$、$8d^2p_2\le32h^2$，即 `restriction.tex:339` 的 $\nu d-16h-32h^2$，再由 `res:scale` 得 $\ge\frac{\nu d}2$，乘 $\frac hd$ 得 $\frac{\nu h}2$。非负量均值 $\ge\frac{\nu h}2$ 保证存在一个取值 $\ge\frac{\nu h}4$（`restriction.tex:346-350`）：这里作者主动让掉一倍，我不认为必要，推测是为了让"固定数据后 $H_j$ 的定义不涉及成功事件"这条口径（`restriction.tex:82-84` 与 `lists.tex:28-29`）在任何取法下都干净。

### 7.3 每个假设与常数的机械理由（c）

$\E_{\mathbf s}f(\mathbf c,\mathbf s)=0$ 对每个 $\mathbf c$ 成立这一条，用途是 $f_\emptyset=0$（`restriction.tex:122-123`）。若只有总均值零而不逐 $\mathbf c$ 零，$f_\emptyset$ 是关于 $\mathbf c$ 的非常数函数，它在任何 $J$ 上都会被权重投影 $\Pi_\emptyset$ 清零从而在 $\|K_{J,j}f\|_2^2$ 里彻底消失，$\|f\|_2^2\ge\nu d$ 里属于 $f_\emptyset$ 的那部分就白丢了；由于丢掉的量可能高达 $\nu d$ 的常数比例，$\nu d-16h-32h^2$ 变负，引理失效。

振荡界 (i) 的 $2$：它给出 $|f-W_j^0f|\le2$ 与 $\le4$ 的平方，权重预算 $\le4d$。若界是 $c_1$，预算变 $c_1^2d$，$8d$ 里的 $4d$ 换成 $c_1^2d$，于是 $16h$ 换成 $2c_1^2h$。

振荡界 (ii) 的 $4$：它给出种子预算 $16\binom d2$。系数 $16=4^2$ 是平方关系，(ii) 从 $4$ 变成 $5$ 就把 $8d^2$ 变成 $\frac{25}2\binom d2\approx12.5d^2$，于是 $32h^2$ 变成 $50h^2$，$\nu d/2$ 那条线要 $d$ 更大。为什么 (ii) 里是 $4$ 而 (i) 里是 $2$：一个种子影响两个位置的查询，每个位置的增量至多变 $2$，合起来 $4$（`analysis.tex:120-122`）。

振荡界 (iii) 的 $2$ 与它的"保留对面问题"限定：这是整个 $O(d)$ 预算的唯一来源。$D_k$ 的纤维恰好是"保留所有对面问题"的那些集合，所以 (iii) 直接给 $\|f-D_kf\|_2^2\le4$。若 (iii) 被去掉，剩下的只有 $O(d^2)$ 的种子预算，$p_2$ 项 $8d^2\cdot\frac{4h^2}{d^2}=32h^2$ 不变，但 $N$ 那部分只能按 $|N|\le|T|$ 记进种子预算，$32h^2$ 会变成含 $h^2$ 与 $d$ 混合的量，而 $N$ 的触发概率只是 $p_1$（一维），把它硬塞进 $p_2$（二维）会让 $h$ 的有效上界从 $\sim\sqrt{\nu d}$ 降到 $\sim(\nu d)^{1/3}$。`[推测]` 这正是作者写 `restriction.tex:180-185` 那段转折的动机：不这样做 $d$ 就要按 $m$ 的更高次幂长，$\sigma$ 也要更小，界好不好看只是副产品。

$16h+32h^2\le\frac{\nu d}2$ 的两项分工：$16h$ 是"位置碰撞"成本（$S$ 的其它成员与 $N$ 的其它成员），$32h^2$ 是"成对碰撞"成本（$T$ 里的对）。当 $h$ 远大于 $1$ 时后者主导，所以 $d$ 的阶由 $h^2\le\frac{\nu d}4$ 决定，即 $d\ge\frac{4h^2}\nu=\frac{4\cdot2^{24}m^6}{2^{-7}m^{-3}}=2^{33}m^9$。作者取 $d=2^{38}m^{10}$ 比这个最低要求多留 $2^5m$ 的余量（`conclusion.tex:27-28` 明确算成 $2^{16}m^3+2^{29}m^6\le2^{30}m^7=\frac{\nu d}2$）。

$J$ 的取法（`restriction.tex:305` 均匀取 $h$ 元子集）与"冻结数据随后固定"是这套论证能声称"不是条件在成功事件上"的原因：`restriction.tex:82-84` 的 "In particular it is not conditioned on an event involving a draw of those remaining variables." 与 `lists.tex:28-29` 的 "The choice of the fixed data does not condition these remaining draws on any event of success." 我在读的时候特意对了一下，这两句是同一件事的两次声明，第二次是为了防止读者把 $J,\mathbf a$ 的选取误当成对后续样本的条件。若真的条件在成功事件上，`lists.tex:53-56` 定义的 $\kappa_j(u)$ 就不是原来的乘积律，`lists.tex:391-396` 的 locality 论证与 `decoding.tex:102-107` 的"重建元组在原隐藏种子律下受支持"都会断。

### 7.4 候选失败路线（d）

`[推测]` 路线一：不做星形重采样，改用"每个种子只保留自己两个端点问题"的对称投影 $O_{e,j}O_{e,k}$。同一种子上的两个端点投影不交换，乘积不再是投影，正交分解失效；即使强行用 $O_{e,j}$ 与 $O_{e,k}$ 分别记账，$N$ 的集合要同时看两端，$p_1$ 的系数翻倍，$16h$ 变大而 $O(d)$ 性质不变，看上去能救。真正的坑是：$T$ 里避开代表位置的对要求"两端都不入 $J$"，概率 $\sim p_2$ 是对的，但入 $J$ 的关联种子只需一个额外端点入 $J$，概率 $\sim p_1$，把它按 $p_2$ 记会低估存活概率，$\nu d-16h-32h^2$ 那一步的方向就反了。
`[推测]` 路线二：先对 $\mathbf a$ 取平均再取 $J$，即考虑"随机冻结"。这样得到的条件是"以正概率成立"的事件，$H_j$ 的定义会被污染成条件律，`restriction.tex:82-84` 的独立性声明作废，$f$ 的振荡界 (iii) 在条件律下不再由 (ii) 加线性组合推出来。
`[推测]` 路线三：把 $h$ 取成 $d$ 的固定比例（比如 $h=d/2$）以省掉 union bound。那会让 $16h+32h^2\approx 8d^2$ 远大于 $\frac{\nu d}2$，除非 $d\le O(1/\nu)$，即 $d$ 有上界；而 $d$ 需要同时满足 $\sqrt d>4m$，$1/\nu=2^7m^3$，于是 $m$ 被限制在有界范围内，任意固定 $m$ 的结论就没了。这条路线死于 $h$ 必须远小于 $d$。

### 8.2 中间步骤（b）

参数链我先自己算一遍。$\beta=\frac\nu8=\frac1{2^{10}m^3}$，$\ell=\frac2\beta=2^{11}m^3$，$h=2\ell=2^{12}m^3$，与 `conclusion.tex:15-16` 逐字一致。$\ell,h$ 是整数的理由（`lists.tex:11-12`）：$\nu$ 是 $2^{-7}m^{-3}$ 的倒数型有理数，$\frac2\beta=\frac{16}\nu=2^{11}m^3$ 恰好整除。这里 $16/\nu$ 要成整数，$\nu$ 的 $2$ 的幂分母是刻意选的。

列表长度界：$\frac\beta2|L_j|\le\|\bar g_j\|_1\le1$ 给出 $|L_j|\le\frac2\beta=\ell$（`lists.tex:332-335`）。注意 $\ell=\frac2\beta$ 的定义让阈值 $\frac\beta2$ 与长度上界 $\ell$ 的乘积恰为 $1$，即 $\frac\beta2\cdot\ell=1$，这是饱和设计。

$\E Z\ge\frac{\beta h}2$ 的中间步骤我全部展开。第一步，$\beta h$ 是保留的平方能量，来自 $\sum_j\E\|\bar g_j\|_2^2\ge\nu h/8$，而 $\nu h/8=\beta h$ 正是 $\beta=\nu/8$ 的定义。第二步，逐位置拆成"列表槽"与"非列表槽"：非列表槽上 $\lvert\bar g\rvert<\frac\beta2$，故 $\lvert\bar g\rvert^2<\frac\beta2\lvert\bar g\rvert$，对 $t'\notin T_j$ 求和后用 $\ell^1\le1$ 得 $\le\frac\beta2$；列表槽上 $\lvert\bar g\rvert\le1$ 使 $\lvert\bar g\rvert^2\le\lvert\bar g\rvert$，再由条件 Jensen（$\bar g_j$ 是 $g_j$ 关于 $\mathcal G_j=(u_j,s_j)$ 的条件期望，且 $T_j$ 由 $\mathcal G_j$ 决定）得 $\sum_{T_j}\lvert\bar g\rvert\le\E[\sum_{T_j}\lvert g\rvert\mid\mathcal G_j]$。两式相减：$\|\bar g_j\|_2^2\le\E[\sum_{\lambda\in L_j}\lvert g_{\mathrm{slot}}\rvert\mid\mathcal G_j]+\frac\beta2$。对 $j$ 求和取期望：$\E\sum_j\sum_{\lambda\in L_j}\lvert g_{\mathrm{slot}}\rvert\ge\beta h-\frac\beta2h$。要它等于 $\frac{\beta h}2$ 就得 $\frac\beta2h=\frac{\beta h}2$，恒成立，所以右端是 $\frac{\beta h}2$；再由 $h=2\ell$ 与 $\beta\ell=1$ 得 $\frac{\beta h}2=\beta\ell=1$？我算 $\frac{\beta h}2=\frac{\beta\cdot2\ell}2=\beta\ell=\beta\cdot\frac2\beta=2$，与 `lists.tex:325` 的 $=2$ 一致，$\frac\beta2h=\frac\beta2\cdot2\ell=\beta\ell=2$ 也等于 $2$，所以 $\beta h-\frac\beta2h=4-2=2$。

第三步是纯凸几何的确定性陈述（`lists.tex:372-385`）：固定查询族与固定列表，$\Phi(g)=\sum_j\sum_{\lambda\in L_j}\lvert g_{j,\mathrm{slot}(\lambda)}\rvert$ 是 $\R^{J\times[r]}$ 上的凸函数；在生成元 $\pm v_I(\boldsymbol i)$ 上它的值恰是"选择 $I$ 命中的位置数"，因为每个块至多一个非零坐标（`lists.tex:88-89`： "It has at most one nonzero entry in each block \(j\)."）。凸函数在凸包上的值不超过其在生成元上的最大值，故 $\Phi(g)\le Z$ 逐点成立。把两步合起来给 $\E Z\ge2$。原文 `lists.tex:386-387` 特别强调"No independence between the lists and the gradient, or between positions, is required."，这句我读成对审稿人疑虑的直接回应：列表与梯度显然是同源的、极度相关的，但搬运用的是凸性，并非独立性。

梯度规则 $g$ 的存在性我按 `lists.tex:119-177` 补。关键是 $F$ 是两距离之差之半，而每个距离都是"有限集上取 min、再在兼容选择与符号上取 max"的仿射函数族 $L_{\zeta,I,\varepsilon}$（`lists.tex:124-128`）的复合，因此 $\psi_{\boldsymbol i}$ 分段仿射、片有限。在非退化点，最内层的 $\min$ 与 $\max$ 各自选中一支仿射片，链式求导给 $g=\frac12(\varepsilon_-v_{I_-}-\varepsilon_+v_{I_+})$（`lists.tex:167-170`），两支都是带符号兼容关联向量，故在凸包里。退化点用规定的规则：若两支不同斜率的候选在数值上打平就取 $g=0$（`lists.tex:141-142`），零也在对称凸包内。$g$ 在超平面之外等于真梯度、在每个点都满足凸包界，这个"逐点成立 vs 几乎处处成立"的分野在 `lists.tex:282-288` 被专门写出来：导数恒等式只是几乎处处的，而 `ana:hull`、`ana:block-bound`、`ana:mean-block-bound` 三式在每个输入上都成立。

立方体方差界（`lists.tex:253-279`）：单坐标线段上 $w_0$，Cauchy-Schwarz 给 $\lvert w_0(x)-w_0(y)\rvert^2\le\lvert x-y\rvert\int\lvert w_0'\rvert^2\le2\int_{-1}^1\lvert w_0'\rvert^2$；对独立均匀 $X,Y$ 取期望，用 $\Var(w_0(X))=\frac12\E\lvert w_0(X)-w_0(Y)\rvert^2$ 得 $\Var(w_0(X))\le2\E\lvert w_0'(X)\rvert^2$。Efron-Stein 把总方差控在"各坐标条件方差之和"内，$\sum_t2\E\lvert\bar g_t\rvert^2=2\E\lVert\bar g\rVert_2^2$，即界里的 $2$。原文 `lists.tex:266-276` 还给了 Efron-Stein 的直接证明：按坐标子集分解，总方差对每个非恒定平方分量计一次，坐标条件方差之和按该子集的非空元素个数计，故后者不小于前者。这个"dimension-independent"是相对于 $r$ 而言的：界里不含 $r$，只含 $\ell^2$ 能量本身。

### 8.3 每个常数与假设的机械理由（c）

$\beta=\frac\nu8$ 里的 $8$：`lists.tex:220-221` 的 $\nu h/8=\beta h$ 从 $\nu h/4$ 再折半而来，折半的代价是 `lists.tex:254-265` 的线段估计里的 $2$（$\Var\le2\E\lvert w'\rvert^2$）。所以 $\frac\nu4\to\frac\nu8$ 是分析常数，$\beta$ 只是它的记号化。若把 $8$ 改成 $4$，则 $\ell=2/\beta$ 减半、$h=2\ell$ 减半，$\beta h/2$ 仍是 $2$（因为它是恒等式），但 `lists.tex:14-16` 的预算 $16h+32h^2\le\nu d/2$ 会变松，$d$ 可以取小；真正的约束是 $\beta h$ 必须等于 $4$ 才能给出 $\E Z\ge2$，而这个等式对 $\nu$ 与 $m$ 完全解耦。于是 $h=32/\nu=2^{12}m^3$ 才是 $\beta h=4$ 与 $\ell^1\le1$ 两个条件的联合解。

阈值 $\frac\beta2$ ，并非 $\beta$：若阈值取 $\beta$，则非列表槽的质量损失界仍是 $\frac\beta2$（用 $\lvert\bar g\rvert<\beta$ 与 $\ell^1\le1$ 得 $\sum\lvert\bar g\rvert^2\le\beta\sum\lvert\bar g\rvert\le\beta$），于是 $\E\sum\sum\lvert g\rvert\ge\beta h-\beta h=0$，整条链归零。$\frac\beta2$ 恰好让损失是收益的一半，这是 $\E Z\ge\frac{\beta h}2$ 里那个 $\frac12$ 的全部来源。

列表为什么必须用 $\bar g_j$（自身条件梯度）而不用 $g_j$（全梯度）：$g$ 的定义允许看整批查询与整批权重（`lists.tex:114-116`： "The rule uses the fixed formula for \(F\), the frozen increments, and the supplied batch queries and weights. It does not inspect which hidden seed occurrences produced those queries."），它满足 locality 的方式只到"不看种子出现编号"为止，而解码要求"不看其它位置的问题"。$\bar g_j$ 通过 $\kappa_j(u)$（`lists.tex:51-65`）把其它位置的问题按条件律平均掉，才得到只依赖 $(u_j,s_j)$ 的映射。`lists.tex:317-322` 把这条写成命题结论的一部分。

$J$ 之外的增量固定成 $c_0=\sum_{k\notin J}z(i_k,s_k)$（`lists.tex:74-78`）：这个冻结把 $\psi_{\boldsymbol i}$ 变成只含 $h$ 个变量块的函数，同时保持它仿射结构的斜率不变，`lists.tex:152-155` 声明"被丢弃的等式在非冻结坐标上有非零法向，而冻结只改截距不改斜率"，所以退化超平面族仍是真超平面。若允许 $J$ 外的权重也动，超平面计数会随 $d$ 增长，"$\psi_{\boldsymbol i}$ 分段仿射、片有限"（`lists.tex:137-138`）仍真，但规则 $g$ 的定义域维数变成 $d$，后面 $\ell^1$ 预算按位置求和时多出 $d-h$ 项。

$\Phi,F,J,\mathbf a$ 固定后的核 $\kappa_j$ 与列表映射不再重算：`lists.tex:400-406` 收尾声明 "Conditioning later on other hidden seeds or on all weights changes the distribution of the inputs to these maps; it does not recompute their conditional averages."。这一句是 `decoding.tex:66-69` 能安全固定所有其它数据的前提，两处互相引用，缺一处整个 soundness 就会被质疑成循环定义。

### 8.4 候选失败路线（d）

`[推测]` 路线一：直接对 $g$ 阈值化拿列表，跳过 $\bar g$。列表会短（$\ell^1\le1$ 对 $g$ 也成立），但 $g$ 依赖整批输入，解码器 $A_{\rho,\tau}$ 给变量赋值时会出现"同一个变量在不同样本下拿到不同符号"，`decoding.tex:91-94` 的"符号只依赖 $x$ 或只依赖 $y$"直接断，源承诺无从套用。
`[推测]` 路线二：用 $\ell^2$ 阈值，并非 $\ell^1$。若按 $\lvert\bar g\rvert\ge\beta$ 且用 $\ell^2\le1$ 控长度，列表规模变成 $O(1/\beta)$ 同阶，但搬运质量那步需要 $\sum_{T}\lvert g\rvert$ 对 $\ell^2$ 的界，凸包生成元上的值就不再是"命中数"这个整数，`lists.tex:372-378` 的组合解释消失。
`[推测]` 路线三：绕开质量搬运，改成分别对 $\bar g_j$ 做组合解码。那要求每个位置的条件梯度自身携带兼容表示；而 `introduction.tex:130-132` 明说 "the derivatives of the own-question means have the required information restriction, but need not together lie in that same hull"。少了"搬到同一个全梯度"这一步，命中数 $Z$ 就没有任何上界来源，$2$ 与 $3/2$ 的矛盾造不出来。

### 9.2 中间步骤（b）

`graph:norm` 的三条各自独立。绝对齐次与三角来自"一族线性型的绝对值取 max"，这条我一眼就过。正定性我当时卡了一下：max 取遍 $\mathcal I$，若 $\mathcal I$ 只有空选择那最大值恒为 $0$，正定就废了；原文 `graph.tex:80-81` 把"包含每个坐标单点"和"遗传"分开声明，再在证明里 `graph.tex:90-91` 用"单点属于 $\mathcal I$ 由合法查询标号的定义给出"补齐。逻辑链是：单点在，则 $\lVert z\rVert\ge\lvert z_{i,\lambda}\rvert$ 对每个坐标成立，$\lVert z\rVert=0$ 逼出所有坐标为零。反过来"合法标号"的定义（`graph.tex:31-33`：满足那些两端都落在 $P(i)$ 内的源约束出现）已经自带了内部一致性，所以单点选择自动兼容，无需额外验证。空坐标集的情形原文在 `graph.tex:94-95` 用"零维空间上的唯一范数"一句话带过，我核对过：$r=q^{d-1}$ 在源字母表非空时至少为 $1$，$\mathcal P$ 真为空只可能出现在所有 $\Lambda_i$ 都空的情况，这条兜底纯粹是形式完备。

增量界 $\lVert z(i,s)\rVert\le\lVert s\rVert_\infty$ 的整个证明就压在"兼容选择在每个查询块里至多取一个坐标"上（`graph.tex:49-50` 的定义 + `graph.tex:95-97`）。我特意确认了：这条界在第 7 节的星形能量账里被用了两次（$D_k$ 纤维上的振荡 $\le2$ 来自"替换一个权重块改变一个增量，其范数至多 $2$"，即 $2\lVert s\rVert_\infty$ 型），也在 `graph:polynomial` 的 $\zeta/p\le2d$ 里被用了第三次。

`graph:local-norm` 的等式本身是一行：任意兼容选择与支撑块集 $\mathcal B$ 取交，遗传性保证交仍兼容，而块外的坐标全为零故和不变。真正的信息量在 $(1+r)^{2d}$ 这个数上，我按原文 `graph.tex:170-183` 重数了一遍。$z=S_v+S_w$ 的支撑块是 $v$ 的 $d$ 个查询与 $w$ 的 $d$ 个查询的并。我第一次读到这里以为"重复查询"是指一个顶点内部重复，后来发现按 `graph.tex:114-115` "不同位置类型的查询永不相同"，一个顶点内 $d$ 个块的类型互异，重复只跨 $v,w$ 出现，这正是 `graph.tex:171-172` 要"先把同一查询的所有出现坐标合并"的原因。合并后每块至多 $r=q^{d-1}$ 个候选标号（因 $\lvert P(i)\rvert\le d-1$），每块还要允许"一个都不选"，故 $1+r$ 支；块数 $\le 2d$，得 $(1+r)^{2d}$。每个候选选择要做两件事：块间重复变量上的取值一致，以及并集 $P(I)$ 内部所有源约束都满足；后者要扫一遍源约束表，前者的变量总数 $\le 2d(d-1)$。这两句合起来给出 `graph.tex:191` 的"每条边的判定都是精确的"，因为整个过程只涉及比较、枚举与查表，没有极限、没有采样。

`graph:polynomial` 里我原先没看懂的那半页在 `graph.tex:210-221`。逻辑是：网格值都是 $\frac{2u}{p}$ 型有理数，同块贡献相加后每个坐标分母仍为 $p$；局域 max 是这些坐标之和，故形如 $\zeta/p$，$\zeta$ 为非负整数。上界 $\zeta/p\le2d$ 由增量界（每块 $\le\lVert s\rVert_\infty\le1$）加三角不等式给出，于是 $\zeta$ 与 $p$ 的二进制长度都只依赖固定参数。边判定 $\lVert S_v+S_w\rVert\le2t$ 变成 $\zeta/p\le 2t$。代 $t=\sqrt d/(4m)$：$\zeta/p\le\sqrt d/(2m)$，交叉相乘（两边正）得 $2m\zeta\le p\sqrt d$。这与 `graph.tex:218` 逐字一致，两端皆整数，无需实数比较。

尾界 `graph:anticoncentration` 的账我全部重算。目标是 $\Pr[\sum_jT_j>t]>\frac12-\frac1m$，其中 $T_j$ 是网格 $\mathcal T$ 上独立均匀。用连续版本 $C_j$ 做桥梁：先把 $C_j$ 落到所属子区间的中点得到 $T_j$，误差 $\lvert\sum_jT_j-\sum_jC_j\rvert\le d/p<\frac12$（$p=2d+1$ 使 $d/p<\frac12$）。取 $A=t+d/p=a\sqrt d+d/p$，则 $\sum_jC_j>A$ 推出 $\sum_jT_j>t$。接着是全文我觉得最漂亮的一手：不直接用 Hoeffding 或 Berry-Esseen，而把每个 $C_j$ 拆成 $(L_j+U_j)/2$，$L_j$ 是公平符号、$U_j$ 是 $[-1,1]$ 均匀，两者独立。这个分解的用途是让条件分布变成"符号和落在某个区间"这种格点计数问题：固定 $U_1,\dots,U_d$，事件 $\lvert\sum_jC_j\rvert\le A$ 等价于 $\sum_jL_j$ 落在长度 $4A$ 的区间内。符号和取值彼此间隔 $2$，长度 $D$ 的区间至多含 $D/2+1$ 个格点值，故候选个数 $<2a\sqrt d+2$。剩下的纯粹是单点概率：$d=2d_0$ 时符号和的分布是 $4^{-d_0}\binom{2d_0}{v}$，相邻比 $(2d_0-v)/(v+1)$ 说明中心最大，而中心值用乘积写成 $\prod_{u=1}^{d_0}(1-\frac1{2u})$，平方后逐项压成 $\frac{u}{u+1}$ 使乘积望远镜，得 $\le\frac1{\sqrt{d_0+1}}<\frac{\sqrt2}{\sqrt d}$。把"格点数 $\times$ 最大单点概率"合起来：条件中心概率 $<\sqrt2(2a+\frac2{\sqrt d})$，取平均同界；对称性给出 $\Pr[\sum_jC_j>A]=\frac12(1-\Pr[\lvert\sum_jC_j\rvert\le A])>\frac12-\sqrt2(a+\frac1{\sqrt d})$。最后用 $\sqrt d>4m=\frac1a$ 把 $\frac1{\sqrt d}<a$，链成 $2\sqrt2 a<3a=\frac3{4m}<\frac1m$。

完全性 `graph:completeness` 的取集规则 `graph.tex:331-334` 是"沿满足标号 $A$ 选中的那个槽求和"。条件在种子族上，每个位置 $j$ 的选中槽号是常数，于是这 $d$ 项各自来自独立的 $s_j$ 块，独立性与槽号是否重合无关（`graph.tex:339-340`）。留下的顶点集大小按尾界 $>(\frac12-\frac1m)n$。两两不相邻：$I_A$ 本身是兼容选择（一致性与内部约束由 $A$ 全局满足给出），所以在 $S_v+S_w$ 上按定义代入 $I_A$ 得到的和至少是两者保留式和，$>2t$，正好违反 `graph.tex:137-141` 的边条件。这里 `graph.tex:343-346` 特别强调"即使同一查询在两个顶点都出现，代入 $I_A$ 也把两份贡献都算进去"，与 `graph:local-norm` 的合并处理互相印证。

### 9.3 每个常数与假设的机械理由（c）

$a=\frac1{4m}$ 里的 $4$：它同时喂三处。尾界里 $A=a\sqrt d+d/p$ 与格点数 $2a\sqrt d+2$；最终链 $\sqrt2(a+\frac1{\sqrt d})<2\sqrt2 a<3a=\frac3{4m}$，要 $3a\le\frac1m$ 就需要 $4\ge3$，余量只有 $1/3$。若把 $4$ 换成 $3$，$\frac{3}{3m}=\frac1m$ 变成严格相等，`graph.tex:309` 那条严格不等号就断，尾界退化成 $\ge$ 而完全性要的是"大于 $(\frac12-\frac1m)n$"。所以这个 $4$ 是严格性缓冲，$\sqrt2\cdot2<3$ 用了 $2.83<3$，两处缓冲叠在同一个 $4$ 上。

$t=\sqrt d/(4m)$ 与"边判定整数化"：$t$ 由 $a\sqrt d$ 给出，$\sqrt d$ 是整数才让 $2m\zeta\le p\sqrt d$ 两端都是整数。我在 `analysis.tex:9-11` 与 `conclusion.tex:13` 对过，$b_0=\frac1{2m}$、$\nu=\frac{b_0a^2}4$，$a$ 一旦改，$\nu$ 改，$h$、$\ell$、$\beta$ 全改，$d$ 的预算 $\frac{\nu d}2$ 也改，所以 $4m$ 这个选择是把图侧严格性与分析侧 $\nu$ 绑在同一根绳上。

"$d$ 是偶数"被谁消费：`graph.tex:275` 的 $d=2d_0$，即符号和格点计数。"$d$ 是完全平方"我最初的猜测是"为了让边判定精确"，这条猜错了一次：若 $\sqrt d$ 无理，$2m\zeta\le p\sqrt d$ 两端同正，平方后 $(2m\zeta)^2\le p^2d$ 仍是纯整数比较，精确性并不依赖平方。真正的依赖在别处：Lean 侧把 $t$ 声明成自然数（`GridBudget.lean:50`：`def t (m : ℕ) : ℕ := 2^17*m^4`），要在类型层面写自然数就要求 $a\sqrt d$ 落在 $\mathbb N$，即 $d=(2^{19}m^5)^2$（`GridBudget.lean:52` 的 `d_square`、`:56` 的 `sqrt_d`、`:61` 的 `t_eq` 三定理就是干这件事）。也就是说 $d$ 取 $2^{38}m^{10}$ 这种"平方加偶"的形状，一半是为符号和，一半是为机器侧的整型参数。`[推测]` 论文本身用实数 $t$ 也能写，是形式化把这条约束变得可见的。

$p=2d+1$：它把 $\mathcal T$ 做成 $[-1,1]$ 的 $p$ 等分子区间中点集，对称、含 $0$，且 $d/p<\frac12$。同时给出 $n\ge p>2m$（`graph.tex:144-146`），这条被 `analysis.tex:17-19` 的"$n\ge p>1/b_0$"消费，用来保证大独立集里高范数顶点数 $>b_0n$。$p$ 只要比 $2d$ 大就够，取 $2d+1$ 是让中点公式干净。

$r=q^{d-1}$ 与 $(1+r)^{2d}$：指数 $d-1$ 来自 $\lvert P(i)\rvert\le d-1$（一个查询最多问其它 $d-1$ 个位置各一个变量），底数 $q$ 是源字母表规模上限。$2d$ 是"一对顶点"的块数。这两个 $d$ 让 $(1+r)^{2d}$ 对固定 $m$ 与固定源字母表成为常数，但它的实际数量级是 $q^{2d(d-1)}$，配合 $n^2=M^{d(d-1)}p^{2rd}$，整个"多项式"的次数是 $\binom d2\approx2^{75}m^{20}$ 量级。我把这层读出来的时候有点不舒服，但原文 `graph.tex:226-232` 与 `conclusion.tex:37-38` 都明说常数与次数依赖 $m$，没有任何掩饰，这个坦白本身值得记下来：因子二的门槛是"每个固定因子各自有一条 reduction"，把 $m$ 打包进去的 uniform 版本本来就不在声明范围内。

$\zeta/p\le2d$：这是比特长度界的来源，用的正是 `graph:increment` 每块贡献 $\le1$ 加上 $2d$ 块。若增量界写成 $\le c\lVert s\rVert_\infty$，$c$ 会同时进 $\zeta$ 上界（比特长不变阶）与 `analysis.tex:118-124` 的三条振荡界（$2$ 变 $2c$、$4$ 变 $4c$），后者再进 `restriction.tex:172-175` 的 $16\binom d2$，平方成 $c^2$，最终把 $d$ 的最低要求从 $2^{33}m^9$ 推到 $c\ge2$ 时的更大值。$c=1$ 是这套常数能收得这么紧的前提。

### 9.4 候选失败路线（d）

`[推测]` 路线一：把边条件写成 $\lVert S_v-S_w\rVert\le2t$。看上去只是把 $w$ 换成"取负"，实际整个完全性论证崩掉。独立集给出的是 $\lVert S_v+S_w\rVert>2t$（`analysis.tex:80-83` 证明里逐字用到"不同顶点不相邻故 `graph.tex:137-141` 的边条件不成立"），它对差毫无控制。$F$ 之所以取 $\frac12(\dist_*(z,-A_*)-\dist_*(z,A_*))$ 这种"到对称集合的两个距离之差"，是因为 $F(z)>t$ 与 $F(-z)<-t$ 的奇函数形状把"和的范数大"翻译成了"函数值符号相反"；换成差的形式，`analysis.tex:39-40` 的奇性与 `lists.tex` 里对 $F$ 的分段仿射求导都得重写。这条路线我试到"高范数顶点和 $\le2t$ 的团"就停了：低范数集合在差口径下也仍是团（$\lVert S_v-S_w\rVert\le\lVert S_v\rVert+\lVert S_w\rVert\le2t$ 照样成立），所以失败点出现在高范数一侧，那里没有可用的三角不等式方向。
`[推测]` 路线二：顶点直接用连续权重 $([-1,1]^r)^d$ 配上某种离散化测度，跳过网格。图的阶立刻不可数，$n=\lvert V(G)\rvert$ 与 $\tau(G)<(\frac12+\frac1m)n$ 这类基数陈述失效，`graph:completeness` 的"比例"论证需要一个有限计数。网格的真正作用是把"均匀采样顶点"与"独立均匀取网格点"这两件事等同（`graph.tex:147-150`），同时给取整误差一个 $\le d/p<\frac12$ 的硬界。代价在 `analysis.tex:103-116`：为吸收取整误差，方差下界只能按 $\frac{t}{2}$ 来记，于是 $\E f^2\ge b_0t^2/4$，那个 $/4$ 就是离散化的账单。
`[推测]` 路线三：省掉符号分解 $C_j=(L_j+U_j)/2$，直接对 $T_j$ 用 Hoeffding。会得到 $\Pr[\sum T_j>t]\ge 1-\exp(-2t^2/d\cdot\text{const})$ 型的界，$t=a\sqrt d$ 时指数是 $-ca^2$ 这种与 $d$ 无关的常数，趋近 $\frac12$ 的速度只能靠 $a\to0$，也就是 $m\to\infty$，看起来一样能用。坑在尾部精度：Hoeffding 给的是 $\frac12-O(a)$ 还是 $\frac12-O(a^2)$ 级别取决于展开方式，而这里需要的常数 $\frac3{4m}$ 要一路压到 $\frac1m$，指数型界里的高阶项无法保证 `graph.tex:309` 那条 $2\sqrt2a<3a$ 型的显式系数。符号分解把问题降成"格点区间计数 $\times$ 单点最大概率"，两边都是精确组合量，这跟整篇文章"处处要精确整数"的口味一致。我当时以为作者用初等方法是审美选择，现在倾向读成常数被迫：$\sqrt2$ 与 $\frac1{\sqrt{d_0+1}}$ 都能纸面验证，而 Berry-Esseen 的误差常数带不可控量。

### 10.2 中间步骤（b）

分解的记号我先自证一遍再读。$\Pi_S$ 是"权重块恰好在 $S$ 上非常数"的 Efron-Stein 支撑投影，$f_S=\Pi_S f$；$S\ne\varnothing$ 的 $f_S$ 彼此正交且都落在 $\operatorname{ran}(\Pi_S)$。种子侧在每个 $e$ 上用两支之一：$j\notin e$ 时只有 $P_e^0$ 与 $\operatorname{Id}-P_e^0$；$j\in e$ 时拆成 $P_e^0$、$O_{e,j}-P_e^0$、$\operatorname{Id}-O_{e,j}$ 三支。$O_{e,j}-P_e^0$ 这一支的存在理由我要强调，因为第一遍读时我完全没懂它想干什么：它是"只知道 $j$ 侧那个问题、不知道种子本身"的那部分信息，正是它必须被 $K_{J,j}$ 保留，否则 $H_j$ 里就没有条件方差可留。嵌套值域 $\operatorname{ran}(P_e^0)\subseteq\operatorname{ran}(O_{e,j})$ 加 $P_e^0O_{e,j}=O_{e,j}P_e^0=P_e^0$（`restriction.tex:107-110`）使这三支两两正交且和为单位，从而按 $\omega$ 分量分解合法。

$T_{S,\omega}$、$N_{S,\omega}$、$j(S)$ 三个记号与三条件的对应关系，我把它写成一张对照表（第 15 节台账里也复述了一遍）：$S\cap J=\{j\}$ 是权重侧的存活条件，管的是"这个分量的非常数块必须正好是代表位置"；$N_{S,\omega}\cap J=\varnothing$ 管"与代表位置相邻、但被投影成 $\operatorname{Id}-O$ 的那些种子"，也就是"连对面问题都不保留"的成分不能撞上 $J$ 里的第二个位置；$T_{S,\omega}\cap\binom{J\setminus\{j\}}2=\varnothing$ 管"完全避开代表位置的隐藏种子"，它的两个端点都进了 $J$ 就死。

`res:seed-degree` 的 $\le8d^2$ 我核过：$\lvert f-P_e^0f\rvert\le4$ 由振荡界 (ii) 加平均（平均一组两两差 $\le4$ 的值，极差不变），故 $\lVert f-P_e^0f\rVert_2^2\le16$；乘上 $\binom d2$ 个种子得 $16\binom d2=8d(d-1)\le8d^2$。这一项按 $|T_{S,\omega}|$ 加权，所以它就是"种子次数 $\times$ 能量"的总账。

星形那步的关键转折在 `restriction.tex:180-185`，原文自己承认 $\binom d2$ 型账对"避开代表位置的隐藏对"够用（要两个端点都进 $J$，概率 $p_2$，于是多出来的因子是 $h^2$ 级），对"与代表位置相邻的隐藏种子"不够用（只要一个额外端点进 $J$，概率 $p_1$，多出 $h$ 级但能量系数带 $d$）。$D_k$ 的用处就是把后者一次性换成"保留对面问题"的投影：它的纤维恰好是振荡界 (iii) 覆盖的方向，$\lVert f-D_kf\rVert_2^2\le4$（界值 $2$ 的平方），而 $d$ 个位置各记一次，总能量 $O(d)$。我把这条读成"用问题视角换种子视角"：$D_k$ 保留的数据正是 $H_k$ 也保留的那类数据的对偶版本，所以两个投影的交换性可以验算，这就是后面 $\lVert K_{J,j}f\rVert_2^2$ 里"种子因子在选定分解下是对角的"（`restriction.tex:288-291`）的根据。

`res:restriction-variance` 那条恒等式我按 $\mathbf a$ 的随机性重推了一遍。$\mathcal V(J,\mathbf a)$ 是冻结数据为 $\mathbf a$ 时的保留方差和，$K_{J,j}$ 是"先把 $J$ 外权重与 $J$ 外种子按 $P_e^0$ 平均、再对 $J\setminus\{j\}$ 的种子按对面问题 $O$ 平均、最后只对 $s_j$ 之外的 $J$ 权重与 $j$ 的入射种子按自己的问题平均"这一串投影之积。对 $\mathbf a$ 取期望等价于不在这些坐标上冻结，于是 $\E_{\mathbf a}\mathcal V(J,\mathbf a)=\sum_{j\in J}\lVert K_{J,j}f\rVert_2^2$。原文 `restriction.tex:270-272` 提醒这条只依赖种子坐标的独立性，而 $\binom J2$ 内部的种子绝不出现在 $\mathbf a$ 里，它们仍是全平均状态，这正是 $H_j$ 的条件结构得以保住的缺口处。

`res:surviving-energy` 的"无相消"我一开始怀疑：$\lVert K_{J,j}f\rVert_2^2$ 展开后是不是会交叉项吃掉一部分。原文 `restriction.tex:282-284` 用 $K_{J,j}$ 与每个 $\Pi_S$ 交换来排除这一点：交换使 $K_{J,j}f$ 按 $S$ 分解成正交分量，$\lVert K_{J,j}f\rVert_2^2=\sum_S\lVert K_{J,j}f_S\rVert_2^2$，然后"每个非零系数都是某个分量本身"，所以只丢项不加项。剩下的就是把 $\sum_{S,\omega}\lVert f_{S,\omega}\rVert_2^2=\lVert f\rVert_2^2\ge\nu d$ 里满足三条件的那部分挑出来，其余全部丢掉。

概率账：代表位置进 $J$ 的概率 $\frac hd$；$S$ 里另一个位置进 $J$ 的概率 $p_1$；$T$ 中避开代表位置的一对进 $J$ 的概率 $p_2$；$N$ 中位置进 $J$ 的概率也是 $p_1$。三条件都活的下界由 union bound 给 $1-\frac{(|S|-1+|N|)}{d}\cdot\frac hd-\frac{hd^2}{d^2}\cdot\frac hp_2$ 型表达式（原文在 `restriction.tex:320` 之后合账，我读到的最终形式是 $16h+32h^2\le\frac{\nu d}2$ 那条预算）。系数分工我在第 7.3 节算过：$16h$ 来自一维碰撞（$4^2=16$ 的常数直接来自振荡界 (ii) 的 $4$ 与 $|S|+|N|\le d$ 的粗记），$32h^2$ 来自二维碰撞（$8d^2$ 的种子能量与 $\frac{h^2}{d^2}$ 的每对概率相乘，再折半）。

### 10.3 每个常数与假设的机械理由（c）

$p_1=\frac{h-1}{d-1}$ 与 $p_2=\frac{(h-1)(h-2)}{(d-1)(d-2)}$：这两个数是"条件在代表位置已属于 $J$"之后的超几何概率，$d-1$ 是分母，并非 $d$，因为代表位置已占一个名额。当 $h\ll d$ 时 $p_1\approx\frac hd$、$p_2\approx\frac{h^2}{d^2}$，与直觉一致；$d=2^{38}m^{10}$、$h=2^{12}m^3$ 使 $\frac hd=2^{-26}m^{-7}$，所以 $p_1,p_2$ 都极小，union bound 无损耗，$O(d)$ 能量乘 $\frac hd$ 得 $O(h)$ 方差，这就是 $\frac{\nu h}4$ 的量级来源。

$h\ge2$：引理陈述要求 $2\le h\le d$（`restriction.tex:56`）。$h=1$ 时 $p_2$ 分母 $(h-2)$ 归零、$\binom J2=\varnothing$，$\binom J2$ 内部种子不存在，所有种子都在 $\mathbf a$ 里被冻结，那 $H_j$ 里就没有"自己的问题"之外的随机性，条件方差为零。所以 $h\ge2$ 是这条论证的最低门槛，而 $h=2\ell$ 把它抬到 $2^{12}m^3$。

预算里的 $16$ 与 $32$：这两个数我核对过是"平方系数"型，$16=4^2$ 对应 $|f-P^0f|\le4$，$32=2\times16$ 是能量分配时再折半一次。$16h$ 项是"碰撞到 $J$ 中另一位置"的成本，所以带 $h$；$32h^2$ 项是"碰撞到 $J$ 中某对"的成本，所以带 $h^2$。这两项与 $\frac{\nu d}2$ 的比较是整套论证里唯一真正约束 $d$ 的地方，$d=2^{38}m^{10}$ 就是从这里解出来的。

$\mathbf a$ 的组成（`restriction.tex:31-34`：$(c_e)_{e\notin\binom J2}$ 与 $(s_k)_{k\notin J}$）：注意 $\binom J2$ 内部的种子属于"剩余随机数据"，不进 $\mathbf a$。若把 $\mathbf a$ 扩成也包含这些种子，那么 $H_j$ 里"自己的问题"就成了常量，条件方差消失；若把 $\mathbf a$ 缩小（比如冻结一部分入射种子），$J$ 外的权重就会通过未冻结种子漏进 $H_j$ 的定义，locality 立刻破。这两种改法都会让 `lists.tex:51-65` 的 $\kappa_j$ 不再是原乘积律。

"非条件于成功事件"这条声明的机械作用在第 10.2 节末尾体现：$J$ 与 $\mathbf a$ 是先随机抽取再固定的，抽取时的期望账给的是 $\E_{\mathbf a}\mathcal V(J,\mathbf a)\ge\frac{\nu h}4$，于是存在好的 $(J,\mathbf a)$。选出来之后所有后续论证都在这对固定数据下进行，$\mathcal V(J,\mathbf a)$ 是确定量的期望，不再有"以正概率成立"的措辞。这就是 `restriction.tex:82-84` 那句话在证明结构上的位置。

### 10.4 候选失败路线（d）

`[推测]` 路线一：给 $O_{e,j}$ 与 $O_{e,k}$ 强行假定交换性，把两个端点都当成"保留对面问题"。这在单个种子上不可能：$\operatorname{ran}(O_{e,j})$ 里的函数只依赖 $x$-侧问题，$\operatorname{ran}(O_{e,k})$ 只依赖 $y$-侧，两者交集是只依赖"种子本身到两侧问题的联合映射"的那部分，一般真小于二者值域。原文 `restriction.tex:111-113` 明写"两端投影不必交换，我们不假定交换"。若假定了交换，分解 $P_e^0$、$O_{e,j}-P_e^0$、$\operatorname{Id}-O_{e,j}$ 的三支里"$O_{e,j}-P_e^0$ 与 $\operatorname{Id}-O_{e,j}$ 正交"这条要重新证，而它只依赖嵌套值域，不依赖交换，所以真正的损失在 $D_k$：$d-1$ 个 $O$ 的乘积之所以是投影，靠的是它们作用在互不相同的种子坐标上（`restriction.tex:192-193`），与两端交换性无关；一旦想用"两端都保留"的版本 $D_k'\prod_{j\ne k}O_{\{k,j\},k}$，那些因子作用在同一批种子上，就不是投影了。这条路线死在"乘积是投影"这个代数事实上。
`[推测]` 路线二：跳过星形重采样，改用"逐种子条件在对面问题"的逐步投影乘积，即先 $O_{\{k,1\},1}$ 再 $O_{\{k,2\},2}$。这些因子确实作用在不同坐标上，交换且乘积为投影，看着与 $D_k$ 等价。区别在于每步投影保留的是"对面问题"，而逐种子做的话，中途某一步会保留"当前种子两侧的问法组合"，最终纤维与 $D_k$ 的一致，$\le2$ 的振荡界仍然可用。我原本以为这条路通，后来发现失败点在能量分配：`restriction.tex:163-168` 的 $N_{S,\omega}$ 定义依赖"在代表位置那一侧投影取 $\operatorname{Id}-O$"这个唯一判据，逐步乘积会让同一分量在不同 $k$ 下有不同的 $N$，$\mathbf1$ 指标里的三条件不再对同一个分量成立，$\sum_{S,\omega}\mathbf1\lVert f_{S,\omega}\rVert_2^2$ 就不可能从 $\lVert f\rVert_2^2$ 里挑出来。
`[推测]` 路线三：把 $J$ 的抽样改成"贪心挑方差最大的 $h$ 个位置"。那会引入对样本的条件依赖，`restriction.tex:82-84` 的声明作废，同时 $p_1,p_2$ 的超几何计数不再可用（$J$ 与种子族相关），union bound 的每一项都要换成带条件的版本，最坏情况下三条件的存活概率跌到 $0$。这条我写下来纯粹是为了记住"随机 $J$"是计算的必需件，并非取巧。

### 11.3 每个常数与假设的机械理由（c）

$b_0=\frac1{2m}$：被两处钉死。$n/m=2b_0n$ 要求 $2b_0=\frac1m$；完全性一侧要排除的密度是 $\frac12-\frac1m$，两侧之间的 gap 比值 $R_m=2-\frac6{m+2}$ 也靠 $m$ 这一个参数走。$b_0$ 若写成 $\frac{c}{m}$，则 $\nu=\frac{b_0a^2}4=\frac{ca^2}{4m}$，$h=\frac{32}\nu$、$d$ 都要按 $\frac1c$ 缩放，最后 $R_m$ 里的 $6$ 会变，门槛表达式不再是 $\frac{1-1/m}{1/2+1/m}$。

$t/2$ 这个容差：它把 $\E f^2$ 的下界压到 $b_0t^2/4$，那个 $/4$ 里有 $t/2$ 的平方贡献一半、概率 $b_0$ 无损失。若取整误差能压到 $t\varepsilon$（$\varepsilon<\frac12$），$\nu$ 变大 $\frac1{4\varepsilon^2}$ 倍，$h$ 与 $d$ 都缩小；要压小误差就得增大 $p$，而 $p$ 增大让 $n=p^{rd}$ 与 $r=q^{d-1}$ 的枚举更贵。$\varepsilon=\frac12$ 是 $p=2d+1$ 这个最小对称网格的自然选择。

$\lVert f\rVert_\infty\le d$ 的 $d$：来自 $d$ 个块每块 $\le1$。这条界与"每个顶点是 $d$ 个增量之和"同构，说明 $\nu d$ 的方差是 $O(d)$，即逐位置独立贡献；$f$ 的方差与 $\lVert f\rVert_\infty^2$ 之比是 $\frac1{\nu d}$，也就是 $128m^3/d$，这个比例在限制引理里以"能量集中在低支撑分量"的形式起作用。

`analysis.tex:16-20` 的 $n\ge p>1/b_0$：三处消费（团观察后的计数、`decoding.tex:155`、以及 `graph.tex:144-146` 的声明）。$p>1/b_0$ 即 $2d+1>2m$，由 $d=2^{38}m^{10}$ 显然满足，属于自动成立的条件；它出现在原文里是为了让"至多一个低范数顶点"的减法不翻车。

### 11.4 候选失败路线（d）

`[推测]` 路线一：把 $F$ 换成 $\dist_*(z,-A_*)$ 单独一支（丢掉减 $\dist_*(z,A_*)$）。$F(z)>t$ 在 $A_*$ 上仍然成立，$1$-Lipschitz 也成立，唯独奇性与 $\E_{\mathbf s}f=0$ 没了。后果按上面所说：$S=\varnothing$ 分量非零，`res:component-energy` 必须在求和里加回一项，而该项在 $K_{J,j}$ 下全保留却对方差无贡献，$\frac{\nu h}4$ 那条下界的推导要重做。我试过给它加个"事后减均值"补丁，即在限制引理里用 $f-\E_{\mathbf s}f$ 替换 $f$；这确实恢复了 $\E_{\mathbf s}=0$，但 $\E_{\mathbf s}f$ 是种子的函数，于是振荡界 (i) 变成"换权重块时 $\E_{\mathbf s}f$ 不变"（成立）而 (iii) 变成"换星形种子时 $\E_{\mathbf s}f$ 会变"，这条我没能给出 $\le2$ 的界，`analysis.tex:118-124` 的证法完全依赖 $F$ 在自变量上的 Lipschitz，均值项没有这种表示。补丁作废。
`[推测]` 路线二：跳过取整，直接在连续立方体上做全部分析，把 $n$ 换成测度。这样 $d/p$ 误差消失、$\nu$ 可以换成 $b_0a^2$ 型更好常数。死点在 $\tau(G)$：图的顶点必须有限才有"最小覆盖基数"与 $\tau(G)>(1-\frac1m)n$ 这类命题，测度版本要么改用可数近似的离散化（回到原路），要么把覆盖数换成某种积分，而 `graph:norm` 的 max 定义在有限坐标集上，兼容选择族 $\mathcal I$ 的有限性也依赖 $\Lambda_i$ 有限。这条路线我走到"$\mathcal I$ 仍有限但顶点无限"就发现两边的计数根本对不上，`lists.tex` 里所有期望都必须相对顶点律取。
`[推测]` 路线三：把独立集假设 weaken 成 $\lvert\mathcal A\rvert\ge(1-\frac1m-\delta)n$ 型，试图同时压低完全性侧的 $\frac12+\frac1m$。这会让 $n/m=2b_0n$ 与"至少 $b_0n$ 个高范数顶点"之间的换算变紧，$b_0n-1$ 项吃掉余量，尾界需要 $\frac12-\frac1m$ 里那个 $\frac1m$ 重新分配给完全性与(soundness 两侧。结果就是 $R_m$ 的分子分母都动，$2-\frac6{m+2}$ 这条干净式子丢掉。原方案把 $\frac1m$ 对称地用两次（一次保完全集密度 $\frac12-\frac1m$，一次保覆盖下界 $1-\frac1m$），是省常数的做法。

### 12.2 中间步骤（b）

$\sigma$ 的定义放在解码节开头（`decoding.tex:4-8`），却要被源定理在更早处索取，这个次序矛盾在 `conclusion.tex:4-6` 用一句话解开："先把构造与分析的所有显式要求列出，再统一选常数，最后才去请求源字母表"。我按这条重排了一遍依赖图：$m\to(a,b_0,\nu)\to(\beta,\ell,h)\to d\to\sigma\to$ 源字母表 $\to(q,r)\to M$ 与 $n$。$\sigma=\frac1{h^2\ell^2}$ 代 $h=2^{12}m^3$、$\ell=2^{11}m^3$ 得 $\frac1{2^{46}m^{12}}$，与 `conclusion.tex:17` 逐字一致。

成对解码的构造我一步步按 `decoding.tex:60-83` 复现。固定 $j<k$、$e=\{j,k\}$，把除 $c_e$ 以外的所有种子与所有权重量固定成常数，此时 $c_e$ 仍按 $[M]$ 均匀。对任意 $x\in U$ 造 $u_j^x$（把 $u_j$ 里那个"由 $e$ 决定的坐标"换成 $x$，其余保持已固定的值），同理造 $u_k^y$。$\ell$ 个秩 $\rho$ 与 $\ell$ 个秩 $\tau$ 各给一台标号：$x$ 处取 $\mathcal L_j(u_j^x,s_j)$ 第 $\rho$ 项在该变量上的值，缺秩就取默认符号 $a_U$；$y$ 处同理用 $\mathcal L_k(u_k^y,s_k)$ 第 $\tau$ 项或 $a_V$。这里我原来担心三件事，原文 `decoding.tex:85-91` 逐条堵住：代入后的元组可能概率为零（列表返回空，走同一个 fallback）；同一变量在查询里重复出现（局部标号本来就是定义在去重变量集上的赋值，取值唯一）；秩不存在（fallback）。三件事的共同要求是 $A_{\rho,\tau}$ 必须是 $U\cup V$ 上的**全函数**，因为源承诺 $\val(\Phi)\le\sigma$ 的量词只覆盖"给所有变量各派一个符号"的标号。

### 12.3 每个常数与假设的机械理由（c）

$\sigma=\frac1{h^2\ell^2}$ 的两个 $h$ 与两个 $\ell$：$\ell^2$ 是秩对 union bound 的开销，$h^2$（其实是 $\binom h2$）是位置对的数量。要 $\binom h2\ell^2\sigma<\frac12$，$\sigma$ 至多要 $\frac1{h^2\ell^2}$ 这个量级，取等号最省。这里"省"的意义是让源字母表尽可能小，因为 $q,r$ 随 $\sigma$ 变差而膨胀，而 $n=M^{\binom d2}p^{rd}$ 与 $(1+r)^{2d}$ 都吃 $r$。

$\frac32$ 与 $2$ 之间的余量：$\frac32$ 完全来自 $\binom h2\ell^2\sigma<\frac12$ 加那个 $+1$，与 $h,\ell$ 的具体值几乎无关（只留 $-\frac1{2h}$ 的余量）；$2$ 来自 $\frac{\beta h}2$ 且 $h=2\ell$、$\beta\ell=1$ 的联立，即 $\frac{\beta h}2=\beta\ell=1$ 会退化，实际 $\frac{\beta h}2=\frac{\beta\cdot2\ell}2=\beta\ell$，而 $\beta\ell=1$ 给出 $1$？这里我算错过一次，重算：$\ell=\frac2\beta$ 故 $\beta\ell=2$，$\frac{\beta h}2=\frac{\beta\cdot2\ell}2=\beta\ell=2$ ✓ 与 `lists.tex:325` 与 `conclusion.tex:33` 的 $=2$ 相符。所以 $h=2\ell$ 这个"两倍的列表长度"正是把 $2$ 从 $1$ 抬到 $2$ 的那一步；若取 $h=\ell$ 则 $\E Z\ge1$，与 $<\frac32$ 不再矛盾。若取 $h=3\ell$，$\E Z\ge3$，余量更大，但预算 $16h+32h^2$ 按 $h^2$ 涨，$d$ 要从 $2^{38}m^{10}$ 抬到 $2^{39}m^{10}$ 量级，$n$ 的双指数代价立刻显形。$2$ 对 $\frac32$ 是能满足矛盾的最小整倍数选择。

默认符号 $a_U,a_V$：必须是源字母表里事先选定的元素（$\Sigma_U,\Sigma_V$ 非空由 `source.tex:23-24` 的"非空常数字母表"保证）。它们的作用只在"秩不存在/元组不支持"时让 $A_{\rho,\tau}$ 全定义，取哪个符号不影响任何不等式，所以这是纯粹的技术性自由度。

`dec:soundness` 陈述里的"假设 $\eqref{src:restriction-budget}$"：即 $h<d$ 与 $16h+32h^2\le\frac{\nu d}2$，方程与标签在 `lists.tex:14-17`。把这条写进 soundness 的前提是诚实做法，它告诉读者解码本身不需要预算，只是要让下界可达。

`[推测]` 路线一：让 $A_{\rho,\tau}$ 也看出现编号 $c$。这在语义上就出局：源承诺的 $\val(\Phi)\le\sigma$ 是对"全局标号"取的上确界，允许每台标号依赖被抽到的那条约束，等于允许"为每条约束各造一份赋值"，此时值可以为 $1$。这条路线与第 8.4 节路线一（直接对 $g$ 阈值化）是同一个障碍的两端，$g$ 依赖整批输入正是通过"标号随样本变"来破坏承诺的。
`[推测]` 路线二：把秩对上的 union bound 换成随机选一个秩对再取期望。得到的是 $\Pr(E_{jk})\le\ell^2\sigma$ 的同样界，因为存在性见证已经把秩对数吃掉；想省掉 $\ell^2$ 就得把列表长度与秩结构绑到某个具体映射上，而 `lists.tex:292-297` 的整个卖点是列表长度不含字母表规模。若真省掉 $\ell^2$，$\sigma$ 可以放大到 $\frac1{h^2}$，源字母表缩小，看上去双赢，但见证 $E_{jk}$ 需要"$I$ 命中的那两个具体标号在各自列表里的秩"，这两个秩是随机变量，不加 $\ell^2$ 就只能条件在它们上，条件概率不再是同一乘积律下的量，`decoding.tex:125-126` 那句"无条件"作废。
`[推测]` 路线三：把 $z\le1+\binom z2$ 换成 $Z\le h\cdot\max_{j}(\text{位置 }j\text{ 命中})$ 型的一阶界。那需要单个位置命中概率 $\le\frac{\beta}2$ 型的信息；而位置命中由 $D_k$ 保留的对面问题决定，其概率账与 $\sigma$ 无关，会退回字母表规模。二阶界之所以有效，是因为"两个位置同时被一个兼容选择命中"恰好等价于"一次采样出现被某台全局标号满足"，这是唯一能把 $\sigma$ 用进去的形状。$z\le1+\binom z2$ 在 $z=1,2$ 处取等的性质也说明这个转换在低命中数时无损，真正付账的是成对概率，这与 `analysis.tex:9-11` 的方差是二阶量（$\E f^2$）形成一种呼应，虽然两处没有直接逻辑关联。

### 14.2 中间步骤（b）

先回答派单里那个问题：论文推论"$\alpha\in[1,2)$ 任意固定，$\alpha$-近似顶点覆盖 NP-hard"这句话在机器侧被拆成七段，每段各自是一个可声明的对象。

第一段是参数化：`GridBudget.lean:41-50` 把 `conclusion.tex:11-22` 那十个常数逐个写成 `m : ℕ` 的函数，其中 $\ell,h,d,p,t$ 用 `ℕ`，$a,b_0,\nu,\beta,\sigma$ 用 `ℝ`。`conclusion.tex:13-19` 的排版是一张大表，Lean 侧是十个独立 `def` 加六条恒等式（`:52,56,61,102,107,112`）与三条不等式账（`:77 dimensions`、`:88 restriction_budget`、`:118 grid_budget`）；`:61` 的 `t_eq` 说的是 $t=a\sqrt d$（第 13.2 节我算的那步），`:112` 的 `σ_eq` 说的是 $\sigma=\frac1{h^2\ell^2}$（`decoding.tex:6`）。

第二段是"归约"这个对象的字段化：`Basic.lean:41-51` 的 `GapReduction m` 把论文里"确定性多项式时间归约，且满足两侧覆盖界"拆成五个字段。`construct` 是函数本体，`computation` 是 `TM2ComputableInPolyTime ExplicitGraph.bits construct`（二带图灵机、以位串为输入输出编码、多项式时间），`finiteAlphabet` 是这台机机的带字母表在每一步都有限（`:39`），`completeness` 与 `soundness` 是两条严格不等式，形状与 `introduction.tex:22-27` 逐字对应。论文用一句话承担的东西，机器侧变成结构体的五个字段，这是第一个"量词被拆开"的地方。

第三段是"$\forall m\ge4$"：`Main.lean:113-114` 的 `explicit_cover_gap (m : ℕ) (hm : 4 ≤ m) : Nonempty (GapReduction m)`，证明就是 `⟨reduction m hm⟩`，即 `:103-108` 那条结构体装配记录。注意它写成 `Nonempty`，也就是说定理只声明"这个类型有人居"，把构造的内容留在 `def reduction` 里。

第四段是"近似算法"的口径：`Basic.lean:56-63` 的 `Approximation α` 有七个字段，除运行时间与字母表有限外，还有 `nodup`（输出是不重复的顶点表）、`vertices`（每个顶点编号 $<G.n$）、`covers`（真是覆盖：每条边至少一个端点在表里）、`quality`（表长 $\le\alpha\cdot$`coverNumber`）。这四个字段的作用是把论文里"返回一个覆盖且大小不超过 $\alpha\tau(G)$"里的"覆盖"从形容词变成可检查的谓词，`covers` 是对边表的逐条析取。

第五段是 $\alpha<2$ 到 $m$ 的换算：`Approximation.lean:92-93` 的 `exists_separating_integer`，陈述 $\exists m,\;4\le m\;\land\;\alpha(\frac12+\frac1m)<1-\frac1m$，与 `conclusion.tex:51-55` 的 $\alpha<R_m$ 交叉相乘后完全同式（第 13.2 节推过）。机器侧的 witness 是 `exists_nat_gt (max 4 (2*(α+1)/(2-α)))`，正是我解出的那个 $m>\frac{2(\alpha+1)}{2-\alpha}$，而 `:94-95` 先把 $0<2-\alpha$ 记成 `hden`、把 $4\le m$ 从 $4<\max$ 用 `exact_mod_cast ... .le` 提出来，所以 $\alpha=1$ 时得到 $m\ge5$ ，并非 $m\ge4$。这段是整个"任意固定"的量化核心：$\alpha$ 只在这一步出现，且只出现在一个存在消去里。

第六段是把上面两段拼成判定机：`Approximation.lean:109-112` 的 `decisionOfGap`，参数依次是 $1\le\alpha$、$m$、$4\le m$、$hsep$、`GapReduction m`、`Approximation α`，返回 `ThreeSATDecision`。它的 `run` 就是 `fun input => A.test m (R.construct input)`（`:112-113`，`test` 是 `:71` 那个把覆盖表长度与阈值比较的布尔判定，配套 `testPoly m` 给出多项式时间证明）。正确性证明的形状值得记：`:118` 那句 `change decide (m*(A.run G).length < (m-1)*G.n)=true ↔ ThreeSAT input`，即把"阈值比较"写成纯自然数不等式 $m\cdot k<(m-1)\cdot n$，再用 `:82-83` 的 `rational_threshold` 换回实数形式。`conclusion.tex:66-68` 那句"比较只用整数算术：把基数乘 $m$，与 $(m-1)n$ 比"，在机器侧就是 `rational_threshold` 加一次 `decide`，两边措辞对齐到字面。两个方向分别用 `R.soundness` 加 `coverNumber_le_length`（`:48`，覆盖数 $\le$ 输出表长）与 `R.completeness`，`:129-135` 处还要证 $G.n\ne0$，做法是反设 $n=0$ 则 `completeness` 给出 $(0:\mathbb R)<0$ 的矛盾。

第七段是顶层定理：`Main.lean:115-118`。它的签名是"给一个实数 $\alpha$、两个不等式 $1\le\alpha$、$\alpha<2$、以及一台 `Approximation α`，构造出 `Nonempty ThreeSATDecision`"。也就是说 NP-hardness 在机器侧的表述形式是"两台机器之间存在一台可计算的变换"，而 P≠NP、NP 类、验证器这些概念一次都没有出现：定理的结论是一个判定机的存在性，前提是近似机的存在性，两者都是同一种带 `computation` 与 `finiteAlphabet` 字段的结构体。$h\alpha:1\le\alpha$ 我从 `:109` 读到 `:135`（再往下是正确性证明的尾部，我没继续读）也没见到它被哪条不等式消费，`[推测]` 它的作用只是与 `introduction.tex:35` 的 $\alpha\in[1,2)$ 对齐，因为 $\alpha<1$ 时 `quality` 与 `coverNumber_le_length` 直接冲突（只有 $\tau(G)=0$ 的无边图才可能满足）。

机器装配的中间层我按调用点记一下，它们对应论文里被省略的"源侧"：`gapInput`（`Main.lean:49-51`）把 $\mathrm{3SAT}$ 公式迭代成一张表式 LabelCover；`base`（`:54-55`）得到 `FixedLC 7 2`；`repeated σ hσ`（`:62-64`）用 `power` 做并行重复，字母表按 `repetitionLength σ hσ` 次方膨胀成 `FixedLC (7^repetitionLength) (2^repetitionLength)`，并配一条 `LabelCover.Iso`（`:68-70`）说明它与 `binaryReduction` 同构；`repeated_complete`/`repeated_sound`（`:71-80`）给出完美完全性与严格 $<\sigma$ 的可靠性。最后 `construct`（`:82-84`）把重复后的实例连同 `Parameters.d m`、`Parameters.t m` 喂给 `GraphMachine.explicitGraph`，并用 `GraphMachine.fullEquiv I (Parameters.d m)` 把机器图与数学图对接（`:95,100`）。这里有一个与论文口径的小差异值得记：`repeated_sound` 给的是 `value < σ`（`:78`），而 `dec:soundness` 的前提写成 `val(Φ) ≤ σ`（`decoding.tex:9,147`），机器侧靠 `hv.le`（`:101`）把严格化非严格，正好一次。

### 14.3 每个常数与假设的机械理由（c）

公理清单 `VertexCover.json:9-13` 恰为三项。`propext` 与 `Quot.sound` 是 Mathlib 里实数、商类型与基数运算的常规依赖，`Classical.choice` 则是排中/选择类推理的入口，三者合起来就是 Mathlib 的"标准三公理"，没有 `sorry`、没有额外公理、也没有 `Native.decide` 之类。这份清单是审计契约里的**允许上界**，实测输出要靠 `#print axioms OAI.VertexCover.every_fixed_factor_below_two` 在 lake 环境里跑，`json` 只声明允许哪三个。我的读法是：`decisionOfGap`（`Approximation.lean:109`）带 `noncomputable` 标记、`coverNumber`（`Basic.lean:28`）也带，这两处是 `Classical.choice` 的可见入口；而 $hsep$ 之后所有实数运算都靠 `field_simp`、`nlinarith`、`exact_mod_cast` 这类 tactic 在 `ℝ`（商类型构造）上做 rewriting，对应前两项。至于 `Basic.lean:28` 的 `noncomputable`：它的定义体看着是可计算的（`Nat.find` 配一份显式见证 $\langle G.n,\texttt{Finset.univ}\rangle$），`[推测]` 标记来自 ambient 的经典性或 `Decidable` 实例解析，我没有逐行确认，也不打算为这条单独跑编译。

`theorem_names` 恰好两项（`:5-6`），`definition_names` 为空（`:8`）。这两项给出审计面的范围：只审两条定理的公理集，不审任何定义。`every_fixed_factor_below_two` 是登记项（`formalization.yaml:1639`）里的那一条，而 `explicit_cover_gap` 只在 json 里作为附加审计项出现，说明比较器把"族存在性"与"任意因子"两条都视作交付物。第 13.3 节那条极大匹配的上界论证（`conclusion.tex:72-81`）没有出现在任何审计面里：机器侧只形式化了硬度方向，`Approximation 2` 这样的正机器与它的 `quality` 证明都在范围外。

`ExplicitGraph` 的形状（`Basic.lean:14-18`）用 `Fin n × Fin n` 的边表加两条良构性字段 `increasing`（每条边左端点严格小于右端点）与 `nodup`（无重复）。这等于把论文的"有限简单无向图"（`introduction.tex:18-19`）编码成上三角规范表：无向性由约定 $e.1<e.2$ 与 `Cover` 的析取（`:23`）共同承担，简单性由 `nodup` 承担，因此不需要额外的对称性证明。`bits`（`:32-35`）把 $n$、$\mathrm{Fin}\ n$ 的全部元素、边表长度与各端点拼成位串，正是 `computation` 字段里机器可比较的编码。`ThreeSAT`（`:10-12`）声明为"存在某公式，其编码解码为 `some formula` 且可满足"，即输入位串必须是良编码这一点被写进谓词，类型层面不做保证。

`Approximation.run` 返回 `List ℕ` 并要求 `nodup` 与 `vertices`（`:60-61`），这两条与 `covers`（`:62`）合起来保证输出的确是一个顶点集；`quality`（`:63`）用 `(run G).length` 与 `coverNumber` 的实数比较。这里有个我一开始以为是冗余的设计：`vertices` 与 `nodup` 都不参与 `decisionOfGap` 的正确性证明，它只用到 `length` 与 `covers`（经由 `coverNumber_le_length`）。我的解释是 `coverNumber_le_length`（`:48`）本身需要"输出是一个覆盖"才能把 `Nat.find` 的最小性与表长连上，而 `covers` 里的 `e.1.val ∈ run G` 又要求表元素是合法编号，于是那两条"冗余"字段其实是 `covers` 的良构前提。

`Main.lean` 里我没法解释的一处形状：`:10-40` 连着 $31$ 行 `section`，`:41` 是一行只含空格的空白，`:42` 再来一条 `section`，共 $32$ 条匿名 `section`，而文件尾部 `:120` 与 `:123-153` 恰好 $32$ 个匿名 `end` 与之配对，`:47` 的 `noncomputable section` 由 `:109` 的 `end` 关闭。这个嵌套围栏对定理内容毫无作用，纯粹是作用域隔离。我猜它是增量编辑的沉积（每加一段机器代码就套一层 `section`，以便 `unfold`、`simp` 的作用域不外泄），`[推测]`，但它留下的后果是真的：$155$ 行的文件里有 $63$ 行是围栏，声明本体只占约 $60$ 行，读这个文件时噪声比信号多。

### 14.4 候选失败路线（d）

`[推测]` 路线一：把顶层定理写成"$\mathrm P\ne\mathrm{NP}\Rightarrow\neg\exists$ 机器"。那需要先形式化 $\mathrm P$、$\mathrm NP$、归约传递与类不等，而本模块选的口径是"给定近似机就造出判定机"的函数式陈述，公理面小、也不需要把 `ThreeSATDecision` 与某个复杂性类挂钩。代价是结论的语感变弱：`Nonempty ThreeSATDecision` 读起来像"存在一台判定 3SAT 的多项式机"，而"NP-hard"这个词在类型里并不出现，它由 `GapReduction` 与 `Approximation` 两个结构体的组合隐式承担。
`[推测]` 路线二：把 $\alpha$ 作为位串输入。要做实数编码与 $m=\lceil\frac{2(\alpha+1)}{2-\alpha}\rceil$ 的可计算上取整，且 $d,p,t$ 都得从"关于 $m$ 的 `def`"变成"关于 $\alpha$ 的可计算函数"，`FiniteAlphabet` 字段里的带字母表也会跟着变。第 13.4 节路线一是同一件事的论文版，机器侧同样撞在 `src:hardness` 只对固定有理 $\sigma$ 供货。
`[推测]` 路线三：用 Mathlib 的 `SimpleGraph` ，并非自建 `ExplicitGraph`。类型层面更贴论文措辞，但 `SimpleGraph` 没有位串编码，也没有把"顶点是 $\mathrm{Fin}\ n$"这种可枚举性写进结构，`computation : TM2ComputableInPolyTime ExplicitGraph.bits construct` 这条字段就没法写；同时 `coverNumber` 需要"顶点集有限且可枚举"来给 `Nat.find` 供见证（`Basic.lean:29-30` 用的是 `Finset.univ : Finset (Fin G.n)`）。这条路线我认为是最先被作者否掉的，因为 `bits`、`increasing`、`nodup` 三处设计都为机器口径服务、对纯图论陈述毫无用处。

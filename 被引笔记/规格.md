# 被引文献笔记规格（`被引笔记/` 一族的唯一口径）

本规格只管一件事：给本语料（`研究笔记/D##-*.md`，下称"语料稿"）引用到的**外部关键论文**写精读笔记。语料稿自身的纪律在 `.tools/spec_other.md`，与本文件互不覆盖。

## 1 这一族是什么

- 素材：从 arXiv 取的原文源码包，解压后落在 `E:\math\被引素材/<id>/`，`<id>` 是把 arXiv id 里的 `/` 换成 `_` 的形式（如 `math_0405285`）。
- 成品：`E:\math\研究笔记被引\C<nn>-<中文题名>.md`（真实目录名 `被引笔记/`），每篇外部论文一份。
- 编号 `C01、C02…` 只在 `被引笔记/INDEX.md` 里领取：一行 = 一个 arXiv id → 一个 `C<nn>` + 文件题名 + 素材路径。**已占用的号不得复用，不得自造新号。**
- 这一族不进语料稿的闸门与普查（全库尺子按 `研究笔记/D*.md` 取），所以结构判据只由本文件与派单规定。

## 2 取材

1. **只读 `被引素材/<id>/` 下的 `.tex`**。压缩包、`.bib`、样式文件（`.sty/.cls`）只用来解释记号，不当内容来源。
2. 目录里的 `.pdf` 只可能是插图或附属图，**不得抽取其中文字作为来源**；若某论文只交到 PDF 而无 `.tex`，在派单里登记"PDF-only"，该篇本轮不写。
3. 位置串必须逐字来自你读过的行，形如 `文件名.tex:123` 或 `文件名.tex:123-140`；带 `sections/` 之类前缀时以盘面真实相对路径为准。**不许凭标题、目录名或记忆推测行号。**
4. 取证调用不超过 10 次读取；单次读取不超过 400 行。

## 3 记法（与语料稿同规）

- 数学跨度用 `$…$`，展示式用 `$$…$$`；一行内 `$` 必须成对。**定界符两侧都要贴紧**：开符后不留空格、闭符前不留空格（`$ x$`、`$x $` 在 KaTeX 的读法里不成跨度，一枚半形会使其后整行的跨度成对错位，普查报成 `Can't use function '$' in math mode`）。
- **KaTeX 是唯一宏凭据**：素材的 `\newcommand` 自定义命令，动笔那一刻就按 preamble 定义写成 KaTeX 认得的写法（如 `\pfour`→`\mathbb P^4`、`\Pic`→`\operatorname{Pic}`）；形义不明就登记不发明。收稿侧会跑 KaTeX 普查，落盘即拒渲的形（如把结构层写作 `\OO_X`，应为 `\mathcal O_X`；命令名吞掉后一个字母的 `\inX` `\toM` 同族）都要回改。
- **AMS 字体梯子不许逐字搬**：素材常见 `\bP`→`{\Bbb P}`、`\Bbb`→`\fam\msbfam\tenmsb`、`\cC`→`{\Cal C}`、`\NE`→`\mathop{\rm NE}\nolimits` 这类由 `\font` 声明的字体形，它们要按族写作 `\mathbb P`／`\mathcal C`／`\mathfrak a`／`\operatorname{NE}`（算子名大小写逐字）。判据是「展开后必须可渲」而不是「抄得逐字」：`\fam`、`\tenmsb`、`\textfont` 这类排版内部名一律不许落进正文，收稿侧的回改尺会把它们退回登记那条路。裸字体开关（不带字形的 `\Bbb`、`\Cal`、`\rm`）没有合法形，写正文时不要单独使用。
- 不抄素材的 `\label{}`／`\ref{}`／`\cite{}`／`\eqref{}` 进正文；要指代定理就用文字（"定理 3.1"）并给位置串。
- 反引号只包代码跨度（含 Lean/TeX 片段）；代码跨度里的 `|` 保持 `\|`，数学跨度里用 `\lvert \rvert \lVert \rVert \mid`。
- 散文口径与语料稿相同：不写"而是""而非""而不是""值得注意""需要指出""换句话说""综上""总体而言"，不用长破折号；一处结论先给数再给判断。
- 落盘禁 CR；中文正文里不要出现内部工具词——脚本名、内部目录与台账名，名单就是这一句反引号里那几枚：`_work/`、`.tools/`、`INDEX.md`、`ccheck.py`、`c_collect.py`、`sweep.py`、`gate_one.py`、`katex_census.js`。取材边界只说"只读素材的 `.tex`，未读 `.pdf` 与编译产物"，不逐枚列举禁读目录；收工报告里的合规项也不把这些词带回正文。

## 4 结构

一份 C 稿依次为：

1. `# C<nn> <中文题名>（arXiv:<id>）` 标题行；
2. `## 0 取证边界`：arXiv id、作者（原文署名逐字）、发表年月、素材目录与主 `.tex` 清单（字节数/行数）、**本语料引用它的稿号与 bib key**、取材薄读之处；
3. `## 1`–`## K` 正文精读，K 取 5–15（2026-10-16 用户定：厚素材按节切细不是缺陷，字节与数学密度达标就照收），节号从 0 起连续、物理排布按编号顺序；每节以"这条论文自己的陈述"为纲：定理/构造/证明要点逐段对齐原文行号，写出关键不等式的推导链，不许只复述摘要；
4. 末节 `## K 与本语料的接缝`：写明该结论被上面哪些语料稿在什么位置使用、用到的记号在 C 稿里如何读。

体量：**每篇不少于 22,000 字节**；一节一笔，单笔新增正文不超过 10,000 字节。

### 4.1 数学优先（本族的优先级，压在结构条款之上）

结构是脚手架，数学才是交付物。字节预算、节数、取证次数三者不够用时，一律保数学：宁可少一节背景、少一段动机，也要把定理的公式与证明骨架写全。

- **主定理逐条给到公式级别**。素材摘要与引言申报的每一条主结果（"定理 A""定理 1.3"这一级），稿内要写出它自己的完整数学陈述：全部假设为 `$…$` 形（半正、 nef、维数、上界常数），结论给到等式/不等式/同构本身，并配位置串。只用中文转述"作者证明了某估计"不合格。
- **推导链要露出中间式**。一条估计从哪一步换成哪一步（Hölder、Nadel 消没、Miyaoka 型、Slobodean 之类的哪一枚），中间式要写成数学，不许只写"由标准估计得"。
- **反例与尖锐例子同规格**：论文自己举的例子要给到具体空间与具体数字（维数、次数、上同调群的秩）。
- 背景、动机、文献综述各写一段即可，不得成节扩张；体量不足 22,000 字节时靠补数学陈述补，不靠加议论。
- 收稿侧的尺子读这些数：数学跨度字节占比、`$…$` 与 `$$…$$` 的枚数、定理/证明级陈述的行数。全族实测占比 32.1%。占比单独低不算缺陷——长段落里逐条推导的稿实测有占比 20.9% 仍带 20 条展示式；**占比低于 25% 且展示式少于 5 条**才判公式级陈述缺失，那种稿要回改补数学。

## 5 落盘

- 新建一份 C 稿允许 **一次 `Write`** 落 `# 标题 + ## 0` 骨架，此后全部用 `Edit` 追加；同一文件不得第二次 `Write`。
- 不得删除、回滚、改写、重排已落盘内容；发现自己前笔写错，只在后一笔里更正并申报。
- 每份稿子收工前自查并在报告里给数：字节、行数、CR、全文 `$` 总数（偶）、反引号数（偶）、小节数与编号连续、逐笔实测字节、取证次数、`Write` 次数，以及数学跨度枚数与数学字节占比（4.1 那条尺子）。
- **C 稿不改语料稿**：语料稿侧的回引（在 `研究笔记/D##-*.md` 里加指向 C 稿的一节）由本体侧统一执行，写手不碰。

## 1 综述与基本记号

论文围绕高维各向同性对数凹测度的 Cheeger 常数 $G_n$ 给出两条主结果，第一条把 $G_n$ 用各阶薄壳常数 $\sigma_k$ 的累积和控住，第二条把 Brunn-Minkowski 不等式从「等号成立当且仅当平移」推进到「差 $V-1$ 越小时 $K,T$ 的形心偏差越紧」，两条证明的核心工具是同一套随机局部化方案。

- 各向同性对数凹：测度 $\mu$ 在 $\mathbb{R}^n$ 上，称其各向同性当且仅当 $\int x \, d\mu(x) = 0$ 且 $\int (x-b(\mu)) \otimes (x-b(\mu)) \, d\mu(x) = I_n$。`main.tex:64-71`。
- 对数凹密度的形式：$\rho(x) = e^{-H(x)}$，$H: \mathbb{R}^n \to \mathbb{R}\cup\{\infty\}$ 凸，$\int \rho = 1$。`main.tex:56-67`。
- Minkowski 边界测度：$\mu^+(A) = \liminf_{\varepsilon \to 0^+} [\mu(A_\varepsilon) - \mu(A)]/\varepsilon$，$A_\varepsilon$ 为 $A$ 的 $\varepsilon$-扩张。`main.tex:73-82`。
- Cheeger 常数（亦称最优逆 Cheeger 常数）：$G_n^{-1} := \inf_\mu \inf_A \mu^+(A) / \mu(A)$，外层下确界取所有各向同性对数凹测度 $\mu$，内层下确界取所有 Borel 集 $A \subset \mathbb{R}^n$ 且 $\mu(A) \leq 1/2$。`main.tex:84-88`。
- Poincaré 谱隙等价：存在通用常数 $C>0$ 使 $\frac{1}{C} G_n^2 \leq \sup_\mu \sup_\varphi \frac{\int \varphi^2 \, d\mu}{\int |\nabla \varphi|^2 \, d\mu} \leq C G_n^2$，$\varphi$ 取遍满足 $\int \varphi \, d\mu = 0$ 的光滑函数，`main.tex:90-95`（即 Ledoux 的等价，[Survey of Differential Geometry IX, 2004]）。本文简称「谱隙」即指此 Poincaré 常数。
- 薄壳常数：对各向同性对数凹随机向量 $X$，$\sigma_n^2 := \sup_X \mathbb{E}[(|X| - \sqrt{n})^2]$。`main.tex:103-107`。
- 中间常数 $K_n$：$K_n^2 := \sup_X \sup_{\theta \in S^{n-1}} \sum_{i,j=1}^n \mathbb{E}[X_i X_j \langle X, \theta \rangle]^2$。`main.tex:163-169`。
- Brunn-Minkowski 不等式：紧集 $K, T \subset \mathbb{R}^n$ 满足 $\mathrm{Vol}_n((K+T)/2) \geq \sqrt{\mathrm{Vol}_n(K) \mathrm{Vol}_n(T)}$，$K, T$ 闭凸时等号当且仅当二者互为平移。`main.tex:200-208`。

## 2 第一主定理：薄壳蕴含谱隙

### 2.1 主定理 A

存在通用常数 $C>0$，使对一切 $n \geq 2$ 都有

$$
G_n \leq C \sqrt{(\log n) \sum_{k=1}^n \frac{\sigma_k^2}{k}}.
$$

`main.tex:134-140`。若 $\sigma_n \leq n^{\kappa}$，结论化为 $G_n \leq C \sqrt{\log n} \cdot n^{\kappa}$；若薄壳猜想 $\sigma_n \leq C$ 成立，则 $G_n \leq C \sqrt{\log n}$。

### 2.2 中间命题：$G_n$ 受 $K_n$ 控制

存在通用常数 $C>0$，使对一切 $n \geq 2$ 都有

$$
G_n \leq C K_n \sqrt{\log n}.
$$

`main.tex:181-186`。这条是主定理 A 的「对数因子」剥离：把 $K_n$ 换成 $\sigma$ 的累积和才出现 $\sqrt{\log n}$ 之外的依赖。

### 2.3 中间引理：$K_n$ 由 $\sigma$ 的累积和给出

存在通用常数 $C>0$，使

$$
K_n \leq C \sqrt{\sum_{k=1}^n \frac{\sigma_k^2}{k}}.
$$

`main.tex:173-178`。证明见 §6 中 `ksigma` 引理的对角线逼近，依赖 $K_n$ 的谱分解与方差递推。

### 2.4 $K_n$ 的几何意义

`main.tex:188-196`：$K_n^{-1} \geq c \inf_\mu \inf_E \mu^+(E)/\mu(E)$，$E$ 仅取所有各向同性对数凹测度下的椭球 $E$ 且 $\mu(E) \leq 1/2$。这说明主定理 A 等价于「控制所有 Borel 集 $A$」可被「只控制椭球 $E$」代替（只多 $\sqrt{\log n}$ 因子），即论文题目里「thin shell implies spectral gap up to polylog via a stochastic localization scheme」的几何面。

### 2.5 推论与已有界的衔接

- 用目前 $\sigma_n \leq C n^{1/3}$（Guedon-Milman, 2010）代入主定理 A 得到 $G_n \leq C n^{1/3} \sqrt{\log n}$，改进了此前由 $G_n \leq C n^{5/12}$（Guedon-Milman 与 Bobkov, 2007 推论）得到的界。`main.tex:142-148`。
- 与 Bobkov 估计 `main.tex:154-160` 的对比：Bobkov 的不等式 $\mathrm{Var}[\varphi(X)]/\mathbb{E}[|\nabla \varphi(X)|^2] \leq C \mathbb{E}[|X|] \sqrt{\mathrm{Var}[|X|]}$ 在薄壳假设下推得 $G_n \leq C n^{1/4}$；主定理 A 用同假设把指数从 $1/4$ 降到 $0$（对数修正）。
- 与 Klartag-Eldan 2011 [Proc. Workshop on Concentration, 55-68] 的关系在 `main.tex:149-153`：共享一族工具但侧重不同；与 Ball-Nguyen 同期 preprint 的关系：`main.tex:152` 给出谱隙 → 各向同性常数的指数型界，但与本结果正交。
- 与 Klartag 首篇薄壳界 $\sigma_n \leq C \sqrt{n}/\log(n+1)$（Invent. Math. 168, 2007）的串联见 `main.tex:120`；后续 Klartag 2007 J. Funct. Anal. 245、Fleury 2010 J. Funct. Anal. 259、Guedon-Milman 2010 均给出 $\sigma_n$ 的多项式上界。

## 3 随机局部化方案的构造

### 3.1 紧支撑化简

`main.tex:292-296`：把任意各向同性对数凹随机向量 $X$ 用 Klartag 2007 J. Funct. Anal. 245 第 2 节的集中界替换成支集落在 $n B_n$（$B_n$ 为单位 Euclidean 球）的版本，整个证明均在该紧支撑假设下进行；最后的常数经对支集的局部化处理保持通用。

### 3.2 三个基本函数

设 $c \in \mathbb{R}^n$、$B$ 为 $n\times n$ 矩阵，定义

$$
V_f(c, B) = \int_{\mathbb{R}^n} e^{\langle c, x \rangle - \frac{1}{2} \langle B x, x \rangle} f(x) \, dx,
$$

$$
a_f(c, B) = V_f(c, B)^{-1} \int_{\mathbb{R}^n} x \, e^{\langle c, x \rangle - \frac{1}{2} \langle B x, x \rangle} f(x) \, dx,
$$

$$
A_f(c, B) = V_f(c, B)^{-1} \int_{\mathbb{R}^n} (x - a_f(c, B)) \otimes (x - a_f(c, B)) \, e^{\langle c, x \rangle - \frac{1}{2} \langle B x, x \rangle} f(x) \, dx.
$$

`main.tex:298-309`。紧支撑假设保证它们是 $c, B$ 的光滑函数。$a_f$、$A_f$ 分别解释为重整化密度 $f(x) e^{\langle c, x\rangle - \frac{1}{2}\langle Bx, x\rangle}/V_f(c, B)$ 的「重心」与「协方差」。

### 3.3 SDE 定义 $(c_t, B_t)$

设 $W_t$ 为标准 Wiener 过程，$(c_t, B_t)$ 服从

$$
c_0 = 0, \qquad d c_t = A_f(c_t, B_t)^{-1/2} dW_t + A_f(c_t, B_t)^{-1} a_f(c_t, B_t) \, dt,
$$

$$
B_0 = 0, \qquad d B_t = A_f(c_t, B_t)^{-1} \, dt.
$$

`main.tex:311-317`。由于 $A_f(c, B)$ 对一切 $c, B$ 正定且 $A_f, a_f$ 光滑，依 Oksendal《Stochastic Differential Equations》第 5.2 节的常微分方程存在唯一性定理，`main.tex:318-320`，SDE 在某区间 $0 \leq t \leq t_0$（$t_0 > 0$ a.s.）内有强解。

### 3.4 重整化密度 $f_t = \Gamma_t(f)$

定义

$$
F_t(x) = V_f(c_t, B_t)^{-1} e^{\langle c_t, x \rangle - \frac{1}{2} \langle B_t x, x \rangle},
$$

$$
f_t(x) = \Gamma_t(f)(x) := f(x) F_t(x).
$$

`main.tex:321-333`。记 $a_t = a_f(c_t, B_t)$、$A_t = A_f(c_t, B_t)$、$V_t = V_f(c_t, B_t)$。

### 3.5 关键引理：连续局部化的随机微分

$f_t$ 满足

$$
F_0(x) = 1, \qquad d F_t(x) = \langle x - a_t, A_t^{-1/2} dW_t \rangle F_t(x),
$$

$$
a_t = \int_{\mathbb{R}^n} x f(x) F_t(x) \, dx, \qquad A_t = \int_{\mathbb{R}^n} (x - a_t) \otimes (x - a_t) f(x) F_t(x) \, dx.
$$

`main.tex:336-345`。证明分三步：先对 $G_t(x) = V_t F_t(x)$ 用 Itô 公式，注意 $[B]_t = 0$ 抵消 $-\frac{1}{2}\langle dB_t x, x\rangle$ 项，得 $d G_t(x) = \langle x, A_t^{-1/2} dW_t + A_t^{-1} a_t dt \rangle G_t(x)$，`main.tex:360-378`；再对 $V_t$ 用 Itô 公式算出 $d V_t^{-1}$；最后一次 Itô 应用合并两者得 $d F_t(x) = \langle A_t^{-1/2} dW_t, x - a_t \rangle F_t(x)$，`main.tex:387-402`。

### 3.6 局部化的基本性质

`main.tex:417-429`，引理 basic1：

- (i) $f_t$ 几乎必然对一切 $t > 0$ 良定、有限、对数凹；
- (ii) $\int f_t \, dx = 1$（直接由 $\langle x - a_t, A_t^{-1/2} dW_t\rangle$ 在 $f_t$ 意义下为零得到，`main.tex:447`）；
- (iii) 半群性质 $\Gamma_{s+t}(f) \sim \frac{1}{\sqrt{\det A_s}} \Gamma_t(\sqrt{\det A_s} \Gamma_s(f) \circ L^{-1}) \circ L$，$L(x) = A_s^{-1/2}(x - a_s)$，`main.tex:422-427`；
- (iv) $f_t(x)$ 对每个 $x$ 是鞅。

(i) 与 $t_0 = \infty$ 的论证由 basic1.5（见 §6）保证：每发生一次 $\|A_t^{-1}\|_{OP}$ 触底 $c^{-1}(n)$，下次再触底至少要等 $c(n)$，`main.tex:474-484`。

### 3.7 重心路径

`main.tex:487-497`：由 (ii) 的鞅性与 $d F_t(x)$ 的公式，

$$
d a_t = d \int_{\mathbb{R}^n} x f(x) F_t(x) \, dx = \int_{\mathbb{R}^n} x f(x) F_t(x) \langle x - a_t, A_t^{-1/2} dW_t \rangle \, dx = A_t^{1/2} dW_t.
$$

第三步用 $a_t$ 的定义消掉 $a_t \otimes (x-a_t)$ 项。这说明重心 $a_t$ 走一条 $A_t^{1/2}$ 控制扩散系数的 Itô 过程，控制 $A_t$ 的谱是控制 $a_t$ 漂移的关键。

### 3.8 Gaussian 例子

`main.tex:589-624`：取 $f(x) = (2\pi)^{-n/2} e^{-|x|^2/2}$，则 $B_t = (e^t - 1) I_n$，$A_t = e^{-t} I_n$，$a_t \sim W_{1 - e^{-t}}$，$f_t = e^{nt/2}(2\pi)^{-n/2} e^{-\frac{1}{2} e^t |x - W_{1-e^{-t}}|^2}$。这一步给出直观：局部化过程把原测度按指数速度 $e^t$ 集中到一条 Ornstein-Uhlenbeck 路径。

### 3.10 与 Lehec 表示式的区别

`main.tex:583-587`：Lehec (arXiv:1006.3028, 2010) 的方案用加性漂移让局部化收敛到给定对数凹测度；本构造用 $A_t$（即乘性协方差）控制收敛路径。两条路线同源但实现的极限机制不同，本文的优势在 §4 的矩阵 $A_t$ 估计。

## 4 协方差矩阵 $A_t$ 的分析

### 4.1 朴素上界

`main.tex:566-572`：把 Bakry-Emery 命题 `main.tex:503-521` 应用于 $f_t$ 的形式 $e^{-\frac{1}{2} |B_t^{1/2} x|^2} f(x)/V_t$（对数凹权重），得

$$
A_t \leq \Theta \|B_t^{-1}\|_{OP} I_n \leq \Theta \left( \int_0^t \frac{ds}{\|A_s\|_{OP}} \right)^{-1} I_n,
$$

再用紧支撑 $\|A_t\|_{OP} \leq n^2$ 代入得 $A_t \leq \Theta n^2/t \cdot I_n$。这一条给出后验 $W_2(f_t, \delta_{a_t}) \to 0$（`main.tex:579-582`），即 $a_t$ 的 Wasserstein 极限等于 $X$ 本身，但指数衰减常数 $n^2$ 远不够用。

### 4.2 主命题 mainsec3

`main.tex:629-645`：

- (i) 存在通用常数 $C, c>0$，令事件 $F := \{\|A_t\|_{OP} < C K_n^2 (\log n) e^{-ct}, \forall t>0\}$，则 $\mathbb{P}(F) \geq 1 - n^{-10}$。
- (ii) 对一切 $t>0$，$\mathbb{E}[\mathrm{Tr}(A_t)] \leq n$。
- (iii) 当 $F$ 成立且 $t > 1/(K_n^2 \log n)$，存在凸函数 $\phi_t$ 使

$$
f_t(x) = \exp\left( -\left| \frac{x}{C K_n \sqrt{\log n}} \right|^2 - \phi_t(x) \right).
$$

(ii) 是 $S_t = \mathrm{Tr}(\tilde A_t^p)$ 在 $p=1$ 时 $\frac{d}{dt}\mathbb{E}[S_t]=0$ 的直接推论（`main.tex:878-879`）。

### 4.3 $A_t$ 的微分与上界控制

`main.tex:649-708`：用 Itô 公式与 (3.5) 的 $d F_t(x)$，记 $\tilde A_t = A_t + \int_0^t A_s \, ds$，有 $d \tilde A_t$ 写成「协方差-方向-Itô 三阶矩」的随机积分，$\tilde A_t \geq A_t$；取 $\tilde A_t$ 对角化基 $v_1, \ldots, v_n$ 后定义

$$
\xi_{i,j} = \frac{1}{\sqrt{\alpha_{i,i} \alpha_{j,j}}} \int_{\mathbb{R}^n} \langle x, v_i\rangle \langle x, v_j\rangle A_t^{-1/2} x \, f_t(x + a_t) \, dx,
$$

得 $d \alpha_{i,j} = \sqrt{\alpha_{i,i} \alpha_{j,j}} \langle \xi_{i,j}, dW_t\rangle$ 与 $\frac{d}{dt}[\alpha_{i,j}]_t = \alpha_{i,i} \alpha_{j,j} |\xi_{i,j}|^2$。

### 4.4 $\xi_{i,j}$ 的两阶估计

`main.tex:713-748`，引理 xibounds：

- (i) $|\xi_{i,i}| < C$（用 Cauchy-Schwartz 与对数凹各向同性测度的 $p$ 阶矩一致上界 `main.tex:737-740`，即 Lovász-Vempala 2007 RSA 30 引理 5.7）；
- (ii) $\sum_{j=1}^n |\xi_{i,j}|^2 \leq K_n^2$（直接由 $K_n^2$ 的定义）。

### 4.5 $S_t = \mathrm{Tr}(\tilde A_t^p)$ 的鞅分解

`main.tex:752-812`：取固定 $p$，$S_t = \sum \alpha_{j_1,j_2} \cdots \alpha_{j_p,j_{p+1}}$ 是 Itô 过程，分两类微分项：

- 第一类（全对角 $\alpha_{i,i}^p$）：$d \alpha_{i,i}^p = p \alpha_{i,i}^p \langle \xi_{i,i}, dW_t\rangle + p(p-1)\alpha_{i,i}^p |\xi_{i,i}|^2 dt$；
- 第二类（一对非对角 $\alpha_{i,j}, \alpha_{j,i}$ 出现两次）：$d((\alpha_{i,i})^k (\alpha_{j,j})^{p-k-2} \alpha_{i,j}^2) \leq \alpha_{i,i}^p |\xi_{i,j}|^2 dt$。

合起来得 $d S_t \leq \sum_i p \alpha_{i,i}^p \langle \xi_{i,i}, dW_t\rangle + p^2 S_t K_n^2 dt$，于是漂移项 $dE_t/dt \leq p^2 K_n^2 S_t$，二次变差 $d[S]_t/dt \leq C p^2 S_t^2$。

### 4.6 反射原理与对数鞅

`main.tex:813-845`：分解 $\log S_t = Y_t + Z_t$，$Y_t$ 局部鞅、$Z_t$ 有界变差；$d[Y]_t/dt \leq C p^2$。由 Dambis-Dubins-Schwarz 定理把 $Y_t$ 嵌入到 $W_{[Y]_t}$，反射原理给出 $\mathbb{P}(\max_{t \in [0, p]} \tilde W_t \geq C_1 p) < e^{-10 p}$。取 $t = 1/p$，得 $\mathbb{P}(\max_{t \in [0, 1/(K_n^2 p)]} \log S_t - \log n > C p) < e^{-10 p}$。取 $p = \lceil \log n \rceil$ 得 $\mathbb{P}(\max_{t \in [0, 1/(K_n^2 \log n)]} S_t^{1/\lceil \log n \rceil} > C') < n^{-10}$。

### 4.7 $F$ 事件的推论

`main.tex:847-879`：在 $F^c$ 的补事件下，对 $t \in [0, 1/(K_n^2 \log n)]$ 都有 $\|A_t\|_{OP} \leq C'$；再用 (4.1) 的 $\|B_t^{-1}\|_{OP}^{-1}$ 演化给出 $\|B_t^{-1}\|_{OP}^{-1} \geq c \delta^2$（$t = \delta^2 = 1/(K_n^2 \log n)$），推出 $B_t \geq c \delta^2 e^{(t-\delta^2)/\Theta} I_n$，$A_t \leq C \delta^{-2} e^{(\delta^2 - t)/\Theta} I_n$。这就把 $\|A_t\|_{OP}$ 的上界从 (4.1) 的 $\Theta n^2/t$ 改进到 $C K_n^2 \log n \cdot e^{-ct}$。

### 4.8 推论 goodcheeger

`main.tex:884-897`：当 $F$ 成立时取 $\delta = 1/(K_n \sqrt{\log n})$，$t > \delta^2$，任何满足 $0.1 \leq \int_E f_t(x)\,dx \leq 0.9$ 的可测集 $E$ 都有 $\int_{E_{\Theta/\delta} \setminus E} f_t(x) \, dx \geq c$，$E_{\Theta/\delta}$ 是 $E$ 的 $\Theta/\delta$-扩张。这是把 Cheeger 型下界从「任意 Borel 集」搬到「$E$ 测度离开 $0$ 与 $1$」的关键。

### 4.9 $g(t) = \int_E f_t(x) \, dx$ 的方差界

`main.tex:924-969`，引理 gtbound：存在通用常数 $T>0$，使

$$
\mathbb{P}(0.1 \leq g(t) \leq 0.9) > 0.5, \quad \forall t \in [0, T].
$$

证明用 $d g(t) = \langle \int_{E_t} y \tilde f_t(y) \, dy, dW_t \rangle$（$\tilde f_t$ 是 $f_t$ 的各向同性重整化版本），并由各向同性得出 $|\int_{E_t} y \tilde f_t(y) \, dy| \leq 1$，从而 $d[g]_t/dt \leq 1$；$h(t) = (g(t)-0.5)^2$ 的 Itô 公式给出 $\mathbb{E}[(g(t)-0.5)^2] \leq t$，Chebyshev 即得。

### 4.10 E. Milman 定理与主命题 gk 的终结

`main.tex:972-980`：E. Milman 定理（Contemp. Math. 545，Florida 2009 workshop）：设对数凹 $\mu$ 满足存在 $0 < \lambda < 1/2$、$\Theta > 0$，使 $\mu(E) \geq 1/2$ 时 $\mu(E_\Theta) \geq 1 - \lambda$，则 $\mu^+(E)/\mu(E) \geq (1 - 2\lambda)/\Theta$，对所有 $\mu(E) \leq 1/2$ 的 $E$ 成立。

`main.tex:982-997`：把事件 $G := \{0.1 \leq g(T) \leq 0.9\} \cap F$ 由 gtbound 与 mainsec3 (i) 联合得 $\mathbb{P}(G) > 0.4$；再用 goodcheeger 与 martlocE 公式（`main.tex:914`）$\int_{E_{\Theta/\delta} \setminus E} f(x) \, dx = \mathbb{E}[\int_{E_{\Theta/\delta} \setminus E} f_T(x) \, dx]$，对条件期望用 Milman 定理即得 $G_n \leq C K_n \sqrt{\log n}$，命题 gk 证毕。

### 4.11 Bobkov 与 Bakry-Emery 的替代路线

`main.tex:998-1000`：若用 Bakry-Emery 1983/84（Sém. Prob. XIX, LNM 1123, 177-206）的超压缩结果替换 Bakry-Emery 命题，可直接对 $f_t$ 取 Cheeger 常数，避免 gtbound 的 Chebyshev 步骤，但路径要求 hypercontractivity ，并非纯 log-concavity。

## 5 第二主定理：Brunn-Minkowski 不等式的稳定性

### 5.1 指数 $\kappa$ 与慢变因子 $\tau_n$

`main.tex:221-225`：记

$$
\kappa := \liminf_{n \to \infty} \frac{\log \sigma_n}{\log n}, \qquad \tau_n := \max\left(1, \max_{1 \leq j \leq n} \frac{\sigma_j}{j^\kappa} \right),
$$

则 $\sigma_n \leq \tau_n n^\kappa$。薄壳猜想蕴含 $\kappa = 0$、$\tau_n < C$。

### 5.2 主定理 B（mainthm2）

`main.tex:227-240`：对每个 $\epsilon > 0$，存在常数 $C(\epsilon)$，使对任意 $\mathrm{Vol}_n = 1$、形心在原点、协方差为 $L_K I_n$ 的凸体 $K, T$，记

$$
V = \mathrm{Vol}_n\left( \frac{K + T}{2} \right), \qquad \delta = C(\epsilon) L_K V^5 \tau_n n^{2(\kappa - \kappa^2) + \epsilon},
$$

则

$$
\mathrm{Vol}_n(K_\delta \cap T) \geq 1 - \epsilon.
$$

$K_\delta$ 是 $K$ 的 $\delta$-扩张。此估计的核心是把 $V$ 与 $\|K \Delta T\|_{W_2}$ 用 $\tau_n, \kappa, n$ 量化，并依赖 §4 的 $A_t$ 估计把 $\sigma_n$ 的偏差传到 BM 稳定的指标。

### 5.3 与已有稳定性结果的衔接

- Klartag-Eldan 2011 (Annali SNS) 给出 $\delta = C(\epsilon) \sqrt{\tau_n} n^{1/4 + \kappa/2} V^{5/2}$（`main.tex:243-248`）。当 $\kappa \geq 1/4$ 时本结果弱于该上界；当 $\kappa < 1/4$（特别是 $\kappa = 0$，即薄壳猜想成立）时本结果显著更强。
- Guedon-Milman 的 $\sigma_n \leq C n^{1/3}$ 代入得 $\kappa = 1/3$，$\tau_n \leq C$，于是 $\delta = C(\epsilon) n^{4/9 + \epsilon} V^5 L_K$（`main.tex:251-255`）。注意不要求 $K, T$ 协方差相同时最好的界是 $\delta = C \sqrt{n} L_K$（以 cube 对 ball 为反例）。
- 与 Figalli-Maggi-Pratelli 2010 (Invent. Math. 182) 的对比见 `main.tex:257-265`：FMP 给出 $\mathrm{Vol}_n((K+x_0) \Delta T)^2 \leq n^7 (\mathrm{Vol}_n((K+T)/2) - 1)$，在 $V \to 1$ 极限下比本结果更强；但本结果在 $V = 10$ 这样的远离极限处仍能给出非平凡下界，两条路径互补。

### 5.4 紧化与基本量 $K(f, g)$

`main.tex:1014-1026`：对两概率密度 $f, g: \mathbb{R}^n \to \mathbb{R}^+$，定义上确界卷积

$$
H(f, g)(x) := \sup_{y \in \mathbb{R}^n} \sqrt{f(x+y) g(x-y)},
$$

以及 $K(f, g) := \int_{\mathbb{R}^n} H(f, g)(x) \, dx$。对凸体 $K, T$，归一化为 $f(x) = \mathbf{1}_{K/L_K}(x) L_K^n$、$g(x) = \mathbf{1}_{T/L_K}(x) L_K^n$，$f$ 各向同性，$K(f, g) = V$（`main.tex:1276`）。

### 5.5 引理 transportation：协方差特征值的夹逼

`main.tex:1028-1042`：存在通用常数 $C, C_1$，使对各向同性 $f$、对数凹 $g$（重心在原位），若 $A = \mathrm{Cov}(f)^{-1/2} \mathrm{Cov}(g) \mathrm{Cov}(f)^{-1/2}$ 的特征值按 $|\delta_i - 1|$ 降序排，则

$$
|\delta_i - 1| \leq C K(f, g)^4, \quad \forall 1 \leq i \leq n,
$$

$$
|\delta_i - 1| \leq C K(f, g) \tau_n i^{\kappa - 1/2}, \quad \forall (\log K(f, g))^{C_1} \leq i \leq n.
$$

证明是 Klartag-Eldan 2011 引理 6.5 的改写，依赖 supremum convolution 的对数凹乘积性质（薄壳给出大 $i$ 处的尖锐度，平凡 $\leq 4$ 次方给出所有 $i$ 的粗糙界）。

### 5.6 引理 mainlemmasec5：耦合 Wasserstein 距离

`main.tex:1046-1058`：存在密度 $\tilde f, \tilde g$ 满足

$$
\tilde f(x) \leq f(x), \quad \tilde g(x) \leq g(x), \quad \forall x,
$$

$$
\int_{\mathbb{R}^n} \tilde f = \int_{\mathbb{R}^n} \tilde g \geq 1 - \epsilon,
$$

$$
W_2(\tilde f, \tilde g) \leq \frac{C}{\epsilon^6} \tau_n K(f, g)^5 n^{2(\kappa - \kappa^2) + \epsilon}.
$$

证明要点（`main.tex:1060-1258`）：对 $f, g$ 同时跑 §3 的局部化过程（共用同一 $W_t$），并用第三过程 $h_t(x) = H_t(x) H(f, g)(x)$ 插值；Itô 公式给出 $2 d \log h_t(x) \geq d \log f_t(x+y) + d \log g_t(x-y)$，从而 $h_t \geq H(f_t, g_t)$；令 $S_t = \int h_t$，由 Dambis-Dubins-Schwarz + Doob 最大值不等式定义 $G_t := \{\max_{s \leq t} S_s \leq 2K(f,g)/\epsilon\}$，$\mathbb{P}(G_t) \geq 1 - \epsilon/2$；与 §4 的 $F_t$ 求交得 $E_t := G_t \cap F_t$，$\mathbb{P}(E_t) > 1 - \epsilon$。

将 $\tilde f_T(x) dx = \mathbb{E}[\mathbf{1}_{E_T} f_T(x) dx]$、$\tilde g_T$ 类似定义，构造耦合 $\mu_T(A \times B) = \mathbb{E}[\mathbf{1}_{E_T} \int_{A\times B} f_T(x) g_T(y) dx dy]$，则 $W_2(\tilde f_T, \tilde g_T) \leq (\mathbb{E}[\mathbf{1}_{E_T} |a_T - b_T|^2])^{1/2}$（`main.tex:1169`）。

接着 $d a_t = A_t^{1/2} dW_t$、$d b_t = C_t A_t^{-1/2} dW_t$，$C_t$ 是 $g_t$ 的协方差矩阵（`main.tex:1175-1188`）；分解 $|a_t - b_t|^2 = M_t + N_t$ 后 $d N_t / dt = \|A_t^{1/2}(I - A_t^{-1/2} C_t A_t^{-1/2})\|_{HS}^2$。由 Tam (Linear Algebra Appl. 272, 1998, 91-101) 的迹不等式 $\|D_t\|_{HS}^2 \leq \sum \lambda_j \delta_j^2$（`main.tex:1210-1212`）；代入 transportation 引理 $\delta_j \leq C K(f_t, g_t)^5 \tau_n j^{\kappa}/\sqrt{j}$，再用 Hölder 不等式（指数 $1/(1-\alpha)$ 与 $\alpha$，$\alpha > 1 - 2\kappa$），合起来得

$$
\mathbb{E}[\|D_t\|_{HS}^2] \leq \frac{C'}{\epsilon} K(f,g)^{10} \tau_n^2 \max(\beta, 1) \lambda_1^{1-2\kappa+\epsilon} n^{2\kappa} e^{-t},
$$

$\beta = (1/n)\sum \lambda_j$；再以 (ii) 中 $\mathbb{E}[\beta] \leq 1$、$\lambda_1 \leq C \tau_n^2 n^{2\kappa} \log n$（事件 $F$ 下）、$K(f_t, g_t) \leq 2 K(f, g)/\epsilon$ 代入，得

$$
W_2(\tilde f_T, \tilde g_T)^2 \leq \mathbb{E}\left[ \int_0^{T \wedge \rho} \|D_s\|_{HS}^2 ds \right] \leq \frac{C}{\epsilon^{11}} K(f,g)^{10} \tau_n^2 n^{4\kappa - 4\kappa^2 + \epsilon}.
$$

注意：此条上界包含 $n^{4\kappa - 4\kappa^2}$ 而 mainthm2 用的是 $n^{2(\kappa - \kappa^2)}$，因为取 $\tilde f, \tilde g$ 是 $(\tilde f, \tilde g)$ 重新赋范后的版本。

### 5.7 mainthm2 的最终化简

`main.tex:1267-1306`：取 $f, g$ 为 §5.4 的形式，由 mainlemmasec5 得 $\tilde f, \tilde g$ 使 $W_2(\tilde f, \tilde g) \leq \Theta$，$\Theta = C(\epsilon) V^5 \tau_n n^{2(\kappa - \kappa^2) + \epsilon}$；因 $\tilde g$ 的支集落在 $T$，有 $\int_K d^2(x, T/L_T) \tilde f(x) \, dx \leq \Theta^2$；记 $K_\alpha = \{x \in K/L_K : d(x, T) \geq \alpha \Theta\}$，Markov 不等式给出 $\mathrm{Vol}_n(K_\alpha) \leq L_K^{-n}(\epsilon + 1/\alpha^2)$；取 $\delta = L_K \Theta/\sqrt{\epsilon}$，得 $\mathrm{Vol}_n(K \setminus T_\delta) \leq 2\epsilon$。改用阈值等价表述就是 mainthm2。

## 6 收尾：K_sigma 引理与 basic1.5 的证明

### 6.1 ksigma 引理证明

`main.tex:1310-1343`：给定各向同性对数凹 $X \in \mathbb{R}^n$ 与 $\theta \in S^{n-1}$，记 $A = \mathbb{E}[X \otimes X \langle X, \theta \rangle]$，目标是 $\|A\|_{HS}^2 \leq C \sum_{k=1}^n \sigma_k^2/k$。

对 $k \leq n$，取 $k$ 维子空间 $E_k$，$P(X) = \mathrm{Proj}_{E_k}(X)$，$Y = |P(X)| - \sqrt{k}$，由 $\sigma_k$ 定义 $\mathrm{Var}[Y] \leq \sigma_k^2$。各向同性给出 $\mathbb{E}[|P(X)|^2] = k$，从而 $\mathrm{Var}[|P(X)|^2] \leq C k \mathrm{Var}[Y] \leq C k \sigma_k^2$。Cauchy-Schwartz 得

$$
|\mathbb{E}[\langle X, \theta\rangle |P(X)|^2]| \leq \sqrt{\mathrm{Var}[\langle X, \theta\rangle] \mathrm{Var}[|P(X)|^2]} \leq C \sqrt{k} \sigma_k,
$$

即 $|\mathrm{Tr}[\mathrm{Proj}_{E_k} A \mathrm{Proj}_{E_k}]| \leq C \sqrt{k} \sigma_k$。令 $\lambda_1, \ldots, \lambda_\ell$ 为 $A$ 的非负特征值（降序），上一行说明 $\mathrm{Proj}_{E_k} A \mathrm{Proj}_{E_k}$ 至少有一个特征值 $\leq C \sqrt{1/k} \sigma_k$；取 $E_k$ 为前 $k$ 个对应特征向量张成的子空间，得 $\lambda_k^2 < C \sigma_k^2/k$（$k \leq \ell$）；负特征值 $\zeta_k$ 同理。最后 $\|A\|_{HS}^2 = \sum_{k=1}^\ell \lambda_k^2 + \sum_{k=1}^{n-\ell} \zeta_k^2 \leq 2C \sum_{k=1}^n \sigma_k^2/k$。

### 6.2 $Q_n$ 与 $R_n$ 的关系

`main.tex:1345-1375`：定义

$$
Q_n^2 := \sup_{X, Q} \frac{\mathrm{Var}[Q(X)]}{\mathbb{E}[|\nabla Q(X)|^2]}, \quad R_n^{-1} := \inf_{\mu, E} \frac{\mu^+(E)}{\mu(E)},
$$

$Q$ 取遍所有二次型，$E$ 取所有椭球 $\mu(E) \leq 1/2$。存在 $C_1, C_2$ 使 $K_n \leq C_1 Q_n \leq C_2 R_n$。证明 $K_n \leq C Q_n$：固定各向同性对数凹 $X$，$A = \mathbb{E}[X \otimes X X_1]$，对角化 $B = \mathrm{diag}\{a_1, \ldots, a_n\}$、$Q(x) = \langle Bx, x\rangle$，

$$
\mathrm{Tr}(BA) = \mathbb{E}[X_1 \sum_i a_i X_i^2] \leq \sqrt{\mathbb{E}[X_1^2] \mathrm{Var}[\sum_i a_i X_i^2]} = \sqrt{\mathrm{Var}[Q(X)]} \leq \sqrt{2 Q_n^2 \sum a_i^2 \mathbb{E}[X_i^2]} = \sqrt{2} Q_n \|B\|_{HS},
$$

故 $\|A\|_{HS} \leq \sqrt{2} Q_n$；$K_n$ 由 $\|A\|_{HS}$ 的 sup 给出，$K_n \leq C Q_n$。$Q_n \leq C R_n$ 用 coarea 公式与 Cauchy-Schwartz 得到。

### 6.3 basic1.5 引理证明

`main.tex:1381-1470`：维数 $n$ 给定，常数 $c, c_1, \ldots$ 都可依赖 $n$。

- 步骤一（`main.tex:1383-1406`）：由 Lovász-Vempala 2007 RSA 30 定理 5.14，存在 $c_1, c_2$ 使 $f(x) \geq c_1$ 在 $|x| \leq c_2$；取 $g(x) = c_1 \mathbf{1}_{\{|x|\leq c_2\}}$。又由该书引理 5.7，存在 $c_3, c_4$ 使 $\int e^{\langle x, y\rangle} f(x) \, dx \leq c_3$ 对 $|y| < c_4$ 成立；从而 $V_f(c, B) \leq c_3$ 对 $|c| < c_4$、$B \leq I_n$。代入得 $A_f(c, B) \geq c_5 I_n$ 对某 $c_5 > 0$。

- 步骤二（`main.tex:1407-1432`）：定义停止时 $T_1 = \sup\{t > 0 : |c_t| < c_4\}$、$T_2 = \sup\{t > 0 : B_t \geq I_n\}$、$T = \min(T_1, T_2)$；在事件 $E = \{T_2 \leq T_1\}$ 上，$T_2 \geq c_5$，从而 $T \geq c_5$。

- 步骤三（`main.tex:1433-1470`）：用 Itô 公式得 $d |c_t|^2 = 2\langle c_t, A_t^{-1/2} dW_t\rangle + 2\langle A_t^{-1} a_t, c_t\rangle dt + \|A_t^{-1/2}\|_{HS}^2 dt$；在 $t < T$ 上用 $A_t \geq c_5 I_n$ 得 $[e]_t \leq 4 c_4^2 c_5^{-1} t$；由 Dambis-Dubins-Schwarz 与 Wiener 反射原理得事件 $F = \{\max_{0 \leq s \leq c_6} \tilde W_s \leq c_4^2/2\}$，$\mathbb{P}(F) \geq 0.9$；另由紧支撑 $\|A_s^{-1/2}\|_{HS}^2 \leq n c_5^{-1}$ 与 $|A_s^{-1} a_s| \leq c_4$ 得 $d |c_t|^2 \leq d e_t + c_7 t$；合并得 $\mathbb{P}(T_1 > c) > c$ 对某 $c$；再 union bound $\mathbb{P}(F \cap E^c) \geq 0.8$，从而 $T \geq c$ 在该事件上成立。

把 (i) 的 $t_0 \geq c(n)$ 与 (ii) 的「下界至少 $c(n)$」合起来得 basic1.5，引理证毕。
